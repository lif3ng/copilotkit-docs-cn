CopilotKit 为 React、React Native、Vue 和 Angular 维护官方包。社区框架补充其他前端，由核心团队之外的人构建和维护。

## 社区的含义

- **仅以一个版本测试**。每个包都会列出它经过测试的 `@copilotkit/core` 版本。请使用该版本。
- **更新属于尽力而为**。社区包可能落后于 CopilotKit 的发布节奏。请在 GitHub 上报告问题。我们会阅读每一份报告，但不承诺响应时间。
- **独立发布**。社区包按自己的节奏发布，不会阻塞 CopilotKit 的发布。
- **每个包的 README 就是它的配置指南**。CopilotKit 文档不覆盖社区包。

## 请求或贡献框架

想请求某个框架，请[提交 issue](https://github.com/CopilotKit/CopilotKit/issues/new/choose)。每份请求都能让我们了解大家需要哪些前端。

要构建一个框架，请从 `@copilotkit/core` 开始。它是框架无关的层，官方包用它处理 agent、工具、上下文和线程。社区包则为其框架添加绑定和聊天 UI。
