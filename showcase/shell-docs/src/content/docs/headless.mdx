## 通过 hooks 获得完全的渲染控制

CopilotKit 的无头（headless）hooks 让你对聊天体验拥有完全的控制权：
消息、流式传输和工具调用等界面统统由你自己组装，不带任何预设的
UI 方案。带上你自己的设计系统，按你的方式渲染一切。

本页有两个可运行的 cell。先从
[**最小实现**](#最小实现headless-simple)开始，看看基于
`useAgent` + `useCopilotKit` 搭建的最小自定义聊天；然后跳到
[**完整实现**](#完整实现headless-complete)，看看完整的生成式 UI
组合（工具调用、推理过程、活动消息、自定义前后插槽）如何用底层
hooks 手工重建。

## 何时使用无头 UI？

以下场景适合使用无头 UI：

- 用自己的设计系统构建完全自定义的聊天界面
- 将智能体聊天集成到现有的 UI 模式中
- 完全掌控消息渲染与交互
- 把生成式 UI 原语（`useRenderToolCall`、
  `useRenderActivityMessage`、`useRenderCustomMessages`）放进一个
  根本不是聊天的布局里

## 最小实现（`headless-simple`）

<FrameworkSetup concept="programmatic-control-setup" />

最精简的形态：三个 hooks 承担了全部重活。

- `useAgent({ agentId })` 暴露当前会话（`messages`、
  `isRunning`）和运行状态对象。
- `useCopilotKit()` 返回运行时句柄，你在它上面调用
  `runAgent({ agent })`（这也是 `<CopilotChat />`
  内部使用的同一个入口）。
- `useComponent(...)`（`useFrontendTool`
  的语法糖）让你注册一个 React 组件，智能体可以通过调用具名工具
  来渲染它。`useRenderToolCall()` 随后返回一个函数，可以把任意工具
  调用内联绘制出来。

## 完整实现（`headless-complete`）

这是本页的核心。`headless-complete` cell 直接用底层 hooks 重建了
**完整的**生成式 UI 编排（文本、经由
`useRenderTool` / `useDefaultRenderTool` / `useComponent` /
`useFrontendTool` 的工具调用、推理卡片、A2UI + MCP Apps 活动消息，
以及自定义前后消息插槽），全程不导入 `<CopilotChatMessageView>` 或
`<CopilotChatAssistantMessage>`。

### `useRenderedMessages` Hook

这个 cell 的核心是一段手写的 `useRenderedMessages(messages,
isRunning)`，它返回同样的扁平消息列表，只是每条消息都附加了一个
`renderedContent: ReactNode` 字段。这个 hook 是**对
`<CopilotChatMessageView>` 所做之事的手工复刻**；可以与标准原语
内部的 `renderMessageBlock` 辅助函数逐行对照：
[`packages/react-core/src/v2/components/chat/CopilotChatMessageView.tsx:542-612`](https://github.com/CopilotKit/CopilotKit/blob/main/packages/react-core/src/v2/components/chat/CopilotChatMessageView.tsx#L542-L612)。

<Snippet region="use-rendered-messages-hook" title="frontend/src/app/use-rendered-messages.tsx — composition hook" />

有三个底层 hooks 为它供料：

- `useRenderToolCall()` —— 返回任意已注册工具调用的渲染器
  （每个工具可经 `useRenderTool` / `useComponent` 指定，外加
  `useDefaultRenderTool` 提供的通配渲染器）。
- `useRenderActivityMessage()` —— 为当前智能体作用域渲染
  A2UI + MCP Apps 活动消息。
- `useRenderCustomMessages()` —— 调用注册在当前生效的
  `CopilotChatConfigurationProvider` 上的 `renderCustomMessage` hooks，
  在每条消息前后产生 `"before"` 与 `"after"` 插槽。
