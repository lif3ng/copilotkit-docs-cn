渠道工具让你的 agent 在 Slack 或 Teams 中工作的同时调用应用代码。上下文则向 agent 提供它应当考虑的信息，而不暴露另一个可调用操作。

安装这些示例用到的 schema 库：

```bash title="Terminal"
npm install zod
```

## 添加渠道级工具

对每条会话都可用的操作，请使用 `defineChannelTool`。参数 schema 会成为该工具的 JSON schema，并为 handler 提供类型。

```ts title="tools.ts"
import { defineChannelTool } from "@copilotkit/channels";
import { z } from "zod";

export const getIncident = defineChannelTool({
  name: "get_incident",
  description: "Read the current status of an incident by its id.",
  parameters: z.object({
    incidentId: z.string().describe("Incident id, for example INC-421"),
  }),
  async handler({ incidentId }) {
    const incident = await incidents.get(incidentId);
    return incident; // objects are serialized for the model
  },
});
```

在创建 Channel 时注册它：

<FrontendOnly frontend="slack">

```ts title="channel.ts"
import { createChannel } from "@copilotkit/channels";
import { makeAgent } from "./agent.js";
import { getIncident } from "./tools.js";

function required(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`Missing ${name}`);
  return value;
}

const channel = createChannel({
  name: required("CHANNEL_CODE"),
  identifyUser: "platform",
  agent: makeAgent,
  tools: [getIncident],
});
```

返回模型可以直接利用的信息：

- 数据类工具返回原始对象或数组。
- handler 已经发布 UI 时，返回简短确认。
- 返回或抛出真实失败原因，让模型可以自行恢复。
- 不要手动对成功数据调用 `JSON.stringify`。

想让 agent 把数据变成图像？请通过[将 JSX 作为图像发布](/channels/posting-jsx-as-images)发布你自己的展示型 React 标记。

## 添加稳定上下文

渠道上下文会在每次 agent 运行时发送：

<FrontendOnly frontend="slack">

```ts title="channel.ts"
import { createChannel } from "@copilotkit/channels";
import { makeAgent } from "./agent.js";

function required(name: string): string {
  const value = process.env[name];
  if (!value) throw new Error(`Missing ${name}`);
  return value;
}

const channel = createChannel({
  name: required("CHANNEL_CODE"),
  identifyUser: "platform",
  agent: makeAgent,
  context: [
    {
      description: "Support policy",
      value:
        "Never disclose credentials. Escalate Sev-1 incidents immediately.",
    },
    {
      description: "Response style",
      value: "Use short paragraphs and put the next action first.",
    },
  ],
});
```

</FrontendOnly>

## 为单轮使用提供方与用户上下文

在托管 Channel 上，`message.platform`、`thread.platform` 以及渠道级工具的 `ctx.platform` 会报告原生来源（`"slack"` 或 `"teams"`）。

运行 agent 时添加原生上下文：

```ts title="channel.ts"
channel.onMessage(async ({ thread, message }) => {
  await thread.runAgent({
    prompt: message.contentParts?.length
      ? [
          ...(message.text
            ? [{ type: "text" as const, text: message.text }]
            : []),
          ...message.contentParts,
        ]
      : message.text,
    context: [
      { description: "Originating platform", value: message.platform },
      {
        description: "Requesting user",
        value: message.user?.name ?? "Unidentified application user",
      },
    ],
  });
});
```

如果某个工具必须限定于当前用户，请在 handler 内定义它，并只为该次运行传入。它的闭包会捕获可信的入站身份：

```ts title="channel.ts"
channel.onMessage(async ({ thread, message }) => {
  if (!message.user) return;
  const listMyApprovals = defineChannelTool({
    name: "list_my_approvals",
    description: "List approvals assigned to the requesting user.",
    parameters: z.object({}),
    async handler() {
      return approvals.forApplicationUser(message.user.id);
    },
  });

  await thread.runAgent({
    prompt: message.text,
    tools: [listMyApprovals],
  });
});
```

把提供方 actor ID 视为外部标识符。涉及个人产品数据时使用解析后的应用 `user`，并在写入前检查其是否为 `null`。

## 将工具结果渲染为原生 UI

工具可以发布一条可移植的 JSX 消息，并向模型返回简短确认：

```tsx title="tools.tsx"
import { defineChannelTool } from "@copilotkit/channels";
import { Header, Message, Section } from "@copilotkit/channels/ui";
import { z } from "zod";

export const showIncident = defineChannelTool({
  name: "show_incident",
  description: "Display an incident summary in the conversation.",
  parameters: z.object({
    id: z.string(),
    status: z.string(),
    summary: z.string(),
  }),
  async handler({ id, status, summary }, { thread }) {
    await thread.post(
      <Message>
        <Header>{`${id} · ${status}`}</Header>
        <Section>{summary}</Section>
      </Message>,
    );
    return `Displayed ${id}.`;
  },
});
```

使用此示例前请先启用 Channels JSX：

```json title="tsconfig.json"
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@copilotkit/channels"
  }
}
```

## MCP 的适用位置

将 MCP 服务器连接到所选的 agent 后端。Channels SDK 会通过 AG-UI 转发渠道工具，与该 agent 已暴露的工具并存，因此你不需要第二条渠道专用的 MCP 传输。从 [MCP 工具](/agentic-protocols/mcp)开始，然后只把 `defineChannelTool` 用于需要当前渠道会话的操作。

继续阅读[交互式消息与审批](/channels/interactive)，或使用 [Channel API 参考](/reference/channels/classes/Channel)。
