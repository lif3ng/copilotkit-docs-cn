轨迹会记录你应用中的一次会话，可以包含点击、表单编辑、页面切换与网络请求。

CopilotKit Intelligence 会存储这些事件，并关联相关的智能体对话。你可以查看用户在对话之前、期间与之后做了什么。

<Callout type="info" title="与工程团队一起抢先体验">
  轨迹功能目前处于抢先体验阶段，用于与我们的工程团队进行概念验证。如需访问方面的帮助，请[预约我们的工程师](https://www.copilotkit.ai/talk-to-an-engineer)。
</Callout>

从[快速开始](/intelligence/trajectories-quickstart)入手，在自托管的 Intelligence 中录制你的第一次会话。

## 轨迹与 Automatic Learning 的关系

轨迹提供关于用户如何使用你应用的证据。[Automatic Learning](/learning) 会分析这些证据，并提出供你审阅的 Skill。

仅靠捕获不会启动分析，也不会改变智能体。要把轨迹用作证据，需将它加入 Learning Space。参见[将浏览器活动分配到 Learning Space](/learning#assign-browser-activity-to-a-learning-space)。

在你审阅并发布某个 Skill 之后，[Skill 交付](/intelligence/learned-skills)会让智能体能够使用它。

[User Memory](/intelligence/memories) 跨会话存储关于某个用户的事实，它是一个独立的特性。录制和查看轨迹既不需要 User Memory，也不需要 Automatic Learning。
