## 概览

每个组织都从 **Developer** 计划开始，该计划免费，包含 AG-UI Streams、用户记忆和自动学习，外加产品分析的限量试用。完整的产品分析属于 Enterprise 计划。当你的团队或流量需要时再升级。

<Accordions>
  <Accordion title="Developer 计划包含什么？">
    Developer 包含一个席位、AG-UI Streams、用户记忆和自动学习，还包含产品分析的限量试用。免费计划有用量限制。
  </Accordion>
  <Accordion title="何时应该升级到付费计划？">
    在逐步完善应用时升级到 **Pro**，当整个团队都需要访问时选择 **Team**，当你的智能体大规模运行或必须运行在你自己的基础设施中时选择 **Enterprise**。当前计划详情请参见[定价页面](https://dashboard.operations.copilotkit.ai/pricing)。
  </Accordion>
  <Accordion title="Developer 计划包含产品分析吗？">
    Developer 包含产品分析的限量试用。完整的产品分析属于 Enterprise 计划。
  </Accordion>
  <Accordion title="抢先体验是什么意思？">
    抢先体验（early access）特性遵循抢先体验计划，在正式发布前可能发生变化。云托管与自托管部署的比较请参见[架构页面](/intelligence/intelligence-platform)。
  </Accordion>
</Accordions>
