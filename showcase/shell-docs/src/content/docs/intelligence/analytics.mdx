## 概览

产品数据分析基于 Intelligence 已记录的智能体运行，展示用户如何使用你的智能体、它的可靠性如何、成本是多少。无需任何额外的埋点工作。

智能体调用了哪些工具？有多少人在使用它？运行失败的频率有多高？活动（Activity）、可靠性（Reliability）、Token、记忆（Memory）这几个标签页会针对一个项目、一个时间范围回答这些问题。

产品数据分析在 Developer 套餐中以限量试用形式提供；完整功能属于 Enterprise 套餐。项目侧边栏会显示你的套餐可用的特性；当前的用量限制请参阅[定价页面](/intelligence/plans#overview)。

## 查看你的首批指标

<Steps>
  <Step>
    ### 连接你的应用

    按照[快速开始](/intelligence/quickstart)操作。它会通过 CLI 让你登录、选择一个项目，并把项目密钥写入 `.env`。产品数据分析只统计通过该密钥到达 Intelligence 的运行。

  </Step>

  <Step>
    ### 发送几条消息

    像真实用户一样使用你的应用：提一个问题、触发一个工具、完成一次对话。每次运行都会成为项目中的一组运行时事件。你可以在 [AG-UI Streams](/AG-UI-Streams) 或 Inspector 中打开该线程，确认运行已经落地。

  </Step>

  <Step>
    ### 打开产品数据分析

    在[云托管版 Intelligence](/intelligence/managed-intelligence-platform) 中打开你的项目，并在侧边栏中选择**产品数据分析**。右上角的状态徽标会先显示**正在加载指标**，随后显示**指标已加载**。

    如果显示的是**项目尚无指标**，说明还没有任何运行到达该项目。在有运行到达之前，页面会一直展示一个演示仪表盘。

  </Step>

  <Step>
    ### 选择时间范围

    选择 **1 小时**、**1 天**、**3 天**或 **7 天**；也可以选择**自定义**来指定起止时间。所选范围会应用到每一个标签页。如果该范围内没有运行，页面会显示**该范围内暂无数据**。

  </Step>

  <Step>
    ### 阅读活动标签页

    页面默认打开**活动**标签页。四个指标卡汇总了所选范围的情况，三张图表展示其随时间的变化。下一节会逐一说明。

  </Step>
</Steps>

## 产品数据分析的工作原理

### 统计哪些内容

每个经过 Intelligence 的智能体运行都会产生运行时事件：运行开始、消息流式传输、工具被调用、模型响应、运行结束或失败。在每次运行被接受后不久，Intelligence 会把这些事件写入一个时序存储。产品数据分析会针对你的项目查询该存储。

有两类情况不会被统计：

- 从其他系统[导入](/threads-import)的线程。只有实时运行才会产生运行时事件。
- 从未到达 Intelligence 的运行，例如没有配置项目密钥的本地应用。

运行时事件会保留 **90 天**。如果所选范围的起点早于此期限，将只返回仍然存储着的数据。

### 分桶

每张图表都会把事件归入分桶（bucket）。分桶的粒度随时间范围变化：

| 时间范围                   | 分桶粒度 |
| -------------------------- | ------ |
| 1 小时、1 天、3 天         | 按小时 |
| 7 天                       | 按天   |
| 自定义，不超过 3 天        | 按小时 |
| 自定义，超过 3 天          | 按天   |

指标卡上标注的**最新分桶**或**最繁忙分桶**指的就是这些分组。指标卡上的小百分比是把范围内的最后一个分桶与第一个分桶进行比较。错误率上升时会显示为负向趋势，即便数字本身在变大。

### 标签页

| 标签页          | 指标卡                                                   | 图表                                                                                                                                                           |
| --------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **活动**        | 运行时事件、活跃用户、平均事件量、峰值事件量             | **事件量**，每个分桶的运行时事件数。**活跃用户**，在此期间与智能体交互过的人数。**工具使用占比**，每个工具的调用次数。                                          |
| **可靠性**      | 错误率、错误事件、工具调用、无错误运行                   | 随时间变化的**错误率**，按总活动量归一化。**工具使用**，每个分桶中使用最多的工具。**错误占比**，无错误运行与出现错误的运行之比。                                |
| **Token**       | 总 Token 数、平均响应、峰值响应、输出 Token              | **Token 量**、**响应时间**，以及输入与输出之间的 **Token 分布**。                                                                                              |
| **记忆**        | 已创建、已失效、净新增、留存                             | 每天的**记忆创建**、**记忆失效**与**记忆分布**。                                                                                                                |

几点说明：

- **活跃用户**统计的是去重后的应用用户。Intelligence 会记录你的应用随每次运行传递的用户 ID，因此请为每个用户传递一个稳定的 ID。参见[将 AG-UI Streams 限定为已登录用户](/threads-lifecycle#scope-rich-threads-to-the-signed-in-user)。
- **工具使用占比**按工具名称对工具调用进行分组。图例会以文字形式显示每个名称，因此名为 `show_capabilities` 的工具会显示为 **Show capabilities**。
- **错误事件**指以错误结束的运行。**无错误运行**则是未出错的运行所占比例。
- **Token** 与**响应时间**在运行结束时记录。在模型响应之前就失败的运行没有 Token 计数。
- **记忆**标签页读取的是[用户记忆](/intelligence/memories)而非运行时事件，因此它反映的是记忆每天保存与失效的内容。只有当项目开启自动学习（Automatic Learning）时，该标签页才会出现。

### 状态消息

| 页面显示                                    | 含义                                                           | 处理方式                                                              |
| ------------------------------------------- | ------------------------------------------------------------- | --------------------------------------------------------------------- |
| **指标已加载**                              | 每个指标都返回了数据。                                         | 无需操作。                                                            |
| **该范围内暂无数据**                        | 存储中有该项目的事件，但此范围内没有。                         | 扩大时间范围。                                                        |
| **项目尚无指标**                            | 还没有任何运行到达该项目。                                     | 完成[快速开始](/intelligence/quickstart)并发送一条消息。              |
| **你的角色无法使用数据分析**                | 你在该项目中的角色无权读取分析数据。                           | 向项目管理员申请权限。                                                |
| **数据分析暂时不可用**                      | 存储没有响应。                                                 | 点击指标卡上的**重试**，或稍后再试。                                  |

无法加载的指标卡会显示 **N/A** 和一个**重试**按钮。其他指标卡不受影响。

## 自托管部署

在云托管版 Intelligence 上，CopilotKit 会为你运行数据分析管线。而[自托管](/intelligence/self-hosting)部署则会在你自己的网络内运行该管线。在 Helm values 中开启它：

```yaml title="values.yaml"
analytics:
  enabled: true
  database:
    # A Secret that holds the TimescaleDB URL. Use sslmode=verify-full.
    existingSecret: intelligence-analytics-db
    secretKeys:
      url: timescale-url
  migrations:
    enabled: true
    # A schema-owner credential. Do not reuse the runtime credential.
    existingSecret: intelligence-analytics-db-owner
```

Chart 会把 TimescaleDB URL 传给应用 API 与实时网关，并以 Job 的形式执行 schema 迁移。你的许可证必须包含数据分析功能。管线一开启，整个部署的事件就会被记录下来，因此当你打开页面时历史数据已经在那里了。安装的其余内容见[自托管指南](/intelligence/self-hosting)。

## 导出到你自己的工具

产品数据分析是 Intelligence 内部的一个视图，图表本身无法导出。

自托管部署可以把链路追踪（traces）和产品事件（例如线程被创建、运行被发起）发送到你自行运行的 OpenTelemetry collector。产品事件绝不包含消息内容。[使用 OpenTelemetry 监控](/intelligence/self-hosting-observability)列出了每一路数据流的内容与开启方式。
