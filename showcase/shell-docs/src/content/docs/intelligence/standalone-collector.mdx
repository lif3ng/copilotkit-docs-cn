## 概览

`@copilotkit/learning` 会将点击、表单编辑、页面切换与网络请求捕获为 AG-UI `CUSTOM` 事件，并以批次发送到你提供的 sink。这个独立集成目前处于实验阶段，且面向自托管场景。

默认情况下，捕获会保留浏览器可见的文本、值、请求头、有长度上限的 body 快照以及完整 URL。字段、限制与显式排除项请参阅[捕获的数据](/intelligence/captured-data)。

完成后，你的应用就会把事件批次发送到你自己的端点。你还可以为你在意的结果补充自定义事件。

## 采集事件

<Steps>
  <Step>
    ### 安装软件包

    ```bash
    npm install @copilotkit/learning
    ```

  </Step>
  <Step>
    ### 创建采集器并启动

    ```ts title="src/capture.ts"
    import { createCollector, httpSink } from "@copilotkit/learning";

    export const collector = createCollector({
      sink: httpSink("/api/learning-events"),
    });

    collector.start({ trajectoryId: crypto.randomUUID() });
    ```

    在调用 `start()` 之前，采集器不会安装任何监听。只有在用户允许捕获之后，再调用 `start()`。

  </Step>
  <Step>
    ### 为结果添加事件

    点击能反映用户做了什么，却不能反映是否成功。当结果已可知时，发出一个事件：

    ```ts
    collector.emit("report.exported", { format: "csv", rows: 120 });
    ```

    请使用你自己的命名。`click` 等内置名称是保留名。

  </Step>
  <Step>
    ### 会话结束时停止

    ```ts
    collector.stop();
    ```

    `stop()` 会移除所有监听器与补丁，然后把队列中的事件发送一次。它不会等待送达，也不会重试失败的发送。

  </Step>
</Steps>

此时你的端点就会收到形如 `{ "trajectoryId": "...", "events": [...], "dropped": 0 }` 的批次。

## 将事件发送到别处

sink 是一个接收每批数据的函数。可以用它把事件转发到你自己的服务：

```ts
import { createCollector } from "@copilotkit/learning";
import type { LearningBatch } from "@copilotkit/learning";

const collector = createCollector({
  sink: async (batch: LearningBatch) => {
    const response = await fetch("https://events.example.com/ingest", {
      method: "POST",
      headers: { "content-type": "application/json" },
      body: JSON.stringify(batch),
    });
    if (!response.ok) throw new Error(`Capture endpoint returned ${response.status}`);
  },
  ignoreUrls: ["https://events.example.com/"],
});
```

把 sink 的 URL 加入 `ignoreUrls`，这样采集器就不会记录自己发出的请求。`httpSink` 已替你做好这一点。

## 为点击添加上下文

`enrich` 会根据被点击的元素为每次点击补充字段：

```ts
const collector = createCollector({
  sink: httpSink("/api/learning-events"),
  enrich: (element) => ({
    section: element.closest("[data-section]")?.getAttribute("data-section") ?? null,
  }),
});
```

捕获本身已包含元素文本、属性以及控件的实时值。`enrich` 用于补充额外的应用上下文。要排除数据，请使用 `beforeSend`、捕获开关或 `data-copilotkit-ignore`。

完整的字段与控件清单请参阅[捕获的数据](/intelligence/captured-data)。如果使用 CopilotKit，请改用 [`learning` prop](/intelligence/capture-interactions)。
