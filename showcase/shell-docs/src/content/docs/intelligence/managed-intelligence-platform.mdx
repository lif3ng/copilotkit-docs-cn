## 概览

云托管 Intelligence 为你代管整个平台：只需一个项目和一个 API 密钥，无需运维任何集群。你的应用仍然使用 CopilotKit SDK。

![云托管 Intelligence 就绪页面。](/images/cloud-hosted/cloud-hosted-ready.png)

云托管服务会存储项目的线程、事件和 API 密钥。你只需创建一次项目，用 CLI 连接你的应用，其余一切都在 Web 应用中完成。

Web 应用面向构建和运营该应用的人。与你的智能体对话的用户无需在那里登录。你的应用仍会识别这些用户，并通过运行时传递其身份。

请在[架构页面](/intelligence/intelligence-platform)上将此部署方式与自托管进行比较。

## 开始使用

从 [intelligence.copilotkit.ai](https://intelligence.copilotkit.ai) 或 CopilotKit CLI 开始。

<Steps>
  <Step>
    ### 登录

    新账户需接受 CopilotKit 自助服务协议。已接受过该协议的账户不会再次弹出。

    <OpsPlatformCTA
      variant="inline"
      title="开始云托管配置"
      body="登录并创建组织，然后返回 CLI 或 Web 应用并选择一个项目。"
      ctaLabel="开始云托管配置"
      href="https://intelligence.copilotkit.ai/"
      surface="docs_intelligence_managed_platform_intro"
    />

    新组织可选择 Developer 计划或付费计划。Developer 是免费计划。想更改这一选择时，请阅读[计划](/intelligence/plans)。
  </Step>

  <Step>
    ### 创建或选择组织

    在浏览器中选择一个组织，或创建一个新组织。
  </Step>

  <Step>
    ### 返回发起跳转的工具

    完成组织步骤后，浏览器会返回打开它的 CLI 或 Web 应用。如果是 CLI 打开的浏览器，请回到终端并让命令继续执行。
  </Step>

  <Step>
    ### 选择或创建项目

    一个项目承载一个应用或一个环境。请为生产、预发布、演示和实验分别创建独立的项目。它们的 API 密钥和线程彼此隔离。

    在[快速开始](/intelligence/quickstart#select-an-intelligence-project)中登录并选择项目。该页面会把 `CPK_INTELLIGENCE_API_KEY` 写入 `.env`。

    另有两个命令适用于不同的起点：

    - `npx copilotkit@latest create` 创建一个新应用并写入同样的密钥。
    - `npx copilotkit@latest skills onboard` 将 CopilotKit 添加到现有应用。
  </Step>
</Steps>

[CopilotKit CLI](/cli) 使用同样的登录方式。首次 `login` 会打开浏览器登录页面并保存本地会话。后续命令会复用该会话。`project select` 会创建项目 API 密钥并写入 `.env`。

![云托管项目列表。](/images/cloud-hosted/cloud-hosted-projects.png)

选择一个项目即可打开其**概览**。项目导航将其页面分为两个区域：

- **Overview**、**Product Analytics** 和 **Automatic Learning** 展示项目动态与分析。在 Developer 试用期内，Product Analytics 和 Automatic Learning 会标记 **TRIAL**。
- **Project resources** 包含[线程](/AG-UI-Streams)、[渠道](/intelligence/channels)、[用户记忆](/intelligence/memories)和 [API 密钥](#创建-api-密钥)。

每个页面都限定于所选项目。该项目 API 密钥将你的运行时连接到同一个项目。

在项目内打开 **Threads**，即可查看为该项目保存的对话。

![云托管项目及其线程。](/images/cloud-hosted/cloud-hosted-thread-list.png)

打开某个线程即可查看其事件时间线。

![云托管线程及其事件时间线。](/images/cloud-hosted/cloud-hosted-thread-detail.png)

线程页面会显示智能体、应用用户、状态、最后更新时间和事件时间线。需要查看原始负载时，可以打开某个事件。**Rename**、**Archive** 和 **Delete** 与你应用中的线程 API 对应：archive 会将线程从活动列表中隐藏并保留历史，delete 则将其删除。线程在应用中的工作方式请阅读 [AG-UI Streams](/AG-UI-Streams)。

## 创建 API 密钥

项目 API 密钥将你的运行时连接到该项目。[快速开始](/intelligence/quickstart#select-an-intelligence-project)会把它作为 `CPK_INTELLIGENCE_API_KEY` 写入 `.env`。`init` 及其别名 `create` 在创建应用时也会写入同样的密钥。

云托管配置不会签发 `COPILOTKIT_LICENSE_TOKEN`。许可证密钥仅用于自托管部署。它不能替代项目 API 密钥。

请将 `CPK_INTELLIGENCE_API_KEY` 保存在服务器端。

![云托管 API 密钥页面。](/images/cloud-hosted/cloud-hosted-api-keys.png)

CLI 会将完整密钥写入 `.env`。之后再运行一次 `project select` 会为同一项目创建另一个密钥。删除某个密钥会导致所有仍在使用它的应用失效。

请在[快速开始](/intelligence/quickstart)中连接该密钥。
