title: "第 1 步：检出仓库"
---

<Steps>
<Step>
### 检出仓库

我们首先检出待办列表应用的基础代码。

```shell
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit/examples/starters/todos-app/start
```

</Step>
<Step>
### 安装依赖

运行以下命令安装依赖：

```shell
npm install
```

</Step>
<Step>
### 启动项目

现在可以运行以下命令启动项目：

```shell
npm run dev
```

现在你可以访问 [http://localhost:3000](http://localhost:3000) 查看待办列表应用。不妨先随意把玩一番，找找感觉。

</Step>
</Steps>
