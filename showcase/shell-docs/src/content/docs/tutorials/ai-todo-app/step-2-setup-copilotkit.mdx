待办列表应用已经跑起来了，接下来可以集成 CopilotKit。本教程需要安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit provider 和一系列实用的 hook。
- `@copilotkit/react-ui`：CopilotKit 的 UI 库，包含侧边栏、聊天弹窗、文本框等 CopilotKit UI 组件。

## 安装依赖

运行以下命令安装 CopilotKit 依赖：

```npm
npm install @copilotkit/react-core
```

### CopilotKit 聊天弹窗

我们提供了多个即插即用的组件，方便你与 copilot 交互，例如 `<CopilotPopup/>`、`<CopilotSidebar/>` 和 `<CopilotChat/>`。当然，你也可以以无头（headless）模式使用 CopilotKit，并通过 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) 提供完全自定义的 UI。

本教程将使用 `<CopilotPopup/>` 组件来显示聊天弹窗。

```tsx title="app/page.tsx" showLineNumbers {6-7,15}
"use client";

export default function Home() {
  return (
    <>
      <TasksProvider>
        <TasksList />
      </TasksProvider>
      {/* [!code highlight:1] */}
      <CopilotPopup />
    </>
  );
}
```

我们做了这几件事：

- 我们从 `@copilotkit/react-ui` 导入了 `<CopilotPopup />` 组件。
- 我们用 `<CopilotKit>` provider 包裹了页面。
- 我们从 `@copilotkit/react-ui` 导入了内置样式。

现在回到应用，你会在页面右下角看到一个聊天弹窗。到这里，就可以开始与你的 copilot 互动了！🎉
