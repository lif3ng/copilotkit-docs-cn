接下来，让 copilot 能够执行工具，变得更加强大好用。

## 可用工具

我们再来看一看 [`lib/hooks/use-tasks.tsx`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/starters/todos-app/start/lib/hooks/use-tasks.tsx#L19-L33) 文件中的应用状态。

本质上，我们希望 copilot 能够调用 `addTask`、`setTaskStatus` 和 `deleteTask` 这几个函数。

## `useFrontendTool` hook

[`useFrontendTool`](/reference/v1/hooks/useFrontendTool) hook 可以把工具提供给 copilot。我们在 [`lib/hooks/use-tasks.tsx`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/starters/todos-app/start/lib/hooks/use-tasks.tsx) 文件中实现它。

```tsx filename="lib/hooks/use-tasks.tsx" showLineNumbers {3-3,8-22,24-38,40-61}
// ... the rest of the file

export const TasksProvider = ({ children }: { children: ReactNode }) => {
  const [tasks, setTasks] = useState<Task[]>(defaultTasks);

  // [!code highlight:10]
  useFrontendTool({
    name: "addTask",
    description: "Adds a task to the todo list",
    parameters: z.object({
      title: z.string().describe("The title of the task"),
    }),
    handler: async ({ title }) => {
      addTask(title);
      return `Added task: ${title}`;
    },
  });

  // [!code highlight:10]
  useFrontendTool({
    name: "deleteTask",
    description: "Deletes a task from the todo list",
    parameters: z.object({
      id: z.number().describe("The id of the task"),
    }),
    handler: async ({ id }) => {
      deleteTask(id);
      return `Deleted task ${id}`;
    },
  });

  // [!code highlight:11]
  useFrontendTool({
    name: "setTaskStatus",
    description: "Sets the status of a task",
    parameters: z.object({
      id: z.number().describe("The id of the task"),
      status: z
        .enum(Object.values(TaskStatus) as [string, ...string[]])
        .describe("The status of the task"),
    }),
    handler: async ({ id, status }) => {
      setTaskStatus(id, status);
      return `Set task ${id} status to ${status}`;
    },
  });

  // ... the rest of the file
};
```

`useFrontendTool` hook 功能强大，可以在 copilot 中注册工具。它接收一个包含以下属性的对象：

- `name`：工具的名称。
- `description`：工具的描述。描述要写得贴切，这样 copilot 才能选对工具。
- `parameters`：一个 Zod schema，定义工具接受的参数，同时提供运行时校验和 TypeScript 类型推断。
- `handler`：工具被触发时调用的函数。得益于 Zod，它是类型安全的！

`useFrontendTool` hook 的完整参考请见[这里](/reference/hooks/useFrontendTool)。
