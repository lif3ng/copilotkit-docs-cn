## 你将学到什么

在本教程中，我们将以一个简单的待办列表应用为例，为它加上 copilot 的强力加持。你将学到：

- 如何嵌入带聊天 UI 的应用内 copilot
- 如何使用 `useAgentContext` 让 copilot 读取应用状态
- 如何使用 `useFrontendTool` 让 copilot 执行工具
