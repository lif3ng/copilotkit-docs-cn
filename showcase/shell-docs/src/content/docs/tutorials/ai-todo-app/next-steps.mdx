## 接下来做什么？

关于后续步骤，这里有一些想法：

- 使用 [`useCopilotChatSuggestions`](/reference/v1/hooks/useCopilotChatSuggestions) hook 为你的 copilot 添加建议。
- 为聊天窗口添加一条初始助手消息（更多信息请查看 [`<CopilotPopup />`](/reference/v1/components/chat/CopilotPopup) 的文档）。
- 深入了解十分好用的 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) hook，它让你能够设置系统消息、追加消息等。
- 使用 [`<CopilotTextarea />`](/reference/v1/components/CopilotTextarea) 组件实现自动补全。
- 跟随 [文本框自动补全教程](/tutorials/ai-powered-textarea/overview) 进一步了解 CopilotKit。

更多教程即将推出，敬请期待。
