## 你将学到什么

在本教程中，你将从一个简单的邮件应用出发，为它添加 AI 驱动的自动补全。该应用是一个基础的邮件客户端，带有一个用于撰写邮件的纯 textarea。你将加入 CopilotKit，让 textarea 在你输入时提供相关的自动补全，并能感知完整的邮件历史。

你将学到：

- 如何使用 `useAgentContext` 让你的 copilot 访问应用的状态
- 如何使用 `<CopilotTextarea />` 组件实现上下文感知的自动补全
- 如何使用 Copilot Textarea Action Popup 生成或调整已有文本
