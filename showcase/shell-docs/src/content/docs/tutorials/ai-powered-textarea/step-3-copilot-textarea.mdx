目前，我们的应用只有一个用于回复邮件的普通文本框。现在我们把它替换成 AI 文本框，让这位乐于助人的 AI 助手派上用场。

## `<Reply />` 组件

打开 [`/components/Reply.tsx`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/starters/textarea/start/components/Reply.tsx) 文件。

一眼望去就能发现，该组件使用 `useState` 保存当前输入值并提供给文本框，同时利用文本框的 `onChange` prop 更新状态。

## 实现 `<CopilotTextarea />`

`<CopilotTextarea />` 组件的设计初衷就是作为 `<textarea />` 组件的直接替代品。动手实现它吧！

```tsx title="components/Reply.tsx"
// ... the rest of the file

export function Reply() {
  // ...
  return (
    <div className="mt-4 pt-4 space-y-2 bg-background p-4 rounded-md border">
      <CopilotTextarea // [!code highlight]
        className="min-h-40 border h-40 p-2 overflow-hidden"
        value={input}
        onChange={(e) => setInput(e.target.value)}
        placeholder="Write your reply..."
        // [!code highlight:4]
        autosuggestionsConfig={{
          textareaPurpose: `Assist me in replying to this email thread. Remember all important details.`,
          chatApiConfigs: {},
        }}
      />
      <Button disabled={!input} onClick={handleReply}>
        Reply
      </Button>
    </div>
  );
}
```

我们导入 `<CopilotTextarea />` 组件，并用它替换原来的 `<textarea />` 组件，此外还做了一些可选的样式调整。

我们可以通过 `autoSuggestionsConfig.textareaPurpose` 属性，为这个特定文本框提供更具体的指令。

## 试试看吧！

现在回到应用，在文本框里随便输入点什么。你会看到 AI 助手随着你的输入实时给出建议。是不是很酷？

## `CMD + K`/`CTRL + K` 快捷键

在文本框获得焦点时，你可以使用 `CMD + K`（macOS）或 `CTRL + K`（Windows）快捷键打开操作弹窗。在这里，你可以给 copilot 下达具体指令，例如：

- `Rephrase the text to be more formal`
- `Make the reply shorter`
- `Tell John that I'm happy to help`

`<CopilotTextarea />` 已经接入完毕，但 copilot 还不了解这封邮件的往来内容 —— 自动补全无法引用更早的邮件消息。
