现在我们的待办清单应用已经跑起来了，可以开始集成 CopilotKit。在本教程中，我们将安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit provider 和实用的钩子。
- `@copilotkit/react-textarea`：CopilotKit 的 textarea 组件，让你能在应用中获得即时的上下文感知自动补全。

## 安装依赖

要安装 CopilotKit 依赖，请运行以下命令：

```npm
npm install @copilotkit/react-core @copilotkit/react-textarea
```
