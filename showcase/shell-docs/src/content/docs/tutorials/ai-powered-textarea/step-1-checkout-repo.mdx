---
title: "第 1 步：检出仓库"
---

<Steps>
<Step>
### 检出仓库
我们先检出 textarea 应用的基础代码。

```shell
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit/examples/starters/textarea/start
```

</Step>
<Step>
### 安装依赖

要安装依赖，请运行以下命令：

```shell
npm install
```

</Step>
<Step>
### 启动项目

现在，你可以运行以下命令来启动项目：

```shell
npm run dev
```

你应该可以访问 [http://localhost:3000](http://localhost:3000) 看到 textarea 应用。不妨先随意把玩一下这个应用，找找感觉。

</Step>
</Steps>
