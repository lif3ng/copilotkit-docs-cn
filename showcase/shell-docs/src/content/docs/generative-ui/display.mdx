## 这是什么？

仅展示（render-only）的生成式 UI 允许你把 React 组件注册为智能体可调用的工具。当智能体调用该工具时，CopilotKit 会把工具参数作为 props 直接在聊天中渲染你的组件，无需处理逻辑，也无需用户交互。

```tsx

export const ChartProps = z.object({
  title: z.string(),
  data: z.array(z.object({ label: z.string(), value: z.number() })),
});

export function Chart({ title, data }: z.infer<typeof ChartProps>) {
  return (
    <div>
      <h3>{title}</h3>
      <ResponsiveContainer width="100%" height={300}>
        <BarChart data={data}>
          <XAxis dataKey="label" /><YAxis /><Tooltip />
          <Bar dataKey="value" fill="#6366f1" />
        </BarChart>
      </ResponsiveContainer>
    </div>
  );
}
````

## 何时使用？

当你想要以下效果时，可使用仅展示的生成式 UI：

- 在聊天中内联展示富 UI（卡片、图表、表格）
- 展示来自智能体响应的结构化数据
- 渲染预览、状态指示器或可视化反馈
- 让智能体以纯文本之外的形式呈现信息
