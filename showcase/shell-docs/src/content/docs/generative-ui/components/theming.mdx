## 这是什么？

标准组件的默认外观是中性风格。你会希望它们使用你的强调色、你的字体和你的深色模式。

标准组件的每一种颜色、圆角、阴影和字体都是一个 CSS 变量。通过 `theme` 选项设置这些变量：

```tsx
<CopilotKitProvider
  runtimeUrl="/api/copilotkit"
  generativeUI={{
    ui: standardUI,
    theme: {
      "--a2ui-color-accent": "#d97706",
      "--a2ui-font-family": "Inter, sans-serif",
      "--a2ui-radius-md": "10px",
    },
  }}
>
```

这些键是带类型的。组件不读取的名称（例如 `"--a2ui-color-acent"`）会导致类型错误。

## 变量列表

| 分组 | 变量 |
| --- | --- |
| 强调色与控件 | `--a2ui-color-accent`、`--a2ui-color-on-accent`、`--a2ui-color-control`、`--a2ui-color-focus` |
| 表面色 | `--a2ui-color-surface`、`--a2ui-color-surface-secondary`、`--a2ui-color-surface-elevated`、`--a2ui-color-panel` 以及更多 `--a2ui-color-surface-*` |
| 文本 | `--a2ui-color-text-default`、`--a2ui-color-text-secondary`、`--a2ui-color-text-tertiary` 以及 `--a2ui-color-text-*` 状态色 |
| 边框 | `--a2ui-color-border-default`、`--a2ui-color-border-subtle`、`--a2ui-color-border-strong`、`--a2ui-color-border-control` |
| 形状与字体 | `--a2ui-radius-*`、`--a2ui-shadow-xs` 到 `--a2ui-shadow-md`、`--a2ui-font-family` |
| 图表 | `--a2ui-chart-1` 到 `--a2ui-chart-6` |

在 `theme` 中键入键名时，编辑器会列出全部变量。如果要把主题定义在单独的文件中，可以使用 `GenerativeUITheme`：

```ts
import type { GenerativeUITheme } from "@copilotkit/react-core/v2/generative-ui";

export const theme: GenerativeUITheme = { "--a2ui-color-accent": "#d97706" };
```

## 深色模式

深色模式是内置的。当某个祖先元素带有 `dark` 类时，标准组件会切换为深色配色，与 CopilotKit 聊天组件的规则相同：

```html
<html class="dark">
```

如果你的应用已经用 `dark` 类来切换深色模式，则无需任何操作。若要跟随系统设置，请在 `<head>` 中用一小段脚本设置该类，以避免页面闪烁：

```tsx
const colorSchemeScript = `(() => {
  const media = matchMedia("(prefers-color-scheme: dark)");
  const apply = () => document.documentElement.classList.toggle("dark", media.matches);
  apply();
  media.addEventListener("change", apply);
})();`;

<head>
  <script dangerouslySetInnerHTML={{ __html: colorSchemeScript }} />
</head>;
```

## 各模式的颜色

`theme` 顶层的值在浅色与深色模式下都生效。`dark` 中的值仅在深色模式下覆盖它们：

```tsx
theme: {
  "--a2ui-color-accent": "#d97706",
  dark: {
    "--a2ui-color-panel": "#1f2937",
    "--a2ui-color-surface": "#111827",
  },
},
```

因此，品牌强调色只需在顶层设置一次，只有深色模式下不同的颜色才放进 `dark`。

## 地图

`Map` 组件默认绘制浅色底图，深色模式下则绘制深色底图。可以为每种模式指定你自己的 [MapLibre 样式](https://maplibre.org/maplibre-style-spec/)：

```tsx
theme: {
  mapStyle: "https://tiles.example.com/light.json",
  dark: { mapStyle: "https://tiles.example.com/dark.json" },
},
```

## 在 CSS 中设置变量

你也可以在样式表中、在包裹每个界面载体的 `.a2ui-surface` 元素上设置这些变量：

```css
.a2ui-surface {
  --a2ui-color-accent: #d97706;
}
```

`theme` 中的值优先于 CSS 中的同名变量。

现在，你的强调色、字体和深色配色会应用到每一个标准组件，无论是在聊天中还是在页面上。
