# 生成式 UI

CopilotKit 支持多种生成式 UI 方案：

- [仅展示](/generative-ui/display)——智能体渲染只读组件
- [交互式](/generative-ui/interactive)——智能体渲染带回调的交互式组件
- [工具渲染](/generative-ui/tool-rendering)——将后端工具调用映射为 UI 组件
- [状态渲染](/generative-ui/state-rendering)——从智能体状态渲染 UI
- [MCP Apps](/generative-ui/mcp-apps)——Model Context Protocol 集成
- [组件与界面载体](/generative-ui/components)：智能体在聊天中以及页面各区域渲染你的 React 组件
- [A2UI](/generative-ui/a2ui)——Agent 到 UI 的协议
- [你的组件](/generative-ui/your-components)——使用你自己的组件库
