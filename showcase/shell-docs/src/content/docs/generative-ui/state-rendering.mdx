## 这是什么？

状态渲染让你能构建实时反映智能体状态的 UI。当你的智能体在各节点间推进并发出状态更新时，前端会渲染这些变化，展示进度、草稿或中间结果。

## 什么时候应该使用？

当你想要以下效果时，就使用状态渲染：

- 展示实时进度（例如“正在研究…… 已完成 2/5”）
- 展示随智能体工作而更新的草稿
- 构建反映智能体状态的仪表盘
- 在聊天之外渲染结构化输出

## 代码中的工作方式

在前端，订阅智能体的状态。每当后端转发来一个新值，你的组件就会带着最新的部分输出重新渲染。

<Snippet region="frontend-use-coagent-state" title="frontend/src/app/page.tsx —— 智能体状态订阅" />

在后端，状态流式映射会在某个工具参数*生成的过程中*把它直接转发进一个状态键。一些框架以中间件的形式提供这一能力；直接集成的 SDK 适配器则可以在其流式循环中发出 `STATE_SNAPSHOT` 事件。无论哪种方式，UI 都能看到答案逐 token 拼装成型，而不是在检查点之间一次性蹦出来。
