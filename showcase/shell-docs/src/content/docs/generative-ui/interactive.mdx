## 这是什么？

交互式的生成式 UI 可以构建这样的流程：智能体暂停执行，等待用户输入后再继续。它适用于审批工作流、确认对话框，以及任何需要在执行中途引入人工判断的场景。

## 何时使用？

当你需要以下能力时，可使用交互式的生成式 UI：

- 审批/驳回流程（例如“要运行这条命令吗？”）
- 智能体应当知晓的用户决策
- 带结构化响应的确认对话框
- 任何需要智能体暂停以等待人工判断的流程
