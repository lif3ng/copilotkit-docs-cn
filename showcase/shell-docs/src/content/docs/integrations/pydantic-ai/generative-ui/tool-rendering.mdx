## 这是什么？

工具（tool）是 LLM 调用预定义（通常为确定性）函数的方式。CopilotKit 允许你在 UI 中把这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 什么时候该用它？

在 UI 中渲染工具，适合在你希望向用户反馈智能体正在做什么时使用，尤其是智能体正在调用工具的场景。CopilotKit 允许你完全自定义这些工具在聊天中的渲染方式。

### 给你的智能体一个可调用的工具

<Tabs groupId="language_pydantic-ai_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from pydantic_ai import Agent
        from pydantic_ai.ui.ag_ui import AGUIAdapter
        from starlette.applications import Starlette
        from starlette.requests import Request
        from starlette.responses import Response
        from starlette.routing import Route

        agent = Agent("openai:gpt-5.4-mini")


        @agent.tool_plain
        async def get_weather(location: str = "Everywhere ever") -> str:
            """Get the weather for a given location. Ensure location is fully spelled out."""
            return f"The weather in {location} is sunny."


        async def run_agent(request: Request) -> Response:
            return await AGUIAdapter.dispatch_request(request, agent=agent)


        app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])

        if __name__ == "__main__":
            import uvicorn

            uvicorn.run(app, host="0.0.0.0", port=8000)
        ```
    </Tab>

</Tabs>

<Step>
### 在前端渲染工具调用
此时，你的智能体已经能够调用 `get_weather` 工具。现在我们只需添加一个 `useRenderTool` hook，即可在 UI 中渲染这次工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染一次工具调用，操作的名称必须与工具的名称一致。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "Calling weather API..."}
          {status === "complete" && `Called the weather API for ${args.location}.`}
        </p>
      );
    },
  });
  // ...
}
```

</Step>
