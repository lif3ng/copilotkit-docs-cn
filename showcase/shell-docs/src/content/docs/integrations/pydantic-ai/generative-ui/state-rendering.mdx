## 这是什么？

所有 Pydantic AI 智能体都是有状态的。这意味着当智能体在各节点间推进时，一个状态对象会在它们之间传递，从而保留整个会话的整体状态。CopilotKit 允许你在应用中用自定义 UI 组件渲染这一状态，我们称之为**智能体生成式 UI（Agentic Generative UI）**。

## 什么时候该用它？

在 UI 中渲染智能体的状态，适合在你希望向用户反馈会话整体状态时使用。一个典型的例子是：用户与智能体协作解决问题，智能体可以把草稿存入自己的状态，再由 UI 渲染出来。

## 实现步骤

<Steps>
  <Step>
    ### 运行并连接你的智能体
    <RunAndConnect components={props.components} />
  </Step>
  <Step>
    ### 设置带状态的智能体

    创建一个具有状态化结构的 Pydantic AI 智能体。下面是一个追踪搜索记录的完整示例：

    ```python title="agent.py"
    // ...

    // Define the state of the agent, should match the state of your Pydantic AI Agent.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:13]
      // styles omitted for brevity
      useAgent({
        agentId: "my_agent",
        render: ({ state }) => (
          <div>
            {state.searches?.map((search, index) => (
              <div key={index}>
                {search.done ? "✅" : "❌"} {search.query}{search.done ? "" : "..."}
              </div>
            ))}
          </div>
        ),
      });

      // ...

      return <div>...</div>;
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与你在 CopilotRuntime 配置中定义的智能体名称完全一致（例如快速开始中的 `my_agent`）。
    </Callout>

  </Step>
  <Step>
    ### 在聊天之外渲染状态
    你也可以**在聊天之外**渲染智能体的状态。当你希望在聊天以外的任意位置渲染智能体状态时，这会非常有用。

    ```tsx title="app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]
    // ...

    // Define the state of the agent, should match the state of your Pydantic AI Agent.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:3]
      const { agent } = useAgent({
        agentId: "my_agent",
      })

      // ...

      return (
        <div>
          {/* ... */}
          <div className="flex flex-col gap-2 mt-4">
            {/* [!code highlight:5] */}
            {agent.state?.searches?.map((search, index) => (
              <div key={index} className="flex flex-row">
                {search.done ? "✅" : "❌"} {search.query}
              </div>
            ))}
          </div>
        </div>
      )
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与你在 CopilotRuntime 配置中定义的智能体名称完全一致（例如快速开始中的 `my_agent`）。
    </Callout>

  </Step>
  <Step>
    ### 试一试吧！

    现在你已经创建了一个能在聊天中渲染智能体状态的组件。
