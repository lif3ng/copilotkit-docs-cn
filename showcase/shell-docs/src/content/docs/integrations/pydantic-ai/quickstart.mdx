## 从你的编码智能体开始

使用此提示词将你的 Pydantic AI 智能体连接到 CopilotKit，并验证对话正常工作。你的编码智能体会在你的项目中按照本指南操作，你也可以跟着下面的手动步骤一步步来。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- OpenAI API 密钥
- Node.js 20+
- Python 3.9+
- 你喜欢的包管理器

    <Step>
        ### 选择你的起点

            <Step>
                ### 运行我们的 CLI

                ```bash
                npx copilotkit@latest create
                ```

                CLI 会引导你完成：

                - **项目名称**
                - **CopilotKit Intelligence** —— 持久化线程与检查器。选择 **Yes** 可生成一个为该平台预先接线的项目（CLI 会引导你完成注册，你也可以先[创建账号](https://dashboard.operations.copilotkit.ai/?utm_source=docs&utm_medium=cta&utm_campaign=intelligence&utm_content=docs_cli_prompt)），选择 **No** 则使用标准 Pydantic AI 配置。
                - **框架** —— 出现提示时选择 **Pydantic AI**。
            </Step>

                ### 安装依赖

                ```npm
                npm install
                ```

            </Step>
            <Step>
                ### 配置你的环境

                ```plaintext title="agent/.env"
                OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="想使用其他模型提供方？">
                  起步模板默认配置为使用 OpenAI 的 GPT-4o，但你可以修改它，改用 Pydantic AI 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 启动开发服务器

                    <Tab value="npm">

                        ```bash
                        bun dev
                        ```

                这会同时启动 UI 服务端和智能体服务端。
            </Step>
        </TailoredContentOption>
        <TailoredContentOption
            id="bring-your-own"
            title="使用现有智能体"
            description="我已经有一个 Pydantic AI 智能体，想添加 CopilotKit。"
        >
            <Step>
                ### 初始化你的智能体项目

                如果你还没有设置 Python 项目，使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### 安装带 AG-UI 的 Pydantic AI

                为你的项目添加带 AG-UI 支持的 Pydantic AI 以及 uvicorn：

                ```bash
                uv add 'pydantic-ai-slim[ag-ui,openai]>=2,<3' 'starlette>=0.46.2' uvicorn
                ```
            </Step>
            <Step>
                ### 配置你的环境

                将你的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="想使用其他模型提供方？">
                  本例使用 OpenAI 的 GPT-4.1-mini，但你可以修改它，改用 Pydantic AI 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露你的智能体

                更新你的智能体文件，将其暴露为 AG-UI ASGI 应用：

                ```python title="main.py"
                from pydantic_ai import Agent
                from pydantic_ai.ui.ag_ui import AGUIAdapter
                from starlette.applications import Starlette
                from starlette.requests import Request
                from starlette.responses import Response
                from starlette.routing import Route

                agent = Agent('openai:gpt-4.1-mini', instructions='Be fun!')


                async def run_agent(request: Request) -> Response:
                    return await AGUIAdapter.dispatch_request(request, agent=agent)


                app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])

                if __name__ == "__main__":
                    import uvicorn

                    uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
                ```

                <Callout type="info" title="AG-UI 是什么？">
                  AG-UI 是让 Copilot Runtime 与你的 Pydantic AI 智能体通信的协议。
                </Callout>
            </Step>
            <Step>
                ### 创建你的前端

                CopilotKit 适用于任何基于 React 的前端。本例中我们使用 Next.js。

                ```bash
                cd ..
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 软件包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/client@1.0.2
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由，将 CopilotKit 连接到 Pydantic AI
                的 AG-UI 端点：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                ```

                在这个前端应用目录下，将运行时连接到一个 Intelligence 项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会把服务端项目 API 密钥写入 `.env`。运行时在此处读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用 Intelligence 平台运行？">
                  去掉 `intelligence` 与 `identifyUser` 选项，运行时就会回退到使用内存运行器的 SSE 模式。聊天仍可工作，但 Threads 与
                  Inspector 将保持锁定，密钥也永远不会被读取。完整构造参数以及如何确认密钥已生效，请参阅
                  [将你的运行时连接到 Intelligence](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                用 CopilotKit provider 包裹你的应用：

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此它改为渲染你的客户端文件。保留脚手架的
                `globals.css` 导入，并添加一次 CopilotKit 样式表：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers";
                import "@copilotkit/react-core/v2/styles.css";
                import "./globals.css";

                export default function RootLayout({ children }: { children: React.ReactNode }) {
                  return (
                    <html lang="en">
                      <body>
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="info" title="此相对 runtimeUrl 假定由 Next.js 提供运行时服务">
                  `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源同时提供你的应用与运行时。纯客户端前端没有共享源，因此它需要
                  一个自己独立的运行时服务端，以及一个绝对的 `runtimeUrl`，例如
                  `http://localhost:8200/api/copilotkit`。`/react-spa`、`/vue`、
                  `/angular` 和 `/react-native` 的各前端指南都展示了这种配置。
                </Callout>
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到你的页面：

              ```tsx title="app/page.tsx"
              "use client"; // [!code highlight]

              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>Your App</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### 启动你的智能体

                在上面创建的前端目录下，启动智能体
                服务端：

                ```bash
                cd ../my-agent
                uv run main.py
                ```

                你的智能体将可在 `http://localhost:8000` 访问。
            </Step>
            <Step>
                ### 启动你的 UI

                在单独的终端中，进入你的前端目录并启动开发服务器：

                <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn', 'bun']}>

                    </Tab>

                        ```bash
                        pnpm dev
                        ```
                    </Tab>
                    <Tab value="yarn">
                        ```bash
                        cd my-copilot-app
                        yarn dev
                        ```
                    </Tab>
                    <Tab value="bun">
                        ```bash
                        cd my-copilot-app
                        bun dev
                        ```
                    </Tab>
                </Tabs>
            </Step>
        </TailoredContentOption>
    </TailoredContent>
    </Step>
    <Step>
        ### 🎉 开始聊天！

        你的 AI 智能体现在已经可以使用了！前往 `localhost:3000`，试着问它几个问题：


                - 如果遇到连接问题，尝试用 `0.0.0.0` 或 `127.0.0.1` 代替 `localhost`
                - 确保你的智能体运行在端口 8000 上

                - 确认前端中已安装 `@ag-ui/client` 软件包
