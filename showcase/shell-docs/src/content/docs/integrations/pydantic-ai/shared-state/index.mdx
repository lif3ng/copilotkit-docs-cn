## 什么是共享状态？

CoAgent 维护着一种共享状态，可将你的 UI 与智能体的执行无缝连接起来。这套共享状态系统让你能够：

- 展示智能体的当前进度与中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用中实时响应状态变化

这套系统的基础是 Pydantic AI 经由 AG-UI 的有状态架构。

## 什么时候应该使用它？

当你想要促进智能体与用户之间的协作时，状态流式传输是绝佳选择。你的 Pydantic AI 智能体所持久化的任何状态都会自动共享给 UI；同样，用户在 UI 中更新的任何状态也会自动反映出来。

这让智能体与用户始终保持信息同步，带来一致的体验。
