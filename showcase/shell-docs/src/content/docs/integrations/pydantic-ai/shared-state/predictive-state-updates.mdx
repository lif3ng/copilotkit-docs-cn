## 这是什么？

Pydantic AI 智能体的状态更新是不连续的，只在流程中的函数切换时发生。
但流程中的_单个函数_往往要运行很多秒，并且包含用户感兴趣的子步骤。

**智能体原生应用**会**尽可能连续地**向最终用户反映智能体正在做什么。

CopilotKit 通过 **_预测性状态更新_** 这一概念来实现这一点。

## 什么时候应该使用它？

当你想向用户提供关于智能体正在做什么的反馈时可以使用它，尤其是为了：

- 通过避免漫长的加载指示来**保持用户参与度**
- 通过展示智能体正在处理的内容来**建立信任**
- 支持**智能体引导**——允许用户在需要时纠正智能体的方向

## 重要提示

当 Pydantic AI 智能体中的函数执行完毕时，**其返回的状态会成为唯一的可信来源**。
中间状态更新非常适合实时反馈，但任何你想要持久化的变更都必须显式
包含在函数最终返回的状态中，否则它们会在函数完成时被覆盖。

## 实现

<Steps>
    <Step>
        ### 定义状态

        创建一个带有状态结构的 Pydantic AI 智能体。下面是一个跟踪已观察步骤的完整示例：

        ```python title="agent.py"
        from pydantic import BaseModel
        from pydantic_ai import Agent
        from pydantic_ai.ui import StateDeps
        from pydantic_ai.ui.ag_ui import AGUIAdapter
        from starlette.applications import Starlette
        from starlette.requests import Request
        from starlette.responses import Response
        from starlette.routing import Route


        class AgentState(BaseModel):
            """State for the agent."""
            observed_steps: list[str] = []


        agent = Agent('openai:gpt-5.4-mini', deps_type=StateDeps[AgentState])


        async def run_agent(request: Request) -> Response:
            # Build the deps fresh on every request: `dispatch_request` writes the state
            # the client sent into `deps.state`, so a shared instance leaks state between
            # concurrent requests and users.
            return await AGUIAdapter.dispatch_request(
                request, agent=agent, deps=StateDeps(AgentState())
            )


        app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])

        if __name__ == "__main__":
            import uvicorn

            uvicorn.run(app, host="0.0.0.0", port=8000)
        ```

        然后在前端渲染预测状态：

        ```tsx title="ui/app/page.tsx"
        import { useAgent } from "@copilotkit/react-core/v2";

        // ...

        const YourMainContent = () => {
            // Get access to both predicted and final states
            const { agent } = useAgent({ agentId: "my_agent" });

            // Add a state renderer to observe predictions
            useAgent({
                agentId: "my_agent",
                render: ({ state }) => {
                    if (!state.observed_steps?.length) return null;
                    return (
                        <div>
                            <h3>Current Progress:</h3>
                            <ul>
                                {state.observed_steps.map((step, i) => (
                                    <li key={i}>{step}</li>
                                ))}
                            </ul>
                        </div>
                    );
                },
            });

            return (
                <div>
                    <h1>Agent Progress</h1>
                    {agent.state?.observed_steps?.length > 0 && (
                        <div>
                            <h3>Final Steps:</h3>
                            <ul>
                                {agent.state.observed_steps.map((step, i) => (
                                    <li key={i}>{step}</li>
                                ))}
                            </ul>
                        </div>
                    )}
                </div>
            )
        }
        ```

        <Callout type="warn" title="重要">
          `name` 参数必须与你在 CopilotRuntime 配置中定义的智能体名称完全一致（例如快速开始中的 `my_agent`）。
        </Callout>
    </Step>
    <Step>
        ### 试一试！
        现在你会注意到，随着智能体不断推进，状态预测会被逐步发出，让你在最终状态确定之前就能了解它的工作。
        你可以将这种模式应用到智能体中的任何长时间运行的任务上。
    </Step>

</Steps>
