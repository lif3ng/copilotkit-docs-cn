## 这是什么？

[基于流程的智能体](https://docs.pydantic-ai.com/concepts/flows)是有状态的智能体，可以被中断并恢复，以便等待用户输入。

CopilotKit 让你能够添加自定义 UI 来收集用户输入，并在完成后将其传回智能体。

## 为什么要用它？

人机协同（human-in-the-loop）是实现生产级复杂工作流的强大方式。通过让人类参与流程，你可以确保智能体始终做出正确的决策，并最终朝着正确的方向前进。

对于更复杂的工作流，基于流程的智能体是实现 HITL 的绝佳方式——在这些场景中，你希望确保智能体知晓 HITL 交互期间发生的一切。

## 实现步骤

<Steps>
    <Step>
        ### 运行并连接你的智能体

        在继续之前，你需要运行智能体并将其连接到 CopilotKit。如果还没有完成，可以按照[快速开始](/pydantic-ai/quickstart)指南中的说明操作。

        如果你还没有智能体，可以使用 [Pydantic AI starter](https://github.com/CopilotKit/CopilotKit/tree/main/examples/integrations/pydantic-ai) 作为起点，本指南也是以它为基础展开的。
    </Step>

    <Step>
        ### 在前端添加 `useFrontendTool`
        首先，我们创建一个组件，用于渲染智能体的文章草稿并等待用户审批。

        ```tsx title="ui/app/page.tsx"

        function YourMainContent() {
          // ...

          useFrontendTool({
            name: "write_essay",
            available: "frontend",
            description: "Writes an essay and takes the draft as an argument.",
            parameters: z.object({
              draft: z.string().describe("The draft of the essay"),
            }),
            // [!code highlight:25]
            renderAndWaitForResponse: ({ args, respond, status }) => {
              return (
                <div>
                  <Markdown content={args.draft || 'Preparing your draft...'} />

                  <div className={`flex gap-4 pt-4 ${status !== "executing" ? "hidden" : ""}`}>
                    <button
                      onClick={() => respond?.("CANCEL")}
                      disabled={status !== "executing"}
                      className="border p-2 rounded-xl w-full"
                    >
                      Try Again
                    </button>
                    <button
                      onClick={() => respond?.("SEND")}
                      disabled={status !== "executing"}
                      className="bg-blue-500 text-white p-2 rounded-xl w-full"
                    >
                      Approve Draft
                    </button>
                  </div>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>

    <Step>
    ### 设置 Pydantic AI 智能体
接下来我们来设置 Pydantic AI 智能体。没有完整示例的话，这个流程很难理解，所以下面给出智能体的完整实现并附上说明。

    有几个要点需要注意：
    - 智能体的状态继承自 `CopilotKitState`，以引入 CopilotKit 的操作。
    - CopilotKit 的操作会作为工具绑定到模型上。
    - 如果在模型的响应中发现 `writeEssay` 操作，智能体会把控制权交回前端，以获取用户反馈。

    <Tabs groupId="language" items={["Python"]}>
      <Tab value="Python">
        ```python title="agent/sample_agent/agent.py"
        from pydantic_ai import Agent
        from pydantic_ai.ui.ag_ui import AGUIAdapter
        from starlette.applications import Starlette
        from starlette.requests import Request
        from starlette.responses import Response
        from starlette.routing import Route

        agent = Agent('openai:gpt-5.4-mini')

        @agent.tool_plain
        async def write_essay(topic: str) -> str:
            """Write an essay on the given topic."""
            # This would typically generate an essay
            # The agent will wait for user feedback before proceeding
            return f"Essay draft on '{topic}' has been generated. Please review."


        async def run_agent(request: Request) -> Response:
            return await AGUIAdapter.dispatch_request(request, agent=agent)


        app = Starlette(routes=[Route("/", run_agent, methods=["POST"])])
        ```
      </Tab>
    </Tabs>
    </Step>
    <Step>
        ### 试一试吧！
        试着让智能体写一篇关于 AI 好处的文章。你会看到它先生成文章、流式展示进度，最后请你审阅。
    </Step>

</Steps>
