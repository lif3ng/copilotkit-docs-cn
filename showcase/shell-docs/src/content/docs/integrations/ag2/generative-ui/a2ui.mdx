## 从 AG2 智能体提供 A2UI

AG2（1.0+）在 `ag2.a2ui` 模块中提供了一流的 A2UI 集成：将任意普通的 `Agent` 包装在带有 `AgUiTransport` 的 `A2UIServer` 中，其经过校验的 A2UI 输出便会通过 AG-UI 协议流式传输到 CopilotKit——无需任何自定义桥接代码。

### 后端

安装带有 A2UI、AG-UI 和 OpenAI extras 的 AG2：

```bash
pip install "ag2[a2ui,ag-ui,openai]>=1.1.2" uvicorn
```

构建一个普通智能体并将其包装在 `A2UIServer` 中。该服务器实例本身就是 ASGI 应用；`AgUiTransport` 提供 AG-UI 端点，而带有 `@a2ui_action` 装饰器的函数会变成可点击的按钮，其处理程序在服务器端运行：

```python title="server.py"
import uvicorn

from ag2 import Agent
from ag2.a2ui import A2UIServer, a2ui_action
from ag2.a2ui.transports import AgUiTransport
from ag2.config import OpenAIResponsesConfig

@a2ui_action(description="Book the selected dinner reservation")
def book_table(time: str, party_size: int) -> str:
    return f"booked a table for {party_size} at {time}"

agent = Agent(
    name="ui_agent",
    prompt=(
        "Answer with an A2UI surface whenever a list, a choice, or a "
        "confirmation would help the user."
    ),
    config=OpenAIResponsesConfig(model="gpt-5.5"),
)

app = A2UIServer(
    agent,
    transport=AgUiTransport(),  # AG-UI endpoint at POST /
    actions=[book_table],
    protocol_version="v0.9",
)

if __name__ == "__main__":
    uvicorn.run(app, host="127.0.0.1", port=8000)
```

`A2UIServer` 会对照组件目录校验智能体产出的每条 A2UI 消息（校验出错时会重试），因此格式错误的 UI 永远不会到达客户端。随后 `AgUiTransport` 会将这些已校验的消息作为 AG-UI activity 快照（`activityType: "a2ui-surface"`）发出——这正是 CopilotKit A2UI 渲染器所消费的线上契约。

### 连接到 CopilotKit

在 Copilot Runtime 中注册 AG2 端点并启用 A2UI：

```ts title="app/api/copilotkit/route.ts"
import { HttpAgent } from "@ag-ui/client";
import {
  CopilotRuntime,
  createCopilotRuntimeHandler,
} from "@copilotkit/runtime/v2";

const runtime = new CopilotRuntime({
  agents: {
    ui_agent: new HttpAgent({ url: "http://localhost:8000/" }),
  },
  a2ui: {},
});

const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  mode: "single-route",
});

export { handler as POST };
```

大功告成——由你的 AG2 智能体生成的 A2UI 界面现在会自动渲染在聊天中，按钮点击也会通过同一连接回传到你的 `@a2ui_action` 处理程序。

<Callout type="info">
  AG2 的 A2UI 传输层支持通过 <code>protocol_version</code> 参数选择协议版本 <code>v0.9</code>（默认）、<code>v0.9.1</code> 和 <code>v1.0</code>。底层协议桥接请参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>
