## 这是什么？

前端工具让你能够定义 AG2 智能体可以调用的客户端函数，其执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，逻辑在客户端运行，你可以直接访问前端环境。

它可以用来[让智能体控制 UI](/ag2/frontend-tools)、实现[生成式 UI](/ag2/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

本指南将介绍如何将前端工具用于人机协同。

<Callout type="info">
  CopilotKit 会消费 AG2 通过 <code>/chat</code> 流式传输的 AG-UI 协议事件。参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>

## 什么时候应该使用？

当你需要智能体与客户端原语交互时，请使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookies 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 实现步骤

<Steps>
    <Step>
      ### 运行并连接你的智能体

      在 `/chat` 端点上启动你的 AG2 后端，并使用 CopilotKit 将前端连接到它。
    </Step>

    <Step>
        ### 创建前端人机协同工具

        前端工具可以以多种方式加以利用。其中一种方式是构建人机协同流程，让工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的“审批”流程。首先，使用 `useHumanInTheLoop` hook 创建一个提示用户进行审批的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 配置你的 AG2 后端

        前端工具会发出 AG-UI 工具事件。AG2 可以消费这些事件，然后将用户的决定持久化到共享状态中：

        ```python title="agent.py"
        from typing import Annotated

        from fastapi import FastAPI, Header
        from fastapi.responses import StreamingResponse
        from pydantic import Field

        from ag2 import Agent, Context, tool
        from ag2.ag_ui import AGUIStream, RunAgentInput
        from ag2.config import OpenAIResponsesConfig

        @tool
        def store_user_choice(
            choice: Annotated[str, Field(description="The option selected by the user")],
            context: Context,
        ) -> str:
            """Store the latest user choice in shared state."""
            context.variables["hitl"] = {"latest_choice": choice}
            return f"Stored choice: {choice}"

        agent = Agent(
            name="assistant",
            prompt=(
                "When you need the user to choose, call the frontend tool `offerOptions`. "
                "After it returns, call `store_user_choice` with the selected value."
            ),
            config=OpenAIResponsesConfig(model="gpt-5.5"),
            tools=[store_user_choice],
        )

        stream = AGUIStream(agent)
        app = FastAPI()

        @app.post("/chat")
        async def run_agent(
            message: RunAgentInput,
            accept: str | None = Header(None),
        ) -> StreamingResponse:
            return StreamingResponse(
                stream.dispatch(message, accept=accept),
                media_type=accept or "text/event-stream",
            )
        ```

        前端工具会由 CopilotKit 通过 AG-UI 协议自动注入，供你的 AG2 后端使用。当工具更新 `context.variables` 时，`AGUIStream` 会在运行结束时自动发出 `STATE_SNAPSHOT` 事件——无需手动构造事件。
    </Step>
    <Step>
        ### 试一试

        现在你的智能体已经能够向用户展示两个选项并让用户选择其一。之后智能体会感知到用户的选择，并在后续步骤中使用它。

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>
</Steps>

## 通过中断审批工具调用

前端工具把决定权放在浏览器中。AG-UI 1.0 还允许**后端**暂停一次运行并发起询问：被 `ApprovalRequired` 包装的工具会被挂起，直到用户批准或拒绝该调用。AG2 会将被挂起的调用作为 AG-UI 中断发送给客户端，由 CopilotKit 的 `useInterrupt` 进行渲染。

<Steps>
    <Step>
        ### 在 AG2 中拦截工具

        ```python title="tools.py"
        from typing import Annotated

        from pydantic import Field

        from ag2 import Context, tool
        from ag2.middleware.builtin.tools.approval import ApprovalRequired

        @tool(
            description="Save a city to the user's favorites. The user confirms before anything is saved.",
            middleware=[
                ApprovalRequired("Save this city to your favorites?\n{tool_arguments}", allow_always=False)
            ],
        )
        async def save_favorite_city(
            context: Context,
            city: Annotated[str, Field(description="The city name to save, e.g. 'Lisbon'")],
        ) -> list[str]:
            favorites = list(context.variables.get("favorites", []))
            if city not in favorites:
                favorites.append(city)
            context.variables["favorites"] = favorites
            return favorites
        ```

        像往常一样使用 `AGUIStream` 来伺服智能体。不要在智能体上设置 `hitl_hook`：一旦设置了，AG2 会在进程内直接询问，中断就不会到达浏览器。
    </Step>
    <Step>
        ### 用 `useInterrupt` 响应中断

        这次运行会以一个 reason 为 `tool_call` 的中断结束。后端将应答读取为布尔值，因此 `resolve(true)` 表示批准该调用，`resolve(false)` 表示拒绝。拒绝不会导致运行失败：模型会被告知该调用已被拒绝，然后继续执行。

        ```tsx title="page.tsx"
        import { useInterrupt } from "@copilotkit/react-core/v2"; // [!code highlight]

        export function Page() {
          useInterrupt({
            agentId: "agenticChatAgent",
            render: ({ interrupt, resolve }) => (
              <div>
                <p>{interrupt?.message ?? "The assistant needs your confirmation."}</p>
                <button onClick={() => resolve(true)}>Approve</button>
                <button onClick={() => resolve(false)}>Reject</button>
              </div>
            ),
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 试一试

        ```
        Save Lisbon to my favorites
        ```

        审批卡片会出现在聊天中。批准之后，这个城市就会出现在[共享状态](/ag2/shared-state)中。
    </Step>
</Steps>

<Callout type="warn">
  `useInterrupt().resolve()` 和 `.cancel()` 在恢复条目中不会发送 `metadata`。对于上面这样的受拦截工具调用来说已经足够，但对于使用 `require_resume_proof=True` 构建的 AG2 服务器则不够——它需要把中断的 `metadata` 复制进恢复条目。参见 AG2 文档中的 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/overview#asking-the-human-a-question" target="_blank">Asking the human a question</a>。
</Callout>

被挂起的轮次存在于伺服该次运行的 AG2 进程中，因此恢复运行必须到达同一个进程。在运行多个副本之前，请参阅 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/overview#deployment-a-held-turn-lives-in-one-process" target="_blank">AG2 部署说明</a>。
