CopilotKit 最常见的用例之一，就是用 `useAgentContext` 注册应用状态与上下文。这样你就可以实时告知 CopilotKit 你的应用里正在发生什么。例如：当前用户、当前页面等。

这些上下文随后可以共享给你的 AG2 后端。在 AG2 1.1.2 或更新版本中，`AGUIStream` 已经会把每一条 `useAgentContext` 条目交给模型，因此一个普通的 AG-UI 端点无需额外代码。在 AG2 1.0.x 上这些条目根本到不了模型，请先升级。

            <Step>
                ### 把数据添加给 Copilot

                [`useAgentContext` hook](/reference/v2/hooks/useAgentContext) 用于把数据作为上下文添加给 Copilot。

                ```tsx title="YourComponent.tsx" showLineNumbers {1, 7-10}
                "use client" // only necessary if you are using Next.js with the App Router. // [!code highlight]
                import { useAgentContext } from "@copilotkit/react-core/v2"; // [!code highlight]
                import { useState } from 'react';

                export function YourComponent() {
                  const [colleagues, setColleagues] = useState([
                    { id: 1, name: "John Doe", role: "Developer" },
                    { id: 2, name: "Jane Smith", role: "Designer" },
                    { id: 3, name: "Bob Wilson", role: "Product Manager" }
                  ]);

                  // [!code highlight:4]
                  useAgentContext({
                    description: "The current user's colleagues",
                    value: colleagues,
                  });
                  return (
                    <>...</>
                  );
                }
                ```
            </Step>

            <Step>
                ### 像平常一样提供你的智能体
                通过 `RunAgentInput.context` 发送的条目会作为一个文本块追加到运行的系统提示中，位于智能体自身提示之后：

                ```text
                ## Context from the application

                - The current user's colleagues: [{"id":1,"name":"John Doe","role":"Developer"}, ...]
                ```

                每一行先是条目的 `description`，然后是客户端原样发来的 `value`。这个块对模型来说是散文文本，而不是变量：工具代码看不到它。你的端点保持[快速开始](/ag2/quickstart)里那个普通端点即可：

                ```python title="agent.py"
                from fastapi import FastAPI, Header
                from fastapi.responses import StreamingResponse

                from ag2 import Agent
                from ag2.ag_ui import AGUIStream, RunAgentInput
                from ag2.config import OpenAIResponsesConfig

                agent = Agent(
                    name="assistant",
                    prompt="You are a helpful assistant that can help emailing colleagues.",
                    config=OpenAIResponsesConfig(model="gpt-5.5"),
                )

                stream = AGUIStream(agent)
                app = FastAPI()

                @app.post("/chat")
                async def run_agent(
                    message: RunAgentInput,
                    accept: str | None = Header(None),
                ) -> StreamingResponse:
                    return StreamingResponse(
                        stream.dispatch(message, accept=accept),
                        media_type=accept or "text/event-stream",
                    )
                ```

                不要自己把可读接口塞进 `dispatch(prompt=...)`：那会造成重复，而且 `prompt=` 是替换智能体自身提示，而不是追加。
            </Step>

            <Step>
                ### 自定义文本块（可选）
                给 `dispatch` 传入 `context_prompt=` 可以用不同方式渲染这些条目。它接收条目并返回文本块，返回 `None` 则表示不包含它们：

                ```python title="agent.py"
                def colleagues_only(entries):
                    lines = [f"- {e.value}" for e in entries if "colleagues" in e.description]
                    return "## Colleagues\n\n" + "\n".join(lines) if lines else None

                stream.dispatch(message, accept=accept, context_prompt=colleagues_only)
                ```
            </Step>

            <Step>
                ### 试一试
                就上下文内容问你的智能体一个问题。它应该能答上来。
            </Step>

            <Step>
                ### 把可读接口作为变量传入运行
                提示块只是散文文本。要把值本身交给工具，请从 `RunAgentInput.context` 中解码该条目，并把它作为会话变量传入。`Variable()` 注解会把它注入工具，无需 LLM 到处传递。

                ```python title="agent.py"
                import json
                from typing import Annotated

                from fastapi import FastAPI, Header
                from fastapi.responses import StreamingResponse

                from ag2 import Agent, Variable, tool
                from ag2.ag_ui import AGUIStream, RunAgentInput
                from ag2.config import OpenAIResponsesConfig

                def get_readable(message: RunAgentInput, description: str):
                    raw = next(
                        (item.value for item in message.context if item.description == description),
                        None,
                    )
                    if raw is None:
                        return None
                    # `useAgentContext` JSON-encodes objects and arrays, but passes a
                    # plain string through untouched — so decoding is best-effort.
                    try:
                        return json.loads(raw)
                    except json.JSONDecodeError:
                        return raw

                @tool
                def get_colleagues(
                    colleagues: Annotated[list, Variable(default_factory=list)],
                ) -> list:
                    """Return the current user's colleagues from CopilotKit readables."""
                    return colleagues

                agent = Agent(
                    name="assistant",
                    prompt="You are a helpful assistant that can help emailing colleagues.",
                    config=OpenAIResponsesConfig(model="gpt-5.5"),
                    tools=[get_colleagues],
                )

                stream = AGUIStream(agent)
                app = FastAPI()

                @app.post("/chat")
                async def run_agent(
                    message: RunAgentInput,
                    accept: str | None = Header(None),
                ) -> StreamingResponse:
                    colleagues = get_readable(message, "The current user's colleagues") or []
                    return StreamingResponse(
                        stream.dispatch(message, variables={"colleagues": colleagues}, accept=accept),
                        media_type=accept or "text/event-stream",
                    )
                ```

                <Callout type="warn">
                    `dispatch(variables=...)` 中的所有内容都会通过 `STATE_SNAPSHOT` 送回浏览器。不要把机密信息放在那里；请通过 `dispatch(dependencies=...)` 传递，它永远不会离开服务器。
                </Callout>
            </Step>
