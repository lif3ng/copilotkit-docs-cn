## 从你的编码智能体开始

使用这段提示词把你的 AG2 智能体接入 CopilotKit，并验证对话可以正常工作。你的编码智能体会在你的项目里按照本指南操作，你也可以跟着下方的手动步骤一步步来。

<PageAgentPrompt />

## 简介

本快速开始指南演示如何使用 AG2 与 CopilotKit 构建一个**天气智能体**。只需几分钟，你就能得到一个可运行的应用：用户可以查询全球任意城市的实时天气——由 AG2 基于 AG-UI 协议的 `AGUIStream` 驱动，并用 CopilotKit 的聊天 UI 渲染。

<Callout type="info">
  CopilotKit 消费 AG2（1.1.2 或更新版本）通过 HTTP 流式传输的 AG-UI 1.0 协议事件。参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>

## AG2 起步模板

如果你不想克隆仓库，更想用生成好的起步模板，可以使用 CopilotKit bootstrap 模板，并在配置过程中选择 **AG2**。它会为你接好一个基于 AG-UI 的 AG2 后端和一个开箱即跑的前端。

```bash
npx copilotkit@latest init
```

按照提示选择 AG2 和你想要的特性，然后运行它打印出的安装/启动命令。

## 前置条件

开始之前，你需要准备以下内容：

- **Python 3.10–3.14**，用于运行 AG2 后端
- <a href="https://docs.astral.sh/uv/getting-started/installation/" target="_blank">uv</a>（用于 Python 依赖管理）
- <a href="https://nodejs.org/en/download" target="_blank">Node.js</a> 20.9 或更新版本
- <a href="https://pnpm.io/installation" target="_blank">pnpm</a>（用于前端包管理）
- <a href="https://platform.openai.com/api-keys" target="_blank">OpenAI API 密钥</a>

## 开始使用

<Steps>
    <Step>
        ### 配置 CopilotKit 智能中枢

        <SignupLink surface="docs_ag2_quickstart_step1">登录云端托管的智能中枢</SignupLink>。云端托管配置使用服务端项目 API 密钥，不会签发 `COPILOTKIT_LICENSE_TOKEN`。稍后克隆完应用，再把它连接上来。
    </Step>

    <Step>
        ### 克隆 AG2 示例仓库

        ```bash
        git clone https://github.com/ag2ai/ag2-samples.git
        cd ag2-samples
        npx copilotkit@latest project select
        ```

        `project select` 会创建或选择一个智能中枢项目，并把其服务端 API 密钥以 `CPK_INTELLIGENCE_API_KEY` 的形式写入 `.env`。
    </Step>
    <Step>
        ### 配置 AG2 后端

        #### 安装依赖：

        ```bash
        uv sync
        ```

        #### 设置你的 `OPENAI_API_KEY` 与 `AUTH_SECRET`：

        该示例只向已登录的用户提供智能体。`AUTH_SECRET` 用于签名并校验用户的访问令牌，因此后端与前端必须使用相同的值。任意长随机字符串都可以。

        ```sh
        export OPENAI_API_KEY="your_openai_api_key"
        export AUTH_SECRET="a-long-random-string"
        ```

        #### 启动 AG2 天气智能体：

        ```bash
        uv run python -m backend
        ```
        后端服务器将启动于 http://localhost:8000，并在 `/weather` 路径上提供智能体服务。
    </Step>
    <Step>
        ### 配置 CopilotKit UI

        最后一步是使用 CopilotKit 的 UI 组件来渲染与你的智能体的聊天交互。

        在新终端中：

        ```bash
        cd ui
        pnpm install
        AUTH_SECRET="a-long-random-string" pnpm dev
        ```

        前端应用将启动于 http://localhost:3000。请使用与后端相同的 `AUTH_SECRET`。

        <Callout type="warn">
            该示例的登录仅作演示：它接受任意名字，并把令牌保存在 `localStorage` 中。在复用这套模式之前，请替换 `backend/auth.py` 中的 `verify_access_token` 以及 UI 中的令牌路由。参见[身份验证](/ag2/auth)。
        </Callout>
    </Step>
    <Step>
        ### 🎉 和你的智能体对话吧！

        恭喜！你已成功把一个 AG2 智能体聊天机器人集成到你的应用中。输入名字登录，然后试着问几个问题：

        ```
        伦敦的天气怎么样？
        ```

        ```
        东京的天气
        ```

        ```
        这里的天气怎么样？
        ```

        该示例还在聊天旁边展示了 AG-UI 1.0 的各项特性：

        | 特性 | 试试这样问 |
        | --- | --- |
        | [子智能体](/ag2/multi-agent/subagents)（`ClothingAdvisor`、`TripPlanner`） | “我在奥斯陆该穿什么？” |
        | [中断](/ag2/human-in-the-loop#approve-a-tool-call-with-interrupts)（`save_favorite_city` 会等待批准） | “把里斯本保存到我的收藏” |
        | [共享状态](/ag2/shared-state)（收藏面板） | 保存一个城市，然后观察面板 |
        | 能力 | `curl localhost:8000/weather` |

        <Callout type="info">
            询问 “这里的天气怎么样？” 时，只要你允许，就会使用浏览器的定位。如果定位访问被拒绝，智能体会改为让你提供一个城市名。
        </Callout>
    </Step>

</Steps>

## 接入你自己的 AG2 智能体

示例仓库是一个现成的例子。要通过 AG-UI 暴露任何 AG2 智能体，请安装带 AG-UI 与 OpenAI 附加依赖的 AG2（1.1.2+），并把智能体包进 `AGUIStream`：

```bash
pip install "ag2[ag-ui,openai]>=1.1.2"
```

```python title="run_ag_ui.py"
from fastapi import FastAPI, Header
from fastapi.responses import StreamingResponse

from ag2 import Agent
from ag2.ag_ui import AGUIStream, RunAgentInput
from ag2.config import OpenAIResponsesConfig

agent = Agent(
    name="support_bot",
    prompt="You help users with billing questions.",
    config=OpenAIResponsesConfig(model="gpt-5.5"),
)

stream = AGUIStream(agent)
app = FastAPI()

@app.post("/chat")
async def run_agent(
    message: RunAgentInput,
    accept: str | None = Header(None),
) -> StreamingResponse:
    return StreamingResponse(
        stream.dispatch(message, accept=accept),
        media_type=accept or "text/event-stream",
    )
```

如果你不需要围绕该端点的自定义身份验证、日志或中间件，可以改用 `AGUIStream.build_asgi()` 构建一个可直接挂载的 ASGI 端点：

```python title="run_ag_ui.py"
from fastapi import FastAPI

from ag2 import Agent
from ag2.ag_ui import AGUIStream
from ag2.config import OpenAIResponsesConfig

agent = Agent(
    name="support_bot",
    prompt="You help users with billing questions.",
    config=OpenAIResponsesConfig(model="gpt-5.5"),
)

stream = AGUIStream(agent)
app = FastAPI()
app.mount("/chat", stream.build_asgi())
```

把 Copilot Runtime 中的 `HttpAgent` 指向 `http://localhost:8000/chat`，你的智能体就会在 UI 中上线。受支持的协议事件、中断、能力与共享状态细节，参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
