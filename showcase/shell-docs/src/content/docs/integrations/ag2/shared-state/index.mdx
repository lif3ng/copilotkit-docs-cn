## 什么是共享状态？

CoAgent 会维护一份共享状态，把你的 UI 与智能体的执行无缝连接起来。这套共享状态系统让你能够：

- 展示智能体的当前进度与中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用中实时响应状态变化

这套系统的基础是 AG2 **会话变量**（`Context.variables`）与 AG-UI 的 `StateSnapshotEvent`——`AGUIStream` 会在运行开始时（当智能体或 `dispatch()` 定义了初始变量时）自动发出一次，并在运行结束、工具修改了变量之后再发出一次。

<Callout type="info">
  CopilotKit 消费 AG2 通过 <code>/chat</code> 流式传输的 AG-UI 协议事件。参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>

## 什么时候应该用它？

当你想促进智能体与用户之间的协作时，状态流式传输非常合适。你的 AG2 后端在快照事件中发出的任何状态，都会被 UI 自动共享；同样，用户在 UI 中更新的任何状态也会被自动反映。

这让智能体与用户始终看到同一份状态，体验保持一致。
