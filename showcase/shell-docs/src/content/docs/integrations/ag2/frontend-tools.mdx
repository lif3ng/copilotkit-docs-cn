## 这是什么？

前端操作是功能强大的工具，能让你的 AI 智能体直接与应用的用户界面交互并更新它。可以把它们想象成一座座桥梁，将智能体的决策能力与前端的交互元素连接起来。

<Callout type="info">
  CopilotKit 消费由 AG2 通过 <code>/chat</code> 流式传输的 AG-UI 协议事件。参见 <a href="https://docs.ag2.ai/docs/user-guide/ag-ui/" target="_blank">AG2 AG-UI 集成文档</a>。
</Callout>

## 什么时候应该使用它？

当你想创建真正可交互的 AI 应用、且智能体需要完成以下事情时，前端操作必不可少：

- 动态更新 UI 元素
- 触发前端动画或过渡效果
- 显示提醒或通知
- 修改应用状态
- 以编程方式处理用户交互

没有前端操作时，智能体只能处理并返回数据。通过实现前端操作，你可以构建丰富的交互式体验，让智能体主动驱动用户界面。

## 实现

<Steps>
    <Step>
        ### 配置 CopilotKit

        要使用前端操作，你需要先配置 CopilotKit。为节省篇幅，此处不再展开。

        请查看我们的[快速开始指南](/ag2/quickstart)，完成配置后再回到这里。
    </Step>

    <Step>
        ### 创建前端操作

        首先，你需要使用 [useFrontendTool](/reference/v2/hooks/useFrontendTool) hook 创建一个前端操作。下面这个简单示例会向用户问好，可供入门。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          // [!code highlight:12]
          useFrontendTool({
            name: "sayHello",
            description: "Say hello to the user",
            parameters: z.object({
              name: z.string().describe("The name of the user to say hello to"),
            }),
            handler: async ({ name }) => {
              alert(`Hello, ${name}!`);
              return `Said hello to ${name}!`;
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 修改你的智能体
        接下来，我们需要修改智能体以访问这些前端操作。打开你的 AG2 后端文件，从那里继续。
    </Step>
    <Step>
        ### 通过 AG-UI 配置你的 AG2 后端

        AG2 可以通过 AG-UI 工具事件，经由标准的 `/chat` 端点调用前端操作：

        <Tabs groupId="language" items={['Python']} default="Python">
            <Tab value="Python">
                ```python title="agent.py"
                from fastapi import FastAPI, Header
                from fastapi.responses import StreamingResponse

                from ag2 import Agent
                from ag2.ag_ui import AGUIStream, RunAgentInput
                from ag2.config import OpenAIResponsesConfig

                agent = Agent(
                    name="assistant",
                    prompt="You are a helpful assistant.",
                    config=OpenAIResponsesConfig(model="gpt-5.5"),
                )

                stream = AGUIStream(agent)
                app = FastAPI()

                @app.post("/chat")
                async def run_agent(
                    message: RunAgentInput,
                    accept: str | None = Header(None),
                ) -> StreamingResponse:
                    return StreamingResponse(
                        stream.dispatch(message, accept=accept),
                        media_type=accept or "text/event-stream",
                    )
                ```
            </Tab>
        </Tabs>

        大功告成。现在你的 AG2 后端已经能够接收 CopilotKit 通过 AG-UI 发出的前端操作工具定义。
    </Step>
    <Step>
        ### 试一试
        现在你的智能体已经可以直接调用你定义的任何 CopilotAction。这些操作会作为工具提供给智能体，供其按需使用。
    </Step>

</Steps>
