## 从你的编码智能体开始

使用这段提示词将你的 AWS Strands 智能体接入 CopilotKit，并验证对话可以正常运行。你的编码智能体会在项目中按照本指南操作，你也可以按下面的手动步骤一步步来。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 OpenAI 或 Anthropic API 密钥
- Node.js 20+
- Python 3.12+（仅 Python 智能体需要）
- 你顺手的包管理器

                ### 通过 AG-UI 暴露你的智能体

                <Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
                    <Tab value="Python">
                        更新你的智能体文件，将其暴露为 AG-UI ASGI 应用：

                        ```python title="main.py"
                        import os

                        from ag_ui_strands import StrandsAgent, create_strands_app
                        from strands import Agent
                        from strands.models.openai import OpenAIModel

                        # Setup your Strands agent
                        api_key = os.getenv("OPENAI_API_KEY", "")
                        model = OpenAIModel(
                            client_args={"api_key": api_key},
                            model_id="gpt-5.4",
                        )

                        agent = Agent(
                            model=model,
                            system_prompt="You are a helpful AI assistant.",
                        )

                        # Wrap with AG-UI integration
                        agui_agent = StrandsAgent(
                            agent=agent,
                            name="strands_agent",
                        )

                        # Create the FastAPI app
                        app = create_strands_app(agui_agent, "/")

                        if __name__ == "__main__":
                            import uvicorn

                            uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)

                        ```

                        <Callout type="info" title="什么是 AG-UI？">
                          AG-UI 是一个用于前端与智能体通信的开放协议。`create_strands_app` 函数会创建一个 CopilotKit 可连接的 ASGI 应用。
                        </Callout>
                    </Tab>
                    <Tab value="TypeScript">
                        更新你的智能体文件，将其暴露为 AG-UI Express 应用：

                        ```typescript title="main.ts"
                        import { Agent } from "@strands-agents/sdk";
                        import { OpenAIModel } from "@strands-agents/sdk/models/openai";
                        import { StrandsAgent } from "@ag-ui/aws-strands";
                        import { createStrandsApp } from "@ag-ui/aws-strands/server";

                        // Setup your Strands agent
                        const model = new OpenAIModel({
                          apiKey: process.env.OPENAI_API_KEY ?? "",
                          modelId: "gpt-5.4",
                        });

                        const agent = new Agent({
                          model,
                          systemPrompt: "You are a helpful AI assistant.",
                        });

                        await agent.initialize();

                        // Wrap with AG-UI integration
                        const aguiAgent = new StrandsAgent({
                          agent,
                          name: "strands_agent",
                        });

                        // Create the Express app
                        const app = await createStrandsApp(aguiAgent, { path: "/" });

                        app.listen(8000, () => {
                          console.log("Agent listening on http://localhost:8000");
                        });
                        ```

                        <Callout type="info" title="什么是 AG-UI？">
                          AG-UI 是一个用于前端与智能体通信的开放协议。`createStrandsApp` 函数会返回一个 CopilotKit 可连接的 Express 应用。
                        </Callout>

            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由，将 CopilotKit 连接到你的 Strands 智能体：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                const runtime = new CopilotRuntime({
                  agents: {
                    strands_agent: new HttpAgent({ url: "http://localhost:8000" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
               ```

                在此前端应用目录下，将运行时连接到一个 Intelligence 项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会将服务端项目 API 密钥写入 `.env`。运行时在此处读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用 Intelligence 平台运行？">
                  去掉 `intelligence` 与 `identifyUser` 选项后，运行时会回退到使用内存运行器的
                  SSE 模式。聊天功能仍然可用，但线程（Threads）与检查器（Inspector）将保持锁定，
                  密钥也不会被读取。完整的构造函数用法以及如何确认密钥已生效，请参阅
                  [将你的运行时连接到 Intelligence](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                用 CopilotKit provider 包裹你的应用：

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="strands_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此改为渲染你的客户端文件：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```
            </Step>
