## 在现有应用中接入 Intelligence

为你的 Strands 智能体提供跨设备的重连、进度跟进与消息送达能力。按照 [Intelligence 快速开始](/intelligence/quickstart)连接你现有的 CopilotKit 应用与 Runtime，然后验证新对话会被保存。这会为通过 CopilotKit 运行的会话启用 AG-UI 流，无需任何历史导入。

保持 Strands 智能体及其持久化存储处于连接状态，这样导入之后你可以继续这些对话。参见[流如何与框架存储协同工作](/intelligence/threads-explained#how-threads-work-with-framework-storage)。

## 纳入更早的对话（可选）

要让用户能够重新打开接入 Intelligence 之前记录的对话，可使用下方的导入器复制受支持的历史内容。导入不会启用实时送达，也不会建立持续的数据库复制，且无法恢复源存储已不再暴露的历史。

Strands 导入器可从本地会话文件或 S3 读取 Python 与 TypeScript 保存的单智能体对话。Python 还支持读取由 `AgentCoreMemorySessionManager` 保存的 AgentCore Memory 会话。它会迁移已保存的消息、富工具结果、附件，以及（在可用时）智能体状态。部分交互内容（如 MCP 应用视图）可能未保存在原始历史中。外部媒体引用不会被自动下载。

以下前置条件与命令仅适用于该历史导入。可使用 Threads Drawer 或[无头线程（Headless Threads）](/headless-threads)通过同一 UI 打开导入的与新创建的对话。

## 前置条件

- 一个已启用 CopilotKit Intelligence 的 CopilotKit 应用。
- Node.js 20.9 或更高版本，用于运行 CopilotKit CLI。
- 保存在持久化存储中的 Strands 对话。内存中的对话无法导入。
- 对源存储的读取权限，以及要导入的对话所对应的 Strands 智能体 ID。

## 确认目标项目

选择接收历史记录的 Intelligence 项目。其 app-api URL 与项目级运行时密钥决定了导入目的地。导入前你需要导出这些值。

对于 CLI 创建的应用，你可以选择一个云托管项目：

```bash title="Terminal"
npx copilotkit@latest project select
```

该命令会更新当前目录所选的项目，并将其项目级运行时密钥写入应用生成的 `.env`。

## 配置来源

选择你在 [Strands 快速开始](/quickstart)中使用的同一语言，然后选择应用保存对话的位置。S3 与 AgentCore Memory 会被直接读取，无需先下载历史。

对于 AWS 来源，使用你现有的 AWS profile、SSO 会话或角色凭证。如需选择 profile，请设置 `AWS_PROFILE`。这些凭证用于读取来源；下方的 Intelligence 项目密钥决定目的地。

<Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
    ```bash title="Terminal"
    export STRANDS_PY_IMPORT_SOURCE_ID="my-strands-app"
    export STRANDS_PY_IMPORT_AGENT_IDS="support"
    export STRANDS_PY_IMPORT_END_USER_ID="user-123"
    ```

    将 `STRANDS_PY_IMPORT_END_USER_ID` 设置为你的 Runtime 从 `identifyUser` 返回的应用用户 ID。所有选中的对话都会归到该用户名下：只在该目录、S3 前缀或 AgentCore actor 范围内选择该用户的会话，并为每个用户重复此操作。

    <Tabs groupId="strands_python_import_storage" items={['本地文件', 'S3', 'AgentCore Memory']}>
      <Tab value="本地文件">
        ```bash title="Terminal"
        export STRANDS_PY_IMPORT_STORAGE="filesystem"
        export STRANDS_PY_IMPORT_ROOT="/absolute/path/to/sessions"
        export STRANDS_PY_IMPORT_FORMAT="records"
        ```
      </Tab>
      <Tab value="S3">
        ```bash title="Terminal"
        export STRANDS_PY_IMPORT_STORAGE="s3"
        export STRANDS_PY_IMPORT_AWS_REGION="us-east-1"
        export STRANDS_PY_IMPORT_S3_BUCKET="my-strands-bucket"
        export STRANDS_PY_IMPORT_S3_PREFIX="sessions/"
        export STRANDS_PY_IMPORT_FORMAT="records"
        ```

        使用包含已保存会话的存储桶与精确前缀，包括对象键中重复的斜杠。读取权限需要该前缀的 `s3:ListBucket` 及其对象的 `s3:GetObject`，必要时还需要 `kms:Decrypt`。
      </Tab>
      <Tab value="AgentCore Memory">
        ```bash title="Terminal"
        export STRANDS_PY_IMPORT_STORAGE="agentcore"
        export STRANDS_PY_IMPORT_AWS_REGION="us-east-1"
        export STRANDS_PY_IMPORT_FORMAT="records"
        export STRANDS_PY_IMPORT_AGENTCORE_MEMORY_ID="my-memory-id"
        export STRANDS_PY_IMPORT_AGENTCORE_ACTOR_IDS="actor-123"
        ```

        使用保存了 Python `AgentCoreMemorySessionManager` 会话的 memory 与 actor。这会导入默认分支上的原生序列化会话，而非任意纯文本事件或分叉。

        读取权限需要 `bedrock-agentcore:ListEvents`。若要枚举 actor 或会话，还需要 `bedrock-agentcore:ListActors` 或 `bedrock-agentcore:ListSessions`；提供对应的 ID 即可避免这些枚举调用。请将权限范围限定到所选的 memory。

        Actor ID 用于选择原生历史，并不会自动等同于应用用户 ID。将上方的终端用户 ID 设置为应看到这些对话的用户。
      </Tab>
    </Tabs>

    对于本地文件或 S3，请选择应用保存时采用的格式：

    - **会话记录**：`S3SessionManager` 或包含 `session_<id>/session.json` 与智能体消息文件的本地存储，使用 `records`。
    - **快照**：当根目录或前缀中包含 `session/<id>/scopes/agent/<id>/snapshots/snapshot_latest.json` 时，使用 `snapshots`。如果你的应用使用了其他命名空间文件夹，请将 `STRANDS_PY_IMPORT_SNAPSHOT_NAMESPACE` 设置为该文件夹名；若根目录或前缀已位于其中，则设置为空字符串。

    要选择特定对话，请将 `STRANDS_PY_IMPORT_SESSION_IDS="session-1,session-2"` 设置为它们的原生会话 ID。
  </Tab>
  <Tab value="TypeScript">
    ```bash title="Terminal"
    export STRANDS_TS_IMPORT_SOURCE_ID="my-strands-app"
    export STRANDS_TS_IMPORT_LAYOUT="unified"
    export STRANDS_TS_IMPORT_AGENT_IDS="support"
    export STRANDS_TS_IMPORT_END_USER_ID="user-123"
    ```

    将 `STRANDS_TS_IMPORT_END_USER_ID` 设置为你的 Runtime 从 `identifyUser` 返回的应用用户 ID。所有选中的对话都会归到该用户名下：只在该目录或 S3 前缀范围内选择该用户的会话，并为每个用户重复此操作。

    <Tabs groupId="strands_typescript_import_storage" items={['本地文件', 'S3']}>
      <Tab value="本地文件">
        ```bash title="Terminal"
        export STRANDS_TS_IMPORT_STORAGE="filesystem"
        export STRANDS_TS_IMPORT_ROOT="/absolute/path/to/sessions"
        ```
      </Tab>
      <Tab value="S3">
        ```bash title="Terminal"
        export STRANDS_TS_IMPORT_STORAGE="s3"
        export STRANDS_TS_IMPORT_AWS_REGION="us-east-1"
        export STRANDS_TS_IMPORT_S3_BUCKET="my-strands-bucket"
        export STRANDS_TS_IMPORT_S3_PREFIX="sessions/"
        ```

        使用包含已保存快照的存储桶与精确前缀。读取权限需要该前缀的 `s3:ListBucket` 及其对象的 `s3:GetObject`，必要时还需要 `kms:Decrypt`。
      </Tab>
    </Tabs>

    请选择应用保存时采用的布局：

    - **统一布局**：当根目录或 S3 前缀包含 `session/<id>/scopes/agent/<id>/snapshots/snapshot_latest.json` 时，使用 `unified`，例如 `LocalFileStorage`。
    - **旧版布局**：当会话 ID 文件夹直接位于根目录或前缀之下时，使用 `legacy`，例如 `FileStorage`。对于自定义命名空间，请将根目录或前缀指向该命名空间并使用 `legacy`。

    要选择特定对话，请将 `STRANDS_TS_IMPORT_SESSION_IDS="session-1,session-2"` 设置为它们的原生会话 ID。

    TypeScript 的 AgentCore Memory 历史仅为纯文本，不包含本次导入所需的工具、媒体、状态与待处理的交互。请改用本地文件或 S3 中的原生会话快照。
  </Tab>
</Tabs>

将 `support` 替换为你的原生 Strands 智能体 ID。要跨会话选择多个智能体，请在 `STRANDS_PY_IMPORT_AGENT_IDS` 或 `STRANDS_TS_IMPORT_AGENT_IDS` 中使用逗号分隔的 ID，例如 `"support,sales"`。每个会话必须属于单个智能体；不支持编排式多智能体会话。

来源 ID 是你为该存储起的名字。再次导入时请保持不变，包括在同一存储的本地文件与 S3 之间切换时。请在这些对话空闲时运行导入。只有已保存的历史可以导入：快照导入使用最近一次保存的视图，已删除的消息或已过期的 AgentCore 事件无法恢复。

## 执行试运行

在写入任何内容之前预览导入。

<Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
    ```bash title="Terminal"
    npx copilotkit@latest import --source strands-python --dry-run
    ```
  </Tab>
  <Tab value="TypeScript">
    ```bash title="Terminal"
    npx copilotkit@latest import --source strands-typescript --dry-run
    ```
  </Tab>
</Tabs>

试运行会统计对话数量、报告无法导入的对话，并估算上传大小。它不需要 CopilotKit Intelligence URL 或 API 密钥。

## 将 Strands 智能体映射到 CopilotKit agent ID

将你在 `STRANDS_PY_IMPORT_AGENT_IDS` 或 `STRANDS_TS_IMPORT_AGENT_IDS` 中设置的每个原生 Strands 智能体 ID，映射到线上 CopilotKit 运行时所使用的 `agentId`。

```json title="agent-map.json"
{
  "support": "support-agent"
}
```

与线上流量使用相同的 `agentId`，可以让导入的历史与后续对话归在一起。

## 准备 CopilotKit Intelligence 目标

正式导入需要目的地的 app-api URL 与项目级运行时密钥。CLI 创建的起步模板会把它们写入 `.env`，但导入器读取的是当前进程环境，不会自动加载 `.env` 或 `.copilotkit/project.json`。

导入前，将生成的值复制到你的 shell 中：

```bash title="Terminal"
export INTELLIGENCE_API_URL="https://..."
export CPK_INTELLIGENCE_API_KEY="cpk-..."
```

你也可以改用 `--api-url` 与 `--api-key` 直接传入目的地。

## 导入对话

在试运行与智能体映射都确认无误后，运行导入。

<Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
    ```bash title="Terminal"
    npx copilotkit@latest import --source strands-python --agent-map ./agent-map.json
    ```

    对于自托管的 CopilotKit Intelligence，请显式传入目标连接：

    ```bash title="Terminal"
    npx copilotkit@latest import \
      --source strands-python \
      --api-url "$INTELLIGENCE_API_URL" \
      --api-key "$CPK_INTELLIGENCE_API_KEY" \
      --agent-map ./agent-map.json \
      --yes
    ```
  </Tab>
  <Tab value="TypeScript">
    ```bash title="Terminal"
    npx copilotkit@latest import --source strands-typescript --agent-map ./agent-map.json
    ```

    对于自托管的 CopilotKit Intelligence，请显式传入目标连接：

    ```bash title="Terminal"
    npx copilotkit@latest import \
      --source strands-typescript \
      --api-url "$INTELLIGENCE_API_URL" \
      --api-key "$CPK_INTELLIGENCE_API_KEY" \
      --agent-map ./agent-map.json \
      --yes
    ```
  </Tab>
</Tabs>

没有终端用户 ID 的对话默认会被跳过。导入前请在上面的来源配置中设置终端用户 ID。

## 验证已导入的对话

以你导入其 ID 的应用用户身份登录。打开 Threads Drawer，选择一个已导入的 Strands 对话，确认其历史显示在聊天中。

## 重新运行或替换

已导入的对话默认会被跳过。

使用 `--replace` 刷新它们；正在进行或已继续的对话保持不变：

<Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
  <Tab value="Python">
    ```bash title="Terminal"
    npx copilotkit@latest import \
      --source strands-python \
      --agent-map ./agent-map.json \
      --replace
    ```
  </Tab>
  <Tab value="TypeScript">
    ```bash title="Terminal"
    npx copilotkit@latest import \
      --source strands-typescript \
      --agent-map ./agent-map.json \
      --replace
    ```
  </Tab>

## 继续使用 Strands 持久化

导入会复制受支持的历史，但不会建立持续的数据库复制。Intelligence 的重命名、归档与删除操作只影响 Intelligence 记录，原生 Strands 记录保持不变。

你的应用会通过 CopilotKit 将后续对话发送到 CopilotKit Intelligence。保持应用以正常的读写凭证连接到同一存储后端中的原始原生会话与智能体（对 AgentCore 而言包括相同的 memory 与 actor），然后从 Threads Drawer 重新打开已导入的对话，即可从上次中断的地方继续，包括受支持的待审批项与输入请求。

保持应用的前端工具、审批处理器与 UI 渲染器处于配置状态。对于不带生成包装器的原生 A2UI 输出，请在 A2UI 中间件配置中设置 `a2uiGenerationToolNames: []`；如果你的应用使用生成包装器，则改为列出它们的工具名。参见 [A2UI 配置](/generative-ui/a2ui)。

- **Threads Drawer**：CLI 创建的起步模板已内置。使用 [Threads Drawer 指南](/prebuilt-components/copilot-threads-drawer)自定义其现成的线程 UI。
- **无头线程**（Headless Threads）：仅在你需要自定义 UI 时使用[无头线程指南](/headless-threads)。用 `useThreads` 选择线程，保存其 `thread.id`，并将该值作为 `threadId` 传给你的聊天组件。

打开一个已导入的对话并发送后续消息，即可继续它。
