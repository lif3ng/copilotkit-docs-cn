## 这是什么？

前端工具让你能够定义 ADK 智能体可以调用的客户端函数，其执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，
逻辑在客户端运行，让你可以直接访问前端环境。

它可以用来[让你的智能体控制 UI](/adk/frontend-tools)、实现[生成式 UI](/adk/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

本指南介绍如何将前端工具用于人机协同。

## 什么时候该用它？

当你需要智能体与以下客户端原语交互时，可以使用前端工具：

- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 实现

<Steps>
    <Step>
      ### 运行并连接你的智能体
      <RunAndConnect />
    </Step>

    <Step>
        ### 创建前端人机协同工具

        前端工具可以用在多种场景中。其中之一是人机协同流程——工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的“审批”流程。首先，使用 `useHumanInTheLoop` 钩子创建一个提示用户进行批准的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```

        就这些！你的智能体会自动获得对你在 React 组件中用 `useHumanInTheLoop` 定义的所有人机协同工具的访问能力。

        <Callout type="info">
          通过 `useHumanInTheLoop` 注册的人机协同工具会经由 AG-UI 协议自动转发给你的智能体。
        </Callout>
    </Step>
    <Step>
        ### 试试看！

        现在，你的智能体已经能够向用户展示两个选项并让用户选择其一。随后智能体会知晓用户的选择，并能在后续步骤中使用它。

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
