## 从你的编码智能体开始

使用此提示词将你的 Google ADK 智能体接入 CopilotKit，并验证对话可以正常工作。你的编码智能体会按照本指南在你的项目中操作，你也可以按下面的手动步骤逐步完成。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 Google Gemini API 密钥
- Node.js 20+
- Python 3.9+
- 你顺手的包管理器

                ### 安装带 AG-UI 的 ADK

                将带 AG-UI 支持的 ADK 以及 uvicorn 添加到你的项目：

                ```bash
                uv add ag-ui-adk google-adk uvicorn fastapi
                ```

                <Callout type="info" title="什么是 AG-UI？">
                  AG-UI 是一个用于前端与智能体通信的开放协议。`ag-ui-adk` 包提供了 CopilotKit 可以连接的 ADK 集成。
                </Callout>
            </Step>
            <Step>
                ### 配置环境

                将你的 Google API 密钥设置为环境变量：

                ```bash
                export GOOGLE_API_KEY=your_google_api_key
                ```

                <Callout type="info" title="其他模型呢？">
                  本例使用 Gemini 3.8 Flash，但你可以修改它，改用 ADK 支持的任意语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露你的智能体

                更新你的智能体文件，将其暴露为 AG-UI ASGI 应用：

                ```python title="main.py"
                from fastapi import FastAPI
                from ag_ui_adk import ADKAgent, add_adk_fastapi_endpoint
                from google.adk.agents import LlmAgent

                agent = LlmAgent(
                    name="assistant",
                    model="gemini-3.8-flash",
                    instruction="Be helpful and fun!"
                )

                adk_agent = ADKAgent(
                    adk_agent=agent,
                    app_name="demo_app",
                    user_id="demo_user",
                    session_timeout_seconds=3600,
                    use_in_memory_services=True
                )

                app = FastAPI()
                add_adk_fastapi_endpoint(app, adk_agent, path="/")

                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)
                ```
            </Step>
            <Step>
                ### 创建你的前端

                CopilotKit 可以与任何基于 React 的前端配合使用。本例中我们将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/client@1.0.2
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由，将 CopilotKit 连接到你的 ADK 智能体：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
               ```

                在这个前端应用目录中，将 runtime 连接到一个 Intelligence 项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会把服务端项目 API 密钥写入 `.env`。runtime 会在这里读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用 Intelligence 平台运行？">
                  去掉 `intelligence` 和 `identifyUser` 选项，runtime 会回退到使用内存 runner 的 SSE 模式。聊天仍然可用，但 Threads 与 Inspector 将保持锁定，密钥也永远不会被读取。完整构造方式以及如何确认密钥已生效，请参见[将你的 runtime 连接到 Intelligence](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                用 CopilotKit provider 包装你的应用：

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此它改为渲染你的客户端文件：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="info" title="这个相对 runtimeUrl 假设由 Next.js 提供服务">
                  `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源（origin）同时提供你的应用与 runtime。纯客户端前端没有共同的源，因此它需要自己单独的 runtime 服务器，以及绝对的 `runtimeUrl`，例如 `http://localhost:8200/api/copilotkit`。`/react-spa`、`/vue`、`/angular` 与 `/react-native` 的各前端指南都展示了这种配置。
                </Callout>
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到你的页面：

              ```tsx title="app/page.tsx"
              "use client"; // [!code highlight]

              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>Your App</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
