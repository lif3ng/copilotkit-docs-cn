## 这是什么？

ADK 智能体的状态更新是不连续的，只有在显式进行状态更改时才会更新。
但即便是_单个操作_，也往往需要运行数秒之久，其中还包含用户关心的多个子步骤。

**智能体原生应用**会以**尽可能连续的方式**向最终用户反映智能体正在做什么。

CopilotKit 通过**_预测性状态更新_**这一概念来实现这一点。

## 什么时候应该使用它？

在以下情况下使用预测性状态更新：

- **保持用户参与度**，避免长时间显示加载指示器
- **建立信任**，展示智能体正在处理的内容
- 支持**智能体引导**——允许用户在需要时纠正智能体的方向

## 重要提示

当智能体执行完毕后，**其最终状态将成为唯一的真相来源**。中间状态更新非常适合提供实时反馈，但任何你想要持久保留的更改都必须显式包含在最终状态中。否则，操作完成时这些更改将被覆盖。

## 实现

<Steps>
  <Step>
    ### 定义状态
    我们将在状态中定义一个 `observed_steps` 字段，随着智能体执行任务的不同步骤，该字段会被更新。

    ```python title="agent.py"
    from typing import Dict, List
    from fastapi import FastAPI
    from pydantic import BaseModel
    from ag_ui_adk import ADKAgent, add_adk_fastapi_endpoint
    from google.adk.agents import LlmAgent
    from google.adk.tools import ToolContext


    class AgentState(BaseModel):
        """State for the agent."""
        observed_steps: List[str] = []
    ```

  </Step>
  <Step>
    ### 发出中间状态

    <TailoredContent
        id="state-emission"
        header={
            <div>
                <p className="text-xl font-semibold">你希望如何发出状态更新？</p>
                <p className="text-base">
                    你可以手动发出状态更新，也可以配置特定的工具调用来发出更新。
                </p>
            </div>
        }
    >
        <TailoredContentOption
            id="tool-emission"
            title="基于工具的预测性状态更新"
            description="配置特定的工具调用，自动发出中间状态更新。"
            icon={<FaWrench />}
        >
            对于长时间运行的任务，你可以创建一个更新状态并将其发送到前端的工具。在本例中，我们将创建一个步骤进度工具，由 LLM 调用它来报告进度。

            ```python title="agent.py"
            from typing import Dict, List
            from fastapi import FastAPI
            from pydantic import BaseModel
            from ag_ui_adk import ADKAgent, add_adk_fastapi_endpoint
            from google.adk.agents import LlmAgent
            from google.adk.tools import ToolContext


            class AgentState(BaseModel):
                """State for the agent."""
                observed_steps: List[str] = []


            def step_progress(tool_context: ToolContext, steps: List[str]) -> Dict[str, str]:
                """Reports the current progress steps.

                Args:
                    tool_context (ToolContext): The tool context for accessing state.
                    steps (List[str]): The list of steps completed so far.

                Returns:
                    Dict[str, str]: A dictionary indicating the progress was received.
                """
                tool_context.state["observed_steps"] = steps
                return {"status": "success", "message": "Progress received."}


            agent = LlmAgent(
                name="my_agent",
                model="gemini-3.8-flash",
                instruction="""
                You are a task performer. When given a task, break it down into steps
                and report your progress using the step_progress tool after completing each step.
                """,
                tools=[step_progress],
            )

            adk_agent = ADKAgent(
                adk_agent=agent,
                app_name="demo_app",
                user_id="demo_user",
                session_timeout_seconds=3600,
                use_in_memory_services=True,
            )

            app = FastAPI()
            add_adk_fastapi_endpoint(app, adk_agent, path="/")

            if __name__ == "__main__":
                uvicorn.run(app, host="0.0.0.0", port=8000)
            ```

            <Callout>
              通过这种配置，智能体每次调用 `step_progress` 工具时都会发出状态更新，让前端能够实时掌握进度。
            </Callout>
        </TailoredContentOption>
    </TailoredContent>

  </Step>
  <Step>
    ### 观察预测
    这些预测会在智能体运行过程中发出，让你能在最终状态确定之前跟踪其进度。

    ```tsx title="ui/app/page.tsx"
    "use client";


    // ...
    type AgentState = {
        observed_steps: string[];
    };

    const YourMainContent = () => {
        // Get access to both predicted and final states
        const { agent } = useAgent({ agentId: "my_agent" });

        // Add a state renderer to observe predictions
        useAgent({
            agentId: "my_agent",
            render: ({ state }) => {
                if (!state.observed_steps?.length) return null;
                return (
                    <div>
                        <h3>Current Progress:</h3>
                        <ul>
                            {state.observed_steps.map((step, i) => (
                                <li key={i}>{step}</li>
                            ))}
                        </ul>
                    </div>
                );
            },
        });

        return (
            <div>
                <h1>Agent Progress</h1>
                {agent.state?.observed_steps?.length > 0 && (
                    <div>
                        <h3>Final Steps:</h3>
                        <ul>
                            {agent.state.observed_steps.map((step, i) => (
                                <li key={i}>{step}</li>
                            ))}
                        </ul>
                    </div>
                )}
            </div>
        )
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与你在 CopilotRuntime 配置中定义的智能体名称完全一致（例如快速开始中的 `my_agent`）。
    </Callout>

  </Step>
  <Step>
    ### 动手试试！
    现在你会看到，随着智能体不断推进，状态预测会持续发出，让你在最终状态确定之前就能了解它的工作内容。
    你可以将这一模式应用到智能体中任何长时间运行的任务上。
  </Step>
</Steps>
