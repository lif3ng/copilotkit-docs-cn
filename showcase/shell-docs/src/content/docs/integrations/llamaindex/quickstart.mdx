## 从你的编码智能体开始

使用以下提示词将你的 LlamaIndex 智能体连接到 CopilotKit，并验证对话可用。你的编码智能体会在项目中遵循本指南执行，你也可以按下面的手动步骤操作。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 OpenAI API 密钥
- Node.js 20+
- Python 3.10+
- 你顺手的包管理器

            <Step>
                ### 初始化你的智能体项目

                如果你还没有 Python 项目，使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```

            <Step>
                ### 安装带 AG-UI 的 LlamaIndex

                为你的项目添加带 AG-UI 支持的 LlamaIndex 与 uvicorn：

                ```bash
                uv add llama-index llama-index-llms-openai llama-index-protocols-ag-ui fastapi uvicorn
                ```

                <Callout type="info" title="AG-UI 是什么？">
                  AG-UI 是一个用于前端与智能体通信的开放协议。`llama-index-protocols-ag-ui` 包提供了 CopilotKit 可连接的 LlamaIndex 集成。
                </Callout>
            </Step>
            <Step>
                ### 配置你的环境

                将你的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="想使用其他模型？">
                  本示例使用 OpenAI 的 GPT-4o，但你可以修改为使用 LlamaIndex 支持的任何语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露你的智能体

                更新你的智能体文件，将其暴露为 AG-UI ASGI 应用：

                ```python title="main.py"
                from fastapi import FastAPI
                from llama_index.llms.openai import OpenAI
                from llama_index.protocols.ag_ui.router import get_ag_ui_workflow_router

                # Initialize the LLM
                llm = OpenAI(model="gpt-5.4")

                # Create the AG-UI workflow router
                agentic_chat_router = get_ag_ui_workflow_router(
                    llm=llm,
                    system_prompt="You are a helpful AI assistant with access to various tools and capabilities.",
                )

                # Create FastAPI app
                app = FastAPI(
                    title="LlamaIndex Agent",
                    description="A LlamaIndex agent integrated with CopilotKit",
                    version="1.0.0"
                )

                # Include the router
                app.include_router(agentic_chat_router)

                # Health check endpoint
                @app.get("/health")
                async def health_check():
                    return {"status": "healthy", "agent": "llamaindex"}

                if __name__ == "__main__":
                    import uvicorn
                    uvicorn.run(app, host="localhost", port=8000)
                ```
            </Step>
            <Step>
                ### 创建你的前端

                CopilotKit 可与任何基于 React 的前端配合使用。本示例将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/llamaindex
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由，把 CopilotKit 连接到你的 LlamaIndex 智能体：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { LlamaIndexAgent } from "@ag-ui/llamaindex";

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new LlamaIndexAgent({ url: "http://localhost:8000/run" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
               ```

                在这个前端应用目录下，将运行时连接到一个 Intelligence 项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会把服务端项目 API 密钥写入 `.env`。运行时在这里读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用 Intelligence 平台运行？">
                  去掉 `intelligence` 与 `identifyUser` 选项后，运行时会回退到使用内存 runner 的 SSE 模式。聊天仍然可用，但 Threads 与 Inspector 将保持锁定，密钥也不会被读取。完整构造方式以及如何确认密钥已生效，参见[将你的运行时连接到 Intelligence](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                用 CopilotKit provider 包裹你的应用：

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务器组件，无法直接导入 provider，因此它改为渲染你的客户端文件：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="info" title="此相对 runtimeUrl 假定由 Next.js 提供运行时服务">
                  `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源提供你的应用与运行时。纯客户端前端没有共享源，因此需要自建一个独立的运行时服务器，并使用绝对 `runtimeUrl`（如 `http://localhost:8200/api/copilotkit`）。`/react-spa`、`/vue`、`/angular` 与 `/react-native` 的各前端指南分别展示了这种配置。
                </Callout>
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到你的页面：

              ```tsx title="app/page.tsx"
              "use client"; // [!code highlight]

              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>Your App</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
