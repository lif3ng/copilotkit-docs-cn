## 什么是共享状态？

CoAgents 维护一种共享状态，将你的 UI 与智能体的执行无缝连接起来。这套共享状态系统让你可以：

- 展示智能体的当前进度与中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用中实时响应状态变化

这套系统的基础是 LlamaIndex 的 AG-UI 协议集成，它在 workflow router 中提供了 `initial_state` 支持。

## 何时应该使用它？

当你想促进智能体与用户之间的协作时，状态流式传输非常合适。你的 LlamaIndex 智能体持久化的任何状态都会自动共享给 UI；同样，用户在 UI 中更新的任何状态也会自动反映到智能体侧。

这让智能体与用户始终保持同步，带来一致的体验。
