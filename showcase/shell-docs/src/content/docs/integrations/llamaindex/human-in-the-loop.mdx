## 这是什么？

前端工具让你能够定义 LlamaIndex 智能体可以调用的客户端函数，其执行完全发生在用户的浏览器中。当智能体调用前端工具时，逻辑在客户端一侧运行，你可以直接访问前端环境。

它可用于让[智能体控制 UI](/llamaindex/frontend-tools)、实现[生成式 UI](/llamaindex/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

本指南介绍如何使用前端工具实现人机协同。

## 什么时候应该使用它？

当你需要智能体与客户端底层能力交互时，可以使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

    <Step>
        ### 为智能体添加工具
        为智能体添加一个工具，它将用于撰写文章。由于该工具会在前端使用，
        我们把它加进 `frontend_tools` 列表。

        ```python title="agent.py"
        from fastapi import FastAPI
        from llama_index.llms.openai import OpenAI
        from llama_index.protocols.ag_ui.router import get_ag_ui_workflow_router

        def offerOptions(option_1: str, option_2: str) -> str:
            """Give the user a choice between two options and have them select one."""
            return f"Presenting options: {option_1} or {option_2}"

        # Initialize the LLM
        llm = OpenAI(model="gpt-5.4")

        # Create the AG-UI workflow router
        agentic_chat_router = get_ag_ui_workflow_router(
            llm=llm,
            frontend_tools=[offerOptions],
            system_prompt="You are a helpful AI assistant that can write essays. When the user asks you to choose between two options or when you need to present them with a choice, you MUST use the offerOptions tool to let them select between the options.",
        )

        # Create FastAPI app
        app = FastAPI(
            title="LlamaIndex Agent",
            description="A LlamaIndex agent integrated with CopilotKit",
            version="1.0.0"
        )

        # Include the router
        app.include_router(agentic_chat_router)

        # Health check endpoint
        @app.get("/health")
        async def health_check():
            return {"status": "healthy", "agent": "llamaindex"}

        if __name__ == "__main__":
            import uvicorn
            uvicorn.run(app, host="localhost", port=8000)
        ```
    </Step>

    <Step>
        ### 创建前端人机协同工具

        前端工具可以以多种方式加以利用。其中一种方式是打造人机协同流程：
        让工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的“审批”流程。首先，使用 `useHumanInTheLoop` hook
        创建一个提示用户进行批准的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```

        大功告成！你在 React 组件中用 `useHumanInTheLoop` 定义的所有人机协同工具，都会自动对智能体可用。

        <Callout type="info">
          通过 `useHumanInTheLoop` 注册的人机协同工具会经由 AG-UI 协议自动转发给你的智能体。
        </Callout>
    </Step>

