title: 代码贡献

感谢你有兴趣为 CopilotKit 做贡献。我们欢迎新贡献者，也感谢你帮助 CopilotKit 变得更好。

本指南将帮助你尽可能顺利地开始。

## 第 1 步：安装前置条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- 全局安装 [pnpm](https://pnpm.io/) v10.x（`npm i -g pnpm@^10`）

## 第 2 步：仓库设置

<Steps>
  <Step>
  ### 复刻（Fork）仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit)并创建一个 fork（复刻）。

  然后，将你的 fork 克隆到本地：
  ```bash
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit
  ```
  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是一个使用 [pnpm](https://pnpm.io/) workspace 的 monorepo。跨包任务由 [Nx](https://nx.dev/) 编排。
  </Callout>

  使用 pnpm 安装依赖：
  ```bash
  pnpm install
  ```
  </Step>
  <Step>
  ### 构建包
  为确保一切正常，先把所有包构建一次：
  ```bash
  pnpm run build
  ```
  </Step>
</Steps>

## 第 3 步：开发模式
一切就绪并按预期工作后，就可以开始开发了：

```bash
# 以开发模式启动所有包
pnpm run dev

# 以开发模式启动某个特定包
pnpm exec nx watch --projects=packages/package-name -- pnpm run build
```

现在可以开始修改代码了。

<Callout type="info">
所有 `@copilotkit/*` 包都位于 monorepo 的 `packages` 文件夹下。
</Callout>

## 第 4 步：实时测试变更

大多数情况下，你希望在开发过程中能够无缝地实时测试自己的变更。

monorepo 中有一个 `examples` 文件夹，包含若干使用 CopilotKit 的示例。这些示例与 monorepo 中的 `@copilotkit/*` 包相互链接，你可以运行它们来测试自己的变更。

本教程使用 `next-openai` 示例，具体是 Presentation Demo（`/presentation`）。

另开一个终端，运行以下命令启动该示例：

```bash
cd examples/v1/next-openai
export OPENAI_API_KEY=<your-openai-api-key>
pnpm run example-dev
```

<Callout type="info">
我们用 `pnpm run example-dev` 命令来运行示例，这与开发各个包时所用的 `pnpm run dev` 命令不同。
</Callout>

现在打开 http://localhost:3000/presentation，应该能看到示例正在运行。你对 CopilotKit 包所做的任何更改都会立即反映在这里。

## 第 5 步：格式化与 Lint 检查

提交变更前，请在 monorepo 根目录运行以下命令，确保文件已正确格式化：
```bash
pnpm run format
```

此外，请确保没有 lint 错误：
```bash
pnpm run lint
```

## 第 6 步：提交 Pull Request

完成变更后，提交并推送它们。然后前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls)创建一个 pull request 即可。干得漂亮！

## 启动支持热重载的开发环境

CopilotKit 内置了一个现成的脚本，可基于某个 CoAgent 示例启动开发环境。它让你在核心 TypeScript 与 Python 代码中开发 CopilotKit 内部实现的同时，看到变更应用到所选示例上。

前置条件：确保已安装 GNU parallel 和 langgraph CLI。

接着，进入 `CopilotKit/` 目录，为你要开发的示例运行 `example.sh` 脚本：

```bash
./scripts/develop/example.sh coagents-starter
```

这会启动一个支持热重载的开发环境。

你也可以选择在 LangGraph 平台上运行同一示例：

```bash
./scripts/develop/example.sh coagents-starter langgraph-platform
```

## 调试

每次在 localhost 上运行 CopilotKit 时，你都能在聊天窗口中看到 **CopilotKit 开发者控制台**（Dev Console）。开发者控制台提供了实用的调试功能（例如查看 copilot 感知到的状态、它可以执行的操作等）。

<Frame description="CopilotKit 开发者控制台">
  <img
    src="https://cdn.copilotkit.ai/docs/copilotkit/images/contributing/copilotkit-dev-console.png"
    className="w-auto max-w-[420px]"
  />
</Frame>

如果想在本地禁用开发者控制台，只需在 `<CopilotKit />` Provider 中将 `showDevConsole` 设置为 `false`。

## （进阶）包链接

有时你想在自己的项目中测试对 CopilotKit 的修改。例如，你尝试把 CopilotKit 集成到自己的代码库时遇到了一个想修复的 bug。

方便的是，你可以把本地的 CopilotKit 包链接到自己的项目来测试变更。

具体做法参见[进阶：包链接](/contributing/code-contributions/package-linking)指南。
