---

在本指南中，我们将教你如何把 CopilotKit 包链接到自己的项目来测试更改。这样，你可以在 CopilotKit monorepo 中运行 `pnpm run dev`，并立即在自己的项目中看到更改。

## 使用 `pnpm` 进行全局包链接

我们将使用 pnpm 的[全局链接功能](https://pnpm.io/cli/link#pnpm-link---global)把 CopilotKit 包链接到你的项目。

<Steps>
  <Step>
  ### 在 CopilotKit monorepo 中
  假设你已按贡献指南完成所有步骤，那么一切应已正确配置完毕、随时可以开始。

  进入 CopilotKit monorepo，运行以下命令全局链接这些包：

  ```bash
  pnpm exec nx run-many -t link:global
  ```
  </Step>
  <Step>
  ### 在你的项目中
  在你的项目中，确保已配置 pnpm。这并不妨碍你同时使用 npm 或 yarn。但为了进行全局链接，必须使用 pnpm。

  ```bash
  cd your-project
  pnpm i
  ```

  接下来，在项目中链接所需的包：
  ```bash
  # 例如，链接 @copilotkit/react-core 包：
  pnpm link --global @copilotkit/react-core
  ```

  你可以对所有包执行这一操作，也可以只链接需要的包。你的更改现在会同步生效。
  </Step>
  <Step>
  ### 解除链接
  完成后，你可以在 CopilotKit monorepo 中运行以下命令来解除全局链接：

  ```bash
  pnpm exec nx run-many -t unlink:global
  ```

  然后在你的项目中：
  ```bash
  pnpm install
  ```

  大功告成，一切恢复原样！
  </Step>
</Steps>
