## 快速开始

<Steps>
  <Step>
    ### 使用 A2A 起步模板

    ```bash
    git clone https://github.com/CopilotKit/CopilotKit.git
    cd CopilotKit/examples/integrations/a2a-a2ui
    ```

    已归档的 `copilotkit/with-a2a-a2ui`
    起步模板现在位于这个 monorepo
    路径。当前起步模板使用其本地的 v0.8
    渲染器，并输出一份 v0.8
    操作对象的 JSON 列表。本页记录的正是这份起步模板所接受的载荷。把起步模板迁移到
    v0.9 渲染器与 `a2ui_operations`
    信封所需的改动不在本文档的目标范围内。

  </Step>

    ### 安装依赖

    ```
    pnpm install
    ```

  <Step>
    ### 为智能体配置组件

    起步模板当前的智能体接受下面这份 v0.8
    操作列表。添加你自己的组件时，请保持操作的顺序与形态；列表中的每一项都会由起步模板智能体作为一个独立的
    A2A data part 发送。

    ```python title="agent/prompt_builder.py"
      RESTAURANT_UI_EXAMPLES = """
      ...
      ---BEGIN SINGLE_COLUMN_LIST_EXAMPLE---
      [
        {{ "beginRendering": {{ "surfaceId": "default", "root": "root-column", "styles": {{ "primaryColor": "#FF0000", "font": "Roboto" }} }} }},
        {{ "surfaceUpdate": {{
          "surfaceId": "default",
          "components": [
            {{ "id": "root-column", "component": {{ "Column": {{ "children": {{ "explicitList": ["title-heading", "item-list"] }} }} }} }},
            {{ "id": "title-heading", "component": {{ "Text": {{ "usageHint": "h1", "text": {{ "literalString": "Top Restaurants" }} }} }} }},
            {{ "id": "item-list", "component": {{ "List": {{ "direction": "vertical", "children": {{ "template": {{ "componentId": "item-card-template", "dataBinding": "/items" }} }} }} }} }},
            {{ "id": "item-card-template", "component": {{ "Card": {{ "child": "card-layout" }} }} }},

                {{ "key": "rating", "valueNumber": 4.8 }},
                {{ "key": "detail", "valueString": "Fine dining experience" }},

      ]
      ---END SINGLE_COLUMN_LIST_EXAMPLE---
      # ... more examples below
      ```

    这些 widget 会被注入智能体的提示中，本例使用
    `RESTAURANT_UI_EXAMPLES` 变量。widget
    的定义方式是给智能体一个它应输出的 JSON
    数组示例，并用注释块包裹起来。
    - 标记示例开始的一条注释
    - beginRendering：启动 v0.8 surface
    - surfaceUpdate：定义 v0.8 组件树
    - dataModelUpdate：提供 v0.8 数据模型内容
    - 标记示例结束的一条注释

    在示例仓库中，所有 widget 都定义在 prompt_builder.py
    文件的同一个变量里，但你可以按任意方式组织它们；只需要以清晰划界
    的方式注入智能体的提示即可。本起步模板页不演示 v0.9 SDK
    迁移。

    当前起步模板的 v0.8
    渲染器显示 `Book Now`
    控件时，没有附加 `onClick`
    处理器，也不派发动作。这个按钮是惰性的，因此没有任何点击到达
    智能体，执行器的 `book_restaurant`
    分支也不会被触及。补上动作接线不属于这份纯文档改动。

  <Step>
    ### 配置你的应用渲染 A2UI
    AG-UI 负责与你的 a2a
    智能体通信，并以 `ActivityMessage`
    对象的形式来回传递 a2ui
    消息。要在前端渲染它们，你需要配置活动消息（activity
    message）的渲染。

    当前起步模板注册了它本地的 v0.8 渲染器与 v0.8
    主题。下面的配置与该 `app/page.tsx`
    一致；v0.9 渲染器与 `a2ui_operations`
    信封在其他 A2UI 集成指南中说明。

    ```tsx title="app/page.tsx"
    "use client";

    import { CopilotChat, CopilotKitProvider } from "@copilotkit/react-core/v2";
    import { a2uiV08Renderer } from "./components/a2ui-v0-8-renderer";
    import { theme } from "./theme";

    // Disable static optimization for this page
    export const dynamic = "force-dynamic";

    const activityRenderers = [a2uiV08Renderer];

    export default function Home() {
      return (
        <CopilotKitProvider
          runtimeUrl="/api/copilotkit"
          useSingleEndpoint={false}
          a2ui={{ theme }}
          renderActivityMessages={activityRenderers}
        >
          <main
            className="h-full overflow-auto w-screen"
            style={{ minHeight: "100dvh" }}
          >
            <CopilotChat className="h-full" />
          </main>
        </CopilotKitProvider>
      );
    }
    ```
