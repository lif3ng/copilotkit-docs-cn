## 从你的编码智能体开始

使用此提示词将你的 A2A 智能体接入 CopilotKit，并验证对话可以正常工作。你的编码智能体会按照本指南在你的项目中操作，你也可以按下面的手动步骤逐步完成。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 Google Gemini API 密钥
- Node.js 20+
- Python 3.9+
- 你顺手的包管理器

## 开始使用

<Steps>
    <Step>
        ### 设置 CopilotKit Intelligence

        <SignupLink surface="docs_a2a_quickstart_step1">登录云托管版 Intelligence</SignupLink>。云托管配置使用服务端项目 API 密钥，不会签发 `COPILOTKIT_LICENSE_TOKEN`。你将在下文克隆应用后再完成连接。
    </Step>

    <Step>
        ### 克隆 A2A 起步模板

        ```bash
        git clone https://github.com/copilotkit/with-a2a-a2ui.git
        cd with-a2a-a2ui
        npx copilotkit@latest project select
        ```

        `project select` 会创建或选择一个 Intelligence 项目，并将其服务端 API 密钥以 `CPK_INTELLIGENCE_API_KEY` 的形式写入 `.env`。
    </Step>
    <Step>
        ### 安装依赖

        ```
        pnpm install
        ```
    </Step>
    <Step>
        ### 配置环境

        在你的智能体目录中创建 `.env` 文件，并添加你的 Google API 密钥：

        ```plaintext title="agent/.env"
        GEMINI_API_KEY=your_gemini_api_key
        ```

        <Callout type="info" title="其他模型呢？">
          起步模板默认配置使用 Google 的 Gemini，但你可以修改它，改用 ADK 支持的任意语言模型。
        </Callout>
    </Step>
    <Step>
        ### 启动开发服务器

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn', 'bun']}>
            <Tab value="npm">
                ```bash
                npm run dev
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm dev
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn dev
                ```
            </Tab>
            <Tab value="bun">
                ```bash
                bun dev
                ```
            </Tab>
        </Tabs>

        这会同时启动 UI 服务器与智能体服务器。
    </Step>
    <Step>
        ### 🎉 开始对话！

        你的 AI 智能体现在已经可以使用了！访问 `localhost:3000`，开始向它提问：

        ```
        Show me chinese restaurants in NYC
        ```

        <Accordions className="mb-4">
            <Accordion title="故障排查">
                - 如果遇到连接问题，尝试用 `0.0.0.0` 或 `127.0.0.1` 代替 `localhost`
                - 确保你的智能体运行在 10002 端口
                - 检查你的 Google API 密钥是否已正确设置
            </Accordion>
        </Accordions>

    </Step>

    <Step>
        <OpenInspectorStep components={props.components} />
    </Step>


</Steps>
