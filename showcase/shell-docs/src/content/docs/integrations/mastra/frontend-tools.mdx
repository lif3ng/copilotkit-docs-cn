## 这是什么？

前端工具让你能够定义 Mastra 智能体可以调用的客户端函数，其执行完全发生在用户的浏览器中。当你的智能体调用某个前端工具时，逻辑会在客户端运行，让你可以直接访问前端环境。

它可以用来[让智能体控制 UI](/mastra/frontend-tools)、实现[生成式 UI](/mastra/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

在本指南中，我们将介绍如何使用前端工具来驱动 UI 并与之交互。

## 什么时候应该使用它？

当你需要智能体与客户端原语交互时，可以使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

    <Step>
        ### 创建一个前端工具

        首先，你需要使用 [useFrontendTool](/reference/v1/hooks/useFrontendTool) hook 创建一个前端工具。下面是一个简单的入门示例，它会向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          // [!code highlight:12]
          useFrontendTool({
            name: "sayHello",
            description: "Say hello to the user",
            parameters: z.object({
              name: z.string().describe("The name of the user to say hello to"),
            }),
            handler: async ({ name }) => {
              alert(`Hello, ${name}!`);
              return `Said hello to ${name}!`;
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 访问前端工具

        由于 Mastra 原生支持 AG-UI 协议，前端工具会自动作为工具提供给智能体使用。
    </Step>
