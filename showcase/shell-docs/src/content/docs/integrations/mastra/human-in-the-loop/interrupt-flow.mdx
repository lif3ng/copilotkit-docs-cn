<Callout type="warning">
  **Mastra 不支持原生中断流**。该框架缺少 LangGraph 风格的 `interrupt()` 原语——即让工具在执行中途暂停并发出 AG-UI 中断事件的机制。本页出于参考目的记录了中断模式，但它 **在 Mastra 中无法工作**。

  要在 Mastra 中实现可用的人机协同（human-in-the-loop）功能，请改用带 `useHumanInTheLoop` 的[基于工具方案](/mastra/human-in-the-loop/tool-based)。
</Callout>

## 什么是中断？

一些框架（如 LangGraph）提供原生的中断能力：工具可以通过 `interrupt()` 或 `suspend()` 调用在执行中途暂停自身，向前端发出 AG-UI 中断事件，并等待用户响应后再继续。CopilotKit 的 `useInterrupt` hook 会捕获这些事件并渲染自定义 UI。

## 为什么 Mastra 不支持这种方式？

Mastra 不会发出 AG-UI 中断事件。虽然 Mastra 为工具审批工作流提供了 `suspend()` API，但它运行在 Mastra 自身的执行模型之内，无法通过 AG-UI 协议与 CopilotKit 的中断处理集成。在 Mastra 应用中，任何 `useInterrupt` hook 监听的都将是永远不会到达的事件，导致 UI 卡在工具调用的占位状态上。

## 应该改用什么？

**请使用带 `useHumanInTheLoop` 的基于工具方案**。这是 Mastra 受支持且切实可用的模式：

<Steps>
<Step>
  ### 注册一个前端工具

  定义一个渲染 UI 并等待用户响应的前端工具：

  ```tsx title="ui/app/page.tsx"
  import { useHumanInTheLoop } from "@copilotkit/react-core/v2";
  import { z } from "zod";

  function YourMainContent() {
    useHumanInTheLoop({
      agentId: "my-agent",
      name: "confirm_action",
      description: "Ask the user to confirm before performing a critical action",
      parameters: z.object({
        action: z.string().describe("Description of the action to confirm"),
      }),
      render: ({ args, respond }) => {
        if (!respond) return null;
        return (
          <div>
            <p>{args.action}</p>
            <button onClick={() => respond({ confirmed: true })}>
              Approve
            </button>
            <button onClick={() => respond({ confirmed: false })}>
              Reject
            </button>
          </div>
        );
      },
    });

    return <div>{/* Your UI */}</div>;
  }
  ```
</Step>

<Step>
  ### 智能体自动使用该工具

  Mastra 原生支持 AG-UI 协议。当你的智能体调用 `confirm_action` 工具（在前端定义）时，CopilotKit 会自动把该调用路由到你的 `useHumanInTheLoop` 处理器，渲染 UI，并等待用户响应。

  无需后端工具定义——前端注册工具就足够了。
</Step>

<Step>
  ### 试一试

  向智能体提出一个需要确认的请求：

  ```
  Can you delete all inactive user accounts?
  ```

  智能体会调用 `confirm_action` 工具，渲染你的审批 UI，并等待用户响应后再继续。
</Step>
</Steps>

## 对比：中断 vs. 基于工具

| 特性 | 中断（LangGraph） | 基于工具（Mastra） |
|------|------------------|-------------------|
| **后端支持** | ✅ 原生 `interrupt()` | ❌ 无中断事件 |
| **前端 hook** | `useInterrupt` | `useHumanInTheLoop` |
| **执行模型** | 工具在执行中途暂停 | 智能体调用前端工具 |
| **适用场景** | LangGraph 及其他原生支持中断的框架 | Mastra 及其他没有中断原语的框架 |
| **能否与 Mastra 配合？** | ❌ 否 | ✅ 是 |
