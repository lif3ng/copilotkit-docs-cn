## 什么是人机协同（HITL）？

人机协同（human-in-the-loop，简称 HITL）允许智能体在执行过程中请求人工输入或批准，使 AI 系统更加可靠、可信。在构建需要处理复杂决策、或需要人类判断的操作的 AI 应用时，这种模式至关重要。

## 什么时候应该使用它？

人机协同将 AI 的效率与人类判断相结合，打造出既强大又可靠的系统。主要优势包括：

- **质量控制**：在关键决策点上进行人工监督
- **边界情况**：从容处理置信度低的情形
- **专家输入**：在需要时借助人类专家的经验
- **可靠性**：让系统在真实场景中更加健壮

## 怎么使用它？

Mastra 通过渲染 UI 并收集用户输入的前端工具来支持人机协同。
