## 这是什么？

CopilotKit 允许你添加自定义 UI 来获取用户输入，并在完成后把结果传回智能体。这种方式使用 `useHumanInTheLoop` 注册一个前端工具，该工具渲染一个 UI 组件并等待用户响应。

<Callout type="info">
  想找一种工具可以在执行中途暂停并等待用户输入的方式？请参阅[基于中断的方式](/mastra/human-in-the-loop/interrupt-flow)。
</Callout>

## 为什么要使用它？

人机协同是实现可用于生产的复杂工作流的强大方式。让人参与到流程中，你就能确保智能体始终做出正确的决策，并最终被引导到正确的方向上。

## 实现步骤

<Steps>
  <Step>
    ### 运行并连接你的智能体
    <RunAndConnect components={props.components} />
  </Step>

  <Step>
    ### 在前端添加一个人机协同工具
    首先，我们创建一个向用户提供选项并等待其选择的组件。

    ```tsx title="ui/app/page.tsx"
    import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
    import { z } from "zod"

    function YourMainContent() {
      // ...

      useHumanInTheLoop({
        name: "offerOptions",
        description: "Give the user a choice between two options and have them select one.",
        parameters: z.object({
          option_1: z.string().describe("The first option"),
          option_2: z.string().describe("The second option"),
        }),
        render: ({ args, respond }) => {
          if (!respond) return <></>;
          return (
            <div>
              {/* [!code highlight:2] */}
              <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
              <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
            </div>
          );
        },
      });

      // ...
    }
    ```
  </Step>

  <Step>
    ### 配置 Mastra 智能体
    在智能体一侧，我们已经大功告成！Mastra 原生支持 AG-UI 协议，当智能体调用 `offerOptions` 工具时，会自动把控制权交回前端。
  </Step>
  <Step>
    ### 试一试！
    试着向智能体提出一个需要做出选择的问题。

    ```
    Can you show me two good options for a restaurant name?"
    ```

    你会看到智能体给出两个选项，并等待你选择其中之一后才继续。
  </Step>
</Steps>
