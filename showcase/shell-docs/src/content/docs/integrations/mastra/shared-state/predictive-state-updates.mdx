## 这是什么？

智能体的工作记忆通常要等到一次运行结束后才会一次性呈现到 UI。但单次运行可能耗时数秒，并写入大量内容——一份草稿、一个计划、一段总结——而用户更愿意看着这些内容**在生成过程中**逐步出现。

**智能体原生应用**会**尽可能持续地**向最终用户呈现智能体正在做的事情。CopilotKit 通过把工作记忆更新逐 token 流式传输到前端，为 Mastra 实现了这一点，因此 `agent.state` 会在运行期间实时增长，而不是在最后一步直接跳到最终值。

## 什么时候该用它？

当你想就智能体正在产出的内容向用户提供实时反馈时使用它，具体来说：

- **让用户保持投入**，避免漫长的加载指示
- **建立信任**，让用户看到内容被逐步写出的过程
- 支持**智能体转向**——让用户在运行完成之前就做出反应

## 工作原理

只要启用了工作记忆，Mastra 就会注入一个内置的 `updateWorkingMemory` 工具。当智能体在运行中调用它时，CopilotKit 的 Mastra 集成会拦截该工具调用的**流式参数**，解析不断增长的载荷，并按照工作记忆 schema 先发出一个初始 `STATE_SNAPSHOT`，随后发出增量的 `STATE_DELTA` 更新。前端的 `useAgent` 订阅会在每个增量到达时重新渲染。

<Callout type="info" title="重要">
  本指南假设你像下面这样把 Mastra 智能体内嵌在 Copilot Runtime 中。

  ```ts
  const runtime = new CopilotRuntime({
    agents: MastraAgent.getLocalAgents({ mastra, resourceId: "user-1" }),
  });
  ```
</Callout>

## 实现

<Steps>
  <Step>
    ### 运行并连接你的智能体
    <RunAndConnect components={props.components} />
  </Step>
  <Step>
    ### 定义要流式传输的状态
    提供一个工作记忆 schema，其字段存放你想流式传输的内容。这里的 `document` 是一个字符串，智能体会逐步把内容填入其中。

    ```ts title="mastra/agents/streaming-agent.ts"
    import { openai } from "@ai-sdk/openai";
    import { Agent } from "@mastra/core/agent";
    import { LibSQLStore } from "@mastra/libsql";
    import { Memory } from "@mastra/memory";
    import { z } from "zod";

    // 1. Define the streamed state schema
    export const StreamingAgentState = z.object({
      document: z.string().default(""),
    });

    // 2. Create the agent with working memory enabled
    export const streamingAgent = new Agent({
      id: "streaming-agent",
      name: "Streaming Agent",
      model: openai("gpt-4o"),
      // The prompt drives the model to write the full document straight into
      // working memory via the built-in updateWorkingMemory tool, rather than
      // pasting it into a chat message.
      instructions: `You are a collaborative writing assistant. Whenever the user asks you to write, draft, or revise anything, call the \`updateWorkingMemory\` tool with the FULL content under the \`document\` field. Never paste the document into a chat message — it belongs in shared state, and the UI renders it live as you stream it.`,
      memory: new Memory({
        storage: new LibSQLStore({ id: "mastra-storage", url: ":memory:" }),
        options: {
          workingMemory: {
            enabled: true, // [!code highlight]
            schema: StreamingAgentState, // [!code highlight]
          },
        },
      }),
    });
    ```
  </Step>
  <Step>
    ### 观察流式更新
    用 `useAgent` 订阅智能体状态。智能体写入时，`agent.state.document` 会随每个增量更新，因此面板会实时填充。

    ```tsx title="ui/app/page.tsx"
    import { useAgent, UseAgentUpdate } from "@copilotkit/react-core/v2"; // [!code highlight]

    const YourMainContent = () => {
      // [!code highlight:4]
      const { agent } = useAgent({
        agentId: "streamingAgent",
        updates: [UseAgentUpdate.OnStateChanged, UseAgentUpdate.OnRunStatusChanged],
      });

      const document = (agent.state as { document?: string })?.document ?? "";

      return (
        <div>
          <h1>Document {agent.isRunning && <span>· LIVE</span>}</h1>
          <pre>{document || "Ask the agent to write something…"}</pre>
        </div>
      );
    };
    ```
  </Step>
  <Step>
    ### 动手试试吧！
    让智能体写一首诗、起草一封邮件或解释某个主题。文档面板会随智能体的流式输出逐 token 填充，运行结束时的最终工作记忆快照会校正任何偏差。
  </Step>
</Steps>
