这套系统的基础建立在 Mastra 通过 AG-UI 实现的有状态架构之上。Mastra 智能体可以在整个执行过程中维护其内部状态，你可以通过 `useAgent` hook 访问这些状态。

## 什么时候该用它？
当你想促进智能体与用户之间的协作时，状态流式传输再合适不过。Mastra 智能体持久化的任何状态都会自动共享给 UI；同样，用户在 UI 中更新的任何状态也会自动反映回来。

这让智能体与用户始终保持信息一致，带来协调一致的体验。
