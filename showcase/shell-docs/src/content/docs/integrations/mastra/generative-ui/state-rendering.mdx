## 这是什么？

所有 Mastra 智能体都通过工作记忆（working memory）具备状态。也就是说，随着智能体的推进，工作记忆会在整个会话期间得以保留。CopilotKit 允许你在应用中用自定义 UI 组件渲染这种状态，我们称之为 **Agentic Generative UI**（智能体化生成式 UI）。

## 什么时候应该使用它？

当你想向用户提供关于会话整体状态的反馈时，在 UI 中渲染智能体的状态会非常有用。一个典型的例子是用户与智能体协作解决问题的场景：智能体可以把一份草稿存入工作记忆，然后由 UI 渲染出来。

    ### 运行并连接你的智能体

  <Step>
    ### 为智能体配置工作记忆

    创建带工作记忆的 Mastra 智能体。下面是一个追踪搜索的完整示例：

    ```ts title="src/mastra/agents/index.ts"
    import { openai } from "@ai-sdk/openai";
    import { Agent } from "@mastra/core/agent";
    import { LibSQLStore } from "@mastra/libsql";
    import { z } from "zod";
    import { Memory } from "@mastra/memory";
    import { createTool } from "@mastra/core/tools";

    // Define the agent state schema
    const AgentStateSchema = z.object({
      searches: z.array(
        z.object({
          query: z.string(),
          done: z.boolean(),
        })
      ).default([]),
    });

    export type AgentState = z.infer<typeof AgentStateSchema>;

    // Create tools that update working memory
    const addSearch = createTool({
      id: "addSearch",
      inputSchema: z.object({
        query: z.string(),
      }),
      description: "Add a search to the agent's list of searches",
      execute: async ({ query }) => {
        // Tool implementation - working memory is automatically updated
        return { success: true, query };
      },
    });

    export const searchAgent = new Agent({
      id: "search-agent",
      name: "Search Agent",
      model: openai("gpt-5.4"),
      instructions: `
        You are a helpful assistant for storing searches.

        IMPORTANT:
        - Use the addSearch tool to add a search to the agent's state
        - ONLY USE THE addSearch TOOL ONCE FOR A GIVEN QUERY
      `,
      tools: {
        addSearch,
      },
      memory: new Memory({
        storage: new LibSQLStore({ id: "mastra-storage", url: ":memory:" }),
        options: {
          workingMemory: {
            enabled: true,
            schema: AgentStateSchema,
          },
        },
      }),
    });
    ```

  </Step>
  <Step>
    ### 在聊天中渲染智能体状态
    现在我们可以使用带 `render` 函数的 `useAgent`，**在聊天中**渲染智能体的状态。

    ```tsx title="app/page.tsx"
    // ...
    import { useAgent } from "@copilotkit/react-core/v2";
    // ...

    // Define the state of the agent, should match the working memory of your Mastra Agent.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:13]
      // styles omitted for brevity
      useAgent({
        agentId: "searchAgent",
        render: ({ state }) => (
          <div>
            {state.searches?.map((search, index) => (
              <div key={index}>
                {search.done ? "✅" : "❌"} {search.query}{search.done ? "" : "..."}
              </div>
            ))}
          </div>
        ),
      });

      // ...

      return <div>...</div>;
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与你在 Mastra 实例中定义的智能体名称完全一致（例如上文的 `searchAgent`）。
    </Callout>

  </Step>
  <Step>
    ### 在聊天外渲染智能体状态
    你也可以**在聊天之外**渲染智能体的状态。当你想在聊天以外的任何位置渲染智能体状态时，这会很有用。

    ```tsx title="app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]
    // ...

    // Define the state of the agent, should match the working memory of your Mastra Agent.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:3]
      const { agent } = useAgent({
        agentId: "searchAgent",
      })

      // ...

      return (
        <div>
          {/* ... */}
          <div className="flex flex-col gap-2 mt-4">
            {/* [!code highlight:5] */}
            {agent.state?.searches?.map((search, index) => (
              <div key={index} className="flex flex-row">
                {search.done ? "✅" : "❌"} {search.query}
              </div>
            ))}
          </div>
        </div>
      )
    }
    ```

    <Callout type="warn" title="重要">
      `name` 参数必须与你在 Mastra 实例中定义的智能体名称完全一致（例如上文的 `searchAgent`）。
    </Callout>

  </Step>
