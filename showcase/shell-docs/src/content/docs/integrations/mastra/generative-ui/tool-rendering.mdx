## 这是什么？

工具是 LLM 调用预定义（通常为确定性）函数的一种方式。CopilotKit 允许你在 UI 中把这些工具渲染成自定义组件，我们称之为 **Generative UI**（生成式 UI）。

## 什么时候应该使用它？

当你想让用户了解智能体正在做什么——尤其是智能体正在调用工具时——在 UI 中渲染工具会非常有用。CopilotKit 允许你完全自定义这些工具在聊天中的渲染方式。

<Step>
### 给智能体一个可调用的工具

添加一个新的工具定义：

```ts title="src/mastra/tools/weatherInfo.ts"
import { createTool } from "@mastra/core/tools";
import { z } from "zod";

export const weatherInfo = createTool({
  id: "weatherInfo",
  inputSchema: z.object({
    location: z.string(),
  }),
  description: `Fetches the current weather information for a given location`,
  execute: async ({ location }) => {
    // Tool logic here (e.g., API call)
    console.log("Using tool to fetch weather information for", location);
    return { temperature: 20, conditions: "Sunny" }; // Example return
  },
});
```

然后，将该工具传给智能体：

```ts title="src/mastra/agents/weatherAgent.ts"
import { Agent } from "@mastra/core/agent";
import { openai } from "@ai-sdk/openai";
import { weatherInfo } from "../tools/weatherInfo";

export const weatherAgent = new Agent({
  id: "weather-agent",
  name: "Weather Agent",
  instructions:
    "You are a helpful assistant that provides current weather information. When asked about the weather, use the weather information tool to fetch the data.",
  model: openai("gpt-5.4-mini"),
  tools: {
    weatherInfo,
  },
});
```

</Step>
<Step>
### 在前端渲染工具调用
此时，你的智能体已经能够调用 `weatherInfo` 工具。接下来只需添加一个 `useRenderTool` hook，即可在 UI 中渲染这次工具调用。

<Callout type="info" title="重要">
  要在 UI 中渲染一次工具调用，action 的名称必须与工具的名称一致。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:12]
  useRenderTool({
    name: "weatherInfo",
    render: ({ status, args }) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "Calling weather API..."}
          {status === "complete" &&
            `Called the weather API for ${args.location}.`}
        </p>
      );
    },
  });
  // ...
};
```

</Step>
<Step>
### 试一试！

试着让智能体查询某个地点的天气。你应该能看到我们添加的自定义 UI 组件渲染出这次工具调用，并显示传给该工具的参数。
