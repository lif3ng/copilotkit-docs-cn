动态模式（dynamic schema）A2UI 让智能体直接从对话中绘制出界面。前端通过目录（catalog）提供可用的组件及其 props；智能体则为每次请求生成组件树与数据。

## 前端目录

在演示源码中定义你的组件、渲染器与目录。无论 Mastra 是与 CopilotKit 路由同进程运行，还是在独立进程中运行，都可以使用同一份目录。

## 同进程中的 Mastra

在线演示使用了一条专用的 CopilotKit runtime 路由和一个本地 Mastra 智能体。该智能体已自带 `generate_a2ui` 工具，因此路由设置 `injectA2UITool: false` 以避免重复注册该工具。路由还将 `defaultCatalogId` 固定为页面注册的那份目录。

当 Mastra 实例被导入到与 runtime 路由相同的进程中时，请使用这种布局。本地智能体桥接请参阅 [Copilot Runtime 指南](/mastra/copilot-runtime)。

## 独立进程中的 Mastra

当 Mastra 作为独立服务运行时，请**在该服务上**注册一个 CopilotKit 端点。这样可将 Mastra 智能体保留在注入并执行 `generate_a2ui` 的那个端点本地，而浏览器则通过 HTTP 访问它。下面的示例是位于 `showcase/integrations/mastra/tests/fixtures/remote-a2ui/mastra/index.ts` 的可运行 Mastra fixture：

请使用 `@ag-ui/mastra` 1.1.4 或更高版本，并搭配兼容的 `@ag-ui/core` 与 `@ag-ui/client` 版本。Showcase fixture 使用的是 1.1.4 和 0.0.58。

```ts title="src/mastra/index.ts"
import { Mastra } from "@mastra/core/mastra";
import { Agent } from "@mastra/core/agent";
import { getLocalAgent } from "@ag-ui/mastra";
import { registerCopilotKit } from "@ag-ui/mastra/copilotkit";

const dashboardAgent = new Agent({
  id: "declarative-gen-ui",
  name: "Dashboard",
  model: yourModel,
  instructions: "Call generate_a2ui for dashboard requests.",
});

export const mastra = new Mastra({
  agents: { dashboardAgent },
  server: {
    apiRoutes: [
      registerCopilotKit({
        path: "/copilotkit",
        resourceId: "demo-user",
        agents: () => {
          const agent = getLocalAgent({
            mastra,
            agentId: "dashboardAgent",
            resourceId: "demo-user",
          });
          if (!agent) throw new Error("dashboardAgent is not registered");
          return { "declarative-gen-ui": agent, default: agent };
        },
        a2ui: {
          injectA2UITool: true,
          defaultCatalogId: "declarative-gen-ui-catalog",
        },
        cors: { origin: "http://localhost:3000" },
      }),
    ],
  },
});
```

将 provider 的 `runtimeUrl` 设置为你的 Mastra 服务的 `/copilotkit` URL（或在前端代理该路径）。保持 provider 的智能体名 `declarative-gen-ui` 与目录 ID `declarative-gen-ui-catalog` 同路由侧保持一致。当从浏览器直接调用该服务时，请在 `cors.origin` 中使用前端来源。在生产环境中，应从经过身份验证的调用方推导 `resourceId`，而不要沿用示例中的固定值。

[runtime 指南](/mastra/copilot-runtime)中介绍的通用 `MastraAgent.getRemoteAgents()` 桥接服务于普通的远程智能体运行。对于这种 A2UI 配置，请使用注册的端点，让 A2UI 工具在 Mastra 智能体旁边运行。仅仅完成一次 `render_a2ui` 工具调用并不能证明界面已渲染：请检查响应中是否包含针对组件与数据的非空 `a2ui_operations`，并确认仪表盘确实出现在浏览器中，而不是停留在“Building Interface”状态。

## 何时使用动态模式

当用户可能请求不同的布局和数据时，请使用这种方式。如果结构已提前确定，请使用[固定模式](./fixed-schema)。
