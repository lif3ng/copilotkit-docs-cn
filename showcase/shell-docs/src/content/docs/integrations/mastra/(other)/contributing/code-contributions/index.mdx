感谢你有意为 CopilotKit 做出贡献。我们欢迎新贡献者的加入，也感谢你帮助 CopilotKit 变得更好。

本指南将帮助你尽可能顺利地上手。

## 第 1 步：安装前置条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- 全局安装 [pnpm](https://pnpm.io/) v10.x（`npm i -g pnpm@^10`）

## 第 2 步：仓库设置

<Steps>
  <Step>
  ### Fork 仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit)并创建一个 Fork。

  然后，将你的 Fork 克隆到本地：
  ```bash
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit/CopilotKit
  ```
  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是一个使用 [pnpm](https://pnpm.io/) workspace 的 monorepo，跨软件包的任务由 [Nx](https://nx.dev/) 编排。
  </Callout>

  使用 pnpm 安装依赖：
  ```bash
  pnpm install
  ```
  </Step>
  <Step>
  ### 构建软件包
  为确保一切正常，先把所有软件包构建一遍：
  ```bash
  pnpm run build
  ```
  </Step>
</Steps>

## 第 3 步：开发模式

一切就绪且运行符合预期后，就可以开始开发了：

```bash
# 以开发模式启动所有软件包
pnpm run dev

# 以开发模式启动某个特定软件包
pnpm exec nx watch --projects=packages/package-name -- pnpm run build
```

现在可以开始修改代码了。

<Callout type="info">
所有 `@copilotkit/*` 软件包都位于 monorepo 的 `packages` 文件夹下。
</Callout>

## 第 4 步：实时测试变更

在大多数情况下，你希望在开发过程中就能无缝地实时测试自己的变更。

monorepo 中有一个 `examples` 文件夹，里面包含若干使用 CopilotKit 的示例。这些示例与 monorepo 中的 `@copilotkit/*` 软件包相互链接，你可以运行它们来测试自己的变更。

在本教程中，我们将使用 `next-openai` 示例，具体来说是 Presentation Demo（`/presentation`）。

在另一个终端中运行以下命令来启动该示例：

```bash
cd examples/v1/next-openai
export OPENAI_API_KEY=<your-openai-api-key>
pnpm run example-dev
```

<Callout type="info">
我们使用 `pnpm run example-dev` 命令来运行示例，这与开发各个软件包时使用的 `pnpm run dev` 命令不同。
</Callout>

现在访问 http://localhost:3000/presentation，你应该能看到示例正在运行。对 CopilotKit 软件包的任何改动都会立即反映在这里。

## 第 5 步：格式化与代码检查

提交变更之前，请在 monorepo 根目录运行以下命令，确保文件格式正确：
```bash
pnpm run format
```

此外，请确保没有代码检查（lint）错误：
```bash
pnpm run lint
```

## 第 6 步：提交 Pull Request

完成变更后，将其 commit 并推送。然后前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls)创建一个 pull request 即可。干得漂亮！

## 启动支持热重载的开发环境

CopilotKit 提供了一个现成的脚本，可基于某个 CoAgent 示例启动开发环境。它让你能够修改核心 TypeScript 和 Python 代码中的 CopilotKit 内部实现，同时在所选示例中看到这些变更生效。

前置条件：请确保已安装 GNU parallel 和 langgraph CLI。

接下来，进入 `CopilotKit/` 目录，针对你想开发的示例运行 `example.sh` 脚本：

```bash
./scripts/develop/example.sh coagents-starter
```

这将启动一个支持热重载的开发环境。

你也可以选择在 LangGraph platform 上运行同一个示例：

```bash
./scripts/develop/example.sh coagents-starter langgraph-platform
```

## 调试

每次在 localhost 上运行 CopilotKit 时，你都可以在聊天窗口中看到 **CopilotKit Dev Console**。Dev Console 提供了实用的调试功能，帮助你调试 copilot（例如查看 copilot 感知到的状态、它可以执行哪些操作等）。

  />
</Frame>

如果想在本地禁用 Dev Console，只需在 `<CopilotKit />` provider 中将 `showDevConsole` 设置为 `false`。

## （进阶）软件包链接

有时你想在自己的项目中测试对 CopilotKit 所做的修改。例如，你尝试将 CopilotKit 集成到自己的代码库时遇到了一个 bug，想要修复它。

方便的是，你可以将本地的 CopilotKit 软件包链接到自己的项目中来测试这些修改。

具体做法请参阅[进阶：软件包链接](/contributing/code-contributions/package-linking)指南。
