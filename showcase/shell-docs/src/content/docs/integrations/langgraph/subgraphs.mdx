## 什么是子图？

子图就是被当作另一个图中的节点来使用的图。
可以把它理解为 LangGraph 的封装：每个子图都是一个自包含的单元，可以组合起来构建更大、更复杂的系统。

## 何时应该使用它？

当你需要把一个图拆分成更小、可复用的片段时，子图会很有用。
它们让你能够构建多智能体系统、在多个图之间复用节点集合，并让不同团队独立开发图的各个部分。

## CopilotKit 如何支持这一特性？

CopilotKit 支持直接从子图进行流式传输，因此嵌套的图可以像单个图一样实时发出事件。

使用该特性在智能体一侧不需要任何额外步骤。
你只需在前端订阅智能体状态即可：

<FrontendOnly frontend="react">
```tsx
const { agent } = useAgent({
  agentId: "sample_agent",
});

// Access agent state as usual - subgraph streaming is handled automatically
const state = agent.state;
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```typescript
import { injectAgentStore } from "@copilotkit/angular";

export class AgentStatusComponent {
  readonly store = injectAgentStore("sample_agent");

  // Read this.store().state() in the template or another computed signal.
  // Subgraph streaming updates it automatically.
}
```
</FrontendOnly>

子图节点会照常流式传输，你也可以直接在子图中使用 `interrupt()`。
