CopilotKit 提供三个可直接连接你的 LangGraph 智能体的预构建聊天组件。每个都是 `CopilotChat` 的包装器，只是布局不同——选一个适合你应用的即可。

<Callout type="info">
  如果你已完成[快速开始](/langgraph/quickstart)，那么其中之一你已经配置好了。

### CopilotChat

一个灵活的聊天组件，可以放置在应用的任意位置，并按需调整尺寸。

```tsx title="page.tsx"
// [!code word:CopilotChat]

export function YourComponent() {
  return (
    <CopilotChat
      labels={{
        modalHeaderTitle: "Your Assistant",
        welcomeMessageText: "Hi! How can I assist you today?",
      }}
    />
  );
}
```

### CopilotSidebar

包裹你的主要内容，并提供一个可折叠的侧边栏聊天。

```tsx title="page.tsx"
// [!code word:CopilotSidebar]

export function YourApp() {
  return (
    <CopilotSidebar
      defaultOpen={true}
      labels={{
        modalHeaderTitle: "Sidebar Assistant",
        welcomeMessageText: "How can I help you today?",
      }}
    >
      <YourMainContent />
    </CopilotSidebar>
  );
}
```

### CopilotPopup

一个悬浮的聊天气泡，位于你的内容旁边，可切换展开/收起。

```tsx title="page.tsx"
// [!code word:CopilotPopup]

export function YourApp() {
  return (
    <>
      <YourMainContent />
      <CopilotPopup
        labels={{
          modalHeaderTitle: "Popup Assistant",
          welcomeMessageText: "Need any help?",
        }}
      />
    </>
  );
}
```

## 自定义

这三个组件都支持[插槽系统（slot system）](/langgraph/custom-look-and-feel/slots)以进行深度自定义——从 Tailwind 类到完整替换组件：

```tsx title="page.tsx"
<CopilotChat
  // Style slots with Tailwind classes
  input={{
    textArea: "text-lg",
    sendButton: "bg-blue-600 hover:bg-blue-700",
  }}
  // Customize nested message slots
  messageView={{
    assistantMessage: {
      className: "bg-gray-50 rounded-xl p-4",
      toolbar: "border-t mt-2",
    },
    userMessage: "bg-blue-100 rounded-xl",
  }}
  // Hide elements by returning null
  scrollView={{
    feather: () => null,
  }}
/>
```
