上面的视频展示了 [Tako](https://tako.com) 如何驱动智能体原生的 Research Canvas——依托其覆盖金融、体育、政治等领域的可信实时数据索引，生成交互式可视化图表。

想深入了解，可以查阅 Tako 的[文档](https://docs.tako.com/documentation/integrations-and-examples/langgraph-copilotkit)，以及他们用 CopilotKit、LangGraph、Tako 和 Tavily 构建的开源 [Research Canvas 示例](https://github.com/TakoData/tako-copilotkit)。

<YouTubeVideo videoId="0b6BVqPwqA0" defaultPlaybackRate={1.25} />

这段录像使用的是 CopilotKit v1 API，演示了如何用 LangGraph 构建智能体化的 Research Canvas。关于当前的实现，你可以[运行 CopilotKit v2 应用](https://examples-coagents-research-canvas-ui.vercel.app/)，或浏览[当前的 CopilotKit v2 源代码](https://github.com/CopilotKit/CopilotKit/blob/main/examples/v1/research-canvas/readme.md)。升级旧应用时，请使用 [v1 到 v2 迁移指南](/migrate/v2)。
