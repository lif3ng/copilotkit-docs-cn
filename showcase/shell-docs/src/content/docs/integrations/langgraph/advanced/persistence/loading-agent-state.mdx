### 设置 threadId

在 CopilotKit 中设置 `threadId` 属性时，即：

<Callout>使用 LangGraph Platform 时，`threadId` 必须是 UUID。</Callout>

```tsx
<CopilotKit threadId="2140b272-7180-410d-9526-f66210918b13">
  <YourApp />
</CopilotKit>
```

CopilotKit 会从数据库恢复该线程的完整状态，包括消息。（详见[消息持久化](/langgraph/advanced/persistence/message-persistence)。）

### 加载智能体状态

这意味着任何智能体的状态也会被恢复。例如：

```tsx
const { agent } = useAgent({ agentId: "research_agent" });

// agent.state will now be the state of research_agent in the thread id given above
```
