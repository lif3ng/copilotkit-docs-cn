## 这是什么？

CopilotKit 的 Python SDK 提供 **emit 函数**，你的 LangGraph 节点可以调用它们来推送工具调用并控制流式传输行为。在前端，React v2 提供 **Hooks**，用于为这些被发出的事件注册处理器和渲染器。

本页精确展示两侧如何连接，让你无需猜测即可构建可预测的端到端集成。

## 映射一览

| 后端（Python SDK） | 前端（React v2） | 作用 |
|---|---|---|
| `copilotkit_emit_tool_call(config, name, args)` | `useFrontendTool` | 智能体手动触发一次工具调用；已注册的处理器在浏览器中运行 |
| LLM 以常规方式调用前端工具（通过 `bind_tools`） | `useFrontendTool` | 智能体让 LLM 决定何时调用工具；相同的处理器，相同的结果 |
| LLM 调用前端工具（通过 `bind_tools`） | `useComponent` | 智能体调用工具，已注册的组件在聊天中内联渲染 |
| `copilotkit_customize_config(config, emit_tool_calls=["ToolName"])` | `useFrontendTool` / `useComponent` | 控制哪些工具调用被流式传输到前端；用它过滤噪音 |
| `copilotkit_customize_config(config, emit_tool_calls=False)` | — | 抑制该次 LLM 调用的所有工具调用流式传输 |

### 持久化与发送的工具调用

<Callout type="info" title="关键概念：持久化与瞬时">
- **持久化工具调用**是存储在 `state["messages"]` 中的、由 LLM 生成的工具调用消息。它们会出现在聊天历史中，并在页面刷新后重放。
- **发送的工具调用**（`copilotkit_emit_tool_call`）是瞬时事件，会立即触发前端处理器。它们 **不会** 存入聊天历史，除非你显式向状态添加一条消息。

`useComponent` 和 `useFrontendTool` 都会响应由 LLM 触发的持久化工具调用。`copilotkit_emit_tool_call` 让你以命令式方式触发同样的前端机制，而无需等待 LLM。
</Callout>

## 端到端示例：`copilotkit_emit_tool_call` → `useFrontendTool`

此模式让 LangGraph 节点 **直接调用** 某个前端函数——例如更新 React 状态、显示 toast 或触发浏览器 API——而无需由 LLM 决定何时调用它。

### 步骤 1：注册前端工具

```tsx title="app/page.tsx"
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/react-core/v2"; // [!code highlight]

export function Page() {
  const [status, setStatus] = React.useState("");

  // [!code highlight:10]
  useFrontendTool({
    name: "updateStatus",
    description: "Update the status displayed in the UI.",
    parameters: z.object({
      message: z.string().describe("The status message to display"),
    }),
    handler: async ({ message }) => {
      setStatus(message);
      return `Status updated to: ${message}`;
    },
  });

  return <div>Agent says: {status}</div>;
}
```

### 步骤 2：从 LangGraph 节点发送工具调用

```python title="agent.py"
from langchain_core.runnables import RunnableConfig
from copilotkit import CopilotKitState
from copilotkit.langgraph import copilotkit_emit_tool_call # [!code highlight]

class AgentState(CopilotKitState):
    pass

async def my_node(state: AgentState, config: RunnableConfig):
    # Imperatively fires the frontend tool handler without the LLM
    await copilotkit_emit_tool_call( # [!code highlight]
        config,                      # [!code highlight]
        name="updateStatus",         # [!code highlight]
        args={"message": "Processing your request..."}, # [!code highlight]
    )                                # [!code highlight]

    # ... do other work ...

    await copilotkit_emit_tool_call(
        config,
        name="updateStatus",
        args={"message": "Done!"},
    )

    return state
```

当 `copilotkit_emit_tool_call` 被调用时：
1. CopilotKit 通过 SSE 将工具调用事件发送到前端。
2. 匹配 `"updateStatus"` 的 `useFrontendTool` 处理器立即在浏览器中运行。
3. 处理器的返回值会作为工具结果发送回智能体。
4. 该调用 **不会** 保存到 `state["messages"]`，除非你自己添加。

## 端到端示例：LLM 工具调用 → `useComponent`

此模式让 LLM 决定何时在聊天中渲染一个自定义 React 组件，并将其参数作为 props 传入。

### 步骤 1：注册组件

```tsx title="app/page.tsx"
import { useComponent } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";

function WeatherCard({ city, temperature, condition }: {
  city: string;
  temperature: number;
  condition: string;
}) {
  return (
    <div className="rounded-lg border p-4">
      <h3 className="font-semibold">{city}</h3>
      <p className="text-2xl">{temperature}°F</p>
      <p className="text-sm text-gray-500">{condition}</p>
    </div>
  );
}

export function Page() {
  // [!code highlight:10]
  useComponent({
    name: "showWeather",
    description: "Display a weather card for a city.",
    parameters: z.object({
      city: z.string(),
      temperature: z.number(),
      condition: z.string(),
    }),
    render: WeatherCard,
  });

  return <div>{/* your app */}</div>;
}
```

### 步骤 2：通过 `bind_tools` 将其暴露给 LLM

```python title="agent.py"
from langchain_openai import ChatOpenAI
from langchain_core.runnables import RunnableConfig
from copilotkit import CopilotKitState

class AgentState(CopilotKitState):
    pass

async def chat_node(state: AgentState, config: RunnableConfig):
    model = ChatOpenAI(model="gpt-4o").bind_tools(
        state["copilotkit"]["actions"]  # includes all registered frontend tools/components # [!code highlight]
    )
    response = await model.ainvoke(state["messages"], config)
    return {"messages": response}
```

当 LLM 调用 `showWeather` 时：
1. 工具调用作为消息存储在 `state["messages"]` 中（持久化）。
2. CopilotKit 将该工具调用流式传输到前端。
3. `useComponent` 以工具参数为 props 在聊天中内联渲染 `WeatherCard`。
4. 由于消息已持久化，重放/刷新后组件仍在聊天中可见。

## 使用 `copilotkit_customize_config` 控制哪些工具调用被流式传输

默认情况下，CopilotKit 会将所有 LLM 工具调用流式传输到前端。使用 `copilotkit_customize_config` 来过滤它们。

```python title="agent.py"
from copilotkit.langgraph import copilotkit_customize_config # [!code highlight]

async def chat_node(state: AgentState, config: RunnableConfig):
    # Only stream "showWeather" to the frontend; suppress all others
    streaming_config = copilotkit_customize_config( # [!code highlight]
        config,                                      # [!code highlight]
        emit_tool_calls=["showWeather"],             # [!code highlight]
    )                                                # [!code highlight]

    model = ChatOpenAI(model="gpt-4o").bind_tools(
        state["copilotkit"]["actions"]
    )
    response = await model.ainvoke(state["messages"], streaming_config) # [!code highlight]
    return {"messages": response}
```

<Callout type="warn" title="使用新变量">
始终将结果赋给一个 **新变量**（例如 `streaming_config`），而不是覆盖 `config`。在 LangGraph Python 中，`config` 会被隐式传给作用域内的所有 LangChain LLM 调用——覆盖它会意外改变每个后续调用的行为。
</Callout>

### `emit_tool_calls` 选项一览

| 取值 | 效果 |
|---|---|
| `True`（默认） | 将所有工具调用流式传输到前端 |
| `False` | 抑制本次 LLM 调用的所有工具调用流式传输 |
| `"ToolName"` | 只流式传输指定名称的工具调用 |
| `["Tool1", "Tool2"]` | 只流式传输列出的工具调用 |

## 选择合适的模式

| 目标 | 推荐模式 |
|---|---|
| 智能体以命令式触发浏览器动作（toast、状态更新） | `copilotkit_emit_tool_call` → `useFrontendTool` |
| LLM 决定何时触发浏览器动作 | `bind_tools(state["copilotkit"]["actions"])` → `useFrontendTool` |
| LLM 在聊天中渲染富组件（持久化在历史中） | `bind_tools(state["copilotkit"]["actions"])` → `useComponent` |
| 对前端隐藏某些 LLM 工具调用 | `copilotkit_customize_config(emit_tool_calls=[...])` |
| 敏感 LLM 调用对前端隐藏所有工具调用 | `copilotkit_customize_config(emit_tool_calls=False)` |
