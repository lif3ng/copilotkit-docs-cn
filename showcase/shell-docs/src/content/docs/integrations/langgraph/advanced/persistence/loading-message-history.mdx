LangGraph 支持线程（threads），这是一种把消息归组在一起、最终维护连续聊天历史的方式。CopilotKit
提供了几种与此概念交互的方式。

本指南假设你已经完成过[快速开始](/langgraph/quickstart)指南。

## 加载已有线程

要在 CopilotKit 中加载一个已有线程，只需像下面这样在 `<CopilotKit>` 上设置 `threadId` 属性。

<Callout>使用 LangGraph Platform 时，`threadId` 必须是 UUID。</Callout>

```tsx
{
  /* [!code highlight:1] */
}
<CopilotKit threadId="37aa68d0-d15b-45ae-afc1-0ba6c3e11353">
  <YourApp />
</CopilotKit>;
```

## 动态切换线程

你还可以让 `threadId` 变为动态。一旦设置，CopilotKit 就会加载该线程此前的消息。

```tsx

const Page = () => {
  const [threadId, setThreadId] = useState("af2fa5a4-36bd-4e02-9b55-2580ab584f89"); // [!code highlight]
  return (
    {/* [!code highlight:3] */}
    <CopilotKit threadId={threadId}>
      <YourApp setThreadId={setThreadId} />
    </CopilotKit>
  )
}

const YourApp = ({ setThreadId }) => {
  return (
    {/* [!code highlight:1] */}
    <Button onClick={() => setThreadId("679e8da5-ee9b-41b1-941b-80e0cc73a008")}>
      Change Thread
    </Button>
  )
}
```
