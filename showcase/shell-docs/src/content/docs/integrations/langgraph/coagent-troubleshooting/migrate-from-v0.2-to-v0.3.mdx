## v0.3 有哪些新变化？

从 `v0.3` 开始，我们改变了智能体（LangGraph）与 CopilotKit 之间同步消息的方式。本质上，现在双方将共享完全相同的消息历史。

这意味着你需要从 LangGraph 节点中返回希望出现在 CopilotKit 聊天中的消息，例如：

```python
from langchain_core.runnables import RunnableConfig

def my_node(state: State, config: RunnableConfig) -> State:
    response = # ... llm call ...
    return {
        "messages": response,
    }
```

现在所有工具消息默认都会发出，因此你无需再手动调用 `copilotkit_customize_config` 来配置工具调用的发出。

## 如何迁移？

1. 确保从 LangGraph 节点中返回你希望纳入消息历史的所有消息（工具调用或文本消息）。

2. 可选：如果你本来是为了发出工具调用而手动调用 `copilotkit_customize_config`，现在可以移除这些调用。

3. 如果你想在聊天中隐藏某些工具调用或消息，请使用 `copilotkit_customize_config` 并将 `emit_tool_calls` 或 `emit_messages` 设为 `False`。同时确保不要在节点中返回这些消息，以免它们进入消息历史。
