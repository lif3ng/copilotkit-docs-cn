## 概览

`useCopilotKit` 是一个底层 React Hook，返回 CopilotKit 上下文的值，提供对核心实例与提供方级别状态的直接访问。它会订阅运行时连接状态的变化，并在连接状态更新时触发重新渲染。

<Callout type="info">
  `useCopilotKit` 是一个底层 Hook。大多数应用应改用 `useAgent` 或 `useFrontendTool` 等更高层级的 Hook。
</Callout>

在 `CopilotKit`（或 `<CopilotKit>` 包装器组件）之外使用时**会抛出错误**。

## 签名

```tsx
import { useCopilotKit } from "@copilotkit/react-core/v2";

function useCopilotKit(): CopilotKitContextValue;
```

## 参数

该 Hook 不接收任何参数。

## 返回值

<PropertyReference name="context" type="CopilotKitContextValue">
  包含核心实例与提供方级别状态的上下文对象。

  <PropertyReference name="copilotkit" type="CopilotKitCoreReact">
    活动的 CopilotKit 核心实例。它是管理智能体、工具、建议与运行时通信的中央协调器，提供以下方法：
    - 智能体管理（`agents`、`getAgent`）
    - 工具注册与执行
    - 建议的配置与获取
    - 运行时连接管理
    - 通过 `subscribe()` 订阅事件

    核心实例在每个 `CopilotKit` 中只创建一次，并在重新渲染之间保持稳定。

  </PropertyReference>

  <PropertyReference name="executingToolCallIds" type="ReadonlySet<string>">
    当前正在执行的工具调用 ID 集合。它在提供方级别进行跟踪，以确保即使子组件尚未挂载，工具执行事件也能被捕获。这对于人机协同（human-in-the-loop）重连等场景非常重要——组件树挂载时可能已经存在待处理的工具调用。
  </PropertyReference>
</PropertyReference>

## 用法

### 访问核心实例

```tsx
function DebugPanel() {
  const { copilotkit } = useCopilotKit();

  const agents = Object.keys(copilotkit.agents ?? {});

  return (
    <div>
      <h3>Registered Agents</h3>
      <ul>
        {agents.map((id) => (
          <li key={id}>{id}</li>
        ))}
      </ul>
    </div>
  );
}
```

### 订阅核心事件

```tsx
function ConnectionMonitor() {
  const { copilotkit } = useCopilotKit();

  useEffect(() => {
    const subscription = copilotkit.subscribe({
      onRuntimeConnectionStatusChanged: () => {
        console.log("Runtime connection status changed");
      },
    });

    return () => {
      subscription.unsubscribe();
    };
  }, [copilotkit]);

  return null;
}
```

### 以编程方式运行工具

`copilotkit.runTool()` 让你可以直接从代码中执行已注册的前端工具——无需 LLM 回合。工具的处理器会运行，渲染组件会出现在 UI 中，工具调用及其结果都会被添加到智能体的消息历史中。

```tsx
function ExportButton() {
  const { copilotkit } = useCopilotKit();

  // Register the tool
  useFrontendTool({
    name: "exportData",
    description: "Export data as CSV",
    parameters: [{ name: "format", type: "string" }],
    handler: async ({ format }) => {
      const csv = await generateCsv(format);
      downloadFile(csv);
      return `Exported as ${format}`;
    },
  });

  // Trigger it from a button — no LLM needed
  const handleExport = async () => {
    const { result, error } = await copilotkit.runTool({
      name: "exportData",
      parameters: { format: "csv" },
    });
    if (error) console.error(error);
  };

  return <button onClick={handleExport}>Export CSV</button>;
}
```

#### `runTool` 参数

<PropertyReference name="params" type="CopilotKitCoreRunToolParams">
  <PropertyReference name="name" type="string" required>
    要执行的已注册前端工具的名称。
  </PropertyReference>

<PropertyReference name="agentId" type="string">
  用于工具与消息作用域划分的智能体 ID。默认为 `"default"`。
</PropertyReference>

<PropertyReference
  name="parameters"
  type="Record<string, unknown>"
  default="{}"
>
  传递给工具处理器的参数。
</PropertyReference>

  <PropertyReference name="followUp" type="string | false" default="false">
    控制执行完成后是否触发 LLM 后续处理：
    - `false` —— 执行工具后停止（默认）
    - `"generate"` —— 触发一次智能体运行，让 LLM 对工具结果做出响应
    - 其他任意字符串 —— 以该文本添加一条用户消息，然后触发一次智能体运行
  </PropertyReference>
</PropertyReference>

#### `runTool` 返回值

<PropertyReference name="result" type="CopilotKitCoreRunToolResult">
  <PropertyReference name="toolCallId" type="string">
    工具调用的唯一 ID，与添加到历史记录中的消息相对应。
  </PropertyReference>

<PropertyReference name="result" type="string">
  工具处理器返回值的字符串化结果（纯渲染工具为空字符串）。
</PropertyReference>

  <PropertyReference name="error" type="string | undefined">
    处理器抛出错误时的错误消息。工具结果消息中将包含 `"Error: ..."`。
  </PropertyReference>
</PropertyReference>

### 检查工具执行状态

```tsx
function ToolExecutionIndicator() {
  const { executingToolCallIds } = useCopilotKit();

  if (executingToolCallIds.size === 0) {
    return null;
  }

  return <div>Executing {executingToolCallIds.size} tool call(s)...</div>;
}
```

## 行为

- **缺少提供方时抛错**：在 `CopilotKit` 或 `<CopilotKit>` 包装器组件之外使用该 Hook 会抛出错误。
- **运行时状态订阅**：该 Hook 会订阅 `onRuntimeConnectionStatusChanged` 事件，因此当运行时连接完成或失败时，组件会重新渲染。
- **稳定的核心引用**：`copilotkit` 实例在每个提供方中只创建一次，并在重新渲染之间保持稳定。只有 `executingToolCallIds` 集合会随着工具调用的开始与结束而变化。
- **提供方级别的工具跟踪**：`executingToolCallIds` 在提供方级别而非单个组件中进行跟踪。这确保了在子组件挂载之前触发的工具执行开始事件不会丢失。
