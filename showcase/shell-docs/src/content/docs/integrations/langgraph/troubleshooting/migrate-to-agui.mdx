AG-UI 是 CopilotKit 采用的新一代智能体到 UI 协议。
它已经与 LangGraph 智能体集成。

本指南将展示如何完成这次过渡。

        ### 将当前的 `CopilotRuntime` 实例化代码从
        ```typescript

        let runtime = new CopilotRuntime({
            remoteEndpoints: [
                langGraphPlatformEndpoint({
                    deploymentUrl: "https://your-deployment-url",
                    langsmithApiKey: '<langsmith API key>', // optional
                    agents: [], // Your previous agents definition
                })
            ],
        })
        ```
        改为
        ```typescript

        let runtime = new CopilotRuntime({
            agents: {
                'sample_agent': new LangGraphAgent({
                    deploymentUrl: "https://your-deployment-url",
                    langsmithApiKey: '<langsmith API key>', // optional
                    graphId: 'sample_agent', // Identical to what is defined in the `langgraph.json` graphs config.
                }),
            }
        })
        ```
        就这么简单，一切就绪！
    </TailoredContentOption>
    <TailoredContentOption
        id="fastapi"
        title="自托管（FastAPI）"
        description="我自行托管我的智能体，并通过 FastAPI 提供服务。"
    >

假设你的 Python 智能体配置如下：

```python
from fastapi import FastAPI
from copilotkit.integrations.fastapi import add_fastapi_endpoint
from copilotkit import CopilotKitRemoteEndpoint, LangGraphAgent
from .agent import graph

app = FastAPI()
sdk = CopilotKitRemoteEndpoint(
    agents=[
        LangGraphAgent(
            name="sample_agent",
            description="my agent",
            graph=graph,
        ),
    ],
)

add_fastapi_endpoint(app, sdk, "/copilotkit")
```

要完成迁移，只需导入并使用新的端点初始化器与智能体类。
其余部分（主要是你的图）保持不变。

<Steps>
    <Step>
        ### 第一步，把你的 FastAPI 端点迁移为使用新的智能体类
        ```python
        from fastapi import FastAPI
        from copilotkit import LangGraphAGUIAgent
        from ag_ui_langgraph import add_langgraph_fastapi_endpoint
        from .agent import graph

        app = FastAPI()
        add_langgraph_fastapi_endpoint(
            app=app,
            agent=LangGraphAGUIAgent(
                name="sample_agent",
                description="my agent",
                graph=graph,
            ),
            path="/agent/sample_agent" # Agent will be served at this path. Use "/" to mount at root.
        )
        ```
    </Step>
    <Step>
        ### 然后，在你的 `CopilotRuntime` 实例化中，让一个 `HttpAgent` 指向该端点
        ```typescript
        import { HttpAgent } from "@ag-ui/client";

        let runtime = new CopilotRuntime({
            agents: {
                'sample_agent': new HttpAgent({
                    url: "http://localhost:8000/agent/sample_agent",
                }),
            }
        })
        ```
    </Step>

</Steps>
