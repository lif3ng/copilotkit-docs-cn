## 这是什么？

`useComponent` 允许你将一个 React 组件注册为智能体可以调用的工具。当智能体调用该工具时，CopilotKit 会以工具参数作为 props，把你的组件直接渲染在聊天中。

这是生成式 UI 最简单的形式——由智能体决定何时显示组件，CopilotKit 负责渲染。无需处理器逻辑，也无需用户交互。

## 什么时候应该使用它？

当你想要以下效果时，可以使用 `useComponent`：
- 在聊天中内联展示富 UI（卡片、图表、表格）
- 展示来自智能体响应的结构化数据
- 渲染预览、状态指示器或可视化反馈
- 让智能体呈现纯文本以外的信息

对于需要用户交互的组件，请参阅[交互式](/langgraph/generative-ui/your-components/interactive)或[基于中断](/langgraph/generative-ui/your-components/interrupt-based)。

    ### 注册组件

    使用 `useComponent` hook 注册一个 React 组件。智能体将能够按名称调用它，CopilotKit 会以工具参数作为 props 渲染该组件。

    ```tsx title="app/page.tsx"
    import { useComponent } from "@copilotkit/react-core/v2"; // [!code highlight]
    import { z } from "zod";

    const weatherSchema = z.object({
      city: z.string().describe("City name"),
      temperature: z.number().describe("Temperature in Fahrenheit"),
      condition: z.string().describe("Weather condition"),
    });

    function WeatherCard({ city, temperature, condition }: z.infer<typeof weatherSchema>) {
      return (
        <div className="rounded-lg border p-4">
          <h3 className="font-semibold">{city}</h3>
          <p className="text-2xl">{temperature}°F</p>
          <p className="text-sm text-gray-500">{condition}</p>
        </div>
      );
    }

    function YourMainContent() {
      // [!code highlight:9]
      useComponent({
        name: "showWeather",
        description: "Display a weather card for a city.",
        parameters: weatherSchema,
        render: WeatherCard,
      });

      return <div>{/* ... */}</div>;
    }
    ```

## 无参数

对于不需要类型化参数的简单组件：

```tsx
useComponent({
  name: "showGreeting",
  render: ({ message }: { message: string }) => (
    <div className="rounded border p-3 bg-blue-50">
      <p>{message}</p>
    </div>
  ),
});
```

## 限定到特定智能体

在多智能体场景中，可将组件限定到特定的智能体：

```tsx
useComponent({
  name: "renderProfile",
  parameters: z.object({ userId: z.string() }),
  render: ProfileCard,
  agentId: "support-agent",
});
```
