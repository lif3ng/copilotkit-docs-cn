## 自定义 A2UI 进度渲染器

使用[动态 Schema A2UI](./dynamic-schema) 时，一个辅助 LLM 会生成 UI schema 与数据。这一过程需要几秒钟——期间 CopilotKit 会显示内置的进度指示器。

你可以使用 `useRenderTool` 将内置指示器替换为自己的组件。

### 工作原理

动态 schema 流程在底层会调用一个名为 `render_a2ui` 的工具。当该工具调用处于进行中时（`status === "inProgress"`），会显示你的自定义渲染器。一旦 A2UI surface 开始渲染（`status === "complete"`），你的组件就会被隐藏，由真正的 surface 接管。

### 实现

<Steps>
<Step>
### 创建进度组件

```tsx title="src/components/a2ui-progress.tsx"
"use client";

import { memo } from "react";

interface A2UIProgressProps {
  parameters: Record<string, unknown>;
}

export const A2UIProgress = memo(function A2UIProgress({
  parameters,
}: A2UIProgressProps) {
  // You can inspect `parameters` to show partial progress.
  // As the LLM streams, `parameters.components` and `parameters.items`
  // will progressively populate.
  const componentCount = Array.isArray(parameters?.components)
    ? parameters.components.length
    : 0;
  const itemCount = Array.isArray(parameters?.items)
    ? parameters.items.length
    : 0;

  return (
    <div className="rounded-lg border border-gray-200 bg-gray-50 p-4">
      <div className="flex items-center gap-2 text-sm text-gray-600">
        <div className="h-4 w-4 animate-spin rounded-full border-2 border-gray-300 border-t-gray-600" />
        <span>Building interface...</span>
      </div>
      {componentCount > 0 && (
        <p className="mt-2 text-xs text-gray-500">
          {componentCount} components, {itemCount} items
        </p>
      )}
    </div>
  );
});
```
</Step>

<Step>
### 注册渲染器

使用 `useRenderTool` 拦截 `render_a2ui` 工具调用，并在其进行期间显示你的组件：

```tsx title="src/hooks/use-a2ui-progress.tsx"
"use client";

import { useRenderTool } from "@copilotkit/react-core/v2";
import { z } from "zod";
import { A2UIProgress } from "@/components/a2ui-progress";

export function useA2UIProgress() {
  useRenderTool(
    {
      name: "render_a2ui",
      parameters: z.any(),
      render: ({ status, parameters }) => {
        // Hide when complete — the A2UI surface renderer takes over
        if (status === "complete") return <></>;
        return <A2UIProgress parameters={parameters ?? {}} />;
      },
    },
    [],
  );
}
```
</Step>

<Step>
### 在页面中调用 Hook

```tsx title="src/app/page.tsx"
"use client";

import { useA2UIProgress } from "@/hooks/use-a2ui-progress";

function Chat() {
  useA2UIProgress();

  return <CopilotChat className="flex-1" />;
}
```
</Step>
</Steps>

<Callout type="info">
`parameters` 对象会随着 LLM 流式传输 `render_a2ui` 工具调用而逐步更新。你可以借此展示一个骨架屏，随着组件与数据到达逐步填充。
</Callout>

### `parameters` 里有什么？

随着辅助 LLM 生成 A2UI surface，`parameters` 对象会不断累积：

| 字段 | 类型 | 说明 |
|---|---|---|
| `surfaceId` | `string` | 该 surface 的唯一 ID |
| `components` | `array` | 组件树（schema）——最先到达 |
| `root` | `string` | 根组件 ID |
| `items` | `array` | 数据项——在 schema 之后到达 |

常见的模式是：一旦 `components` 有了数据就显示骨架布局，然后随着 `items` 流式到达显示条目数量。

## 操作处理器

本节中的操作处理均在客户端进行。当前 Python SDK 的 `a2ui.render` 不支持 `action_handlers=` 关键字；固定 schema 指南保留了按钮 schema，并注明不支持服务端处理器。当前 React API 提供了带有 `onAction` 拦截器的 `createA2UIMessageRenderer`。

本节介绍当前的前端拦截器以及 v0.9 schema 按钮格式。

### 带操作上下文的 schema 按钮

v0.9 A2UI schema 为按钮定义了事件以及绑定数据的上下文字段。重复列表内的组件使用相对路径，因此上下文值会从被点击的条目中解析：

```json
{
  "id": "book-button",
  "component": "Button",
  "child": "book-label",
  "variant": "primary",
  "action": {
    "event": {
      "name": "book_flight",
      "context": {
        "flightNumber": { "path": "flightNumber" },
        "price": { "path": "price" }
      }
    }
  }
}
```

生成的 `A2UIUserAction` 将包含解析后的上下文：

```typescript
{
  name: "book_flight",
  surfaceId: "flight-search-results",
  sourceComponentId: "book-button",
  timestamp: "2025-01-01T00:00:00.000Z",
  context: { flightNumber: "AA100", price: "$350" },
}
```

### `onAction` 拦截器

将 `onAction` 传给导出的渲染器工厂，即可在浏览器中处理操作。在本地处理完该操作后返回 `null`；返回 `undefined` 则将其原样转发给智能体：

```tsx
import {
  createA2UIMessageRenderer,
  type A2UIUserAction,
} from "@copilotkit/react-core/v2";
import { theme } from "./theme";

const A2UIMessageRenderer = createA2UIMessageRenderer({
  theme,
  onAction: (action: A2UIUserAction) => {
    if (action.name === "book_flight") {
      console.info("Booking requested", action.context);
      return null;
    }
    return undefined;
  },
});
```

当你需要这种自定义 `onAction` 行为时，请将返回的渲染器通过 Provider 的 `renderActivityMessages` prop 传入。用户提供的渲染器优先于 Provider 内置的 A2UI 渲染器。

### 转发修改后的操作

拦截器可以返回一个修改后的 `A2UIUserAction`（导出类型）；渲染器会将该操作转发给智能体：

```tsx
const A2UIMessageRenderer = createA2UIMessageRenderer({
  theme,
  onAction: (action) => {
    if (action.name !== "book_flight") return;

    return {
      ...action,
      context: {
        ...(action.context ?? {}),
        source: "a2ui",
      },
    };
  },
});
```

### 当前的操作流程

当前渲染器在转发操作之前会先应用 `onAction`：

1. 返回 `null` 表示在浏览器中处理该操作，并跳过智能体。
2. 返回一个 `A2UIUserAction` 则转发修改后的操作。
3. 返回 `undefined` 则转发原始操作。

当前 Python SDK 不会根据 `action_handlers=` 参数创建服务端操作处理器。在本文档中，前端拦截器是受支持的自定义处理路径。当前 React bridge 传给 `onAction` 的操作中不包含 `dataContextPath`；回调所需的值请使用 `context`。

### 类型参考

| 类型 | 说明 |
|---|---|
| `A2UIUserAction` | 派发的操作：`{ name, surfaceId, sourceComponentId, timestamp, context? }` |
| `A2UIActionInterceptor` | `(action, forward) => A2UIUserAction \| null \| void \| Promise<void \| A2UIUserAction \| null>` —— 导出的拦截器类型 |
| `createA2UIMessageRenderer` | 接受 `theme` 和可选 `onAction` 的导出工厂函数 |
