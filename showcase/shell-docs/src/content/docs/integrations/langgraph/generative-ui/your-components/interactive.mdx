## 这是什么？
前端工具让你能够定义 LangGraph 智能体可以调用的客户端函数，其执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，
逻辑会在客户端运行，让你能够直接访问前端环境。

它可以用来让[你的智能体控制 UI](/langgraph/frontend-tools)、实现[生成式 UI](/langgraph/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

本指南介绍如何将前端工具用于人机协同（human-in-the-loop）。

## 什么时候应该使用它？
当你需要智能体与以下客户端原语交互时，可以使用前端工具：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

    <Step>
        ### 创建前端人机协同工具

        前端工具的使用方式多种多样。其中一种方式是构建人机协同（human-in-the-loop）流程，让工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的“审批”流程。首先，使用 `useHumanInTheLoop` hook 创建一个提示用户进行审批的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod";

        export function Page() {
          // ...

          // [!code highlight:20]
          useHumanInTheLoop({
            name: "humanApprovedCommand",
            description: "Ask human for approval to run a command.",
            parameters: z.object({
              command: z.string().describe("The command to run"),
            }),
            render: ({ args, respond, status }) => {
              if (status !== "executing") return <></>;
              return (
                <div>
                  <pre>{args.command}</pre>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond?.(`Command is APPROVED`)}>Approve</button>
                  <button onClick={() => respond?.(`Command is DENIED`)}>Deny</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 安装 CopilotKit SDK

        接下来，需要修改智能体以访问这些前端工具。在终端中，进入你的智能体所在文件夹，然后从那里继续！

    <Step>
        ### 继承 CopilotKitState

        要访问 CopilotKit 提供的前端工具，可以在智能体的状态定义中继承 CopilotKitState：

        <Tabs groupId="language_langgraph_agent" items={['Python', 'TypeScript']} default="Python" persist>
            <Tab value="Python">
                ```python title="agent.py"
                from copilotkit import CopilotKitState # [!code highlight]

                class YourAgentState(CopilotKitState): # [!code highlight]
                    your_additional_properties: str
                ```
            </Tab>
            <Tab value="TypeScript">
                ```typescript title="agent-js/src/agent.ts"
                import { StateSchema } from "@langchain/langgraph";
                import { CopilotKitStateSchema } from "@copilotkit/sdk-js/langgraph"; // [!code highlight]
                import { z } from "zod";

                export const YourAgentStateSchema = new StateSchema({
                    yourAdditionalProperty: z.string(),
                    ...CopilotKitStateSchema.fields, // [!code highlight]
                });
                export type YourAgentState = typeof YourAgentStateSchema.State;
                ```
            </Tab>
        </Tabs>

        这样一来，智能体的状态就会包含 `copilotkit` 属性，其中含有可供访问和调用的前端工具。
    </Step>
