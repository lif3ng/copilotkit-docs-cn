---
title: "第 1 步：运行示例"
---

<Steps>
<Step>
### 检查前置条件

开始之前，请安装 Node.js 20.9.0 及以上版本、pnpm、Python 3.12 及以上版本，以及 [`uv`](https://docs.astral.sh/uv/getting-started/installation/)。在 macOS 或 Linux 上，可以用官方安装脚本安装 `uv`：

```shell
curl -LsSf https://astral.sh/uv/install.sh | sh
```

</Step>
<Step>
### 克隆当前仓库

```shell
git clone https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit
pnpm install
```

完整的 v2 示例位于 `examples/v1/travel`，其主要组成部分如下：

- `app/`：Next.js 页面与 v2 运行时路由
- `components/`：地图、聊天 UI 和审批卡片
- `lib/`：共享智能体状态、类型和 React hooks
- `agent/`：Python LangGraph 智能体和 AG-UI 服务器

</Step>
<Step>
### 安装智能体

在仓库根目录下，使用示例自带的脚本安装 Python 依赖：

```shell
cd examples/v1/travel
pnpm install:agent
```

该脚本会在 `agent/` 目录中运行 `uv sync`。

</Step>
<Step>
### 添加 API 密钥

在旅行示例中创建 `agent/.env`：

```txt title="examples/v1/travel/agent/.env"
OPENAI_API_KEY=<your-openai-api-key>
GOOGLE_MAPS_API_KEY=<your-google-maps-api-key>
```

OpenAI 密钥可在 [OpenAI API 控制台](https://platform.openai.com/api-keys)获取，Google Maps 密钥可参考 [Google Maps Platform 指南](https://developers.google.com/maps/documentation/places/web-service/get-api-key#creating-api-keys)获取。

</Step>
<Step>
### 启动应用与智能体

在 `examples/v1/travel` 目录下运行以下命令：

```shell
pnpm dev
```

这会在 [http://localhost:3000](http://localhost:3000) 启动 Next.js 应用，并在 `8000` 端口启动智能体。打开应用，让它帮你规划一次旅行。

</Step>
</Steps>
