现在应用和智能体都已经在运行，接下来用 CopilotKit 把它们连接起来。`frontend` 目录中已经安装好了必要的依赖：

- `@copilotkit/react-core`：CopilotKit 核心功能与 hooks
- `@copilotkit/react-ui`：用于聊天界面的预构建组件

<Accordions>
<Accordion title="安装命令（可选）">
  **本教程中的包版本是固定的，更新依赖可能会导致教程无法正常运行**。

```npm
npm install @copilotkit/react-core
```

</Accordion>
</Accordions>

<Steps>
<Step>
### 设置 Copilot Cloud
首先，创建一个 [Copilot Cloud 账户](https://dashboard.operations.copilotkit.ai/sign-in)。它会为你的 LLM 提供一个可用于生产环境的代理。

<Callout>Copilot Cloud 包含用于开发的免费 LLM 额度。</Callout>

</Step>
<Step>
### 获取 Copilot Cloud API 密钥

登录后，你会看到一些入门引导步骤。我们真正需要的是一个公开 API 密钥。为此，
你需要创建一个 OpenAI API 密钥并将其提供给 Copilot Cloud。

<ImageZoom
  src="https://cdn.copilotkit.ai/docs/copilotkit/images/coagents/tutorials/ai-travel-app/cpkCloudSetup.png"
  alt="CopilotCloud API Key"
  height={1000}
  width={1000}
/>

</Step>
<Step>
### 配置环境变量
创建并填充前端环境文件：

```shell
touch frontend/.env
```

然后，将你的 Copilot Cloud API 密钥添加到该文件中，如下所示：

```txt title="frontend/.env"
NEXT_PUBLIC_CPK_PUBLIC_API_KEY=...
```

</Step>
<Step>
### 添加 CopilotKit provider
用 CopilotKit provider 包裹你的应用：

```tsx title="frontend/src/app/layout.tsx"
"use client";

// ...
// ...

export default function RootLayout({
  children,
}: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en" className="h-full">
      <body className={`${lato.variable} ${noto.className} antialiased h-full`}>
        // [!code ++:4]
        <CopilotKit publicApiKey={process.env.NEXT_PUBLIC_CPK_PUBLIC_API_KEY}>
          <TooltipProvider>
            <ResearchProvider>{children}</ResearchProvider>
          </TooltipProvider>
        </CopilotKit>{" "}
        // [!code ++]
      </body>
    </html>
  );
}
```

</Step>
<Step>

### 添加聊天界面

我们提供了多个可定制的组件，供你与 copilot 交互。其中包括 [`<CopilotPopup/>`](/reference/v1/components/chat/CopilotPopup)、[`<CopilotSidebar/>`](/reference/v1/components/chat/CopilotSidebar) 和 [`<CopilotChat/>`](/reference/v1/components/chat/CopilotChat)，也可以通过 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) 构建完全自定义的 UI。

在本教程中，我们将使用 `<CopilotChat/>` 组件，因为我们的目标是打造一个非模态的聊天界面。

<Callout>
  `Chat` 组件将作为 CopilotKit `CopilotChat` 组件的包装器，以便简化你在整个过程中需要编写的代码。
</Callout>

```tsx title="frontend/src/components/Chat.tsx"
"use client"


export default function Chat({ onSubmitMessage }: { onSubmitMessage: () => void }) {
  return (
      // [!code ++:10]
      <CopilotChat
          labels={{
              modalHeaderTitle: MAIN_CHAT_TITLE,
              welcomeMessageText: INITIAL_MESSAGE,
          }}
          className="h-full w-full font-noto"
          onSubmitMessage={onSubmitMessage}
      />
      // [!code --:4]
      <h1 className="text-2xl font-bold flex items-center justify-center h-full mx-auto mr-20">
        It'd be really cool if we had chat here!
      </h1>
  )
}
```

</Step>
</Steps>

## 回顾

大功告成！以下是我们做过的事情：

- 我们注册了 Copilot Cloud 账户并获取了 API 密钥。
- 我们在应用中配置了 CopilotKit provider，使其使用我们的 API 密钥。
- 我们在应用中添加了 CopilotSidebar。

现在，回到应用，你会在页面左侧看到一个聊天界面。此时，你就可以开始与你的 copilot 交互了！🎉
