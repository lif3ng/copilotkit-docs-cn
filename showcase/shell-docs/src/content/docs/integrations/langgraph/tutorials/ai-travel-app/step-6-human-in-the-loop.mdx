title: "第 6 步：添加人工审批"
---

旅行智能体在添加、更新或删除行程之前会先暂停。React 应用展示提议的变更，并把用户的决定发回暂停中的运行。

## 暂停图

`agent/src/agent.py` 让行程工具经过 `trips_node`，并在编译图时在该节点之后设置中断：

```python title="examples/v1/travel/agent/src/agent.py"
graph_builder.add_edge("trips_node", "perform_trips_node")

graph = graph_builder.compile(
    interrupt_after=["trips_node"],
    checkpointer=MemorySaver(),
)
```

这个中断为前端争取了时间，让用户能在 `perform_trips_node` 修改状态之前批准或拒绝该工具调用。

## 注册审批 UI

v2 的 `useHumanInTheLoop` hook 将每个行程工具与一个 React 组件配对。本例使用 Zod schema，并使用与 provider 相同的 `travel` 智能体 ID：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
import { useHumanInTheLoop } from "@copilotkit/react-core/v2";

useHumanInTheLoop({
  name: "add_trips",
  agentId: "travel",
  description: "Add some trips",
  parameters: tripsSchema,
  render: ({ args, status, respond }) => (
    <AddTrips args={args} status={status} respond={respond} />
  ),
});
```

更新与删除工具使用同一个 hook。它们把当前行程状态作为依赖传入，因为对应的审批卡片需要用到它：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
useHumanInTheLoop(
  {
    name: "delete_trips",
    agentId: "travel",
    description: "Delete some trips",
    parameters: z.object({
      trip_ids: z.array(z.string()).describe("The IDs of the trips to delete"),
    }),
    render: ({ args, status, respond }) => (
      <DeleteTrips
        args={args}
        status={status}
        respond={respond}
        trips={state.trips}
      />
    ),
  },
  [state.trips],
);
```

## 发送决策

hook 的 `respond` 函数会恢复暂停中的运行。审批组件只在工具调用等待结果时才启用按钮：

```tsx title="examples/v1/travel/components/humanInTheLoop/ActionButtons.tsx"
import { ToolCallStatus } from "@copilotkit/react-core/v2";

<Button
  disabled={status !== ToolCallStatus.Executing || isPending}
  onClick={async () => sendResponse("CANCEL")}
>
  {reject}
</Button>
<Button
  disabled={status !== ToolCallStatus.Executing || isPending}
  onClick={async () => sendResponse("SEND")}
>
  {approve}
</Button>
```

`sendResponse` 会等待 `respond`，并在请求进行期间保持按钮禁用。它还会保留失败的结果，方便用户重试。

## 在智能体中处理拒绝

响应会作为最新的 `ToolMessage` 到达。当其内容为 `CANCEL` 时，智能体中止行程操作：

```python title="examples/v1/travel/agent/src/trips.py"
async def perform_trips_node(state: AgentState, config: RunnableConfig):
    ai_message = cast(AIMessage, state["messages"][-2])
    tool_message = cast(ToolMessage, state["messages"][-1])

    if tool_message.content == "CANCEL":
        state["messages"].append(AIMessage(content="Cancelled the trip operation."))
        await copilotkit_emit_message(config, "Cancelled the trip operation.")
        return state

    # Apply the approved add, update, or delete operation.
```

让运行中的应用添加或删除一个行程。批准其中一个请求、拒绝另一个请求，把两条路径都走一遍。
