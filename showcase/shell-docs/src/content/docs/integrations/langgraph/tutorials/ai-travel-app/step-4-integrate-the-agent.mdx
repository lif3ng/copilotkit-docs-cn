旅行 UI 和 LangGraph 智能体都在处理行程与当前选中的行程。v2 的 `useAgent` hook 让 UI 可以直接访问这份共享状态。

## 选择智能体

聊天通过 `app/page.tsx` 中的 `CopilotChatConfigurationProvider` 选择了 `travel`。状态 hook 则在 `lib/hooks/use-trips.tsx` 中使用同一个 ID：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
import { useAgent } from "@copilotkit/react-core/v2";

export const TripsProvider = ({ children }: { children: ReactNode }) => {
  const { agent, isReady } = useAgent({ agentId: "travel" });
  const state = normalizeAgentState(agent.state);

  // ...
};
```

`agent.state` 会随着 AG-UI 状态事件的到达而变化。在智能体发出第一份完整状态之前，`normalizeAgentState` 能保证 UI 不出错。

## 初始化共享状态

智能体就绪后，provider 会用示例的默认行程补齐缺失的字段：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
useEffect(() => {
  if (!isReady) return;
  if (isAgentStateInitialized(agent.state)) return;

  agent.setState(normalizeAgentState(agent.state));
}, [agent, agent.state, isReady]);
```

## 从 UI 更新状态

UI 控件调用 `agent.setState`。每次更新都从最新的智能体状态出发，以免覆盖更新的改动：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
const setSelectedTripId = (trip_id: string | null) => {
  agent.setState({
    ...normalizeAgentState(agent.state),
    selected_trip_id: trip_id,
  });
};

const addTrip = (trip: Trip) => {
  const currentState = normalizeAgentState(agent.state);
  agent.setState({
    ...currentState,
    trips: [...currentState.trips, trip],
  });
};
```

在运行中的应用里问问它能看到哪些行程，然后在地图上选择另一个行程，再问一次。React 控件和智能体读取的是同一份状态。
