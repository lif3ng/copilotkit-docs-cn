现在我们已经可以与智能体对话了，接下来开始实现人机协同（human-in-the-loop）。在这种模式下，用户可以审查智能体的输出并提供反馈。在我们的应用中，我们将允许用户在研究开始之前审查并批准一份大纲，以此来实现人机协同。

<Steps>
<Step>
## 理解人机协同

在 LangGraph 中，目前建议使用 [interrupt](https://docs.langchain.com/oss/python/langgraph/interrupts) 方法来实现人机协同。调用该函数会在调用处暂停节点，之后带着用户的决定重新运行该节点。你可以在[这里](https://docs.langchain.com/langsmith/interrupt-concurrent)了解更多关于 interrupt 的内容。

## 在前端添加 `useLangGraphInterrupt`

还记得我们启动智能体时的内容吗？当需要审查一份研究大纲提案时，interrupt 会停止相应节点。

CopilotKit 允许我们通过 `useLangGraphInterrupt` hook 渲染一个 UI，以获取用户对这个中断的决定并做出相应响应。

在 `page.tsx` 文件中，添加以下代码。

```tsx title="frontend/src/app/page.tsx"
// ...
// ...

export default function HomePage() {
  // ...
  const { state: researchState, setResearchState } = useResearch();

  const streamingSection = useStreamingContent(researchState);

  // [!code ++:12]
  useLangGraphInterrupt<Proposal>({
    render: ({ resolve, event }) => {
      return (
        <ProposalViewer
          proposal={event.value}
          onSubmit={(approved, proposal) =>
            resolve(
              JSON.stringify({
                ...proposal,
                approved,
              }),
            )
          }
        />
      );
    },
  });
  // ...
}
```

现在，当 LangGraph 被中断时，`ProposalViewer` 组件会渲染给用户，其中 `event.value` 作为提案。提交时，hook 的 `resolve` 函数会带着用户的决定被调用。

<Callout>
想了解更多渲染细节，可以查看 `frontend/src/components/ProposalViewer.tsx` 文件中的 `ProposalViewer` 组件代码。

它只是一个标准的 React 组件，包含一些样式、一个表单和一个提交按钮。

</Callout>

## 回顾

真的就这么简单！现在，我们已经为智能体实现了人机协同。回顾一下，我们做了以下事情：

- 了解了 LangGraph 中的人机协同。
- 在应用中添加了 `useLangGraphInterrupt` hook。
- 在聊天中向用户渲染了 `ProposalViewer` 组件
