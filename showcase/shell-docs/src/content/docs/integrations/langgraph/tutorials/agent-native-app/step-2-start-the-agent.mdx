在开始集成 LangGraph 智能体之前，我们先来了解它的工作原理。

出于本教程的目的，我们不会从零开始构建 LangGraph，而是直接使用 `agent/` 目录中已经构建好的 LangGraph。它包含了构建研究型 ANA 所需的全部逻辑，唯独不含 CopilotKit 相关特性——这部分我们将一起添加。

<Callout>
  如果你想循序渐进地学习如何构建 LangGraph 智能体，可以查阅
  [LangGraph 快速开始指南](https://docs.langchain.com/oss/python/langgraph/quickstart)。
</Callout>

在把 LangGraph 智能体集成到应用之前，我们先把它过一遍，理解它是如何工作的。

<Steps>
<Step>
### 获取 API 密钥
你需要两个 API 密钥：
- [OpenAI API 密钥](https://platform.openai.com/api-keys)
- [Tavily API 密钥](https://tavily.com/)

</Step>
<Step>
### 配置 `.env` 文件
创建并配置智能体的环境：

```shell
cd agent
touch .env
```

添加你的 API 密钥：

```txt title=".env"
OPENAI_API_KEY=<your-openai-api-key>
TAVILY_API_KEY=<your-tavily-api-key>
```

</Step>
<Step>
### 启动智能体
安装并运行 LangGraph CLI：

```shell
pip install -r requirements.txt # 安装依赖
brew install langgraph-cli # 安装 LangGraph CLI
langgraph dev --host localhost --port 8000 # 启动智能体
```

这会在浏览器中打开 LangGraph Studio，你可以在其中查看智能体的可视化并与它交互。

<Callout>
  该智能体将在 https://localhost:8000 上可用，供后续步骤使用。
</Callout>

</Step>

### 理解 LangGraph 智能体

由于我们要把这个智能体打造成智能体化的体验，就需要理解它的工作原理。这里涉及的关键概念有：

- **状态**（State）：状态是智能体用来做出决策并传达决策的数据。你可以在屏幕左下角看到所有的状态变量。**状态只会在节点转换之间更新**。
- **节点**（Nodes）：节点是 LangGraph 智能体的构建单元，是智能体为完成任务所采取的步骤。在本例中，我们有 **agent**、**tools**、**human input** 和 **processing feedback** 等节点。
- **边**（Edges）：边是连接节点的箭头，定义了智能体从一个节点移动到下一个节点的逻辑。它们在代码中定义，条件逻辑则通过 `route` 函数处理。
- **中断**（Interrupts）：中断是一种让用户能够与智能体协同工作并审查其决策的机制。在本例中，**human** 节点之后有一个**中断**，它会阻止智能体继续推进，直到用户提供反馈。

</Step>
<Step>
### 测试 LangGraph 智能体

你可以在 `messages` 状态变量中添加一条消息，然后点击 “Submit”，即可向智能体提交消息。这个智能体是为本教程做了简化的版本，用于代表一个简单的研究智能体。

在后续步骤中我们会把它打造得更炫酷，但现在你可以先让它做一些研究，看看我们将把哪些行为集成到应用中。

</Step>
</Steps>

## 回顾

现在我们有了一个正在运行的智能体！它将在 `https://localhost:8000` 上可用。以下是我们做过的事情：

- 安装了 LangGraph Studio
- 配置了 `.env` 文件
- 启动、可视化并测试了 LangGraph 智能体

在下一步中，我们将把 LangGraph 智能体作为 Copilot Agent（CoAgent）集成到应用中。
