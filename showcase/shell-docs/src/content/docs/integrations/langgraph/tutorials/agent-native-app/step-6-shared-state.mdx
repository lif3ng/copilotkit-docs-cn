title: "第 6 步：共享状态"

在 LangGraph 中，智能体是有状态的。这意味着当图遍历各个节点时，整体应用状态会被更新并持久化。

CopilotKit 提供两个主要 hook，让你轻松读取和更新这个状态：

- [`useCoAgent`](/reference/v1/hooks/useCoAgent) - 提供在应用任意位置读写智能体状态的方式。
- [`useCoAgentStateRender`](/reference/v1/hooks/useCoAgentStateRender) - 提供在聊天中渲染智能体状态的方式。

明确这一点后，我们当前的目标是在应用状态与 LangGraph 智能体状态之间建立双向连接。这将让我们能够在右侧面板中渲染智能体完成的研究内容。

为此，我们将使用 `useCoAgent` hook。

<Callout>
  `useCoAgentStateRender` 将在下一步中用于在聊天中渲染智能体的进度。
</Callout>

<Steps>
<Step>
## 理解智能体的状态
智能体的状态定义在 `agent/state.py` 中。

```python title="agent/state.py"
# ...
from typing import Dict, Union, List
from langgraph.graph import MessagesState

class ResearchState(MessagesState):
    title: str
    proposal: Dict[str, Union[str, bool, Dict[str, Union[str, bool]]]]  # Stores proposed structure before user approval
    outline: dict
    sections: List[dict]  # list of dicts with 'title','content',and 'idx'
    footnotes: str
    sources: Dict[str, Dict[str, Union[str, float]]]
    tool: str
    logs: List[dict]  # list of dicts logs to be sent to frontend with 'message', 'status'
```

这里有几点需要注意，但我们先关注 `proposal` 字段和 `sections` 字段。

- `proposal` 字段是一个字典，存储用户批准之前的研究结构提案。
- `sections` 字段是一个字典列表，每一项都包含 `title`、`content` 和 `idx`。这就是将显示在右侧面板中的实际研究内容。

我们在上一步中已经完成了 `proposal` 字段批准逻辑的接线，现在需要为 `sections` 字段接线渲染。

</Step>
<Step>

## `useCoAgent` hook

我们当前的目标是在这两个状态之间建立双向连接。幸运的是，[`useCoAgent`](/reference/v1/hooks/useCoAgent) hook 让这一切变得简单。

在 `useResearch` hook 中，我们只需把 React 状态对象替换为 `useCoAgent` hook。

```tsx title="frontend/src/components/research-context.tsx" {3,8-11}
// ...
// ...

interface ResearchContextType {
    state: ResearchState;
    setResearchState: (newState: ResearchState | ((prevState: ResearchState) => ResearchState)) => void
    sourcesModalOpen: boolean
    setSourcesModalOpen: (open: boolean) => void
    runAgent: () => void
}

const ResearchContext = createContext<ResearchContextType | undefined>(undefined)

export function ResearchProvider({ children }: { children: ReactNode }) {
    const [sourcesModalOpen, setSourcesModalOpen] = useState<boolean>(false)
    // [!code ++:5]
    const { state, setState, run } = useAgent<ResearchState>({
        name: 'agent',
        initialState: {},
    });
    const [state, setState] = useState<ResearchState>({} as ResearchState) // [!code --]

    // ...

    return (
        <ResearchContext.Provider
            value={{
              state,
              setResearchState: setState as ResearchContextType['setResearchState'],
              setSourcesModalOpen,
              sourcesModalOpen,
              runAgent: run  // [!code ++]
              runAgent: () => {} // [!code --]
            }}>
            {children}
        </ResearchContext.Provider>
    )
}

export function useResearch() {
    const context = useContext(ResearchContext)
    if (context === undefined) {
        throw new Error('useResearch must be used within a ResearchProvider')
    }
    return context
}
```

<Callout>
`useCoAgent` hook 是泛型的。这意味着我们可以指定一个类型来表示 LangGraph 智能体的状态。如果你要指定类型，请务必确保该类型的结构与 LangGraph 智能体的状态完全一致。

虽然不推荐，但你也可以舍弃类型参数，转而使用 `any` 类型。

</Callout>

在这个示例中，我们使用 `useCoAgent` hook 把应用状态接到 LangGraph 智能体状态上。

- 对于泛型类型，我们传入 `AgentState` 类型，它已经在 `@/lib/types.ts` 中为应用定义好了。
- 对于 `name` 参数，我们传入 `agent/langgraph.json` 中定义的图名称。
- 对于 `initialState` 参数，我们传入 LangGraph 智能体的初始状态，它已经在 `@/lib/trips.ts` 中定义好了。

</Step>
</Steps>
