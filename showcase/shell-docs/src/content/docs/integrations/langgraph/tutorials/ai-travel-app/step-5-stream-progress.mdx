地点搜索可能耗时数秒。旅行智能体会在每次查询后发送当前的 `search_progress` 状态。在对应工具调用执行期间，React 应用会在聊天入口处渲染该状态。

Python 版 CopilotKit SDK 已列在 `agent/pyproject.toml` 中，并已在第 1 步由 `pnpm install:agent` 安装。

## 从智能体发送中间状态

`agent/src/search.py` 告诉 CopilotKit 哪个状态字段属于 `search_for_places` 工具调用：

```python title="examples/v1/travel/agent/src/search.py"
from copilotkit.langgraph import copilotkit_emit_state, copilotkit_customize_config


async def search_node(state: AgentState, config: RunnableConfig):
    ai_message = cast(AIMessage, state["messages"][-1])

    config = copilotkit_customize_config(
        config,
        emit_intermediate_state=[
            {
                "state_key": "search_progress",
                "tool": "search_for_places",
                "tool_argument": "search_progress",
            }
        ],
    )
```

该节点为每个查询创建一条进度项，并在搜索开始前发送状态：

```python title="examples/v1/travel/agent/src/search.py"
state["search_progress"] = []
queries = ai_message.tool_calls[0]["args"]["queries"]

for query in queries:
    state["search_progress"].append(
        {"query": query, "results": [], "done": False}
    )

await copilotkit_emit_state(config, state)
```

每条查询完成时会再次发送状态，整个搜索结束后清空进度：

```python title="examples/v1/travel/agent/src/search.py"
async with httpx.AsyncClient() as client:
    for i, query in enumerate(queries):
        places.extend(await _search_places(client, query, i))
        state["search_progress"][i]["done"] = True
        await copilotkit_emit_state(config, state)

state["search_progress"] = []
await copilotkit_emit_state(config, state)
```

## 在 React 中渲染进度

`lib/hooks/use-trips.tsx` 中的 v2 `useRenderTool` hook 为同一个工具名注册 UI。它读取最新的共享状态，只在工具调用执行期间渲染现有的 `SearchProgress` 组件：

```tsx title="examples/v1/travel/lib/hooks/use-trips.tsx"
import { useRenderTool } from '@copilotkit/react-core/v2';

useRenderTool(
  {
    name: 'search_for_places',
    agentId: 'travel',
    parameters: z.object({
      queries: z.array(z.string()).describe('The place searches to run'),
    }),
    render: ({ status }) =>
      status === 'executing' &&
      state.search_progress &&
      state.search_progress.length > 0 ? (
        <SearchProgress progress={state.search_progress} />
      ) : (
        <></>
      ),
  },
  [state.search_progress],
);
```

状态检查可防止已完成的工具调用渲染更新的进度状态。依赖列表会在进度变化时刷新渲染器。让应用为某次行程查找地点，就能在聊天中看到每条搜索依次完成。
