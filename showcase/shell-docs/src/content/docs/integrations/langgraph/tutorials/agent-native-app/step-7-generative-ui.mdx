我们就快完成了！在这一步中，我们将为应用添加生成式 UI，以便在聊天 UI 中将智能体状态可视化。这样做的最终目标是让用户能够看到智能体研究完成过程中的进度。

<Callout>
  我们把从智能体状态或其工具调用渲染出来的 UI 称为
  “生成式 UI（Generative UI）”。
</Callout>

在本指南中，我们将开始使用 CopilotKit SDK 手动发出智能体的状态。这是因为在 LangGraph 中，只有当节点发生变化（即遍历一条边）时状态才会更新。

因此，进行中的工作默认不会发送给用户。不过，我们可以使用 `copilotkit_emit_state` 函数手动发出状态。有了这些发出的状态，我们将使用 `useCoAgentStateRender` hook 在聊天中渲染更新，让用户感受到进度。

## 手动发出状态
研究型 ANA 在多处发出状态。为了简单起见，我们把 `copilotkit_emit_state` 函数添加到 `agent/graph.py` 文件中，以便你理解它的工作原理。如果你有兴趣，也可以查看以下发出状态的文件：
- `agent/tools/outline_writer.py`
- `agent/tools/section_writer.py`
- `agent/tools/tavily_extract.py`
- `agent/tools/tavily_search.py`

这些文件都会把各自的进度写入智能体状态的 `logs` 字段。紧接着，我们调用 `copilotkit_emit_state` 把状态发送到前端。

例如，在 `tool_node` 中，我们根据工具结果更新一些状态，然后使用 `copilotkit_emit_state` 把状态发送到前端。

```python title="agent/graph.py"
# ...
from copilotkit.langchain import copilotkit_emit_state # [!code ++]
#...

async def tool_node(self, state: ResearchState, config: RunnableConfig) -> Command[Literal["process_feedback_node", "call_model_node"]]:
        # ...
        for tool_call in state["messages"][-1].tool_calls:
            # ...

            tool_state = {
                "title": new_state.get("title", ""),
                "outline": new_state.get("outline", {}),
                "sections": new_state.get("sections", []),
                "sources": new_state.get("sources", {}),
                "proposal": new_state.get("proposal", {}),
                "logs": new_state.get("logs", []),
                "tool": new_state.get("tool", {}),
                "messages": msgs
            }
            await copilotkit_emit_state(config, tool_state) # [!code ++]

        return tool_state
```

随着这个循环的迭代，工具写入的中间状态会被发送到前端。基本上，任何时候你想把状态发送到前端，都可以通过调用 `copilotkit_emit_state` 来实现。

</Step>

## 渲染发出的状态
现在，状态已经被发送到前端了。但我们还需要在聊天中渲染它。为此，我们将使用 `useCoAgentStateRender` hook。

```tsx title="frontend/src/app/layout.tsx"
export default function HomePage() {
  //...
  const { state: researchState, setResearchState } = useResearch();
  // ...

  // [!code ++:10]
  useCoAgentStateRender<ResearchState>(
    {
      name: "agent",
      render: ({ state }) => {
        if (state.logs?.length > 0) {
          return <Progress logs={state.logs} />;
        }
        return null;
      },
    },
    [researchState],
  );

  // ...
}
```
