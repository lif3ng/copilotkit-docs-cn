旅行应用使用 CopilotKit v2 的 React 与运行时入口。两者都是 `examples/v1/travel/package.json` 中已声明包的子路径：

- React hooks、provider 和聊天 UI 来自 `@copilotkit/react-core/v2`。
- 运行时类与处理器来自 `@copilotkit/runtime/v2`。
- LangGraph 适配器来自 `@copilotkit/runtime/langgraph`。

完整的 import 映射请参阅 [v1 到 v2 迁移指南](/migrate/v2)。

## 配置 React 应用

`app/page.tsx` 从 v2 React 入口导入 provider、聊天配置、侧边栏和样式：

```tsx title="examples/v1/travel/app/page.tsx"
import {
  CopilotChatConfigurationProvider,
  CopilotKit,
  CopilotSidebar,
} from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

provider 默认使用本地运行时。如果设置了 `NEXT_PUBLIC_CPK_PUBLIC_API_KEY`，则会改用对应的 Copilot Cloud 项目：

```tsx title="examples/v1/travel/app/page.tsx"
export default function Home() {
  const publicApiKey = process.env.NEXT_PUBLIC_CPK_PUBLIC_API_KEY;

  return (
    <CopilotKit
      runtimeUrl={publicApiKey ? undefined : "/api/copilotkit"}
      publicApiKey={publicApiKey}
    >
      <CopilotChatConfigurationProvider
        agentId="travel"
        isModalDefaultOpen={false}
      >
        <MainContent />
        <CopilotSidebar
          defaultOpen={false}
          labels={{
            modalHeaderTitle: "Travel Planner",
            welcomeMessageText: "Hi! I'm here to plan your trips.",
          }}
        />
      </CopilotChatConfigurationProvider>
    </CopilotKit>
  );
}
```

`CopilotChatConfigurationProvider` 为聊天选择了 `travel` 智能体。后续步骤中的状态与工具 hook 会使用同一个智能体 ID。

## 配置本地运行时

`app/api/copilotkit/[[...slug]]/route.ts` 将面向浏览器的运行时连接到智能体。对于纯本地路由，使用 `HttpAgent` 调用第 2 步中启动的 AG-UI 端点。在 `examples/v1/travel` 目录下添加它的包：

```shell
pnpm add @ag-ui/client@1.0.2
```

然后配置该路由：

```ts title="examples/v1/travel/app/api/copilotkit/[[...slug]]/route.ts"
import {
  CopilotRuntime,
  createCopilotRuntimeHandler,
} from "@copilotkit/runtime/v2";
import { HttpAgent } from "@ag-ui/client";

const travel = new HttpAgent({
  url: process.env.REMOTE_ACTION_URL || "http://localhost:8000/copilotkit",
});

const runtime = new CopilotRuntime({
  agents: { travel },
});

const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
});

export const GET = handler;
export const POST = handler;
```

这份[仓库中自带的路由](https://github.com/CopilotKit/CopilotKit/blob/main/examples/v1/travel/app/api/copilotkit/%5B%5B...slug%5D%5D/route.ts)还通过一个兼容适配器支持已部署的 LangGraph 图，同时保留示例的 CopilotKit 状态与事件。使用 `LANGGRAPH_DEPLOYMENT_URL` 和 `LANGSMITH_API_KEY` 时请保留该路由。如果用的是第 2 步中的本地服务器，则不要设置部署 URL。
