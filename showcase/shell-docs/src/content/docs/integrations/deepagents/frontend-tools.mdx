## 这是什么？
前端工具让你能够定义客户端函数，供你的 Deep Agents 智能体调用，执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，
逻辑会在客户端运行，让你可以直接访问前端环境。

它可以用来让智能体控制 UI、实现生成式 UI，或进行人机协同（human-in-the-loop）交互。

在本指南中，我们将介绍如何使用前端工具来驱动 UI 并与之交互。

## 什么时候应该使用它？
当你需要智能体与客户端底层能力交互时，可以使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookies 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户即时浏览器上下文的操作

    <Step>
        ### 创建前端工具

        首先，你需要使用 [useFrontendTool](/reference/v2/hooks/useFrontendTool) 钩子创建一个前端工具。下面是一个简单的入门示例，
        它会向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          // [!code highlight:12]
          useFrontendTool({
            name: "sayHello",
            description: "Say hello to the user",
            parameters: z.object({
              name: z.string().describe("The name of the user to say hello to"),
            }),
            handler: async ({ name }) => {
              alert(`Hello, ${name}!`);
              return `Said hello to ${name}!`;
            },
          });

          // ...
        }
        ```
    </Step>

    <Step>
        ### 将 CopilotKit 状态接入你的智能体

        要访问 CopilotKit 提供的前端工具，需要在智能体所需的任意自定义状态之外，同时注册 CopilotKit 状态。

        <Tabs groupId="agent_language" items={['Python', 'TypeScript']} persist>
            <Tab value="Python">
                在 Python 中，让智能体的状态定义继承 `CopilotKitState`：

                ```python title="agent.py"
                from copilotkit import CopilotKitState # [!code highlight]

                class YourAgentState(CopilotKitState): # [!code highlight]
                    your_additional_properties: str
                ```
            </Tab>
            <Tab value="TypeScript">
                在 TypeScript 中，通过 `createMiddleware` 将自定义状态定义为中间件，再与 `copilotkitMiddleware` 组合：

                ```ts title="agent.ts"
                import { createMiddleware } from "langchain";
                import { copilotkitMiddleware } from "@copilotkit/sdk-js/langgraph"; // [!code highlight]
                import { z } from "zod";

                export const yourStateMiddleware = createMiddleware({
                    name: "YourAgentState",
                    stateSchema: z.object({
                        yourAdditionalProperty: z.string().optional(),
                    }),
                });

                // Pass both middlewares when constructing the agent:
                // createDeepAgent({ middleware: [yourStateMiddleware, copilotkitMiddleware], ... })
                ```
            </Tab>
        </Tabs>

        这样一来，智能体的状态就会包含 `copilotkit` 属性，其中含有可访问和调用的前端工具。
    </Step>
