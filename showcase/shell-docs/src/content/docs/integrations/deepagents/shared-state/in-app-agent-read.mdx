## 这是什么？

实时智能体状态不仅可以用于聊天 UI，也可以轻松用于应用自身的 UX。

## 何时使用？

当你想向用户提供关于智能体状态的反馈时，可以使用它。随着智能体状态的更新，你可以在应用中原生地反映这些更新。

## 实现

<Steps>
  <Step>
    ### 运行并连接你的智能体
    <RunAndConnect />
  </Step>
  <Step>
    ### 定义智能体状态
    LangGraph 是有状态的。当你在节点之间流转时，状态会被更新并传递给下一个节点。在本示例中，我们假设智能体状态大致如下。

    <Tabs groupId="agent_language" items={["Python", "TypeScript"]} persist>
      <Tab value="Python">
        ```python title="agent.py"
        from copilotkit import CopilotKitState
        from typing import Literal

        class AgentState(CopilotKitState):
            language: Literal["english", "spanish"] = "english"

        # The agent reads `state["language"]` from tools or middleware hooks
        # as it runs — no custom node required.
        ```
      </Tab>
      <Tab value="TypeScript">
        ```ts title="agent.ts"
        import { createMiddleware } from "langchain";
        import { copilotkitMiddleware, zodState } from "@copilotkit/sdk-js/langgraph"; // [!code highlight]
        import { z } from "zod";

        // Define the state as a middleware. The default flows through automatically.
        export const languageStateMiddleware = createMiddleware({
            name: "AgentState",
            stateSchema: z.object({
                language: zodState(z.enum(["english", "spanish"]).default("english")),
            }),
        });

        // Compose with copilotkitMiddleware when constructing the agent:
        // createDeepAgent({ middleware: [languageStateMiddleware, copilotkitMiddleware], ... })
        ```
      </Tab>
    </Tabs>
  </Step>
  <Step>
    ### 使用 `useAgent` Hook
    智能体连接并运行起来后，剩下的就是调用 `useAgent` hook、传入智能体的 ID，然后读取状态。

    ```tsx title="ui/app/page.tsx"
    import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

    function YourMainContent() {
      // [!code highlight:3]
      const { agent } = useAgent({
        agentId: "sample_agent",
      });

      const language = (agent.state.language as string) ?? "english";

      // ...

      return (
        // style excluded for brevity
        <div>
          <h1>Your main content</h1>
          {/* [!code highlight:1] */}
          <p>Language: {language}</p>
        </div>
      );
    }
    ```
    <Callout type="info">
      `agent.state` 是响应式的，当智能体状态发生变化时会自动更新。
    </Callout>
  </Step>
  <Step>
    ### 试一试！
    随着智能体状态的更新，你的 `state` 变量也会自动跟着更新！在本例中，你会看到语言被设为 “english”，因为这是我们设置的初始状态。

## 在聊天中渲染智能体状态

你也可以使用 `useRenderTool`，或通过 `useAgent` 访问 `agent.state`，在聊天 UI 中渲染智能体的状态。该状态是响应式的，会自动更新。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function YourMainContent() {
  // [!code highlight:3]
  const { agent } = useAgent({
    agentId: "sample_agent",
  });

  const language = (agent.state.language as string) ?? "english";

  return (
    <div>
      <p>Language: {language}</p>
    </div>
  );
}
```

## 流式传输并渲染中间状态
默认情况下，Deep Agents 的智能体状态只会在 LangGraph 节点切换*之间*更新——这意味着状态更新是不连续且有延迟的。

你可能希望智能体状态在更新过程中**持续**地渲染出来。

参见 **[发出中间状态](/deepagents/shared-state/predictive-state-updates)**。
