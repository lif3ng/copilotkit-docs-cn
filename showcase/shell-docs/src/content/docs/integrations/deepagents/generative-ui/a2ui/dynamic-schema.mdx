---
title: "动态模式 A2UI"
description: LLM 生成的 A2UI——由辅助 LLM 根据任意提示同时生成 schema 与数据。
---
在动态模式（dynamic-schema）方案中，辅助 LLM 根据对话上下文生成完整的 UI——schema、数据和布局。这是最灵活的 A2UI 形态：智能体可以为任意请求渲染任意 UI，而无需预定义的 schema。

## 工作原理

1. 主 LLM 决定调用 `generate_a2ui`
2. 在该工具内部，辅助 LLM 生成一个包含组件、数据和布局的 `render_a2ui` 工具调用
3. 工具调用参数以 `TOOL_CALL_ARGS` 事件的形式流经 LangGraph
4. A2UI 中间件拦截这些事件，并在数据流入时逐步渲染卡片

## 前端 / 运行时

通过 `injectA2UITool: true` 在你的 `CopilotRuntime` 上启用 A2UI：

```typescript title="app/api/copilotkit/route.ts"
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {
    injectA2UITool: true,
  },
});
```

`injectA2UITool: true` 是唯一的开关：它会将决策转发给智能体，从而注入 A2UI 工具。将其设为 `false` 即可完全关闭 A2UI——不会注入任何内容，也不会渲染任何 surface。

在提供方（provider）侧注册你的组件目录（catalog），让 LLM 知道它能绘制什么（catalog 的 `definitions` / `renderers` / `createCatalog` 拆分方式参见 [Bring Your Own Catalog](../../../../generative-ui/a2ui/dynamic-schema)）：

```tsx title="frontend/src/app/page.tsx"
<CopilotKit a2ui={{ catalog: myCatalog }}>
  {/* ... */}
</CopilotKit>
```

## 后端

只需添加 `CopilotKitMiddleware`——当 `injectA2UITool` 开启时，它会自动注入 `generate_a2ui`（基于智能体自身的模型构建）并执行它：

```python title="agent/a2ui_dynamic.py"
from copilotkit import CopilotKitMiddleware
from deepagents import create_deep_agent
from langchain_openai import ChatOpenAI

graph = create_deep_agent(
    model=ChatOpenAI(model="gpt-5.4"),
    tools=[],
    middleware=[CopilotKitMiddleware()],
    system_prompt=(
        "Whenever a response would benefit from a rich visual — a dashboard, "
        "KPI summary, card layout, or chart — call `generate_a2ui` to draw it. "
        "Keep chat replies to one short sentence and let the UI do the talking."
    ),
)
```

系统提示可用于告诉模型*何时*绘图；工具的提供与运行则由中间件完成。

## 渐进式流式传输

辅助 LLM 的 `render_a2ui` 工具调用以 `TOOL_CALL_ARGS` 事件的形式流经 LangGraph。A2UI 中间件会：

1. 在流式传输过程中提取 `components` 数组——先等待完整 schema 到齐再渲染
2. 从部分 JSON 中提取 `surfaceId` 和 `root`
3. schema 完整后，发出 `createSurface` + `updateComponents`
4. 逐步提取完整的 `items` 对象，并为每个对象发出 `updateDataModel`
5. 随着数据流入，卡片逐个出现

## 内置进度指示器

CopilotKit 内置了一个进度指示器，会在 schema 生成期间显示。它会自动出现，并在数据项开始流入后隐藏。

要将其替换为自定义组件，请参见 [Advanced — Custom A2UI Progress Renderer](./advanced#custom-a2ui-progress-renderer) 指南。
