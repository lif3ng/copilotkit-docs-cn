## 这是什么？

MCP Apps 是一类暴露带关联 UI 资源的工具的 MCP 服务器。当智能体调用其中某个工具时，CopilotKit 会自动获取并在聊天中渲染对应的 UI 组件——无需额外的前端代码。

主要优势：
- **零前端代码**——UI 组件由 MCP 服务器提供
- **完整交互性**——组件可以使用 HTML、CSS 和 JavaScript
- **安全沙箱**——内容在隔离的 iframe 中运行
- **线程持久化**——MCP Apps 会存储在会话历史中，并在重新连接时恢复

## 实现

<Steps>
  <Step>
    ### 运行并连接你的智能体
    <RunAndConnect />
  </Step>
  <Step>
    ### 为你的智能体添加 MCP Apps 中间件

    安装中间件包，并通过 `.use()` 将其添加到你的 `LangGraphAgent`：

    ```bash
    npm install @ag-ui/mcp-apps-middleware
    ```

    请使用 `@copilotkit/runtime` 1.76.0 或更高版本。当前中间件版本依赖 `@ag-ui/client` 1.x，运行时 1.76.0 及更高版本已在使用该版本。

    ```typescript title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
    import {
      CopilotRuntime,
      createCopilotRuntimeHandler,
      InMemoryAgentRunner,
    } from "@copilotkit/runtime/v2";
    import { LangGraphAgent } from "@copilotkit/runtime/langgraph"; // [!code highlight]
    import { MCPAppsMiddleware } from "@ag-ui/mcp-apps-middleware"; // [!code highlight]

    const agent = new LangGraphAgent({
      deploymentUrl: process.env.LANGGRAPH_DEPLOYMENT_URL || "http://localhost:8123",
      graphId: "sample_agent",
      langsmithApiKey: process.env.LANGSMITH_API_KEY || "",
    });

    // [!code highlight:10]
    agent.use(
      new MCPAppsMiddleware({
        mcpServers: [
          {
            type: "http",
            url: "https://mcp.excalidraw.com",
            serverId: "excalidraw",
          },
        ],
      }),
    );

    const runtime = new CopilotRuntime({
      agents: { sample_agent: agent },
      runner: new InMemoryAgentRunner(),
    });

    const handler = createCopilotRuntimeHandler({
      runtime,
      basePath: "/api/copilotkit",
    });

    export const GET = handler;
    export const POST = handler;
    ```

    <Callout type="info" title="服务器 ID">
      在生产部署中务必提供 `serverId`。否则，CopilotKit 会根据服务器 URL 生成哈希值。如果你的 URL 发生变化（例如不同环境），会话历史中先前存储的 MCP Apps 将无法正确加载。
    </Callout>

    <Callout type="info" title="使用 Intelligence？">
      在连接到 Intelligence 的运行时上，请改用运行时的 `mcpApps` 选项配置服务器，并用 `intelligence` 代替 `runner`。参见 [MCP Apps with Intelligence](/generative-ui/mcp-apps#mcp-apps-with-intelligence)。
    </Callout>
  </Step>
  <Step>
    ### 试一试！

    就是这样。当智能体使用带有关联 UI 资源的工具时，MCP Apps 会自动渲染。无需修改智能体代码或前端。
  </Step>
</Steps>

## 传输类型

中间件支持两种传输类型：

### HTTP 传输

适用于基于 HTTP 通信的 MCP 服务器：

```typescript
{
  type: "http",
  url: "http://localhost:3101/mcp",
  serverId: "my-http-server"
}
```

### SSE 传输

适用于使用 Server-Sent Events 的 MCP 服务器：

```typescript
{
  type: "sse",
  url: "https://mcp.example.com/sse",
  headers: {
    "Authorization": "Bearer token"
  },
  serverId: "my-sse-server"
}
```
