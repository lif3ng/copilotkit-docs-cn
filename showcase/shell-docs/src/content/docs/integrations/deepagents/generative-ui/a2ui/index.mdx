[A2UI](https://a2ui.org)（Agent-to-UI）是一项由 Google 主导的声明式生成式 UI 规范，CopilotKit 是其发布与设计合作伙伴。它让你的智能体能够使用基于 JSON 的 schema 渲染结构化的 UI 组件。智能体不再发送纯文本，而是生成 surface——卡片、列表、按钮、图片——并以原生方式呈现在聊天中。

你可以使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/) 可视化地设计和预览 A2UI schema。

## 配置

在 CopilotRuntime 中添加 `a2ui: true` 即可启用 A2UI，也可以传入对象进行自定义：

```typescript title="app/api/copilotkit/[[...slug]]/route.ts"
import { CopilotRuntime, InMemoryAgentRunner } from "@copilotkit/runtime/v2";

// Simple — enable with defaults
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: true,
  runner: new InMemoryAgentRunner(),
});

// Or customise — e.g. inject a render tool into the agent
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {
    injectA2UITool: true,
  },
  runner: new InMemoryAgentRunner(),
});
```

这会让运行时将 A2UI 中间件应用到你的智能体。中间件会拦截包含 A2UI 操作的工具结果，并将其渲染为聊天中丰富的 UI surface。

<Callout type="warn">
如果 CopilotRuntime 中没有配置 `a2ui`，A2UI surface 将无法渲染——工具结果会以纯文本形式显示。
</Callout>

## 实现方式

CopilotKit 支持三种 A2UI 实现方式，各有不同的取舍：

- **[Fixed Schema](./fixed-schema)**——预定义的 schema 从 JSON 加载。智能体只提供数据。最快——无需 LLM 生成 schema。
- **[Fixed Schema (Streaming)](./fixed-schema)**——同样的预定义 schema，但卡片会随着 LLM 流式输出数据逐个出现。非常适合列表。
- **[Dynamic Schema](./dynamic-schema)**——由辅助 LLM 同时生成 schema 和数据。完全灵活——任意提示生成任意 UI。

## 如何选择？

| 实现方式 | schema 来源 | 渲染方式 | 最适合 |
|---|---|---|---|
| **Fixed Schema** | JSON 文件 | 即时（一次性全部呈现） | 已知的 UI 模式（航班卡片、商品列表） |
| **Fixed Schema Streaming** | JSON 文件 | 渐进式（逐卡呈现） | 希望立即看到反馈的长列表 |
| **Dynamic Schema** | LLM 生成 | 渐进式（逐卡呈现） | 未知/多变的 UI——由智能体决定展示什么 |

<Callout type="info">
三种方式使用相同的 A2UI 协议和渲染器。区别在于 schema 的来源以及数据到达客户端的方式。
</Callout>

## 工作原理

每个 A2UI v0.9 surface 都由三个操作构成：

1. **`createSurface`**——用组件目录初始化 surface（必须最先执行）
2. **`updateComponents`**——定义组件树（即 schema）
3. **`updateDataModel`**——提供填充组件的数据

CopilotKit Python SDK 提供了构建这些操作的辅助函数：

```python
from copilotkit import a2ui

a2ui.create_surface(surface_id)
a2ui.update_components(surface_id, components)
a2ui.update_data_model(surface_id, {"items": data})
a2ui.render(operations)  # wraps in a2ui_operations and serializes
```
