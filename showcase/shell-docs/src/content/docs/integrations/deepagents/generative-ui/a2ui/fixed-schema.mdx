---
title: "固定模式 A2UI"
description: 预定义 A2UI schema 配合动态数据——最快的方式，无需 LLM 生成 schema。
---
在固定模式（fixed-schema）方案中，你只需设计一次 UI schema（写成 JSON 文件，或使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/)），而智能体工具只负责提供数据。工具返回时，surface 会立即呈现。

## 工作原理

1. schema 在启动时从 JSON 文件加载
2. 智能体工具从 LLM 接收数据（例如航班搜索结果）
3. 工具返回带有 createSurface + updateComponents + updateDataModel 的 `a2ui.render()`
4. A2UI 中间件拦截工具结果并渲染 surface

## 实现

<Steps>
<Step>
### 创建 A2UI schema

使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/) 设计你的 schema，或者手写。将其保存为 JSON 文件：

```
apps/agent/src/a2ui/schemas/flight_schema.json
```
</Step>

<Step>
### 定义智能体工具（Python）

```python title="apps/agent/src/a2ui_fixed_schema.py"
from copilotkit import a2ui
from langchain.tools import tool
from pathlib import Path
from typing import TypedDict

class Flight(TypedDict):
    id: str
    airline: str
    airlineLogo: str
    flightNumber: str
    origin: str
    destination: str
    date: str
    departureTime: str
    arrivalTime: str
    duration: str
    status: str
    statusIcon: str
    price: str

SURFACE_ID = "flight-search-results"
FLIGHT_SCHEMA = a2ui.load_schema(
    Path(__file__).parent / "a2ui" / "schemas" / "flight_schema.json"
)


@tool
def search_flights(flights: list[Flight]) -> str:
    """Search for flights and display results as rich cards."""
    return a2ui.render(
        operations=[
            a2ui.create_surface(SURFACE_ID),
            a2ui.update_components(SURFACE_ID, FLIGHT_SCHEMA),
            a2ui.update_data_model(SURFACE_ID, {"flights": flights}),
        ],
    )
```

要点：
- `Flight` TypedDict 至关重要——LangChain 会将其序列化到工具的 JSON schema 中，LLM 在决定生成什么数据时看到的就是它。
- Python SDK 的 `a2ui.render` 尚不支持 `action_handlers=` 关键字，因此本示例保留了按钮 schema，但未声明服务端处理器。按钮点击会转发给智能体，但本示例没有针对它们的服务端处理器。
- `"book_flight"` 是 schema 按钮使用的操作名称，可通过 [Advanced — Action Handlers](./advanced#action-handlers) 指南中的前端 API 来处理。
</Step>

<Step>
### 注册工具

```python title="apps/agent/main.py"
from deepagents import create_deep_agent
from src.a2ui_fixed_schema import search_flights

agent = create_deep_agent(
    tools=[search_flights, ...],
    ...
)
```
</Step>

<Step>
### 配置运行时（TypeScript）

在 CopilotRuntime 中启用 A2UI，但禁用注入的 `generate_a2ui` 工具。后端的 `search_flights` 工具拥有这个固定模式的 surface；A2UI 中间件仍会渲染其 `a2ui.render()` 结果：

```typescript title="app/api/copilotkit/route.ts"
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {
    injectA2UITool: false,
  },
});
```
</Step>
</Steps>

## 操作处理器详情

当前的 Python SDK 不支持 `action_handlers=` 选项。按钮 schema 仍可定义供前端处理器使用的操作上下文。schema 侧的写法如下：

### 带操作上下文的按钮

在 `flight_schema.json` 中，按钮声明一个带有数据绑定上下文字段的 `action`。点击时，这些值会从对应卡片的数据中解析出来：

```json
{
  "id": "book-button",
  "component": "Button",
  "child": "book-label",
  "variant": "primary",
  "action": {
    "event": {
      "name": "book_flight",
      "context": {
        "flightNumber": { "path": "flightNumber" },
        "price": { "path": "price" }
      }
    }
  }
}
```

当在显示航班 AA100、价格 $350 的卡片上点击该按钮时，前端操作处理会收到 `context: { flightNumber: "AA100", price: "$350" }`。Python 的 `action_handlers=` 路径尚未支持。

<Callout type="info">
要了解如何使用 `createA2UIMessageRenderer` 及其 `onAction` 选项进行自定义前端处理，请参见 [Advanced — Action Handlers](./advanced#action-handlers) 指南。
</Callout>
