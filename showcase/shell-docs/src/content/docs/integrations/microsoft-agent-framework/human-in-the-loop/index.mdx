## 什么是人机协同（HITL）？

人机协同（human-in-the-loop，HITL）让智能体在运行过程中请求人类输入或批准。当某个操作代价高昂、具有破坏性，或需要智能体不具备的判断力时，就可以使用它。

## 如何使用它？

Microsoft Agent Framework 支持两种模式，它们解决的问题各不相同。

当决策由后端掌控时，使用**基于中断**的人机协同。你把一个后端工具标记为需要审批（approval-gated），智能体在执行它之前会先暂停。前端无需知道该工具的名称。

当工作由前端掌控时，使用**基于工具**的人机协同。你定义一个在浏览器中运行的工具，智能体像调用其他工具一样调用它。
