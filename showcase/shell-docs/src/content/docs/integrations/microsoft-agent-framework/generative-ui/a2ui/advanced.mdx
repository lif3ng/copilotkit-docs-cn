## 概览

`useDefaultRenderTool` 是 `useRenderTool` 以 `name: "*"` 调用时的便捷包装器。

它属于 v2 工具渲染 Hook 套件，同套件的还有 [`useComponent`](/reference/hooks/useComponent)、[`useRenderTool`](/reference/hooks/useRenderTool) 与 [`useRenderToolCall`](/reference/hooks/useRenderToolCall)。

- 不传配置时，它注册的是 CopilotKit 内置的默认工具调用 UI。
- 传入 `render` 时，它会用你自己的通配渲染器替换该默认 UI。

当工具调用没有具名渲染器时，可以用它来做兜底渲染。

## 签名

```tsx
import { useDefaultRenderTool } from "@copilotkit/react-core/v2";

function useDefaultRenderTool(
  config?: {
    render?: (props: {
      name: string;
      parameters: any;
      status: string;
      result: string | undefined;
    }) => React.ReactElement | null;
    group?: boolean;
  },
  deps?: ReadonlyArray<unknown>,
): void;
```

## 行为

- 内部调用 `useRenderTool({ name: "*", ... })`。
- 如果省略 `config.render`，则使用可展开的默认卡片 UI，展示状态、参数与结果。
- 如果提供了 `config.render`，则改用你的渲染器。
- 你的渲染器可以返回 `null`，表示不绘制任何内容。可以用它只渲染你关心的工具调用，并隐藏其余调用。
- `config.group` 允许聊天界面把你的渲染器绘制的调用编组，方式与内置卡片的编组一致（参见 [`toolCallDisplay`](/reference/components/CopilotChatMessageView#toolcalldisplay)）。内置卡片默认开启该选项，而自定义 `render` 默认关闭，因为什么都不绘制的渲染器会留下一个空组。
- 继承 `useRenderTool` 的注册行为与依赖语义。
- 智能体连续发起的工具调用默认会被编组（参见 [`toolCallDisplay`](/reference/components/CopilotChatMessageView#toolcalldisplay)）。在组内，内置卡片会把自己绘制成紧凑的一行：状态、工具名称与主要参数，展开后显示参数与结果。自定义 `render` 则在组内按原样绘制。

## 用法

### 内置默认渲染器

```tsx
function App() {
  useDefaultRenderTool();
  return null;
}
```

### 自定义通配渲染器

```tsx
function App() {
  useDefaultRenderTool(
    {
      render: ({ name, status, result }) => (
        <div>
          <strong>{name}</strong>: {status}
          {status === "complete" && result ? <pre>{result}</pre> : null}
        </div>
      ),
    },
    [],
  );

  return null;
}
```
