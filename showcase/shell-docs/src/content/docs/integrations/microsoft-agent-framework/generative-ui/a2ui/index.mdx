[A2UI](https://a2ui.org)（Agent-to-UI）是一项由 Google 主导、CopilotKit 作为发布与设计合作伙伴的声明式生成式 UI 规范。它让你的智能体能够使用基于 JSON 的 schema 渲染结构化的 UI 组件。智能体不再发送纯文本，而是产出 surface——卡片、列表、按钮、图片——并在聊天中原生渲染。

你可以使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/) 以可视化的方式设计和预览 A2UI schema。

## 配置

在 CopilotRuntime 中添加 `a2ui: true` 即可启用 A2UI，也可以传入一个对象进行自定义：

```typescript title="app/api/copilotkit/route.ts"
import { CopilotRuntime } from "@copilotkit/runtime";

// Simple — enable with defaults
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: true,
});

// Or customise — e.g. inject a render tool into the agent
const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {
    injectA2UITool: true,
  },
});
```

这会告诉运行时对你的智能体应用 A2UI 中间件。该中间件会拦截包含 A2UI 操作的工具结果，并将它们作为丰富的 UI surface 渲染在聊天中。

<Callout type="warn">
如果 CopilotRuntime 中没有配置 `a2ui`，A2UI surface 将不会渲染——工具结果会以纯文本形式出现。
</Callout>

## 实现方案

CopilotKit 支持两种 A2UI 实现方案，各有不同的取舍：

- **[固定模式](./fixed-schema)**——预定义的 schema 从 JSON 加载。智能体只提供数据。最快——无需 LLM 生成 schema。
- **[动态模式](./dynamic-schema)**——由辅助 LLM 同时生成 schema 与数据。完全灵活——任意提示都能生成任意 UI。

## 如何选择？

| 方案 | Schema 来源 | 渲染方式 | 最适合 |
|---|---|---|---|
| **固定模式** | JSON 文件 | 即时（一次性全部呈现） | 已知的 UI 模式（航班卡片、商品列表） |
| **动态模式** | LLM 生成 | 渐进式（逐卡呈现） | 未知/多变的 UI——由智能体决定展示什么 |

<Callout type="info">
两种方案使用相同的 A2UI 协议和渲染器。区别在于 schema 的来源，以及数据如何到达客户端。
</Callout>

## 工作原理

每个 A2UI v0.9 surface 都由三个操作构成：

1. **`createSurface`**——用目录初始化 surface（必须排在第一位）
2. **`updateComponents`**——定义组件树（即 schema）
3. **`updateDataModel`**——提供填充组件所需的数据

包装在 `a2ui_operations` 容器中时，这些操作如下所示：

```python
{
    "a2ui_operations": [
        {"version": "v0.9", "createSurface": {"surfaceId": ..., "catalogId": ...}},
        {"version": "v0.9", "updateComponents": {"surfaceId": ..., "components": [...]}},
        {"version": "v0.9", "updateDataModel": {"surfaceId": ..., "path": "/", "value": {...}}},
    ]
}
```

固定模式下，你的工具直接返回这个容器；动态模式下，`agent-framework-ag-ui` 适配器会为你构建它。
