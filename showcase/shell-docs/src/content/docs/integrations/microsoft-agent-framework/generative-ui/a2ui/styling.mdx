---
title: "样式定制"
description: "使用 CSS 自定义属性、字体和组件级覆盖来自定义 A2UI surface 的外观。"
---
A2UI surface 支持通过限定在 `.a2ui-surface` 类作用域内的 CSS 自定义属性进行主题定制。

## 主题 CSS

创建一个主题文件，并在布局中导入：

```css title="src/a2ui/theme.css"
.a2ui-surface {
  --primary: #111111;
  --primary-foreground: #ffffff;
  --card: #ffffff;
  --border: #e0e0e0;
  --radius: 12px;
  --foreground: #111111;
  --input: #d4d4d4;
  --background: #fafafa;
}
```

```tsx title="src/app/layout.tsx"
import "@/a2ui/theme.css";
```

## CSS 自定义属性参考

| 变量 | 默认值 | 说明 |
|---|---|---|
| `--primary` | — | 主强调色（按钮、链接） |
| `--primary-foreground` | — | 主色背景上的文字颜色 |
| `--card` | — | 卡片背景色 |
| `--border` | — | 卡片、分隔线、输入框的边框颜色 |
| `--radius` | — | 卡片和按钮的圆角 |
| `--foreground` | — | 默认文字颜色 |
| `--input` | — | 输入框边框颜色 |
| `--background` | — | surface 背景色 |

<Callout type="info">
这些变量的作用域限定在 `.a2ui-surface`——不会影响应用的其他部分。如果想要全局默认值，也可以在 `:root` 上设置它们。
</Callout>

## 自定义字体

在 surface 容器上覆盖字体系列：

```css title="src/a2ui/theme.css"
@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap');

.a2ui-surface {
  font-family: "Plus Jakarta Sans", -apple-system, BlinkMacSystemFont, system-ui, sans-serif !important;
  letter-spacing: -0.01em;
}
```

## 图片尺寸

A2UI surface 会按 Image 组件的自然尺寸渲染。为了让布局保持一致（例如航空公司徽标、头像），可以用 CSS 约束图片尺寸：

```css title="src/a2ui/theme.css"
/* Constrain logos and avatars */
.a2ui-surface img {
  max-width: 28px;
  max-height: 28px;
  border-radius: 4px;
}

/* Smaller status indicator icons */
.a2ui-surface img[alt="On Time"],
.a2ui-surface img[alt="Delayed"] {
  max-width: 10px;
  max-height: 10px;
  border-radius: 50%;
}
```

## 卡片宽度

逐张流式渲染卡片时，单张卡片可能会收缩到很窄的宽度。请设置一个最小宽度：

```css title="src/a2ui/theme.css"
.a2ui-surface .a2ui-card {
  min-width: 280px;
}
```

## 深色模式

通过类名或媒体查询适配深色模式：

```css title="src/a2ui/theme.css"
.dark .a2ui-surface,
@media (prefers-color-scheme: dark) {
  .a2ui-surface {
    --primary: #e5e5e5;
    --primary-foreground: #111111;
    --card: #1a1a1a;
    --border: #333333;
    --foreground: #e5e5e5;
    --input: #444444;
    --background: #111111;
  }
}
```

## 完整示例

下面是一个整合了上述所有模式的完整主题文件：

```css title="src/a2ui/theme.css"
@import url('https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap');

.a2ui-surface {
  /* Colors */
  --primary: #111111;
  --primary-foreground: #ffffff;
  --card: #ffffff;
  --border: #e0e0e0;
  --radius: 12px;
  --foreground: #111111;
  --input: #d4d4d4;
  --background: #fafafa;

  /* Typography */
  font-family: "Plus Jakarta Sans", -apple-system, BlinkMacSystemFont, system-ui, sans-serif !important;
  letter-spacing: -0.01em;
}

/* Image constraints */
.a2ui-surface img {
  max-width: 28px;
  max-height: 28px;
  border-radius: 4px;
}

/* Streaming card width */
.a2ui-surface .a2ui-card {
  min-width: 280px;
}
```
