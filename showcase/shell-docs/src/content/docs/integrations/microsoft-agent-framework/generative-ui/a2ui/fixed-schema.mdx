---
title: "固定模式 A2UI"
description: "预定义的 A2UI schema 搭配动态数据——最快的方式，无需 LLM 生成 schema。"
---
在固定模式（fixed schema）方案中，你只需设计一次 UI schema（放在 JSON 文件里，或使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/) 设计），而智能体工具只需提供数据。工具返回时，surface 会立即呈现。

## 工作原理

1. schema 在启动时从 JSON 文件加载
2. 智能体工具从 LLM 接收数据（例如航班搜索结果）
3. 工具返回一个包含 createSurface + updateComponents + updateDataModel 的 `a2ui_operations` 容器
4. A2UI 中间件拦截工具结果并渲染 surface

## 实现

<Steps>
<Step>
### 创建 A2UI schema

使用 [A2UI Composer](https://a2ui-composer.ag-ui.com/) 设计你的 schema，或者手写。将它保存为 JSON 文件：

```
apps/agent/src/a2ui/schemas/flight_schema.json
```
</Step>

<Step>
### 定义智能体工具（Python）

```python title="src/agents/a2ui_fixed.py"
import json
from pathlib import Path
from typing import Annotated

from agent_framework import tool
from pydantic import Field

CATALOG_ID = "copilotkit://flight-fixed-catalog"
SURFACE_ID = "flight-fixed-schema"

FLIGHT_SCHEMA = json.load(
    open(Path(__file__).parent / "a2ui_schemas" / "flight_schema.json")
)


@tool(name="display_flight", description="Show a flight card for the given trip.")
def display_flight(
    origin: Annotated[str, Field(description="3-letter origin code, e.g. 'SFO'.")],
    destination: Annotated[str, Field(description="3-letter destination code.")],
    airline: Annotated[str, Field(description="Airline name.")],
    price: Annotated[str, Field(description="Price string, e.g. '$289'.")],
) -> str:
    """Show a flight card for the given trip."""
    ops = [
        {"version": "v0.9", "createSurface": {"surfaceId": SURFACE_ID, "catalogId": CATALOG_ID}},
        {"version": "v0.9", "updateComponents": {"surfaceId": SURFACE_ID, "components": FLIGHT_SCHEMA}},
        {"version": "v0.9", "updateDataModel": {"surfaceId": SURFACE_ID, "path": "/", "value": {"origin": origin, "destination": destination, "airline": airline, "price": price}}},
    ]
    return json.dumps({"a2ui_operations": ops})
```

要点：
- `Annotated` + `Field` 参数必不可少——Microsoft Agent Framework 会把它们序列化进工具的 JSON schema，而 LLM 在决定生成什么数据时看到的就是这份 schema。
- 该工具手动构建 `a2ui_operations` 容器，且没有声明服务端操作处理器。按钮点击会被转发给智能体，但本示例中没有针对它们的服务端处理器。
- `"book_flight"` 是 schema 按钮使用的操作名称，可以通过[高级——操作处理器](./advanced#action-handlers)指南中的前端 API 来处理。
</Step>

<Step>
### 注册工具

```python title="src/agents/a2ui_fixed.py"
from agent_framework import Agent
from agent_framework_ag_ui import AgentFrameworkAgent

base_agent = Agent(
    client=chat_client,
    name="a2ui_fixed_agent",
    instructions="You help users find flights. Call `display_flight` with origin, destination, airline, and price.",
    tools=[display_flight],
)

agent = AgentFrameworkAgent(agent=base_agent)
```
</Step>

<Step>
### 配置运行时（TypeScript）

在 CopilotRuntime 中启用 A2UI。中间件会自动检测任何工具结果中的 A2UI 操作，因此这里无需注入工具——智能体的 `display_flight` 工具会直接返回它们。

```typescript title="app/api/copilotkit-a2ui-fixed-schema/route.ts"
const runtime = new CopilotRuntime({
  agents: { "a2ui-fixed-schema": fixedSchemaAgent },
  a2ui: {
    injectA2UITool: false,
  },
});
```
</Step>
</Steps>

## 操作处理器详情

当前的 Python SDK 尚不支持 `action_handlers=` 选项。不过按钮 schema 仍然可以定义前端处理器所使用的操作上下文。schema 一侧的写法如下：

### 带操作上下文的按钮

在 `flight_schema.json` 中，按钮会声明一个带有数据绑定上下文字段的 `action`。点击时，这些值会从该卡片的具体数据中解析出来：

```json
{
  "id": "book-button",
  "component": "Button",
  "child": "book-label",
  "variant": "primary",
  "action": {
    "event": {
      "name": "book_flight",
      "context": {
        "flightNumber": { "path": "flightNumber" },
        "price": { "path": "price" }
      }
    }
  }
}
```

当在显示 AA100 航班（价格 $350）的卡片上点击该按钮时，前端操作处理会收到 `context: { flightNumber: "AA100", price: "$350" }`。Python 的 `action_handlers=` 路径目前尚不受支持。

<Callout type="info">
要了解如何通过 `createA2UIMessageRenderer` 及其 `onAction` 选项进行自定义前端处理，请参阅[高级——操作处理器](./advanced#action-handlers)指南。
</Callout>
