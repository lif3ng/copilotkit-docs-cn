title: 代码贡献
---

感谢你有兴趣为 CopilotKit 做出贡献。我们欢迎新贡献者，也感谢你帮助 CopilotKit 变得更好。

本指南将帮助你尽可能顺利地上手。

## 步骤 1：安装前置条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- 全局安装的 [pnpm](https://pnpm.io/) v10.x（`npm i -g pnpm@^10`）

## 步骤 2：仓库设置

<Steps>
  <Step>
  ### Fork 仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit)并创建一个 Fork。

  然后，将你的 Fork 克隆到本地：
  ```bash
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit
  ```
  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是一个使用 [pnpm](https://pnpm.io/) workspace 的 monorepo。跨软件包的任务由 [Nx](https://nx.dev/) 编排。
  </Callout>

  使用 pnpm 安装依赖：
  ```bash
  pnpm install
  ```
  </Step>
  <Step>
  ### 构建软件包
  为了确保一切正常，先把所有软件包构建一遍：
  ```bash
  pnpm run build
  ```
  </Step>
</Steps>

## 步骤 3：开发模式
一切就绪并正常工作后，就可以开始开发了：

```bash
# 以开发模式启动所有软件包
pnpm run dev

# 以开发模式启动指定软件包
pnpm exec nx watch --projects=packages/package-name -- pnpm run build
```

现在就可以开始修改代码了。

<Callout type="info">
所有 `@copilotkit/*` 软件包都位于 monorepo 的 `packages` 文件夹下。
</Callout>

## 步骤 4：实时测试更改

大多数情况下，你都希望在开发过程中能够无缝地实时测试自己的更改。

monorepo 中有一个 `examples` 文件夹，包含若干使用 CopilotKit 的示例。这些示例与 monorepo 中的 `@copilotkit/*` 软件包相互链接，你可以运行它们来测试自己的更改。

在本教程中，我们将使用 `next-openai` 示例，具体来说是 Presentation Demo（`/presentation`）。

在另一个终端中运行以下命令来启动该示例：

```bash
cd examples/v1/next-openai
export OPENAI_API_KEY=<your-openai-api-key>
pnpm run example-dev
```

<Callout type="info">
我们使用 `pnpm run example-dev` 命令来运行示例，它与开发各个软件包时使用的 `pnpm run dev` 命令不同。
</Callout>

现在访问 http://localhost:3000/presentation，应该就能看到示例在运行。你对 CopilotKit 软件包所做的任何更改都会立即反映在这里。

## 步骤 5：格式化与 Lint 检查

在提交更改之前，请在 monorepo 根目录运行以下命令，确保文件已正确格式化：
```bash
pnpm run format
```

此外，还要确保没有任何 Lint 错误：
```bash
pnpm run lint
```

## 步骤 6：提交 Pull Request

完成更改后，将其 commit 并 push。然后只需前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls)创建一个 pull request 即可。干得漂亮！

## 调试

每次在 localhost 上运行 CopilotKit 时，你都可以在聊天窗口中看到 **CopilotKit Dev Console**。Dev Console 提供了实用的调试功能，帮助你调试 copilot（例如查看 copilot 感知到的状态、它可以执行的操作等）。

<Frame description="CopilotKit Dev Console">
  <img
    src="https://cdn.copilotkit.ai/docs/copilotkit/images/contributing/copilotkit-dev-console.png"
    className="w-auto max-w-[420px]"
  />
</Frame>

如果想在本地禁用 Dev Console，只需在你的 `<CopilotKit />` provider 中将 `showDevConsole` 设置为 `false`。

## 进阶：软件包链接

某些情况下，你可能想在自己的项目中测试对 CopilotKit 的更改。例如，你尝试将 CopilotKit 集成到自己的代码库中时遇到了一个 bug，想要修复它。

方便的是，你可以将本地的 CopilotKit 软件包链接到自己的项目来测试更改。

请查阅[进阶：软件包链接](/contributing/code-contributions/package-linking)指南了解具体做法。
