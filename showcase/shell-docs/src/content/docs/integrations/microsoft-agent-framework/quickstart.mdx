## 从你的编码智能体开始

使用此提示词将你的 Microsoft Agent Framework 智能体连接到 CopilotKit，并验证对话正常工作。你的编码智能体会在你的项目中按照本指南操作，你也可以跟着下面的手动步骤一步步来。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- [OpenAI API 密钥](https://platform.openai.com/api-keys)，.NET 起步模板需要
- .NET 9.0 SDK 或更高版本
- Node.js 20+
- 你喜欢的包管理器（npm、pnpm、yarn 或 bun）

                ### 运行我们的 CLI

                ```bash
                npx copilotkit@latest create
                ```

                ### 启动你的 Microsoft Agent Framework 智能体

                确保你的智能体正在运行并暴露了一个 AG-UI 端点。下面是一个最简示例：

                <Tabs groupId="language_microsoft-agent-framework_agent" items={['.NET', 'Python']} persist>
                    <Tab value=".NET">
                        首先，创建一个新的 .NET 项目：
                        ```bash
                        dotnet new web -n AGUIServer
                        cd AGUIServer
                        dotnet add package Microsoft.Agents.AI.Hosting.AGUI.AspNetCore --version 1.19.0-preview.260822.1
                        dotnet add package Microsoft.Agents.AI.OpenAI --version 1.19.0
                        dotnet user-secrets init
                        ```

                        构建一个最简智能体并通过 AG-UI 提供服务：

                        ```csharp title="Program.cs"
                        using Microsoft.Agents.AI;
                        // [!code highlight:1]
                        using Microsoft.Agents.AI.Hosting.AGUI.AspNetCore;
                        using OpenAI;
                        using OpenAI.Chat;

                        var builder = WebApplication.CreateBuilder(args);
                        // [!code highlight:1]
                        builder.Services.AddAGUIServer();
                        var app = builder.Build();

                        var openAiApiKey = builder.Configuration["OPENAI_API_KEY"]
                            ?? throw new InvalidOperationException("Set OPENAI_API_KEY");
                        var openAI = new OpenAIClient(openAiApiKey);

                        var agent = openAI.GetChatClient("gpt-5.4-mini").AsAIAgent(
                            name: "MyAgent",
                            instructions: "You are a helpful assistant.");

                        // [!code highlight:1]
                        app.MapAGUIServer("/", agent);
                        app.Run("http://localhost:8000");
                        ```

                        设置密钥，然后运行智能体：

                        ```bash
                        dotnet user-secrets set OPENAI_API_KEY "<your-openai-api-key>"
                        dotnet run
                        ```
                    </Tab>
                    <Tab value="Python">

                        创建一个 Python 项目

                        ```bash
                        uv init my-agent
                        cd my-agent
                        uv add agent-framework-ag-ui python-dotenv uvicorn agent-framework-openai
                        ```
                        创建一个最简 FastAPI 服务端，通过 AG-UI 暴露一个 Microsoft Agent Framework 智能体：
                        将 main.py 文件替换为以下内容

                        ```python title="main.py"
                        from __future__ import annotations
                        import os
                        import uvicorn
                        from agent_framework import Agent
                        from agent_framework.openai import OpenAIChatClient
                        from agent_framework.ag_ui import add_agent_framework_fastapi_endpoint
                        from azure.identity import DefaultAzureCredential
                        from dotenv import load_dotenv
                        from fastapi import FastAPI

                        load_dotenv()

                        def _build_chat_client():
                            if os.getenv("AZURE_OPENAI_ENDPOINT"):
                                azure_api_key = os.getenv("AZURE_OPENAI_API_KEY")
                                return OpenAIChatClient(
                                    model=os.getenv("AZURE_OPENAI_CHAT_DEPLOYMENT_NAME", "gpt-4o-mini"),
                                    api_key=azure_api_key,
                                    credential=None if azure_api_key else DefaultAzureCredential(),
                                    azure_endpoint=os.getenv("AZURE_OPENAI_ENDPOINT"),
                                )
                            if os.getenv("OPENAI_API_KEY"):
                                return OpenAIChatClient(
                                    model=os.getenv("OPENAI_CHAT_MODEL_ID", "gpt-4o-mini"),
                                    api_key=os.getenv("OPENAI_API_KEY"),
                                )
                            raise RuntimeError(
                                "Set AZURE_OPENAI_ENDPOINT (uses az login unless AZURE_OPENAI_API_KEY is set) or OPENAI_API_KEY."
                            )

                        chat_client = _build_chat_client()

                        agent = Agent(
                            name="MyAgent",
                            instructions="You are a helpful assistant.",
                            client=chat_client,
                        )

                        app = FastAPI(title="Microsoft Agent Framework - Quickstart")
                        add_agent_framework_fastapi_endpoint(app=app, agent=agent, path="/")

                        if __name__ == "__main__":
                            uvicorn.run("main:app", host="0.0.0.0", port=8000, reload=True)
                        ```

                        然后设置你的环境并运行：

                        ```bash
                        # OpenAI（agent/.env）
                        OPENAI_API_KEY=sk-...your-openai-key-here...
                        OPENAI_CHAT_MODEL_ID=gpt-5.4-mini
                        # 或 Azure OpenAI（agent/.env）
                        AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
                        AZURE_OPENAI_CHAT_DEPLOYMENT_NAME=gpt-5.4-mini
                        # az login 不可用时的可选项：
                        # AZURE_OPENAI_API_KEY=...

                        # 运行智能体
                        uv run main.py
                        ```

            <Step>
                ### 设置 Copilot Runtime

                CopilotKit 需要一个 Copilot Runtime 端点来与你的智能体安全通信。它可以部署在任何能运行 Node.js 的地方，但本例中我们使用 Next.js。

                在 `app/api/copilotkit/[[...slug]]/route.ts` 创建一个新的 API 路由：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { HttpAgent } from "@ag-ui/client";

                // 1. You can use any service adapter here for multi-agent support. We use
                //    the empty adapter since we're only using one agent.

                // 2. Create the CopilotRuntime instance and utilize the Microsoft Agent Framework
                //    AG-UI integration to setup the connection.
                // [!code highlight:5]
                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                // 3. Build a Next.js API route that handles the CopilotKit runtime requests.
                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                ```

                在这个前端应用目录下，将运行时连接到一个 Intelligence 项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会把服务端项目 API 密钥写入 `.env`。运行时在此处读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用 Intelligence 平台运行？">
                  去掉 `intelligence` 与 `identifyUser` 选项，运行时就会回退到使用内存运行器的 SSE 模式。聊天仍可工作，但 Threads 与
                  Inspector 将保持锁定，密钥也永远不会被读取。完整构造参数以及如何确认密钥已生效，请参阅
                  [将你的运行时连接到 Intelligence](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                接下来，用 CopilotKit provider 包裹你的应用，让 CopilotKit 能够通过 Microsoft Agent Framework 智能体接管整个应用。

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此它改为渲染你的客户端文件：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="info" title="此相对 runtimeUrl 假定由 Next.js 提供运行时服务">
                  `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源同时提供你的应用与运行时。纯客户端前端没有共享源，因此它需要
                  一个自己独立的运行时服务端，以及一个绝对的 `runtimeUrl`，例如
                  `http://localhost:8200/api/copilotkit`。`/react-spa`、`/vue`、
                  `/angular` 和 `/react-native` 的各前端指南都展示了这种配置。
                </Callout>
            </Step>

            <Accordion title="故障排查">
                **智能体连接问题**
                - 如果你看到 “I'm having trouble connecting to my tools”，请确认：
                  - C# 智能体正在端口 8000 上运行
                  - 你的 OpenAI API 密钥已通过 .NET user secrets 设置
                  - 两个服务端都已成功启动（检查终端输出）

                **OpenAI API 密钥问题**
                - 如果智能体报错 “OPENAI_API_KEY not found”：
                  ```bash
                  cd agent
                  dotnet user-secrets set OPENAI_API_KEY "<your-openai-api-key>"
                  ```

                **.NET SDK 问题**
                - 验证 .NET SDK 是否已安装：
                  ```bash
                  dotnet --version  # 应为 9.0.x 或更高
                  ```
                - 如有需要，手动还原包：
                  ```bash
                  cd agent
                  dotnet restore
                  dotnet run
                  ```

                **端口冲突**
                - 如果端口 8000 已被占用，你可以在以下位置修改：
                  - `agent/Properties/launchSettings.json` —— 更新 `applicationUrl`
                  - `src/app/api/copilotkit/route.ts` —— 更新远端端点 URL
