## 什么是人机协同（HITL）？

人机协同（human-in-the-loop，HITL）允许智能体在执行过程中请求人类输入或批准，使 AI 系统更加可靠、可信。在构建需要处理复杂决策、或需要执行依赖人类判断的动作的 AI 应用时，这一模式至关重要。

<Callout type="info" title="对话式 Flow">
  在对话模式下，前端 HITL API 保持不变。对于原生的 `useInterrupt` 流程，除了
  `conversational=True` 之外，注册 AG-UI 端点时还需设置
  `emit_interrupt_outcome=True` 和
  `enable_legacy_on_interrupt_event=False`。
</Callout>

## 什么时候该用它？

HITL 将 AI 的效率与人类的判断相结合，打造出既强大又可靠的系统。主要优势包括：

- **质量控制**：在关键决策点上进行人工监督
- **边界情况**：从容应对低置信度的场景
- **专家输入**：在需要时借助人类的专业知识
- **可靠性**：面向真实场景的更健壮的系统
