# 理解线程持久化

CrewAI Flows 支持线程（threads），这是一种将消息分组在一起并在会话之间维持连续聊天历史的机制。CopilotKit 提供了相应机制，确保对话状态在前端与后端之间正确持久化。

本指南假定你已经阅读过[快速开始](/crewai-flows/quickstart)指南。

<Callout>
  **注意**：虽然前端使用 `threadId` 管理对话会话，但真正跨会话的持久化需要后端配置。后端智能体需要实现一种持久化机制（例如[消息持久化](/crewai-flows/persistence/message-persistence)中展示的那样），以保存和加载与每个 `threadId` 关联的状态。

具体示例请参阅[示例智能体实现](https://github.com/CopilotKit/CopilotKit/blob/main/examples/coagents-starter-crewai-flows/agent-py/sample_agent/agent.py#L291)。

</Callout>

## 前端：设置 ThreadId

### 加载现有线程

要在 CopilotKit 中加载现有线程，请在 `<CopilotKit>` 上设置 `threadId` 属性：

```tsx
<CopilotKit threadId="37aa68d0-d15b-45ae-afc1-0ba6c3e11353">
  <YourApp />
</CopilotKit>
```

### 动态切换线程

你可以让 `threadId` 动态变化。一旦设置，CopilotKit 就会加载该线程之前的消息。

```tsx
const Page = () => {
  const [threadId, setThreadId] = useState(
    "af2fa5a4-36bd-4e02-9b55-2580ab584f89",
  );
  return (
    <CopilotKit threadId={threadId}>
      <YourApp setThreadId={setThreadId} />
    </CopilotKit>
  );
};

const YourApp = ({ setThreadId }) => {
  return (
    <Button onClick={() => setThreadId("679e8da5-ee9b-41b1-941b-80e0cc73a008")}>
      Change Thread
    </Button>
  );
};
```
