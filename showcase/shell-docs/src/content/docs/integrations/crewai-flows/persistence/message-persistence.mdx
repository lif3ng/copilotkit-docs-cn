<Callout>
  要了解如何加载之前的消息与智能体状态，请查阅[加载消息历史](/crewai-flows/persistence/loading-message-history)与[加载智能体状态](/crewai-flows/persistence/loading-agent-state)页面。
</Callout>

要将 CrewAI Flow 消息持久化到数据库，你可以使用 `@persist` 装饰器。例如，可以使用默认的 `SQLiteFlowPersistence`，也可以提供你自己的自定义持久化类。

<Callout type="info" title="对话式 Flow 会话">
  无需单独的 CopilotKit 持久化适配器。CopilotKit 的 `threadId` 会成为 CrewAI 的 `session_id`，因此 CrewAI 的 `@persist` 支持会存储并恢复相应的对话会话。
</Callout>

有关如何实现 `InMemoryFlowPersistence` 这类自定义持久化类，并将其与 `@persist` 装饰器配合使用的具体示例，请参阅[示例智能体实现](https://github.com/CopilotKit/CopilotKit/blob/main/examples/coagents-starter-crewai-flows/agent-py/sample_agent/agent.py)。

更多关于持久化的内容，请阅读 [CrewAI Flows 文档](https://docs.crewai.com/concepts/flows#class-level-persistence)。
