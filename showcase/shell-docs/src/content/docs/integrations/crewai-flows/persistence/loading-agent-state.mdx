### 设置 threadId

在 CopilotKit 中设置 `threadId` 属性时，即：

```tsx
<CopilotKit threadId="2140b272-7180-410d-9526-f66210918b13">
  <YourApp />
</CopilotKit>
```

CopilotKit 会从数据库中恢复该线程的完整状态，包括其中的消息。
（更多细节请参阅[消息持久化](/crewai-flows/persistence/message-persistence)。）

### 加载智能体状态

<Callout>
  **重要**：要正确加载智能体状态，你必须先确保消息历史与持久化已正确配置。请遵循[线程与持久化](/crewai-flows/persistence/loading-message-history)和[消息持久化](/crewai-flows/persistence/message-persistence)指南。
</Callout>

这意味着任何智能体的状态也将被恢复。例如：

```tsx
const { state } = useAgent({ agentId: "research_agent" });

// state will now be the state of research_agent in the thread id given above
```
