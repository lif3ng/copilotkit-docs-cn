## 这是什么？

所有 CrewAI Flow 智能体都是有状态的。这意味着当智能体在各个节点间推进时，会有一个状态对象在节点之间传递，从而保存整个会话的整体状态。CopilotKit 允许你在应用中使用自定义 UI 组件渲染这个状态，我们称之为 **Agentic Generative UI**（智能体化生成式 UI）。

## 什么时候该用它？

当你想向用户反馈会话的整体状态时，在 UI 中渲染智能体的状态会非常有用。一个典型的例子是用户与智能体协同解决问题的场景：智能体可以把一份草稿保存在自己的状态里，再将其渲染到 UI 中。

## 实现

<Steps>
  <Step>
    ### 运行 CrewAI Flow 并将其连接到 CopilotKit
    首先，你需要确保有一个正在运行的 CrewAI Flow。如果还没有，可以参考[快速开始指南](/crewai-flows/quickstart)。

    本指南以 [CoAgents 起步模板仓库](https://github.com/CopilotKit/CopilotKit/tree/main/examples/coagents-starter-crewai-flows)作为起点。

  </Step>
  <Step>
    ### 定义智能体状态
    如果你不熟悉 CrewAI：Flow 是有状态的。随着在各函数之间推进，状态对象会在它们之间不断更新。CopilotKit 让你能够在应用中轻松渲染这个状态。

    在本指南中，假设智能体里的状态如下所示。

    <Tabs groupId="language_crewai-flows_agent" items={['Python']} default="Python" persist>
        <Tab value="Python">
          ```python title="agent.py"
          # ...
          from copilotkit.crewai import CopilotKitState # extends MessagesState
          # ...

          # This is the state of the agent.
          # It inherits from the CopilotKitState properties from CopilotKit.
          class AgentState(CopilotKitState):
              searches: list[dict]
          ```
        </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 模拟状态更新
    接下来，我们在智能体中编写一些逻辑，用于模拟状态更新的发生。

    <Tabs groupId="language_crewai-flows_agent" items={['Python']} default="Python" persist>
      <Tab value="Python">
        ```python title="agent.py"
        from crewai.flow.flow import start
        from litellm import completion
        from copilotkit.crewai import copilotkit_stream, CopilotKitState, copilotkit_emit_state
        from typing import TypedDict

        class Searches(TypedDict):
            query: str
            done: bool

        class AgentState(CopilotKitState):
            searches: list[Searches] = [] # [!code highlight]

        @start
        async def chat(self):
            self.state.searches = [
                {"query": "Initial research", "done": False},
                {"query": "Retrieving sources", "done": False},
                {"query": "Forming an answer", "done": False},
            ]
            await copilotkit_emit_state(self.state)

            # Simulate state updates # [!code highlight:4]
            for search in self.state.searches:
                await asyncio.sleep(1)
                search["done"] = True
                await copilotkit_emit_state(self.state)

            # Run the model to generate a response
            response = await copilotkit_stream(
                completion(
                    model="openai/gpt-5.4",
                    messages=[
                        {"role": "system", "content": "You are a helpful assistant."},
                        *self.state.get("messages", [])
                    ],
                    stream=True
                )
            )
        ```
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 在聊天中渲染智能体状态
    现在我们可以使用带有 `render` 函数的 `useAgent`，**在聊天中**渲染智能体的状态。

    ```tsx title="app/page.tsx"
    // ...
    // ...

    // Define the state of the agent, should match the state of the agent in your Flow.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:13]
      // styles omitted for brevity
      useAgent({
        agentId: "sample_agent",
        render: ({ state }) => (
          <div>
            {state.searches?.map((search, index) => (
              <div key={index}>
                {search.done ? "✅" : "❌"} {search.query}{search.done ? "" : "..."}
              </div>
            ))}
          </div>
        ),
      });

      // ...

      return <div>...</div>;
    }
    ```

  </Step>
  <Step>
    ### 在聊天之外渲染智能体状态
    你也可以**在聊天之外**渲染智能体的状态。当你想在聊天以外的任何位置渲染智能体状态时，这会非常有用。

    ```tsx title="app/page.tsx"
    // ...

    // Define the state of the agent, should match the state of the agent in your Flow.
    type AgentState = {
      searches: {
        query: string;
        done: boolean;
      }[];
    };

    function YourMainContent() {
      // ...

      // [!code highlight:3]
      const { agent } = useAgent({
        agentId: "sample_agent",
      })

      // ...

      return (
        <div>
          {/* ... */}
          <div className="flex flex-col gap-2 mt-4">
            {/* [!code highlight:5] */}
            {agent.state?.searches?.map((search, index) => (
              <div key={index} className="flex flex-row">
                {search.done ? "✅" : "❌"} {search.query}
              </div>
            ))}
          </div>
        </div>
      )
    }
    ```

  </Step>
  <Step>
    ### 试一试！

    现在你已经创建了一个能在聊天中渲染智能体状态的组件。

  </Step>
</Steps>
