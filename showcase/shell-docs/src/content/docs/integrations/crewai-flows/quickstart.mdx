## 从你的编码智能体开始

使用以下提示词将你的 CrewAI 智能体连接到 CopilotKit，并验证对话可用。你的编码智能体会在你的项目中遵循本指南操作，你也可以按下面的手动步骤自行完成。

<PageAgentPrompt />

## 前置条件

开始之前，你需要一个 [CrewAI Flow](https://docs.crewai.com/guides/flows/first-flow)。它可以在本地或你自行管理的基础设施上运行；CrewAI Enterprise 部署是可选项。如果你采用下方的 CopilotKit CLI 路线，起步模板会为你创建 Flow 集成。

        <Step>
            ### 将你的 Flow 暴露为 AG-UI 端点

            CopilotKit 通过 [AG-UI](https://docs.ag-ui.com) 连接智能体。CrewAI Enterprise Live Automation URL 或其他普通 CrewAI 端点并不自动兼容 AG-UI，即使它返回 HTTP 200。请在承载你的 Flow 的服务中添加官方 CrewAI 适配器：

            ```bash title="Terminal"
            pip install -U "crewai>=1.15.11,<2" ag-ui-crewai fastapi uvicorn
            ```

            ```python title="server.py"
            from fastapi import FastAPI
            from ag_ui_crewai import add_crewai_flow_fastapi_endpoint

            from flow import YourFlow

            app = FastAPI()

            add_crewai_flow_fastapi_endpoint(app, YourFlow(), "/")
            ```

            使用 `uvicorn server:app --host 0.0.0.0 --port 8000` 在本地启动服务器，然后将其部署到 Copilot Cloud 可访问的公网 HTTPS URL。
        </Step>

        <Step>
            ### 验证 AG-UI 流

            在连接前端之前，先直接向部署好的端点发送一次运行：

            ```bash title="Terminal"
            export AG_UI_URL="https://your-service.example.com/"

            curl --fail-with-body --no-buffer --include \
              --request POST "$AG_UI_URL" \
              --header "Content-Type: application/json" \
              --header "Accept: text/event-stream" \
              --data '{
                "threadId": "preflight-thread",
                "runId": "preflight-run",
                "messages": [
                  {
                    "id": "preflight-message",
                    "role": "user",
                    "content": "Say hello"
                  }
                ],
                "state": {},
                "tools": [],
                "context": [],
                "forwardedProps": {}
              }'
            ```

            兼容的响应应带有 `Content-Type: text/event-stream` 头，并依次发出 `RUN_STARTED` 和 `RUN_FINISHED`。如果它返回普通 JSON 响应或发出 `RUN_ERROR`，请不要注册该 URL；应先修复智能体端点。
        </Step>

        <Step>
            ### 连接到 Copilot Cloud
            1. 前往 [Copilot Cloud](https://dashboard.operations.copilotkit.ai)，登录并点击 Get Started
            2. 点击 “Add Remote Endpoint”，输入你在上面验证过的公网 AG-UI URL。注意：如果你的智能体名称包含多个单词，请使用下划线（`_`）作为分隔符。
            3. 点击 “Save Endpoint”
            4. 复制 Copilot Cloud Public API Key

            <img src="https://cdn.copilotkit.ai/docs/copilotkit/images/copilot-cloud/crewai-flow-cpk-setup.gif" alt="CrewAI Flow Copilot Setup" className="rounded-lg shadow-xl mt-4" />
        </Step>

        <Step>
            ### 安装 CopilotKit
            首先，在你的前端中安装最新的 CopilotKit 软件包。
            ```npm
            npm install @copilotkit/react-core
            ```
        </Step>

        <Step>
            ### 设置 CopilotKit Provider
            [`<CopilotKit>`](/reference/v1/components/CopilotKit) 组件必须包裹应用中需要 Copilot 能力的部分。对于大多数用例，将 CopilotKit Provider 包裹整个应用是合适的做法，例如在你的 layout.tsx 中。

            <CloudCopilotKit />
        </Step>
        <Step>
            ### 选择 Copilot UI
            就快完成了！现在来设置你的 Copilot UI。
            <CopilotUI />
        </Step>
        <Step>
            ### 创建 CrewAI Flow 组件
            将以下代码片段放到你的**主页面**（例如 Next.js 中的 `page.tsx`）或任何你想使用 CopilotKit 的地方。

            ```tsx title="page.tsx"
            "use client";

            const publicApiKey = process.env.NEXT_PUBLIC_COPILOT_API_KEY || "";
            /**
             * AgentName refers to the Crew Flow Agent you have saved via CLI during setup.
             * It is used to identify the agent you want to use for the chat.
             */
            const agentName =
              process.env.NEXT_PUBLIC_COPILOTKIT_AGENT_NAME || "DefaultAgent";

            // Main Chat Component: Handles chat interface and background customization
            const Chat = () => {
              const [background, setBackground] = useState(
                "linear-gradient(135deg, #667eea 0%, #764ba2 100%)"
              );

              // Action: Allow AI to change background color dynamically
              useFrontendTool({
                name: "change_background",
                description:
                  "Change the background color of the chat. Can be anything that the CSS background attribute accepts. Regular colors, linear of radial gradients etc.",
                parameters: z.object({
                  background: z.string().describe("The background. Prefer gradients."),
                }),
                handler: async ({ background }) => {
                  setBackground(background);
                  return `Background changed to ${background}`;
                },
                followUp: false,
              });

              return (
                <div
                  className="h-screen w-full flex items-center justify-center"
                  style={{ background }}
                >
                  <div className="w-full max-w-3xl h-[80vh] px-4">
                    <div className="h-full bg-white/10 backdrop-blur-lg rounded-2xl shadow-2xl overflow-hidden">
                      <CopilotChat
                        className="h-full"
                        labels={{
                          welcomeMessageText: "Hi, I'm an agent. Want to chat?",
                          placeholder: "Type a message...",
                        }}
                      />
                    </div>
                  </div>
                </div>
              );
            }

            // App Component: Main wrapper that provides CopilotKit context
            const CrewAIFlow: React.FC = () => (
              <CopilotKit publicApiKey={publicApiKey} agent={agentName}>
                <Chat />
              </CopilotKit>
            );

            export default CrewAIFlow;
            ```
        </Step>
        <Step>
