## 这是什么？

在 CrewAI 中，消息只会在函数执行完成后才发出。CopilotKit 允许你在函数执行过程中手动发送消息，以便向用户提供即时反馈。

## 什么时候应该使用？

手动发送消息非常适合**不想等待函数完成**、同时又想：

- 提供长时间运行任务的进展反馈
- 向用户提供状态更新
- 发出警告或错误消息

    <Step>
        ### 手动发送消息
        `copilotkit_emit_message` 方法允许你在函数执行早期发送消息，向用户传达状态更新。这对于长时间运行的任务尤其有用。

        <Tabs groupId="language_crewai-flows_agent" items={['Python']} default="Python" persist>
            <Tab value="Python">
                ```python
                from litellm import completion
                from crewai.flow.flow import start
                from copilotkit.crewai import copilotkit_emit_message # [!code highlight]
                # ...

                @start()
                async def start(self):
                    # [!code highlight:2]
                    intermediate_message = "Thinking really hard..."
                    await copilotkit_emit_message(intermediate_message)

                    # simulate a long running task
                    await asyncio.sleep(2)

                    response = copilotkit_stream(
                        completion(
                            model="openai/gpt-5.4",
                            messages=[
                                {"role": "system", "content": "You are a helpful assistant."},
                                *self.state["messages"]
                            ],
                            stream=True
                        )
                    )
                     message = response.choices[0]["message"]

                    self.state["messages"].append(message)
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### 试试看！
        现在与智能体对话时，你会注意到它会立即回复消息 “Thinking really hard...”，然后在 2 秒后才给出正式响应。
    </Step>

</Steps>
