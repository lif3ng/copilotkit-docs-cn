## 什么是共享状态？

CoAgent 维护着一种共享状态，将你的 UI 与智能体的执行无缝连接起来。这套共享状态系统让你能够：

- 展示智能体的当前进度与中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用中实时响应状态变化

这套系统的基石是 CrewAI 的有状态架构。

<Callout type="info" title="对话式 Flow 状态">
  如果你已将 Flow 升级为对话模式，请从 `ag_ui_crewai.CopilotKitState` 继承自定义 Pydantic 状态。除了 CopilotKit 消息、操作和共享状态之外，它还包含 CrewAI 所需的对话字段。
</Callout>

## 什么时候应该使用？

当你想促进智能体与用户之间的协作时，状态流式传输就非常适用。你的 CrewAI Flow 持久化的任何状态都会自动共享给 UI。同样，用户在 UI 中更新的任何状态也会自动得到反映。

这让智能体与用户始终保持信息同步，带来一致的体验。
