## 这是什么？

你不仅可以在聊天 UI 中使用实时智能体状态，还可以在应用本身的 UX 中使用它。

## 什么时候应该使用？

当你想向用户提供关于智能体状态的反馈时，就可以使用它。随着智能体状态更新，你可以在应用中原生地反映这些更新。

## 实现

<Steps>
  <Step>
    ### 运行智能体并连接到 CopilotKit

    在继续之前，你需要运行你的智能体并将其连接到 CopilotKit。如果尚未完成，可以按照[快速开始](/crewai-flows/quickstart)指南中的说明操作。

    如果你还没有智能体，可以使用 [coagent starter](https://github.com/copilotkit/copilotkit/tree/main/examples/coagents-starter-crewai-flows) 作为起点，本指南也以它为起点。

  </Step>
  <Step>
    ### 定义智能体状态
    CrewAI Flows 是有状态的。当你在 Flow 中逐步推进时，状态会被更新并可供下一个函数使用。在本示例中，我们假设智能体状态大致如下。

    <Tabs groupId="language_crewai-flows_agent" items={["Python"]} persist>
      <Tab value="Python">
        ```python title="agent.py"
        from copilotkit.crewai import CopilotKitState
        from typing import Literal

        class AgentState(CopilotKitState):
            language: Literal["english", "spanish"] = "english"
        ```
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 使用 `useAgent` Hook
    智能体连接并运行后，剩下的就是调用 `useAgent` hook，传入智能体名称，并在所连接的智能体就绪后初始化缺失的 UI 侧状态。

    ```tsx title="ui/app/page.tsx"
    import { useEffect } from "react";
    import { useAgent } from "@copilotkit/react-core/v2";

    // Define the agent state type, should match the actual state of your agent
    type AgentState = {
      language: "english" | "spanish";
    }

    function YourMainContent() {
      // [!code highlight:4]
      const { agent, isReady } = useAgent({
        agentId: "sample_agent",
      });
      const state = (agent.state ?? {}) as Partial<AgentState>;

      useEffect(() => {
        if (!isReady || state.language !== undefined) return;
        agent.setState({ ...(agent.state ?? {}), language: "english" });
      }, [agent, isReady, state.language]);

      // ...

      return (
        // style excluded for brevity
        <div>
          <h1>Your main content</h1>
          {/* [!code highlight:1] */}
          <p>Language: {agent.state?.language}</p>
        </div>
      );
    }
    ```
    <Callout type="info">
      `useAgent` 中的 `agent.state` 是响应式的，当智能体状态变化时会自动更新。
    </Callout>

  </Step>
  <Step>
    ### 动手试试！
    随着智能体状态更新，你的 `state` 变量也会自动更新！在本例中，当所连接的智能体就绪后，你会看到 language 被设置为 “english”。
  </Step>
</Steps>

## 在你的应用中渲染智能体状态

你可以在 `<CopilotKit>` 下的任意 React 组件中渲染智能体状态。读取 `agent.state` 并返回普通 JSX 即可。

```tsx title="ui/app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2";

type AgentState = {
  language: "english" | "spanish";
};

function YourMainContent() {
  const { agent } = useAgent({
    agentId: "sample_agent",
  });
  const state = (agent.state ?? {}) as Partial<AgentState>;

  if (!state.language) return null;
  return <div>Language: {state.language}</div>;
}
```

<Callout type="info">
  `useAgent` 中的 `agent.state` 是响应式的，当智能体状态变化时会自动更新。
</Callout>

## 以中间状态流式渲染智能体状态

默认情况下，CrewAI Flow 智能体状态只_会在 CrewAI Flow 节点切换之间_更新——这意味着状态更新是不连续且滞后的。

你可能希望智能体状态在更新时**持续地**渲染。

参阅 **[发出中间状态](/crewai-flows/shared-state/predictive-state-updates)**。
