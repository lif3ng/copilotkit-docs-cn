---
title: 文档贡献
---

我们明白，由于迭代速度很快，文档网站有时会略显过时。因此，我们非常重视对文档的贡献。

## 前置条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- 全局安装 [pnpm](https://pnpm.io/) v10.x（`npm i -g pnpm@^10`）

## 如何贡献

<Steps>
  <Step>
  ### 复刻仓库

  首先，前往 [CopilotKit GitHub 仓库](https://github.com/CopilotKit/CopilotKit)并创建一个复刻（fork）。

  然后，把复刻出的仓库克隆到本地：

  ```shell
  git clone https://github.com/<your-username>/CopilotKit
  cd CopilotKit/docs
  ```
  </Step>
  <Step>
  ### 在本地运行文档站

  要在本地运行文档站，请先安装依赖，然后以开发模式启动文档：

  ```shell
  pnpm install
  pnpm run dev
  ```

  文档站应可通过 [http://localhost:3000](http://localhost:3000) 访问。
  </Step>
  <Step>
  ### 进行更改

  现在，你可以对文档网站进行更改了。

  - 所有与文档相关的文件都位于 docs 仓库中
  - 建议先熟悉一下 [Nextra](https://nextra.site/)，了解文档网站的结构。

  <Callout type="info">
    请检查你的更改，确保没有语法、拼写和排版错误。同时，确保链接和图片都能正常工作。
  </Callout>
  </Step>
  <Step>
  ### 审查更改并提交 Pull Request

  对更改满意后，即可提交并推送它们。然后前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls)创建一个 pull request。感谢你的贡献！
  </Step>
</Steps>
