## 这是什么？

工具是 LLM 调用预定义（通常为确定性）函数的一种方式。CopilotKit 允许你在 UI 中将这些工具渲染为自定义组件，我们称之为**生成式 UI**。

## 何时使用？

当你想就智能体正在做的事情向用户提供反馈时，在 UI 中渲染工具会很有用，尤其是当你的智能体正在调用工具时。CopilotKit 允许你完全自定义这些工具在聊天中的渲染方式。

### 给你的智能体一个可调用的工具

<Tabs groupId="language_agno_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from agno.agent import Agent
        from agno.models.openai import OpenAIChat
        from agno.tools import tool
        # ...

        # [!code highlight:6]
        @tool
        def get_weather(location: str):
            """
            Get the weather for a given location.
            """
            return f"The weather for {location} is 70 degrees."

        # ...

        agent = Agent(
            model=OpenAIChat(id="gpt-5.4"),
            tools=[get_weather], # [!code highlight]
            description="A helpful assistant that can answer questions and provide information.",
            instructions="Be helpful and friendly. Format your responses using markdown where appropriate.",
        )
        ```
    </Tab>

</Tabs>
</Step>
<Step>
### 在前端渲染工具调用
此时，你的智能体已经能够调用 `get_weather` 工具。现在
我们只需添加一个 `useRenderTool` Hook，即可在 UI 中渲染该工具调用。

<Callout type="info" title="重要提示">
  要在 UI 中渲染工具调用，操作的名称必须与工具的名称一致。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  {/* [!code highlight:12] */}
  useRenderTool({
    name: "get_weather",
    render: ({status, args}) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "Calling weather API..."}
          {status === "complete" && `Called the weather API for ${args.location}.`}
        </p>
      );
    },
  });
  // ...
}
```

</Step>
<Step>
### 试一试！

试着让智能体查询某个地点的天气。你应该会看到我们添加的自定义 UI 组件渲染出该工具调用，并显示传递给工具的参数。
