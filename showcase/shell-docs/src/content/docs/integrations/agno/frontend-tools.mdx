## 这是什么？
前端工具让你能够定义可供 Agno 智能体调用的客户端函数，其执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，
逻辑会在客户端运行，让你可以直接访问前端环境。

它可以用于让[你的智能体控制 UI](/agno/frontend-tools)、实现[生成式 UI](/agno/frontend-tools)，或进行[人机协同](/agno/human-in-the-loop)（human-in-the-loop）交互。

本指南介绍如何使用前端工具驱动 UI 并与之交互。

## 何时使用？
当你需要智能体与客户端基础能力交互时，可以使用前端工具，例如：
- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookies 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

    <Step>
        ### 创建前端工具

        首先，你需要使用 [useFrontendTool](/reference/v1/hooks/useFrontendTool) Hook 创建一个前端工具。下面是一个简单的入门示例，
        它会向用户问好。

        ```tsx title="page.tsx"
        import { z } from "zod";
        import { useFrontendTool } from "@copilotkit/react-core/v2" // [!code highlight]

        export function Page() {
          // ...

          {/* [!code highlight:12] */}
          useFrontendTool({
            name: "sayHello",
            description: "Say hello to the user",
            parameters: z.object({
              name: z.string().describe("The name of the user to say hello to"),
            }),
            handler: async ({ name }) => {
              alert(`Hello, ${name}!`);
              return `Said hello to ${name}!`;
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 在 Agno 智能体中定义前端工具

        接下来，我们需要修改智能体，使其能够访问这些前端工具。

        在你的 Agno 智能体中，使用 `@tool(external_execution=True)` 装饰器定义一个工具。这会告诉 Agno：该工具将在外部（前端）执行。

        ```python title="tools/frontend.py"
        from agno.tools import tool

        @tool(external_execution=True)
        def sayHello(name: str):
            """
            Say hello to the user.

            Args:
                name: The name of the user to say hello to
            """
        ```

        将该工具注册到智能体：

        ```python title="agent.py"
        from agno.agent import Agent
        from agno.db.sqlite import SqliteDb
        from agno.models.openai import OpenAIChat
        from agno.os import AgentOS
        from agno.os.interfaces.agui import AGUI
        from tools.frontend import sayHello

        db = SqliteDb(db_file="tmp/agno.db")

        agent = Agent(
            model=OpenAIChat(id="gpt-5.4"),
            tools=[sayHello],
            db=db,
            description="A helpful assistant that can answer questions and provide information.",
            instructions="Be helpful and friendly. Format your responses using markdown where appropriate.",
        )

        agent_os = AgentOS(agents=[agent], interfaces=[AGUI(agent=agent)])
        app = agent_os.get_app()
        ```
    </Step>
    <Step>
        ### 试一试！
        现在，你的智能体已经可以直接调用你定义的任何前端工具了。这些工具对智能体可用，可在需要时使用。
