## 从你的编码智能体开始

使用此提示词将你的 Agno 智能体接入 CopilotKit，并验证对话可以正常进行。你的编码智能体会在你的项目中遵循本指南操作，你也可以按照下方的手动步骤自己完成。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 OpenAI API 密钥
- Node.js 20+
- Python 3.9+
- 你惯用的包管理器

                ### 运行我们的 CLI

                ```bash
                npx copilotkit@latest create
                ```

                CLI 会引导你完成以下配置：

                - **项目名称**
                - **CopilotKit 智能中枢**——持久化线程与 Inspector。选择 **Yes** 即可生成一个预先接入该平台的项目（CLI 会引导你完成注册，你也可以先[创建账号](https://dashboard.operations.copilotkit.ai/?utm_source=docs&utm_medium=cta&utm_campaign=intelligence&utm_content=docs_cli_prompt)），选择 **No** 则使用标准 Agno 配置。
                - **框架**——在提示时选择 **Agno**。
            </Step>

                ### 安装依赖

                ```npm

                ```
            </Step>
            <Step>
                ### 配置环境

                ```plaintext title="agent/.env"
                OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="想用其他模型？">
                  起步模板默认配置为使用 OpenAI 的 GPT-4o，但你可以修改它，改用 Agno 支持的任意语言模型。
                </Callout>
            </Step>

        <TailoredContentOption
            id="bring-your-own"
            title="使用现有智能体"
            description="我已经有一个 Agno 智能体，想为其添加 CopilotKit。"
        >
            <Step>
                ### 初始化你的智能体项目

                如果你还没有搭建 Python 项目，可以使用 `uv` 创建一个：

                ```bash
                uv init my-agent
                cd my-agent
                ```
            </Step>
            <Step>
                ### 安装带 AG-UI 的 Agno

                将 Agno 和 uvicorn 添加到你的项目中：

                ```bash
                uv add agno fastapi uvicorn openai ag-ui-protocol
                ```
            </Step>
            <Step>
                ### 配置环境

                将你的 OpenAI API 密钥设置为环境变量：

                ```bash
                export OPENAI_API_KEY=your_openai_api_key
                ```

                <Callout type="info" title="想用其他模型？">
                  本示例使用 OpenAI 的 GPT-4o，但你可以修改它，改用 Agno 支持的任意语言模型。
                </Callout>
            </Step>
            <Step>
                ### 通过 AG-UI 暴露你的智能体

                更新你的智能体文件，将其暴露为 AG-UI ASGI 应用：

                ```python title="main.py"
                from agno.agent import Agent
                from agno.models.openai import OpenAIChat
                from agno.os import AgentOS
                from agno.os.interfaces.agui import AGUI

                agent = Agent(
                    model=OpenAIChat(id="gpt-5.4"),
                    description="A helpful assistant that can answer questions and provide information.",
                    instructions="Be helpful and friendly. Format your responses using markdown where appropriate.",
                )

                agent_os = AgentOS(agents=[agent], interfaces=[AGUI(agent=agent)])
                app = agent_os.get_app()

                if __name__ == "__main__":
                    agent_os.serve(app="main:app", port=8000, reload=True)
                ```

                <Callout type="info" title="AG-UI 是什么？">
                  AG-UI 是一个用于前端与智能体通信的开放协议。带有 AGUI 接口的 AgentOS 会创建一个 CopilotKit 可以连接的 ASGI 应用。
                </Callout>
            </Step>
            <Step>
                ### 创建你的前端

                CopilotKit 可以搭配任何基于 React 的前端使用。本示例我们将使用 Next.js。

                ```bash
                npx create-next-app@latest my-copilot-app
                cd my-copilot-app
                ```
            </Step>
            <Step>
                ### 安装 CopilotKit 包

                ```npm
                npm install @copilotkit/react-ui @copilotkit/react-core @copilotkit/runtime @ag-ui/agno
                ```
            </Step>
            <Step>
                ### 设置 Copilot Runtime

                创建一个 API 路由，将 CopilotKit 连接到你的 Agno 智能体：

                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotKitIntelligence,
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                } from "@copilotkit/runtime/v2";
                import { AgnoAgent } from "@ag-ui/agno";

                const runtime = new CopilotRuntime({
                  agents: {
                    my_agent: new AgnoAgent({ url: "http://localhost:8000/agui" }),
                  },
                  // [!code highlight:8]
                  intelligence: new CopilotKitIntelligence({
                    apiKey: process.env.CPK_INTELLIGENCE_API_KEY!,
                  }),
                  // Threads are per-user. Without this, every visitor shares one history.
                  identifyUser: (request) => ({
                    id: request.headers.get("x-user-id") ?? "anonymous",
                    name: request.headers.get("x-user-name") ?? "Anonymous",
                  }),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
               ```

                在这个前端应用目录下，将运行时连接到一个智能中枢项目：

                ```bash title="Terminal"
                npx copilotkit@latest project select
                ```

                该命令会将服务端项目 API 密钥写入 `.env`。运行时在这里读取它：

                ```plaintext title=".env"
                CPK_INTELLIGENCE_API_KEY=cpk-...
                ```

                <Callout type="info" title="不使用智能中枢平台运行？">
                  去掉 `intelligence` 与 `identifyUser` 选项，运行时将回退到使用内存运行器的
                  SSE 模式。聊天仍可正常工作，但线程（Threads）与 Inspector 会保持锁定，
                  密钥也永远不会被读取。完整构造参数以及如何确认密钥已生效，请参阅
                  [将你的运行时连接到智能中枢](/intelligence/quickstart)。
                </Callout>
            </Step>
            <Step>
                ### 配置 CopilotKit Provider

                用 CopilotKit Provider 包裹你的应用：

                ```tsx title="app/providers.tsx"
                "use client";

                import { CopilotKit } from "@copilotkit/react-core/v2";

                export function Providers({ children }: { children: React.ReactNode }) {
                  return (
                    <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
                      {children}
                    </CopilotKit>
                  );
                }
                ```

                `app/layout.tsx` 是服务端组件，无法直接导入该 Provider，因此它改为渲染你的客户端文件：

                ```tsx title="app/layout.tsx"
                import { Providers } from "./providers"; // [!code highlight]
                import "@copilotkit/react-core/v2/styles.css";
                import './globals.css';

                // ...

                export default function RootLayout({ children }: {children: React.ReactNode}) {
                  return (
                    <html lang="en">
                      <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                          {children}
                        </Providers>
                      </body>
                    </html>
                  );
                }
                ```

                <Callout type="info" title="此相对 runtimeUrl 假设由 Next.js 提供运行时服务">
                  `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源同时提供你的应用与运行时。
                  纯客户端前端没有共享源，因此需要它自己独立的运行时服务器，以及形如
                  `http://localhost:8200/api/copilotkit` 的绝对 `runtimeUrl`。`/react-spa`、`/vue`、
                  `/angular` 与 `/react-native` 的各前端指南分别展示了该配置。
                </Callout>
            </Step>
            <Step>
              ### 添加聊天界面

              将 CopilotSidebar 组件添加到你的页面：

              ```tsx title="app/page.tsx"
              "use client"; // [!code highlight]

              import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight:1]

              export default function Page() {
                return (
                  <main>
                    <h1>Your App</h1>
                    {/* [!code highlight:1] */}
                    <CopilotSidebar />
                  </main>
                );
              }
              ```
            </Step>
            <Step>
                ### 启动你的智能体

                在智能体目录下，启动智能体服务器：

                ```bash
                cd ..
                uv run main.py
                ```

                你的智能体将在 `http://localhost:8000/agui` 上可用。
            </Step>
            <Step>
                ### 启动你的 UI

                在另一个终端中，进入你的前端目录并启动开发服务器：

                    </Tab>

                        ```bash
                        yarn dev
                        ```
                    </Tab>
                    <Tab value="bun">
                        ```bash
                        cd my-copilot-app
                        bun dev
                        ```
                    </Tab>
                </Tabs>
            </Step>
        </TailoredContentOption>
    </TailoredContent>
    </Step>
    <Step>
        ### 🎉 开始对话

        你的 AI 智能体现在已经可以使用了！访问 `localhost:3000`，试着问它几个问题：

        ```

        ```

                - 确保你的智能体运行在 8000 端口
                - 检查你的 OpenAI API 密钥是否已正确设置
                - 确认你的前端中已安装 `@ag-ui/client` 包
