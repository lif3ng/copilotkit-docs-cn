title: 共享状态
icon: "lucide/Repeat"
description: 在 Agent Spec 集成中同步应用与智能体状态。
---

Agent Spec 智能体化聊天支持流式文本与工具事件。对于高级共享状态模式，在专用的状态通道可用之前，可将需要呈现的内容以消息或工具调用的形式镜像出来。
