## 这是什么？

前端工具让你能够定义客户端函数，供你的 Agent Spec 智能体调用，其执行完全发生在用户的浏览器中。当你的智能体调用前端工具时，逻辑会在客户端运行，让你可以直接访问前端环境。

这可用于让[你的智能体控制 UI](/frontend-tools)、实现[生成式 UI](/frontend-tools)，或用于人机协同（human-in-the-loop）交互。

在本指南中，我们将介绍如何将前端工具用于人机协同。

## 什么时候使用？

当你需要智能体与客户端原语交互时，可以使用前端工具，例如：

- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 实现步骤

<Steps>
    <Step>
      ### 运行并连接你的智能体
      <RunAndConnect />
    </Step>

    <Step>
        ### 创建一个人机协同的前端工具

        前端工具可以以多种方式加以利用。其中一种方式是实现人机协同流程，即工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的 “审批” 流程。首先，使用 `useHumanInTheLoop` hook 创建一个提示用户进行批准的工具。

        ```tsx title="page.tsx"
        import { useHumanInTheLoop } from "@copilotkit/react-core/v2" // [!code highlight]
        import { z } from "zod"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: z.object({
              option_1: z.string().describe("The first option"),
              option_2: z.string().describe("The second option"),
            }),
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 配置你的智能体

        人机协同工具通过 Agent Spec 中的 `ClientTool` 概念来启用。详情请参阅[前端工具指南](/frontend-tools)。简而言之，你需要在 Agent Spec 配置中提供工具声明，而执行则发生在客户端（即你的前端）。
    </Step>
    <Step>
        ### 试一试！

        现在，你的智能体已经能够向用户展示两个选项并让其从中选择一个。智能体随后会知晓用户的选择，并可以在后续步骤中使用它。

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
