`BuiltInAgent` 接受一整套配置选项，用于控制模型行为、工具调用等。

## 多步工具调用

默认情况下，智能体只执行单个生成步骤。设置 `maxSteps` 可让智能体在调用工具后继续推理：

```typescript title="src/copilotkit.ts"
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  maxSteps: 5, // [!code highlight]
  tools: [searchDocs, createTicket],
});
```

设为 `maxSteps: 5` 后，智能体可以调用工具、处理结果、再调用下一个工具，依此类推——最多 5 次迭代。对于需要串联多次工具调用的工作流，这一点至关重要。

## 工具选择

控制智能体如何选择工具：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  toolChoice: "auto",       // Let the model decide (default)
  // toolChoice: "required", // Force the model to call a tool
  // toolChoice: "none",     // Disable tool calling
  // toolChoice: { type: "tool", toolName: "searchDocs" }, // Force a specific tool
});
```

## 系统提示

自定义智能体的系统提示：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  prompt: "You are a customer support agent for Acme Corp. Be concise and helpful. Always check the knowledge base before answering.", // [!code highlight]
});
```

## 生成参数

微调模型的输出：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  temperature: 0.7,        // Creativity (0 = deterministic, 1+ = creative)
  topP: 0.9,               // Nucleus sampling
  topK: 40,                // Top-K sampling (provider-dependent)
  maxOutputTokens: 4096,   // Maximum tokens in the response
  presencePenalty: 0.1,    // Penalize repeated topics
  frequencyPenalty: 0.1,   // Penalize repeated tokens
  stopSequences: ["END"],  // Stop generation at these sequences
  seed: 42,                // Deterministic output (provider-dependent)
  maxRetries: 3,           // Retry on transient failures
});
```

<Callout type="info">
并非所有提供方都支持全部参数。例如 `topK` 受 Google 支持但 OpenAI 不支持。不受支持的参数会被忽略。
</Callout>

## 提供方专属选项

使用 `providerOptions` 传入特定于模型提供方的选项：

```typescript
// OpenAI reasoning models (o3, o4-mini) with reasoning effort
const agent = new BuiltInAgent({
  model: "openai:o3",
  providerOptions: { // [!code highlight:3]
    openai: { reasoningEffort: "high" },
  },
});
```

```typescript
// Anthropic with adaptive thinking
const agent = new BuiltInAgent({
  model: "anthropic:claude-sonnet-4-6",
  providerOptions: { // [!code highlight:3]
    anthropic: { thinking: { type: "adaptive" }, effort: "high" },
  },
});
```

## 可覆盖属性

允许前端在运行时覆盖特定配置。当你希望用户无需重新部署即可切换模型或调整行为时，这非常有用：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  temperature: 0.5,
  overridableProperties: ["model", "temperature", "prompt"], // [!code highlight]
});
```

可覆盖属性的完整列表：
`model`, `toolChoice`, `maxOutputTokens`, `temperature`, `topP`, `topK`, `presencePenalty`, `frequencyPenalty`, `stopSequences`, `seed`, `maxRetries`, `prompt`, `providerOptions`

## 消息转发

控制是否将对话中的 system 与 developer 消息转发给 LLM：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  forwardSystemMessages: true,    // Forward system-role messages
  forwardDeveloperMessages: true, // Forward developer-role messages (as system messages)
});
```

## URL 附件

当消息带有以 URL 形式给出的图片或文件，而模型无法直接接收该 URL 时，服务器会下载该文件并将其内容发送给模型。使用 `urlDownload` 控制这些下载：

```typescript
const agent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  urlDownload: { // [!code highlight:4]
    allowedHosts: ["cdn.example.com", "*.example-uploads.com"],
    maxBytes: 10 * 1024 * 1024,
  },
});
```

- **默认**：仅从公共互联网地址下载。服务器会解析主机名，并拒绝环回、私有、链路本地（包括云元数据）及其他非公共地址。它只连接已核验过的地址，对每次重定向重新校验，并拒绝从 https 到 http 的重定向。每次下载限制为 20 MiB（`maxBytes`）与 30 秒（`timeoutMs`），每次模型调用限制为 20 个不同 URL（`maxDownloads`）与总计 50 MiB（`maxTotalBytes`）。AI SDK 在多步运行的每个步骤中都会重新下载附件，因此每个步骤单独计数。
- **`allowedHosts`**：仅从你列出的主机名下载。地址仍必须是公共地址，且每个重定向目标也必须在列表中。`cdn.example.com` 只匹配该主机。`*.example-uploads.com` 匹配其子域名，但不匹配 `example-uploads.com` 本身；如果两者都需要，请同时列出。匹配忽略大小写与末尾的点。只填写主机名：带协议、端口或路径的条目，以及针对 IP 地址的通配符（`*.1.2.3.4`），都会在智能体创建时被拒绝。空列表会拒绝所有服务端下载。
- **`"disabled"`**：绝不从网络下载。除 `data:` 之外、模型无法直接接收的任何附件 URL 都会导致运行失败。
- **函数**：你自己的 AI SDK 下载函数（来自 `ai` 的 `Experimental_DownloadFunction`）。仅当你必须从私有网络获取内容时使用，并自行校验每个 URL。

无效的选项（包括未知的选项名）会在智能体创建时抛出错误，而不是在请求到达时。

模型可直接接收的 URL 会原样传给模型提供方。`data:` URL 由 AI SDK 解码，不发起网络请求，适用于所有模式。当下载失败或被拒绝时，客户端会收到一条不含 URL 查询参数或网络错误详情的简短消息；服务器会以 `[BuiltInAgent]` 为前缀记录原因。无论主机名无法解析还是解析到非公共地址，客户端收到的消息都相同。

默认下载器需要 Node.js 网络模块。在缺少这些模块的运行时（如 edge runtime）上，所有下载都会失败；此时请将 `urlDownload` 设置为 `"disabled"` 或你自己的下载函数。

在 AI SDK 工厂模式下，你自己调用 `streamText()`，因此 `urlDownload` 不生效；在该模式下设置它会在智能体创建时抛出错误。传入相同的下载器即可获得相同的保护，并附带运行的 abort 信号，这样中止的运行也会停止其下载：

```typescript
import { createSafeUrlDownload } from "@copilotkit/runtime/v2";

factory: (ctx) =>
  streamText({
    // ...
    abortSignal: ctx.abortSignal,
    experimental_download: createSafeUrlDownload({ signal: ctx.abortSignal }),
  }),
```

## 完整配置参考

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `model` | `string \| LanguageModel` | — | 模型标识符或 AI SDK 实例 |
| `apiKey` | `string` | 环境变量 | 该提供方的 API 密钥 |
| `maxSteps` | `number` | `1` | 最大工具调用迭代次数 |
| `toolChoice` | `"auto" \| "required" \| "none" \| { type: "tool", toolName: string }` | `"auto"` | 工具的选择方式 |
| `maxOutputTokens` | `number` | — | 响应中的最大 token 数 |
| `temperature` | `number` | — | 采样温度 |
| `topP` | `number` | — | 核采样（nucleus sampling） |
| `topK` | `number` | — | Top-K 采样 |
| `presencePenalty` | `number` | — | 存在惩罚 |
| `frequencyPenalty` | `number` | — | 频率惩罚 |
| `stopSequences` | `string[]` | — | 停止序列 |
| `seed` | `number` | — | 随机种子 |
| `maxRetries` | `number` | — | 重试次数 |
| `prompt` | `string` | — | 系统提示 |
| `tools` | `ToolDefinition[]` | `[]` | 服务端工具 |
| `mcpServers` | `MCPClientConfig[]` | `[]` | MCP 服务器连接（由智能体管理，按请求） |
| `mcpClients` | `MCPClientProvider[]` | `[]` | 用户管理的 MCP 客户端（持久化，生命周期由用户控制） |
| `overridableProperties` | `string[]` | `[]` | 前端可覆盖的属性 |
| `providerOptions` | `Record<string, any>` | — | 提供方专属选项 |
| `forwardSystemMessages` | `boolean` | `false` | 转发 system 消息 |
| `forwardDeveloperMessages` | `boolean` | `false` | 转发 developer 消息 |
| `urlDownload` | `"disabled" \| SafeUrlDownloadOptions \| Experimental_DownloadFunction` | 仅公共地址 | 服务端下载 URL 附件 |

<Callout type="info" title="需要更强的控制力？">
  如果 `BuiltInAgent` 的配置选项无法满足你的需求——例如你想使用 TanStack AI、自定义 LLM 后端或异步初始化——请参阅[自定义智能体](/backend/custom-agent)。
</Callout>
