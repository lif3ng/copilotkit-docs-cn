## 这是什么？

MCP Apps 是一类暴露带有关联 UI 资源的工具的 MCP 服务器。当智能体调用其中某个工具时，CopilotKit 会自动获取并在聊天中渲染对应的 UI 组件——无需编写任何额外的前端代码。

主要优势：
- **零前端代码**——UI 组件由 MCP 服务器直接提供
- **完全可交互**——组件可以使用 HTML、CSS 和 JavaScript
- **安全的沙箱隔离**——内容在隔离的 iframe 中运行
- **线程持久化**——MCP Apps 会保存在会话历史中，并在重新连接时恢复

## 实现步骤

<Steps>
  <Step>
    ### 安装中间件

    ```bash
    npm install @ag-ui/mcp-apps-middleware
    ```

    请使用 `@copilotkit/runtime` 1.76.0 或更高版本。当前版本的中间件依赖 `@ag-ui/client` 1.x，而 runtime 1.76.0 及以上版本已在使用该依赖。
  </Step>
  <Step>
    ### 为智能体添加 MCP Apps 中间件

    使用 `.use()` 将 `MCPAppsMiddleware` 附加到你的 `BuiltInAgent` 上：

    ```typescript title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
    import {
      CopilotRuntime,
      createCopilotRuntimeHandler,
      InMemoryAgentRunner,
    } from "@copilotkit/runtime/v2";
    import { BuiltInAgent } from "@copilotkit/runtime/v2"; // [!code highlight]
    import { MCPAppsMiddleware } from "@ag-ui/mcp-apps-middleware"; // [!code highlight]

    const agent = new BuiltInAgent({
      model: "openai:gpt-5.4-mini",
      prompt: "You are a helpful assistant.",
    }).use( // [!code highlight:9]
      new MCPAppsMiddleware({
        mcpServers: [
          {
            type: "http",
            url: "http://localhost:3108/mcp",
            serverId: "my-server",
          },
        ],
      }),
    );

    const runtime = new CopilotRuntime({
      agents: { default: agent },
      runner: new InMemoryAgentRunner(),
    });

    const handler = createCopilotRuntimeHandler({
      runtime,
      basePath: "/api/copilotkit",
    });

    export const GET = handler;
    export const POST = handler;
    ```

    <Callout type="info" title="服务器 ID">
      在生产环境部署中务必提供 `serverId`。否则，CopilotKit 会根据服务器 URL 生成一个哈希值。如果你的 URL 发生变化（例如切换环境），会话历史中先前存储的 MCP Apps 将无法正确加载。
    </Callout>

    <Callout type="info" title="正在使用 Intelligence？">
      在连接到 Intelligence 的 runtime 上，请改为通过 runtime 的 `mcpApps` 选项配置服务器，并用 `intelligence` 替代 `runner`。参见 [搭配 Intelligence 使用 MCP Apps](/generative-ui/mcp-apps#mcp-apps-with-intelligence)。
    </Callout>
  </Step>
  <Step>
    ### 试一试！

    就是这样。当智能体调用带有关联 UI 资源的工具时，MCP Apps 会自动渲染，你的前端无需任何改动。
  </Step>
</Steps>

## 传输类型

中间件支持两种传输类型：

### HTTP 传输

适用于基于 HTTP 通信的 MCP 服务器：

```typescript
{
  type: "http",
  url: "http://localhost:3101/mcp",
  serverId: "my-http-server"
}
```

### SSE 传输

适用于使用 Server-Sent Events（SSE）的 MCP 服务器：

```typescript
{
  type: "sse",
  url: "https://mcp.example.com/sse",
  headers: {
    "Authorization": "Bearer token"
  },
  serverId: "my-sse-server"
}
```
