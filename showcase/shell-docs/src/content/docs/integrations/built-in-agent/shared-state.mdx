在你的 React 应用与内置智能体之间双向共享状态。你的应用可以读写智能体状态，智能体也可以更新状态，让你的 UI 实时响应。

## 这是什么？

共享状态让你的前端与智能体保持同步。智能体可以更新状态（例如向列表添加条目或更改设置），你的 React 组件会自动重新渲染。你的应用也可以写入供智能体读取的状态。

## 什么时候应该使用它？

- 智能体需要能够修改你应用的 UI（添加条目、更新字段、切换设置）
- 你希望在智能体工作时获得实时的 UI 更新
- 你的应用需要读取智能体的工作进展（进度指示器、中间结果）

<Callout type="info">
如需完整示例——展示如何依据结构化的 AI 判断选择预先准备好的控件，并把用户操作返回给智能体——请参阅 [CopilotKit + Jev 示例集](/cookbook/jev-generative-ui)。
</Callout>

## 读取智能体状态

使用 `useAgent` hook 访问智能体的当前状态：

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2"; // [!code highlight]

function TaskBoard() {
  // [!code highlight:3]
  const { agent } = useAgent();

  // Read state set by the agent // [!code highlight]
  const tasks = (agent.state.tasks as any[]) ?? [];

  return (
    <div>
      <h2>Tasks</h2>
      <ul>
        {tasks.map((task, i) => (
          <li key={i}>
            {task.title} — {task.status}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

<Callout type="info">
  `agent.state` 是响应式的——当智能体更新状态时，你的组件会自动重新渲染。
</Callout>

## 从前端写入状态

你也可以从前端把状态推送给智能体：

```tsx title="app/page.tsx"
import { useAgent } from "@copilotkit/react-core/v2";

function SettingsPanel() {
  const { agent } = useAgent();

  const handleThemeChange = (theme: string) => {
    agent.setState({ // [!code highlight]
      ...agent.state, // [!code highlight]
      userPreferences: { theme }, // [!code highlight]
    }); // [!code highlight]
  };

  return (
    <div>
      <button onClick={() => handleThemeChange("dark")}>Dark Mode</button>
      <button onClick={() => handleThemeChange("light")}>Light Mode</button>
    </div>
  );
}
```

## 工作原理

内置智能体通过 AG-UI 协议自动获得对状态工具（`AGUISendStateSnapshot` 和 `AGUISendStateDelta`）的访问能力。当智能体调用这些工具时：

1. 智能体发送状态更新（完整快照或增量）
2. CopilotKit runtime 通过 SSE 将更新传递到前端
3. 你的 `useAgent` hook 接收更新并触发重新渲染

无需任何额外的后端配置——状态工具对内置智能体默认可用。

## 示例：协作式待办清单

下面是一个完整示例，智能体可以在其中添加并管理任务：

```tsx title="app/page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";
import { useAgent } from "@copilotkit/react-core/v2";

function TodoApp() {
  const { agent } = useAgent();

  const todos = (agent.state.todos as any[]) ?? [];

  return (
    <div style={{ display: "flex", gap: "1rem" }}>
      <div>
        <h2>My Todos</h2>
        <ul>
          {todos.map((todo, i) => (
            <li key={i} style={{ textDecoration: todo.done ? "line-through" : "none" }}>
              {todo.text}
            </li>
          ))}
        </ul>
      </div>
      <CopilotChat
        labels={{
          welcomeMessageText: "I can help manage your todos. Try 'Add a task to buy groceries'.",
        }}
      />
    </div>
  );
}
```

当你告诉智能体 “Add a task to buy groceries”（添加一条购买杂货的任务）时，它会更新共享状态，你的待办清单会立即渲染出这个新条目。
