## 接下来做什么？

关于后续步骤，这里有一些建议：

- 使用 [`useCopilotChatSuggestions`](/reference/v1/hooks/useCopilotChatSuggestions) 钩子为你的 copilot 添加建议。
- 为你的聊天窗口添加一条初始助手消息（更多信息请查阅 [`<CopilotPopup />`](/reference/v1/components/chat/CopilotPopup) 的文档）。
- 深入了解十分实用的 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) 钩子，它支持设置系统消息、追加消息等操作。
- 使用 [`<CopilotTextarea />`](/reference/v1/components/CopilotTextarea) 组件实现自动补全。
- 跟随 [Textarea 自动补全教程](/tutorials/ai-powered-textarea/overview) 进一步了解 CopilotKit。

我们很快会推出更多教程。
