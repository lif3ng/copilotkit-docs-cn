---
title: "第 1 步：检出仓库"
---

<Steps>
<Step>
### 检出仓库
我们首先检出待办清单应用的基础代码。

```shell
GIT_LFS_SKIP_SMUDGE=1 git clone --depth 1 https://github.com/CopilotKit/CopilotKit.git
cd CopilotKit/examples/starters/todos-app/start
```

</Step>
<Step>
### 安装依赖

要安装依赖，请运行以下命令：

```shell
npm install
```

</Step>
<Step>
### 启动项目

现在，你可以运行以下命令启动项目：

```shell
npm run dev
```

你应该可以访问 [http://localhost:3000](http://localhost:3000)，看到待办清单应用。不妨先随便把玩一下，感受一下这个应用。

</Step>
</Steps>

接下来，我们开始为这个应用添加一些 AI copilot 超能力。
