## 你将学到什么

在本教程中，你将为一个简单的邮件应用添加 AI 驱动的自动补全。该应用是一个简单的邮件客户端，带有一个用于撰写邮件的普通 textarea。你将在应用中加入 CopilotKit，让 textarea 在你输入时提供相关的自动补全。textarea 将能感知完整的邮件历史。

你将学到：

- 💡 如何使用 `useAgentContext` 让你的 copilot 读取应用的状态
- 💡 如何使用 `<CopilotTextarea />` 组件在应用中获得即时的、感知上下文的自动补全
- 💡 如何使用 Copilot Textarea 操作弹窗在 textarea 中生成文本或调整已有文本
