现在待办清单应用已经跑起来了，接下来就可以集成 CopilotKit。在本教程中，我们将安装以下依赖：

- `@copilotkit/react-core`：CopilotKit 的核心库，包含 CopilotKit provider 和实用的钩子。
- `@copilotkit/react-ui`：CopilotKit 的 UI 库，包含侧边栏、聊天弹窗、textarea 等 CopilotKit UI 组件。

## 安装依赖

要安装 CopilotKit 依赖，请运行以下命令：

```npm
npm install @copilotkit/react-core @copilotkit/react-ui
```

### CopilotKit 聊天弹窗

我们提供了多个即插即用的组件，供你与 copilot 交互，例如 `<CopilotPopup/>`、`<CopilotSidebar/>` 和 `<CopilotChat/>`。当然，你也可以以无头模式（headless）使用 CopilotKit，并通过 [`useCopilotChat`](/reference/v1/hooks/useCopilotChat) 提供完全自定义的 UI。

在本教程中，我们将使用 `<CopilotPopup/>` 组件来展示聊天弹窗。

```tsx title="app/page.tsx" showLineNumbers {6-7,15}
"use client";

import { TasksList } from "@/components/TasksList";
import { TasksProvider } from "@/lib/hooks/use-tasks";
import { CopilotKit } from "@copilotkit/react-core/v2";
import { CopilotPopup } from "@copilotkit/react-core/v2"; // [!code highlight]
import "@copilotkit/react-core/v2/styles.css"; // [!code highlight]

export default function Home() {
  return (
    <>
      <TasksProvider>
        <TasksList />
      </TasksProvider>
      {/* [!code highlight:1] */}
      <CopilotPopup />
    </>
  );
}
```

以下是刚才所做的事情：

- 我们从 `@copilotkit/react-ui` 导入了 `<CopilotPopup />` 组件。
- 我们用 `<CopilotKit>` provider 包裹了页面。
- 我们从 `@copilotkit/react-ui` 导入了内置样式。

现在，回到你的应用，你会在页面右下角看到一个聊天弹窗。至此，你就可以开始与 copilot 交互了！🎉
