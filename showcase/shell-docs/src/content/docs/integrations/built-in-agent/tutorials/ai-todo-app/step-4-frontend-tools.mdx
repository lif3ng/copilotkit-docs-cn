现在，是时候让我们的 copilot 更上一层楼了——让它能够执行工具。

## 可用工具

我们再来看一看 [`lib/hooks/use-tasks.tsx`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/starters/todos-app/start/lib/hooks/use-tasks.tsx#L19-L33) 文件中应用的状态。

本质上，我们希望 copilot 能够调用 `addTask`、`setTaskStatus` 和 `deleteTask` 这几个函数。

## `useFrontendTool` 钩子

[`useFrontendTool`](/reference/v1/hooks/useFrontendTool) 钩子可以为 copilot 提供可用的工具。我们在 [`lib/hooks/use-tasks.tsx`](https://github.com/CopilotKit/CopilotKit/tree/main/examples/starters/todos-app/start/lib/hooks/use-tasks.tsx) 文件中实现它。

```tsx filename="lib/hooks/use-tasks.tsx" showLineNumbers {3-3,8-22,24-38,40-61}
// ... the rest of the file

import { useAgentContext, useFrontendTool } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod"; // [!code highlight]

export const TasksProvider = ({ children }: { children: ReactNode }) => {
  const [tasks, setTasks] = useState<Task[]>(defaultTasks);

  // [!code highlight:10]
  useFrontendTool({
    name: "addTask",
    description: "Adds a task to the todo list",
    parameters: z.object({
      title: z.string().describe("The title of the task"),
    }),
    handler: async ({ title }) => {
      addTask(title);
      return `Added task: ${title}`;
    },
  });

  // [!code highlight:10]
  useFrontendTool({
    name: "deleteTask",
    description: "Deletes a task from the todo list",
    parameters: z.object({
      id: z.number().describe("The id of the task"),
    }),
    handler: async ({ id }) => {
      deleteTask(id);
      return `Deleted task ${id}`;
    },
  });

  // [!code highlight:11]
  useFrontendTool({
    name: "setTaskStatus",
    description: "Sets the status of a task",
    parameters: z.object({
      id: z.number().describe("The id of the task"),
      status: z
        .enum(Object.values(TaskStatus) as [string, ...string[]])
        .describe("The status of the task"),
    }),
    handler: async ({ id, status }) => {
      setTaskStatus(id, status);
      return `Set task ${id} status to ${status}`;
    },
  });

  // ... the rest of the file
};
```

`useFrontendTool` 钩子十分强大，它允许我们向 copilot 注册工具。它接收一个对象，包含以下属性：

- `name` 是工具的名称。
- `description` 是工具的描述。选择一个恰当的描述非常重要，这样 copilot 才能选对工具。
- `parameters` 是一个 Zod schema，定义了该工具接受的参数，可提供运行时校验和 TypeScript 类型推断。
- `handler` 是工具被触发时调用的函数。得益于 Zod，它是类型安全的！

你可以在[这里](https://docs.copilotkit.ai/reference/v1/hooks/useFrontendTool)查阅 `useFrontendTool` 钩子的完整参考。
