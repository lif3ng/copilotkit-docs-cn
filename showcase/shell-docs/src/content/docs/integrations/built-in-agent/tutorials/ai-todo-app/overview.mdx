## 你将学到什么

在本教程中，你将对一个简单的待办清单应用进行增强，为其注入 copilot 能力。你将学到：

- 💡 如何嵌入带有聊天 UI 的应用内 copilot
- 💡 如何使用 `useAgentContext` 让你的 copilot 读取应用状态
- 💡 如何使用 `useFrontendTool` 让你的 copilot 执行工具
