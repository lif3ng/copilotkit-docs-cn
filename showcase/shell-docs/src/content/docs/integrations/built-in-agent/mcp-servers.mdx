## 什么是 MCP 服务器？

MCP（Model Context Protocol）服务器为你的智能体提供额外的工具与能力。内置智能体支持通过 **HTTP** 或 **SSE** 传输方式连接 MCP 服务器。

## 何时应该使用它？

- 你想把智能体连接到现有的兼容 MCP 的工具服务器
- 你需要添加来自第三方 MCP 提供方的能力
- 你想在多个智能体或应用之间共享工具

## SSE 传输

SSE（Server-Sent Events）传输方式是最常见的选择：

```typescript title="src/copilotkit.ts"
import { BuiltInAgent } from "@copilotkit/runtime/v2";

const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpServers: [
    {
      type: "sse", // [!code highlight]
      url: "https://my-mcp-server.example.com/sse",
    },
  ],
});
```

### 身份验证头

传入自定义请求头进行身份验证：

```typescript
const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpServers: [
    {
      type: "sse",
      url: "https://my-mcp-server.example.com/sse",
      headers: { // [!code highlight:3]
        Authorization: `Bearer ${process.env.MCP_API_KEY}`,
      },
    },
  ],
});
```

## HTTP 传输

HTTP（Streamable HTTP）传输方式使用标准 HTTP 请求：

```typescript
const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpServers: [
    {
      type: "http", // [!code highlight]
      url: "https://my-mcp-server.example.com/mcp",
    },
  ],
});
```

HTTP 传输方式还接受可选的 `options`，用于对底层的 `StreamableHTTPClientTransport` 进行高级配置。

## 多个服务器

连接多个 MCP 服务器——来自所有服务器的工具都可供智能体使用：

```typescript
const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpServers: [
    {
      type: "sse",
      url: "https://search-mcp.example.com/sse",
    },
    {
      type: "sse",
      url: "https://db-mcp.example.com/sse",
      headers: { Authorization: `Bearer ${process.env.DB_MCP_KEY}` },
    },
    {
      type: "http",
      url: "https://analytics-mcp.example.com/mcp",
    },
  ],
});
```

### 工具名称冲突

两个服务器可能暴露同名的工具。例如，预发服务器与生产服务器暴露相同的工具。智能体会保留每一个副本。当名称发生冲突时，每个 MCP 副本都会加上前缀，并且智能体会记录一条警告：

```typescript
const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpServers: [
    { type: "http", url: "https://staging.example.com/mcp", name: "staging" }, // [!code highlight]
    { type: "http", url: "https://prod.example.com/mcp", name: "production" }, // [!code highlight]
  ],
});
// Both servers expose `search`, so the model sees `staging_search` and `production_search`.
```

- 只有发生冲突的名称才会加前缀，其他工具保持原名。
- 如果某个 MCP 工具与你自己的工具同名，你的工具保留原名，MCP 工具加前缀。
- 如果服务器没有设置 `name`，前缀为 `mcp<N>`，其中 N 是该服务器在 `mcpClients`（其次 `mcpServers`）中的位置，从 1 开始。`mcpClients` 中的条目没有 `name`，因此始终使用 `mcp<N>`。
- `name` 中除字母、数字、`_` 和 `-` 以外的字符都会变成 `_`。
- 如果加前缀后的名称已被占用，会追加一个数字，例如 `production_search_2`。这种情况发生在两台服务器的 `name` 相同时，因此请为每台服务器设置不同的 `name`。
- 你在前端注册的工具渲染器只匹配暴露后的名称。如果 `search` 变成了 `production_search`，就要为 `production_search` 注册渲染器。

## 与服务器工具配合使用

MCP 服务器可与 `defineTool` 服务器工具并用——智能体能看到来自两个来源的全部工具：

```typescript
import { BuiltInAgent, defineTool } from "@copilotkit/runtime/v2";
import { z } from "zod";

const customTool = defineTool({
  name: "getUser",
  description: "Get the current user",
  parameters: z.object({}),
  execute: async () => {
    return { name: "Jane", role: "Admin" };
  },
});

const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  tools: [customTool], // Your custom tools
  mcpServers: [        // Plus tools from MCP servers
    { type: "sse", url: "https://search-mcp.example.com/sse" },
  ],
});
```

## 用户自管的 MCP 客户端

`mcpServers` 方式会在每次智能体运行时新建一条 MCP 连接。对于延迟敏感的场景——或者当你需要持久连接、动态身份验证或工具缓存时——请改用 `mcpClients`。MCP 客户端由你自己创建和管理，智能体只需调用 `.tools()` 即可获取工具定义。

```typescript
import { BuiltInAgent } from "@copilotkit/runtime/v2";
import { createMCPClient } from "@ai-sdk/mcp";
import { StreamableHTTPClientTransport } from "@modelcontextprotocol/sdk/client/streamableHttp.js";

// Create a persistent client at startup
const transport = new StreamableHTTPClientTransport(
  new URL("https://my-mcp-server.example.com/mcp"),
);
const client = await createMCPClient({ transport });

const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpClients: [client], // [!code highlight]
});
```

与 `mcpServers` 不同，智能体**绝不会**创建或关闭这些客户端——完整的生命周期由你掌控。

### 工具缓存

默认情况下，`.tools()` 会在每次智能体运行时从 MCP 服务器拉取工具。若要在启动时缓存工具：

```typescript
const client = await createMCPClient({ transport });

let cachedTools: ToolSet | null = null;
const warmupPromise = client.tools().then(tools => { cachedTools = tools; });

const provider = {
  async tools() {
    if (cachedTools) return cachedTools;
    await warmupPromise;
    return cachedTools!;
  },
};

const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpClients: [provider], // [!code highlight]
});
```

工具发现在后台只运行一次。只有当预热尚未完成时，首个请求才会等待；后续请求会立即从缓存返回。

### 动态身份验证

使用持久客户端时，身份验证令牌可能在请求之间过期。请在你的 provider 内部处理这种情况：

```typescript
const provider = {
  async tools() {
    if (isTokenExpired()) {
      await currentClient.close();
      currentClient = await createMCPClient({
        transport: makeTransport(getFreshToken()),
      });
    }
    return currentClient.tools();
  },
};

const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpClients: [provider],
});
```

只有当令牌真正过期时才需要付出重连成本，而不是每个请求都要付出。

### 与 mcpServers 配合使用

`mcpClients` 与 `mcpServers` 可以搭配使用。两者的工具会合并——名称冲突时，`mcpServers` 的工具优先：

```typescript
const builtInAgent = new BuiltInAgent({
  model: "openai:gpt-5.4-mini",
  mcpClients: [persistentClient],  // User-managed, persistent
  mcpServers: [                     // Agent-managed, per-request
    { type: "sse", url: "https://other-mcp.example.com/sse" },
  ],
});
```

## 传输方式参考

| 属性 | SSE | HTTP | 说明 |
|------|-----|------|------|
| `type` | `"sse"` | `"http"` | 传输类型 |
| `url` | string | string | MCP 服务器 URL |
| `headers` | `Record<string, string>` | — | 自定义 HTTP 请求头（仅 SSE） |
| `options` | — | `StreamableHTTPClientTransportOptions` | 传输选项（仅 HTTP） |
