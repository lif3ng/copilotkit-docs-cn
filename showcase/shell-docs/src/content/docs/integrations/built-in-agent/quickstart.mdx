## 从你的编码智能体开始

使用这个提示词，与 CopilotKit 的内置智能体一起搭建一个可用的聊天应用。你的编码智能体会跟随本指南在你的项目中操作，你也可以按下面的手动步骤逐步完成。

<PageAgentPrompt />

## 前置条件

开始之前，你需要准备以下内容：

- 一个 OpenAI API 密钥（或 Anthropic/Google——参见[模型选择](/model-selection)）
- Node.js 20+
- 你顺手的包管理器

## 开始使用

<Steps>
    <Step>
        ### 创建你的前端

        CopilotKit 的 React 组件可与 Next.js、React Router、Remix、TanStack Start、Vite 及其他 React 应用配合使用。本演练使用 Next.js，因为它可以在同一个项目中同时承载前端与运行时。

        ```bash
        npx create-next-app@latest my-copilot-app
        cd my-copilot-app
        ```

        <Callout type="info" title="已有应用？">
          保留你现有的配置，直接在其中安装 CopilotKit 即可。CopilotKit CLI（`npx copilotkit@latest create`，别名为 `init`）会创建一个独立项目，不会修改现有应用。

          <FrontendOnly frontend="react">
          如果是纯客户端的 Vite 应用，请参阅 [React SPA 指南](/react-spa)；或参照 React Router 或 TanStack Start 示例，[将运行时部署到你的服务器框架](/runtime-server-adapter)。
          </FrontendOnly>
          <FrontendOnly frontend="angular">
          对于现有应用，请参阅 [Angular 指南](/angular)，或[将运行时部署到你的服务器框架](/runtime-server-adapter)。
          </FrontendOnly>
        </Callout>
    </Step>
    <Step>
        ### 安装 CopilotKit 软件包

        ```npm
        npm install @copilotkit/react-core @copilotkit/runtime
        ```

        下文用到的组件（`CopilotKitProvider`、`CopilotSidebar`）与样式表都来自
        `@copilotkit/react-core/v2`，因此这种配置不需要 `@copilotkit/react-ui`。

        <Callout type="info" title="TypeScript：使用 bundler 模块解析">
          CopilotKit 的 `/v2` 子路径通过软件包的 `exports` 映射发布，而 TypeScript 旧版的
          `"moduleResolution": "node"`（`node10`）会忽略它。在该设置下，即使应用能正常运行，
          类型检查也会报 `Cannot find module '@copilotkit/react-core/v2'`。请在
          `tsconfig.json` 中设置 `"moduleResolution": "bundler"`；如果 `module` 是
          `commonjs` 或未设置，还需设置 `"module": "esnext"`。`create-next-app` 已经使用
          `bundler`。
        </Callout>
    </Step>
    <Step>
        ### 配置你的环境

        创建 `.env` 文件并加入你的 OpenAI API 密钥：

        ```plaintext title=".env"
        OPENAI_API_KEY=your_openai_api_key
        ```

        <Callout type="info" title="其他模型呢？">
          本示例使用 OpenAI 模型。Anthropic、Google 或自定义模型的配置请参见[模型选择](/model-selection)。
        </Callout>
    </Step>
    <Step>
        ### 设置 Copilot Runtime

        使用 `BuiltInAgent` 与 `CopilotRuntime` 创建一个 API 路由：

        <Callout type="warn" title="已有智能体？请不要使用 BuiltInAgent">
          `BuiltInAgent` 是 CopilotKit *自带*的智能体——它直接调用模型。把它注册为
          `default` 意味着聊天会与它对话，而不是与你已编写的任何智能体对话。它是取代你的智能体，而不是连接它。

          如果你已经有 LangGraph、CrewAI、Mastra、ADK、Pydantic AI 或其他智能体，请采用本页的前端步骤，
          但运行时接线请参考**你的框架的**快速开始——它注册的是*你自己的*智能体，例如
          [LangGraph（Python）](/langgraph-python/quickstart)。你可以从[文档首页](/)选择你的框架。
        </Callout>

        ```ts title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
        import {
          CopilotRuntime,
          createCopilotRuntimeHandler,
        } from "@copilotkit/runtime/v2";
        import { BuiltInAgent } from "@copilotkit/runtime/v2"; // [!code highlight]

        const builtInAgent = new BuiltInAgent({ // [!code highlight:3]
          model: "openai:gpt-5.4-mini",
        });

        const runtime = new CopilotRuntime({
          agents: { default: builtInAgent }, // [!code highlight],
        });

        const handler = createCopilotRuntimeHandler({
          runtime,
          basePath: "/api/copilotkit",
        });

        export const GET = handler;
        export const POST = handler;
        export const PATCH = handler;
        export const DELETE = handler;
        ```
    </Step>
    <Step>
        ### 配置 CopilotKit Provider

        用 CopilotKit provider 包裹你的应用：

        ```tsx title="app/providers.tsx"
        "use client";

        import { CopilotKitProvider } from "@copilotkit/react-core/v2";

        export function Providers({ children }: { children: React.ReactNode }) {
          return (
            <CopilotKitProvider runtimeUrl="/api/copilotkit">
              {children}
            </CopilotKitProvider>
          );
        }
        ```

        `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此改为渲染你的客户端文件：

        ```tsx title="app/layout.tsx"
        import { Providers } from "./providers"; // [!code highlight]
        import "@copilotkit/react-core/v2/styles.css"; // [!code highlight]
        import './globals.css';

        // ...

        export default function RootLayout({ children }: {children: React.ReactNode}) {
          return (
            <html lang="en">
              <body>
                {/* [!code highlight:3] */}
                <Providers>
                  {children}
                </Providers>
              </body>
            </html>
          );
        }
        ```

        <Callout type="info" title="此相对 runtimeUrl 假设由 Next.js 托管运行时">
          `/api/copilotkit` 之所以能解析，是因为 Next.js 从同一源提供你的应用与运行时。纯客户端前端没有共享源，
          因此需要自己单独的运行时服务器，以及形如
          `http://localhost:8200/api/copilotkit` 的绝对 `runtimeUrl`。`/react-spa`、`/vue`、
          `/angular` 和 `/react-native` 各前端指南都演示了这种配置。
        </Callout>
    </Step>
    <Step>
        ### 添加聊天界面

        将 CopilotSidebar 组件添加到你的页面：

        ```tsx title="app/page.tsx"
        "use client"; // [!code highlight]

        import { CopilotSidebar } from "@copilotkit/react-core/v2"; // [!code highlight]

        export default function Page() {
          return (
            <main>
              <h1>Your App</h1>
              {/* [!code highlight:1] */}
              <CopilotSidebar />
            </main>
          );
        }
        ```
    </Step>
    <Step>
        ### 启动开发服务器

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn', 'bun']}>
            <Tab value="npm">
                ```bash
                npm run dev
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm dev
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn dev
                ```
            </Tab>
            <Tab value="bun">
                ```bash
                bun dev
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### 开始对话

        你的 AI 智能体现在已经可以使用了！试着问它几个问题：

        ```
        Can you tell me a joke?
        ```

        ```
        Can you help me understand AI?
        ```

        ```
        What do you think about React?
        ```

                - 检查 `.env` 文件中的 API 密钥是否设置正确
                - 确保运行时端点路径与 CopilotKit provider 中的 `runtimeUrl` 一致
            </Accordion>
        </Accordions>

    </Step>

    </Step>
