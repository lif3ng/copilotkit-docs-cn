**内置智能体**是 CopilotKit 中最简单的智能体选项，也就是“开箱即用”的那一个。它直接连接 LLM，完整支持工具、生成式 UI、共享状态以及所有 CopilotKit 特性——无需依赖外部智能体框架。

它开箱即用地支持来自 OpenAI、Anthropic、Google 的主流模型，以及由 AI SDK 定义的各种模型

## 何时使用内置智能体

- **快速配置** —— 无需配置或部署外部智能体框架
- **聊天 + 工具** —— 你的用例以对话为主，同时涉及前端工具与服务器工具
- **直接访问模型** —— 你想直接使用 OpenAI、Anthropic、Google 或 AI SDK 的模型

<Callout type="info">
如果你需要对智能体循环（agent loop）更强的控制，可以考虑改用[智能体框架](/#explore-by-ai-backend)。
</Callout>
