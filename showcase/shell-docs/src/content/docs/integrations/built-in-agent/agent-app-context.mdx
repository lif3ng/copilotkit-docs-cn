使用 `useAgentContext` hook 与内置智能体共享应用的状态与上下文。内置智能体会自动接收这些上下文，无需任何后端配置。

<Callout>
    最后这一点是内置智能体特有的。你自己托管的智能体会在 AG-UI 运行输入中收到相同的
    条目，而各框架会自行决定其中哪些内容到达模型——请参阅你的框架自己的智能体应用上下文
    （Agent App Context）页面，例如 [ADK](/adk/agent-app-context)、
    [LangGraph](/langgraph/agent-app-context) 或 [Mastra](/mastra/agent-app-context)。
</Callout>

## 这是什么？

`useAgentContext` hook 允许你注册会纳入智能体上下文的应用特定数据。可以是当前用户、页面内容、购物车商品，或任何能帮助智能体给出相关响应的数据。

## 什么时候该用它？

- 你想让智能体了解应用的当前状态
- 你需要智能体引用用户特定数据（姓名、偏好、角色）
- 智能体应当知道用户当前所在的页面或视图
- 你想提供领域特定数据，而又不把它硬编码进系统提示

<Step>
### 在组件中注册上下文

使用 `useAgentContext` 与智能体共享任意数据：

```tsx title="components/Dashboard.tsx"
"use client"; // only necessary for Next.js App Router // [!code highlight]
import { useAgentContext } from "@copilotkit/react-core/v2"; // [!code highlight]
import { useState } from "react";

export function Dashboard() {
  const [user] = useState({
    name: "Jane Smith",
    role: "Engineering Manager",
    team: "Platform",
  });

  const [projects] = useState([
    { id: 1, name: "Auth Redesign", status: "in-progress" },
    { id: 2, name: "API v2", status: "planning" },
  ]);

  // Share user info with the agent
  // [!code highlight:4]
  useAgentContext({
    description: "The currently logged-in user",
    value: user,
  });

  // Share project data with the agent
  // [!code highlight:4]
  useAgentContext({
    description: "The user's active projects",
    value: projects,
  });

  return <div>{/* Your dashboard UI */}</div>;
}
```
</Step>

<Step>
### 就这么简单——无需后端配置

LangGraph 需要你配置智能体状态才能接收上下文，而内置智能体会自动处理。你注册的上下文会包含在智能体的系统提示中，因此它可以立即引用你的应用数据。

```
User: "What projects am I working on?"
Agent: "You're working on two projects:
  1. Auth Redesign (in progress)
  2. API v2 (planning)"
```
</Step>
</Steps>

## 多个上下文

你可以在不同组件中多次调用 `useAgentContext`。所有注册的上下文会合并后发送给智能体：

```tsx title="components/UserInfo.tsx"
useAgentContext({
  description: "Current user profile",
  value: { name: "Jane", role: "Manager" },
});
```

```tsx title="components/PageContext.tsx"
useAgentContext({
  description: "The page the user is currently viewing",
  value: { page: "settings", section: "notifications" },
});
```

智能体能看到两个上下文，并在响应时引用其中任意一个。

## 动态上下文

底层数据变化时，上下文会自动更新：

```tsx
export function TaskList() {
  const [tasks, setTasks] = useState([]);

  // Context updates whenever tasks change // [!code highlight]
  useAgentContext({
    description: "The user's current task list",
    value: tasks,
  });

  return (
    <div>
      {/* When tasks are added/removed, the agent sees the updated list */}
    </div>
  );
}
```
