# 常见问题

常见问题的答案都在这里！

<Accordions>
  <Accordion title="什么是 Copilot？">
    Copilot 是驻留在你的应用中的可信伙伴，帮助你的用户把事情办成。
    它主要有两种类型：**礼宾型**（Concierge）与**工作型**（Worker）。

    ### 礼宾型

    礼宾型 Copilot 了解你的应用的能力与完整的用户上下文。它作为智能中介，
    把高层的用户意图转化为具体的操作。

    例如，我们的[银行助手](https://github.com/CopilotKit/CopilotKit/tree/main/examples/showcases/reskinnable-demo)就实现了礼宾型 Copilot，
    帮助用户管理自己的（_模拟_）银行需求。


    ### 工作型

    工作型 Copilot 是特定领域的智能体，能帮助用户完成核心的工作任务。
    它是用户的搭档：擅长某些任务，而在另一些任务上稍逊一筹。
    最终，它能让你的用户产出远超自己预期的成果。这种模式
    常见于后台办公（backoffice）类 Copilot 中。

    可以把工作型 Copilot 想象成 Cursor、Replit Agent 或 Windsurf，只是面向任意领域。例如，
    可以看看我们的[开放研究员 ANA](https://github.com/CopilotKit/CopilotKit/tree/main/examples/showcases/research-canvas)。

  </Accordion>
  <Accordion title="CopilotKit 的主要特性有哪些？">
    ### 开箱即用的聊天组件
    精美、强大且可定制的聊天组件，一次 import 即可使用。
    | | |
    |---------|-------------|
    | **聊天** | 简单而强大的聊天界面 |
    | **弹窗** | 以弹窗形式呈现的聊天组件 |
    | **侧边栏** | 以侧边栏形式呈现的聊天组件 |
    | **Copilot Textarea** | 强大的 AI 自动补全，可直接替换任何 textarea |
    | [**无头**](/custom-look-and-feel/slots) | 完全自定义聊天界面 |

    ### 深度集成的 Copilot
    赋予 Copilot 直接在你的应用中执行工具的能力。
    |  |  |
    |---------|-------------|
    | **Copilot 可读状态** | 让 Copilot 能够读取并理解应用状态 |
    | **前端工具** | Copilot 可以在应用中执行工具 |
    | [**生成式 UI**](/generative-ui/your-components/display-only) | 在 copilot 聊天界面中渲染任意组件 |
    | **AI 自动建议** | 在 AI 聊天界面中提供 AI 驱动的自动建议 |
    | **Copilot 任务** | 让你的 copilot 基于应用状态主动执行工具 |

    ### 丰富的智能体体验
    轻松把你的 LangChain 智能体集成到产品中。
    | |  |
    |---------|-------------|
    | **深度支持 LangChain** | 把 LangChain 智能体直接引入你的产品 |
    | **人机协同（human-in-the-loop）** | 让你的用户与智能体协作解决复杂问题 |
    | **共享状态** | 用不到 10 行代码渲染 LangChain 智能体的状态 |

  </Accordion>
  <Accordion title="这一切是如何运作的？">
    问得好！CopilotKit 有三个主要组成部分：
    1. **CopilotKit UI**：用于构建你的 Copilot 与智能体的 UI 组件。
    2. **CopilotKit Runtime**：用于构建你的 Copilot 与智能体的运行时。它是你的 Copilot 与智能体的后端。
    3. **CopilotKit SDK**：在更复杂的应用中，你会用 SDK 把 CopilotKit 深度集成到你的智能体中。
  </Accordion>

  <Accordion title="CopilotKit 可以使用任意 LLM 吗？">
    可以！CopilotKit 支持大多数 LLM，包括 OpenAI、Anthropic、Google 等。此外，任何 LangChain 支持的 LLM 都可以使用。

    更多信息请查阅关于[自带 LLM](/model-selection) 的文档。

  </Accordion>
