CopilotKit v2 提供了一组精炼的 hooks，用于让 agent 在你的应用中*做事*，以及*渲染*它所做的事情。它们分为两类：注册行为的 hooks，以及注册工具调用在聊天中外观的 hooks。把本页当作快速导览，然后顺着每个 hook 查看其完整参考。

## 30 秒版

| Hook | 适用场景 |
| --- | --- |
| [`useFrontendTool`](/reference/hooks/useFrontendTool) | 给 agent 一个可在客户端调用的工具（在浏览器中运行逻辑），并可选内联 UI。 |
| [`useRenderTool`](/reference/hooks/useRenderTool) | 按名称（带类型）为特定工具调用渲染 UI，而无需定义工具的 handler。 |
| [`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool) | 为任何没有专属渲染器的工具调用提供一个通配渲染器。 |
| [`useComponent`](/reference/hooks/useComponent) | 把 React 组件注册为具名的工具渲染器（组件优先的生成式 UI）。 |
| [`useHumanInTheLoop`](/reference/hooks/useHumanInTheLoop) | 在工具调用处暂停 agent，等待用户批准、编辑或提供输入。 |
| [`useInterrupt`](/reference/hooks/useInterrupt) | 处理 agent 发起的中断，用户响应后恢复执行。 |
| [`useRenderToolCall`](/reference/hooks/useRenderToolCall) | 获取工具调用的渲染函数，驱动你自己的自定义聊天界面（无头）。 |

## 如何选择

从动词入手。

- **“agent 应该在我的应用里*运行*某个东西。”** 使用 [`useFrontendTool`](/reference/hooks/useFrontendTool)。你定义工具的 schema 与 handler，由 agent 调用。加上 `render` 还能为该调用显示内联 UI。
- **“agent 的工具调用应该*呈现*成某个样子。”** 使用渲染类 hook。用 [`useRenderTool`](/reference/hooks/useRenderTool) 渲染某个具名工具，用 [`useComponent`](/reference/hooks/useComponent) 把 React 组件绑定到工具名，或用 [`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool) 兜底渲染你没显式处理的一切。
- **“agent 应该在继续之前*停下来问我*。”** 工具级的批准/编辑门控用 [`useHumanInTheLoop`](/reference/hooks/useHumanInTheLoop)，由 agent 发起、以用户输入恢复的中断用 [`useInterrupt`](/reference/hooks/useInterrupt)。
- **“我在构建*自己的*聊天 UI。”** 使用 [`useRenderToolCall`](/reference/hooks/useRenderToolCall)。它返回渲染函数，让你可以把工具调用输出放在无头布局的任何位置。

### 工具与渲染器的区别

这组 hook 中有两个会*注册工具*供 agent 调用：`useFrontendTool`（schema 与 handler）和 `useComponent`（一种组件优先的简写，内部包装 `useFrontendTool`，注册一个“handler”就是渲染你的组件的工具）。只渲染的 hooks——`useRenderTool`、`useDefaultRenderTool` 和 `useRenderToolCall`——*并不*定义工具；它们只*渲染*工具调用，这些调用可能来自你的前端（`useFrontendTool` / `useComponent`），也可能来自 agent/后端。正因如此，你可以把后端工具与 `useRenderTool` 搭配，而完全不用在客户端写 handler。
