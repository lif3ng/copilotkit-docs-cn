## 面向智能体聊天的预构建组件

CopilotKit 的聊天组件让你开箱即得一个功能完整、可定制的 AI 聊天界面。
它们负责处理流式传输、生成式 UI 和深度定制，让你专注于智能体的行为，而不是 UI 的管道工程。
