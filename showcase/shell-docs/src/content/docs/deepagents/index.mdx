## 前置条件

开始之前，你需要准备：

- 一个 OpenAI API 密钥
- Node.js 20+
- 你喜欢的包管理器
- 一个 LangSmith API 密钥——仅部署到 LangSmith Platform 时需要

## 快速开始
<Steps>
    <Step>
        ### 初始化你的智能体项目

        如果你还没有 Python 项目，用 `uv` 创建一个：

        ```bash
        uv init my-agent
        cd my-agent
        ```
    </Step>
    <Step>
        ### 添加必要的依赖

        这个智能体只需要 `deepagents`、`langchain-openai` 和 `copilotkit` 三个包：

        ```bash
        uv add deepagents copilotkit langchain-openai
        ```
    </Step>
    <Step>
        如果你已经写好了一个 LangGraph 智能体，参考下面的代码即可。这一步只是为了演示，我们创建一个简单的 LangGraph 智能体。

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
            <Tab value="LangSmith">
                首先，我们创建一个简单的 LangGraph 智能体：

                ```python title="main.py"
                from deepagents import create_deep_agent
                from copilotkit import CopilotKitMiddleware
                from langgraph.checkpoint.memory import MemorySaver

                def get_weather(location: str):
                    """Get weather for a location"""
                    return f"The weather in {location} is sunny."

                agent = create_deep_agent(
                    model="openai:gpt-5.4",
                    tools=[get_weather],
                    middleware=[CopilotKitMiddleware()], # for frontend tools and context
                    system_prompt="You are a helpful research assistant.",
                )

                graph = agent
                ```

                然后，要用 LangSmith 进行测试和部署，我们还需要一个 `langgraph.json`：

                ```sh
                touch langgraph.json
                ```

                ```json title="langgraph.json"
                {
                    "python_version": "3.12",
                    "dockerfile_lines": [],
                    "dependencies": ["."],
                    "package_manager": "uv",
                    "graphs": {
                        "sample_agent": "./main.py:agent"
                    },
                    "env": ".env"
                }
                ```
            </Tab>
            <Tab value="FastAPI">
                首先，把 `ag-ui-langgraph`、`fastapi` 和 `uvicorn` 包添加到你的项目中：

                ```bash
                uv add ag-ui-langgraph fastapi uvicorn
                ```

                然后，创建一个简单的 LangGraph 智能体，添加一个 FastAPI 应用，并把我们的智能体挂载为 AG-UI 端点。

                ```python title="main.py"
                import os
                from fastapi import FastAPI 
                import uvicorn

                # [!code highlight:2]
                from ag_ui_langgraph import add_langgraph_fastapi_endpoint
                from copilotkit import CopilotKitMiddleware, CopilotKitState, LangGraphAGUIAgent
                from deepagents import create_deep_agent
                from langgraph.checkpoint.memory import MemorySaver

                def get_weather(location: str):
                    """Get weather for a location"""
                    return f"The weather in {location} is sunny."

                agent = create_deep_agent(
                    model="openai:gpt-5.4",
                    tools=[get_weather],
                    middleware=[CopilotKitMiddleware()], # for frontend tools and context
                    system_prompt="You are a helpful research assistant.",
                    checkpointer=MemorySaver()
                )

                app = FastAPI()

                # [!code highlight:9]
                add_langgraph_fastapi_endpoint(
                    app=app,
                    agent=LangGraphAGUIAgent(
                        name="sample_agent",
                        description="An example agent to use as a starting point for your own agent.",
                        graph=agent,
                    ),
                    path="/",
                )

                def main():
                    """Run the uvicorn server."""
                    uvicorn.run(
                        "main:app",
                        host="0.0.0.0",
                        port=8123,
                        reload=True,
                    )

                if __name__ == "__main__":
                    main()
                ```
            </Tab>
        </Tabs>

        <Callout type="info" title="AG-UI 是什么？">
            AG-UI 是一个用于前端与智能体通信的开放协议。
        </Callout>
    </Step>
    <Step>
        ### 配置你的环境

        在你的智能体目录中创建一个 `.env` 文件，并添加你的 OpenAI API 密钥：

        ```plaintext title=".env"
        OPENAI_API_KEY=your_openai_api_key
        ```

        <Callout type="info" title="换其他模型呢？">
        起步模板默认配置为使用 OpenAI 的 GPT-4o，但你可以修改它以使用 LangGraph 支持的任意语言模型。
        </Callout>
    </Step>
    <Step>
        ### 创建你的前端

        CopilotKit 可以配合任何基于 React 的前端使用。本示例使用 Next.js。

        ```bash
        npx create-next-app@latest frontend
        cd frontend
        ```
    </Step>
    <Step>
        ### 安装 CopilotKit 包

        ```npm
        npm install @copilotkit/react-core @copilotkit/runtime
        ```
    </Step>
    <Step>
        ### 设置 Copilot Runtime

        创建一个 API 路由，把 CopilotKit 连接到你的 LangGraph 智能体：

        ```sh
        mkdir -p app/api/copilotkit && touch app/api/copilotkit/route.ts
        ```

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
            <Tab value="LangSmith">
                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
                import {
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                  InMemoryAgentRunner,
                } from "@copilotkit/runtime/v2";
                // [!code highlight]
                import { LangGraphAgent } from "@copilotkit/runtime/langgraph";

                const runtime = new CopilotRuntime({
                    agents: {
                        // [!code highlight:5]
                        sample_agent: new LangGraphAgent({
                            deploymentUrl:  process.env.LANGGRAPH_DEPLOYMENT_URL || "http://localhost:8123",
                            graphId: "sample_agent",
                            langsmithApiKey: process.env.LANGSMITH_API_KEY || "",
                        }),
                    },
                  runner: new InMemoryAgentRunner(),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                ```
            </Tab>
            <Tab value="FastAPI">
                ```tsx title="app/api/copilotkit/[[...slug]]/route.ts"
                import {
                  CopilotRuntime,
                  createCopilotRuntimeHandler,
                  InMemoryAgentRunner,
                } from "@copilotkit/runtime/v2";
                // [!code highlight]
                import { HttpAgent } from "@ag-ui/client";

                const runtime = new CopilotRuntime({
                    agents: {
                        // [!code highlight:3]
                        sample_agent: new HttpAgent({
                            url:  process.env.LANGGRAPH_DEPLOYMENT_URL || "http://localhost:8123",
                        }),
                    },
                  runner: new InMemoryAgentRunner(),
                });

                const handler = createCopilotRuntimeHandler({
                  runtime,
                  basePath: "/api/copilotkit",
                });

                export const GET = handler;
                export const POST = handler;
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### 配置 CopilotKit Provider

        用 CopilotKit provider 包裹你的应用：

        ```tsx title="app/providers.tsx"
        "use client";

        import { CopilotKit } from "@copilotkit/react-core/v2";

        export function Providers({ children }: { children: React.ReactNode }) {
          return (
            <CopilotKit runtimeUrl="/api/copilotkit" agent="sample_agent" useSingleEndpoint={false}>
              {children}
            </CopilotKit>
          );
        }
        ```

        `app/layout.tsx` 是服务端组件，无法直接导入 provider，因此它改为渲染你的客户端文件：

        ```tsx title="app/layout.tsx"
        // [!code highlight:2]
        import { Providers } from "./providers";
        import "@copilotkit/react-core/v2/styles.css";

        // ...

        export default function RootLayout({ children }: {children: React.ReactNode}) {
            return (
                <html lang="en">
                    <body>
                        {/* [!code highlight:3] */}
                        <Providers>
                            {children}
                        </Providers>
                    </body>
                </html>
            );
        }
        ```
    </Step>
    <Step>
    ### 添加聊天界面

    把 CopilotSidebar 组件添加到你的页面：

    ```tsx title="app/page.tsx"
    "use client";

    import { CopilotSidebar } from "@copilotkit/react-core/v2";
    import { useDefaultRenderTool } from "@copilotkit/react-core/v2";

    export default function Page() {
        useDefaultRenderTool({
        render: ({name, status, args, result}) => (
            <details>
                <summary>
                    {status === "complete"? `Called ${name}` : `Calling ${name}`}
                </summary>

                <p>Status: {status}</p>
                <p>Args: {JSON.stringify(args)}</p>
                <p>Result: {JSON.stringify(result)}</p>
            </details>
        )})

        return (
            <main>
                <h1>Your App</h1>
                <CopilotSidebar />
            </main>
        );
    }
    ```
    </Step>
    <Step>
        ### 启动你的智能体
        在你的智能体目录下，启动智能体服务器：

        <Tabs groupId="deployment_method" items={['LangSmith', 'FastAPI']}>
        <Tab value="LangSmith">
            ```bash
            cd ..
            npx @langchain/langgraph-cli dev --port 8123 --no-browser
            ```
        </Tab>
        <Tab value="FastAPI">
            ```bash
            cd ..
            uv run main.py
            ```
        </Tab>
        </Tabs>

        你的智能体将运行在 `http://localhost:8123`。
    </Step>
    <Step>
        ### 启动你的 UI

            </Tab>
        </Tabs>
    </Step>
</Steps>
