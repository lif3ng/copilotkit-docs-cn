`@copilotkit/angular` 为 CopilotKit 提供 Angular 组件、指令与服务。本指南将带你得到一个可运行的 Angular 应用，其聊天 UI 由 [Copilot Runtime](/backend/copilot-runtime) 支撑。当你在侧边栏中选择一个智能体后端时，下方的后端步骤会随之变化；未选择时，指南使用 CopilotKit 的 `BuiltInAgent`。

运行时跑在你自己的服务器上，把模型凭证挡在浏览器之外，并暴露 `CopilotChat` 会自动使用的 `default` 智能体。

## 从你的编码智能体开始

使用这段提示词，把你的 Angular 应用连接到 Copilot Runtime（使用所选的智能体后端），然后验证对话可用。你也可以按照下方的手动步骤操作。

## CopilotKit for Angular 是什么？

CopilotKit for Angular 是面向 AG-UI 智能体与 Copilot Runtime 的第一方、基于 signal 的 Angular 前端。它提供完整的聊天界面与无头（headless）API，并支持无 zone（zoneless）应用。

## 前置条件

- 一个 OpenAI API 密钥（或[模型选择](/model-selection)支持的其他模型提供方）
- Angular 22
- Node.js 22

## 快速开始

<Steps>
    <Step>
        ### 创建你的 Angular 应用

        如果还没有应用，先把 CLI 固定到受支持的大版本：

        ```bash
        npx @angular/cli@22 new my-copilot-app
        cd my-copilot-app
        ```
    </Step>
    <Step>
        ### 安装 CopilotKit

        安装 Angular 前端包、`@angular/cdk`，以及用于本地 Copilot Runtime 服务器的 `@copilotkit/runtime`：

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn']}>
            <Tab value="npm">
                ```bash
                npm install @copilotkit/angular @angular/cdk @copilotkit/runtime
                npm install -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm add @copilotkit/angular @angular/cdk @copilotkit/runtime
                pnpm add -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn add @copilotkit/angular @angular/cdk @copilotkit/runtime
                yarn add -D tsx typescript @types/node
                ```
            </Tab>
        </Tabs>

        <Callout type="info" title="让 @angular/cdk 与你的 Angular 版本匹配">
          `@angular/cdk` 必须与你的 Angular 大版本一致。大多数包管理器会替你解决这个问题，但如果遇到 peer-dependency 报错，请显式固定版本（例如 `@angular/cdk@^22`）。
        </Callout>
    </Step>
    <WhenAngularBackend selected={false}>
      <Step>
        ### 创建 Copilot Runtime

        添加一个小型 Node 服务器，在 `/api/copilotkit` 上承载 Copilot Runtime，并注册一个 `default` 内置智能体：

        ```ts title="server.ts"
        import { createServer } from "node:http";
        import { BuiltInAgent, CopilotRuntime } from "@copilotkit/runtime/v2";
        import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

        const runtime = new CopilotRuntime({
          agents: {
            default: new BuiltInAgent({
              model: "openai:gpt-5-mini",
              prompt: "You are a helpful assistant for an Angular app.",
            }),
          },
        });

        const port = Number(process.env['PORT'] ?? 8200);

        createServer(
          createCopilotNodeListener({
            runtime,
            basePath: "/api/copilotkit",
            cors: true,
          }),
        ).listen(port, () => {
          console.log(
            `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
          );
        });
        ```

        <Callout type="info" title="Angular 把运行时作为独立进程运行">
          Angular 没有路由处理器，因此 Copilot Runtime 是与你应用**相互独立的
          进程**——这里要开第二个终端，等你添加智能体后端后还要再开第三个。
          没有任何东西替你代理它，这就是下文 `runtimeUrl`
          是绝对 URL 而非相对路径的原因。

          `8200` 只是本指南的默认值。上面的服务器会读取 `PORT`，因此
          无需改动任何源码就能换端口：

          ```bash
          PORT=8250 npx tsx server.ts
          ```

          换端口后，把 `runtimeUrl` 设为对应的端口。如果你在同一台
          机器上运行着不止一个 CopilotKit 项目，这一步值得刻意去做——
          默认端口会冲突，而一个绑定到其他项目已占用端口的运行时，
          排查起来非常令人困惑。
        </Callout>
      </Step>
    </WhenAngularBackend>
    <WhenAngularBackend selected>
      <Step>
        ### 连接所选的智能体后端

        此 URL 保持了所选的智能体后端。Angular 的设置保持共享不变；
        下方的后端设置来自该集成的规范 showcase 源。

        <FrameworkSetup concept="agent-setup" />

        <Callout type="info" title="通过 Copilot Runtime 暴露所选的后端">
          配置 Copilot Runtime，把这个后端注册为 `/api/copilotkit` 上的
          `default` 智能体。关于其运行时适配器、凭证与服务器命令，
          请继续参阅所选后端的 [Copilot Runtime 指南](backend/copilot-runtime)。
          不要用独立 Angular 路径中的 `BuiltInAgent` 服务器替换它。
        </Callout>
      </Step>
    </WhenAngularBackend>
    <Step>
        ### 引入样式

        把包的样式表加入你的全局样式。它自成一体，因此聊天组件无需任何其他 CSS 即可渲染。

        ```css title="src/styles.css"
        @import "@copilotkit/angular/styles.css"; /* [!code highlight] */
        ```
    </Step>
    <Step>
        ### 连接到 Copilot Runtime

        把 `provideCopilotKit` 指向运行时端点。聊天会使用你的运行时注册为 `default` 的智能体。

        ```ts title="src/app/app.config.ts"
        import { ApplicationConfig } from "@angular/core";
        import { provideCopilotKit } from "@copilotkit/angular"; // [!code highlight]

        export const appConfig: ApplicationConfig = {
          providers: [
            // [!code highlight:3]
            provideCopilotKit({
              runtimeUrl: "http://localhost:8200/api/copilotkit",
            }),
          ],
        };
        ```
    </Step>
    <Step>
        ### 添加聊天 UI

        把 `CopilotChat` 组件导入你的根组件，并放进模板中。

        ```ts title="src/app/app.ts"
        import { Component } from "@angular/core";
        import { CopilotChat } from "@copilotkit/angular"; // [!code highlight]

        @Component({
          selector: "app-root",
          imports: [CopilotChat], // [!code highlight]
          template: `
            <!-- [!code highlight:3] -->
            <div style="height: 100vh">
              <copilot-chat />
            </div>
          `,
        })
        export class App {}
        ```

    </Step>
    <WhenAngularBackend selected={false}>
      <Step>
        ### 运行运行时与应用

        在一个终端启动 Copilot Runtime：

        ```bash
        export OPENAI_API_KEY=sk-...
        npx tsx server.ts
        ```

        在另一个终端启动 Angular 应用：

        ```bash
        npm start
        ```

        打开开发服务器的 URL（Angular CLI 会打印出来，通常是 `http://localhost:4200`），发送一条消息，你会看到它经由 Copilot Runtime 流式返回。

        <Accordions className="mb-4">
            <Accordion title="故障排查">
                - **聊天组件渲染无样式**：确认你已在 `src/styles.css` 中导入 `@copilotkit/angular/styles.css`。
                - **智能体没有响应**：确认运行时服务器正在运行，且 `http://localhost:8200/api/copilotkit/info` 能返回智能体信息。
                - **CORS 报错**：本地开发时在 `createCopilotNodeListener` 中保持 `cors: true`，生产环境则配置 CORS 允许你的 Angular 应用的源。
                - **模型鉴权报错**：确认在运行 `npx tsx server.ts` 的终端中已设置 `OPENAI_API_KEY`。
                - **安装时 peer-dependency 报错**：`@angular/cdk` 必须与你的 Angular 大版本匹配。请安装匹配的大版本，例如 Angular 22 上安装 `@angular/cdk@^22`。
                - **生产构建超出包体积预算**：CopilotKit 会引入 markdown 与语法高亮依赖，因此新应用可能超出 Angular 默认的 1 MB 预算。如果生产构建因体积失败，请调高 `angular.json` 中的 `budgets`。
            </Accordion>
        </Accordions>
      </Step>
    </WhenAngularBackend>
    <WhenAngularBackend selected>
      <Step>
        ### 运行后端、运行时与 Angular 应用

        按照其运行时指南中的命令启动所选的智能体后端与 Copilot Runtime。
        确认 `http://localhost:8200/api/copilotkit/info` 报告了
        `default` 智能体，然后启动 Angular：

        ```bash
        npm start
        ```

        打开 Angular CLI 打印的 URL（通常是 `http://localhost:4200`）并发送一条
        消息。此时请求会端到端地走所选路径：
        Angular → Copilot Runtime → 你所选的智能体后端。
      </Step>
    </WhenAngularBackend>
    <Step>
        <OpenInspectorStep components={props.components} />
    </Step>

</Steps>
