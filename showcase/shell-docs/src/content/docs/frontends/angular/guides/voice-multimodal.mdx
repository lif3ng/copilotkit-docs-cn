`CopilotChat` 内置麦克风控件与附件编辑器。语音输入经由 Copilot Runtime 转录，并以文本形式插入编辑器；多模态输入则在用户消息中附带图像或文档内容部分（content parts）。

## 什么是语音与多模态输入？

语音输入会在消息发送前，把录制的语音转换为可编辑的文本。多模态输入则在该消息中附带类型化的图像或文档内容部分，使兼容的模型能够理解文本之外的信息。

## 接受语音输入

显示麦克风无需任何组件选项。浏览器会请求麦克风权限、录制音频，并将其发送到 Runtime 转录端点。生成的文本在用户发送之前仍可编辑。

生产环境应用应通过 HTTPS 提供服务，浏览器才会授予麦克风访问权限。

### 配置 Runtime 转录

按照[语音后端配置](/voice#backend)添加专用的 Runtime 路由与转录服务。语音提供方的凭据应与智能体对话所用的凭据分开保管。对于内置智能体 Showcase，请设置：

```bash
OPENAI_TRANSCRIPTION_API_KEY=your-api-key
# Optional: defaults to https://api.openai.com/v1
OPENAI_TRANSCRIPTION_BASE_URL=https://your-speech-provider.example.com/v1
```

缺少专用凭据时，路由必须省略 `transcriptionService`。此时 Copilot Runtime 会在 `/info` 中报告 `audioFileTranscriptionEnabled: false`，聊天界面会隐藏麦克风，而不是暴露一个无法使用的控件。配置转录服务后，浏览器会将录制的音频发送到 `/api/copilotkit-voice/transcribe`。

语音请求可以像键入的请求一样调用相同的后端工具。只需针对后端实际暴露的工具名称注册渲染器：

<AngularSnippet region="voice-tool-renderers" />

渲染器注册是可选的。它只会改变匹配工具调用的展示方式，不会影响语音的采集或转录。

## 配置附件

定义一个 `AttachmentsConfig` 并将其绑定到聊天界面。可运行的 Showcase 接受最大 10 MiB 的图像与 PDF：

<AngularSnippet region="multimodal-attachments" />

```html title="media-chat.component.html"
<copilot-chat [attachments]="multimodalAttachments" />
```

`accept` 值用于过滤文件选择器，`maxSize` 提供即时的客户端反馈。二者都不是服务端安全控制。在存储或处理上传文件的任何位置，都要再次校验文件类型、大小和内容。如果文件应存入对象存储，而不是随消息内联传输，请使用配置中的上传回调。

## 以编程方式发送媒体

若要使用内置示例或自定义上传器，请添加一条用户消息，其 `content` 包含标准的 AG-UI 内容部分。Showcase 会构造一个文本部分，外加一个图像或文档部分：

<AngularSnippet region="multimodal-message" />

将该消息加入所选智能体并运行该智能体。MIME 类型必须作为权威依据：图像使用 `image` 部分，PDF 及其他文档使用 `document` 部分。所选模型和后端转换器必须支持你接受的每一种 MIME 类型。
