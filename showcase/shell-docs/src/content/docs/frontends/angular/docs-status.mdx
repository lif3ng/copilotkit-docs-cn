根据你想要构建的内容选用这些页面：

1. 从 [Angular 快速开始](/angular)入手，安装包、配置 `provideCopilotKit`，并渲染第一个独立聊天组件。
2. 在侧边栏中选择你的智能体后端。该选择会改变后端配置与智能体框架示例，同时不会让你离开 Angular 文档。
3. 使用共享的[运行时](/angular/backend/copilot-runtime)与 [CopilotKit Intelligence](/angular/intelligence/overview) 文档，了解服务器架构、持久化、托管与运维。这些概念不随前端变化；变化的只是前端特定的代码。
4. 使用任务指南：[聊天 UI](/angular/guides/chat-ui)、[前端工具与生成式 UI](/angular/guides/frontend-tools-generative-ui)、[人机协同流程](/angular/guides/human-in-the-loop)、[共享状态](/angular/guides/shared-state)、[线程、记忆、附件与无头 UI](/angular/guides/threads-memory-attachments-headless)，以及[故障排查](/angular/guides/troubleshooting)。
5. 浏览 [Angular 特性示例](/angular/features)，涵盖全部 41 个受支持的特性。其中 40 项带有可运行示例，每一项都链接到源码与 API 文档。
6. 使用 [Angular API 参考](/reference/angular)，查阅组件、函数、服务、指令、输入、输出、signal 与生命周期规则。

标注为 Showcase 示例的代码，是在文档构建过程中从可运行的 Angular
Showcase 源码中提取的。这样指南与应用始终使用同一份实现，
而不必维护第二份拷贝。

Angular 包不适用于 JSON Renderer。A2UI 及其他 Angular 渲染路径请参阅[生成式 UI 指南](/angular/guides/frontend-tools-generative-ui#choose-a-generative-ui-path)。

关于清理、错误处理、服务器端渲染、水合（hydration）与无 zone 更新，请参阅[生产与生命周期](/reference/angular/production-lifecycle)。
