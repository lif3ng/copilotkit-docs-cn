`@copilotkit/vue` 为 CopilotKit 提供 Vue 3 组件与组合式函数（composables）。本指南带你搭好一个可用的 Vue 应用，其聊天 UI 由本地的 [Copilot Runtime](/backend/copilot-runtime) 与 `BuiltInAgent` 支撑。

运行时在你的服务器上运行，把模型凭据挡在浏览器之外，并暴露 `default` 智能体供 `CopilotChat` 自动使用。

## 从编码智能体开始

使用下面的提示词把 Vue 应用连接到 Copilot Runtime（使用所选的智能体后端），然后验证对话确实可用。也可以按下面的手动步骤操作。

<PageAgentPrompt />

## 前置条件

- 一个 OpenAI API 密钥（或[模型选择](/model-selection)支持的其他模型提供方）
- Vue 3.3+
- Node.js 20+

## 开始使用

<Steps>
    <Step>
        ### 创建你的 Vue 应用

        如果还没有：

        ```bash
        npm create vue@latest my-copilot-app
        cd my-copilot-app
        npm install
        ```
    </Step>
    <Step>
        ### 安装 CopilotKit

        安装 Vue 前端包，以及用于本地 Copilot Runtime 服务器的 `@copilotkit/runtime`：

        <Tabs groupId="package-manager" items={['npm', 'pnpm', 'yarn']}>
            <Tab value="npm">
                ```bash
                npm install @copilotkit/vue @copilotkit/runtime
                npm install -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="pnpm">
                ```bash
                pnpm add @copilotkit/vue @copilotkit/runtime
                pnpm add -D tsx typescript @types/node
                ```
            </Tab>
            <Tab value="yarn">
                ```bash
                yarn add @copilotkit/vue @copilotkit/runtime
                yarn add -D tsx typescript @types/node
                ```
            </Tab>
        </Tabs>
    </Step>
    <Step>
        ### 创建 Copilot Runtime

        添加一个小的 Node 服务器，在 `/api/copilotkit` 上承载 Copilot Runtime，并注册一个 `default` 内置智能体：

        <Callout type="warn" title="已有智能体？不要使用 BuiltInAgent">
          `BuiltInAgent` 是 CopilotKit 自带的智能体——它直接调用模型。
          把它注册为 `default` 意味着聊天对接的是它，而不是你已经写好的智能体。它是替换你的智能体，而不是连接它。

          如果你已有 LangGraph、CrewAI、Mastra、ADK、Pydantic AI 或其他智能体，请使用你框架的快速开始来完成运行时接线，让它注册你的智能体。本页的 Vue 前端步骤仍然适用。
        </Callout>

        ```ts title="server.ts"
        import { createServer } from "node:http";
        import { BuiltInAgent, CopilotRuntime } from "@copilotkit/runtime/v2";
        import { createCopilotNodeListener } from "@copilotkit/runtime/v2/node";

        const runtime = new CopilotRuntime({
          agents: {
            default: new BuiltInAgent({
              model: "openai:gpt-5-mini",
              prompt: "You are a helpful assistant for a Vue app.",
            }),
          },
        });

        const port = Number(process.env.PORT ?? 8200);

        createServer(
          createCopilotNodeListener({
            runtime,
            basePath: "/api/copilotkit",
            cors: true,
          }),
        ).listen(port, () => {
          console.log(
            `Copilot Runtime listening at http://localhost:${port}/api/copilotkit`,
          );
        });
        ```

        <Callout type="info" title="Vite 与 Copilot Runtime 运行在不同源上">
          Vite 提供 Vue 应用（通常在 `http://localhost:5173`），而这个 Node 服务器运行在 `http://localhost:8200`。由于浏览器要跨这两个源发起调用，本地开发必须设置 `cors: true`；Node 监听器默认不启用 CORS。
        </Callout>
    </Step>
    <Step>
        ### 导入样式

        在应用入口导入一次包的样式表。它是自包含的，聊天无需任何其他 CSS 即可渲染。

        ```ts title="src/main.ts"
        import { createApp } from "vue";
        import App from "./App.vue";
        import "@copilotkit/vue/styles.css"; // [!code highlight]

        createApp(App).mount("#app");
        ```
    </Step>
    <Step>
        ### 连接 Copilot Runtime

        把 `CopilotKitProvider` 指向运行时端点，并放入 `CopilotChat`。由于运行时注册了名为 `default` 的智能体，聊天会自动选用它。

        ```vue title="src/App.vue"
        <script setup lang="ts">
        import { CopilotKitProvider, CopilotChat } from "@copilotkit/vue/v2"; // [!code highlight]
        </script>

        <template>
          <!-- [!code highlight:8] -->
          <CopilotKitProvider
            runtime-url="http://localhost:8200/api/copilotkit"
          >
            <div style="height: 100vh">
              <CopilotChat />
            </div>
          </CopilotKitProvider>
        </template>
        ```

        <Callout type="info" title="选择你的聊天布局">
          `CopilotChat` 是全高的聊天界面。`CopilotSidebar` 适合带开合行为的固定侧边栏，`CopilotPopup` 适合带切换按钮的浮动面板。它们共享核心的智能体与聊天接线，但每个界面还有各自的布局相关 props 与行为。
        </Callout>
    </Step>
    <Step>
        ### 启动运行时与应用

        在一个终端中启动 Copilot Runtime：

        ```bash
        export OPENAI_API_KEY=sk-...
        npx tsx server.ts
        ```

        在另一个终端中启动 Vue 应用：

        ```bash
        npm run dev
        ```

        打开 dev server 的 URL（Vite 会打印出来，通常是 `http://localhost:5173`），发送一条消息，你会看到它经由 Copilot Runtime 流式返回。

        <Accordions className="mb-4">
            <Accordion title="故障排查">
                - **聊天没有样式**：确保在应用入口导入了 `@copilotkit/vue/styles.css`。
                - **智能体无响应**：确认运行时服务器正在运行，且 `http://localhost:8200/api/copilotkit/info` 返回智能体信息。
                - **CORS 错误**：Vite 应用与 Node 运行时使用不同的源。本地开发时在 `createCopilotNodeListener` 中保留 `cors: true`；Node 监听器默认禁用 CORS。部署前请配置显式的允许源。
                - **模型认证错误**：确认运行 `npx tsx server.ts` 的终端中设置了 `OPENAI_API_KEY`。
            </Accordion>
        </Accordions>
    </Step>
    <Step>
        <OpenInspectorStep components={props.components} />
    </Step>
</Steps>
