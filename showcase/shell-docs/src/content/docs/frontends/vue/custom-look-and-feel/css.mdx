## 这是什么？

CopilotKit Vue 提供了几种纯 CSS 的方式，可以在不改变预构建 UI 行为的前提下调整其外观。你可以：

- 覆盖 v2 设计令牌，为整个 UI 重新调色。
- 将这些令牌限定在单个聊天界面内，避免泄漏到应用的其他部分。
- 围绕稳定的 CopilotKit 根节点和你自己的插槽标记添加结构性 CSS。
- 按界面更改继承的字体。
- 通过 Vue 插槽替换图标，通过 `labels` 替换面向用户的文案。

Vue v2 组件自带一个基于标准 shadcn/ui 令牌集的 Tailwind v4 主题。只需引入一次包样式表，然后在 `[data-copilotkit]` 或其祖先元素上覆盖 CSS 自定义属性即可。

当需要替换标记时，请使用[插槽](/vue/custom-look-and-feel/slots)；当需要完全自建界面时，请使用[无头 UI](/vue/custom-look-and-feel/headless-ui)。

## 限定主题作用域

```ts title="main.ts"
import "@copilotkit/vue/styles.css";
```

组件会用 `data-copilotkit` 标记各自的根节点。当应用的其他部分使用不同的令牌时，可以在某个产品区域外层加一个类，并将下面所有覆盖都限定在该类之下：

```vue title="SupportChat.vue"
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";
</script>

<template>
  <section class="support-chat">
    <CopilotChat agent-id="support" />
  </section>
</template>

<style>
.support-chat [data-copilotkit] {
  --primary: oklch(0.55 0.22 264);
  --primary-foreground: oklch(0.99 0 0);
  --background: oklch(1 0 0);
  --foreground: oklch(0.145 0 0);
  --muted: oklch(0.97 0 0);
  --border: oklch(0.922 0 0);
  --radius: 0.625rem;
}
</style>
```

## CSS 变量（最简单）

最简单的自定义方式是覆盖 CSS 变量，因为每个嵌套的 Vue 聊天组件都会自动继承它。

<Callout type="info" title="Vue 使用 v2 令牌体系">
  针对 `@copilotkit/react-ui` 风格的 v1 React 组件所描述的旧版 `--copilot-kit-*` 变量和 `.copilotKit...` 类，对 `@copilotkit/vue/v2` 不生效。Vue 的公开样式表是 `@copilotkit/vue/styles.css`，使用下文的 v2 令牌。
</Callout>

## v2 设计令牌（shadcn）

这些令牌的作用域限定在 `[data-copilotkit]`，并通过一个 `@theme inline` 块接入带前缀的 Tailwind 工具类。可以在 CopilotKit 根节点或任意祖先元素上覆盖它们，与在 shadcn 项目中的做法一致。

### 参考

以下是最常被覆盖的令牌。每个浅色值在 `.dark [data-copilotkit]` 下都有对应的暗色模式值。完整集合位于 `@copilotkit/vue/styles.css`。

| 令牌 | 说明 |
| --- | --- |
| `--background` / `--foreground` | 基础表面与主文本。 |
| `--primary` / `--primary-foreground` | 操作色及其之上的文本。 |
| `--secondary` / `--secondary-foreground` | 次级面板与卡片。 |
| `--muted` / `--muted-foreground` | 柔和背景与弱化文本。 |
| `--accent` / `--accent-foreground` | 悬停与激活状态的颜色。 |
| `--border` / `--input` / `--ring` | 分隔线、输入框轮廓与焦点环。 |
| `--destructive` / `--destructive-foreground` | 错误与危险状态。 |
| `--card` / `--popover`（及对应 `-foreground`） | 浮起表面。 |
| `--sidebar-*` | 侧边栏专属的背景、前景、边框与 ring 令牌。 |
| `--radius` | 基础圆角；更小与更大的圆角由它派生。 |

样式表能识别 `.dark` 祖先。在该祖先之下覆盖相同的令牌，即可与应用的暗色模式开关保持一致：

```css title="app.css"
.dark [data-copilotkit] {
  --background: oklch(0.145 0 0);
  --foreground: oklch(0.985 0 0);
  --border: oklch(0.269 0 0);
}
```

任何有效的 CSS 颜色都可以；默认使用 `oklch()`，因为它在不同色相之间能更一致地保持感知亮度。

## 自定义 CSS

结构性改动请使用你自己的包装类和插槽标记。Vue v2 内部带前缀的工具类属于实现细节，请避免将其当作 API 来复制或覆盖。稳定的 CopilotKit 根节点加上你自己的类才是更安全的选择器：

```css title="app.css"
.support-chat [data-copilotkit] {
  border-radius: 1rem;
}

.support-chat .support-message-card {
  border: 1px solid var(--border);
  padding: 1rem;
}
```

请使用[插槽](/vue/custom-look-and-feel/slots)来引入 `.support-message-card` 或替换结构。Vue 包不提供 v1 React 的 `.copilotKitMessages`、`.copilotKitInput` 或 `.copilotKitUserMessage` 类约定。

## 自定义字体

字体会通过 CopilotKit 根节点继承，因此可以将字体限定在单个界面，也可以为所有 Vue 聊天统一设置：

```css title="app.css"
.support-chat [data-copilotkit] {
  font-family: Inter, ui-sans-serif, system-ui, sans-serif;
}
```

## 自定义图标

Vue 使用插槽而非 `icons` prop。`CopilotPopup` 与 `CopilotSidebar` 暴露了一个携带打开状态和操作方法的 `toggle-button` 插槽，因此你可以把启动按钮及其图标一并替换：

```vue
<CopilotPopup>
  <template #toggle-button="{ isOpen, toggle }">
    <button type="button" :aria-label="isOpen ? 'Close chat' : 'Open chat'" @click="toggle">
      <MyCloseIcon v-if="isOpen" />
      <MyChatIcon v-else />
    </button>
  </template>
</CopilotPopup>
```

如果想保留默认的按钮行为，公开的 `CopilotChatToggleButton` 叶子组件也暴露了 `open-icon` 和 `close-icon` 插槽。

## 自定义文案

通过 `labels` prop 自定义面向用户的文案：

```vue
<CopilotChat
  :labels="{
    welcomeMessageText: 'Hello! How can I help you today?',
    modalHeaderTitle: 'My Copilot',
    chatInputPlaceholder: 'Ask me anything!',
  }"
/>
```
