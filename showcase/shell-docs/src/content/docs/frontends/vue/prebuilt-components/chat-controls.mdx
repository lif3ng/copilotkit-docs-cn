预构建聊天有两个常见控制场景：从你自己的 UI 打开它，以及捕获助手消息上的点赞或点踩反馈。

## 以编程方式打开或关闭聊天

在 `CopilotPopup` 或 `CopilotSidebar` 上使用 `toggle-button` 作用域插槽，用自己的 UI 替换启动按钮。该插槽会接收当前打开状态以及 `toggle`、`open` 和 `close` 动作：

```vue title="App.vue"
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotPopup agent-id="my-agent">
    <template #toggle-button="{ isOpen, toggle }">
      <button type="button" @click="toggle">
        {{ isOpen ? "Close chat" : "Ask the assistant" }}
      </button>
    </template>
  </CopilotPopup>
</template>
```

在 `CopilotPopup` 或 `CopilotSidebar` 上通过 `:default-open="true"` 声明式地设置初始状态。这些 Vue 组件没有暴露 `open` / `onOpenChange` 风格的受控 API；挂载后请使用作用域插槽中的动作来控制界面。

## 捕获消息反馈

Vue 将助手消息反馈以事件的形式暴露出来。若要在渲染默认助手消息的同时观察其动作，请通过 `CopilotChatMessageView` 的 `assistant-message` 插槽来提供它：

```vue title="ChatWithFeedback.vue"
<script setup lang="ts">
import {
  CopilotChat,
  CopilotChatAssistantMessage,
  CopilotChatMessageView,
} from "@copilotkit/vue/v2";

function recordFeedback(message: { id: string }, value: "up" | "down") {
  analytics.track("feedback", { messageId: message.id, value });
}
</script>

<template>
  <CopilotChat>
    <template #message-view="{ messages, isRunning }">
      <CopilotChatMessageView :messages="messages" :is-running="isRunning">
        <template #assistant-message="{ message, messages: allMessages, isRunning: running }">
          <CopilotChatAssistantMessage
            :message="message"
            :messages="allMessages"
            :is-running="running"
            @thumbs-up="recordFeedback($event, 'up')"
            @thumbs-down="recordFeedback($event, 'down')"
          />
        </template>
      </CopilotChatMessageView>
    </template>
  </CopilotChat>
</template>
```

这些按钮属于 `CopilotChatAssistantMessage` 的一部分；自定义的 `thumbs-up-button` 和 `thumbs-down-button` 插槽会接收其命令式的 `onThumbsUp` 与 `onThumbsDown` 动作。文案由聊天配置的 `labels` prop 控制。
