## 这是什么？

`<CopilotPopup>` 是一个浮动启动按钮，会在页面上方打开一个聊天窗口。它是在不为常驻面板占据布局空间的前提下添加 copilot 的紧凑方式。

## 何时应该使用它？

弹窗适合用户按需打开的、聚焦任务的对话。当聊天应位于工作区旁边时，使用 [CopilotSidebar](/vue/prebuilt-components/sidebar)；当聊天应位于文档流中时，使用 [`<CopilotChat>`](/vue/prebuilt-components/chat)。

## 基础设置

```vue title="App.vue"
<script setup lang="ts">
import { CopilotKitProvider, CopilotPopup } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <main><!-- Your application --></main>
    <CopilotPopup agent-id="my-agent" :default-open="false" />
  </CopilotKitProvider>
</template>
```

## 配置弹窗

除了共享的聊天 prop 之外，`CopilotPopup` 还接受 `width`、`height`、`default-open` 和 `click-outside-to-close`。它的 `header` 和 `toggle-button` 作用域插槽会接收弹窗状态以及打开/关闭动作。该组件还会转发常规的聊天交互事件。
