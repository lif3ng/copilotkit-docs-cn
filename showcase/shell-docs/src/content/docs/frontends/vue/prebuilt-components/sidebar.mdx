## 这是什么？

`<CopilotSidebar>` 是一个预构建的 Vue 聊天界面，停靠在应用一侧，并可按需滑出打开。它非常适合应用内的 copilot：既保持随时可用，又不替换主工作区。

## 何时应该使用它？

侧边栏适合在应用内容旁边提供持久的、可折叠的聊天。需要浮层启动按钮时使用 [CopilotPopup](/vue/prebuilt-components/popup)；需要完全嵌入的面板时使用 [`<CopilotChat>`](/vue/prebuilt-components/chat)。

## 基础设置

```vue title="App.vue"
<script setup lang="ts">
import { CopilotKitProvider, CopilotSidebar } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <main><!-- Your application --></main>
    <CopilotSidebar agent-id="my-agent" :default-open="false" />
  </CopilotKitProvider>
</template>
```

## 配置侧边栏

`CopilotSidebar` 接受聊天 prop，外加 `width` 和 `default-open`。使用 `header` 作用域插槽替换页眉，使用 `toggle-button` 替换启动按钮。二者的插槽属性都包含当前打开状态以及 `toggle`、`open`、`close` 等动作。

该组件会上报与 `CopilotChat` 相同的聊天交互事件，包括 `@submit-message`、`@input-change` 和 `@select-suggestion`。

设计令牌请参见 [CSS 定制](/vue/custom-look-and-feel/css)；替换页眉、启动按钮、消息列表、输入区和欢迎状态请参见[插槽](/vue/custom-look-and-feel/slots)。
