## 这是什么？

`<CopilotChat>` 是基础的预构建 Vue 聊天界面。可将它放入任意布局，并调整其容器尺寸以适配。`CopilotSidebar` 和 `CopilotPopup` 则以停靠式和浮层式外壳组合相同的聊天原语。

## 何时应该使用它？

如果你需要一个专门的聊天页面、与其他内容并排的内联面板，或任何不需要启动按钮的布局，请选择 `CopilotChat`。如需可折叠的停靠式界面，请选择 [CopilotSidebar](/vue/prebuilt-components/sidebar)；如需浮层形式，请选择 [CopilotPopup](/vue/prebuilt-components/popup)。

## 基础设置

从 `@copilotkit/vue/v2` 导入组件，导入包的样式表，并确保聊天组件位于 `CopilotKitProvider` 之内：

```vue title="App.vue"
<script setup lang="ts">
import { CopilotChat, CopilotKitProvider } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <CopilotChat agent-id="my-agent" />
  </CopilotKitProvider>
</template>
```

`runtime-url` 标识为所配置智能体提供服务的运行时。当前的 Vue Showcase 演示了这个基础的 `agentic-chat` 界面。

## 常用 prop 与事件

| 属性 | 用途 |
| --- | --- |
| `agent-id` | 要使用的运行时智能体。 |
| `thread-id` | 要连接的显式线程。 |
| `labels` | 面向用户的文案，例如标题、占位符、欢迎文本和免责声明。 |
| `welcome-screen` | 设为 `false` 可禁用空状态。 |
| `attachments` | 启用并配置文件附件。 |
| `auto-scroll` | 可使用 `"pin-to-bottom"`、`"pin-to-send"`、`"none"`，或旧版布尔值简写。 |
| `@submit-message`, `@input-change`, `@select-suggestion` | 观察相应的聊天交互。 |
| `@stop` | 观察停止操作。 |
| `:on-error` | 为该智能体的 CopilotKit 运行时错误绑定处理函数。 |
