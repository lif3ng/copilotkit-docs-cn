## 这是什么？

`<CopilotThreadsDrawer>` 为你的应用提供一个开箱即用的会话侧边栏。用户可以列出、切换、开始、归档和删除自己的线程，而你**无需接入任何活动线程状态**即可让它工作。把它放在聊天旁边，它会通过共享的聊天配置自动建立连接。

如果你的项目是通过 CopilotKit CLI 起步模板创建的，抽屉及其共享配置可能已经包含在内。否则，请使用下面的设置把它添加到现有的 Vue 应用中。

在底层，该 Vue 组件是独立 `copilotkit-threads-drawer` Web 组件的一个 SSR 安全包装器。它的数据来自 [`useThreads`](/reference/vue/hooks/useThreads) 和当前聊天配置。

想构建自己的线程 UI？同样的数据和动作可以通过 `useThreads` 获得；参见[无头线程](/vue/headless-threads)。线程**重命名**就是其中一个无头动作：预构建抽屉仅覆盖归档、取消归档和删除，需要重命名时请使用你自己的行。

## 何时应该使用它？

在以下情况下使用抽屉：

- 聊天旁边有一个持久的线程切换器
- 零接线即可实现线程切换、新建会话、归档和删除
- 自包含、可主题化、跟随应用明暗主题的 UI
- 移动端就绪、自带启动按钮的屏幕外抽屉

它需要 CopilotKit Intelligence，因为线程是在服务端存储和同步的。<SignupLink surface="docs_drawer">获取免费开发者账户</SignupLink>来完成设置。

对于多用户应用，请将运行时配置为[将 Rich Threads 限定到已登录用户](/vue/threads-lifecycle#scope-rich-threads-to-the-signed-in-user)。

## 设置线程抽屉

将 `<CopilotThreadsDrawer>` 放在 `<CopilotChat>` 旁边，并把**两者**都包裹在同一个共享 `<CopilotChatConfigurationProvider>` 中。这份共享配置让抽屉能够驱动聊天：选中一行会把聊天连接到该线程并回放其历史记录；“新对话”行则会把聊天重置为全新的欢迎界面。

```vue title="src/App.vue"
<script setup lang="ts">
import {
  CopilotChat,
  CopilotChatConfigurationProvider,
  CopilotKitProvider,
  CopilotThreadsDrawer,
} from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider
    runtime-url="/api/copilotkit"
    public-license-key="ck_pub_..."
  >
    <CopilotChatConfigurationProvider agent-id="support">
      <div style="display: flex; height: 100dvh">
        <CopilotThreadsDrawer />
        <CopilotChat />
      </div>
    </CopilotChatConfigurationProvider>
  </CopilotKitProvider>
</template>
```

整个集成到此完成。如果手工构建侧边栏，你需要跟踪活动线程 id，并在列表和聊天之间传递选择/新建线程的处理函数；而共享配置会替抽屉持有这些状态。

## 添加你自己的“新对话”按钮

抽屉自带“新对话”行。你的应用也可以保留自己的按钮，例如放在工具栏或页面页眉中。调用 [`useCopilotChatConfiguration`](/reference/vue/hooks/useCopilotChatConfiguration) 提供的 `startNewThread()`——这正是抽屉为自身行调用的同一个配置方法。

```vue title="src/components/NewConversationButton.vue"
<script setup lang="ts">
import { useCopilotChatConfiguration } from "@copilotkit/vue/v2";

const configuration = useCopilotChatConfiguration();

function startNewConversation() {
  configuration.value?.startNewThread();
}
</script>

<template>
  <button type="button" @click="startNewConversation">New conversation</button>
</template>
```

把按钮放在与抽屉和聊天相同的 `<CopilotChatConfigurationProvider>` 内：

```vue title="src/App.vue with a toolbar button"
<script setup lang="ts">
import {
  CopilotChat,
  CopilotChatConfigurationProvider,
  CopilotKitProvider,
  CopilotThreadsDrawer,
} from "@copilotkit/vue/v2";
import NewConversationButton from "./components/NewConversationButton.vue";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider
    runtime-url="/api/copilotkit"
    public-license-key="ck_pub_..."
  >
    <CopilotChatConfigurationProvider agent-id="support">
      <div style="display: flex; height: 100dvh">
        <CopilotThreadsDrawer />
        <main style="flex: 1; display: flex; flex-direction: column">
          <header><NewConversationButton /></header>
          <CopilotChat />
        </main>
      </div>
    </CopilotChatConfigurationProvider>
  </CopilotKitProvider>
</template>
```

工作原理：

- 在配置提供方之外，`useCopilotChatConfiguration()` 返回一个包含 `null` 的 computed ref，因此按钮不会执行任何操作。
- `startNewThread()` 会为聊天分配新的线程 id 并显示其欢迎界面。抽屉从同一配置读取活动线程，因此不会有任何行保持选中状态。
- 新线程在首次运行后会出现在抽屉列表中。空线程不会获得对应行。
- 如果你在 `<CopilotChatConfigurationProvider>` 上设置了 `threadId`，就由你的应用控制线程。此时配置的 `startNewThread()` 和 `setActiveThreadId()` 不会执行任何操作，只会记录警告。请把 id 保存在你自己的状态里，并向抽屉传入 `onThreadSelect` 和 `onNewThread` 回调。你的按钮更新同一个状态：

  ```vue title="src/components/ControlledChat.vue"
  <script setup lang="ts">
  import { ref } from "vue";
  import {
    CopilotChat,
    CopilotChatConfigurationProvider,
    CopilotThreadsDrawer,
  } from "@copilotkit/vue/v2";

  const threadId = ref<string>(crypto.randomUUID());
  const selectThread = (id: string) => {
    threadId.value = id;
  };
  const startNewConversation = () => {
    threadId.value = crypto.randomUUID();
  };
  </script>

  <template>
    <CopilotChatConfigurationProvider :thread-id="threadId">
      <CopilotThreadsDrawer
        :on-thread-select="selectThread"
        :on-new-thread="startNewConversation"
      />
      <button type="button" @click="startNewConversation">
        New conversation
      </button>
      <CopilotChat />
    </CopilotChatConfigurationProvider>
  </template>
  ```

  在你的 `<CopilotKitProvider>` 内渲染 `ControlledChat`。

若只想显示你自己的按钮，可以通过 CSS parts 隐藏抽屉自带的新建会话控件。`new-thread-button` 是展开抽屉中的那一行；`launcher-new-thread` 是收起或折叠状态下启动按钮中的 (+) 按钮。

```css
copilotkit-threads-drawer::part(new-thread-button),
copilotkit-threads-drawer::part(launcher-new-thread) {
  display: none;
}
```

## 配置抽屉

`<CopilotThreadsDrawer>` 无需任何 prop 即可工作。其可选 prop 如下：

| Prop             | 描述                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------- |
| `agentId`        | 要列出其线程的智能体；默认为聊天配置中的智能体。                                       |
| `label`          | 抽屉区域和列表框的无障碍名称；默认为 `"Threads"`。                                    |
| `recentLabel`    | 列表上方的标题；默认为 `"Recent Conversations"`。                                                  |
| `onThreadSelect` | 接管线程选择的逃生口。                                                                    |
| `onNewThread`    | 处理“新对话”行的逃生口。                                                               |
| `onLicensed`     | 用户在锁定抽屉中点击 Upgrade 时调用。这不是许可证校验完成的通知。 |
| `licenseUrl`     | 覆盖许可证跳转目标地址。                                                                        |
| `collapsible`    | 展开的桌面端抽屉是否可折叠；默认为 `true`。                                          |
| `limit`          | 分页大小。只要还有下一页，抽屉就会显示 Load more。                                               |

完整的 prop 和事件类型请参见 [Vue 线程抽屉参考](/reference/vue/components/CopilotThreadsDrawer)。

## 自定义

抽屉渲染在 shadow root 中，样式自包含并继承主题。Vue 提供了有限的定制逃生口：

- **命名 Web 组件插槽**：通过 `slot` 属性插入子元素，例如 `header`、`empty`、`footer`、`memories` 或 `launcher-icon`。

  ```vue
  <CopilotThreadsDrawer>
    <span slot="header">My conversations</span>
  </CopilotThreadsDrawer>
  ```

- **逐行内容**：使用 Vue 的 `#row="{ thread }"` 作用域插槽。定义它会替换每一行的内部内容，因此如果需要逐行回退，请在插槽内复现默认标记。

  ```vue
  <CopilotThreadsDrawer>
    <template #row="{ thread }">
      <strong>{{ thread.name ?? "New conversation" }}</strong>
    </template>
  </CopilotThreadsDrawer>
  ```

- **CSS parts 与变量**：为 Web 组件的结构性 `::part()` 目标设置样式，或覆盖其 `--cpk-drawer-*` 自定义属性。参考页列出了受支持的 parts 和令牌。

## 许可证

线程需要 CopilotKit Intelligence。如果没有有效的 Threads 许可证，抽屉会显示一个锁定视图来代替列表。
