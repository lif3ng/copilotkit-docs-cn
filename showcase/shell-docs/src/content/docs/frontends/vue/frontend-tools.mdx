## 这是什么？

前端工具让你的智能体能够定义并调用完全运行在用户浏览器中的客户端函数。由于 handler 在前端执行，它可以直接访问组件状态、浏览器 API 以及页面已在使用的任何第三方 UI 库。智能体正是借此“伸入”应用：更新 Vue 状态、触发动画、读取 `localStorage`、弹出 toast，或引导用户的视图。

本页介绍前端工具在“智能体驱动 UI”形态下的用法。同一原语也支撑着生成式 UI 和人机协同（human-in-the-loop）；交互模式请参见相应页面。

## 什么时候应该用它？

当你的智能体需要以下能力时，使用前端工具：

- 读取或修改 Vue 组件状态
- 访问 `localStorage`、`sessionStorage` 或 cookie 等浏览器 API
- 触发 UI 更新、动画或过渡
- 显示警告框、toast 或通知
- 与第三方前端库交互
- 执行任何需要用户当前浏览器上下文的操作

## 代码中的工作方式

使用 `useFrontendTool` 注册一个前端工具。为它提供一个名称、一个描述参数的 Zod schema 和一个 handler。之后智能体就能像调用其他工具一样调用它，而你的前端会在浏览器中执行它。

```vue title="src/components/DashboardAgent.vue"
<script setup lang="ts">
import { ref } from "vue";
import { z } from "zod";
import { CopilotChat, useFrontendTool } from "@copilotkit/vue/v2";

const severity = ref("all");

useFrontendTool(
  {
    name: "filter_incidents",
    description: "Filter the visible incident list by severity.",
    parameters: z.object({
      severity: z.enum(["all", "sev1", "sev2", "sev3"]),
    }),
    handler: async ({ severity: nextSeverity }) => {
      severity.value = nextSeverity;
      return { applied: true, severity: nextSeverity };
    },
  },
  [severity],
);
</script>

<template>
  <p>Current filter: {{ severity }}</p>
  <CopilotChat />
</template>
```

handler 收到的是解析后、类型安全的参数，可以做浏览器能做的任何事：更新状态、调用 API 或操作 DOM。它的返回值会作为工具结果回传给智能体，让模型能够推断发生了什么。

第二个参数是 Vue 侦听源（watch sources）数组。把注册过程中读取到的 ref 或 getter 放进去，handler 才能拿到最新值。

```vue title="src/App.vue"
<script setup lang="ts">
import { CopilotKitProvider } from "@copilotkit/vue/v2";
import DashboardAgent from "./components/DashboardAgent.vue";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <DashboardAgent />
  </CopilotKitProvider>
</template>
```

智能体通过运行时连接获知工具的名称、描述和参数 schema。描述要写得具体收窄，对输入做校验，并在执行不可逆操作前要求用户明确确认。涉及特权的变更、携带密钥的 API 调用和授权决策应放在可信的后端。如果某个工具必须等待用户答复，请改用 `useHumanInTheLoop`。
