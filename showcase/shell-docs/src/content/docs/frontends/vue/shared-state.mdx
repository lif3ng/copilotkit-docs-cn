## 什么是共享状态？

智能体化的 Copilot 会维护一种共享状态，将你的 UI 与智能体的执行无缝连接起来。这套共享状态系统让你可以：

- 展示智能体的当前进度与中间结果
- 通过 UI 交互更新智能体的状态
- 在整个应用中实时响应状态变化

## 何时应该使用它？

当你希望智能体与用户围绕同一份应用状态展开协作时，就使用共享状态。智能体的输出会反映到 UI 中，用户在 UI 里做出的更新也会反映到智能体的执行里。

## 读取智能体状态

<FrameworkSetup concept="shared-state-setup" />

使用 `useAgent` 让组件订阅智能体的状态。每当智能体修改其状态（例如通过工具调用），该组合式函数就会更新其响应式的 `agent` ref，你的 UI 随即以新值重新渲染。

```vue title="src/components/SharedWorkspace.vue"
<script setup lang="ts">
import { computed } from "vue";
import { useAgent, UseAgentUpdate } from "@copilotkit/vue/v2";

type WorkspaceState = {
  notes?: string[];
  preferences?: { tone?: string };
};

const { agent } = useAgent({
  agentId: "workspace",
  updates: [UseAgentUpdate.OnStateChanged],
});
const state = computed(
  () => (agent.value?.state ?? {}) as WorkspaceState,
);
</script>

<template>
  <ul>
    <li v-for="note in state.notes ?? []" :key="note">{{ note }}</li>
  </ul>
</template>
```

返回的 `agent.value.state` 是一个普通对象。像读取其他响应式应用数据那样读取它，并渲染你关心的部分：智能体写入的笔记、结构化输出、进度指示器，或智能体放进去的任何其他内容。

## 写入智能体状态

同一个 agent 对象还暴露了 `setState`。在 UI 事件处理器中调用它，就会把新值推入共享状态，智能体会在自己的下一轮中读取回来。UI 的写入会实实在在地引导模型的行为。

```vue title="src/components/SharedWorkspace.vue"
<script setup lang="ts">
function setTone(tone: string) {
  const current = agent.value;
  if (!current) return;

  const previous = (current.state ?? {}) as WorkspaceState;
  current.setState({
    ...previous,
    preferences: { ...previous.preferences, tone },
  });
}
</script>

<template>
  <button @click="setTone('concise')">Prefer concise answers</button>
</template>
```

正是这一点让这条通道成为双向的：UI 不只是观察智能体，还能向智能体递送全新的输入——偏好、选择或未完成的工作——而不必经过聊天线程。

## 在 UI 中渲染共享状态

由于 `agent.state` 是通过 Vue ref 暴露的普通数据，UI 层就是普通的 Vue。上面的示例把智能体的输出接入一个列表，并通过 `setState` 把用户的修改反馈回去。

这里没有任何聊天特有的东西：`useAgent` 可以在 `CopilotKitProvider` 下的任何组件中使用，因此你可以在主视图或画布中渲染智能体状态，而不只局限于聊天面板之内。完整的主视图模式请参阅**[在应用中渲染智能体状态](/vue/shared-state/rendering-in-app)**。

```vue title="src/App.vue"
<script setup lang="ts">
import { CopilotChat, CopilotKitProvider } from "@copilotkit/vue/v2";
import SharedWorkspace from "./components/SharedWorkspace.vue";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <SharedWorkspace />
    <CopilotChat agent-id="workspace" />
  </CopilotKitProvider>
</template>
```

## 流式传输部分状态更新

默认情况下，智能体状态只会在后端检查点*之间*更新，因此长时间运行的工具调用会在最后一次性大量呈现。状态流式传输则会在某个工具参数*生成的过程中*把它直接转发到对应的状态键，让 UI 能够逐 token 看着答案组装成形。

## 只读上下文

当某个值**由 UI 持有**、智能体应当能读取却绝不应写回时——例如当前用户、选中的记录或滚动位置——请改用 `useAgentContext` 而不是完整的共享状态。它把值发布为一条从 UI 到智能体的单向通道，并在组件卸载时自动注销。

`useAgentContext` 是一项独立的只读能力；它并不能取代上述 `agent.state` / `agent.setState(...)` 的双向约定。

完整模式请参阅**[智能体只读上下文](/vue/shared-state/agent-readonly)**。
