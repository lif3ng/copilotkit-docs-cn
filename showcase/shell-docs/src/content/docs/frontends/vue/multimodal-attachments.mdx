---
title: 多模态附件
icon: "lucide/Paperclip"
description: 让用户在 Vue 聊天中发送图片、音频、视频和文档。
---

你可以在 `CopilotChat` 上启用文件附件功能，而无需替换 Vue 输入区。CopilotKit 会在浏览器中校验每个文件、显示预览，并将准备就绪的附件附加到下一条智能体消息中。

## 快速开始

```vue title="App.vue"
<script setup lang="ts">
import { CopilotChat, CopilotKitProvider } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <CopilotChat :attachments="{ enabled: true }" />
  </CopilotKitProvider>
</template>
```

用户可以通过附件按钮选择文件、将文件拖拽到聊天区域，或从剪贴板粘贴受支持的文件。

## 配置

`attachments` prop 接受一个 `AttachmentsConfig` 对象：

```vue
<CopilotChat
  :attachments="{
    enabled: true,
    accept: 'image/*,audio/*,video/*,application/pdf',
    maxSize: 10 * 1024 * 1024,
  }"
/>
```

| 选项 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `enabled` | `boolean` | — | 在输入区中启用文件附件。 |
| `accept` | `string` | `"*/*"` | MIME 过滤器，支持 `image/*` 之类的模式以及 `.pdf` 之类的扩展名。 |
| `maxSize` | `number` | `20 * 1024 * 1024` | 最大文件大小（字节）。 |
| `onUpload` | `(file: File) => AttachmentUploadResult \| Promise<AttachmentUploadResult>` | — | 自行上传文件，并返回 data 或 URL 形式的来源。 |
| `onUploadFailed` | `(error: AttachmentUploadError) => void` | — | 处理校验失败和上传失败。 |

`accept` 与 `maxSize` 属于客户端校验，并非服务端安全控制。请在应用存储或处理文件的任何位置再次校验文件。

## 支持的文件类型

CopilotKit 将 MIME 类型映射为四种附件模态：

| 模态 | MIME 类型 | 默认预览 |
| --- | --- | --- |
| 图片 | `image/*` | 缩略图与灯箱。 |
| 音频 | `audio/*` | 音频播放器。 |
| 视频 | `video/*` | 缩略图、播放按钮与灯箱。 |
| 文档 | 其他类型 | 文件名/图标；PDF 与文本可预览。 |

所选模型和后端转换器仍需支持相应内容。无法处理某种模态的模型可能在消息发出后才报告运行错误；针对这种情况，请在 `CopilotChat` 上绑定 `:on-error`。

## 自定义上传处理函数

默认情况下，Vue 会将每个文件读取为 base64 数据并内联发送。如果你的应用将上传内容单独存储，可以改为返回一个托管 URL：

```vue
<script setup lang="ts">
async function upload(file: File) {
  const form = new FormData();
  form.append('file', file);
  const response = await fetch('/api/upload', { method: 'POST', body: form });
  const { url } = await response.json();
  return { type: 'url' as const, value: url, mimeType: file.type };
}
</script>

<template>
  <CopilotChat :attachments="{ enabled: true, onUpload: upload }" />
</template>
```

另一种受支持的结果是 `{ type: "data", value, mimeType }`。两种变体都可以包含 `metadata` 对象；文件名会自动添加到附件元数据中。

## 处理上传错误

```vue
<script setup lang="ts">
function onUploadFailed(error: {
  reason: 'file-too-large' | 'invalid-type' | 'upload-failed';
  file: File;
  message: string;
}) {
  toast.error(error.message);
}
</script>

<template>
  <CopilotChat
    :attachments="{
      enabled: true,
      accept: 'image/*',
      maxSize: 5 * 1024 * 1024,
      onUploadFailed,
    }"
  />
</template>
```

校验失败使用 `invalid-type` 或 `file-too-large`；上传处理函数或默认读取器失败则使用 `upload-failed`。消息发出后的错误会改通过聊天的 `:on-error` 回调上报。

## 工作原理

当用户发送消息时，Vue 会：

1. 使用默认读取器读取每个文件，或调用 `onUpload`。
2. 在文本部分之外构建带类型的 AG-UI 内容部分。
3. 消费就绪的附件队列，并将这些部分随用户消息一起发送。

附件来源采用标准的 AG-UI 输入内容结构，因此运行时和智能体必须支持你所接受的模态。
