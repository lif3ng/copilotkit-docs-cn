## 这是什么？

当你想从代码而非聊天输入区驱动智能体运行时——比如按钮、表单、定时任务、键盘快捷键或图回调——就该使用编程式控制。CopilotKit 提供三个原语，覆盖所有触发模式：

- `agent.addMessage(...)`——向对话追加一条消息，但不运行智能体。如果希望这条消息开启一轮对话，请配合 `copilotkit.runAgent({ agent })` 使用。
- `copilotkit.runAgent({ agent })`——`<CopilotChat />` 底层调用的同一入口。它负责编排前端工具、后续运行和订阅者生命周期。
- `agent.subscribe(subscriber)`——底层 AG-UI 事件订阅（`onCustomEvent`、`onRunStartedEvent`、`onRunFinalized`、`onRunFailed` 以及流式增量）。

## 何时应该使用它？

在以下情况下使用编程式控制：

- 从按钮、表单或其他 UI 元素触发智能体运行
- 直接从 UI 交互执行特定工具，无需经过 LLM 回合
- 在没有聊天窗口的情况下构建智能体特性
- 以编程方式访问智能体状态和结果
- 创建完全自定义的智能体驱动工作流

## 从代码发送消息

<FrameworkSetup concept="programmatic-control-setup" />

标准做法是先用 `agent.addMessage` 追加一条用户消息，然后调用 `copilotkit.runAgent({ agent })`。可使用 `copilotkit.stopAgent({ agent })` 取消进行中的运行。

```vue title="src/components/AgentTrigger.vue"
<script setup lang="ts">
import { toRaw } from "vue";
import { useAgent, useCopilotKit } from "@copilotkit/vue/v2";

const { agent } = useAgent({ agentId: "sales" });
const { copilotkit } = useCopilotKit();

async function run() {
  const current = agent.value;
  if (!current || current.isRunning) return;

  current.addMessage({
    id: crypto.randomUUID(),
    role: "user",
    content: "Summarize the latest sales data",
  });

  try {
    await copilotkit.value.runAgent({ agent: toRaw(current) });
  } catch (error) {
    console.error("CopilotKit runAgent failed:", error);
  }
}

function stop() {
  const current = agent.value;
  if (!current) return;
  copilotkit.value.stopAgent({ agent: toRaw(current) });
}
</script>

<template>
  <button :disabled="agent?.isRunning" @click="run">Run agent</button>
  <button :disabled="!agent?.isRunning" @click="stop">Stop</button>
</template>
```

```vue title="src/App.vue"
<script setup lang="ts">
import { CopilotKitProvider } from "@copilotkit/vue/v2";
import AgentTrigger from "./components/AgentTrigger.vue";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <AgentTrigger />
  </CopilotKitProvider>
</template>
```

### `copilotkit.runAgent()` 与 `agent.runAgent()` 的区别

两个方法都会触发智能体，但作用于不同层级：

- **`copilotkit.runAgent({ agent })`**——推荐的默认选择。它编排完整生命周期、执行前端工具、处理后续运行，并通过订阅者系统路由错误。
- **`agent.runAgent(options)`**——智能体实例上的底层方法。它把请求发送到运行时，但**不会**执行前端工具或链接后续运行。只在需要直接控制时才使用它。

## 订阅智能体事件

`agent.subscribe(subscriber)` 返回 `{ unsubscribe }`。订阅者接受所有 AG-UI 生命周期回调：`onCustomEvent`、`onRunStartedEvent`、`onRunFinalized`、`onRunFailed` 以及流式增量。可用它驱动进度 UI、把事件转发到分析系统，或检查框架的暂停/恢复事件。

```ts
import { watch } from "vue";

watch(
  agent,
  (current, _previous, onCleanup) => {
    if (!current) return;
    const subscription = current.subscribe({
      onRunStartedEvent: () => console.log("started"),
      onRunFinalized: () => console.log("done"),
      onRunFailed: ({ error }) => console.error(error),
    });
    onCleanup(() => subscription.unsubscribe());
  },
  { immediate: true },
);
```

## 从按钮解决 LangGraph 中断

在产品 UI 中，请使用 `useInterrupt({ renderInChat: false })`。它订阅标准 AG-UI 中断结果和旧版 `on_interrupt` 事件，把待处理的中断暂存到最终化为止，并暴露通过 `copilotkit.runAgent` 恢复执行的 `resolve` / `cancel` 方法：

```ts
const { slotProps } = useInterrupt({
  agentId: "sales",
  renderInChat: false,
});

async function approve() {
  await slotProps.value?.resolve({ approved: true });
}
```

得到的响应式状态是纯数据；任何 Vue UI 都可以驱动它。如果测试夹具需要自定义累积逻辑，可以基于 `agent.subscribe(...)` 和 `copilotkit.runAgent(...)` 构建。标准中断通过 `resume` 数组恢复；旧版中断通过 `forwardedProps.command` 恢复。

</WhenFrameworkHas>

## 从按钮解决前端工具调用

对于基于 Promise 的集成，没有原生的中断原语。改为注册一个 `useHumanInTheLoop` 前端工具。它的处理函数保持挂起状态，渲染出的 Vue 组件可以在任何应用界面中呈现审批入口，调用 `respond(...)` 即可 resolve 智能体工具调用正在等待的 Promise。

得到的挂起状态和响应回调都是纯数据；同一模式可以驱动模态框、toast、侧边栏表单或语音 UI。

</WhenFrameworkHas>

## 从按钮解决暂停

> **此框架不支持中断式的暂停/恢复。**中断路径要么需要原生的运行时中断，要么需要以 Promise resolve 的前端工具路径。基于工具调用的暂停/恢复请使用 [`useHumanInTheLoop`](./human-in-the-loop)。上面的 `agent.addMessage`、`copilotkit.runAgent` 和 `agent.subscribe` 原语仍然适用；只有中断的解决方式因框架而异。

</WhenFrameworkHas>
