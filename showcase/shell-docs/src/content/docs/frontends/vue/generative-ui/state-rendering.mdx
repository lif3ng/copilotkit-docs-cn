## 这是什么？

状态渲染让你能够构建实时反映智能体状态的 UI。当智能体在各节点间推进并发出状态更新时，你的前端会渲染这些变化，展示进度、草稿或中间结果。

## 何时应该使用它？

在以下场景中使用状态渲染：

- 展示实时进度（如“正在研究……已完成 2/5”）
- 展示随智能体工作而不断更新的草稿
- 构建反映智能体状态的仪表盘
- 在聊天之外渲染结构化输出

## 代码中的工作原理

在前端，订阅智能体的状态。每当后端转发来一个新值时，你的组件就会使用最新的部分输出重新渲染。`useAgent` 返回一个 `agent` ref；在脚本中通过 `agent.value?.state` 读取，或让模板自动解包该 ref。请将 provider 保留在祖先 SFC 中。

```vue title="src/components/ResearchProgress.vue"
<script setup lang="ts">
import { computed } from "vue";
import { useAgent, UseAgentUpdate } from "@copilotkit/vue/v2";

type ResearchState = { status?: string; draft?: string; completed?: number; total?: number };

const { agent } = useAgent({
  agentId: "researcher",
  updates: [UseAgentUpdate.OnStateChanged, UseAgentUpdate.OnRunStatusChanged],
});

const state = computed(() => (agent.value?.state ?? {}) as ResearchState);
</script>

<template>
  <section aria-live="polite">
    <p>{{ state.status ?? "Idle" }}</p>
    <progress :value="state.completed ?? 0" :max="state.total ?? 1" />
    <article v-if="state.draft">{{ state.draft }}</article>
  </section>
</template>
```

```vue title="src/App.vue"
<script setup lang="ts">
import { CopilotChat, CopilotKitProvider } from "@copilotkit/vue/v2";
import ResearchProgress from "./components/ResearchProgress.vue";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <ResearchProgress />
    <CopilotChat agent-id="researcher" />
  </CopilotKitProvider>
</template>
```

在后端，一个状态流式映射会在某个工具参数*生成的过程中*将其直接转发到对应的状态键中。一些框架以中间件的形式提供这一能力；直接使用 SDK 适配器的框架则可以在流式循环中发出 `STATE_SNAPSHOT` 事件。无论采用哪种方式，UI 都能看着答案逐 token 组装成形，而不是在各个检查点之间一次性突然出现。
