## 这是什么？

工具是 LLM 调用预定义的、通常具有确定性的函数的方式。工具渲染让你可以决定每个工具调用在聊天中的呈现方式。你无需展示原始 JSON，而是注册一个 Vue 组件，为该调用绘制一张品牌化的卡片（参数、实时状态以及最终结果）。这就是**生成式 UI** 的一种变体，CopilotKit 称之为**工具渲染**。

</Callout>

## 何时应该使用它？

在以下场景中渲染工具调用：

- 让用户确切看到智能体正在调用哪些工具、传入了哪些参数
- 在工具执行期间展示实时进度指示器
- 在工具完成后渲染丰富、精致的结果
- 为重度使用工具的智能体提供透明且符合品牌风格的聊天体验

## 默认工具渲染（零配置）

最简单的入口是不带任何参数调用 `useDefaultRenderTool()`。CopilotKit 会将其内置的默认渲染器注册为 `*` 通配符：每个工具调用都会渲染成一张状态卡片（工具名称、实时的**运行中 → 完成**状态、可折叠的参数与结果），而你无需编写任何 UI。

如果不使用这个 composable，运行时就没有 `*` 渲染器，工具调用将不可见；用户只能看到助手最后的文字总结。

```vue title="src/components/AgentExperience.vue"
<script setup lang="ts">
import { CopilotChat, useDefaultRenderTool } from "@copilotkit/vue/v2";

useDefaultRenderTool();
</script>

<template><CopilotChat /></template>
```

## 自定义兜底渲染器

当你想要符合品牌风格的界面外观时，可以向 `useDefaultRenderTool` 传入一个 `render` 组件或函数。它是 `useRenderTool({ name: "*", ... })` 的便捷封装：一个通配符渲染器即可处理所有工具调用，无论具名与否。

```ts title="src/components/AgentExperience.vue"
useDefaultRenderTool({ render: BrandedToolCard });
```

## 每个工具的渲染器

最具表现力的方式是为每个工具名称配置一个渲染器。每个渲染器都会收到该工具解析后的参数、实时的 `status`，以及在智能体返回后的 `result`。

```vue title="src/components/WeatherToolCard.vue"
<script setup lang="ts">
defineProps<{
  parameters: { city?: string };
  status: "inProgress" | "executing" | "complete";
  result?: string;
}>();
</script>

<template>
  <p v-if="status !== 'complete'">Checking {{ parameters.city ?? "…" }}</p>
  <article v-else>
    <strong>{{ parameters.city }}</strong>
    <pre>{{ result }}</pre>
  </article>
</template>
```

```vue title="src/components/AgentExperience.vue"
<script setup lang="ts">
import { z } from "zod";
import { CopilotChat, useDefaultRenderTool, useRenderTool } from "@copilotkit/vue/v2";
import WeatherToolCard from "./WeatherToolCard.vue";

useRenderTool({
  name: "get_weather",
  parameters: z.object({ city: z.string() }),
  render: WeatherToolCard,
});

useDefaultRenderTool(); // wildcard fallback for every other tool
</script>

<template><CopilotChat /></template>
```

在参数流式传输期间，`parameters` 是不完整的。只有在状态从 `inProgress` 推进之后才能读取必需字段。当状态为 `complete` 时，结果是一个字符串；只有当你的后端刻意返回某种有文档说明的序列化结构时才去解析它。

<Callout type="info">
  你传给 `useRenderTool` 的 `name` 必须与智能体暴露的工具名称一致；运行时正是据此将调用路由到你的组件。
</Callout>

每个工具的渲染器可以与兜底渲染器组合使用：具名渲染器认领那些“值得关注的”工具，通配符则处理其余所有工具。示例在具名的 `get_weather` 渲染器之后注册了内置通配符。

如果渲染器闭包引用了响应式值，请将 Vue 的 watch 来源作为第二个参数传入：

```ts
useRenderTool({ name: "get_weather", parameters, render: WeatherToolCard }, [locale]);
```

最后，将注册组件挂载到 provider 之下：

```vue title="src/App.vue"
<script setup lang="ts">
import { CopilotKitProvider } from "@copilotkit/vue/v2";
import AgentExperience from "./components/AgentExperience.vue";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit"><AgentExperience /></CopilotKitProvider>
</template>
```

## 后端工具定义

前端渲染器只能看到智能体下发的数据。与之匹配的后端必须暴露一个名为 `get_weather` 的工具、返回结构化数据，并让同名的前端渲染器绘制卡片。Vue 渲染器不会创建或执行那个后端工具。
