## **协议混搭**

CopilotKit 让开发者能够**直接或组合使用**以上任意协议。
CopilotKit 可以通过任意一种交互协议连接到你的智能体后端。

<Image
  src="/images/any-agentic-backend-light.png"
  alt="任意智能体后端"
  width={4096}
  height={2304}
  className="block dark:hidden mb-8 w-full mx-auto"
/>
<Image
  src="/images/any-agentic-backend-dark.png"
  alt="任意智能体后端"
  width={4096}
  height={2304}
  className="hidden dark:block mb-8 w-full mx-auto"
/>

另外，由于 AG-UI 本身也内置了与 **MCP** 和 **A2A** 的**握手**机制，CopilotKit 可以通过 AG-UI 连接支持 MCP 或 A2A 的智能体。

这意味着，如果你的宿主智能体通过 **MCP** 或 **A2A** 连接子智能体，它们的 UI 属性可以一路传递到面向用户的应用——同时保留**完整的安全、策略与可观测性控制**。
