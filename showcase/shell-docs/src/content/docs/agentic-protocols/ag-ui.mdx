## 什么是 AG-UI 协议？

AG-UI 是一个轻量级、基于事件的协议，它标准化了 AI 智能体连接到面向用户的应用的方式。
它为简洁与灵活而生，让 AI 智能体、实时用户上下文与用户界面之间能够无缝集成。
AG-UI 是一个开放标准，由 CopilotKit 团队与多个智能体框架合作伙伴共同开发。

## CopilotKit 如何使用 AG-UI

CopilotKit 使用 AG-UI 来抽象你的应用与驱动你副驾的 AI 智能体之间的连接。你的智能体可以用任何支持 AG-UI 的智能体框架来构建（清单还在不断增长，包括 LangGraph、Mastra、Pydantic AI 等）。与定制的框架集成相比，这一抽象有几个优势。

- **灵活性与互操作性**：遵循 AG-UI 标准，CopilotKit 组件变得可以互换，开发者可以把它们与任何 AG-UI 兼容的智能体搭配使用，或在不更换 UI 的情况下切换不同的后端模型。
- **统一的通信**：CopilotKit 使用 AG-UI 协议来管理前端与 AI 智能体之间的全部往返通信，取代了自定义的 WebSocket 格式与文本解析。
- **前端工具调用**：当智能体需要使用集成在前端应用中的工具时，AG-UI 事件会促成这一交互。
