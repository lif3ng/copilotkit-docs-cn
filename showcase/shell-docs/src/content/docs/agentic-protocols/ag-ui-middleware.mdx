> AG-UI 中间件本质上是 [AG-UI 协议](./ag-ui)的一个概念，在上游的 `@ag-ui/client` 中定义。本页介绍如何
> 把它接入 CopilotKit 运行时；协议层面的参考（生命周期、`runNextWithState`、`Middleware` 基类）请参阅上游指南
> [docs.ag-ui.com/sdk/js/client/middleware](https://docs.ag-ui.com/sdk/js/client/middleware)。

AG-UI 智能体通过 `agent.use(middleware)` 暴露一个中间件层，这是一个强大的钩子，可用于日志记录、护栏（guardrails）、请求转换与事件重写。由于 CopilotKit 在 [Copilot Runtime](/backend/copilot-runtime) 内以服务端方式运行该中间件，它在一个可信环境中执行，客户端无法篡改。

## 定义中间件

中间件继承自 `@ag-ui/client` 的 `Middleware` 基类，并实现 `run(input, next)`。它会接收传入的 `RunAgentInput` 并返回一个 `Observable<BaseEvent>`，通常是订阅 `runNextWithState(input, next)` 并对流进行转换：

```ts title="my-middleware.ts"
import {
  Middleware,
  RunAgentInput,
  AbstractAgent,
  BaseEvent,
} from "@ag-ui/client";
import { Observable } from "rxjs";

export class LoggingMiddleware extends Middleware {
  run(input: RunAgentInput, next: AbstractAgent): Observable<BaseEvent> {
    return new Observable<BaseEvent>((subscriber) => {
      const sub = this.runNextWithState(input, next).subscribe({
        next: ({ event }) => {
          console.log("[agent event]", event.type);
          subscriber.next(event);
        },
        error: (err) => subscriber.error(err),
        complete: () => subscriber.complete(),
      });
      return () => sub.unsubscribe();
    });
  }
}
```

## 把中间件挂载到智能体上

在向运行时注册智能体之前，先对它调用 `.use(...)`：

```ts title="app/api/copilotkit/[[...slug]]/route.ts"
import { CopilotRuntime, InMemoryAgentRunner } from "@copilotkit/runtime/v2";
import { LangGraphAgent } from "@copilotkit/runtime/langgraph";
import { LoggingMiddleware } from "./my-middleware";

const agent = new LangGraphAgent({
  deploymentUrl: process.env.LANGGRAPH_DEPLOYMENT_URL!,
  graphId: "sample_agent",
});
agent.use(new LoggingMiddleware());

const runtime = new CopilotRuntime({
  agents: { default: agent },
  runner: new InMemoryAgentRunner(),
});
```

## 内置中间件

运行时内置了一流的中间件选项，你可以直接在 `CopilotRuntime` 上启用，而无需对每个智能体调用 `.use()`：

- **`a2ui`** —— 对所有（或部分）已注册的智能体应用 `A2UIMiddleware`。参见 [Copilot Runtime → A2UI](/backend/copilot-runtime#a2ui)。
- **`mcpApps`** —— 从一处为所有智能体配置 MCP 服务器。参见 [Copilot Runtime → mcpApps](/backend/copilot-runtime#mcpapps)。
