## A2UI 发布——完全兼容

CopilotKit 一直与 Google 在 A2A 和 A2UI 集成方面紧密合作，并很自豪成为 **A2UI 的发布合作伙伴**。

### 什么是 A2UI？

A2UI（Agent-to-UI）是 Google 推出的声明式、对 LLM 友好的生成式 UI 规范。它定义渲染_什么_以及如何以视觉方式组织智能体响应——让智能体能够产出丰富的交互式 UI 组件，并可在不同平台与框架上渲染。

CopilotKit 为 A2UI 提供**零日支持**，这意味着你可以在基于 CopilotKit 的应用中立即开始使用 A2UI 组件。
