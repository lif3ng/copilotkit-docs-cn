# 向后兼容

你已经在使用的一切都会继续正常工作。v1.50 与使用 v1.10 的客户端代码完全向后兼容。实际上，作为这个预发布阶段的第一步，我们希望你可以先直接重新构建一次，如果遇到任何问题请告诉我们。

### V2 接口

如上所述，所有 v1（或未标注版本）的 hooks 在 v1.50 中继续可用。要使用新的 hooks，请使用标记为 /v2 的版本（如下所示）。

你可以选择启用任意新的开发者接口，也可以继续使用旧接口。以下组合方式均允许混用：

- 新 Chat 组件 + 旧 hooks
- 旧组件 + 新 hooks
- 新的 v2 API 通过子路径暴露：

  ```tsx
  import { CopilotKit, useAgent } from "@copilotkit/react-core/v2";
  ```

# useAgent

v2 hook useAgent 是 `useCoAgent` 的严格超集，可对智能体连接进行更多控制，包括：

### 共享状态

    ```tsx

    const { agent } = useAgent({ agentId: "my-agent" });

    agent.state
    agent.setState
    ```

### 时间旅行

    ```tsx

    const { agent } = useAgent({ agentId: "my-agent" });

    agent.setMessages()
    ```

### 多智能体执行

    ```tsx

    const { agent: langgraph } = useAgent({ agentId: "langgraph" });
    const { agent: pydantic } = useAgent({ agentId: "pydantic" });
    const { copilotkit } = useCopilotKit();

    [langgraph, pydantic].forEach((agent) => {
      agent.addMessage({ id: crypto.randomUUID(), role: "user", content: message });
      copilotkit.runAgent({ agent });
    });
    ```

### 智能体相互感知

你甚至可以让智能体彼此感知对方！

    ```tsx

    const { agent: langgraph } = useAgent({ agentId: "langgraph" });
    const { agent: pydantic } = useAgent({ agentId: "pydantic" });

    langgraph.setMessages(pydantic.messages)
    pydantic.setMessages(langgraph.messages)
    ```

## 即将推出

v1.50 现已发布，其中 useAgent 已完全就绪。其余特性（见下文）将在近期推出时陆续加入。

### 线程与持久化

v1.50 提供了对线程化会话的支持，内置线程存储与连接组件。开发环境请使用 InMemory 或 SQLite。

#### 线程存储

    - **开发环境**：`InMemory` 或 `SQLite`

        ```tsx

        const runtime = new CopilotRuntime({
          agents: {
            default: agent,
          },
          runner: new InMemoryAgentRunner(), // new abstraction for persistence
        });
        ```

    - **生产环境**
        - 使用 **CopilotKit Intelligence**（云托管或自托管）来持久化线程、获得自动流式重连以及内置分析能力。请参阅[线程指南](/AG-UI-Streams)，从免费的 Developer 层级开始上手。
            - **👉 填写[企业版抢先体验](https://go.copilotkit.ai/enterprise-threads-waitlist)表单**。

#### 线程连接

    - 加载线程

        ```tsx

        <CopilotChat threadId="xyz" /> // connects to runtime's runner
        ```

    - 流式重连

        ```tsx

        <CopilotChat threadId="xyz" /> // will reconnect if page is reloaded
        ```

### 全新设计系统

你可以继续使用 v1 接口中的设计系统，但 v2 带来了全面的 UI 改版与更深度的定制：

- 全新的 `CopilotChat`、`CopilotSidebar`、`CopilotPopup`
  - 只需从 `@copilotkit/react-core/v2` 导入即可使用
  - 全新的插槽系统，支持灵活覆盖
  - 开箱即用的 Markdown 渲染效果大幅提升
- 可与智能体顺畅协作的 Suggestions API

---

### Zod Schema 支持

许多 CopilotKit hooks 现在接受 Zod schema，在编译期与运行时都强制保证类型安全。

- `useHumanInTheLoop`——现在接受 Zod schema
- `useFrontendTool`——现在接受 Zod schema
- `useRenderToolCall`——贯彻全新的开发者体验设计原则

---

### 简化的基础设施

早期版本的 CopilotKit 需要安装 GraphQL。新架构已将这一依赖完全移除。

---

### 直连 LLM 改进

我们的直连 LLM 集成现在支持更多模型，并实现了共享状态。

#### BuiltInAgent——现已支持更广泛的模型

```tsx
const runtime = new CopilotRuntime({
  agents: {
    myAgent: new BuiltInAgent({
      model: "openai/gpt-4o-mini", // much broader model support
      prompt: "You are a helpful AI assistant.",
      temperature: 0.7,
    }),
  },
});
```

#### 共享状态支持

```tsx
const { agent } = useAgent({ agentId: "myAgent" });
const { state, setState } = agent;
```
