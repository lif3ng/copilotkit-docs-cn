# A2A 与 MCP 握手

AG-UI 现已包含与 **MCP** 和 **A2A** 协议的**握手**，确保整个智能体化技术栈的顺畅互操作。

## 什么是协议握手？

协议握手让 AG-UI 能与使用不同交互协议的智能体无缝通信。这意味着你可以把前端连接到内部使用 MCP 或 A2A 的智能体，无需任何额外配置。

## 优势

### 完全互操作

如果你的宿主智能体通过 **MCP** 或 **A2A** 连接子智能体，它们的 UI 属性可以一路传播到面向用户的应用。

### 安全与控制

握手在整个通信链路中保持**完整的安全、策略与可观测性控制**。

### 简化的架构

无需在协议之间做选择——在单个应用中把它们全部一起使用。

## 工作原理

1. **前端通过 AG-UI 连接**——你的应用使用 AG-UI 连接到宿主智能体
2. **宿主智能体使用 MCP/A2A**——宿主智能体可以使用 MCP 或 A2A 与子智能体通信
3. **UI 属性传播**——生成式 UI 和其他属性自动流回你的前端
