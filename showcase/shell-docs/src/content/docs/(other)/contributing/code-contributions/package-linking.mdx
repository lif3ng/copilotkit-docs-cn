title: "进阶：包链接"
---

在本指南中，我们将教你如何把 CopilotKit 包链接到自己的项目来测试变更。这样，你就可以在 CopilotKit monorepo 中运行 `pnpm run dev`，并立即在自己的项目中看到变更。

## 使用 `pnpm` 进行全局包链接

我们将使用 pnpm 的[全局链接功能](https://pnpm.io/cli/link#pnpm-link---global)把 CopilotKit 包链接到你的项目。

<Steps>
  <Step>
  ### 在 CopilotKit monorepo 中
  假设你已按照贡献指南完成了所有步骤，那么一切应该都已就绪。

进入 CopilotKit monorepo，运行以下命令全局链接这些包：

```bash
pnpm exec nx run-many -t link:global
```

  </Step>
  <Step>
  ### 在你的项目中
  在你的项目中，确保已配置 pnpm。这并不妨碍你同时使用 npm 或 yarn，但就全局链接而言，你必须使用 pnpm。

```bash
cd your-project
pnpm i
```

接下来，在项目中链接所需的包：

<FrontendOnly frontend="react">
```bash
# 例如，链接 @copilotkit/react-core 包：
pnpm link --global @copilotkit/react-core
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```bash
# 链接 Angular 包：
pnpm link --global @copilotkit/angular
```
</FrontendOnly>

你可以对所有包执行此操作，也可以只链接需要的包。现在你的变更将会同步。

  </Step>
  <Step>
  ### 取消链接
  完成之后，你可以在 CopilotKit monorepo 中运行以下命令来撤销全局链接：

```bash
pnpm exec nx run-many -t unlink:global
```

然后在你的项目中：

```bash
pnpm install
```

大功告成，一切恢复正常！

  </Step>
</Steps>
