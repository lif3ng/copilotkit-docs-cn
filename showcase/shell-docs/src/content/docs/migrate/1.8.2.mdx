## 有哪些变更？

### 全新的外观与体验

CopilotKit 1.8.2 引入了全新的默认外观与体验，包括主题变量的全新用法、新组件，以及整体焕然一新的视觉风格。

**点击右下角的按钮，即可查看全新外观与体验的实际效果**！

### 点赞/点踩处理器

聊天组件现在提供 `onThumbsUp` 与 `onThumbsDown` 处理器。指定这两个处理器后，鼠标悬停在每条消息上时会出现相应图标，让用户可以提供反馈。

```tsx
<CopilotChat 
  onThumbsUp={(message) => console.log(message)} 
  onThumbsDown={(message) => console.log(message)}     
/>
```

此前在我们的框架中也能实现这一功能，但现在它已成为一等公民！你可以用它通过 CopilotKit 微调你的模型，或者常规地追踪用户反馈。

### 移除 ResponseButton prop

`ResponseButton` prop 已被移除。该 prop 此前用于自定义聊天中生成响应后出现的按钮。

取而代之的是，现在每条消息下方会显示以下按钮：
- 点赞
- 点踩
- 复制
- 重新生成

这些按钮的行为、图标和样式均可自定义。更多信息请查看我们的[外观与体验指南](/custom-look-and-feel)。

### 开箱即用的深色模式支持

CopilotKit 现已支持开箱即用的深色模式。它由 `.dark` 类（Tailwind）以及 `color-scheme` CSS 选择器控制。

如果你想创建自定义主题，请查看[自定义外观与体验](/custom-look-and-feel)指南。
