TypeScript 版 CopilotKit 运行时是**框架无关**的。它本质上是一个纯 Fetch 处理器——一个接收 `Request` 并返回 `Response` 的函数。这意味着它可以原生运行在任何支持 [Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) 的平台上，同时我们也为 Express、Hono 等基于 Node.js 的框架提供了轻量适配器。

<Callout type="info" title="TypeScript 服务器适配器">
本指南介绍 TypeScript 运行时，它可以在有无 Intelligence 的情况下工作。对于 Python、Go、Ruby 或 C#/.NET 服务器，请参阅 [Intelligence 快速开始](/intelligence/quickstart#connect-your-runtime)。那些运行时需要 Intelligence，并暴露多路由端点。
</Callout>

## 快速概览

| 运行时 | 导入路径 | 关键函数 |
|---------|------------|--------------|
| **Fetch 原生**（Bun、Deno、CF Workers、Next.js App Router） | `@copilotkit/runtime/v2` | `createCopilotRuntimeHandler` |
| **Node.js HTTP** | `@copilotkit/runtime/v2/node` | `createCopilotNodeHandler` / `createCopilotNodeListener` |
| **Express** | `@copilotkit/runtime/v2/express` | `createCopilotExpressHandler` |
| **Hono** | `@copilotkit/runtime/v2/hono` | `createCopilotHonoHandler` |

## 多路由与单路由

运行时支持两种端点模式：

- **多路由**（默认）——暴露独立的 URL 端点：
  - `GET  {basePath}/info`
  - `POST {basePath}/agent/:agentId/run`
  - `POST {basePath}/agent/:agentId/connect`
  - `POST {basePath}/agent/:agentId/stop/:threadId`
  - `POST {basePath}/transcribe`

- **单路由**——单个 `POST {basePath}` 端点，接受 JSON 信封：
  ```json
  { "method": "agent/run", "params": { "agentId": "default" }, "body": { ... } }
  ```

两种模式使用相同的 Runtime 处理器。较新的客户端和 Runtime 还能通过单端点承载 Intelligence 的线程、内存与标注操作。它们通过 Runtime info 协商这一能力，因此旧客户端和旧服务器保持原有行为。

当你的平台只允许一个路由处理器，或者你更偏好更简单的 URL 结构时，单路由模式会很有用。

<FrontendOnly frontend="react">
<Callout type="warn" title="此处选择的模式会绑定前端">
  当你不传 transport prop 时，`<CopilotKit>` 和 `<CopilotKitProvider>` 都会自动探测模式，因此无论哪一个都会跟随你在这里选择的模式。只有想跳过这一探测时才用 `useSingleEndpoint` 固定它——而且固定后必须与实际模式匹配。完整的映射关系见
  [Provider 与处理器配对](/backend/runtime-endpoints#provider-and-handler-pairs)。
</Callout>
</FrontendOnly>

## Fetch 原生运行时

如果你的平台原生支持 Fetch API（Bun、Deno、Cloudflare Workers 等），可以直接使用 `createCopilotRuntimeHandler`——无需适配器。

```ts
import { CopilotRuntime, createCopilotRuntimeHandler, BuiltInAgent } from "@copilotkit/runtime/v2";

// 1. Create the runtime with your agent(s)
const runtime = new CopilotRuntime({
  agents: {
    default: new BuiltInAgent({ model: "openai/gpt-4o-mini" }),
  },
});

// 2. Create a Fetch handler — takes Request, returns Response
const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: true,
});

// 3. Serve it (Bun example — works the same with Deno.serve, CF Workers, etc.)
Bun.serve({ fetch: handler, port: 4000 });
```

各框架的具体示例见下文各节。

## Cloudflare Workers

<Callout type="warn" title="不要在模块作用域构造智能体">
  Workers 不允许在全局作用域中出现随机值，而智能体在构造时会生成线程 ID。在模块顶层创建的智能体会导致 Worker 无法启动，并报错 `Disallowed operation called within global
  scope`。下面的示例把所有构造都放在 `fetch` 内。如果想在模块作用域只创建一次运行时，可以把 `agents` 作为工厂传入。运行时会在每次请求时调用该工厂：

  ```ts
  const runtime = new CopilotRuntime({
    agents: () => ({
      default: new BuiltInAgent({ model: "openai/gpt-4o-mini" }),
    }),
  });
  ```
</Callout>

## React Router（框架模式）

框架模式下的 React Router v7 使用基于文件的路由和 Fetch API 处理器——CopilotKit 处理器可以直接作为资源路由使用。

<Tabs groupId="runtime-mode" items={["多路由", "单路由"]}>
<Tab value="多路由">
```ts title="app/routes/api.copilotkit.$.ts"
import { CopilotRuntime, createCopilotRuntimeHandler, BuiltInAgent } from "@copilotkit/runtime/v2";
import type { Route } from "./+types/api.copilotkit.$";

const runtime = new CopilotRuntime({
  agents: {
    default: new BuiltInAgent({ model: "openai/gpt-4o-mini" }),
  },
});

const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
});

// loader handles GET requests (e.g. /info)
export function loader({ request }: Route.LoaderArgs) {
  return handler(request);
}

// action handles POST requests (e.g. /agent/:id/run)
export function action({ request }: Route.ActionArgs) {
  return handler(request);
}
```

<Callout type="info">
文件名中的 `$` splat 段（`api.copilotkit.$.ts`）会捕获 `/api/copilotkit/` 下的所有子路径，让 CopilotKit 路由能够处理 `/info`、`/agent/:id/run` 等。
</Callout>
</Tab>
<Tab value="单路由">

```ts title="server.ts"
import { CopilotRuntime, createCopilotRuntimeHandler, BuiltInAgent } from "@copilotkit/runtime/v2";
import { createCopilotNodeHandler } from "@copilotkit/runtime/v2/node";

const runtime = new CopilotRuntime({
  agents: {
    default: new BuiltInAgent({ model: "openai/gpt-4o-mini" }),
  },
});

// 1. Create the Fetch handler
const copilotHandler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: true,
});

// 2. Wrap it as a Node (req, res) handler
const copilotNodeHandler = createCopilotNodeHandler(copilotHandler);

// 3. Use it in your existing server with manual routing
const server = createServer(async (req, res) => {
  const url = new URL(req.url ?? "/", `http://${req.headers.host}`);

  // Route CopilotKit requests to the handler
  if (url.pathname.startsWith("/api/copilotkit")) {
    return copilotNodeHandler(req, res);
  }

  // Your other routes
  if (url.pathname === "/health") {
    res.writeHead(200, { "Content-Type": "application/json" });
    res.end(JSON.stringify({ status: "healthy" }));
    return;
  }

  res.writeHead(200, { "Content-Type": "application/json" });
  res.end(JSON.stringify({ status: "ok" }));
});

server.listen(4000, () => {
  console.log("Listening at http://localhost:4000");
});
```

## Express

Express 适配器返回一个可用 `app.use()` 挂载的路由器。该值是一个真正的 `express.Router()`。它声明的类型是 `CopilotExpressRouter`，不绑定任何 Express 大版本，因此在 Express 4 和 Express 5 上都能挂载。

`express` 是 `@copilotkit/runtime` 的可选 peer 依赖，请在你自己的应用中安装它。两个大版本都受支持。

```
npm install express cors
```

### Express 选项

| 选项 | 类型 | 默认值 | 说明 |
|--------|------|---------|-------------|
| `runtime` | `CopilotRuntime` | *必填* | 运行时实例 |
| `basePath` | `string` | *必填* | URL 路径前缀（例如 `"/api/copilotkit"`） |
| `mode` | `"multi-route"` \| `"single-route"` | `"multi-route"` | 多路由暴露独立端点；单路由使用 JSON 信封 |
| `cors` | `boolean` \| `CorsOptions` | `false` | CORS 配置。`true` 表示宽松默认值，或传入一个 `cors` 选项对象 |
| `hooks` | `CopilotRuntimeHooks` | — | [生命周期钩子](#生命周期钩子) |

<Callout type="info">

</Callout>

## 生命周期钩子

所有适配器都支持生命周期钩子，用于处理身份验证、日志记录、响应修改等横切关注点。

```ts
const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  hooks: {
    // Before routing — auth, correlation IDs
    onRequest: async ({ request, path, runtime }) => {
      const token = request.headers.get("authorization");
      if (!token) {
        throw new Response("Unauthorized", { status: 401 });
      }
    },

    // After routing — route-specific authorization
    onBeforeHandler: async ({ request, route }) => {
      console.log(`Handling ${route.method} for agent ${route.agentId}`);
    },

    // After handler — modify response headers
    onResponse: async ({ response, request }) => {
      const headers = new Headers(response.headers);
      headers.set("x-request-id", crypto.randomUUID());
      return new Response(response.body, {
        status: response.status,
        headers,
      });
    },

    // On error — custom error responses
    onError: async ({ error, request }) => {
      console.error("Handler error:", error);
    },
  },
});
```

| 钩子 | 时机 | 可做的修改 |
|------|------|------------|
| `onRequest` | 路由之前 | 抛出 `Response` 以短路 |
| `onBeforeHandler` | 路由之后、处理器之前 | 访问 `route` 信息（method、agentId、threadId） |
| `onResponse` | 处理器之后 | 返回新的 `Response` 以替换原响应 |
| `onError` | 出现未处理错误时 | 记录日志或生成自定义错误响应 |

## CORS 配置

### Fetch 原生运行时

传入 `cors: true` 即可获得宽松默认值（`Access-Control-Allow-Origin: *`），或提供一个配置对象：

```ts
const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: {
    origin: "https://myapp.com",
    credentials: true,
  },
});
```

### Express

传入 `cors: true` 即可获得宽松默认值，或传入一个 [cors](https://www.npmjs.com/package/cors) 选项对象：

```ts
createCopilotExpressHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: {
    origin: "https://myapp.com",
    credentials: true,
  },
});
```

### Hono

传入带显式 origin 的 `cors` 配置：

```ts
createCopilotHonoHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: {
    origin: "https://myapp.com",
    credentials: true,
  },
});
```

<Callout type="warn">
使用 `credentials: true` 时必须指定显式 origin——CORS 规范不允许通配符（`*`）。
</Callout>
