## 这是什么？

无头（headless）UI 让你对聊天体验拥有**完全控制权**。你自带组件、布局与样式，CopilotKit 则负责智能体通信、消息管理、工具调用渲染和流式传输。不需要 `<CopilotChat>`，也不需要插槽覆盖，只需把你的组件搭建在底层钩子之上。

## 什么时候应该使用它？

以下情况适合使用无头 UI：

- [插槽系统](/custom-look-and-feel/slots)不够用时：你需要一个完全不同的布局。
- 你要把聊天嵌入一个已有自身设计模式的现有 UI。
- 你在构建一个仍要与智能体通信的**非聊天界面**（仪表盘、画布、检查器），并想单独使用 `useRenderToolCall` / `useRenderActivityMessage`。
- 你想在聊天之外完全独立地渲染生成式 UI 原语。

## 核心钩子

支撑它的是三个钩子，也正是 `<CopilotChat>` 内部使用的那几个。

- `useAgent({ agentId })`——暴露当前对话（`messages`、`isRunning`）以及运行状态对象。
- `useCopilotKit()`——返回运行时句柄，你在其上调用 `runAgent({ agent })`。
- `useRenderToolCall()`——返回一个函数，可把任意已注册的工具调用内联渲染出来。

## 完整示例

`headless-complete` 单元直接用底层钩子重建了**完整的**生成式 UI 组合，无需导入 `<CopilotChatMessageView>`：文本、工具调用、推理卡片、A2UI + MCP Apps 活动消息，以及自定义的消息前置/后置插槽。

### `useRenderedMessages` 钩子

该单元的核心是一个手写的 `useRenderedMessages(messages, isRunning)`，它返回同样的扁平消息列表，只是每条消息都附加了一个 `renderedContent: ReactNode` 字段。这个钩子是对 `<CopilotChatMessageView>` 所做工作的**手动复刻**：

<Snippet region="use-rendered-messages-hook" title="frontend/src/app/use-rendered-messages.tsx — 组合钩子" />

三个底层钩子为它提供支持：

- `useRenderToolCall()`——返回任意已注册工具调用的渲染器（通过 `useRenderTool` / `useComponent` 按工具注册，外加 `useDefaultRenderTool` 提供的兜底通配）。
- `useRenderActivityMessage()`——为当前智能体作用域渲染 A2UI + MCP Apps 活动消息。
- `useRenderCustomMessages()`——调用注册在当前 `CopilotChatConfigurationProvider` 上的 `renderCustomMessage` 钩子，在每条消息前后发出 `"before"` 和 `"after"` 插槽。
