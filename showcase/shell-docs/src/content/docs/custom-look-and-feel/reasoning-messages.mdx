一些模型（如 OpenAI 的 o1、o3 和 o4-mini）会输出**推理**（reasoning）token**：即内部的“思考”轨迹，展示模型在给出最终答案之前的思维链。CopilotKit 通过一张可折叠的**推理消息（Reasoning Message）卡片自动呈现这些 token。

## 默认行为

当推理事件从智能体到达时，CopilotKit 会把它们渲染在内置卡片中，该卡片：

- 模型正在推理时，显示带有脉动指示器的 **“Thinking…”** 标签。
- 自动展开，让你实时跟随模型的思考过程。
- 推理结束后折叠，并切换为 **“Thought for X seconds”**。
- 以 **Markdown** 形式渲染推理内容。
- 带有折叠箭头开关，用户可以随时重新展开并查看推理内容。

无需额外配置；只要你的模型输出推理 token，卡片就会自动出现。

唯一的要求是把你的智能体接入 CopilotKit；不需要额外的 props 或配置：

## 自定义推理消息

推理消息由三个子组件组成，每个都可以通过**插槽 props** 独立替换：

| 子组件 | 插槽 prop | 说明 |
| --- | --- | --- |
| `Header` | `header` | 带大脑图标、标签和折叠箭头的可点击栏 |
| `Content` | `contentView` | 推理文本区域（Markdown） |
| `Toggle` | `toggle` | 展开/折叠动画包装器 |

你通过 `CopilotChat`、`CopilotPopup` 或 `CopilotSidebar` 上的 `messageView` prop 传入自定义子组件：

```tsx
<CopilotChat
  messageView={{
    reasoningMessage: {
      header: CustomHeader,
      contentView: CustomContent,
    },
  }}
/>
```

### 自定义头部

替换头部可以更改图标、标签文字或样式。头部会收到以下 props：

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `isOpen` | `boolean` | 内容面板当前是否展开 |
| `label` | `string` | 流式传输期间为 `labels.reasoningMessageThinkingLabel`（`"Thinking…"`），结束后为 `"Thought for X seconds"` |
| `hasContent` | `boolean` | 是否已收到任何推理文本 |
| `isStreaming` | `boolean` | 推理是否正在流式输出 |
| `elapsedSeconds` | `number` | 推理耗时秒数，可用于构建本地化标签 |
| `onClick` | `() => void` | 切换处理器（仅在 `hasContent` 为 `true` 时存在） |

```tsx
import { CopilotChat } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

function CustomHeader({
  isOpen,
  label,
  hasContent,
  isStreaming,
  ...props
}: React.ButtonHTMLAttributes<HTMLButtonElement> & {
  isOpen?: boolean;
  label?: string;
  hasContent?: boolean;
  isStreaming?: boolean;
}) {
  return (
    <button
      className="flex w-full items-center gap-2 px-3 py-2 text-sm font-medium"
      {...props}
    >
      {isStreaming ? "🧠" : "💡"}
      <span>{label}</span>
      {hasContent && (
        <span className="ml-auto text-xs">{isOpen ? "Hide" : "Show"}</span>
      )}
    </button>
  );
}

<CopilotChat
  messageView={{
    reasoningMessage: { header: CustomHeader },
  }}
/>
```

### 自定义内容

替换内容区域可以更改推理文本的展示方式：

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `isStreaming` | `boolean` | 推理 token 是否仍在到达 |
| `hasContent` | `boolean` | 是否已收到任何推理文本 |
| `children` | `string` | 原始推理文本 |

```tsx
function CustomContent({
  isStreaming,
  hasContent,
  children,
  ...props
}: React.HTMLAttributes<HTMLDivElement> & {
  isStreaming?: boolean;
  hasContent?: boolean;
}) {
  if (!hasContent && !isStreaming) return null;

  return (
    <div className="px-4 pb-3 text-sm text-gray-500 font-mono" {...props}>
      {children}
      {isStreaming && <span className="animate-pulse ml-1">▊</span>}
    </div>
  );
}

<CopilotChat
  messageView={{
    reasoningMessage: { contentView: CustomContent },
  }}
/>
```

## 完全自定义推理消息

想完全控制整张推理卡片，传入一个**组件**而不是插槽 props。你的组件会收到与内置组件相同的顶层 props：

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `message` | `ReasoningMessage` | 推理消息对象（`.content` 保存文本） |
| `messages` | `Message[]` | 对话中的所有消息 |
| `isRunning` | `boolean` | 智能体当前是否正在运行 |

## Render-Prop 子组件

内置的 `CopilotChatReasoningMessage` 还支持 **render-prop** 模式，适用于想重新排列内置子组件、又不想重新实现它们的场景：

```tsx
import {
  CopilotChatReasoningMessage,
} from "@copilotkit/react-core/v2";
import { CopilotChat } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

function MyReasoningLayout(props: React.ComponentProps<typeof CopilotChatReasoningMessage>) {
  return (
    <CopilotChatReasoningMessage {...props}>
      {({ header, toggle }) => (
        <div className="rounded-lg border bg-yellow-50 my-2">
          {header}
          {toggle}
        </div>
      )}
    </CopilotChatReasoningMessage>
  );
}

<CopilotChat
  messageView={{
    reasoningMessage: MyReasoningLayout,
  }}
/>
```

render-prop 回调会收到：

| 属性 | 说明 |
| --- | --- |
| `header` | 预渲染的头部元素 |
| `contentView` | 预渲染的内容元素 |
| `toggle` | 预渲染的展开/折叠包装器（包含 `contentView`） |
| `message` | 推理消息对象 |
| `messages` | 所有消息 |
| `isRunning` | 智能体是否正在运行 |
