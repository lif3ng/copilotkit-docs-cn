## 这是什么？

每个 CopilotKit 聊天组件都由可组合的**插槽（slots）**构成——即可以逐个覆盖的具名子组件。插槽系统提供三个层级的自定义，无需重建整个 UI：

1. **Tailwind 类**——传入一个字符串来添加/覆盖 CSS 类
2. **Props 覆盖**——传入一个对象来覆盖默认组件上的特定 props
3. **自定义组件**——传入你自己的 React 组件来完全替换某个插槽

插槽是递归的：你可以在任意深度逐层深入嵌套的子组件。

## Tailwind 类

自定义插槽最简单的方式。传入一个 Tailwind 类名字符串，它会与默认组件的类名合并。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat
      messageView="bg-gray-50 dark:bg-gray-900 p-4"
      input="border-2 border-blue-400 rounded-xl"
    />
  );
}
```

## Props 覆盖

传入一个对象来覆盖默认组件上的特定 props。适合添加 `className`、事件处理器、data 属性，或默认组件接受的任何其他 prop。

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    className: "my-custom-messages",
    "data-testid": "message-view",
  }}
  input={{ autoFocus: true }}
/>
```

## 自定义组件

想要完全控制，就传入你自己的 React 组件。它会收到与默认组件完全相同的 props。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

const CustomMessageView = ({ messages, isRunning }) => (
  <div className="space-y-4 p-6">
    {messages?.map((msg) => (
      <div key={msg.id} className={msg.role === "user" ? "text-right" : "text-left"}>
        {msg.content}
      </div>
    ))}
    {isRunning && <div className="animate-pulse">Thinking...</div>}
  </div>
);

export function Chat() {
  return <CopilotChat messageView={CustomMessageView} />;
}
```

## 嵌套插槽（逐层深入）

插槽是递归的。通过嵌套对象，你可以在任意深度自定义子组件。

### 两层深入

在消息视图中覆盖助手消息的工具栏：

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    assistantMessage: {
      toolbar: CustomToolbar,
      copyButton: CustomCopyButton,
    },
    userMessage: CustomUserMessage,
  }}
/>
```

### 三层深入

覆盖助手消息工具栏中的特定按钮：

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    assistantMessage: {
      copyButton: ({ onClick }) => (
        <button onClick={onClick}>Copy</button>
      ),
    },
  }}
/>
```

### 工具调用

`assistantMessage` 插槽包含 `toolCallsView`，用于渲染一条助手消息的工具调用。包装默认的 `CopilotChatToolCallsView`，即可在保留已注册工具渲染器的同时更改容器：

```tsx title="page.tsx"
import {
  CopilotChat,
  CopilotChatToolCallsView,
  type CopilotChatToolCallsViewProps,
} from "@copilotkit/react-core/v2";

const CustomToolCallsView = (props: CopilotChatToolCallsViewProps) => (
  <div className="rounded-lg border border-dashed p-2">
    <CopilotChatToolCallsView {...props} />
  </div>
);

export function Chat() {
  return (
    <CopilotChat
      messageView={{
        assistantMessage: { toolCallsView: CustomToolCallsView },
      }}
    />
  );
}
```

要查看 `CopilotChatToolCallsView` 的进行中、完成、展开和失败状态，请在 React Storybook 中打开 [`CopilotChatToolCallsView` stories](https://github.com/CopilotKit/CopilotKit/blob/main/examples/v2/react/storybook/stories/CopilotChatToolCallsView.stories.tsx)。

想在不编写组件的情况下更改调用的分组方式（一张卡片、一行文字、一个堆叠，或每轮一条摘要），可在消息视图上设置 `toolCallDisplay`。参见[工具调用分组](/generative-ui/tool-rendering#grouping-tool-calls)。

`assistantMessage` 插槽还包含 `markdownRenderer`，用于控制助手 markdown 的渲染方式。它有自己的指南：[Markdown 渲染](/custom-look-and-feel/markdown)。

## 标签

通过 `labels` prop 自定义 UI 中的任意文本字符串。这是 `CopilotChat`、`CopilotSidebar` 和 `CopilotPopup` 上一个独立的便捷 prop，不属于插槽系统。

```tsx title="page.tsx"
<CopilotChat
  labels={{
    chatInputPlaceholder: "Ask your agent anything...",
    welcomeMessageText: "How can I help you today?",
    chatDisclaimerText: "AI responses may be inaccurate.",
  }}
/>
```

## 可用插槽

### `CopilotChat` / `CopilotSidebar` / `CopilotPopup`

这些是所有聊天组件上都可用的根级插槽 props：

| 插槽 | 说明 |
|------|-------------|
| `messageView` | 消息列表容器。 |
| `scrollView` | 带自动滚动行为的滚动容器。 |
| `input` | 带发送/语音转写控件的文本输入区。 |
| `suggestionView` | 消息下方显示的建议胶囊。 |
| `welcomeScreen` | 初始空状态屏幕（传 `false` 可禁用）。 |

`CopilotSidebar` 和 `CopilotPopup` 还有：

| 插槽 | 说明 |
|------|-------------|
| `header` | 模态框顶栏。 |
| `toggleButton` | 打开/关闭切换按钮。 |
