## 这是什么？

`<CopilotChat>` 是基础的预构建聊天界面。把它放到任何你希望聊天出现的位置，并调整尺寸以适配你的布局即可。`<CopilotSidebar>` 和 `<CopilotPopup>` 都是对同一套底层原语的轻量封装；如果你需要一个专属聊天页面，或一个与其他内容并列的内联面板，这个组件就是你要找的。

## 什么时候应该使用它？

在以下场景使用 `<CopilotChat>`：

- 需要一个铺满容器的全幅聊天
- 需要一个作为更大页面组成部分的内联聊天面板
- 需要一个专属的 `/chat` 路由
- 需要最大的布局自由度（没有停靠的外框或启动器）

如果需要可折叠的停靠式聊天，请使用 [CopilotSidebar](/prebuilt-components/sidebar)。
如果需要覆盖在内容之上的浮动气泡，请使用 [CopilotPopup](/prebuilt-components/popup)。
如果需要保存会话并在历史会话之间切换，请加入 [Threads 抽屉](/prebuilt-components/copilot-threads-drawer)（或者通过 [无头 Threads](/headless-threads) 走无头路线）。

## 基础配置

用 `<CopilotKit>` 包裹你的应用一次（该 provider 负责接通运行时、会话与智能体注册表），然后在你选择的布局中渲染 `<CopilotChat>`：

```tsx
import { CopilotKit, CopilotChat } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

<Callout type="warn">
  `@copilotkit/react-ui` 也导出一个名为 `CopilotChat` 的组件。那个是[已弃用的 v1 聊天](/migrate/v2)。本页文档介绍的是 v2 聊天，需从 `@copilotkit/react-core/v2` 导入。
</Callout>

## 常用 props

`<CopilotChat>` 是根原语。`<CopilotSidebar>` 和 `<CopilotPopup>` 接受相同的插槽与标签，另有少量封装层特有的 prop。

| Prop | 说明 |
|------|-------------|
| `agentId` | 聊天要对话的智能体 slug（必须与运行时上配置的某个智能体匹配）。 |
| `labels` | 面向用户的文案——头部标题、占位符、欢迎语、免责声明。 |
| `messageView` | 消息列表的插槽——参见[插槽](/custom-look-and-feel/slots)。 |
| `input` | 输入区（文本框、发送按钮、免责声明）的插槽。 |
| `scrollView` | 滚动容器的插槽（例如自定义羽化/渐变效果）。 |
| `suggestionView` | 消息下方建议胶囊的插槽。 |
| `welcomeScreen` | 空状态的插槽。传 `false` 可禁用。 |

## 样式

`<CopilotChat>` 支持完全的主题定制：

- **CSS 变量 / 类名覆盖**——参见 [CSS 自定义](/custom-look-and-feel/css)

- **完全无头**——参见[无头 UI](/custom-look-and-feel/headless-ui)
