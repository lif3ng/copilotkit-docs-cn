## 这是什么？

`<CopilotPopup>` 是一个预构建的悬浮启动器，会在页面内容之上打开一个覆盖式聊天窗口。它是为现有应用添加 copilot 的最轻量方式。只需引入一次，角落里就会出现一个随时待聊的气泡。

## 什么时候该用它？

在以下情况下使用弹窗：

- 一个占用极小、可按需覆盖现有内容的 copilot
- 一个可以叠放在任何页面之上而无需重排布局的启动器
- 一个供用户进行简短、聚焦任务的对话时打开的快捷助手气泡

如果你需要聊天与内容并排呈现而不是覆盖在内容之上，请使用 [CopilotSidebar](/prebuilt-components/sidebar)。如果需要完全内嵌的聊天面板，请直接使用 [`<CopilotChat>`](/prebuilt-components/chat)。

## 基础配置

用 `<CopilotKit>` 包裹你的应用一次（provider 会接好运行时、会话与智能体注册表），并把 `<CopilotPopup>` 渲染为主内容的兄弟节点。下面的示例让弹窗默认打开，并通过 `labels` 自定义输入框占位符：

```tsx
import { CopilotKit, CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

<Callout type="warn">
  `@copilotkit/react-ui` 也导出了一个名为 `CopilotPopup` 的组件。那个是[已弃用的 v1 弹窗](/migrate/v2)。本页介绍的是 v2 弹窗，需从 `@copilotkit/react-core/v2` 导入。
</Callout>

## 配置弹窗

`<CopilotPopup>` 接受与 `<CopilotChat>` 相同的 props，另有几个自己的属性。常用选项：

| 属性 | 说明 |
|------|-------------|
| `defaultOpen` | 弹窗首次渲染时是否默认打开。 |
| `agentId` | 弹窗要对话的智能体 slug（必须与运行时上配置的某个智能体匹配）。 |
| `labels` | 页头、占位符与免责声明的用户可见文案。 |
| `header` | 弹窗页头栏的插槽——参见[插槽系统](/custom-look-and-feel/slots)。 |
| `toggleButton` | 悬浮启动按钮的插槽。 |

## 样式

`CopilotPopup` 参与插槽系统，因此它的每一块 UI 都可以自定义——从消息视图上的 Tailwind 类，到整个页头或切换按钮组件的替换。完整的插槽参考见[自定义外观](/custom-look-and-feel/slots)。
