## 智能体化聊天的预构建组件

CopilotKit 提供三种可直接连接到你智能体的预构建聊天界面：[**CopilotChat**](/prebuilt-components/chat)、
[**CopilotSidebar**](/prebuilt-components/sidebar) 和
[**CopilotPopup**](/prebuilt-components/popup)。它们都是同一套底层原语的包装器，只是布局不同。选择适合你应用的一款；它们全都支持流式传输、生成式 UI 和深度自定义。

如果你的聊天界面需要保存会话、历史记录或线程切换，可以把 [**线程抽屉**（Threads Drawer）](/prebuilt-components/copilot-threads-drawer) 放在其中任意一款旁边——或者用 [无头线程（Headless Threads）](/headless-threads) 构建你自己的切换器。

第 1 级以下的一切都是增量式的：你可以在同一个应用里自由混用 CSS 变量、自定义欢迎插槽和无头工具调用渲染器。随着需求增长，没有任何机制迫使你推翻已完成的工作。

## 选择界面形态

每种界面形态都是开箱即用的组件，底层原语相同，仅布局不同。

- [`<CopilotChat>`](/prebuilt-components/chat)：可放在任意位置、按需调整大小的内嵌聊天面板。
- [`<CopilotSidebar>`](/prebuilt-components/sidebar)：停靠在应用边缘、可折叠的侧边栏。
- [`<CopilotPopup>`](/prebuilt-components/popup)：悬浮气泡，覆盖在页面内容之上。

用 [线程抽屉（Threads Drawer）](/prebuilt-components/copilot-threads-drawer) 在其中任意一种旁边加上会话历史侧边栏——一个开箱即用的线程切换器，无需任何活动线程接线。

需要从你自己的按钮打开/关闭聊天，或捕捉点赞/点踩反馈？参见[打开、关闭与反馈](/prebuilt-components/chat-controls)。
