## 这是什么？

`<CopilotSidebar>` 是一个停靠在应用侧边的预构建聊天界面。它包裹你的主内容，让聊天可以按需滑出，非常适合那种需要随时可达、又不希望占据整个视口的应用内 copilot。

## 什么时候该用它？

在以下情况下使用侧边栏：

- 一个附着在应用外壳上、可折叠的常驻聊天
- 聊天与主内容并排呈现，而不是覆盖在内容之上
- 一个用户可以随时开合而不会迷失所在位置的启动器

需要覆盖在内容之上的悬浮气泡，参见 [CopilotPopup](/prebuilt-components/popup)。需要完全内嵌的聊天面板，直接使用 [`<CopilotChat>`](/prebuilt-components/chat)。需要保存会话并在其间切换时，侧边栏可承载 [线程抽屉（Threads Drawer）](/prebuilt-components/copilot-threads-drawer)。

## 基础配置

用 `<CopilotKit>` 包裹你的应用一次（它会接好运行时、会话与智能体注册表），并把 `<CopilotSidebar>` 放在主内容旁边。侧边栏以兄弟节点渲染，因此滑出时不会引起页面重排：

```tsx
import { CopilotKit, CopilotSidebar } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

<Callout type="warn">
  `@copilotkit/react-ui` 也导出了一个名为 `CopilotSidebar` 的组件。那个是[已弃用的 v1 侧边栏](/migrate/v2)。本页介绍的是 v2 侧边栏，需从 `@copilotkit/react-core/v2` 导入。
</Callout>

`<CopilotSidebar>` 接受与 `<CopilotChat>` 相同的 props，另有几个自己的属性。下面的示例让侧边栏默认打开，并指向一个具名智能体：

<Snippet region="sidebar-configuration" title="frontend/src/app/page.tsx —— defaultOpen + agentId" />

侧边栏特有的常用属性：

| 属性 | 说明 |
|------|-------------|
| `defaultOpen` | 侧边栏首次渲染时是否默认打开。 |
| `agentId` | 侧边栏要对话的智能体 slug（必须与运行时上配置的某个智能体匹配）。 |
| `labels` | 页头、占位符与免责声明的用户可见文案。 |
| `header` | 侧边栏页头栏的插槽——参见[插槽系统](/custom-look-and-feel/slots)。 |
| `toggleButton` | 打开/关闭启动按钮的插槽。 |

## 样式

`CopilotSidebar` 参与插槽系统，因此它的每一块 UI 都可以自定义——从消息视图上的 Tailwind 类，到整个页头或切换按钮组件的替换。完整的插槽参考见[自定义外观](/custom-look-and-feel/slots)。
