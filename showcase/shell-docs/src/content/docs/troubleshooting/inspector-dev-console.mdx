description: "在 React、Vue 与 Angular 中配置 CopilotKit Inspector。"
---

`enableInspector` 控制浏览器应用中的内置 Inspector：

- `true` 或省略：在开发构建中显示。
- `false`：在开发构建中隐藏。

Inspector 在生产构建或服务器端渲染期间绝不会加载或渲染。这一安全防护无法通过显式的 `true` 覆盖，而开发主机名则不受限制。

## React v2

```tsx
import { CopilotKit } from "@copilotkit/react-core/v2";

<CopilotKit runtimeUrl="/api/copilotkit" enableInspector={false}>
  {children}
</CopilotKit>;
```

旧版 `showDevConsole` 取值不再控制 Inspector。请使用 `enableInspector` 控制 Inspector 的可见性。

## Vue

```vue
<CopilotKitProvider runtime-url="/api/copilotkit" :enable-inspector="false">
  <App />
</CopilotKitProvider>
```

Vue 中已弃用的 `showDevConsole` prop 不再控制 Inspector。

## Angular

```ts
provideCopilotKit({
  runtimeUrl: "/api/copilotkit",
  enableInspector: false,
});
```

Angular 没有 `showDevConsole` 别名。请通过 `CopilotKitConfig` 上的 `enableInspector` 配置 Inspector。

## React v1

v1 兼容组件遵循同样的仅开发环境生效的 `enableInspector` 行为。其已弃用的 `showDevConsole?: boolean` prop 控制的是错误 toast 与横幅，而不是 Inspector。

<Callout type="warn">
  Inspector 无法在生产构建中启用。调试已部署或远程环境时，请使用开发构建。
</Callout>

## React Native

原生 iOS 与 Android 应用尚无内置 Inspector。当前的 Inspector 是一个 DOM web component，未包含在 React Native 依赖图中。
