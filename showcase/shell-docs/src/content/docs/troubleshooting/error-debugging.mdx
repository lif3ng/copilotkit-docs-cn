# 如何调试错误

CopilotKit 为本地开发提供了可视化错误控制台，并为生产环境可观测性提供了程序化的 `onError` 回调。可视化控制台完全免费，且不需要任何 API 密钥。

## 快速配置

```tsx
import { CopilotKit } from "@copilotkit/react-core/v2";

export default function App() {
  return (
    <CopilotKit
      runtimeUrl="/api/copilotkit"
      showDevConsole={true} // [!code highlight]
    >
      {/* your app */}
    </CopilotKit>
  );
}
```

<Callout type="warn">
避免在生产环境中显示开发控制台——它会向最终用户暴露内部错误细节。
</Callout>

## 何时使用开发调试

- **本地开发** —— 错误会立即出现在你的 UI 中
- **快速调试** —— 无需任何配置，开箱即用
- **测试** —— 在开发过程中验证错误处理

## 程序化错误处理

v2 API 在 `CopilotKit` 和 `CopilotChat` 上都提供了 `onError` 回调，无需 `publicApiKey`。

### Provider 层级的错误处理

捕获整个应用中的所有错误：

```tsx
import { CopilotKit } from "@copilotkit/react-core/v2";

<CopilotKit
  runtimeUrl="/api/copilotkit"
  onError={(event) => {
    // event.code    — error type (e.g. "runtime_info_fetch_failed", "agent_run_failed")
    // event.error   — the Error object
    // event.context — additional context (agentId, toolName, etc.)
    console.error(`[CopilotKit ${event.code}]`, event.error.message);
    errorTracker.capture(event);
  }}
>
  <App />
</CopilotKit>;
```

### Chat 层级的错误处理

只作用于特定聊天的智能体——会在 Provider 层级处理函数**之外额外**触发：

```tsx
import { CopilotChat } from "@copilotkit/react-core/v2";

<CopilotChat
  agentId="my-agent"
  onError={(event) => {
    showToast(`Agent error: ${event.error.message}`);
  }}
/>;
```

### 错误码

| 错误码 | 说明 |
|------|-------------|
| `runtime_info_fetch_failed` | 无法访问运行时的 `/info` 端点 |
| `agent_connect_failed` | 智能体连接（线程初始化）失败 |
| `agent_run_failed` | 智能体运行被拒绝（例如网络错误） |
| `agent_run_failed_event` | 智能体的 `onRunFailed` 订阅者被触发 |
| `agent_run_error_event` | 智能体发出了 `RUN_ERROR` 事件 |
| `tool_argument_parse_failed` | 工具调用参数不是有效的 JSON |
| `tool_handler_failed` | 前端工具处理器抛出了异常 |

<Callout type="info">
想看清完整的事件管线——智能体发出了哪些事件、是否到达客户端、在哪里被丢弃？打开[检查器](../inspector)。启动器会变红，空间允许时还会有一个胶囊标签标明失败原因。点击启动器即可跳到对应的窗格，查看出问题的智能体、失败的工具（如有）以及错误信息。
</Callout>

## 故障排查

### 开发控制台不显示

- 确认设置了 `showDevConsole={true}`
- 检查浏览器控制台中是否有 JavaScript 错误
- 确认没有 CSS 把错误横幅隐藏掉

### 生产环境错误管线检查清单

- Provider 层级的 `onError` 已接线，并转发到你的错误追踪器
- 生产构建中 `showDevConsole` 为 **false**
- 错误中的智能体 ID 与运行时上注册的智能体一致
- 关键错误码（`agent_run_failed`、`tool_handler_failed`）已配置告警，而不只是记录日志
