内置智能体（Built-in Agent）是 CopilotKit 提供的最简单的智能体后端。它不代理到外部框架进程（LangGraph、Mastra 等），而是在你的运行时内实例化 `BuiltInAgent({ model, tools, prompt })`，并在进程内运行智能体循环。无需单独的智能体服务器，也无需安装外部框架——可直连 OpenAI / Anthropic / Google 或任何 AI-SDK 模型，并完整支持工具、生成式 UI 与共享状态。

完整的内置智能体指南——快速开始、服务器工具、MCP 服务器、模型选择、高级配置——请从[文档根目录](/)开始。
