# Open Agent Spec x CopilotKit

Open Agent Spec（Agent Spec）最初由 Oracle 开发，是一种用于定义智能体化系统的可移植语言。它为独立智能体和结构化的智能体化工作流定义了构建块，也定义了将它们组合成多智能体系统的常见方式。
Agent Spec 让用户能够一次编写智能体，然后在任何兼容的运行时上运行。Agent Spec 将设计与执行解耦，帮助跨框架交付更可预测的行为。

现在，借助 CopilotKit 集成，你可以使用 CopilotKit 与 AG-UI 把你的 Agent Spec 智能体接入交互式 UI。使用我们的 Next.js 起步模板，将 CopilotKit UI 连接到你的 Agent Spec FastAPI 端点，该端点会流式输出 AG-UI 事件。

这一集成围绕两个组件展开：

- **后端**：Agent Spec 的 AG-UI 导出器（`pyagentspec` Python 包），位于 [AG-UI GitHub 仓库](https://github.com/ag-ui-protocol/ag-ui/tree/main/integrations/agent-spec/python)。它会加载 Agent Spec 配置（yaml/json），并通过受支持的 Agent Spec 适配器（目前是 LangGraph 或 WayFlow）在你选择的框架上运行它，把 Agent Spec 追踪事件转换为 AG-UI 事件，再经由 FastAPI 端点发送给由 CopilotKit 驱动的前端。
- **前端**：CopilotKit UI（Next.js），负责消费 AG-UI 事件，并渲染聊天、工具调用/结果以及生成式 UI。

快速搭建 UI，然后接好你的流式输出 AG-UI 事件的后端端点。

## 快速开始

```bash
npx copilotkit@latest create
```

然后设置你的后端端点（默认为 `http://localhost:8000/copilotkit`）：

```dotenv title=".env.local"
COPILOTKIT_REMOTE_ENDPOINT=http://localhost:8000/copilotkit
```

运行你的 Agent Spec FastAPI 服务器并启动 Next.js 应用。
后端安装与端点接线请遵循[快速开始](/agent-spec/quickstart)以及各适配器指南：[LangGraph 集成](/agent-spec/langgraph)与 [WayFlow 集成](/agent-spec/wayflow)。

## 工作原理

- 后端：你的 FastAPI 端点（来自 AG-UI Agent Spec 集成）发出 AG-UI SSE 事件。
- 前端：Next.js 模板使用 CopilotKit Runtime 将请求代理到你的后端。
- 协议：AG-UI 的 span/事件支撑流式文本、工具调用与结果，以及运行生命周期。
