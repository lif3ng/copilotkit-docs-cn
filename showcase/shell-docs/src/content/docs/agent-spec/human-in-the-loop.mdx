## 这是什么？

前端工具让你能够定义客户端侧的函数，供你的 Agent Spec 智能体调用，且执行完全发生在用户的浏览器中。当你的智能体调用某个前端工具时，
逻辑会在客户端运行，让你可以直接访问前端环境。

它可以用来让[你的智能体控制 UI](/frontend-tools)、实现[生成式 UI](/frontend-tools)，或用于人机协同交互。

本指南将介绍如何在前端工具中实现人机协同。

## 何时使用？

当你需要智能体与以下这些客户端侧的底层能力交互时，可以使用前端工具：

- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage、cookies 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 实现步骤

<Steps>
    <Step>
      ### 运行并连接你的智能体
      <RunAndConnect />
    </Step>

    <Step>
        ### 创建一个人机协同前端工具

        前端工具可以有多种用法。其中一种是人机协同流程：工具的响应由用户的决定来把关。

        在本例中，我们将模拟一个执行命令的“审批”流程。首先，使用 `useHumanInTheLoop` hook 创建一个
        会请求用户批准的工具。

        ```tsx title="page.tsx"

        export function Page() {
          // ...

          useHumanInTheLoop({
            name: "offerOptions",
            description: "Give the user a choice between two options and have them select one.",
            parameters: [
              {
                name: "option_1",
                type: "string",
                description: "The first option",
                required: true,
              },
              {
                name: "option_2",
                type: "string",
                description: "The second option",
                required: true,
              },
            ],
            render: ({ args, respond }) => {
              if (!respond) return <></>;
              return (
                <div>
                  {/* [!code highlight:2] */}
                  <button onClick={() => respond(`${args.option_1} was selected`)}>{args.option_1}</button>
                  <button onClick={() => respond(`${args.option_2} was selected`)}>{args.option_2}</button>
                </div>
              );
            },
          });

          // ...
        }
        ```
    </Step>
    <Step>
        ### 配置你的智能体

        人机协同工具通过 Agent Spec 中的 `ClientTool` 概念来启用。详情请参阅[前端工具指南](/frontend-tools)。简而言之，在你的 Agent Spec 配置中，你需要提供工具声明，但执行发生在客户端（即你的前端）。
    </Step>
    <Step>
        ### 试用一下！

        现在，你的智能体已经能够向用户展示两个选项并让用户选择其一。智能体随后会感知到用户的选择，并在后续步骤中使用它。

        ```
        Can you show me two good options for a restaurant name?
        ```
    </Step>

</Steps>
