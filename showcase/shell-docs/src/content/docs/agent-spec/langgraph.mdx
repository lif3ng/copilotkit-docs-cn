## 这是什么？

通过 AG-UI 事件协议，把一个由 LangGraph 支撑的 Agent Spec 智能体接入 CopilotKit 的 UI。你将运行一个会发出 AG-UI 事件的 FastAPI 端点，并把你的 Next.js 应用指向它。

关键组成部分：

- 后端端点：`ag-ui/integrations/agent-spec/python/ag_ui_agentspec/endpoint.py`
- 示例服务器：`ag-ui/integrations/agent-spec/python/examples/server.py`
- UI 模板：`npx copilotkit@latest create`

## 何时使用？

当你已经有一个由 Agent Spec 描述的基于 LangGraph 的智能体，并希望以最少的接线获得一个开箱即用的 UI——流式输出助手文本、工具调用/结果以及运行生命周期——就可以使用这一集成。

## 前置条件

- Python 3.10–3.14
- Node.js 20+
- 一份 Agent Spec 配置 JSON/YAML 文件（或通过 `pyagentspec` 编写的 Python 代码）

## 安装 Agent Spec AG-UI 集成

从 AG-UI 仓库的 Agent Spec 集成包开始：

```bash
git clone https://github.com/ag-ui-protocol/ag-ui.git
cd ag-ui/integrations/agent-spec/python
uv pip install -e .[langgraph]
```

注意这会从源码安装 `pyagentspec`。你也可以改用 pip 安装：

```bash
pip install pyagentspec[langgraph]
```

## 步骤

<Step>
### 1. 启动一个 FastAPI 端点（最小示例）

使用 LangGraph 运行时来执行你的 Agent Spec 并流式输出 AG-UI 事件。

```python
from fastapi import FastAPI
from ag_ui_agentspec.agent import AgentSpecAgent
from ag_ui_agentspec.endpoint import add_agentspec_fastapi_endpoint

agentspec_json = <loaded json/yaml string of your Agent Spec config>

app = FastAPI()
agent = AgentSpecAgent(agentspec_json, runtime="langgraph")
add_agentspec_fastapi_endpoint(app, agentspec_agent=agent, path="/")
```

本地运行：

```bash
uvicorn backend.app:app --reload --port 8000
```

</Step>

## 工作原理

- `AgentSpecAgent(runtime="langgraph")` 使用 LangGraph 框架执行你的 Agent Spec 智能体。
- 在 `AgentSpecAgent` 包装器中，`AgUiSpanProcessor` 把 Agent Spec 追踪 span 映射为 AG-UI 事件，写入按请求隔离的队列（`EVENT_QUEUE`）。
- FastAPI 端点将这些事件以 SSE 流式输出，供 CopilotKit 渲染：
  - 助手文本：`TEXT_MESSAGE_START/CONTENT/END`
  - 工具调用：`TOOL_CALL_START/ARGS/END` 与 `TOOL_CALL_RESULT`
  - 生命周期：`RUN_STARTED/RUN_FINISHED`

## 故障排查

- 端点路径必须与你的 UI 所期望的智能体端点一致（在我们的起步模板仓库中是 8000 端口）。
- 该端点会断言已绑定队列。如果出现队列错误，请检查请求是否经由所提供的 FastAPI 路由。
- 如果你没有收到任何事件，请确保智能体正在运行且没有崩溃。
