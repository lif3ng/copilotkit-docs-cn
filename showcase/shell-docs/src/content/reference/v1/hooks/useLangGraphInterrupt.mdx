<Callout type="warning">
  `useLangGraphInterrupt` 仍受支持，但我们建议迁移到 v2 API 中的 [`useInterrupt`](/reference/v2/hooks/useInterrupt)。`useInterrupt` 是结构完全等价的替代品。它使用相同的 `render: ({ event, resolve }) => ...` 模式为中断渲染 UI，并用用户的响应恢复智能体。
</Callout>

`useLangGraphInterrupt` 是一个 React 钩子，可在你的应用中使用，用于提供在使用 LangGraph 的 `interrupt` 时渲染的自定义 UI。
一旦 Interrupt 事件发出，该钩子就会执行，让你能够以自选的用户体验接收用户输入。

## 用法

### 简单用法

```tsx title="app/page.tsx"
import { useLangGraphInterrupt } from "@copilotkit/react-core"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:15]
  // styles omitted for brevity
  useLangGraphInterrupt<string>({
    render: ({ event, resolve }) => (
      <div>
        <p>{event.value}</p>
        <form onSubmit={(e) => {
          e.preventDefault();
          resolve((e.target as HTMLFormElement).response.value);
        }}>
          <input type="text" name="response" placeholder="Enter your response" />
          <button type="submit">Submit</button>
        </form>
      </div>
    )
  });
  // ...

  return <div>{/* ... */}</div>
}
```

## 参数

<PropertyReference name="action" type="Action" required>
  Interrupt 事件发出时要执行的操作。参数中必须定义 `handler` 或 `render` 之一

    <PropertyReference name="name" type="string" required>
      操作的名称。
    </PropertyReference>

    <PropertyReference name="handler" type="(args: LangGraphInterruptRenderProps<T>) => any | Promise<any>">
      用于以编程方式处理中断（Interrupt）的处理函数，或执行一些操作并将其结果传递给 `render` 方法
    </PropertyReference>

    <PropertyReference name="render" type="(props: LangGraphInterruptRenderProps<T>) => string | React.ReactElement">
        render 允许你定义一个自定义组件或字符串，在 Interrupt 事件发出时渲染。
    </PropertyReference>

    <PropertyReference name="enabled" type="(args: { eventValue: TEventValue; agentMetadata: AgentSession }) => boolean">
        返回布尔值的方法，指示该中断操作是否应该运行。在使用多个中断时非常有用
    </PropertyReference>

    <PropertyReference name="agentId" type="string">
        可选的 agent ID，用于将此中断限定到特定智能体。默认为 CopilotKit 聊天配置中所配置的智能体。
    </PropertyReference>
</PropertyReference>

<PropertyReference name="dependencies" type="any[]">
  一个可选的依赖项数组。
</PropertyReference>
