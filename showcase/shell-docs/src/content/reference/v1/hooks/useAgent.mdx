## 概览

`useAgent` 是一个 React hook，返回 [AG-UI AbstractAgent](https://docs.ag-ui.com/sdk/js/client/abstract-agent) 实例。该 hook 会订阅智能体状态变化，并在智能体的状态、消息或执行状态发生变化时触发重渲染。

若未配置具有指定 `agentId` 的智能体，**将抛出错误**。

## 签名

```tsx
function useAgent(options?: UseAgentProps): { agent: AbstractAgent }
```

## 参数

<PropertyReference name="options" type="UseAgentProps">
  该 hook 的配置对象。

  <PropertyReference name="agentId" type="string" default='"default"'>
    要获取的智能体 ID。必须与 `CopilotKitProvider` 中配置的某个智能体匹配。
  </PropertyReference>

  <PropertyReference name="updates" type="UseAgentUpdate[]" default="[OnMessagesChanged, OnStateChanged, OnRunStatusChanged]">
    控制哪些智能体变化会触发组件重渲染。可选项：
    - `UseAgentUpdate.OnMessagesChanged` - 消息变化时重新渲染
    - `UseAgentUpdate.OnStateChanged` - 状态变化时重新渲染
    - `UseAgentUpdate.OnRunStatusChanged` - 执行状态变化时重新渲染

    传入空数组 `[]` 可阻止自动重渲染。
  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="object" type="{ agent: AbstractAgent }">
  包含智能体实例的对象。

  <PropertyReference name="agent" type="AbstractAgent">
    AG-UI 智能体实例。完整的接口细节请参阅 [AbstractAgent 文档](https://docs.ag-ui.com/sdk/js/client/abstract-agent)。

    ### 核心属性

    <PropertyReference name="agentId" type="string | undefined">
      智能体实例的唯一标识符。
    </PropertyReference>

    <PropertyReference name="description" type="string">
      以人类可读形式描述智能体的用途。
    </PropertyReference>

    <PropertyReference name="threadId" type="string">
      当前会话线程的唯一标识符。
    </PropertyReference>

    <PropertyReference name="messages" type="Message[]">
      会话消息数组。每条消息包含：
      - `id: string` - 消息的唯一标识符
      - `role: "user" | "assistant" | "system"` - 消息角色
      - `content: string` - 消息内容
    </PropertyReference>

    <PropertyReference name="state" type="any">
      在应用与智能体之间同步的共享状态对象。双方均可读取和修改该状态。
    </PropertyReference>

    <PropertyReference name="isRunning" type="boolean">
      指示智能体当前是否正在执行。
    </PropertyReference>

    <PropertyReference name="debug" type="boolean">
      为智能体事件与执行启用调试日志。
    </PropertyReference>

    ### 方法

    <PropertyReference name="runAgent" type="(parameters?: RunAgentParameters, subscriber?: AgentSubscriber) => Promise<RunAgentResult>">
      底层方法：向智能体发送一次运行，并在运行结束后以 `RunAgentResult`（`{ result, newMessages }`）兑现。`result` 是该运行的最终结果值，`newMessages` 是运行期间产生的消息。

      它不会发送你注册的前端工具或上下文，不会执行前端工具调用，也不会链式发起后续运行。对于常规运行，请改用 [`useCopilotKit`](/reference/hooks/useCopilotKit) 中的 `copilotkit.runAgent({ agent })`。它接受相同的 `forwardedProps`，并以相同的 `RunAgentResult` 兑现。与 `agent.runAgent()` 不同，当运行本身失败时它不会 reject。核心会将错误（错误码 `AGENT_RUN_FAILED`）报告给其错误订阅者，并以 `{ result: undefined, newMessages: [] }` 兑现。

      **参数**：
      - `parameters.forwardedProps?: any` - 传递给智能体执行上下文的数据

      要响应中断，请使用 [`useInterrupt`](/reference/hooks/useInterrupt)，它会为你恢复运行。如需手动恢复，请传入标准的 `resume` 数组，其中包含被暂停运行所报告的中断 id：`copilotkit.runAgent({ agent, resume: [{ interruptId: interrupt.id, status: "resolved", payload }] })`。较旧的 `forwardedProps: { command: { resume } }` 形式是针对 `on_interrupt` 自定义事件的旧版路径。

      **示例**：
      ```tsx
      const { copilotkit } = useCopilotKit();

      const { result, newMessages } = await copilotkit.runAgent({
        agent,
        // Any data your agent reads from the run input.
        forwardedProps: { source: "refresh-button" },
      });
      ```
    </PropertyReference>

    <PropertyReference name="setState" type="(newState: any) => void">
      更新共享状态。变更对应用与智能体双方立即可见。

      **示例**：
      ```tsx
      agent.setState({
        ...agent.state,
        theme: "dark"
      });
      ```
    </PropertyReference>

    <PropertyReference name="subscribe" type="(subscriber: AgentSubscriber) => { unsubscribe: () => void }">
      订阅智能体事件。返回清理函数。

      **订阅者事件**：
      - `onCustomEvent?: ({ event: { name: string, value: any } }) => void` - 自定义事件（如 LangGraph 中断）
      - `onRunStartedEvent?: () => void` - 智能体执行开始
      - `onRunFinalized?: () => void` - 智能体执行完成
      - `onStateChanged?: (state: any) => void` - 状态变化
      - `onMessagesChanged?: (messages: Message[]) => void` - 消息新增或修改

      **示例**：
      ```tsx
      const { unsubscribe } = agent.subscribe({
        onCustomEvent: ({ event }) => {
          console.log(event.name, event.value);
        }
      });

      // Cleanup
      unsubscribe();
      ```
    </PropertyReference>

    <PropertyReference name="addMessage" type="(message: Message) => void">
      向会话添加单条消息并通知订阅者。

      **示例**：
      ```tsx
      agent.addMessage({
        id: crypto.randomUUID(),
        role: "user",
        content: "Hello"
      });
      ```
    </PropertyReference>

    <PropertyReference name="addMessages" type="(messages: Message[]) => void">
      向会话添加多条消息，且只通知订阅者一次。
    </PropertyReference>

    <PropertyReference name="setMessages" type="(messages: Message[]) => void">
      用新的消息数组替换整个消息历史。
    </PropertyReference>

    <PropertyReference name="connectAgent" type="(options?: RunAgentParameters) => Promise<RunAgentResult>">
      连接到流式智能体端点。与 `runAgent` 类似，但使用 `connect()` 方法建立持久连接。
    </PropertyReference>

    <PropertyReference name="detachActiveRun" type="() => Promise<void>">
      与当前活跃的智能体运行解除关联但不中止它。该运行会在后台继续，但不再更新本地智能体状态。
    </PropertyReference>

    <PropertyReference name="abortRun" type="() => void">
      中止当前正在运行的智能体执行。具体实现因智能体类型而异。
    </PropertyReference>

    <PropertyReference name="clone" type="() => AbstractAgent">
      创建智能体的深拷贝，包括克隆的消息、状态与配置。
    </PropertyReference>

    <PropertyReference name="use" type="(...middlewares: Middleware[]) => this">
      向智能体的执行管线添加中间件。中间件可以拦截并转换智能体运行。
    </PropertyReference>

  </PropertyReference>
</PropertyReference>

## 用法

### 基本用法

```tsx
import { useAgent } from "@copilotkit/react-core/v2";

function AgentStatus() {
  const { agent } = useAgent();

  return (
    <div>
      <div>Agent: {agent.agentId}</div>
      <div>Messages: {agent.messages.length}</div>
      <div>Running: {agent.isRunning ? "Yes" : "No"}</div>
    </div>
  );
}
```

### 访问状态

```tsx
function StateDisplay() {
  const { agent } = useAgent();

  return <pre>{JSON.stringify(agent.state, null, 2)}</pre>;
}
```

### 更新状态

```tsx
function StateController() {
  const { agent } = useAgent();

  return (
    <button onClick={() => agent.setState({ ...agent.state, count: 1 })}>
      Increment
    </button>
  );
}
```

### 事件订阅

```tsx
import { useEffect } from "react";
import { useAgent } from "@copilotkit/react-core/v2";
import type { AgentSubscriber } from "@ag-ui/client";

function EventListener() {
  const { agent } = useAgent();

  useEffect(() => {
    const { unsubscribe } = agent.subscribe({
      onRunStartedEvent: () => console.log("Started"),
      onRunFinalized: () => console.log("Finished"),
    });

    return unsubscribe;
  }, []);

  return null;
}
```

### 多个智能体

```tsx
function MultiAgentView() {
  const { agent: primary } = useAgent({ agentId: "primary" });
  const { agent: support } = useAgent({ agentId: "support" });

  return (
    <div>
      <div>Primary: {primary.messages.length}</div>
      <div>Support: {support.messages.length}</div>
    </div>
  );
}
```

### 优化重渲染

使用 `updates` 参数控制组件何时重渲染：

```tsx
import { useAgent, UseAgentUpdate } from "@copilotkit/react-core/v2";

// Only re-render when messages change
function MessageCount() {
  const { agent } = useAgent({
    updates: [UseAgentUpdate.OnMessagesChanged]
  });

  return <div>Messages: {agent.messages.length}</div>;
}

// Manually manage subscriptions (no automatic re-renders)
function ManualSubscription() {
  const { agent } = useAgent({ updates: [] });

  useEffect(() => {
    const { unsubscribe } = agent.subscribe({
      onMessagesChanged: () => {
        // Handle changes manually
      }
    });
    return unsubscribe;
  }, [agent]);

  return <div>Manual mode</div>;
}
```

## 行为

- **自动重渲染**：当智能体状态、消息或执行状态变化时组件会重渲染（可通过 `updates` 参数配置）
- **错误处理**：如果不存在具有指定 `agentId` 的智能体则抛出错误
- **状态同步**：通过 `setState()` 进行的状态更新对应用与智能体双方立即可见
- **事件订阅**：针对生命周期与自定义事件的订阅/取消订阅模式
