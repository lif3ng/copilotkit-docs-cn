---
title: "useDefaultTool"
description: "useDefaultTool 钩子用于渲染一个默认 UI，可捕获所有没有专用渲染器的工具。"
---

<Callout type="warning">
  `useDefaultTool` 仍受支持，但我们建议迁移到 v2 API 中的 [`useFrontendTool`](/reference/v2/hooks/useFrontendTool)。
</Callout>

`useDefaultTool` 是一个 React 钩子，允许你为任何没有专用渲染器的工具调用渲染自定义 UI

## 用法

```tsx
import { useDefaultTool } from "@copilotkit/react-core";

useDefaultTool({
  render: ({ name, args, status, result }) => {
    return (
      <div className="p-4 border rounded my-2">
        <div className="flex items-center justify-between mb-2">
          <h4 className="font-semibold">{name}</h4>
          <span className="text-sm text-gray-500">
            {status === "inProgress" && "Running..."}
            {status === "executing" && "Executing..."}
            {status === "complete" && "Complete"}
          </span>
        </div>

        {Object.keys(args).length > 0 && (
          <div className="mb-2">
            <p className="text-sm font-medium text-gray-600">Parameters:</p>
            <pre className="text-xs bg-gray-100 p-2 rounded mt-1">
              {JSON.stringify(args, null, 2)}
            </pre>
          </div>
        )}

        {status === "complete" && result && (
          <div>
            <p className="text-sm font-medium text-gray-600">Result:</p>
            <pre className="text-xs bg-gray-100 p-2 rounded mt-1">
              {JSON.stringify(result, null, 2)}
            </pre>
          </div>
        )}
      </div>
    );
  },
});
```

### 渲染 Model Context Protocol（MCP）工具

```tsx
import { useDefaultTool } from "@copilotkit/react-core";

// Render any MCP tool call with a custom UI
useDefaultTool({
  render: ({ name, args, status, result }) => {
    // Custom rendering for MCP tools
    if (name.startsWith("mcp_")) {
      return <MCPToolRenderer name={name} args={args} status={status} result={result} />;
    }

    // Default rendering for other tools
    return <DefaultToolRenderer name={name} args={args} status={status} result={result} />;
  },
});
```

## 参数

<PropertyReference name="tool" type="ReactRenderToolCall<T>" required>
  工具渲染配置对象。
    <PropertyReference name="render" type="React.ComponentType<RenderProps>">
      一个渲染工具调用 UI 的 React 组件。该组件会接收包含以下内容的 props：

      <div className="ml-8">
        <PropertyReference name="status" type="'inProgress' | 'executing' | 'complete'">
          - `"inProgress"`：工具正在准备，或参数正在流式传输。
          - `"executing"`：工具正在运行。
          - `"complete"`：工具执行已结束。
        </PropertyReference>

        <PropertyReference name="args" type="Partial<T> | T | any">
          传递给工具的参数。如果提供了参数 schema，则具有类型安全。
          对于捕获所有工具的渲染器（`name: "*"`），该值为 `any`。
        </PropertyReference>

        <PropertyReference name="result" type="any">
          工具返回的结果。仅在 status 为 `"complete"` 时可用。
        </PropertyReference>

        <PropertyReference name="name" type="string">
          正在执行的工具的实际名称。对于捕获所有工具的渲染器来说尤其有用，可用于得知当前渲染的是哪个工具。
        </PropertyReference>

        <PropertyReference name="description" type="string">
          正在执行的工具的描述。
        </PropertyReference>
      </div>
    </PropertyReference>
</PropertyReference>

<PropertyReference name="dependencies" type="any[]">
  一个可选的依赖项数组。
</PropertyReference>

## 常见用例

1. **后端工具可视化**：展示长时间运行的后端操作的进度和结果
2. **通用工具渲染**：为任何没有专用渲染的工具提供兜底 UI
3. **MCP 工具集成**：渲染来自各种来源的 Model Context Protocol 工具
4. **调试**：在开发过程中展示所有工具调用
5. **分析**：跟踪并展示工具使用情况

## 从 useCopilotAction 迁移

如果你正在从只带 `render` 函数的 `useCopilotAction` 迁移：

```tsx
// Before with useCopilotAction (the catch-all name is "*")
useCopilotAction({
  name: "*",
  render: ({ name, args, status, result }) => (
    <GenericToolCall name={name} args={args} status={status} result={result} />
  ),
});

// After with useDefaultTool
useDefaultTool({
  render: ({ name, args, status, result }) => (
    <GenericToolCall name={name} args={args} status={status} result={result} />
  ),
});
```

迁移非常简单——只需更改钩子名称即可。render props 保持不变。
