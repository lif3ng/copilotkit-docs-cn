`useCopilotAction` 是一个 React hook，可用于在你的应用中提供可被 AI 调用的自定义操作。从本质上讲，它让 Copilot 能够在聊天过程中根据用户的交互和需求，在相应的上下文中执行这些操作。

它的工作方式如下：

使用 `useCopilotAction` 设置 Copilot 可以调用的操作。为了让 Copilot 获得更多上下文，你可以为它提供 `description`（例如说明该操作做什么、在哪些条件下可以调用等）。

然后定义操作的参数，参数可以是简单的（例如字符串、数字等原始类型），也可以是复杂的（例如对象或数组）。

最后，提供一个接收这些参数并返回结果的 `handler` 函数。CopilotKit 会自动推断参数类型，因此你可以免费获得类型安全和自动补全。

要为该操作渲染自定义 UI，可以提供 `render()` 函数。该函数让你渲染自定义组件，或返回一个要显示的字符串。

## 用法

### 简单用法

```tsx
useCopilotAction({
  name: "sayHello",
  description: "Say hello to someone.",
  parameters: [
    {
      name: "name",
      type: "string",
      description: "name of the person to say greet",
    },
  ],
  handler: async ({ name }) => {
    alert(`Hello, ${name}!`);
  },
});
```

## 生成式 UI

此 hook 让你能够动态生成 UI 元素并在 copilot 聊天中渲染它们。更多信息请查看[生成式 UI](/generative-ui/your-components/display-only) 页面。

## 参数

<PropertyReference name="action" type="Action" required>
  提供给 Copilot 使用的函数。参见 [Action](#action)。

    <PropertyReference name="name" type="string" required>
      操作的名称。
    </PropertyReference>

    <PropertyReference name="handler" type="(args) => Promise<any>" required>
      操作的 handler。
    </PropertyReference>

    <PropertyReference name="description" type="string">
      操作的描述。用于指导 Copilot 如何使用该操作。
    </PropertyReference>

    <PropertyReference name="available" type="'enabled' | 'disabled' | 'remote'">
      使用此属性控制该操作何时对 Copilot 可用。设置为 `"remote"` 时，该操作仅对 remote agent 可用。
    </PropertyReference>

    <PropertyReference name="followUp" type="boolean" default="true">
        是否将函数调用的结果报告给 LLM，随后 LLM 会给出后续响应。传入 `false` 可禁用此行为。
    </PropertyReference>

    <PropertyReference name="parameters" type="Parameter[]">
      操作的参数。参见 [Parameter](#parameter)。

      <PropertyReference name="name" type="string" required>
        参数的名称。
      </PropertyReference>

      <PropertyReference
        name="type"
        type="string"
        required
      >
        该实参的类型。可为以下之一：
        - `"string"`
        - `"number"`
        - `"boolean"`
        - `"object"`
        - `"object[]"`
        - `"string[]"`
        - `"number[]"`
        - `"boolean[]"`
      </PropertyReference>

      <PropertyReference name="description" type="string">
        实参的描述。用于指导 Copilot 了解该实参的用途。
      </PropertyReference>

      <PropertyReference name="enum" type="string[]">
        对于字符串实参，可以提供一个可选值数组。
      </PropertyReference>

      <PropertyReference name="required" type="boolean">
        该实参是否必填。默认为 true。
      </PropertyReference>

      <PropertyReference name="attributes">
      如果实参是复杂类型（即 `object` 或 `object[]`），此字段可用于定义对象的属性（attributes）。例如：
      ```js
      {
        name: "addresses",
        description: "The addresses extracted from the text.",
        type: "object[]",
        attributes: [
          {
            name: "street",
            type: "string",
            description: "The street of the address.",
          },
          {
            name: "city",
            type: "string",
            description: "The city of the address.",
          },
          // ...
        ],
      }
      ````
      </PropertyReference>
    </PropertyReference>

    <PropertyReference name="render" type="string | (props: ActionRenderProps<T>) => string">
      通过 render 可以定义自定义组件或字符串，用来替代默认渲染。你可以传入字符串，或一个接收以下 props 的函数：

      <div className="ml-8">
        <PropertyReference name="status" type="'inProgress' | 'executing' | 'complete'">
          - `"inProgress"`：实参以流式方式动态传入函数，让你可以实时调整 UI。
          - `"executing"`：操作 handler 正在执行。
          - `"complete"`：操作 handler 已执行完成。
        </PropertyReference>

        <PropertyReference name="args" type="T">
          实时传递给操作的实参。当状态为 `"inProgress"` 时，实参可能尚不完整。
        </PropertyReference>

        <PropertyReference name="result" type="any">
          操作返回的结果。仅当状态为 `"complete"` 时可用。
        </PropertyReference>
      </div>
    </PropertyReference>

    <PropertyReference name="renderAndWaitForResponse" type="(props: ActionRenderPropsWait<T>) => React.ReactElement">
      这与 `render` 类似，但会在 props 中提供一个 `respond` 函数，你必须携带用户的响应调用它。组件会保持渲染状态，直到 `respond` 被调用。该响应会作为结果传递给操作 handler。
      <div className="ml-8">
        <PropertyReference name="status" type="'inProgress' | 'executing' | 'complete'">
          - `"inProgress"`：实参以流式方式动态传入函数，让你可以实时调整 UI。
          - `"executing"`：操作 handler 正在执行。
          - `"complete"`：操作 handler 已执行完成。
        </PropertyReference>

        <PropertyReference name="args" type="T">
          实时传递给操作的实参。当状态为 `"inProgress"` 时，实参可能尚不完整。
        </PropertyReference>

        <PropertyReference name="respond" type="(result: any) => void">
          必须携带用户的响应调用的函数。该响应会作为结果传递给操作 handler。仅当状态为 `"executing"` 时可用。
        </PropertyReference>

        <PropertyReference name="result" type="any">
          操作返回的结果。仅当状态为 `"complete"` 时可用。
        </PropertyReference>
      </div>
    </PropertyReference>

</PropertyReference>

<PropertyReference name="dependencies" type="any[]">
  可选的依赖数组。
</PropertyReference>
