<Callout type="warning">
  v1 的 `useRenderToolCall` 接受一个 `{ name, parameters, render }` 配置对象，用于为现有的后端工具**注册**渲染器。在 v2 中，这项工作请使用 [`useRenderTool`](https://docs.copilotkit.ai/reference/v2/hooks/useRenderTool)。v2 中名为 [`useRenderToolCall`](/reference/v2/hooks/useRenderToolCall) 的钩子则是另一个不同的低层 API，它返回一个用于消费工具调用的渲染器函数。

```tsx
import { useRenderTool } from "@copilotkit/react-core/v2";
import { z } from "zod";

function StatusTool() {
  useRenderTool({
    name: "showStatus",
    parameters: z.object({}),
    render: ({ status, result }) => (
      <div>{status === "complete" ? result : "Running..."}</div>
    ),
  });
  return null;
}
```

</Callout>

`useRenderToolCall` 是一个纯粹的渲染钩子。它为工具调用显示自定义 UI，而不执行
任何逻辑。它通常用于在聊天界面中可视化后端工具的执行过程，让
用户看到 AI 在幕后正在做什么。

该钩子没有处理函数。你只需提供一个 render 函数，它接收有关
工具调用的信息（参数、状态、结果），并按你想要的方式显示。你可以针对特定的
工具名称，也可以使用星号（`"*"`）来捕获并渲染所有工具调用。

## 用法

### 渲染特定的后端工具

```tsx
import { useRenderToolCall } from "@copilotkit/react-core";

useRenderToolCall({
  name: "analyzeData",
  description: "Display results of data analysis",
  parameters: [
    {
      name: "datasetName",
      type: "string",
      description: "Name of the dataset being analyzed",
      required: true,
    },
    {
      name: "metrics",
      type: "string[]",
      description: "Metrics being calculated",
      required: true,
    },
  ],
  render: ({ args, status, result }) => {
    if (status === "inProgress") {
      return (
        <div className="p-4 border rounded animate-pulse">
          <h3>Analyzing {args.datasetName}...</h3>
          <p>Calculating: {args.metrics?.join(", ")}</p>
        </div>
      );
    }

    if (status === "complete" && result) {
      return (
        <div className="p-4 border rounded bg-green-50">
          <h3>Analysis Complete: {args.datasetName}</h3>
          <pre className="mt-2 p-2 bg-gray-100 rounded">
            {JSON.stringify(result, null, 2)}
          </pre>
        </div>
      );
    }

    return null;
  },
});
```

## 从 useCopilotAction 迁移

如果你正在从只带 `render` 函数的 `useCopilotAction` 迁移：

```tsx
// Before with useCopilotAction
useCopilotAction({
  name: "showResult",
  render: ({ args }) => <ResultCard {...args} />,
});

// After with useRenderToolCall
useRenderToolCall({
  name: "showResult",
  render: ({ args }) => <ResultCard {...args} />,
});
```

迁移非常简单——只需更改钩子名称即可。render props 保持不变。

## 参数

<PropertyReference name="name" type="string" required>
  要渲染的工具名称。使用 `"*"` 可捕获所有工具调用。
</PropertyReference>

<PropertyReference name="description" type="string">
  描述此渲染器的用途。主要用于文档说明。
</PropertyReference>

<PropertyReference name="parameters" type="T"  >
可选的参数定义数组。如果提供，会为 render 函数中的 args 增加类型安全。每个参数对象应包含：
- `name`（string）：参数名称
- `type`（string）：参数类型（例如 "string"、"number"、"boolean"、"string[]"、"object"）
- `description`（string）：说明该参数的用途
- `required`（boolean）：该参数是否必填
- `properties`（array，可选）：对于 object 类型，使用相同的 schema 定义嵌套属性

简单示例：`[{ name: "datasetName", type: "string", description: "Name of the dataset", required: true }]`

嵌套示例：

```typescript
[
  {
    name: "analysisConfig",
    type: "object",
    description: "Configuration for the analysis",
    required: true,
    properties: [
      {
        name: "method",
        type: "string",
        description: "Analysis method to use",
        required: true,
      },
      {
        name: "threshold",
        type: "number",
        description: "Threshold value",
        required: false,
      },
    ],
  },
];
```

</PropertyReference>

<PropertyReference name="render" type="FrontendAction<T>['render']">
  渲染工具调用 UI 的 React 组件。该组件接收的 props
  包含 `status`、`args`、`result`、`name` 和 `description`。
</PropertyReference>

<PropertyReference name="available" type="'disabled' | 'enabled'">
  在此 v1 钩子中目前不起作用。该值仅为 API
  兼容性而被接受，实际会被忽略，因此设置为 `"disabled"` 并不会阻止
  该渲染器被注册。
</PropertyReference>
