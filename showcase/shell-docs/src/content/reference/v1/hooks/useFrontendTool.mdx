---

<Callout type="warning">
  这里是 v1 的 `useFrontendTool`，它接受一个参数定义数组。它仍受支持，但我们建议迁移到 [v2 的 `useFrontendTool`](/reference/v2/hooks/useFrontendTool)（来自 `@copilotkit/react-core/v2`），后者使用 Zod schema 定义参数。
</Callout>

`useFrontendTool` 允许你定义 AI 可以调用的可执行操作，并提供对应的处理函数。
这是赋予你的 AI 智能体在应用中执行操作能力的主要方式，无论是
更新状态、发起 API 调用，还是触发副作用。

该钩子需要三个主要部分：
1. 名称和描述，让 AI 知道何时调用它
2. 参数定义，描述工具接受哪些输入
3. 处理函数，在 AI 调用工具时执行

你还可以选择提供一个 `render` 函数，在聊天界面中显示自定义 UI，展示工具的执行
状态和结果。

## 用法

### 简单用法

```tsx
import { useFrontendTool } from "@copilotkit/react-core";

useFrontendTool({
  name: "sayHello",
  description: "Say hello to someone.",
  parameters: [
    {
      name: "name",
      type: "string",
      description: "name of the person to greet",
      required: true,
    },
  ],
  handler: async ({ name }) => {
    alert(`Hello, ${name}!`);
  },
});
```

### 使用自定义 UI 渲染

```tsx
import { useFrontendTool } from "@copilotkit/react-core";

useFrontendTool({
  name: "showWeatherCard",
  description: "Display weather information for a location",
  parameters: [
    {
      name: "location",
      type: "string",
      description: "The location to show weather for",
      required: true,
    },
    {
      name: "temperature",
      type: "number",
      description: "Temperature in celsius",
      required: true,
    },
  ],
  handler: async ({ location, temperature }) => {
    // Fetch and return weather data
    return { location, temperature, conditions: "Sunny" };
  },
  render: ({ args, status, result }) => {
    if (status === "inProgress") {
      return <div>Loading weather for {args.location}...</div>;
    }
    if (status === "complete" && result) {
      return (
        <WeatherCard
          location={result.location}
          temperature={result.temperature}
          conditions={result.conditions}
        />
      );
    }
    return null;
  },
});
```

## 生成式 UI

该钩子让你能够动态生成 UI 元素并在 copilot 聊天中渲染它们。更多信息请查看[生成式 UI](/generative-ui/your-components/display-only)页面。

## 从 useCopilotAction 迁移

如果你正在从 `useCopilotAction` 迁移，主要区别如下：

1. render 组件的 props 包含 `name` 和 `description`

### 迁移示例

```tsx
// Before with useCopilotAction
useCopilotAction({
  name: "addTodo",
  parameters: [
    {
      name: "text",
      type: "string",
      description: "The todo text",
      required: true,
    },
  ],
  handler: ({ text }) => {
    addTodo(text);
  },
});

// After with useFrontendTool
useFrontendTool({
  name: "addTodo",
  parameters: [
    {
      name: "text",
      type: "string",
      description: "The todo text",
      required: true,
    },
  ],
  handler: ({ text }) => {
    addTodo(text);
  },
});
```

## 参数

<PropertyReference name="name" type="string" required >
工具的名称。
</PropertyReference>

<PropertyReference name="description" type="string"  >
工具的描述。用于指导 Copilot 如何使用该工具。
</PropertyReference>

<PropertyReference name="parameters" type="T"  >
工具的参数定义数组。每个参数对象应包含：
- `name`（string）：参数名称
- `type`（string）：参数类型（例如 "string"、"number"、"boolean"、"string[]"、"object"）
- `description`（string）：说明该参数的用途
- `required`（boolean）：该参数是否必填
- `properties`（array，可选）：对于 object 类型，使用相同的 schema 定义嵌套属性

简单示例：`[{ name: "query", type: "string", description: "The search query", required: true }]`

嵌套示例：
```typescript
[
  {
    name: "user",
    type: "object",
    description: "User information",
    required: true,
    properties: [
      { name: "name", type: "string", description: "User's name", required: true },
      { name: "age", type: "number", description: "User's age", required: false }
    ]
  }
]
```
</PropertyReference>

<PropertyReference name="handler" type="FrontendAction<T>['handler']"  >
执行工具逻辑的处理函数。
</PropertyReference>

<PropertyReference name="followUp" type="boolean"  >
是否将工具调用的结果上报给 LLM，由其随后提供后续响应。传入 `false` 可禁用。
</PropertyReference>

<PropertyReference name="render" type="FrontendAction<T>['render']"  >
为该工具渲染自定义 UI 的 React 组件。
</PropertyReference>

<PropertyReference name="available" type="'disabled' | 'enabled'"  >
该工具是否可用。设置为 "disabled" 可阻止该工具被调用。
</PropertyReference>
