## 概览

`CopilotSidebar` 渲染一个用于聊天交互的固定侧边栏面板。它包裹了 [`CopilotChat`](/reference/components/CopilotChat)，并提供侧边栏专属的布局与打开/关闭行为。侧边栏包含一个带标题和关闭按钮的头部，并可通过浮动按钮切换显示。

本组件的弹窗变体请参见 [`CopilotPopup`](/reference/components/CopilotPopup)。

## 导入

```tsx
import { CopilotSidebar } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## 属性

### 自身属性

<PropertyReference name="header" type="SlotValue<typeof CopilotModalHeader>">
  侧边栏头部的插槽覆盖。接受替换组件、合并进默认样式的 `className` 字符串或部分 props 对象。默认头部显示一个标题和一个关闭按钮。
</PropertyReference>

<PropertyReference name="defaultOpen" type="boolean" default="true">
  组件首次挂载时侧边栏是否打开。此后侧边栏自行持有该状态。若要始终保持控制，请改用 `open`。
</PropertyReference>

<PropertyReference name="open" type="boolean">
  受控的打开状态。提供该属性后，侧边栏是否打开由你的组件决定：侧边栏只渲染该值，绝不会自行更改。请与 `onOpenChange` 搭配使用。同时传入 `open` 和 `defaultOpen` 时，`open` 优先。参见 [打开、关闭与反馈](/prebuilt-components/chat-controls)。
</PropertyReference>

<PropertyReference name="onOpenChange" type="(open: boolean) => void">
  每当侧边栏请求打开或关闭时（切换按钮或移动端上的线程抽屉），都会以目标状态调用该回调。它报告的是一次请求而非已发生的变化：在受控模式下，在你更新 `open` 之前不会有任何变化。
</PropertyReference>

<PropertyReference name="width" type="number | string">
  侧边栏面板的宽度。接受数字（像素）或 CSS 字符串（例如 `"400px"`、`"30vw"`）。
</PropertyReference>

### 继承自 CopilotChat 的属性

`CopilotSidebar` 接受 [`CopilotChatProps`](/reference/components/CopilotChat) 的**全部** props，**唯一例外**是 `chatView`——它在内部被设为 `CopilotSidebarView`。其中包括：

<PropertyReference name="agentId" type="string">
  要使用的智能体 ID。必须与 `CopilotKit` 中配置的某个智能体匹配。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  对聊天中渲染的所有文本字符串的部分标签覆盖。
</PropertyReference>

<PropertyReference name="autoScroll" type="boolean" default="true">
  新消息到达时聊天是否自动滚动到底部。
</PropertyReference>

<PropertyReference
  name="inputProps"
  type="Partial<Omit<CopilotChatInputProps, 'children'>>"
>
  转发给内部 `CopilotChatInput` 组件的额外 props。
</PropertyReference>

<PropertyReference
  name="welcomeScreen"
  type="SlotValue<React.FC<WelcomeScreenProps>> | boolean"
>
  控制没有消息时显示的欢迎屏。
</PropertyReference>

所有 `CopilotChatView` 插槽 props（`messageView`、`input`、`scrollView`、`inputContainer`、`feather`、`disclaimer`、`suggestionView`）也都被接受并透传。

## 插槽系统

所有插槽 props 都遵循 CopilotKit v2 组件通用的覆盖模式。每个插槽接受以下三种取值之一：

| 取值                     | 行为                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| **Component**            | 完全替换默认组件，接收与默认组件相同的 props。                                       |
| **`className` string**   | 通过 `twMerge` 合并进默认组件的类名列表。                                            |
| **Partial props object** | 以附加或覆盖 props 的形式展开传入默认组件。                                          |

## 用法

### 基础用法

```tsx
function App() {
  return (
    <CopilotSidebar
      agentId="my-agent"
      labels={{ modalHeaderTitle: "Assistant" }}
    />
  );
}
```

### 默认打开并自定义宽度

```tsx
function App() {
  return <CopilotSidebar agentId="my-agent" defaultOpen={true} width={500} />;
}
```

### 自定义头部

```tsx
function App() {
  return (
    <CopilotSidebar agentId="my-agent" header="bg-indigo-700 text-white" />
  );
}
```

## 行为

- **切换按钮**：渲染一个浮动切换按钮，用于打开和关闭侧边栏。该按钮在内部使用 `CopilotChatToggleButton`。
- **弹层状态**：打开/关闭状态通过聊天配置上下文管理。`defaultOpen` prop 设置初始状态；此后的状态变化来自用户交互（切换按钮、头部中的关闭按钮）。传入 `open` 和 `onOpenChange` 可自行持有状态，并从你自己的 UI 打开或关闭侧边栏。
- **布局**：侧边栏在内部使用 `CopilotSidebarView`，它提供侧边栏专属的欢迎屏布局：建议位于顶部，欢迎消息居中，输入框固定在底部。
- **固定定位**：侧边栏以固定面板的形式渲染在视口的一侧，根据 CSS 不同会推挤或覆盖页面内容。
- **智能体连接**：所有智能体接线（消息、运行状态、建议）都由父级 `CopilotChat` 逻辑处理。
