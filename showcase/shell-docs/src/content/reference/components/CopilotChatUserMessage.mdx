## 概览

`CopilotChatUserMessage` 用于展示右对齐的用户消息，并支持可选的分支导航。默认的消息渲染器以 `white-space: pre-wrap` 格式化内容，以保留换行。只有当 `numberOfBranches` 大于 1 且提供了 `onSwitchToBranch` 处理函数时，才会渲染分支导航控件，从而让用户可以在多个备选对话分支之间切换。

## 导入

```tsx
import { CopilotChatUserMessage } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## 属性

<PropertyReference name="message" type="UserMessage" required>
  要渲染的用户消息对象。包含消息的 `content`、`id` 和 `role`。
</PropertyReference>

<PropertyReference
  name="onEditMessage"
  type="(props: { message: UserMessage }) => void"
>
  用户点击编辑按钮时调用的回调。未提供时，工具栏中不会显示编辑按钮。
</PropertyReference>

<PropertyReference
  name="onSwitchToBranch"
  type="(props: { message: UserMessage; branchIndex: number; numberOfBranches: number }) => void"
>
  用户切换到其他分支时调用的回调。会接收目标 `branchIndex` 和分支总数 `numberOfBranches`。只有提供了该回调且 `numberOfBranches` 大于 1 时，才会渲染分支导航控件。
</PropertyReference>

<PropertyReference name="branchIndex" type="number">
  当前激活分支的索引（从 0 开始）。分支导航控件使用该值显示当前位置。
</PropertyReference>

<PropertyReference name="numberOfBranches" type="number">
  该消息可用分支的总数。只有该值大于 1 且提供了 `onSwitchToBranch` 时才会渲染分支导航。
</PropertyReference>

<PropertyReference name="additionalToolbarItems" type="React.ReactNode">
  附加到工具栏的额外 React 元素，与默认操作按钮并列显示。
</PropertyReference>

## 插槽

所有插槽类 props 均遵循 CopilotKit 插槽系统：每个插槽都可以接受一个替换用的 React 组件、一个会合并进默认组件类名的 `className` 字符串，或一个用于扩展默认组件的部分 props 对象。

<PropertyReference name="messageRenderer" type="SlotProp<typeof CopilotChatUserMessage.MessageRenderer>">
  消息内容渲染器的插槽。默认为 `CopilotChatUserMessage.MessageRenderer`，它以 `white-space: pre-wrap` 格式化消息文本，保留空白与换行。

**作为替换组件：**

```tsx
<CopilotChatUserMessage
  message={msg}
  messageRenderer={({ message }) => (
    <div className="font-mono text-sm">{message.content}</div>
  )}
/>
```

**作为 className：**

```tsx
<CopilotChatUserMessage message={msg} messageRenderer="text-lg font-medium" />
```

</PropertyReference>

<PropertyReference name="toolbar" type="SlotProp<typeof CopilotChatUserMessage.Toolbar>">
  操作工具栏容器的插槽。默认为 `CopilotChatUserMessage.Toolbar`，它在消息内容下方渲染一行水平排列的操作按钮。

**作为 className：**

```tsx
<CopilotChatUserMessage
  message={msg}
  toolbar="opacity-0 group-hover:opacity-100 transition-opacity"
/>
```

</PropertyReference>

<PropertyReference
  name="copyButton"
  type="SlotProp<typeof CopilotChatUserMessage.CopyButton>"
>
  复制到剪贴板按钮的插槽。默认为 `CopilotChatUserMessage.CopyButton`。工具提示文案来自 `CopilotChatLabels.userMessageToolbarCopyMessageLabel`。
</PropertyReference>

<PropertyReference
  name="editButton"
  type="SlotProp<typeof CopilotChatUserMessage.EditButton>"
>
  编辑按钮的插槽。默认为 `CopilotChatUserMessage.EditButton`。仅在提供了 `onEditMessage` 时渲染。工具提示文案来自 `CopilotChatLabels.userMessageToolbarEditMessageLabel`。
</PropertyReference>

<PropertyReference name="branchNavigation" type="SlotProp<typeof CopilotChatUserMessage.BranchNavigation>">
  分支导航控件的插槽。默认为 `CopilotChatUserMessage.BranchNavigation`，它会渲染上一个/下一个箭头以及分支计数器（例如 “2 / 3”）。仅在 `numberOfBranches` 大于 1 且提供了 `onSwitchToBranch` 时渲染。

**作为替换组件：**

```tsx
<CopilotChatUserMessage
  message={msg}
  numberOfBranches={3}
  branchIndex={1}
  onSwitchToBranch={handleSwitch}
  branchNavigation={({
    branchIndex,
    numberOfBranches,
    onSwitchToBranch,
    message,
  }) => (
    <div className="flex items-center gap-1 text-xs">
      <button
        onClick={() =>
          onSwitchToBranch({
            message,
            branchIndex: branchIndex - 1,
            numberOfBranches,
          })
        }
        disabled={branchIndex === 0}
      >
        Prev
      </button>
      <span>
        {branchIndex + 1} of {numberOfBranches}
      </span>
      <button
        onClick={() =>
          onSwitchToBranch({
            message,
            branchIndex: branchIndex + 1,
            numberOfBranches,
          })
        }
        disabled={branchIndex === numberOfBranches - 1}
      >
        Next
      </button>
    </div>
  )}
/>
```

</PropertyReference>

## 用法

### 基础用户消息

```tsx
function UserBubble({ message }) {
  return <CopilotChatUserMessage message={message} />;
}
```

### 支持编辑

```tsx
function EditableUserMessage({ message, onEdit }) {
  return (
    <CopilotChatUserMessage
      message={message}
      onEditMessage={({ message }) => onEdit(message)}
    />
  );
}
```

### 支持分支导航

```tsx
function BranchedUserMessage({
  message,
  branchIndex,
  totalBranches,
  onSwitch,
}) {
  return (
    <CopilotChatUserMessage
      message={message}
      branchIndex={branchIndex}
      numberOfBranches={totalBranches}
      onSwitchToBranch={({ branchIndex }) => onSwitch(branchIndex)}
    />
  );
}
```

### 使用插槽自定义外观

```tsx
function StyledUserMessage({ message }) {
  return (
    <CopilotChatUserMessage
      message={message}
      messageRenderer="bg-blue-600 text-white rounded-2xl px-4 py-2"
      toolbar="mt-1"
      onEditMessage={({ message }) => console.log("Edit:", message.id)}
      additionalToolbarItems={
        <button onClick={() => console.log("Pin:", message.id)}>Pin</button>
      }
    />
  );
}
```

### 完整的编辑与分支工作流

```tsx
function FullFeaturedUserMessage({ message, branches }) {
  const [currentBranch, setCurrentBranch] = useState(0);

  return (
    <CopilotChatUserMessage
      message={message}
      branchIndex={currentBranch}
      numberOfBranches={branches.length}
      onSwitchToBranch={({ branchIndex }) => setCurrentBranch(branchIndex)}
      onEditMessage={({ message }) => {
        // Open edit modal
        openEditModal(message);
      }}
    />
  );
}
```

## 行为

- **右对齐布局**：用户消息以右对齐方式渲染，在视觉上与助手消息区分开。
- **空白保留**：默认消息渲染器使用 `white-space: pre-wrap`，因此原始消息中的换行与空格都会被保留。
- **条件渲染的分支导航**：只有同时满足 `numberOfBranches > 1` 和已提供 `onSwitchToBranch` 这两个条件时，才会渲染分支导航控件，避免在单分支对话中显示导航。
- **条件渲染的编辑按钮**：只有提供了 `onEditMessage` 时，编辑按钮才会出现在工具栏中。
- **本地化标签**：工具栏按钮的工具提示文案取自最近的 `CopilotChatConfigurationProvider`。可用标签键请参阅 [`useCopilotChatConfiguration`](/reference/hooks/useCopilotChatConfiguration)。
- **插槽系统**：每个插槽 prop 都接受三种形式——替换组件、合并进默认样式的 className 字符串，或扩展默认组件 props 的部分 props 对象。
