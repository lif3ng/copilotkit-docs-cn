## 概览

`CopilotThreadsDrawer` 是一个预构建的线程切换器。把它放到 [`CopilotChat`](/reference/components/CopilotChat) 旁边，它会列出用户的会话，并支持切换、新建、归档和删除线程——**无需接线任何活跃线程状态**。（线程重命名只能通过 [`useThreads`](/reference/hooks/useThreads) 以无头方式实现，抽屉的行菜单不提供该功能。）它是对框架无关的 `<copilotkit-threads-drawer>` shadow-DOM Web 组件的一层轻量 React 包装，由 [`useThreads`](/reference/hooks/useThreads) hook 和周围的聊天配置提供数据。

省略 `onThreadSelect` / `onNewThread` 时，抽屉会直接驱动周围的聊天配置：选中某一行会把聊天连接到该线程（并回放其历史记录）；“新建会话”一行会把聊天重置为全新的欢迎屏。只有当你想自己控制活跃线程时才需要传入这些回调。

请将它与来自 `@copilotkit/react-core/v2` 的 v2 版 `CopilotChat` 或 `CopilotSidebar` 搭配使用。`@copilotkit/react-ui` 也导出了同名的两个组件，但那是[已弃用的 v1 组件](/migrate/v2)。

完整演练请参阅 [CopilotThreadsDrawer 指南](/prebuilt-components/copilot-threads-drawer)，其底层的无头数据层请参见 [`useThreads`](/reference/hooks/useThreads)。

## 导入

```tsx
import { CopilotThreadsDrawer } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## 属性

<PropertyReference name="agentId" type="string">
  要列出和管理其线程的智能体。抽屉只列出一个智能体的线程。省略时，依次使用最近的 `CopilotChatConfigurationProvider` 的智能体、`CopilotKitProvider` 上的 `agentId`，最后是 `"default"`。`CopilotKit` 会根据其 `agent` prop 设置聊天配置（省略 `agent` 时为 `"default"`）。当你的运行时注册了多个智能体、而抽屉应列出另一个智能体时，请传入该属性。
</PropertyReference>

<PropertyReference name="onThreadSelect" type="(threadId: string) => void">
  可选的逃生舱口，在用户选择某个线程行时调用。省略时，抽屉直接驱动周围的聊天配置（`setActiveThreadId`），因此一个裸的 `<CopilotThreadsDrawer>` 无需宿主接线即可切换渲染中的线程。只有当你想自己控制活跃线程时才提供它。
</PropertyReference>

<PropertyReference name="onNewThread" type="() => void">
  可选的逃生舱口，在用户开始新线程时调用（即“新建会话”一行）。包装器总会把核心线程存储重置为全新的非显式线程；省略该回调时，它还会重置周围的聊天配置，因此无需宿主接线即可显示欢迎屏。
</PropertyReference>

<PropertyReference name="renderRow" type="(thread: Thread) => React.ReactNode">
  可选的每行自定义内容。会作为 light-DOM 子元素投影到元素的 `slot="row:{id}"` 中，因此元素仍会在你的内容外围保留行的外观（选中态、归档样式、入场动画、操作按钮）。对某一行返回 `null` 则保留该元素的默认行名称。
</PropertyReference>

<PropertyReference name="label" type="string" default="Threads">
  抽屉的可访问名称。为抽屉区域和线程列表框（listbox）同时设置 `aria-label`。重新设计的头部没有可见标题，因此不再作为头部文字显示。
</PropertyReference>

<PropertyReference name="recentLabel" type="string" default="Recent Conversations">
  线程列表上方显示的分区标题文字（即 `section-heading` 部分），与筛选漏斗并排。
</PropertyReference>

<PropertyReference name="limit" type="number">
  线程分页的页大小。设置后，线程按该大小分页加载，当还有更多线程时，列表底部会出现“加载更多”控件（元素会发出 `load-more` 事件，由包装器路由到 `fetchMoreThreads`）。省略则一次性加载完整列表且不显示该控件。
</PropertyReference>

<PropertyReference name="collapsible" type="boolean" default="true">
  抽屉在桌面端是否提供折叠开关。为 `true`（默认）时，头部会显示一个侧边栏图形开关；折叠后面板会被一个小型浮动组件组取代（一个侧边栏开关 + 一个“新建会话”按钮），并且抽屉会在文档根元素上设置 `--cpk-drawer-reserved-width: 0px`，读取该变量的宿主网格即可收回该列。设为 `false` 则去掉开关并让抽屉始终保持展开。
</PropertyReference>

<PropertyReference name="onCollapseChange" type="(collapsed: boolean) => void">
  用户切换桌面端折叠状态时调用，携带新的 `collapsed` 值。可选——抽屉自己管理折叠状态；仅当你想把它同步到自己的布局时使用。
</PropertyReference>

<PropertyReference name="data-testid" type="string" default="copilot-threads-drawer">
  设置在底层自定义元素上的 `data-testid`，用于测试和从宿主页面定位。
</PropertyReference>

## 自定义

抽屉渲染在 shadow root 内部，自带独立且继承主题的样式，因此在任何宿主中（包括深色模式）零配置即可正确显示。有三个受约束的逃生舱口可以穿透这层边界。

### 插槽

通过 `slot` 属性投影 light-DOM 子元素来替换某个区域：

| 插槽       | 替换的内容                                             |
| ---------- | ------------------------------------------------------ |
| `header`   | 抽屉头部区域（仅当你投影内容时才渲染）。               |
| `empty`    | 没有线程时显示的空状态主体。                           |
| `footer`   | 页脚区域（在你投影内容之前隐藏）。                     |
| `memories` | 为未来的记忆（memories）界面预留的区域。               |
| `launcher-icon` | 移动端浮动启动器内的图标。                         |
| `row:{id}` | 每行内容——建议使用管理此处的 `renderRow` prop。        |

```tsx
<CopilotThreadsDrawer>
  <span slot="header">My conversations</span>
</CopilotThreadsDrawer>
```

### CSS parts

使用 `::part()` 为结构性元素设置样式：

- **结构** —— `root`、`header`、`list`、`footer`
- **行** —— `row`、`row-active`（选中的行）、`row-name`、`row-menu`（kebab 菜单）、`row-menu-popover`、`row-archive`、`row-unarchive`、`row-delete`
- **新建会话与分区** —— `new-thread-button`、`section-heading`
- **筛选** —— `filter-toggle`、`filter-indicator`、`filter-active`、`filter-all`、`filters`
- **折叠、移动端与启动器** —— `collapse-toggle`（桌面端）、`close-toggle`（移动端）、`backdrop`（移动端遮罩）、`launcher`、`launcher-cluster`、`launcher-new-thread`
- **分页** —— `load-more`、`fetching-more`、`fetch-more-error`、`fetch-more-retry`
- **状态与升级引导** —— `loading`、`empty`、`error`、`retry-button`、`licensed`、`licensed-cta`、`memories`
- **删除确认对话框** —— `confirm-dialog`、`confirm-cancel`、`confirm-delete`

活跃/全部筛选藏在 `filter-toggle` 漏斗后面，当应用了非默认筛选时，其 `filter-indicator` 圆点会显示。每行的归档/删除操作位于 `row-menu` kebab 菜单及其 `row-menu-popover` 中。当列表在桌面端被折叠（或移动端被关闭）时，浮动组件组 `launcher-cluster` 会承载 `launcher` 开关和 `launcher-new-thread` 按钮。

### CSS 变量令牌

这些令牌会覆盖内置默认值，并回退到宿主主题的变量（因此抽屉会自动跟随浅色/深色模式）：`--cpk-drawer-bg`、`--cpk-drawer-fg`、`--cpk-drawer-border`、`--cpk-drawer-surface`、`--cpk-drawer-surface-fg`、`--cpk-drawer-muted`、`--cpk-drawer-muted-fg`、`--cpk-drawer-accent`、`--cpk-drawer-accent-fg`、`--cpk-drawer-primary`、`--cpk-drawer-primary-fg`、`--cpk-drawer-danger`、`--cpk-drawer-indicator`（默认 `#5b94e4`，即筛选生效圆点的颜色）、`--cpk-drawer-ring`、`--cpk-drawer-radius`、`--cpk-drawer-width`、`--cpk-drawer-font-family`、`--cpk-drawer-font-size`、`--cpk-drawer-line-height`、`--cpk-drawer-launcher-top`、`--cpk-drawer-launcher-left`。

## 用法

### 基础用法

把抽屉和 `CopilotChat` 包裹在同一个 `CopilotChatConfigurationProvider` 中，让它们操作**同一个**聊天配置——正是这份共享配置让选择线程（或“新建会话”）能够驱动聊天。没有共享 Provider 时，抽屉与聊天各自的作用域配置相互独立，无法切换其线程。

```tsx
import {
  CopilotThreadsDrawer,
  CopilotChat,
  CopilotChatConfigurationProvider,
} from "@copilotkit/react-core/v2";

function App() {
  return (
    <CopilotChatConfigurationProvider>
      <div style={{ display: "flex", height: "100%" }}>
        <CopilotThreadsDrawer />
        <CopilotChat />
      </div>
    </CopilotChatConfigurationProvider>
  );
}
```

### 自定义行内容与标签

```tsx
function App() {
  return (
    <CopilotThreadsDrawer
      label="History"
      renderRow={(thread) => <em>{thread.name ?? "New conversation"}</em>}
    />
  );
}
```

## 行为

- **自动接线**：在没有 `onThreadSelect`/`onNewThread` 的情况下，抽屉直接驱动聊天配置——选择即连接并回放；“新建会话”一行会显示欢迎屏。
- **可折叠侧边栏**：在较大的屏幕上，抽屉默认是展开的侧边栏，头部带有折叠开关（侧边栏图形）。折叠后面板会被一个小型浮动组件组取代——一个用于展开的侧边栏开关加一个“新建会话”按钮——并（通过 `--cpk-drawer-reserved-width`）让宿主网格收回该列。设为 `collapsible={false}` 可去掉开关。“新建会话”是头部下方独立的一行；投影 `slot="header"` 内容可在开关旁添加你自己的元素。
- **行操作**：每行的**归档/删除**藏在每行的 kebab（⋮）菜单（`row-menu`）中，而不是始终可见的行内按钮；删除仍会要求确认。
- **乐观更新**：归档/取消归档/重命名/删除都在核心线程存储中乐观执行；若服务器拒绝，删除会回滚。
- **删除活跃线程**会重置为一个新线程；**归档**活跃线程则你仍可继续查看它。已归档线程在“全部”视图中以内联的斜体/弱化样式渲染。
- **筛选**：活跃/全部筛选藏在“最近会话”标题下方的**漏斗**图标气泡弹层中；当应用了非默认筛选时，漏斗上会出现一个小指示圆点。切换筛选会在服务端重新拉取。
- **移动端**：在 768px 以下，抽屉是画布外的模态层。关闭时，它显示同样的浮动组件组（一个打开它的启动器 + 一个“新建会话”按钮）；打开时，它滑入显示，点击遮罩或按 Escape 即可关闭。启动器图标（`launcher-icon` 插槽）和位置（`--cpk-drawer-launcher-*`）均可自定义。
- **Intelligence 访问**：线程功能需要 CopilotKit Intelligence。如果运行时报告 Threads 不可用，抽屉会显示一个锁定视图替代列表。云托管项目在服务器端使用 `CPK_INTELLIGENCE_API_KEY`。持许可证的自托管部署在服务器端使用 `COPILOTKIT_LICENSE_TOKEN`。
