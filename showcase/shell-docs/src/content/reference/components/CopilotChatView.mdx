## 概览

`CopilotChatView` 是一个布局组件，它将可滚动的消息会话记录与聊天输入区、建议胶囊按钮、滚动到底部按钮以及可选的欢迎屏组合在一起。它是聊天界面的视觉核心，被 [`CopilotChat`](/reference/components/CopilotChat)、[`CopilotPopup`](/reference/components/CopilotPopup) 和 [`CopilotSidebar`](/reference/components/CopilotSidebar) 在内部使用。

`CopilotChatView` 的每个视觉部分都以**插槽**的形式暴露出来，因此你无需重写整个布局，即可替换、美化或扩展任意部分。

## 导入

```tsx
import { CopilotChatView } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

<Callout type="info">
  `CopilotChatView` 是 `@copilotkit/react-core/v2` 入口的一个**具名**导出。包根路径 `@copilotkit/react-core` 并不导出它。
</Callout>

## 插槽

`CopilotChatView` 使用 `WithSlots` 模式。每个插槽 prop 接受以下三种取值之一：

| 取值                     | 行为                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| **Component**            | 完全替换默认组件，接收与默认组件相同的 props。                                       |
| **`className` string**   | 通过 `twMerge` 合并进默认组件的类名列表。                                            |
| **Partial props object** | 以附加或覆盖 props 的形式展开传入默认组件。                                          |

传入 `children` 渲染函数后，你可以拿到所有组合好的插槽元素以及数据 props，从而以完全自定义的方式排版布局。

### 插槽属性

<PropertyReference
  name="messageView"
  type="SlotValue<typeof CopilotChatMessageView>"
>
  渲染会话记录的消息列表组件。默认实现会显示助手消息、用户消息和一个正在输入的光标。替换它以添加自定义消息类型或修改消息布局。
</PropertyReference>

<PropertyReference
  name="scrollView"
  type="SlotValue<React.FC<React.HTMLAttributes<HTMLDivElement>>>"
>
  包裹消息列表的可滚动容器。默认实现负责自动滚动行为与滚动位置跟踪。替换它以实现自定义的滚动机制。
</PropertyReference>

<PropertyReference
  name="scrollToBottomButton"
  type="SlotValue<React.FC<React.ButtonHTMLAttributes<HTMLButtonElement>>>"
>
  当用户从会话记录底部向上滚动时出现的按钮。点击它可将视图滚回最新消息。
</PropertyReference>

<PropertyReference name="input" type="SlotValue<typeof CopilotChatInput>">
  消息输入组件。默认实现提供带发送按钮的文本输入区，以及语音转写控件、文件上传和工具菜单。替换它以构建完全自定义的输入体验。
</PropertyReference>

<PropertyReference
  name="inputContainer"
  type="SlotValue<React.FC<React.HTMLAttributes<HTMLDivElement> & { children: React.ReactNode }>>"
>
  包裹输入框与免责声明、位于聊天底部的容器。采用绝对定位，在内容滚动时固定在底部。
</PropertyReference>

<PropertyReference
  name="feather"
  type="SlotValue<React.FC<React.HTMLAttributes<HTMLDivElement>>>"
>
  出现在输入容器上方的装饰性渐变遮罩，在消息区与输入区之间营造平滑的视觉过渡。
</PropertyReference>

<PropertyReference
  name="disclaimer"
  type="SlotValue<React.FC<React.HTMLAttributes<HTMLDivElement>>>"
>
  显示在输入框下方的免责声明文字（例如 “AI 可能会出错，请核实重要信息。”）。可通过替换组件来覆盖或隐藏它。
</PropertyReference>

<PropertyReference
  name="suggestionView"
  type="SlotValue<typeof CopilotChatSuggestionView>"
>
  渲染建议胶囊的组件。替换它以改变建议的展示或动画方式。
</PropertyReference>

## 数据属性

<PropertyReference name="messages" type="Message[]">
  要显示的会话消息数组。通过 `CopilotChat` 使用时由智能体自动管理；单独使用 `CopilotChatView` 时，你必须自行提供消息。
</PropertyReference>

<PropertyReference name="autoScroll" type="boolean" default="true">
  新消息到达时视图是否自动滚动到底部。若想手动控制滚动，可设为 `false`。
</PropertyReference>

<PropertyReference
  name="inputProps"
  type="Partial<Omit<CopilotChatInputProps, 'children'>>"
>
  转发给内部 `CopilotChatInput` 组件的额外 props。用它配置自动聚焦、自定义提交处理函数、语音转写回调或工具菜单，而无需整体替换输入插槽。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean">
  智能体当前是否正在处理。为 `true` 时，输入框显示停止按钮，消息视图在最新的助手消息上显示正在输入的光标。
</PropertyReference>

<PropertyReference name="suggestions" type="Suggestion[]">
  以可点击胶囊形式显示在输入区下方（或上方）的建议对象数组。每条建议包含 `title`、`message` 和可选的 `isLoading` 标志。
</PropertyReference>

<PropertyReference name="suggestionLoadingIndexes" type="ReadonlyArray<number>">
  当前处于加载状态的建议的索引（例如用户刚点击了建议、智能体正在处理）。
</PropertyReference>

<PropertyReference
  name="onSelectSuggestion"
  type="(suggestion: Suggestion, index: number) => void"
>
  用户点击建议胶囊时调用的回调。接收被选中的建议对象及其索引。
</PropertyReference>

<PropertyReference name="welcomeScreen" type='SlotValue<React.FC<WelcomeScreenProps>> | boolean'>
  控制 `messages` 数组为空时显示的欢迎屏。

- `true` —— 显示默认欢迎屏
- `false` —— 禁用欢迎屏
- **`className` string** —— 为默认欢迎屏设置样式
- **Component** —— 完全替换欢迎屏

欢迎屏组件会以 React 元素的形式接收 `input` 和 `suggestionView`，外加一个 `welcomeMessage` 插槽，因此你可以用任意布局组合它们。

</PropertyReference>

## 静态子组件

`CopilotChatView` 将其默认插槽实现以静态属性的形式暴露出来，便于在自定义组合中使用：

- `CopilotChatView.ScrollView` —— 默认的可滚动容器，支持自动滚动
- `CopilotChatView.ScrollToBottomButton` —— 默认的滚动到底部按钮
- `CopilotChatView.Feather` —— 默认的渐变遮罩
- `CopilotChatView.InputContainer` —— 默认的输入容器
- `CopilotChatView.Disclaimer` —— 默认的免责声明文字
- `CopilotChatView.WelcomeMessage` —— 默认的欢迎消息
- `CopilotChatView.WelcomeScreen` —— 默认的欢迎屏布局

## 用法

### 独立使用

```tsx
function CustomChat({ messages, isRunning }) {
  return (
    <CopilotChatView
      messages={messages}
      isRunning={isRunning}
      autoScroll={true}
    />
  );
}
```

### 用自定义组件替换插槽

```tsx
function CustomDisclaimer(props) {
  return (
    <div {...props}>Powered by CopilotKit. Responses may contain errors.</div>
  );
}

function Chat({ messages, isRunning }) {
  return (
    <CopilotChatView
      messages={messages}
      isRunning={isRunning}
      disclaimer={CustomDisclaimer}
    />
  );
}
```

### 用 className 设置插槽样式

```tsx
function Chat({ messages, isRunning }) {
  return (
    <CopilotChatView
      messages={messages}
      isRunning={isRunning}
      scrollView="bg-gray-50"
      inputContainer="border-t border-gray-200"
    />
  );
}
```

### 使用 children 渲染函数自定义布局

```tsx
function Chat({ messages, isRunning }) {
  return (
    <CopilotChatView messages={messages} isRunning={isRunning}>
      {({
        scrollView,
        input,
        inputContainer,
        feather,
        disclaimer,
        suggestionView,
      }) => (
        <div className="flex flex-col h-full">
          <div className="flex-1 overflow-hidden">{scrollView}</div>
          {feather}
          {suggestionView}
          {inputContainer}
        </div>
      )}
    </CopilotChatView>
  );
}
```

## 行为

- **自动滚动**：当 `autoScroll` 为 `true` 时，视图采用贴底策略，让最新消息始终可见。当用户向上滚动时会出现滚动到底部按钮。
- **欢迎屏**：当 `messages` 为空且 `welcomeScreen` 不为 `false` 时，会用欢迎屏替代会话记录渲染。欢迎屏会收到 `input` 与 `suggestionView` 元素，便于将它们放置在欢迎布局内。
- **输入容器定位**：输入容器绝对定位在聊天底部，滚动区域会通过内边距避免内容重叠。
- **尺寸变化处理**：滚动视图会监测输入容器高度变化以保持内边距同步，并在尺寸变化过渡期间隐藏滚动到底部按钮。
