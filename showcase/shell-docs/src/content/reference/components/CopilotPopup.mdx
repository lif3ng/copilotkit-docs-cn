## 概览

`CopilotPopup` 渲染一个带切换按钮的浮动聊天弹窗。它包裹了 [`CopilotChat`](/reference/components/CopilotChat)，并提供弹窗专属的布局、尺寸与打开/关闭行为。弹窗包含一个带标题和关闭按钮的头部，点击弹窗外部即可将其关闭。

本组件的侧边栏变体请参见 [`CopilotSidebar`](/reference/components/CopilotSidebar)。

## 导入

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## 属性

### 自身属性

<PropertyReference name="header" type="SlotValue<typeof CopilotModalHeader>">
  弹窗头部的插槽覆盖。接受替换组件、合并进默认样式的 `className` 字符串或部分 props 对象。默认头部显示一个标题和一个关闭按钮。
</PropertyReference>

<PropertyReference name="defaultOpen" type="boolean" default="true">
  组件首次挂载时弹窗是否打开。此后弹窗自行持有该状态。若要始终保持控制，请改用 `open`。
</PropertyReference>

<PropertyReference name="open" type="boolean">
  受控的打开状态。提供该属性后，弹窗是否打开由你的组件决定：弹窗只渲染该值，绝不会自行更改。请与 `onOpenChange` 搭配使用。同时传入 `open` 和 `defaultOpen` 时，`open` 优先。参见 [打开、关闭与反馈](/prebuilt-components/chat-controls)。
</PropertyReference>

<PropertyReference name="onOpenChange" type="(open: boolean) => void">
  每当弹窗请求打开或关闭时（切换按钮、点击外部、Escape 键或移动端上的线程抽屉），都会以目标状态调用该回调。它报告的是一次请求而非已发生的变化：在受控模式下，在你更新 `open` 之前不会有任何变化。
</PropertyReference>

<PropertyReference name="width" type="number | string">
  弹窗面板的宽度。接受数字（像素）或 CSS 字符串（例如 `"400px"`、`"30vw"`）。
</PropertyReference>

<PropertyReference name="height" type="number | string">
  弹窗面板的高度。接受数字（像素）或 CSS 字符串（例如 `"600px"`、`"80vh"`）。
</PropertyReference>

<PropertyReference name="clickOutsideToClose" type="boolean" default="true">
  点击弹窗面板外部时是否关闭弹窗。
</PropertyReference>

### 继承自 CopilotChat 的属性

`CopilotPopup` 接受 [`CopilotChatProps`](/reference/components/CopilotChat) 的**全部** props，**唯一例外**是 `chatView`——它在内部被设为 `CopilotPopupView`。其中包括：

<PropertyReference name="agentId" type="string">
  要使用的智能体 ID。必须与 `CopilotKit` 中配置的某个智能体匹配。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  对聊天中渲染的所有文本字符串的部分标签覆盖。
</PropertyReference>

<PropertyReference name="autoScroll" type="boolean" default="true">
  新消息到达时聊天是否自动滚动到底部。
</PropertyReference>

<PropertyReference
  name="inputProps"
  type="Partial<Omit<CopilotChatInputProps, 'children'>>"
>
  转发给内部 `CopilotChatInput` 组件的额外 props。
</PropertyReference>

<PropertyReference
  name="welcomeScreen"
  type="SlotValue<React.FC<WelcomeScreenProps>> | boolean"
>
  控制没有消息时显示的欢迎屏。
</PropertyReference>

所有 `CopilotChatView` 插槽 props（`messageView`、`input`、`scrollView`、`inputContainer`、`feather`、`disclaimer`、`suggestionView`）也都被接受并透传。

## 插槽系统

所有插槽 props 都遵循 CopilotKit v2 组件通用的覆盖模式。每个插槽接受以下三种取值之一：

| 取值                     | 行为                                                                                |
| ------------------------ | ----------------------------------------------------------------------------------- |
| **Component**            | 完全替换默认组件，接收与默认组件相同的 props。                                       |
| **`className` string**   | 通过 `twMerge` 合并进默认组件的类名列表。                                            |
| **Partial props object** | 以附加或覆盖 props 的形式展开传入默认组件。                                          |

## 用法

### 基础用法

```tsx
function App() {
  return (
    <CopilotPopup
      agentId="my-agent"
      labels={{ modalHeaderTitle: "Assistant" }}
    />
  );
}
```

### 自定义尺寸与默认打开

```tsx
function App() {
  return (
    <CopilotPopup
      agentId="my-agent"
      defaultOpen={true}
      width={450}
      height="80vh"
      clickOutsideToClose={false}
    />
  );
}
```

### 自定义头部

```tsx
function App() {
  return <CopilotPopup agentId="my-agent" header="bg-blue-600 text-white" />;
}
```

## 行为

- **切换按钮**：渲染一个浮动切换按钮（通常位于右下角），用于打开和关闭弹窗。该按钮在内部使用 `CopilotChatToggleButton`。
- **弹层状态**：打开/关闭状态通过聊天配置上下文管理。`defaultOpen` prop 设置初始状态；此后的状态变化来自用户交互（切换按钮、关闭按钮、点击外部）。传入 `open` 和 `onOpenChange` 可自行持有状态，并从你自己的 UI 打开或关闭弹窗。
- **点击外部**：当 `clickOutsideToClose` 为 `true`（默认值）时，点击弹窗面板外的任意位置都会关闭弹窗。
- **布局**：弹窗在内部使用 `CopilotPopupView`，它提供弹窗专属的欢迎屏布局，欢迎消息垂直居中，建议紧挨输入框上方。
- **智能体连接**：所有智能体接线（消息、运行状态、建议）都由父级 `CopilotChat` 逻辑处理。
