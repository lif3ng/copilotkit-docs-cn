## 概览

`CopilotChatAssistantMessage` 用于展示助手消息，支持 Markdown、工具调用渲染与操作工具栏。Markdown 渲染器使用 `remark-gfm`、`remark-math`、通过 `rehype-pretty-code` 实现的语法高亮，以及面向数学表达式的 KaTeX 支持。工具栏提供复制、评分（点赞/点踩）、朗读与重新生成按钮，其本地化提示文本来自 `CopilotChatConfigurationProvider`。

## 导入

```tsx
import { CopilotChatAssistantMessage } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## Props

<PropertyReference name="message" type="AssistantMessage" required>
  要渲染的助手消息对象。包含消息的 `content`、`id`、`role` 以及所有关联的工具调用。
</PropertyReference>

<PropertyReference name="messages" type="Message[]">
  完整的会话消息数组。透传给 `toolCallsView` 插槽，用于具备上下文感知的工具调用渲染。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean" default="false">
  智能体当前是否正在执行。插槽组件可用它在流式输出期间调整自身行为。
</PropertyReference>

<PropertyReference name="isLatest" type="boolean">
  这是否是聊天渲染的最后一条消息。当 `isRunning` 为 `true` 时，最新消息会隐藏其工具栏。`CopilotChatMessageView` 会传入该属性，因为当 `transformMessages` 丢弃、替换或重排消息时，其实际渲染的列表可能与 `messages` 不同。省略时，组件会比较 `message.id` 与 `messages` 的最后一项。
</PropertyReference>

<PropertyReference name="onThumbsUp" type="(message: AssistantMessage) => void">
  用户点击点赞按钮时调用的回调；在记录评分期间，仅当点击产生了评分时才会触发。未提供时，工具栏会隐藏点赞按钮，除非设置了 `thumbsUpButton`，或者（在 `CopilotChatMessageView` 内且处于 `CopilotChatConfigurationProvider` 之下时）Automatic Learning 捕获已启动（参见[回复评分](#回复评分)）。当此组件被用作 `CopilotChatMessageView` 的助手插槽时，回调可以收到一个仅用于回调的 `rawEvent` 值，对应实时直接的 AG-UI `TEXT_MESSAGE_START`。直接使用此组件时，收到的是规范化的助手消息。
</PropertyReference>

<PropertyReference
  name="onThumbsDown"
  type="(message: AssistantMessage) => void"
>
  用户点击点踩按钮时调用的回调；在记录评分期间，仅当点击产生了评分时才会触发。未提供时，工具栏会隐藏点踩按钮，除非设置了 `thumbsDownButton`，或者（在 `CopilotChatMessageView` 内且处于 `CopilotChatConfigurationProvider` 之下时）Automatic Learning 捕获已启动。仅当此组件通过 `CopilotChatMessageView` 这一父级路径使用时，才适用其仅用于回调的 `rawEvent` 行为。
</PropertyReference>

<PropertyReference
  name="onReadAloud"
  type="(message: AssistantMessage) => void"
>
  用户点击朗读按钮时调用的回调。未提供时，工具栏会隐藏朗读按钮。
</PropertyReference>

<PropertyReference
  name="onRegenerate"
  type="(message: AssistantMessage) => void"
>
  用户点击重新生成按钮时调用的回调。未提供时，工具栏会隐藏重新生成按钮。
</PropertyReference>

<PropertyReference name="additionalToolbarItems" type="React.ReactNode">
  追加到工具栏上的额外 React 元素，与默认操作按钮并列。
</PropertyReference>

<PropertyReference name="toolbarVisible" type="boolean">
  控制操作工具栏是否可见。设为 `false` 时，无论提供了哪些回调 props，工具栏都会完全隐藏。
</PropertyReference>

## 插槽

所有插槽 props 都遵循 CopilotKit 插槽系统：每个插槽都接受一个替换用的 React 组件、一个合并进默认组件 class 的 `className` 字符串，或一个用于扩展默认组件的局部 props 对象。

<PropertyReference name="markdownRenderer" type="SlotProp<typeof CopilotChatAssistantMessage.MarkdownRenderer>">
  Markdown 渲染引擎的插槽。默认为 `CopilotChatAssistantMessage.MarkdownRenderer`，支持 GFM 表格、通过 KaTeX 呈现的数学表达式，以及通过 `rehype-pretty-code` 实现语法高亮的代码块。

**作为替换组件**：

```tsx
<CopilotChatAssistantMessage
  message={msg}
  markdownRenderer={({ content }) => (
    <div dangerouslySetInnerHTML={{ __html: content }} />
  )}
/>
```

</PropertyReference>

<PropertyReference name="toolbar" type="SlotProp<typeof CopilotChatAssistantMessage.Toolbar>">
  操作工具栏容器的插槽。默认为 `CopilotChatAssistantMessage.Toolbar`，它在消息内容下方渲染一行水平排列的操作按钮。

**作为 className**：

```tsx
<CopilotChatAssistantMessage message={msg} toolbar="border-t pt-2 mt-2" />
```

</PropertyReference>

<PropertyReference
  name="copyButton"
  type="SlotProp<typeof CopilotChatAssistantMessage.CopyButton>"
>
  工具栏中复制到剪贴板按钮的插槽。默认为 `CopilotChatAssistantMessage.CopyButton`。提示文本标签来自 `CopilotChatLabels.assistantMessageToolbarCopyMessageLabel`。
</PropertyReference>

<PropertyReference
  name="thumbsUpButton"
  type="SlotProp<typeof CopilotChatAssistantMessage.ThumbsUpButton>"
>
  点赞评分按钮的插槽。默认为 `CopilotChatAssistantMessage.ThumbsUpButton`。当设置了此插槽或 `onThumbsUp` 时渲染，或者在 `CopilotChatMessageView` 内由 Automatic Learning 捕获该聊天时渲染。在记录评分期间，替换组件会收到 `aria-pressed` 与 `data-copilotkit-rating`，在所选拇指按钮上除 `onClick` 外还会收到 `aria-haspopup`、`aria-expanded`、`onPointerEnter`、`onPointerLeave`、`onFocus`、`onBlur` 与 `onKeyDown`。请把它收到的 props 展开到自己的按钮上，并把点击事件传给 `onClick`，这样键盘评分时焦点才能移入评论文本。提示文本标签来自 `CopilotChatLabels.assistantMessageToolbarThumbsUpLabel`。
</PropertyReference>

<PropertyReference
  name="thumbsDownButton"
  type="SlotProp<typeof CopilotChatAssistantMessage.ThumbsDownButton>"
>
  点踩评分按钮的插槽。默认为 `CopilotChatAssistantMessage.ThumbsDownButton`。当设置了此插槽或 `onThumbsDown` 时渲染，或者在 `CopilotChatMessageView` 内由 Automatic Learning 捕获该聊天时渲染。替换组件收到的 props 与 `thumbsUpButton` 替换组件相同。提示文本标签来自 `CopilotChatLabels.assistantMessageToolbarThumbsDownLabel`。
</PropertyReference>

<PropertyReference
  name="readAloudButton"
  type="SlotProp<typeof CopilotChatAssistantMessage.ReadAloudButton>"
>
  朗读按钮的插槽。默认为 `CopilotChatAssistantMessage.ReadAloudButton`。仅在提供 `onReadAloud` 时渲染。提示文本标签来自 `CopilotChatLabels.assistantMessageToolbarReadAloudLabel`。
</PropertyReference>

<PropertyReference
  name="regenerateButton"
  type="SlotProp<typeof CopilotChatAssistantMessage.RegenerateButton>"
>
  重新生成按钮的插槽。默认为 `CopilotChatAssistantMessage.RegenerateButton`。仅在提供 `onRegenerate` 时渲染。提示文本标签来自 `CopilotChatLabels.assistantMessageToolbarRegenerateLabel`。
</PropertyReference>

<PropertyReference
  name="toolCallsView"
  type="SlotProp<typeof CopilotChatToolCallsView>"
>
  渲染助手消息内嵌工具调用的插槽。默认为 [`CopilotChatToolCallsView`](#copilotchattoolcallsview)，它会用最匹配的已注册工具渲染器渲染每个调用，并将连续发起的调用分组。
</PropertyReference>

<PropertyReference
  name="feedbackComment"
  type="SlotProp<typeof CopilotChatAssistantMessage.FeedbackComment>"
>
  [回复评分](#回复评分)评论输入框的插槽，显示在所选拇指按钮旁的弹层中。默认为 `CopilotChatAssistantMessage.FeedbackComment`。替换组件会收到 `value`、`savedComment`、`inputRef`、`onChange`、`onSubmit`、`onEditingChange` 与 `onLeave`。它渲染在 `children` 之后，因此 `children` 布局无需自行放置它。
</PropertyReference>

## CopilotChatToolCallsView

一个配套组件，用于渲染助手消息中包含的工具调用。每个调用都由最匹配的已注册工具渲染器绘制（通过 `useFrontendTool`、`useHumanInTheLoop`、`useRenderTool` 或 provider 上的 `renderToolCalls` 注册）。

当渲染器选择启用分组时，智能体连续发起的调用会折叠成一个组，由 `group` 插槽绘制。`useDefaultRenderTool()` 的内置卡片即如此；自定义渲染器用 `group: true` 启用。任何其他调用始终单独显示。在 [`CopilotChatMessageView`](/reference/components/CopilotChatMessageView) 内，分组会跨越消息并遵循视图的 `toolCallDisplay`；单独使用时，此组件对 `message` 的调用进行分组。

### 导入

```tsx
import { CopilotChatToolCallsView } from "@copilotkit/react-core/v2";
```

### Props

<PropertyReference name="message" type="AssistantMessage" required>
  要渲染其工具调用的助手消息。
</PropertyReference>

<PropertyReference name="messages" type="Message[]">
  完整的会话消息数组。为需要引用其他消息的工具调用渲染器提供上下文（例如查找对应的工具结果消息）。
</PropertyReference>

<PropertyReference
  name="display"
  type='"grouped" | "line" | "stacked" | "turn" | "separate"'
>
  调用的展示方式。在消息视图内默认取视图的 [`toolCallDisplay`](/reference/components/CopilotChatMessageView#toolcalldisplay)；单独使用时默认为 `"grouped"`。`"separate"` 会将每个调用单独渲染，不分组。
</PropertyReference>

### 插槽

<PropertyReference name="group" type="SlotProp<typeof CopilotChatToolCallGroup>">
  在 `"grouped"`、`"line"` 与 `"stacked"` 展示方式下绘制一组连续发起的调用。`"turn"` 展示方式会把调用绘制为回复内的行，不使用此插槽。默认为 [`CopilotChatToolCallGroup`](/reference/components/CopilotChatToolCallGroup)。与所有插槽一样，它接受一个 className、传给默认组件的 props，或一个替换组件——后者会收到该组的 `calls` 与一个 `renderCall` 函数。

**通过 `CopilotChat`**：

```tsx
<CopilotChat
  messageView={{
    assistantMessage: {
      toolCallsView: { group: "rounded-2xl shadow-sm" },
    },
  }}
/>
```

**作为默认分组的 props**：

```tsx
<CopilotChatToolCallsView
  message={message}
  messages={messages}
  group={{ appearance: "line" }}
/>
```

**作为替换组件**：

```tsx
<CopilotChatToolCallsView
  message={message}
  messages={messages}
  group={({ calls, renderCall }) => (
    <details>
      <summary>Ran {calls.length} tools</summary>
      {calls.map((call) => (
        <div key={call.toolCall.id}>{renderCall(call)}</div>
      ))}
    </details>
  )}
/>
```

</PropertyReference>

## 用法

### 基本助手消息

```tsx
function AssistantBubble({ message }) {
  return (
    <CopilotChatAssistantMessage
      message={message}
      onThumbsUp={(msg) => console.log("Thumbs up:", msg.id)}
      onThumbsDown={(msg) => console.log("Thumbs down:", msg.id)}
    />
  );
}
```

### 自定义工具栏

```tsx
function CustomToolbarMessage({ message }) {
  return (
    <CopilotChatAssistantMessage
      message={message}
      onRegenerate={(msg) => handleRegenerate(msg)}
      onReadAloud={(msg) => speak(msg.content)}
      additionalToolbarItems={
        <button onClick={() => shareMessage(message)}>Share</button>
      }
      toolbar="border-t border-gray-200 pt-2"
    />
  );
}
```

### 隐藏工具栏

```tsx
function MinimalMessage({ message }) {
  return (
    <CopilotChatAssistantMessage message={message} toolbarVisible={false} />
  );
}
```

### 自定义 Markdown 渲染器

```tsx
function CustomRendererMessage({ message }) {
  return (
    <CopilotChatAssistantMessage
      message={message}
      markdownRenderer={({ content }) => (
        <ReactMarkdown>{content}</ReactMarkdown>
      )}
    />
  );
}
```

### 独立的工具调用视图

```tsx
function ToolCallsList({ message, allMessages }) {
  return (
    <div className="tool-calls">
      <CopilotChatToolCallsView message={message} messages={allMessages} />
    </div>
  );
}
```

## 行为

- **Markdown 支持**：默认 Markdown 渲染器支持 GitHub Flavored Markdown（表格、删除线、任务列表）、用 KaTeX 渲染的数学表达式，以及通过 `rehype-pretty-code` 实现语法高亮的代码块。
- **工具栏可见性**：默认情况下工具栏在悬停或聚焦时出现，但当 `isRunning` 为 `true` 时，最新消息除外。只有提供了对应的回调 prop（`onThumbsUp`、`onThumbsDown`、`onReadAloud`、`onRegenerate`）时，各按钮才会渲染。当设置了对应插槽时，或在 `CopilotChatMessageView` 内处于 `CopilotChatConfigurationProvider` 之下且 Automatic Learning 捕获已启动时，两个拇指按钮也会渲染。工具栏显示时，复制按钮始终可见。
- **本地化标签**：所有工具栏按钮的提示文本都来自最近的 `CopilotChatConfigurationProvider`。完整的标签键列表见 [`useCopilotChatConfiguration`](/reference/hooks/useCopilotChatConfiguration)。
- **工具调用渲染**：助手消息内嵌的工具调用由 `toolCallsView` 插槽渲染。每个工具调用通过 `useRenderToolCall` hook 解析，该 hook 按工具名称查找已注册的渲染器。
- **插槽系统**：每个插槽 prop 接受三种形式——替换组件、合并进默认组件的 className 字符串，或扩展默认组件 props 的局部 props 对象。

## 回复评分

当此组件渲染在 `CopilotChatMessageView` 内、处于 `CopilotChatConfigurationProvider` 之下且 Automatic Learning 捕获已启动时，两个拇指按钮会记录评分，在捕获重连或停止期间也同样如此：

- 点击即为回复评分，并在拇指按钮旁打开一个可填写可选评论的输入框。
- 指向或用键盘聚焦所选拇指按钮会再次打开其评论。在触屏上，轻点所选拇指按钮则会移除评分。
- 再次点击所选拇指按钮会移除评分。
- 评分会在页面打开期间显示，并作为 `message.feedback` 事件发送到当前活动的 Trajectory。与任何 Trajectory 事件一样，在没有 Trajectory 捕获时给出的评分不会被发送。

`onThumbsUp` 与 `onThumbsDown` 在给出评分时运行，移除评分时不运行。评论输入框就是 `feedbackComment` 插槽，默认为 `CopilotChatAssistantMessage.FeedbackComment`；其占位符与发送按钮使用 `assistantMessageFeedbackCommentPlaceholder` 与 `assistantMessageFeedbackCommentSubmitLabel` 标签。事件详情以及评分如何到达 Intelligence，参见[收集回复评分](/intelligence/capture-interactions#collect-reply-ratings)。
