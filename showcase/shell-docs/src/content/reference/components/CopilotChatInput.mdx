## 概览

`CopilotChatInput` 是聊天交互的主文本输入框与控制面板。它提供一个可自动增高、最大行数可配置（默认 5 行）的多行文本域，以及发送消息、语音转写与文件附件的操作按钮，还有一个面向声明式命令入口的可选工具菜单。

该组件有三种运行模式：`"input"`（默认文本输入）、`"transcribe"`（用录音组件替换文本域）和 `"processing"`（表示后台处理正在进行中）。当文本跨越多行时，布局会把文本域堆叠到控制行上方。

## 导入

```tsx
import { CopilotChatInput } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";
```

## Props

<PropertyReference
  name="mode"
  type='"input" | "transcribe" | "processing"'
  default='"input"'
>
  输入组件当前的运行模式。- `"input"`——带文本域和发送按钮的标准文本输入模式。- `"transcribe"`——用录音组件替换文本域以进行语音输入。- `"processing"`——表示后台处理正在进行中。
</PropertyReference>

<PropertyReference name="value" type="string">
  输入框当前的文本值。与 `onChange` 配合使用可实现受控模式。
</PropertyReference>

<PropertyReference name="onChange" type="(value: string) => void">
  输入文本变化时调用的回调。与 `value` 配合使用可实现受控模式。
</PropertyReference>

<PropertyReference name="autoFocus" type="boolean">
  为 `true` 时，文本域在挂载时自动获得焦点。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean" default="false">
  智能体当前是否正在执行。为 `true` 时，发送按钮可能被替换为停止按钮，输入框也可能显示处理中状态。
</PropertyReference>

<PropertyReference name="onSubmitMessage" type="(value: string) => void">
  用户提交消息时（按 Enter 或点击发送按钮）调用的回调。接收当前文本值。
</PropertyReference>

<PropertyReference name="onStop" type="() => void">
  在智能体执行期间用户点击停止按钮时调用的回调。
</PropertyReference>

<PropertyReference name="onStartTranscribe" type="() => void">
  用户发起语音转写时调用的回调。通常会将组件切换到 `"transcribe"` 模式。
</PropertyReference>

<PropertyReference name="onCancelTranscribe" type="() => void">
  用户取消进行中的语音转写时调用的回调。
</PropertyReference>

<PropertyReference name="onFinishTranscribe" type="() => void">
  用户完成语音转写时（仅文本结果）调用的回调。
</PropertyReference>

<PropertyReference
  name="onFinishTranscribeWithAudio"
  type="(audioBlob: Blob) => Promise<void>"
>
  用户带着录音完成语音转写时调用的回调。以 `Blob` 形式接收录制的音频。当你需要把原始音频发送到服务端做语音转文字处理时，使用此回调。
</PropertyReference>

<PropertyReference name="onAddFile" type="() => void">
  用户点击文件附件按钮时调用的回调。未提供时，文件附件按钮会隐藏。
</PropertyReference>

<PropertyReference name="toolsMenu" type="(ToolsMenuItem | '-')[]">
  工具菜单的声明式配置。每个条目要么是一个 `ToolsMenuItem` 对象，要么是分隔符字符串 `"-"`。条目结构见 [ToolsMenuItem](#toolsmenuitem)。未提供时，工具菜单按钮会隐藏。
</PropertyReference>

<PropertyReference
  name="children"
  type="(props: { isMultiline: boolean }) => React.ReactElement"
>
  可选的 render-prop 函数，接收布局状态。当文本域内容跨越多行时 `isMultiline` 标志为 `true`，从而触发堆叠布局（文本域位于控制行上方）。
</PropertyReference>

## 插槽

所有插槽 props 都遵循 CopilotKit 插槽系统：每个插槽都接受一个替换用的 React 组件、一个合并进默认组件 class 的 `className` 字符串，或一个用于扩展默认组件的局部 props 对象。

<PropertyReference name="textArea" type="SlotProp">
  文本输入区的插槽。默认为可自动增高的文本域，最多扩展到 5 行（可通过 `maxRows` 配置）。

**作为 className**：

```tsx
<CopilotChatInput textArea="font-mono text-sm" />
```

</PropertyReference>

<PropertyReference name="sendButton" type="SlotProp">
  发送/提交按钮的插槽。默认为提交当前消息的箭头图标按钮。

**作为替换组件**：

```tsx
<CopilotChatInput
  sendButton={({ onClick }) => (
    <button
      onClick={onClick}
      className="bg-blue-500 text-white px-3 py-1 rounded"
    >
      Send
    </button>
  )}
/>
```

</PropertyReference>

<PropertyReference name="startTranscribeButton" type="SlotProp">
  发起语音转写的按钮插槽。仅在提供 `onStartTranscribe` 时渲染。
</PropertyReference>

<PropertyReference name="cancelTranscribeButton" type="SlotProp">
  取消进行中语音转写的按钮插槽。仅在 `"transcribe"` 模式下渲染。
</PropertyReference>

<PropertyReference name="finishTranscribeButton" type="SlotProp">
  完成语音转写的按钮插槽。仅在 `"transcribe"` 模式下渲染。
</PropertyReference>

<PropertyReference name="addMenuButton" type="SlotProp">
  文件附件按钮的插槽。仅在提供 `onAddFile` 时渲染。
</PropertyReference>

<PropertyReference name="audioRecorder" type="SlotProp">
  `"transcribe"` 模式下显示的录音组件插槽。默认为 [`CopilotChatAudioRecorder`](#copilotchataudiorecorder)。
</PropertyReference>

## ToolsMenuItem

`ToolsMenuItem` 类型定义工具菜单中的条目。条目可以直接触发操作，也可以包含嵌套的子菜单。

```ts
type ToolsMenuItem = { label: string } & (
  | { action: () => void }
  | { items: (ToolsMenuItem | "-")[] }
);
```

<PropertyReference name="label" type="string" required>
  菜单条目的显示文本。
</PropertyReference>

<PropertyReference name="action" type="() => void">
  选中该条目时调用的回调。与 `items` 互斥。
</PropertyReference>

<PropertyReference name="items" type="(ToolsMenuItem | '-')[]">
  嵌套的子菜单条目。每个条目要么是另一个 `ToolsMenuItem`，要么是分隔符字符串 `"-"`。与 `action` 互斥。
</PropertyReference>

### 分隔符

将字符串 `"-"` 作为数组条目使用，即可在菜单条目之间渲染一个视觉分隔线：

```tsx
toolsMenu={[
  { label: "Search", action: () => search() },
  "-",
  { label: "Settings", action: () => openSettings() },
]}
```

### 嵌套子菜单

带 `items` 数组的菜单条目会渲染为可展开的子菜单：

```tsx
toolsMenu={[
  {
    label: "Export",
    items: [
      { label: "As PDF", action: () => exportPDF() },
      { label: "As CSV", action: () => exportCSV() },
      "-",
      { label: "Print", action: () => printDoc() },
    ],
  },
]}
```

### 命令式 API

该组件通过 React `ref` 暴露以下命令式方法：

<PropertyReference name="state" type="string">
  录音器当前的状态（如 `"idle"`、`"recording"`、`"stopped"`）。
</PropertyReference>

<PropertyReference name="start" type="() => void">
  开始录音并启动波形可视化。
</PropertyReference>

<PropertyReference name="stop" type="() => void">
  停止当前录音会话。
</PropertyReference>

<PropertyReference name="dispose" type="() => void">
  清理录音器使用的所有资源（媒体流、音频上下文等）。
</PropertyReference>

### 用法

```tsx
function CustomRecorder() {
  const recorderRef = useRef(null);

  return (
    <div>
      <CopilotChatAudioRecorder ref={recorderRef} />
      <button onClick={() => recorderRef.current?.start()}>Record</button>
      <button onClick={() => recorderRef.current?.stop()}>Stop</button>
    </div>
  );
}
```

## 用法

### 基本聊天输入框

```tsx
function ChatInput() {
  const [value, setValue] = useState("");

  return (
    <CopilotChatInput
      value={value}
      onChange={setValue}
      onSubmitMessage={(text) => {
        sendMessage(text);
        setValue("");
      }}
      autoFocus
    />
  );
}
```

### 带语音转写

```tsx
function VoiceInput() {
  const [mode, setMode] = useState<"input" | "transcribe">("input");
  const [value, setValue] = useState("");

  return (
    <CopilotChatInput
      mode={mode}
      value={value}
      onChange={setValue}
      onSubmitMessage={(text) => sendMessage(text)}
      onStartTranscribe={() => setMode("transcribe")}
      onCancelTranscribe={() => setMode("input")}
      onFinishTranscribeWithAudio={async (blob) => {
        const text = await transcribeAudio(blob);
        setValue(text);
        setMode("input");
      }}
    />
  );
}
```

### 带工具菜单

```tsx
function InputWithTools() {
  return (
    <CopilotChatInput
      onSubmitMessage={(text) => sendMessage(text)}
      toolsMenu={[
        { label: "Search the web", action: () => triggerSearch() },
        { label: "Analyze data", action: () => triggerAnalysis() },
        "-",
        {
          label: "Export",
          items: [
            { label: "As PDF", action: () => exportPDF() },
            { label: "As Markdown", action: () => exportMarkdown() },
          ],
        },
      ]}
    />
  );
}
```

### 执行期间带停止按钮

```tsx
function ChatInputWithAgent() {
  const { agent } = useAgent();
  const { copilotkit } = useCopilotKit();

  return (
    <CopilotChatInput
      isRunning={agent.isRunning}
      onSubmitMessage={(text) => {
        agent.addMessage({
          role: "user",
          content: text,
          id: crypto.randomUUID(),
        });
        // Drive the run through CopilotKit so registered frontend tools
        // execute and the run is tracked for stop.
        copilotkit.runAgent({ agent });
      }}
      onStop={() => copilotkit.stopAgent({ agent })}
      autoFocus
    />
  );
}
```

### 用 Children Render Prop 自定义布局

```tsx
function AdaptiveInput() {
  return (
    <CopilotChatInput onSubmitMessage={(text) => sendMessage(text)}>
      {({ isMultiline }) => (

            isMultiline ? "border-2 border-blue-300 rounded-xl p-2" : ""
          }
        >
          {isMultiline && (
            <div className="text-xs text-gray-400 mb-1">Multi-line mode</div>
          )}
        </div>
      )}
    </CopilotChatInput>
  );
}
```

## 行为

- **自动增高文本域**：默认文本域随用户输入自动增高，最多 5 行。达到上限后，文本域变为可滚动。
- **布局堆叠**：当输入文本跨越多行时，布局从行内（文本域与按钮并排）切换为堆叠（文本域位于包含操作按钮的控制行上方）。
- **模式切换**：将 `mode` 设为 `"transcribe"` 会用 `audioRecorder` 插槽组件替换文本域。转写控制按钮（`cancelTranscribeButton`、`finishTranscribeButton`）会替换标准发送按钮。
- **受控与非受控**：组件同时支持受控模式（通过 `value` 与 `onChange`）和非受控模式（内部状态管理）。
- **工具菜单**：`toolsMenu` prop 启用一个声明式菜单，支持平铺条目、分隔符（`"-"`）与嵌套子菜单。仅在提供 `toolsMenu` 时才渲染菜单按钮。
- **插槽系统**：每个插槽 prop 接受三种形式——替换组件、合并进默认组件的 className 字符串，或扩展默认组件 props 的局部 props 对象。
