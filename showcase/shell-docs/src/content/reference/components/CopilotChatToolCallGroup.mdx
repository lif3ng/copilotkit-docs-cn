## 概览

`CopilotChatToolCallGroup` 把智能体连续发起的工具调用绘制成一条折叠的摘要，而不是每个调用一张卡片。当某个调用正在运行时，摘要会点名它（"Running read_file src/app.ts"）。所有调用完成后，它显示"Used 3 tools"，附上所用工具及失败数量，展开后可查看各调用。

它是 [`CopilotChatToolCallsView`](/reference/components/CopilotChatAssistantMessage#copilotchattoolcallsview) 的默认 `group` 插槽。[CopilotChatMessageView](/reference/components/CopilotChatMessageView) 依据 `toolCallDisplay` 选择其外观：`"grouped"` 绘制卡片，`"line"` 绘制一行文本，`"stacked"` 绘制堆栈。

只有由选择加入分组的渲染器绘制的调用才会进入分组。CopilotKit 的内置卡片（来自 [`useDefaultRenderTool()`](/reference/hooks/useDefaultRenderTool)）即属此类，它在卡片、行外观与展开的堆栈中把自己绘制成一行紧凑内容：状态、工具名与主要参数，展开后可查看参数与结果。自定义渲染器用 `group: true` 加入分组，并在分组内绘制它想呈现的内容：

```tsx
useDefaultRenderTool({ render: MyToolRow, group: true });
// or, for one tool
useRenderTool({
  name: "run_command",
  parameters,
  render: CommandRow,
  group: true,
});
```

该分组是 `"grouped"`、`"line"` 与 `"stacked"` 展示方式下的 `group` 插槽。`"turn"` 展示方式把调用绘制为回复内的行，不使用它。

## 导入

```tsx
import { CopilotChatToolCallGroup } from "@copilotkit/react-core/v2";
import type {
  CopilotChatToolCallGroupProps,
  ToolCallEntry,
} from "@copilotkit/react-core/v2";
```

## Props

<PropertyReference name="calls" type="ToolCallEntry[]" required>
  组内的调用，按顺序排列。每个条目持有 `toolCall`，以及在调用完成后携带其结果的 `toolMessage`。工具消息带 `error` 的调用计为失败。
</PropertyReference>

<PropertyReference
  name="renderCall"
  type="(call: ToolCallEntry) => React.ReactNode"
  required
>
  通过已注册的工具渲染器渲染单个调用，与聊天单独渲染一个调用的方式相同。
</PropertyReference>

<PropertyReference name="appearance" type='"card" | "line" | "stack"' default='"card"'>
  - `"card"`：一张卡片，带摘要表头，每个调用一行。
  - `"line"`：一行安静的文本，展开后是行列表。
  - `"stack"`：最新的调用叠在先前调用堆栈的顶部。展开会把堆栈摊开成每个调用一张紧凑卡片。

单个调用的组看起来和多调用的组一样：卡片先显示"Running run_command"再显示"Used 1 tool"，堆栈则只显示顶部的卡片，后面还没有其他内容。与更大的组一样，两者在展开前都保持收起。在行外观下，单个已完成的调用直接绘制为它自己那一行。

</PropertyReference>

<PropertyReference name="isActive" type="boolean" default="false">
  智能体是否正在运行且组后面没有别的内容，因而可能有更多调用加入。活动期间，摘要会在调用之间持续点名最新的调用，而不是切换到"Used 3 tools"再切回来。
</PropertyReference>

<PropertyReference name="className" type="string">
  分组根元素的额外 class。
</PropertyReference>

## 用法

### 选择外观

常规方式是使用消息视图的 `toolCallDisplay`：

```tsx
<CopilotChat messageView={{ toolCallDisplay: "stacked" }} />
```

`group` 插槽可以直接设置它，例如在独立的工具调用视图上：

```tsx
<CopilotChatToolCallsView
  message={message}
  messages={messages}
  group={{ appearance: "line" }}
/>
```

### 重新设计分组样式

```tsx
<CopilotChat
  messageView={{
    assistantMessage: {
      toolCallsView: { group: "rounded-2xl border-dashed" },
    },
  }}
/>
```

### 替换分组

替换组件会收到与默认组件相同的 props。使用 `renderCall` 可让每个调用继续由其已注册的渲染器绘制。

```tsx
import type { CopilotChatToolCallGroupProps } from "@copilotkit/react-core/v2";

function ToolTimeline({ calls, renderCall }: CopilotChatToolCallGroupProps) {
  const running = calls.some((call) => !call.toolMessage);
  return (
    <details className="my-3">
      <summary>{running ? "Working…" : `Ran ${calls.length} tools`}</summary>
      {calls.map((call) => (
        <div key={call.toolCall.id}>{renderCall(call)}</div>
      ))}
    </details>
  );
}

<CopilotChat
  messageView={{
    assistantMessage: { toolCallsView: { group: ToolTimeline } },
  }}
/>;
```

## 行为

- **分组规则**：由设置了 `group: true` 的渲染器绘制的调用会加入当前打开的分组。助手文本、用户消息、推理或活动消息，或任何其他调用都会终结该分组。未设置 `group` 的自定义渲染器总是单独显示其调用，因为它可能什么都没画。完全没有渲染器的调用什么都不渲染，也不会终结分组。
- **默认折叠**：分组初始为收起状态，并保持用户离开时的样子。
- **失败**：工具消息带 `error` 的调用会显示失败图标，摘要中失败数量会取代"Done"（"1 failed"）。
- **停止的运行**：在运行结束前始终没有拿到结果的调用（用户按了停止，或运行出错）显示为已停止而非运行中，摘要显示"Stopped"。
- **无障碍**：摘要是一个带 `aria-expanded` 与 `aria-controls` 的按钮。收起的内容保持挂载但为 `inert`。当用户偏好减弱动态效果时，展开与收起动画会关闭。
- **测试钩子**：根元素带有 `data-testid="copilot-tool-call-group"`、`data-appearance` 与 `data-state`（`"running"`、`"done"`、`"failed"` 或 `"stopped"`）。内置渲染器绘制的行保留 `data-testid="copilot-tool-render"` 及其 `data-tool-name`、`data-status`、`data-args` 与 `data-result` 属性。

## CopilotChatWorkSummary

当消息视图的 `toolCallDisplay` 为 `"turn"` 时，每条回复顶部的那一行。智能体工作期间它显示"Working"并伴随计时，代替光标的位置。回复完成后它显示"Worked for 9s · 7 tools"，并可切换显示已折叠的叙述与调用。它是消息视图的 `workSummary` 插槽。

### 导入

```tsx
import { CopilotChatWorkSummary } from "@copilotkit/react-core/v2";
import type { CopilotChatWorkSummaryProps } from "@copilotkit/react-core/v2";
```

### Props

还接受所有 `<button>` 属性；消息视图会传入 `onClick` 来切换工作内容的展开状态。

<PropertyReference name="isWorking" type="boolean" required>
  智能体仍在处理这条回复。
</PropertyReference>

<PropertyReference name="isOpen" type="boolean" required>
  工作内容（叙述与工具调用）是否正在显示。
</PropertyReference>

<PropertyReference name="calls" type="ToolCallEntry[]" required>
  该回复发起的工具调用。
</PropertyReference>

<PropertyReference name="elapsedMs" type="number">
  智能体处理该回复所用的时间（毫秒），按多次运行累计，因此运行之间的等待时间不计入。仅当客户端亲眼看到回复启动时才会设置；没有它时，摘要会显示工具数量（"Used 7 tools"）而不是耗时。
</PropertyReference>

<PropertyReference name="workingSince" type="number">
  当前运行开始的时间（自纪元起的毫秒数）。在智能体工作期间设置，以便实时计时器能把当前运行累加进 `elapsedMs`。
</PropertyReference>

### 替换摘要

```tsx
import type { CopilotChatWorkSummaryProps } from "@copilotkit/react-core/v2";

function WorkLine({
  isWorking,
  isOpen,
  calls,
  onClick,
}: CopilotChatWorkSummaryProps) {
  return (
    <button onClick={onClick} aria-expanded={isOpen}>
      {isWorking ? "Thinking it through…" : `Checked ${calls.length} sources`}
    </button>
  );
}

<CopilotChat
  messageView={{ toolCallDisplay: "turn", workSummary: WorkLine }}
/>;
```
