## 概览

`useFrontendTool` 在当前组件作用域向 CopilotKit 注册一个客户端工具。当智能体决定调用该工具时，提供的 `handler` 函数会在浏览器中执行。你还可以选择提供一个 `render`（Vue 组件或渲染函数），在聊天中显示自定义 UI，展示工具的执行进度和结果。

该组合式函数管理完整的注册生命周期：立即注册工具（及其可选渲染器），响应式依赖变化时重新执行注册，并在所属作用域销毁时自动移除工具。参数模式用 [Standard Schema](https://standardschema.dev)（例如 [Zod](https://zod.dev) 对象）定义，用于对外声明的工具模式和 TypeScript 类型推断。运行时参数会经 JSON 解析，但不会按该模式校验。

<Callout type="info">
  从 `/v2` 子路径导入：`@copilotkit/vue/v2`。与所有 CopilotKit 组合式函数一样，`useFrontendTool` 必须在 [`CopilotKitProvider`](/reference/vue/components/CopilotKitProvider) 后代组件内调用。
</Callout>

## 签名

```ts
import type { WatchSource } from "vue";
import { useFrontendTool } from "@copilotkit/vue/v2";

function useFrontendTool<T extends Record<string, unknown>>(
  tool: VueFrontendTool<T>,
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="tool" type="VueFrontendTool<T>" required>
  工具定义对象。

  <PropertyReference name="name" type="string" required>
    工具的唯一名称。智能体在决定调用工具时会引用这个名称。如果同名工具已注册（同一 `agentId` 下），现有注册会被覆盖并记录一条警告。
  </PropertyReference>

  <PropertyReference name="description" type="string">
    自然语言描述，告诉智能体这个工具做什么、何时使用。
  </PropertyReference>

  <PropertyReference name="parameters" type="StandardSchemaV1<any, T>">
    定义工具输入参数的 [Standard Schema](https://standardschema.dev)（例如 Zod 对象）。该模式驱动对外声明的工具模式，并为 `handler` 参数提供类型推断。运行时参数会经 JSON 解析，但不会按该模式校验。不带参数的工具可以省略。
  </PropertyReference>

  <PropertyReference
    name="handler"
    type="(args: T, context: FrontendToolHandlerContext) => Promise<unknown>"
  >
    智能体调用工具时执行的异步函数。它接收解析后的参数（类型来自 `parameters`，但不按其校验）以及上下文对象：`toolCall`（原始工具调用元数据）、`agent`（调用该工具的智能体实例；通过 WebMCP 调用工具时不存在）、`signal`（用户停止智能体时会被中止的 `AbortSignal`）和 `isReplay`（在线程历史恢复期间运行该调用时为 `true`；见 `reconnectBehavior`）。
    长时间运行的处理器可以检查 `signal.aborted`，或把 `signal` 传给 `fetch` 以协作式取消。其解析值会作为工具结果回传给智能体。`FrontendToolHandlerContext` 从 `@copilotkit/core` 导出。
  </PropertyReference>

  <PropertyReference
    name="render"
    type="Component<RenderProps<T>> | ((props: RenderProps<T>) => VNodeChild)"
  >
    可选的 Vue 组件或渲染函数，用于在聊天中可视化工具执行过程。它接收一个 props 对象：`name`（工具名称）、`toolCallId`（本次工具调用的唯一 id）、`args`（参数，`InProgress` 流式期间为部分内容，`Executing` 和 `Complete` 期间为完整内容）、`status`（`ToolCallStatus.InProgress`、`ToolCallStatus.Executing` 或 `ToolCallStatus.Complete` 之一）和 `result`（字符串结果，仅在状态为 `Complete` 时可用）。
  </PropertyReference>

  <PropertyReference name="available" type="boolean" default="true">
    工具是否对智能体可见。设为 `false` 可在不注销工具的情况下对智能体隐藏它。这个响应式值变化时会重新执行注册。
  </PropertyReference>

  <PropertyReference name="agentId" type="string">
    可选的智能体作用域。设置后，该工具只对具有此 id 的智能体可用。重名检测按 `agentId` 划分作用域。
  </PropertyReference>

  <PropertyReference name="followUp" type="boolean">
    工具结果返回后，智能体是否应自动继续运行。
  </PropertyReference>

  <PropertyReference name="reconnectBehavior" type='"passive" | "resume-pending"' default='"passive"'>
    线程历史恢复时（例如页面刷新后），该工具仍未应答的调用会如何处理。`"passive"` 时，调用会显示但处理器不运行。`"resume-pending"` 时，处理器会为该调用运行，上下文中 `isReplay: true`，然后运行照常继续。只应对可安全重复运行的处理器启用此选项。同一页面上一次调用不会同时启动两次，但在停止或切换线程后，如果其结果从未到达智能体，它可能再次运行；恢复同一线程的两个标签页也可能各自运行它。如果智能体在调用该工具的同时还调用了保持 passive 的工具，后续运行会发送不带结果的 passive 调用，某些模型提供方会拒绝这种情况。
  </PropertyReference>

  <PropertyReference name="webmcp" type="boolean | { annotations?: { readOnlyHint?: boolean; untrustedContentHint?: boolean } }">
    同时通过 WebMCP API（`document.modelContext`）把该工具暴露给浏览器智能体。传 `true` 以默认注解注册，或传一个对象以自定义 WebMCP 注解注册。浏览器智能体调用该工具时运行的是同一个 `handler`；此时上下文中没有 `agent`。在 WebMCP 不可用的环境（SSR，或未启用该 API 的浏览器）中这是空操作。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的响应式侦听源列表（例如 `ref` 或 getter）。
  其中任何一项变化时注册都会重新执行。当你的
  `handler` 或 `render` 捕获了需要刷新注册的响应式值时使用。组合式函数内部已经侦听 `tool.name` 和 `tool.available`。
</PropertyReference>

## 行为

- **立即注册**。组合式函数一运行工具就会注册（底层 `watch` 使用 `{ immediate: true }`）。
- **重名处理**。同一 `agentId` 下已存在同名工具时，先前的注册会被移除、新注册被加入，并记录一条覆盖警告。每个名称（每个智能体）同时只有一个工具处于活跃状态。
- **渲染器注册**。提供 `render` 时，它会注册为工具调用渲染器。即使省略 `parameters`，渲染器也会注册，因此无参数工具（例如确认对话框）也能在聊天中渲染 UI。
- **响应性**。`tool.name`、`tool.available` 或任何 `deps` 侦听源变化时，注册会重新执行。会变化的响应式值请通过 `deps` 传入。
- **WebMCP 注册**。设置 `webmcp` 后，工具还会注册到 `document.modelContext`，并随工具一起移除。这要求工具有 `description`（WebMCP 拒绝没有描述的工具）。
- **自动清理**。侦听器清理时（包括所属组件作用域销毁时）工具会被移除。随工具一起注册的 `render` 会有意保留在原处，让更早的聊天历史仍能渲染它。
- **无返回值**。该组合式函数返回 `void`。

## 用法

### 带 Zod schema 与异步处理器的基本工具

```vue
<script setup lang="ts">
import { ref } from "vue";
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/vue/v2";

const todos = ref<string[]>([]);

useFrontendTool({
  name: "addTodo",
  description: "Add a new item to the user's todo list",
  parameters: z.object({
    text: z.string().describe("The todo item text"),
    priority: z.enum(["low", "medium", "high"]).describe("Priority level"),
  }),
  handler: async ({ text, priority }) => {
    todos.value.push(text);
    return `Added "${text}" with ${priority} priority`;
  },
});
</script>

<template>
  <ul>
    <li v-for="(todo, i) in todos" :key="i">{{ todo }}</li>
  </ul>
</template>
```

### 带自定义 Vue 渲染器的工具

提供 `render` 组件以在聊天中可视化工具调用。该组件以 `args`、`status` 和 `result` 作为 props。

```vue
<!-- WeatherToolView.vue -->
<script setup lang="ts">
import { ToolCallStatus } from "@copilotkit/core";

defineProps<{
  name: string;
  toolCallId: string;
  args: { city?: string; units?: "celsius" | "fahrenheit" };
  status: ToolCallStatus;
  result?: string;
}>();
</script>

<template>
  <div v-if="status === ToolCallStatus.InProgress" class="animate-pulse">
    Fetching weather for {{ args.city }}...
  </div>
  <div v-else-if="status === ToolCallStatus.Complete && result" class="rounded border p-4">
    <h3>{{ JSON.parse(result).city }}</h3>
    <p>{{ JSON.parse(result).temperature }}&deg; {{ JSON.parse(result).units }}</p>
    <p>{{ JSON.parse(result).conditions }}</p>
  </div>
</template>
```

```vue
<!-- App.vue -->
<script setup lang="ts">
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/vue/v2";
import WeatherToolView from "./WeatherToolView.vue";

useFrontendTool({
  name: "getWeather",
  description: "Fetch and display weather information for a city",
  parameters: z.object({
    city: z.string().describe("City name"),
    units: z.enum(["celsius", "fahrenheit"]).default("celsius"),
  }),
  handler: async ({ city, units }, { signal }) => {
    const response = await fetch(`/api/weather?city=${city}&units=${units}`, {
      signal,
    });
    return JSON.stringify(await response.json());
  },
  render: WeatherToolView,
});
</script>
```

### 条件可用的工具

把 `available` 暴露为读取响应式值的 getter。注册侦听器会在该值变化时重新读取 `available`，因此工具会自动显示或隐藏。（同时也通过 `deps` 传入该值无害，但并非必需。）

```vue
<script setup lang="ts">
import { computed, toRef } from "vue";
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/vue/v2";

const props = defineProps<{ isAdmin: boolean }>();
const isAdmin = toRef(props, "isAdmin");

useFrontendTool(
  {
    name: "deleteUser",
    description: "Delete a user account by ID (admin only)",
    parameters: z.object({
      userId: z.string().describe("The ID of the user to delete"),
    }),
    handler: async ({ userId }) => {
      await fetch(`/api/users/${userId}`, { method: "DELETE" });
      return `User ${userId} deleted`;
    },
    // Expose `available` as a getter so the registration watch re-reads it
    // whenever `isAdmin` changes.
    get available() {
      return isAdmin.value;
    },
  },
  [isAdmin],
);
</script>
```
