---

## 概览

`useHumanInTheLoop` 注册一个交互式前端工具，它会暂停智能体的执行，直到用户通过你的自定义 UI 作出响应。与 `useFrontendTool` 不同，你无需提供 `handler`。该组合式函数会在内部维护一个状态机（`InProgress` -> `Executing` -> `Complete`），并在工具处于 `executing` 阶段时把 `respond` 回调传给你的渲染组件。在以用户输入调用 `respond` 之前，智能体会一直保持暂停。

该组合式函数在内部封装了 `useFrontendTool`：它生成一个返回 Promise 的 handler，把该 Promise 的 `resolve` 保存在一个 ref 中，并在 `respond` 被调用时将其兑现，从而把结果回传给智能体并恢复执行。适用于确认对话框、审批工作流、表单收集，或任何需要人先提供输入、智能体才能继续的场景。

<Callout type="info">
  `useHumanInTheLoop` 必须在能够访问 `CopilotKitProvider` 所提供 CopilotKit 实例的组件中调用。与所有 Vue 组合式函数一样，请在 `<script setup>` 或 `setup()` 函数中同步调用，使其响应式作用域绑定到组件生命周期。作用域清理时，该工具会自动注销。
</Callout>

## 签名

```ts
import { useHumanInTheLoop } from "@copilotkit/vue/v2";

function useHumanInTheLoop<T extends Record<string, unknown>>(
  tool: VueHumanInTheLoop<T>,
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="tool" type="VueHumanInTheLoop<T>" required>
  交互式工具的定义。它接受与前端工具相同的字段，但不包括 `handler`（由内部管理），另外还必须提供 `render` 组件。

<PropertyReference name="name" type="string" required>
  工具的唯一名称。智能体在需要人类输入时会引用该名称。
</PropertyReference>

<PropertyReference name="description" type="string">
  一段自然语言描述，告诉智能体该工具做什么、何时调用（例如 “在删除记录前请用户确认”）。
</PropertyReference>

<PropertyReference name="parameters" type="StandardSchemaV1 (e.g. z.ZodSchema)">
  一个 schema（通常是 Zod schema），定义智能体传给该工具的参数。这些参数会作为 `args` prop 转发给渲染组件，便于你构建具备上下文感知能力的 UI。
</PropertyReference>

  <PropertyReference name="render" type="VueHumanInTheLoopRenderFn<T>" required>
    一个驱动人机协同（human-in-the-loop）交互的 Vue 组件（或渲染函数）。它接收以下 props，其形态取决于当前的 `status`：

    **始终存在**：
    - `name: string` —— 工具名称
    - `description: string` —— 工具描述（若工具未定义则为空字符串）
    - `toolCallId: string` —— 本次工具调用的唯一 id
    - `status: ToolCallStatus` —— 当前阶段（`"inProgress"`、`"executing"` 或 `"complete"`）

    **当 `status` 为 `ToolCallStatus.InProgress`（`"inProgress"`）时**：
    - `args: Partial<T>` —— 仍在流式传入的部分参数
    - `result: undefined`
    - `respond: undefined` —— 尚不可用

    **当 `status` 为 `ToolCallStatus.Executing`（`"executing"`）时**：
    - `args: T` —— 已完整解析的参数
    - `result: undefined`
    - `respond: (result: unknown) => Promise<void>` —— 调用它把用户的响应回传给智能体并恢复执行

    **当 `status` 为 `ToolCallStatus.Complete`（`"complete"`）时**：
    - `args: T` —— 原始参数
    - `result: string` —— 序列化后的结果
    - `respond: undefined` —— 已不可用

  </PropertyReference>

  <PropertyReference name="available" type="boolean" default="true">
    该工具对智能体是否可用。设为 `false` 可对智能体隐藏该工具，而无需注销它。
  </PropertyReference>

  <PropertyReference name="agentId" type="string">
    可选的智能体 ID，用于把该工具限定给特定智能体。指定后，该工具仅对该智能体可用。
  </PropertyReference>

  <PropertyReference name="followUp" type="boolean">
    工具响应后，智能体是否应自动跟进。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的响应式侦听来源数组（ref、getter 等）。提供后，任一来源变化时都会刷新工具注册。
</PropertyReference>

## 用法

将渲染组件定义为独立的 Vue SFC，然后用 `useHumanInTheLoop` 注册它。组件会以 props 形式接收 `status`、`args`、`respond`、`name` 和 `description`。

### 确认对话框

智能体请求用户确认破坏性操作的常见模式。

`ConfirmDeletion.vue`（渲染组件）：

```vue
<script setup lang="ts">
import { ToolCallStatus } from "@copilotkit/core";

defineProps<{
  status: ToolCallStatus;
  args: { itemName?: string; itemCount?: number };
  name: string;
  description: string;
  result?: string;
  respond?: (result: unknown) => Promise<void>;
}>();
</script>

<template>
  <div v-if="status === ToolCallStatus.InProgress" class="p-4 text-gray-500">
    Preparing confirmation...
  </div>

  <div
    v-else-if="status === ToolCallStatus.Executing && respond"
    class="p-4 border rounded"
  >
    <p>Are you sure you want to delete {{ args.itemCount }} {{ args.itemName }}(s)?</p>
    <div class="flex gap-2 mt-4">
      <button
        class="bg-red-500 text-white px-4 py-2 rounded"
        @click="respond({ confirmed: true })"
      >
        Delete
      </button>
      <button
        class="bg-gray-300 px-4 py-2 rounded"
        @click="respond({ confirmed: false })"
      >
        Cancel
      </button>
    </div>
  </div>

  <div
    v-else-if="status === ToolCallStatus.Complete && result"
    class="p-2 text-sm text-gray-600"
  >
    {{ JSON.parse(result).confirmed ? "Items deleted." : "Deletion cancelled." }}
  </div>
</template>
```

在 `CopilotKitProvider` 作用域内的组件中注册：

```vue
<script setup lang="ts">
import { useHumanInTheLoop } from "@copilotkit/vue/v2";
import { z } from "zod";
import ConfirmDeletion from "./ConfirmDeletion.vue";

useHumanInTheLoop({
  name: "confirmDeletion",
  description: "Ask the user to confirm before deleting items",
  parameters: z.object({
    itemName: z.string().describe("Name of the item to delete"),
    itemCount: z.number().describe("Number of items to delete"),
  }),
  render: ConfirmDeletion,
});
</script>

<template>
  <!-- nothing to render here; the tool UI is shown in the chat -->
</template>
```

### 表单输入收集

在智能体继续之前从用户处收集结构化输入。本地表单状态通过 `ref` 保存在渲染组件中。

`ShippingAddressForm.vue`：

```vue
<script setup lang="ts">
import { ref } from "vue";
import { ToolCallStatus } from "@copilotkit/core";

defineProps<{
  status: ToolCallStatus;
  args: { orderSummary?: string };
  name: string;
  description: string;
  result?: string;
  respond?: (result: unknown) => Promise<void>;
}>();

const address = ref({ street: "", city: "", zip: "" });
</script>

<template>
  <div
    v-if="status === ToolCallStatus.Executing && respond"
    class="p-4 border rounded space-y-3"
  >
    <p class="font-medium">Order: {{ args.orderSummary }}</p>
    <p>Please enter your shipping address:</p>
    <input
      v-model="address.street"
      placeholder="Street address"
      class="w-full border p-2 rounded"
    />
    <input
      v-model="address.city"
      placeholder="City"
      class="w-full border p-2 rounded"
    />
    <input
      v-model="address.zip"
      placeholder="ZIP code"
      class="w-full border p-2 rounded"
    />
    <button
      class="bg-blue-500 text-white px-4 py-2 rounded"
      @click="respond({ ...address })"
    >
      Submit Address
    </button>
  </div>

  <div v-else-if="status === ToolCallStatus.Complete" class="p-2 text-green-600">
    Shipping address submitted.
  </div>
</template>
```

注册：

```vue
<script setup lang="ts">
import { useHumanInTheLoop } from "@copilotkit/vue/v2";
import { z } from "zod";
import ShippingAddressForm from "./ShippingAddressForm.vue";

useHumanInTheLoop({
  name: "collectShippingAddress",
  description: "Collect shipping address from the user before placing an order",
  parameters: z.object({
    orderSummary: z.string().describe("A summary of the order being placed"),
  }),
  render: ShippingAddressForm,
});
</script>

<template>
  <!-- tool UI renders inside the chat -->
</template>
```

### 带上下文的审批工作流

`ExpenseApproval.vue`：

```vue
<script setup lang="ts">
import { ToolCallStatus } from "@copilotkit/core";

defineProps<{
  status: ToolCallStatus;
  args: {
    employeeName?: string;
    amount?: number;
    category?: string;
    description?: string;
  };
  name: string;
  description: string;
  result?: string;
  respond?: (result: unknown) => Promise<void>;
}>();
</script>

<template>
  <div
    v-if="status === ToolCallStatus.Executing && respond"
    class="p-4 border rounded"
  >
    <h3 class="font-bold">Expense Approval Required</h3>
    <div class="mt-2 space-y-1 text-sm">
      <p>Employee: {{ args.employeeName }}</p>
      <p>Amount: ${{ args.amount?.toFixed(2) }}</p>
      <p>Category: {{ args.category }}</p>
      <p>Description: {{ args.description }}</p>
    </div>
    <div class="flex gap-2 mt-4">
      <button
        class="bg-green-500 text-white px-4 py-2 rounded"
        @click="respond({ approved: true })"
      >
        Approve
      </button>
      <button
        class="bg-red-500 text-white px-4 py-2 rounded"
        @click="respond({ approved: false, reason: 'Needs more detail' })"
      >
        Reject
      </button>
    </div>
  </div>

  <div
    v-else-if="status === ToolCallStatus.Complete && result"
    class="p-2 text-sm"
    :class="JSON.parse(result).approved ? 'text-green-600' : 'text-red-600'"
  >
    {{
      JSON.parse(result).approved
        ? "Expense approved."
        : `Expense rejected: ${JSON.parse(result).reason}`
    }}
  </div>
</template>
```

注册：

```vue
<script setup lang="ts">
import { useHumanInTheLoop } from "@copilotkit/vue/v2";
import { z } from "zod";
import ExpenseApproval from "./ExpenseApproval.vue";

useHumanInTheLoop({
  name: "approveExpense",
  description: "Request manager approval for an expense report",
  parameters: z.object({
    employeeName: z.string().describe("Name of the employee"),
    amount: z.number().describe("Expense amount in dollars"),
    category: z.string().describe("Expense category"),
    description: z.string().describe("Description of the expense"),
  }),
  render: ExpenseApproval,
});
</script>

<template>
  <!-- tool UI renders inside the chat -->
</template>
```

## 行为

- **会阻塞智能体执行**：内部生成的 handler 返回一个 Promise，在 `respond` 被调用前不会兑现，因此智能体会在这个工具调用上暂停并等待用户。
- **内部状态机**：该组合式函数驱动三个阶段——`inProgress`（参数正在流式传入）、`executing`（等待用户，`respond` 可用）和 `complete`（用户已响应，`result` 可用）。你的渲染组件会在每个阶段收到相应的 props。
- **`respond` 仅在 `executing` 阶段传入**：在 `inProgress` 和 `complete` 阶段，`respond` 为 `undefined`。调用前请先以 `status === ToolCallStatus.Executing && respond` 作防护判断。
- **单次响应**：调用 `respond` 会兑现挂起的 Promise 一次并清除存储的 resolver，因此对同一次工具调用而言，后续调用都是空操作。
- **基于 `useFrontendTool` 构建**：该组合式函数会把一个 `VueFrontendTool`（你的工具加上生成的 `handler` 和一个包装用的渲染组件）转发给 `useFrontendTool`，因此注册生命周期与之相同。
- **作用域生命周期**：在组合式函数的响应式作用域存续期间，工具及其渲染组件保持注册，并在作用域清理时自动移除——渲染组件通过 `onScopeDispose` 移除，工具则通过底层 `useFrontendTool` 侦听器的清理逻辑移除。
- **无返回值**：该组合式函数返回 `void`。

## ToolCallStatus

`ToolCallStatus` 枚举从 `@copilotkit/core` 导出，定义了工具执行的三个阶段。渲染组件的 `status` prop 中出现的正是其字符串值。

| 值                          | 字符串值        | 说明                                                                                     |
| --------------------------- | -------------- | ---------------------------------------------------------------------------------------- |
| `ToolCallStatus.InProgress` | `"inProgress"` | 参数正从智能体流式传入。工具尚未开始执行。                                                |
| `ToolCallStatus.Executing`  | `"executing"`  | 参数已完整解析。对 `useHumanInTheLoop` 而言，此时会传入 `respond` 回调。                   |
| `ToolCallStatus.Complete`   | `"complete"`   | 执行已结束。`result` 字符串可用。                                                          |
