## 概览

`useRenderTool` 是一个 Vue 3 组合式函数，用于为工具调用注册聊天渲染器。
你可以针对特定工具名称（并提供带类型的 Zod `parameters` schema），也可以使用通配符（`"*"`）兜底渲染器。

渲染目标可以是一个 Vue 渲染函数（返回 `VNodeChild`）或一个 Vue `Component`。它会收到工具的 `name`、解析后的 `parameters`、当前 `status`，以及 `result`（执行完成时）。这不是 JSX；你可以用 Vue 的 `h()`、在 setup 中定义的渲染函数，或直接传入一个单文件 Vue 组件来渲染。

该组合式函数只负责渲染，不会注册前端 handler。

<Callout type="info">
  请在挂载于 [`CopilotKitProvider`](/reference/vue/components/CopilotKitProvider) 之下的组件的 `setup()`（或 `<script setup>`）内调用 `useRenderTool`。它从 provider 上下文读取当前的 CopilotKit 实例，因此无法在该组件树之外调用。
</Callout>

## 导入

```ts
import { useRenderTool } from "@copilotkit/vue/v2";
```

## 签名

### 通配符重载

```ts
import { useRenderTool } from "@copilotkit/vue/v2";
import type { WatchSource } from "vue";

useRenderTool(
  {
    name: "*",
    render: ((props) => VNodeChild) | Component,
    agentId?: string,
  },
  deps?: WatchSource<unknown>[],
): void;
```

### 具名重载

在此签名中，`RenderToolProps<S>` 是[渲染 Props](#渲染-props) 中所述可辨识联合类型的简写。它并未从 `@copilotkit/vue/v2` 导出；请让 `render` 回调从 schema 推断其 props，如下方示例所示。

```ts
import { z } from "zod";
import { useRenderTool } from "@copilotkit/vue/v2";
import type { WatchSource } from "vue";

useRenderTool<S>(
  {
    name: string,
    parameters: S, // a Zod / Standard Schema; parameters are inferred from it
    render: ((props: RenderToolProps<S>) => VNodeChild) | Component<RenderToolProps<S>>,
    agentId?: string,
  },
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="config" type="object" required>
  渲染器的配置。

  <PropertyReference name="name" type="string" required>
    要渲染的工具名称；设为 `"*"` 时作为通配符兜底，匹配任何未被其他渲染器处理的工具调用。
  </PropertyReference>

  <PropertyReference name="parameters" type="StandardSchemaV1">
    描述工具参数的 Zod（或其他 Standard Schema）schema。具名渲染器必须提供；传给 `render` 的 `parameters` 的类型由它推断。通配符（`"*"`）重载则省略它。
  </PropertyReference>

  <PropertyReference name="render" type="((props: RenderToolProps) => VNodeChild) | Component" required>
    可以是返回 `VNodeChild` 的渲染函数，或一个 Vue `Component`。若提供组件，渲染 props 会作为组件 props 传给它。
  </PropertyReference>

  <PropertyReference name="agentId" type="string">
    将渲染器限定于特定智能体。渲染器按 `agentId:name` 键去重。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的响应式侦听来源。当 `name`、`agentId` 或任一来源变化时，渲染器会重新注册。请把 `render` 闭包引用的响应式值（ref、getter）也加入其中，以保持其时效性。默认为空数组。
</PropertyReference>

## 渲染 Props

`render` 接收一个以 `status` 为判别键的可辨识联合类型（`RenderToolProps`）。`name` 与 `toolCallId` 在所有状态下都存在。

<PropertyReference name="name" type="string" required>
  工具名称。
</PropertyReference>

<PropertyReference name="toolCallId" type="string" required>
  本次工具调用的唯一 id。
</PropertyReference>

<PropertyReference name="status" type='"inProgress" | "executing" | "complete"' required>
  工具调用当前所处的生命周期阶段。
</PropertyReference>

<PropertyReference name="parameters" type="Partial<T> | T" required>
  解析后的工具参数，类型来自 `parameters` schema。`inProgress` 阶段为 `Partial<T>`（参数仍在流式传入），进入 `executing` 或 `complete` 后为完整解析的 `T`。
</PropertyReference>

<PropertyReference name="result" type="string | undefined">
  工具结果字符串。在 `status` 变为 `"complete"` 之前为 `undefined`。
</PropertyReference>

三种状态分别为：

- `{ status: "inProgress", parameters: Partial<T>, result: undefined }` —— 参数仍在流式传入。
- `{ status: "executing", parameters: T, result: undefined }` —— 参数已完整解析，工具正在执行。
- `{ status: "complete", parameters: T, result: string }` —— 执行结束，结果可用。

## 行为

- 用 `defineToolCallRenderer` 构建渲染器条目，并通过 `addHookRenderToolCall` 注册到当前 CopilotKit 实例上。
- 在调用 `render` 前，把内部的 `args` prop 映射为 `parameters`，因此你的渲染函数看到的始终是 `parameters`。
- 按 `agentId:name` 键去重（以最新注册为准）。
- 有意不在清理时移除渲染器，以便历史聊天记录仍能渲染。
- 当 `name`、`agentId` 或 `deps` 中任一值变化时，会以响应式方式重新注册（通过 `watch`，`immediate: true`）。请把会变化的响应式捕获值放入 `deps`。

## 用法

### 具名工具渲染器（渲染函数）

```vue
<script setup lang="ts">
import { h } from "vue";
import { z } from "zod";
import { useRenderTool } from "@copilotkit/vue/v2";

useRenderTool({
  name: "searchDocs",
  parameters: z.object({ query: z.string() }),
  render: (props) => {
    if (props.status === "inProgress") {
      return h("div", `Preparing ${props.name}...`);
    }
    if (props.status === "executing") {
      return h("div", `Searching for: ${props.parameters.query}`);
    }
    return h("div", `Done: ${props.result}`);
  },
});
</script>

<template>
  <slot />
</template>
```

### 具名工具渲染器（Vue 组件）

传入 Vue 组件而非渲染函数。渲染 props 会成为该组件的 props。

```vue
<!-- SearchDocsRenderer.vue -->
<script setup lang="ts">
defineProps<{
  name: string;
  toolCallId: string;
  status: "inProgress" | "executing" | "complete";
  parameters: { query?: string };
  result?: string;
}>();
</script>

<template>
  <div v-if="status === 'inProgress'">Preparing {{ name }}...</div>
  <div v-else-if="status === 'executing'">Searching for: {{ parameters.query }}</div>
  <div v-else>Done: {{ result }}</div>
</template>
```

```vue
<!-- App.vue -->
<script setup lang="ts">
import { z } from "zod";
import { useRenderTool } from "@copilotkit/vue/v2";
import SearchDocsRenderer from "./SearchDocsRenderer.vue";

useRenderTool({
  name: "searchDocs",
  parameters: z.object({ query: z.string() }),
  render: SearchDocsRenderer,
});
</script>

<template>
  <slot />
</template>
```

### 通配符兜底渲染器

省略 `parameters` 并使用 `name: "*"`，即可为任何未被处理的工具调用提供通用 UI。

```vue
<script setup lang="ts">
import { h } from "vue";
import { useRenderTool } from "@copilotkit/vue/v2";

useRenderTool({
  name: "*",
  render: (props) =>
    h("div", `${props.status === "complete" ? "done" : "running"} ${props.name}`),
});
</script>

<template>
  <slot />
</template>
```

### 用 `deps` 响应变化的值

`deps` 是 Vue 的 `WatchSource` 值（ref 或 getter），不是依赖数组。当 `render` 读取响应式状态时请传入它们，渲染器便会在变化时重新注册。

```vue
<script setup lang="ts">
import { h, ref } from "vue";
import { z } from "zod";
import { useRenderTool } from "@copilotkit/vue/v2";

const locale = ref("en");

useRenderTool(
  {
    name: "searchDocs",
    parameters: z.object({ query: z.string() }),
    render: (props) =>
      h("div", `[${locale.value}] ${props.name}: ${props.status}`),
  },
  [locale],
);
</script>

<template>
  <slot />
</template>
```
