## 概览

`useAgent` 是一个 Vue 3 组合式函数，返回指向 [AG-UI AbstractAgent](https://docs.ag-ui.com/sdk/js/client/abstract-agent) 实例的响应式引用。该组合式函数会订阅智能体的变化，并在智能体的状态、消息或执行状态变化时触发响应式更新。

组合式函数返回 `{ agent }`，出于 API 兼容性考虑，`agent` 的类型是 Vue 的 `shallowRef<AbstractAgent | null>`。在 setup 期间，它会同步赋值一个已有或临时的智能体；如果两者都无法解析，它会抛出错误，而不是返回 `agent.value` 为 `null`。在 `<script setup>` 中用 `agent.value` 访问底层实例，或在 `<template>` 中依赖自动解包。消费可空的公开类型时，可选链仍然有用。

<Callout type="warn">
  如果运行时同步后仍无法为给定 `agentId` 解析出智能体（例如该 id 与运行时
  `/info` 报告的任何智能体或通过 `agents__unsafe_dev_only` 注册的智能体都不匹配），
  则抛出错误。
</Callout>

## 签名

```ts
import { useAgent } from "@copilotkit/vue/v2";
import type { ShallowRef } from "vue";
import type { AbstractAgent } from "@ag-ui/client";

function useAgent(props?: UseAgentProps): {
  agent: ShallowRef<AbstractAgent | null>;
};
```

## 参数

响应式 props 接受 `MaybeRefOrGetter`，因此你可以传普通值、`ref` 或 getter 函数。组合式函数会按下文描述的行为响应每个输入。

<PropertyReference name="props" type="UseAgentProps">
  组合式函数的配置对象。

  <PropertyReference name="agentId" type="MaybeRefOrGetter<string | undefined>" default='"default"'>
    要解析的智能体 ID。解析顺序为：显式 `agentId`，其次周围聊天配置的
    `agentId`，最后 `DEFAULT_AGENT_ID`。该 id 可能解析为运行时发现的智能体
    或提供方注册的智能体。在线程作用域用法中，它是注册私有代理所用的本地 id。
  </PropertyReference>

  <PropertyReference name="runtimeAgentId" type="MaybeRefOrGetter<string>">
    线程作用域用法使用的运行时智能体 id。将它与 `agentId` 和 `threadId`
    一起传入（三者都必须提供），可注册一个路由到此运行时智能体的私有本地代理。
    部分组合是无效的。
  </PropertyReference>

  <PropertyReference name="threadId" type="MaybeRefOrGetter<string>">
    线程作用域用法使用的会话线程 ID。将它与 `agentId` 和 `runtimeAgentId`
    一起传入，可注册私有代理、将其路由到运行时智能体，并把该线程固定到当前代理上。
    更改 `threadId` 会重新固定该代理。共享智能体形式下请省略它；
    当前聊天配置中存在显式线程时会使用它。
  </PropertyReference>

  <PropertyReference name="updates" type="UseAgentUpdate[]" default="[OnMessagesChanged, OnStateChanged, OnRunStatusChanged]">
    控制哪些智能体变化触发响应式更新。可选项：
    - `UseAgentUpdate.OnMessagesChanged` - 消息变化时更新
    - `UseAgentUpdate.OnStateChanged` - 状态变化时更新
    - `UseAgentUpdate.OnRunStatusChanged` - 执行状态变化时更新

    传入空数组 `[]` 可阻止自动响应式更新。
  </PropertyReference>

  <PropertyReference name="throttleMs" type="MaybeRefOrGetter<number | undefined>">
    `onMessagesChanged` 与 `onStateChanged` 触发的更新的节流间隔（毫秒）。
    有助于在高频流式传输期间降低更新频率。

    解析规则为 `throttleMs ?? provider defaultThrottleMs ?? 0`。
    即使提供方指定了非零 `defaultThrottleMs`，显式传入 `throttleMs: 0`
    也会禁用节流。

    运行生命周期回调（`onRunInitialized`、`onRunFinalized`、`onRunFailed`、
    `onRunErrorEvent`）始终立即触发，不受节流影响。
  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="object" type="{ agent: ShallowRef<AbstractAgent | null> }">
  包含响应式智能体引用的对象。

  <PropertyReference name="agent" type="ShallowRef<AbstractAgent | null>">
    持有 AG-UI 智能体实例的 Vue `shallowRef`。其公开类型包含 `null`，
    但当前实现会在 setup 期间同步解析：赋值一个已有智能体或临时代理，
    无法解析时抛出错误。在 `<script setup>` 中用 `agent.value` 读取，
    或在 `<template>` 中直接读取（自动解包）。下文示例保留了 `agent?.` /
    `v-if` 保护，因为调用方消费的是可空的公开类型。完整接口细节参见
    [AbstractAgent 文档](https://docs.ag-ui.com/sdk/js/client/abstract-agent)。

    以下属性和方法属于解包后的智能体（`agent.value`）。

    ### 核心属性

    <PropertyReference name="agentId" type="string | undefined">
      智能体实例的唯一标识符。
    </PropertyReference>

    <PropertyReference name="description" type="string">
      智能体用途的人类可读描述。
    </PropertyReference>

    <PropertyReference name="threadId" type="string">
      当前会话线程的唯一标识符。
    </PropertyReference>

    <PropertyReference name="messages" type="Message[]">
      会话消息数组。每条消息都是一个 AG-UI `Message`。常见字段：
      - `id: string` - 消息的唯一标识符
      - `role: "user" | "assistant" | "system" | "tool" | "developer"` - 消息角色（每条消息的形态随角色而异；例如 `tool` 消息携带 `toolCallId` 而非普通 `content`）
      - `content: string` - 消息内容（文本消息）
    </PropertyReference>

    <PropertyReference name="state" type="any">
      在应用与智能体之间同步的共享状态对象。双方都可读取和修改此状态。
    </PropertyReference>

    <PropertyReference name="isRunning" type="boolean">
      指示智能体当前是否正在执行。
    </PropertyReference>

    ### 方法

    <PropertyReference name="runAgent" type="(parameters?: RunAgentParameters, subscriber?: AgentSubscriber) => Promise<RunAgentResult>">
      低层方法：向智能体发送一次运行，并在运行结束后以 `RunAgentResult`
      （`{ result, newMessages }`）兑现。`result` 是运行的最终值，
      `newMessages` 是运行期间产生的消息。

      它不会发送你注册的前端工具或上下文，不会执行前端工具调用，
      也不会串联后续运行。正常运行请改用
      [`useCopilotKit`](/reference/vue/hooks/useCopilotKit) 中的
      `copilotkit.value.runAgent({ agent: agent.value })`。
      它接受相同的 `forwardedProps`，并以相同的 `RunAgentResult` 兑现。
      与 `agent.runAgent()` 不同，运行本身失败时它不会拒绝（reject）。
      核心会将错误（代码 `AGENT_RUN_FAILED`）报告给它的错误订阅者，
      并以 `{ result: undefined, newMessages: [] }` 兑现。

      **参数**：
      - `parameters.forwardedProps?: any` - 传给智能体执行上下文的数据

      要应答中断，请使用 [`useInterrupt`](/reference/vue/hooks/useInterrupt)，
      它会替你恢复运行。要手动恢复，请传入标准 `resume` 数组并带上暂停运行
      所报告的中断 id：
      `copilotkit.value.runAgent({ agent: agent.value, resume: [{ interruptId: interrupt.id, status: "resolved", payload }] })`。
      较旧的 `forwardedProps: { command: { resume } }` 形式是
      `on_interrupt` 自定义事件的旧版路径。

      **示例**：
      ```ts
      const { copilotkit } = useCopilotKit();

      if (agent.value) {
        const { result, newMessages } = await copilotkit.value.runAgent({
          agent: agent.value,
          // Any data your agent reads from the run input.
          forwardedProps: { source: "refresh-button" },
        });
      }
      ```
    </PropertyReference>

    <PropertyReference name="setState" type="(newState: any) => void">
      更新共享状态。更改对应用和智能体都立即可见。

      **示例**：
      ```ts
      agent.value.setState({
        ...agent.value.state,
        theme: "dark",
      });
      ```
    </PropertyReference>

    <PropertyReference name="subscribe" type="(subscriber: AgentSubscriber) => { unsubscribe: () => void }">
      订阅智能体事件。返回清理句柄。

      **订阅者事件**：
      - `onCustomEvent?: ({ event: { name: string, value: any } }) => void` - 自定义事件
      - `onRunStartedEvent?: () => void` - 智能体执行开始
      - `onRunFinalized?: () => void` - 智能体执行完成
      - `onStateChanged?: (params: { state: any, messages: Message[], agent: AbstractAgent }) => void` - 状态变化（从 `params.state` 读取新状态）
      - `onMessagesChanged?: (params: { messages: Message[], state: any, agent: AbstractAgent }) => void` - 消息新增或修改（从 `params.messages` 读取）
    </PropertyReference>

    <PropertyReference name="addMessage" type="(message: Message) => void">
      向会话添加一条消息并通知订阅者。
    </PropertyReference>

    <PropertyReference name="addMessages" type="(messages: Message[]) => void">
      向会话添加多条消息并只通知订阅者一次。
    </PropertyReference>

    <PropertyReference name="setMessages" type="(messages: Message[]) => void">
      用新的消息数组替换整个消息历史。
    </PropertyReference>

    <PropertyReference name="abortRun" type="() => void">
      中止当前正在运行的智能体执行。
    </PropertyReference>

    <PropertyReference name="clone" type="() => AbstractAgent">
      创建智能体的深拷贝，消息、状态和配置均被克隆。
    </PropertyReference>

  </PropertyReference>
</PropertyReference>

## 用法

### 基本用法

```vue
<script setup lang="ts">
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <div v-if="agent">
    <div>Agent: {{ agent.agentId }}</div>
    <div>Messages: {{ agent.messages.length }}</div>
    <div>Running: {{ agent.isRunning ? "Yes" : "No" }}</div>
  </div>
</template>
```

### 访问与更新状态

```vue
<script setup lang="ts">
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();

function updateState() {
  if (!agent.value) return;
  agent.value.setState({ ...agent.value.state, count: 1 });
}
</script>

<template>
  <div>
    <pre>{{ JSON.stringify(agent?.state, null, 2) }}</pre>
    <button @click="updateState">Update State</button>
  </div>
</template>
```

### 事件订阅

```vue
<script setup lang="ts">
import { watchEffect } from "vue";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();

watchEffect((onCleanup) => {
  if (!agent.value) return;
  const { unsubscribe } = agent.value.subscribe({
    onRunStartedEvent: () => console.log("Started"),
    onRunFinalized: () => console.log("Finished"),
  });

  onCleanup(unsubscribe);
});
</script>

<template>
  <div />
</template>
```

### 多智能体

```vue
<script setup lang="ts">
import { useAgent } from "@copilotkit/vue/v2";

const { agent: primary } = useAgent({ agentId: "primary" });
const { agent: support } = useAgent({ agentId: "support" });
</script>

<template>
  <div>
    <div>Primary: {{ primary?.messages?.length ?? 0 }} messages</div>
    <div>Support: {{ support?.messages?.length ?? 0 }} messages</div>
  </div>
</template>
```

### 线程作用域智能体

```vue
<script setup lang="ts">
import { ref } from "vue";
import { useAgent } from "@copilotkit/vue/v2";

const threadId = ref("thread-1");

// Registers a local proxy routed to the runtime agent and pins it to this thread.
const { agent } = useAgent({
  agentId: "thread-1",
  runtimeAgentId: "default",
  threadId,
});
</script>

<template>
  <div v-if="agent">Thread: {{ agent.threadId }} ({{ agent.messages.length }} messages)</div>
</template>
```

### 优化响应式更新

```vue
<script setup lang="ts">
import { useAgent, UseAgentUpdate } from "@copilotkit/vue/v2";

// Only update when messages change.
const { agent } = useAgent({
  updates: [UseAgentUpdate.OnMessagesChanged],
});
</script>

<template>
  <div>Messages: {{ agent?.messages?.length ?? 0 }}</div>
</template>
```

### 节流高频更新

```ts
import { useAgent } from "@copilotkit/vue/v2";

// Coalesce streaming message and state updates into at most one update
// per 100ms. Run lifecycle callbacks still fire immediately.
const { agent } = useAgent({ throttleMs: 100 });
```

## 行为

- **响应式更新**：`agent` 引用会在状态、消息或执行状态变化时触发响应（可通过 `updates` 参数配置）。
- **响应式输入**：`agentId` 和 `runtimeAgentId` 驱动私有代理注册；`agentId` 加上核心注册表与连接变化驱动解析。`threadId` 固定或重新固定当前智能体。`updates`、`throttleMs` 和提供方的 `defaultThrottleMs` 驱动订阅行为。
- **智能体绑定**：共享智能体形式按显式 `agentId`、聊天配置的 `agentId`、`DEFAULT_AGENT_ID` 的顺序解析，并可能返回运行时发现的智能体或提供方注册的智能体。线程作用域形式在本地 `agentId` 下注册私有代理，将其路由到 `runtimeAgentId`，并把 `threadId` 固定到该代理。三个线程作用域属性必须一起提供；更改 `threadId` 会重新固定现有代理。
- **节流**：消息与状态更新可通过 `throttleMs` 节流，解析规则为 `throttleMs ?? provider defaultThrottleMs ?? 0`。运行生命周期回调始终立即触发。
- **错误处理**：如果运行时同步后仍无法为指定 `agentId` 解析出智能体，则抛出错误。
- **状态同步**：通过 `setState()` 进行的状态更新对应用和智能体都立即可用。
