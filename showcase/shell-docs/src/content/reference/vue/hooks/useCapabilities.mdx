## 概览

`useCapabilities` 返回某个智能体声明的 [AG-UI `AgentCapabilities`](https://docs.ag-ui.com/concepts/capabilities)。能力描述了智能体支持什么：工具调用、流式传输、多智能体协作、人机协同（human-in-the-loop）等等。

能力来自连接时运行时的 `/info` 响应。在运行时握手完成之前，或智能体未声明能力时，该值为 `undefined`。

<Callout type="info">
  该组合式函数返回一个 Vue `ComputedRef`。在 `<script setup>` 中通过 `.value` 读取，或在 `<template>` 中直接自动解包。ref 保持响应式，因此一旦运行时握手填充了能力，它就会自动更新。
</Callout>

## 签名

```ts
import { useCapabilities } from "@copilotkit/vue/v2";

function useCapabilities(agentId?: string): ComputedRef<AgentCapabilities | undefined>
```

## 参数

<PropertyReference name="agentId" type="string" default='"default"'>
  要读取其能力的智能体 ID。省略时使用默认智能体。与 `useAgent` / `useThreads` / `useSuggestions` 不同，这个参数是组合式函数运行时一次性捕获的普通 `string`——它不是 `MaybeRefOrGetter`，也不会响应变化。若要在运行时读取另一个智能体的能力，请重新挂载组件（例如使用会变化的 `:key`）。
</PropertyReference>

## 返回值

<PropertyReference name="capabilities" type="ComputedRef<AgentCapabilities | undefined>">
  一个计算属性 ref，持有该智能体的能力声明；如果智能体尚未上报能力（例如运行时握手仍在进行中）或未声明任何能力，则为 `undefined`。该组合式函数直接读取智能体的 `capabilities` 属性，不会调用 `getCapabilities()`。

  有值时，解包后的对象包含以下可选类别：

  <PropertyReference name="identity" type="IdentityCapabilities">
    智能体元数据：`name`、`type`（框架）、`description`、`version`、`provider`、`documentationUrl`、`metadata`。
  </PropertyReference>

  <PropertyReference name="transport" type="TransportCapabilities">
    支持的传输方式：`streaming`、`websocket`、`httpBinary`、`pushNotifications`、`resumable`。
  </PropertyReference>

  <PropertyReference name="tools" type="ToolsCapabilities">
    工具支持：`supported`、`items`、`parallelCalls`、`clientProvided`。
  </PropertyReference>

  <PropertyReference name="output" type="OutputCapabilities">
    输出格式：`structuredOutput`、`supportedMimeTypes`。
  </PropertyReference>

  <PropertyReference name="state" type="StateCapabilities">
    状态管理：`snapshots`、`deltas`、`memory`、`persistentState`。
  </PropertyReference>

  <PropertyReference name="multiAgent" type="MultiAgentCapabilities">
    多智能体协作：`supported`、`delegation`、`handoffs`、`subAgents`。
  </PropertyReference>

  <PropertyReference name="reasoning" type="ReasoningCapabilities">
    推理/思考过程可见性：`supported`、`streaming`、`encrypted`。
  </PropertyReference>

  <PropertyReference name="multimodal" type="MultimodalCapabilities">
    多模态输入/输出：`input` 与 `output` 子对象，涵盖图像、音频、视频、PDF 与文件支持。
  </PropertyReference>

  <PropertyReference name="execution" type="ExecutionCapabilities">
    代码执行：`codeExecution`、`sandboxed`、`maxIterations`、`maxExecutionTime`。
  </PropertyReference>

  <PropertyReference name="humanInTheLoop" type="HumanInTheLoopCapabilities">
    人机协同：`supported`、`approvals`、`interventions`、`feedback`。
  </PropertyReference>

  <PropertyReference name="custom" type="Record<string, unknown>">
    任意键值对，用于集成特有的能力。
  </PropertyReference>
</PropertyReference>

## 用法

### 基于能力条件渲染 UI

```vue title="ToolPanel.vue"
<script setup lang="ts">
import { useCapabilities } from "@copilotkit/vue/v2";

const capabilities = useCapabilities();
</script>

<template>
  <!-- Hide the panel when the agent doesn't support tools -->
  <div v-if="capabilities?.tools?.supported">
    <h3>Tools</h3>
    <p v-if="capabilities.tools.clientProvided">
      This agent accepts client-provided tools.
    </p>
  </div>
</template>
```

### 读取指定智能体的能力

```vue title="AgentInfo.vue"
<script setup lang="ts">
import { useCapabilities } from "@copilotkit/vue/v2";

const props = defineProps<{ agentId: string }>();

const capabilities = useCapabilities(props.agentId);
</script>

<template>
  <p v-if="!capabilities">Loading capabilities...</p>
  <ul v-else>
    <li>Streaming: {{ capabilities.transport?.streaming ? "Yes" : "No" }}</li>
    <li>Tools: {{ capabilities.tools?.supported ? "Yes" : "No" }}</li>
    <li>Human-in-the-loop: {{ capabilities.humanInTheLoop?.supported ? "Yes" : "No" }}</li>
  </ul>
</template>
```

### 在脚本中读取值

由于该组合式函数返回 `ComputedRef`，在模板之外（例如 `watch` 或计算属性内部）需通过 `.value` 访问值：

```ts
import { watch } from "vue";
import { useCapabilities } from "@copilotkit/vue/v2";

const capabilities = useCapabilities();

watch(capabilities, (caps) => {
  if (caps?.tools?.supported) {
    console.log("Agent supports tools");
  }
});
```

## 行为

- **同步读取**。该组合式函数通过 [`useAgent`](/reference/vue/hooks/useAgent) 直接从智能体实例读取 `capabilities`。没有单独的加载状态或异步请求：在运行时 `/info` 握手填充之前，值为 `undefined`，之后变为有值。
- **响应式计算属性**。底层的智能体 ref 变化时，返回的 `ComputedRef` 会重新计算，因此能力一到，组件（或侦听器）就会更新。
