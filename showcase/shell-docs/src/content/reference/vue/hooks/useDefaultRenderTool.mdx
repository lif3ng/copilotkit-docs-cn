## 概览

`useDefaultRenderTool` 是一个 Vue 3 便捷组合式函数，是对 [`useRenderTool`](/reference/vue/hooks/useRenderTool) 的轻量包装，内部使用 `name: "*"`。它为没有特定命名渲染器的工具调用注册一个兜底渲染器。

- 不传配置时，它注册 CopilotKit 内置的默认工具调用 UI：一张可展开的卡片，显示工具名称、状态、参数和结果。
- 传入 `render` 配置时，它会用你自己的通配符渲染器替换该默认 UI。

在 Vue 中，渲染器是一个 Vue 渲染函数或 Vue 组件（不是 JSX）。它返回 `VNodeChild`（Vue 能渲染的任何东西：VNode、字符串、VNode 数组、`null` 等）。无论底层调用点传入什么形态，你的渲染器始终会收到文档所述的 `DefaultRenderProps`。

<Callout type="info">
  `useDefaultRenderTool` 必须在能访问 `CopilotKitProvider` 所提供 CopilotKit 实例的组件中调用。与所有 Vue 组合式函数一样，应在 `<script setup>` 或 `setup()` 函数内同步调用，使其响应式作用域绑定到组件生命周期。
</Callout>

## 签名

```ts
import { useDefaultRenderTool } from "@copilotkit/vue/v2";
import type { Component, VNodeChild, WatchSource } from "vue";

type DefaultRenderProps = {
  name: string;
  toolCallId: string;
  parameters: unknown;
  status: "inProgress" | "executing" | "complete";
  result: string | undefined;
};

function useDefaultRenderTool(
  config?: {
    render?:
      | ((props: DefaultRenderProps) => VNodeChild)
      | Component<DefaultRenderProps>;
  },
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="config" type="{ render?: RenderFn | Component }">
  可选配置。完全省略它即可注册内置的默认工具调用卡片。

  <PropertyReference name="render" type="((props: DefaultRenderProps) => VNodeChild) | Component<DefaultRenderProps>">
    一个 Vue 渲染函数或 Vue 组件，用于渲染任何未被处理的工具调用。渲染函数接收 `DefaultRenderProps` 并返回 `VNodeChild`；组件则以 `DefaultRenderProps` 作为 props。省略时使用 CopilotKit 内置的可展开卡片。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的响应式依赖。它们会被转发给 `useRenderTool` 并加入内部 `watch` 源，因此其中任何一项变化时渲染器都会重新注册。传入 ref、计算属性或 getter 函数，与任何 Vue `WatchSource` 一样。
</PropertyReference>

## DefaultRenderProps

渲染器收到的 props。它们由框架内部的渲染器 props 规范化而来，因此 `parameters` 始终有值（必要时从 `args` 取得），`status` 始终是下面的字符串联合类型（由 `ToolCallStatus` 枚举映射而来）。

<PropertyReference name="name" type="string">
  被调用工具的名称。
</PropertyReference>

<PropertyReference name="toolCallId" type="string">
  本次工具调用的唯一标识符。
</PropertyReference>

<PropertyReference name="parameters" type="unknown">
  传给工具的参数。调用还在流式传输（`inProgress`）时，可能只是部分内容。
</PropertyReference>

<PropertyReference name="status" type='"inProgress" | "executing" | "complete"'>
  工具调用的生命周期状态。参数还在流入时为 `inProgress`；参数完整且工具开始运行时为 `executing`；有结果可用时为 `complete`。
</PropertyReference>

<PropertyReference name="result" type="string | undefined">
  工具的结果。`status` 为 `complete` 之前为 `undefined`。
</PropertyReference>

## 用法

### 内置默认渲染器

不带参数调用组合式函数，即可注册 CopilotKit 内置的可展开工具调用卡片。

```vue
<script setup lang="ts">
import { useDefaultRenderTool } from "@copilotkit/vue/v2";

useDefaultRenderTool();
</script>

<template>
  <!-- Unhandled tool calls render with the built-in default card -->
</template>
```

### 自定义通配符渲染器（渲染函数）

提供一个 `render` 函数。它接收 `DefaultRenderProps` 并返回 `VNodeChild`。用 Vue 的 `h` 辅助函数构建 VNode。

```vue
<script setup lang="ts">
import { h } from "vue";
import { useDefaultRenderTool } from "@copilotkit/vue/v2";

useDefaultRenderTool({
  render: ({ name, status, result }) =>
    h("div", [
      h("strong", name),
      `: ${status}`,
      status === "complete" && result ? h("pre", result) : null,
    ]),
});
</script>

<template>
  <!-- Unhandled tool calls render with the custom function above -->
</template>
```

### 自定义通配符渲染器（Vue 组件）

传入一个 Vue 组件而不是函数。它以 `DefaultRenderProps` 作为 props。用 `defineProps` 定义 `props`，让值具有类型。

```vue
<!-- ToolCallCard.vue -->
<script setup lang="ts">
defineProps<{
  name: string;
  toolCallId: string;
  parameters: unknown;
  status: "inProgress" | "executing" | "complete";
  result: string | undefined;
}>();
</script>

<template>
  <div :data-status="status">
    <strong>{{ name }}</strong>
    <span>{{ status }}</span>
    <pre v-if="status === 'complete' && result">{{ result }}</pre>
  </div>
</template>
```

```vue
<!-- App.vue -->
<script setup lang="ts">
import { useDefaultRenderTool } from "@copilotkit/vue/v2";
import ToolCallCard from "./ToolCallCard.vue";

useDefaultRenderTool({ render: ToolCallCard });
</script>

<template>
  <!-- Unhandled tool calls render with ToolCallCard -->
</template>
```

### 依赖变化时重新注册

传入响应式 `deps`，在其变化时重新注册渲染器。渲染器本身通常应当稳定，但渲染器闭包引用的任何响应式源都可以列在这里。

```vue
<script setup lang="ts">
import { h, ref } from "vue";
import { useDefaultRenderTool } from "@copilotkit/vue/v2";

const compact = ref(false);

useDefaultRenderTool(
  {
    render: ({ name, status }) =>
      compact.value
        ? h("span", `${name}: ${status}`)
        : h("div", [h("strong", name), h("span", status)]),
  },
  [compact],
);
</script>

<template>
  <button @click="compact = !compact">Toggle layout</button>
</template>
```

## 行为

- **通配符注册**：内部调用 `useRenderTool({ name: "*", render })`。`"*"` 名称匹配任何没有特定命名渲染器的工具调用。
- **默认 UI**：省略 `config.render` 时，会渲染一张可展开卡片。它显示工具名称、状态标签（进行中为 `Running`，完成时为 `Done`），展开后显示 JSON 字符串化的参数和结果。
- **prop 规范化**：你的 `render` 总会被包装，确保它收到文档所述的 `DefaultRenderProps`——无论调用点传入的是原始内部 props（`args` 加 `ToolCallStatus` 枚举）还是已适配的 props（`parameters` 加字符串联合状态）。渲染函数和组件都会以这种方式包装。
- **状态映射**：`ToolCallStatus` 枚举会映射为 `"inProgress" | "executing" | "complete"` 联合类型。未知或未来的枚举值会回退到 `"inProgress"`，并对每个不同取值记录一次 `console.warn`。
- **清理时不移除**：已注册的渲染器有意在清理时不被移除，这样聊天历史中过去的工具调用才能继续正确渲染。
- **返回值**：该组合式函数返回 `void`。
