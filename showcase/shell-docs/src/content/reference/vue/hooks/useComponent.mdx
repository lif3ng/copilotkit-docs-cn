## 概览

`useComponent` 是构建在 [`useFrontendTool`](/reference/vue/hooks/useFrontendTool) 之上的便捷组合式函数。它注册一个工具，并在聊天中渲染一个 Vue 组件，把工具调用参数作为组件的 props。

当你想要一个可视化的组件渲染器、又不想手动编写完整的前端工具配置时，用它即可。若需要更底层地控制渲染状态（进行中、执行中、已完成），或想用通配符渲染任意工具，请改用 [`useRenderTool`](/reference/vue/hooks/useRenderTool)。

<Callout type="info">
  从 `/v2` 子路径导入：`@copilotkit/vue/v2`。与所有 CopilotKit 组合式函数一样，`useComponent` 必须在 [`CopilotKitProvider`](/reference/vue/components/CopilotKitProvider) 后代组件内调用。
</Callout>

## 签名

```ts
import type { Component, WatchSource } from "vue";
import type { StandardSchemaV1 } from "@copilotkit/shared";
import { useComponent } from "@copilotkit/vue/v2";

function useComponent<TSchema extends StandardSchemaV1 | undefined = undefined>(
  config: {
    name: string;
    description?: string;
    parameters?: TSchema;
    // When parameters is provided, props are inferred from the schema output.
    // When omitted, the component accepts any props.
    render: Component<NoInfer<InferRenderProps<TSchema>>>;
    agentId?: string;
  },
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="config" type="object" required>
  组件工具的配置。

  <PropertyReference name="name" type="string" required>
    智能体调用此组件工具时使用的工具名称。
  </PropertyReference>

  <PropertyReference name="description" type="string">
    可选的额外描述，用于指导模型。它会被追加到一条默认指令之后（参见[行为](#行为)）。
  </PropertyReference>

  <PropertyReference name="parameters" type="StandardSchemaV1">
    可选的 [Standard Schema](https://standardschema.dev)（例如 Zod schema），用于对外声明的工具模式和带类型的参数。提供时，`render` 组件的 props 会从模式输出推断；运行时参数会经 JSON 解析，但不会按该模式校验。省略时，组件接受任意 props。
  </PropertyReference>

  <PropertyReference name="render" type="Component<NoInfer<InferRenderProps<TSchema>>>" required>
    一个 Vue 组件，以解析后的工具参数作为 props 进行渲染。这些参数会被展开为组件的 props。
  </PropertyReference>

  <PropertyReference name="agentId" type="string">
    可选的注册作用域，限定到某个智能体。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的响应式侦听源列表。其中任何一项变化时，注册会重新执行。`render` 捕获到的、需要刷新注册的响应式值都应列入其中（例如 `ref` 或 getter）。
</PropertyReference>

## 行为

- **默认指令**。组合式函数会在描述前附加一条默认指令：_"Use this tool to display the \"&lt;name&gt;\" component in the chat. This tool renders a visual UI component for the user."_。如果你提供了 `description`，它会被追加在其后。
- **构建于 `useFrontendTool` 之上**。它内部调用 [`useFrontendTool`](/reference/vue/hooks/useFrontendTool)，用一个渲染函数挂载你的组件（通过 Vue 的 `h`），并把工具的 `args` 展开为组件的 props。
- **继承的生命周期**。它继承 `useFrontendTool` 的行为：重名注册会记录覆盖警告并替换先前的工具；所属作用域销毁时，工具会被自动移除。
- **响应性**。注册对 `config.name` 和 `deps` 侦听源保持响应。你依赖的任何会变化的响应式值都应通过 `deps` 传入。

## 用法

为参数定义一个 Zod schema，编写一个以它们为 props 的 Vue 组件，然后用 `useComponent` 把两者一起注册。

```vue
<!-- WeatherCard.vue -->
<script setup lang="ts">
defineProps<{
  city: string;
  unit: "c" | "f";
}>();
</script>

<template>
  <div class="rounded border p-3">
    <div class="text-sm text-zinc-500">Weather request</div>
    <div class="font-medium">{{ city }} ({{ unit.toUpperCase() }})</div>
  </div>
</template>
```

```vue
<!-- App.vue -->
<script setup lang="ts">
import { z } from "zod";
import { useComponent } from "@copilotkit/vue/v2";
import WeatherCard from "./WeatherCard.vue";

const weatherCardSchema = z.object({
  city: z.string().describe("City name"),
  unit: z.enum(["c", "f"]).default("c"),
});

useComponent({
  name: "showWeatherCard",
  description: "Render a weather card in chat for the requested city.",
  parameters: weatherCardSchema,
  render: WeatherCard,
});
</script>
```

### 无参数

省略 `parameters` 时，组件接受任意 props，智能体可以不带任何参数调用该工具。

```vue
<script setup lang="ts">
import { useComponent } from "@copilotkit/vue/v2";
import LoadingSpinner from "./LoadingSpinner.vue";

useComponent({
  name: "showSpinner",
  render: LoadingSpinner,
});
</script>
```

### 响应式变化时刷新

通过 `deps` 传入响应式侦听源，捕获的值变化时注册便会重新执行。

```vue
<script setup lang="ts">
import { ref } from "vue";
import { z } from "zod";
import { useComponent } from "@copilotkit/vue/v2";
import WeatherCard from "./WeatherCard.vue";

// Pass any reactive watch sources the registration should track through `deps`;
// the tool is re-registered whenever one of them changes.
const refreshKey = ref(0);

useComponent(
  {
    name: "showWeatherCard",
    parameters: z.object({ city: z.string() }),
    render: WeatherCard,
  },
  [refreshKey],
);
</script>
```

<Callout type="info">
  `agentId` 在组合式函数运行时只读取一次，因此无法通过 `deps` 使其变为响应式。若要在运行时把组件限定到另一个智能体，请条件渲染调用 `useComponent` 的那个组件。
</Callout>
