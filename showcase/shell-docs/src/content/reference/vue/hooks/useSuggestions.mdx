## 概览

`useSuggestions` 提供对指定智能体当前聊天建议的响应式访问。它会订阅 CopilotKit core 上的建议变更事件，每当建议被添加、清空、重新加载或加载完成时，更新其返回的 ref。

建议通过 [`useConfigureSuggestions`](/reference/vue/hooks/useConfigureSuggestions) 配置，可以是静态的（预定义列表）或动态的（由智能体生成）。

<Callout type="info">
  `useSuggestions` 必须在能够访问 `CopilotKitProvider` 所提供 CopilotKit 实例的组件中调用。与所有 Vue 组合式函数一样，请在 `<script setup>` 或 `setup()` 函数中同步调用，使其订阅绑定到组件生命周期，并在组件卸载时自动清理。
</Callout>

## 签名

```ts
import { useSuggestions } from "@copilotkit/vue/v2";

function useSuggestions(options?: UseSuggestionsOptions): UseSuggestionsResult;
```

## 参数

<PropertyReference name="options" type="UseSuggestionsOptions">
  组合式函数的可选配置对象。

  <PropertyReference name="agentId" type="MaybeRefOrGetter<string | undefined>" default='"default"'>
    要获取其建议的智能体 ID。接受普通字符串、`ref` 或 getter 函数，因此解析出的智能体可以响应式变化。若省略（或解析为 `undefined`），会回退到最近聊天配置中的 `agentId`，再回退到默认智能体 ID（`"default"`）。
  </PropertyReference>
</PropertyReference>

## 返回值

该组合式函数返回一个由 Vue ref 与控制函数组成的对象。由于 `suggestions` 和 `isLoading` 是 ref，在 `<script setup>` 中需通过 `.value` 访问（在 `<template>` 中会自动解包）。

<PropertyReference name="result" type="UseSuggestionsResult">
  包含响应式建议状态与控制函数的对象。

<PropertyReference name="suggestions" type="Ref<Suggestion[]>">
  当前建议的响应式数组。每个 `Suggestion` 包含： - `title: string` —— 建议的简短显示标题。 - `message: string` —— 选中该建议时发送的消息内容。 - `isLoading: boolean` —— 该建议本身是否仍在生成中。 - `className?: string` —— 应用于建议胶囊（pill）的可选 CSS 类名。
</PropertyReference>

<PropertyReference name="isLoading" type="Ref<boolean>">
  响应式标志，表示当前是否正在为解析出的智能体生成或加载建议。
</PropertyReference>

<PropertyReference name="reloadSuggestions" type="() => void">
  触发重新加载解析出的智能体的建议。对动态建议而言，这会重新执行生成过程。`isLoading` ref 会通过订阅事件自动更新。
</PropertyReference>

  <PropertyReference name="clearSuggestions" type="() => void">
    清空解析出的智能体的所有当前建议。
  </PropertyReference>
</PropertyReference>

## 用法

### 基础用法

```vue
<script setup lang="ts">
import { useSuggestions } from "@copilotkit/vue/v2";

const { suggestions, isLoading } = useSuggestions();
</script>

<template>
  <div v-if="isLoading">Loading suggestions...</div>
  <ul v-else>
    <li v-for="(suggestion, i) in suggestions" :key="i">
      <strong>{{ suggestion.title }}</strong>
      <p>{{ suggestion.message }}</p>
    </li>
  </ul>
</template>
```

### 带刷新与清空控件

```vue
<script setup lang="ts">
import { useSuggestions } from "@copilotkit/vue/v2";

const { suggestions, reloadSuggestions, clearSuggestions, isLoading } =
  useSuggestions();
</script>

<template>
  <div>
    <div>
      <button :disabled="isLoading" @click="reloadSuggestions">Refresh</button>
      <button @click="clearSuggestions">Clear</button>
    </div>
    <button
      v-for="(suggestion, i) in suggestions"
      :key="i"
      :disabled="suggestion.isLoading"
    >
      {{ suggestion.title }}
    </button>
  </div>
</template>
```

### 面向特定智能体

```vue
<script setup lang="ts">
import { useSuggestions } from "@copilotkit/vue/v2";

const { suggestions } = useSuggestions({ agentId: "support-agent" });
</script>

<template>
  <div>
    <h3>Support Agent Suggestions</h3>
    <div v-for="(s, i) in suggestions" :key="i">{{ s.title }}</div>
  </div>
</template>
```

### 响应式智能体 ID

由于 `agentId` 接受 `ref` 或 getter，源变化时组合式函数会重新解析并重新订阅，自动切换为新智能体的建议。

```vue
<script setup lang="ts">
import { ref } from "vue";
import { useSuggestions } from "@copilotkit/vue/v2";

const activeAgentId = ref("default");

const { suggestions } = useSuggestions({ agentId: activeAgentId });
</script>

<template>
  <select v-model="activeAgentId">
    <option value="default">Default</option>
    <option value="support-agent">Support</option>
  </select>
  <div v-for="(s, i) in suggestions" :key="i">{{ s.title }}</div>
</template>
```

## 行为

- **响应式订阅**：该组合式函数订阅 CopilotKit core 上的建议事件（`onSuggestionsChanged`、`onSuggestionsStartedLoading`、`onSuggestionsFinishedLoading`、`onSuggestionsConfigChanged`），每当解析出的智能体的建议被添加、移除、更新或加载状态变化时更新其 ref。组件卸载时订阅会自动清理。
- **智能体解析**：解析出的智能体 ID 按以下优先级确定：`agentId` 选项（字符串、ref 或 getter），其次是最近聊天配置中的 `agentId`，最后是默认智能体 ID（`"default"`）。
- **变化时重新订阅**：当解析出的智能体 ID 或底层 CopilotKit 实例变化时，组合式函数会重新读取当前建议并重新订阅，使事件限定于新智能体。
- **加载状态**：动态建议重新加载开始时 `isLoading` 变为 `true`，生成完成后恢复为 `false`。
- **初始状态**：在 setup 时，组合式函数会同步从 core 实例读取当前建议与加载状态，因此静态建议不会出现不必要的加载闪烁。
