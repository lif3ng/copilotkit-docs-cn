## 概览

`useConfigureSuggestions` 向 CopilotKit 核心注册一条建议配置。它支持两种模式：**静态**建议（固定列表）和**动态**建议（由智能体根据指令生成）。

该配置在组合式函数的响应式作用域活跃期间持续注册，并在作用域清理（组件卸载）时自动移除。由于配置以响应式方式追踪，改变配置（或可选 `deps` 侦听源中的任何值）都会自动重新加载建议，无需手动清理。

<Callout type="info">
  `useConfigureSuggestions` 必须在能访问 `CopilotKitProvider` 所提供 CopilotKit 实例的组件中调用。与所有 Vue 组合式函数一样，应在 `<script setup>` 或 `setup()` 函数内同步调用，使其响应式作用域绑定到组件生命周期。
</Callout>

## 签名

```ts
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

function useConfigureSuggestions(
  config: SuggestionsConfigInput | null | undefined,
  deps?: WatchSource<unknown>[],
): void;
```

## 参数

<PropertyReference name="config" type="SuggestionsConfigInput | null | undefined">
  建议配置。传入 `null` 或 `undefined` 可禁用建议。可以是 `DynamicSuggestionsConfig` 或 `StaticSuggestionsConfigInput`。

  ### 动态配置

  用于需要由智能体在运行时生成建议的场景。

  <PropertyReference name="instructions" type="string" required>
    供模型生成建议所用的提示或指令。这是区分动态配置与静态配置的关键字段。
  </PropertyReference>

  <PropertyReference name="minSuggestions" type="number" default="1">
    要生成的建议数量下限。
  </PropertyReference>

  <PropertyReference name="maxSuggestions" type="number" default="3">
    要生成的建议数量上限。
  </PropertyReference>

  <PropertyReference
    name="available"
    type="SuggestionAvailability"
    default='"after-first-message"'
  >
    建议何时可用。选项：- `"before-first-message"`
    - 在发送任何消息之前显示建议。- `"after-first-message"` -
    在第一条消息之后显示建议（动态配置的默认值）。- `"always"` -
    始终显示建议。- `"disabled"` - 禁用建议。
  </PropertyReference>

  <PropertyReference name="providerAgentId" type="string" default='"default"'>
    生成建议的提供方智能体 ID。
  </PropertyReference>

  <PropertyReference name="consumerAgentId" type="string" default='"*"'>
    显示建议的消费方智能体 ID。默认为 `"*"`
    （所有智能体）。
  </PropertyReference>

  ### 静态配置

  用于建议是预定义列表的场景。

  <PropertyReference name="suggestions" type="StaticSuggestionInput[]" required>
    建议对象数组。每个建议包含：- `title: string` - 建议的简短显示标题。-
    `message: string` - 选中后发送的消息内容。- `isLoading?: boolean` -
    可选的加载状态（默认为 `false`）。- `className?: string` -
    应用到建议胶囊上的可选 CSS 类。
  </PropertyReference>

  <PropertyReference
    name="available"
    type="SuggestionAvailability"
    default='"before-first-message"'
  >
    建议何时可用。选项与动态配置相同。
  </PropertyReference>

  <PropertyReference name="consumerAgentId" type="string" default='"*"'>
    显示建议的消费方智能体 ID。默认为 `"*"`（所有智能体）。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="WatchSource<unknown>[]">
  可选的 Vue 侦听源数组（ref、计算属性或 getter 函数）。
  其中任何一个源变化时，建议都会重新加载。这对依赖外部响应式状态的动态建议很有用。
</PropertyReference>

## 用法

### 静态建议

```vue
<script setup lang="ts">
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

useConfigureSuggestions({
  suggestions: [
    { title: "Get started", message: "Help me get started with my project" },
    { title: "Show examples", message: "Show me some example use cases" },
    { title: "Documentation", message: "Where can I find the documentation?" },
  ],
  available: "before-first-message",
});
</script>

<template>
  <div>Suggestions configured</div>
</template>
```

### 动态建议

```vue
<script setup lang="ts">
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

useConfigureSuggestions({
  instructions:
    "Suggest follow-up questions based on the conversation so far. " +
    "Focus on actionable next steps the user might want to take.",
  maxSuggestions: 3,
  minSuggestions: 1,
  available: "after-first-message",
});
</script>

<template>
  <div>Smart suggestions enabled</div>
</template>
```

### 带响应式依赖的动态建议

将侦听源作为第二个参数传入，底层响应式状态变化时建议便会重新加载。

```vue
<script setup lang="ts">
import { ref } from "vue";
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

const reloadKey = ref(0);

// `deps` re-runs (reloads) suggestion generation whenever a watch source
// changes. The `config` -- including the `instructions` string -- is captured
// once when the composable runs and is not re-read.
useConfigureSuggestions(
  {
    instructions: "Suggest concise next steps based on the current conversation",
    maxSuggestions: 3,
  },
  [reloadKey],
);
</script>

<template>
  <button @click="reloadKey++">Refresh suggestions</button>
</template>
```

<Callout type="info">
  `config` 对象在组合式函数运行时从外围作用域一次性捕获。内部会将其序列化并加以侦听，因此如果配置的响应式内容发生变化，注册*确实*会重新执行——但由普通（非响应式）局部变量构成的配置永远不会变化，所以实践中它只被读取一次。用 `deps` 可以基于捕获的配置*重新加载*（重新生成）建议。若要在运行时更改 `instructions` 本身（例如注入一个响应式的主题），请重新挂载调用 `useConfigureSuggestions` 的组件——例如给它一个会变化的 `:key`——让组合式函数以新值重新运行。
</Callout>

### 条件禁用建议

传入 `null`（或 `available: "disabled"` 的配置）即可跳过注册配置。

```vue
<script setup lang="ts">
import { computed } from "vue";
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

const props = defineProps<{ enabled: boolean }>();

useConfigureSuggestions(
  props.enabled
    ? { suggestions: [{ title: "Help", message: "I need help" }] }
    : null,
);
</script>

<template>
  <div>Conditional suggestions</div>
</template>
```

<Callout type="info">
  与上面的动态配置一样，`enabled` 分支在组合式函数运行时只求值一次——之后再翻转 `props.enabled` 不会重新注册或移除配置。若要在运行时开启或关闭建议，请条件渲染调用 `useConfigureSuggestions` 的组件（例如用 `v-if`），让组合式函数重新运行，先前的配置也会在清理时移除。
</Callout>

### 面向特定智能体

```vue
<script setup lang="ts">
import { useConfigureSuggestions } from "@copilotkit/vue/v2";

useConfigureSuggestions({
  instructions: "Suggest data analysis tasks the user can perform.",
  maxSuggestions: 4,
  providerAgentId: "analyst",
  consumerAgentId: "analyst",
  available: "always",
});
</script>

<template>
  <div>Agent-specific suggestions</div>
</template>
```

## 行为

- **作用域生命周期**：配置在组合式函数的响应式作用域活跃期间通过 `addSuggestionsConfig` 注册到核心，并在作用域清理（组件卸载）时通过 `removeSuggestionsConfig` 移除。无需手动清理。
- **响应式变化检测**：钩子会把规范化后的配置序列化为 JSON 用于比较。序列化值变化时，注册会更新并触发重新加载。
- **依赖追踪**：提供 `deps` 侦听源数组时，这些源的任何变化都会触发建议重新加载，即使序列化后的配置本身没有变化。
- **配置判别**：钩子通过检查 `instructions` 属性是否存在来区分动态与静态配置。存在 `instructions` 即视为动态配置。
- **禁用状态**：传入 `null`、`undefined` 或 `available: "disabled"` 的配置，会移除先前注册的任何配置，并且不产生建议。
- **isLoading 规范化**：对于静态建议，`isLoading` 字段在未显式提供时默认为 `false`。
- **消费方解析**：`consumerAgentId` 为 `"*"`（或未设置）的配置被视为全局配置，对所有智能体生效；否则只作用于指定智能体。解析出的消费方会回退到聊天配置的 `agentId`，再回退到默认智能体 ID。
- **运行中重载**：对当前正在运行的智能体，全局重载会被推迟，待该次运行结束后再执行，因此建议不会在运行中途重载。
