## 概览

`CopilotSidebar` 渲染一个用于聊天交互的固定侧边栏面板。它包装了 [`CopilotChat`](/reference/vue/components/CopilotChat)，并提供侧边栏专属的布局与打开/关闭行为。侧边栏包含一个带标题和关闭按钮的页眉，并可通过浮动切换按钮开关。

由于它构建在 `CopilotChat` 之上，它会替你解析智能体、订阅消息与运行状态、管理建议，并接线输入与转写。通常你只需选择智能体，并可选地设置初始打开状态、宽度，或覆盖某个具名插槽。

<Callout type="info">
  `sidebar` 特性需要许可。未获得许可时，组件会渲染内联警告并输出控制台警告。
  详情请访问 [copilotkit.ai/pricing](https://copilotkit.ai/pricing)。
</Callout>

## 导入

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>
```

## 属性（Props）

所有响应式 props 都通过 `defineProps` 声明。`CopilotSidebar` 继承 `CopilotChat` 的 props（并透过它们继承 `CopilotChatView` 的 props），并新增两个自身 props。

### 自身 props

<PropertyReference name="defaultOpen" type="boolean" default="true">
  组件首次挂载时侧边栏是否打开。挂载后，打开/关闭状态由用户交互驱动
  （切换按钮和页眉的关闭按钮）。
</PropertyReference>

<PropertyReference name="width" type="number | string">
  侧边栏面板的宽度。接受数字（像素）或 CSS 字符串（例如 `"400px"` 或 `"30vw"`）。
  省略时使用默认面板宽度。
</PropertyReference>

### 继承自 CopilotChat 的 props

<PropertyReference name="agentId" type="string">
  要连接的智能体 ID。必须与 `CopilotKitProvider` 中配置的某个智能体匹配。
  省略时回退到外层 `CopilotChatConfigurationProvider` 的 `agentId`，
  再回退到默认智能体。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。传入特定线程 id 可恢复已有会话。省略时会在本地生成线程 id，
  并在智能体首次运行时创建新线程。
</PropertyReference>

<PropertyReference name="throttleMs" type="number">
  转发给 `useAgent` 的节流间隔（毫秒），用于在智能体流式输出时合并响应式更新。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  对聊天内所渲染文本字符串的部分标签覆盖（输入占位符、欢迎消息、页眉标题、
  工具栏按钮、免责声明等）。省略的标签回退到内置默认值。
</PropertyReference>

<PropertyReference name="attachments" type="AttachmentsConfig">
  文件附件的配置（接受的 MIME 类型、上传处理等）。设置后会启用添加文件操作
  和拖放，聊天会自动管理附件队列。
</PropertyReference>

<PropertyReference name="onError" type="(event: { error: Error; code: CopilotKitCoreErrorCode; context: Record<string, any> }) => void | Promise<void>">
  限定于此聊天智能体的错误处理器。除提供方级别的错误处理外还会触发。
</PropertyReference>

### 继承自 CopilotChatView 的 props

<PropertyReference name="autoScroll" type="AutoScrollMode | boolean" default="true">
  控制新消息流入时面板的滚动方式。接受 `"pin-to-bottom"` / `true`
  （位于底部时贴住底部）、`"pin-to-send"`（助手流式输出期间将最新用户消息
  锚定在顶部附近）或 `"none"` / `false`（从不自动滚动）。
</PropertyReference>

<PropertyReference name="welcomeScreen" type="boolean" default="true">
  在没有消息且未选择显式线程时是否显示欢迎屏。传 `false` 可禁用。
  覆盖 `welcome-screen` 插槽可完全自定义。
</PropertyReference>

<PropertyReference name="inputValue" type="string">
  聊天输入区的受控值。提供时，聊天将输入视为受控，
  并通过 `input-change` 事件回传变更。
</PropertyReference>

<PropertyReference name="inputMode" type='"input" | "transcribe" | "processing"' default='"input"'>
  初始输入模式。组件会在音频转写期间管理这些模式之间的切换。
</PropertyReference>

<PropertyReference name="inputToolsMenu" type='(ToolsMenuItem | "-")[]' default="[]">
  输入区工具菜单的菜单项。每一项包含 `label`，以及 `action` 回调或嵌套
  `items` 二者之一；使用 `"-"` 作分隔线。
</PropertyReference>

<PropertyReference name="onFinishTranscribeWithAudio" type="(audioBlob: Blob) => void | Promise<void>">
  转写完成时以录制的音频 blob 调用的自定义处理器。省略时，
  音频会使用所配置的运行时进行转写并追加到输入区。
</PropertyReference>

## 事件（Events）

`CopilotSidebar` 会转发 `CopilotChat` 的聊天事件（在模板中用 `@event-name` 监听）。除组件内部处理外，这些事件也会触发。

| 事件                | 负载                                     | 触发时机             |
| ------------------- | ---------------------------------------- | -------------------- |
| `submit-message`    | `value: string`                          | 提交了消息           |
| `stop`              | 无                                       | 按下了停止按钮       |
| `input-change`      | `value: string`                          | 输入值变化           |
| `select-suggestion` | `suggestion: Suggestion, index: number`  | 选中了建议胶囊       |
| `add-file`          | 无                                       | 触发了添加文件操作   |
| `start-transcribe`  | 无                                       | 音频转写开始         |
| `cancel-transcribe` | 无                                       | 音频转写被取消       |
| `finish-transcribe` | 无                                       | 音频转写结束         |

## 插槽（Slots）

Vue 使用具名插槽替代 React 的 render props 与子组件 props。提供插槽即可替换侧边栏的相应部分。每个插槽都接收可用 `v-slot` 解构的作用域属性。

<PropertyReference name="header" type="{ title: string; onClose: () => void; isOpen: boolean }">
  替换默认侧边栏页眉。接收解析后的 `title`、`onClose` 回调以及当前 `isOpen` 状态。
  默认页眉显示标题和关闭按钮。
</PropertyReference>

<PropertyReference name="toggle-button" type="{ isOpen: boolean; toggle: () => void; open: () => void; close: () => void }">
  替换默认浮动切换按钮。接收当前 `isOpen` 状态，以及用于控制面板的
  `toggle`、`open` 和 `close` 回调。
</PropertyReference>

<PropertyReference name="chat-view" type="CopilotChatViewOverrideSlotProps">
  替换整个内侧边栏视图。接收全部组合的视图状态与处理器
  （`messages`、`isRunning`、`suggestions`、`inputValue`、`onSubmitMessage`、
  `onSelectSuggestion`、`onStop`、转写与附件处理器等），
  因此你可以渲染完全自定义的布局。
</PropertyReference>

<PropertyReference name="message-view" type="{ messages: Message[]; isRunning: boolean }">
  替换默认的消息列表渲染。
</PropertyReference>

<PropertyReference name="input" type="CopilotSidebarWelcomeScreenInputSlotProps">
  替换默认聊天输入区。接收 `modelValue`、`isRunning`、`inputMode`、
  `inputToolsMenu`，以及 `onUpdateModelValue`、`onSubmitMessage`、`onStop`
  和转写回调等处理器。
</PropertyReference>

<PropertyReference name="suggestion-view" type="CopilotSidebarWelcomeScreenSuggestionViewSlotProps">
  替换默认建议胶囊。接收 `suggestions`、`loadingIndexes` 和 `onSelectSuggestion`。
</PropertyReference>

<PropertyReference name="welcome-screen" type="CopilotChatWelcomeScreenSlotProps">
  替换没有消息时显示的默认侧边栏欢迎屏。接收建议属性以及输入模型值与提交处理器。
</PropertyReference>

<PropertyReference name="welcome-message" type="() => unknown">
  仅替换默认欢迎屏内的标题文本，保持周围布局不变。
</PropertyReference>

<Callout type="info">
  侧边栏欢迎屏的布局是：建议在顶部、欢迎消息居中、输入区固定在底部。
  覆盖 `welcome-screen` 插槽可整体替换此布局，覆盖 `welcome-message`
  则只更改问候语。
</Callout>

## 用法

### 基本用法

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotSidebar
    agent-id="my-agent"
    :labels="{ chatInputPlaceholder: 'Ask me anything...' }"
  />
</template>
```

### 挂载时关闭并自定义宽度

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotSidebar agent-id="my-agent" :default-open="false" :width="500" />
</template>
```

### 自定义页眉

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotSidebar agent-id="my-agent">
    <template #header="{ title, onClose }">
      <div class="flex items-center justify-between bg-indigo-700 px-4 py-3 text-white">
        <span>{{ title }}</span>
        <button @click="onClose">Close</button>
      </div>
    </template>
  </CopilotSidebar>
</template>
```

### 自定义切换按钮

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotSidebar agent-id="my-agent">
    <template #toggle-button="{ isOpen, toggle }">
      <button class="fixed bottom-6 right-6" @click="toggle">
        {{ isOpen ? "Close chat" : "Open chat" }}
      </button>
    </template>
  </CopilotSidebar>
</template>
```

### 监听事件

```vue
<script setup lang="ts">
import { CopilotSidebar } from "@copilotkit/vue/v2";

function onSubmit(value: string) {
  console.log("user submitted:", value);
}
</script>

<template>
  <CopilotSidebar agent-id="my-agent" @submit-message="onSubmit" />
</template>
```
