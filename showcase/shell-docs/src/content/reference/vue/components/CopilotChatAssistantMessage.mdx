## 概览

`CopilotChatAssistantMessage` 是一个 Vue 3 组件，用于展示支持 Markdown、工具调用渲染与操作工具栏的助手消息。Markdown 由 `streamdown-vue`（`StreamMarkdown`）渲染，支持 GitHub Flavored Markdown 表格、数学表达式（自动加载 KaTeX 样式），以及通过 Shiki 实现语法高亮的代码块（`github-light` / `github-dark` 主题）。表格与代码块内置复制和下载操作，图片则带有悬停下载按钮。

工具栏提供复制、点赞、点踩、朗读与重新生成按钮。工具提示与 aria 标签取自最近的 `CopilotChatConfigurationProvider`（参见 [`useCopilotChatConfiguration`](/reference/vue/hooks/useCopilotChatConfiguration)）。点赞、点踩、朗读与重新生成按钮只有在挂接了对应事件的监听器时才会渲染；只要工具栏可见，复制按钮始终显示。

<Callout type="info">
  当最新一条助手消息仍在流式输出时（最后一条消息的 `isRunning` 为 `true`），
  以及消息没有文本内容时，工具栏会被隐藏。工具栏还会遵循 `toolbarVisible` prop。
</Callout>

## 导入

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
</script>
```

## 示例

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

const message: AssistantMessage = {
  id: "1",
  role: "assistant",
  content: "Here is **Markdown** with a `code` sample.",
};
</script>

<template>
  <CopilotChatAssistantMessage
    :message="message"
    @thumbs-up="(msg) => console.log('Thumbs up:', msg.id)"
    @thumbs-down="(msg) => console.log('Thumbs down:', msg.id)"
  />
</template>
```

## 属性（Props）

<PropertyReference name="message" type="AssistantMessage" required>
  要渲染的助手消息对象。包含消息的 `content`、`id`、`role` 以及所有关联的
  工具调用。类型为 `text` 的数组内容部分会以换行符拼接；其他内容类型会被忽略。
</PropertyReference>

<PropertyReference name="messages" type="Message[]" default="[]">
  完整的会话消息数组。会透传给工具调用视图以实现上下文感知渲染，并用于判断
  本消息是否为最新的助手消息（这决定流式输出期间工具栏的可见性）。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean" default="false">
  智能体当前是否正在执行。为 `true` 时，最新助手消息的工具栏会被隐藏，
  以免在流式输出中途出现。
</PropertyReference>

<PropertyReference name="toolbarVisible" type="boolean" default="true">
  控制操作工具栏是否可见。设为 `false` 时，无论挂接了哪些事件监听器，
  工具栏都会完全隐藏。
</PropertyReference>

## 事件（Events）

每个事件都会以当前 `message` 作为载荷发出。为 `thumbs-up`、`thumbs-down`、
`read-aloud` 或 `regenerate` 挂接监听器还会让对应的工具栏按钮渲染出来；
没有监听器时则不渲染该按钮。

<PropertyReference name="thumbs-up" type="(message: AssistantMessage) => void">
  用户点击点赞按钮时发出。只有挂接了监听器时按钮才会出现。
</PropertyReference>

<PropertyReference name="thumbs-down" type="(message: AssistantMessage) => void">
  用户点击点踩按钮时发出。只有挂接了监听器时按钮才会出现。
</PropertyReference>

<PropertyReference name="read-aloud" type="(message: AssistantMessage) => void">
  用户点击朗读按钮时发出。只有挂接了监听器时按钮才会出现。
</PropertyReference>

<PropertyReference name="regenerate" type="(message: AssistantMessage) => void">
  用户点击重新生成按钮时发出。只有挂接了监听器时按钮才会出现。
</PropertyReference>

<Callout type="info">
  把消息复制到剪贴板由复制按钮在内部处理。没有 `copy` 事件；只要工具栏可见，
  复制按钮始终存在。
</Callout>

## 插槽（Slots）

该组件暴露了多个具名插槽，让你可以覆盖默认布局的各个部分。每个插槽都会接收
作用域 props（如下所示），把自身行为接到消息与工具栏处理器上。

<PropertyReference name="layout" type="slot">
  替换整个组件布局。接收 `message`、`content`、`is-running`、`toolbar-visible`、
  `should-show-toolbar`，嵌套的插槽渲染函数（`message-renderer`、`toolbar`、
  `copy-button`、`thumbs-up-button`、`thumbs-down-button`、`read-aloud-button`、
  `regenerate-button`、`tool-calls-view`），以及 `on-copy`、`on-thumbs-up`、
  `on-thumbs-down`、`on-read-aloud` 与 `on-regenerate` 处理器。
</PropertyReference>

<PropertyReference name="message-renderer" type="slot">
  替换 Markdown 渲染器。接收 `message` 与 `content`（归一化后的文本）。
  可用它把 `StreamMarkdown` 换成自定义渲染器。
</PropertyReference>

<PropertyReference name="tool-calls-view" type="slot">
  替换工具调用视图。接收 `message` 与 `messages`。默认为
  `CopilotChatToolCallsView`，它会使用最近的已注册工具渲染器来渲染该消息的
  工具调用。
</PropertyReference>

<PropertyReference name="toolbar" type="slot">
  替换操作工具栏容器。接收 `message` 与 `should-show-toolbar`。
  只在应当显示工具栏时渲染。
</PropertyReference>

<PropertyReference name="copy-button" type="slot">
  替换复制到剪贴板按钮。接收 `on-copy`、`copied`（复制状态当前是否激活）
  与 `label`。
</PropertyReference>

<PropertyReference name="thumbs-up-button" type="slot">
  替换点赞按钮。接收 `on-thumbs-up` 与 `label`。只有挂接了 `thumbs-up`
  监听器时才渲染。
</PropertyReference>

<PropertyReference name="thumbs-down-button" type="slot">
  替换点踩按钮。接收 `on-thumbs-down` 与 `label`。只有挂接了 `thumbs-down`
  监听器时才渲染。
</PropertyReference>

<PropertyReference name="read-aloud-button" type="slot">
  替换朗读按钮。接收 `on-read-aloud` 与 `label`。只有挂接了 `read-aloud`
  监听器时才渲染。
</PropertyReference>

<PropertyReference name="regenerate-button" type="slot">
  替换重新生成按钮。接收 `on-regenerate` 与 `label`。只有挂接了 `regenerate`
  监听器时才渲染。
</PropertyReference>

<PropertyReference name="toolbar-items" type="slot">
  追加在工具栏默认按钮之后。可用它添加自定义工具栏操作。不接收任何作用域 props。
</PropertyReference>

## 用法

### 基本助手消息

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();
</script>

<template>
  <CopilotChatAssistantMessage
    :message="message"
    @thumbs-up="(msg) => console.log('Thumbs up:', msg.id)"
    @thumbs-down="(msg) => console.log('Thumbs down:', msg.id)"
  />
</template>
```

### 添加重新生成与朗读

挂接这些监听器后，对应按钮会自动出现。

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();

function handleRegenerate(msg: AssistantMessage) {
  // re-run the agent for this message
}

function handleReadAloud(msg: AssistantMessage) {
  // speak msg.content
}
</script>

<template>
  <CopilotChatAssistantMessage
    :message="message"
    @regenerate="handleRegenerate"
    @read-aloud="handleReadAloud"
  />
</template>
```

### 添加自定义工具栏项

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();
</script>

<template>
  <CopilotChatAssistantMessage :message="message">
    <template #toolbar-items>
      <button type="button" @click="shareMessage(message)">Share</button>
    </template>
  </CopilotChatAssistantMessage>
</template>
```

### 隐藏工具栏

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();
</script>

<template>
  <CopilotChatAssistantMessage :message="message" :toolbar-visible="false" />
</template>
```

### 自定义 Markdown 渲染器

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();
</script>

<template>
  <CopilotChatAssistantMessage :message="message">
    <template #message-renderer="{ content }">
      <div class="custom-markdown">{{ content }}</div>
    </template>
  </CopilotChatAssistantMessage>
</template>
```

### 自定义工具栏按钮

```vue
<script setup lang="ts">
import { CopilotChatAssistantMessage } from "@copilotkit/vue/v2";
import type { AssistantMessage } from "@ag-ui/core";

defineProps<{ message: AssistantMessage }>();
</script>

<template>
  <CopilotChatAssistantMessage
    :message="message"
    @regenerate="(msg) => regenerate(msg)"
  >
    <template #regenerate-button="{ onRegenerate, label }">
      <button type="button" :title="label" @click="onRegenerate">
        Regenerate
      </button>
    </template>
  </CopilotChatAssistantMessage>
</template>
```
