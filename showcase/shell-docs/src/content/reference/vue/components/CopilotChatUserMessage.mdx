title: "CopilotChatUserMessage"
description: "用于展示用户消息的 Vue 3 组件，支持复制、编辑与分支导航。"
---

<Callout type="info">
  这是 Vue 3 组件，请从 `@copilotkit/vue/v2` 导入。
</Callout>

## 概览

`CopilotChatUserMessage` 渲染对齐在聊天区域右侧的用户消息。默认消息渲染器会将消息内容摊平为纯文本，并以 `white-space: pre-wrap` 展示，从而保留换行与空格。

消息下方会渲染一个工具栏，包含复制到剪贴板按钮、可选的编辑按钮和可选的分支导航控件。工具栏在悬停时变为可见。只有挂接了 `@edit-message` 监听器时才会显示编辑按钮；只有当 `numberOfBranches` 大于 1 且挂接了 `@switch-to-branch` 监听器时才会显示分支导航。

## 示例

```vue
<script setup lang="ts">
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
import type { UserMessage } from "@ag-ui/core";

const message: UserMessage = {
  id: "1",
  role: "user",
  content: "What is the capital of France?",
};
</script>

<template>
  <CopilotChatUserMessage :message="message" />
</template>
```

## 属性（Props）

<PropertyReference name="message" type="UserMessage" required>
  要渲染的用户消息对象。默认渲染器会读取 `content`（字符串，或内容分片数组，
  其中的 `text` 分片会以换行符拼接）和 `id`。`UserMessage` 从 `@ag-ui/core` 导入。
</PropertyReference>

<PropertyReference name="branchIndex" type="number" default="0">
  当前活动分支的从零开始的索引。分支导航控件用它来显示当前位置
  （渲染为 `branchIndex + 1`），并据此计算上一个/下一个箭头是否可用。
</PropertyReference>

<PropertyReference name="numberOfBranches" type="number" default="1">
  此消息可用分支的总数。只有当该值大于 1 且挂接了 `@switch-to-branch`
  监听器时，才会渲染分支导航。
</PropertyReference>

## 事件（Events）

操作回调以 Vue 事件的形式发出。为事件挂接监听器的同时也会启用相应控件：只有存在 `@edit-message` 监听器时才渲染编辑按钮；只有存在 `@switch-to-branch` 监听器（且 `numberOfBranches` 大于 1）时才渲染分支导航。

<PropertyReference name="edit-message" type="(payload: { message: UserMessage }) => void">
  用户点击编辑按钮时发出。事件负载包含正在编辑的 `message`。
  未挂接监听器时，工具栏中会隐藏编辑按钮。

```vue
<CopilotChatUserMessage
  :message="message"
  @edit-message="({ message }) => openEditModal(message)"
/>
```

</PropertyReference>

<PropertyReference name="switch-to-branch" type="(payload: { message: UserMessage; branchIndex: number; numberOfBranches: number }) => void">
  用户通过上一个/下一个箭头切换到其他分支时发出。事件负载包含目标
  `branchIndex`、分支总数 `numberOfBranches` 以及 `message`。
  只有挂接了该监听器且 `numberOfBranches` 大于 1 时，才会渲染分支导航控件。

```vue
<CopilotChatUserMessage
  :message="message"
  :branch-index="currentBranch"
  :number-of-branches="branches.length"
  @switch-to-branch="({ branchIndex }) => (currentBranch = branchIndex)"
/>
```

</PropertyReference>

## 插槽（Slots）

每个插槽都会暴露作用域插槽属性（处理器与状态），未提供时回退到默认渲染。使用具名模板（`<template #slot-name="...">`）即可覆盖某个插槽。

<PropertyReference name="message-renderer" type="{ message: UserMessage; content: string; isMultiline: boolean }">
  替换消息内容渲染器。默认实现会在圆角气泡中以 `white-space: pre-wrap`
  渲染摊平后的 `content` 字符串。

```vue
<CopilotChatUserMessage :message="message">
  <template #message-renderer="{ content }">
    <div class="font-mono text-sm">{{ content }}</div>
  </template>
</CopilotChatUserMessage>
```

</PropertyReference>

<PropertyReference name="toolbar" type="{ message: UserMessage; showBranchNavigation: boolean; hasEditAction: boolean }">
  替换在消息内容下方渲染的整个操作工具栏容器。`showBranchNavigation` 与
  `hasEditAction` 用于指示默认工具栏会显示哪些控件。
</PropertyReference>

<PropertyReference name="toolbar-items" type="(no props)">
  在默认工具栏的起始位置插入额外内容，与复制、编辑和分支导航控件并列。
  可在不替换整个工具栏的情况下追加自定义操作。

```vue
<CopilotChatUserMessage :message="message">
  <template #toolbar-items>
    <button @click="pin(message.id)">Pin</button>
  </template>
</CopilotChatUserMessage>
```

</PropertyReference>

<PropertyReference name="copy-button" type="{ onCopy: () => Promise<void>; copied: boolean; label: string }">
  替换复制到剪贴板按钮。`onCopy` 会将摊平后的消息内容复制到剪贴板，
  `copied` 反映短暂的已复制状态（2 秒后重置），`label` 取自
  `userMessageToolbarCopyMessageLabel`。
</PropertyReference>

<PropertyReference name="edit-button" type="{ onEdit: () => void; label: string }">
  替换编辑按钮。只有挂接了 `@edit-message` 监听器时才会渲染。
  `onEdit` 会发出 `edit-message` 事件，`label` 取自
  `userMessageToolbarEditMessageLabel`。
</PropertyReference>

<PropertyReference name="branch-navigation" type="{ branchIndex: number; numberOfBranches: number; canGoPrev: boolean; canGoNext: boolean; goPrev: () => void; goNext: () => void }">
  替换分支导航控件。只有当 `numberOfBranches` 大于 1 且挂接了
  `@switch-to-branch` 监听器时才会渲染。`goPrev` 与 `goNext`
  会针对相邻分支发出 `switch-to-branch`；`canGoPrev` 与 `canGoNext`
  指示导航是否可用。

```vue
<CopilotChatUserMessage
  :message="message"
  :branch-index="branchIndex"
  :number-of-branches="3"
  @switch-to-branch="onSwitch"
>
  <template
    #branch-navigation="{ branchIndex, numberOfBranches, canGoPrev, canGoNext, goPrev, goNext }"
  >
    <div class="flex items-center gap-1 text-xs">
      <button :disabled="!canGoPrev" @click="goPrev">Prev</button>
      <span>{{ branchIndex + 1 }} of {{ numberOfBranches }}</span>
      <button :disabled="!canGoNext" @click="goNext">Next</button>
    </div>
  </template>
</CopilotChatUserMessage>
```

</PropertyReference>

<PropertyReference name="layout" type="{ message; content; isMultiline; showBranchNavigation; hasEditAction; branchIndex; numberOfBranches; canGoPrev; canGoNext; onCopy; onEdit; goPrev; goNext; copied }">
  替换整个组件布局（消息渲染器与工具栏），让你完全掌控标记结构，
  同时仍能接收所有派生状态与处理器。当逐个覆盖插槽仍不够用时，可使用此插槽。
</PropertyReference>

## 用法

### 基本用户消息

```vue
<script setup lang="ts">
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import type { UserMessage } from "@ag-ui/core";

defineProps<{ message: UserMessage }>();
</script>

<template>
  <CopilotChatUserMessage :message="message" />
</template>
```

### 支持编辑

```vue
<script setup lang="ts">
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import type { UserMessage } from "@ag-ui/core";

defineProps<{ message: UserMessage }>();

function handleEdit(payload: { message: UserMessage }) {
  console.log("Edit", payload.message.id);
}
</script>

<template>
  <CopilotChatUserMessage :message="message" @edit-message="handleEdit" />
</template>
```

### 支持分支导航

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import type { UserMessage } from "@ag-ui/core";

defineProps<{ message: UserMessage; branches: UserMessage[] }>();

const currentBranch = ref(0);

function handleSwitch(payload: { branchIndex: number }) {
  currentBranch.value = payload.branchIndex;
}
</script>

<template>
  <CopilotChatUserMessage
    :message="message"
    :branch-index="currentBranch"
    :number-of-branches="branches.length"
    @switch-to-branch="handleSwitch"
  />
</template>
```

### 用插槽自定义外观

```vue
<script setup lang="ts">
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import type { UserMessage } from "@ag-ui/core";

defineProps<{ message: UserMessage }>();
</script>

<template>
  <CopilotChatUserMessage
    :message="message"
    @edit-message="({ message }) => console.log('Edit:', message.id)"
  >
    <template #message-renderer="{ content }">
      <div class="rounded-2xl bg-blue-600 px-4 py-2 text-white">
        {{ content }}
      </div>
    </template>
    <template #toolbar-items>
      <button @click="$emit('pin')">Pin</button>
    </template>
  </CopilotChatUserMessage>
</template>
```

### 完整的编辑与分支工作流

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CopilotChatUserMessage } from "@copilotkit/vue/v2";
import type { UserMessage } from "@ag-ui/core";

defineProps<{ message: UserMessage; branches: UserMessage[] }>();

const currentBranch = ref(0);

function openEditModal(message: UserMessage) {
  // open your edit modal
}
</script>

<template>
  <CopilotChatUserMessage
    :message="message"
    :branch-index="currentBranch"
    :number-of-branches="branches.length"
    @switch-to-branch="({ branchIndex }) => (currentBranch = branchIndex)"
    @edit-message="({ message }) => openEditModal(message)"
  />
</template>
```

## 行为

- **右对齐布局**：用户消息以右对齐方式渲染，以便在视觉上与助手消息区分。
- **内容摊平**：当 `message.content` 是分片数组时，默认渲染器会以换行符拼接各 `text` 分片。字符串内容按原样渲染。
- **空白保留**：默认消息渲染器使用 `white-space: pre-wrap`，因此换行与空格都会保留。当内容为多行时，气泡会获得额外的纵向内边距。
- **悬停显示工具栏**：工具栏默认不可见，当鼠标悬停在消息上时变为可见。
- **短暂的已复制状态**：复制成功后，复制按钮会显示对勾图标 2 秒，然后恢复原状。
- **条件显示的编辑按钮**：只有挂接了 `@edit-message` 监听器时，编辑按钮才会出现。
- **条件显示的分支导航**：只有当 `numberOfBranches` 大于 1 且挂接了 `@switch-to-branch` 监听器时，分支导航才会出现。
- **本地化标签**：工具栏按钮的工具提示取自最近的配置提供方。可用标签键参见 [`useCopilotChatConfiguration`](/reference/vue/hooks/useCopilotChatConfiguration)。
