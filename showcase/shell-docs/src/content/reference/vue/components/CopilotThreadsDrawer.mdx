## 概览

`CopilotThreadsDrawer` 在 [`CopilotChat`](/reference/vue/components/CopilotChat) 旁边渲染预构建的会话抽屉。它是对框架无关的 `<copilotkit-threads-drawer>` 自定义元素的轻量 Vue 包装，只在挂载时加载该元素，从而保持 SSR 安全。抽屉从 [`useThreads`](/reference/vue/hooks/useThreads) 读取数据，在存在周围聊天配置时遵循它，并允许用户切换、新建、归档、取消归档、删除和筛选线程。

省略 `onThreadSelect` 和 `onNewThread` 时，包装器会直接驱动周围的聊天配置：选中一行会调用 `setActiveThreadId(threadId, { explicit: true })`，“新建会话”操作则用 `startNewThread()` 重置聊天。只有当你想自行控制活动线程时才提供这些回调。

抽屉的行菜单不提供线程重命名。需要无头（headless）重命名支持请使用 [`useThreads`](/reference/vue/hooks/useThreads)。

<Callout type="info">
  线程抽屉需要许可。未获得许可时，组件会渲染锁定状态并保持线程存储禁用。
  详情请访问 [copilotkit.ai/pricing](https://copilotkit.ai/pricing)。
</Callout>

## 导入

```vue
<script setup lang="ts">
import { CopilotThreadsDrawer } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>
```

## 属性（Props）

<PropertyReference name="agentId" type="string">
  要列出和管理其线程的智能体。默认为周围聊天配置中的智能体，
  未设置时用平台默认值。
</PropertyReference>

<PropertyReference name="onThreadSelect" type="(threadId: string) => void">
  可选的逃生通道，在用户选择某个线程行时调用。省略时，
  抽屉直接驱动周围的聊天配置。
</PropertyReference>

<PropertyReference name="onNewThread" type="() => void">
  可选的逃生通道，在用户新建线程时调用。省略时，
  抽屉会将周围的聊天配置重置为新线程。
</PropertyReference>

<PropertyReference name="onLicensed" type="() => void">
  用户在抽屉锁定状态下点击 Upgrade 按钮时调用。
  这并不是许可检查完成的通知。
</PropertyReference>

<PropertyReference name="licenseUrl" type="string">
  许可追加销售状态下显示的 URL。省略时使用底层元素的默认许可 URL。
</PropertyReference>

<PropertyReference name="label" type="string" default="Threads">
  抽屉区域与线程列表框的无障碍标签。
</PropertyReference>

<PropertyReference name="recentLabel" type="string" default="Recent Conversations">
  线程列表上方分区标题的文本。
</PropertyReference>

<PropertyReference name="limit" type="number">
  线程分页的每页数量。设置后，只要还有后续页，抽屉就会显示“加载更多”控件。
</PropertyReference>

<PropertyReference name="collapsible" type="boolean" default="true">
  抽屉在桌面上是否提供折叠开关。为 `false` 时，抽屉保持展开。
</PropertyReference>

<PropertyReference name="dataTestId" type="string" default="copilot-threads-drawer">
  应用于底层自定义元素的 `data-testid`。
</PropertyReference>

## 事件（Events）

Vue 包装器发出以下事件。

| 事件 | 负载 | 触发时机 |
| --- | --- | --- |
| `collapse-change` | `collapsed: boolean` | 桌面端折叠状态变化 |

## 插槽（Slots）

Vue 使用具名插槽替代 React 的 render props。`CopilotThreadsDrawer` 只定义了一个作用域 Vue 插槽；其余内容都通过 `slot` 属性投影到底层自定义元素。

<PropertyReference name="row" type="{ thread: Thread }">
  替换所有线程的默认行内容。包装器将此插槽渲染为带 `slot="row:{id}"`
  的 light-DOM 子元素，因此自定义元素会在你的内容周围保留行外观。
  这是全有或全无的：一旦定义了此插槽，就没有逐行回退到内置行的机制。
</PropertyReference>

带这些 `slot` 名称的 light-DOM 子元素会投影进抽屉：

| 插槽 | 替换的内容 |
| --- | --- |
| `header` | 抽屉页眉区域 |
| `empty` | 空状态主体 |
| `footer` | 页脚区域 |
| `memories` | 预留的 memories 界面 |
| `launcher-icon` | 移动端启动器内的图标 |
| `licensed` | 许可追加销售内容 |

使用 `::part()` 为 shadow DOM 设置样式。抽屉暴露了常规的结构与操作部件，包括根元素、页眉、列表、行、菜单、新建线程按钮、分区标题、筛选控件、折叠控件、启动器、加载更多、获取更多出错提示以及许可界面。

## 用法

### 基本用法

把抽屉和 `CopilotChat` 包在共享的 `CopilotChatConfigurationProvider` 中，使它们作用于同一个活动线程。本示例包含了外层的 `CopilotKitProvider`，因此可按原样运行。

```vue
<script setup lang="ts">
import {
  CopilotChat,
  CopilotChatConfigurationProvider,
  CopilotKitProvider,
  CopilotThreadsDrawer,
} from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="http://localhost:8200/api/copilotkit">
    <CopilotChatConfigurationProvider agent-id="support">
      <div class="flex h-full">
        <CopilotThreadsDrawer agent-id="support" />
        <CopilotChat agent-id="support" />
      </div>
    </CopilotChatConfigurationProvider>
  </CopilotKitProvider>
</template>
```

### 自定义行与投影外观

```vue
<script setup lang="ts">
import { CopilotThreadsDrawer } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotThreadsDrawer label="History">
    <span slot="header">My conversations</span>
    <span slot="empty">No threads yet.</span>

    <template #row="{ thread }">
      <strong>{{ thread.name ?? "New conversation" }}</strong>
    </template>
  </CopilotThreadsDrawer>
</template>
```

### 观察折叠状态

```vue
<script setup lang="ts">
import { CopilotThreadsDrawer } from "@copilotkit/vue/v2";

function onCollapseChange(collapsed: boolean) {
  console.log("drawer collapsed:", collapsed);
}
</script>

<template>
  <CopilotThreadsDrawer @collapse-change="onCollapseChange" />
</template>
```

## 行为

- 抽屉会向周围的聊天配置注册自身，以便显示移动端启动器。
- 省略回调时，选中一行会调用 `setActiveThreadId`，“新建会话”会调用 `startNewThread`。
- 归档、取消归档、删除和分页都经由 `useThreads` 完成。
- 未获得许可时抽屉保持惰性，在线程存储上阻止抓取，直至许可问题解决。
- 重命名只支持无头方式；需要该操作请使用 `useThreads().renameThread()`。
- 包装器是 SSR 安全的，因为自定义元素是在客户端懒加载导入的。
