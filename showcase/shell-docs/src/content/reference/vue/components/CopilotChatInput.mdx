## 概览

`CopilotChatInput` 是 Vue 3 聊天交互的主要文本输入与控制面板。它提供一个可自动增高、上限行数可配置（默认 5 行）的多行文本域，发送消息与语音转写的操作按钮，以及一个用于声明式命令入口的可选工具菜单（绑定 `@add-file` 时菜单中还会出现文件附件项，并且可以通过内联的 `/` 斜杠命令触达）。

该组件有三种工作模式：`"input"`（默认文本输入）、`"transcribe"`（用音频录制器替换文本域）和 `"processing"`（后台处理进行中时显示加载指示器）。当文本超过一行时，布局会把文本域堆叠在控制行上方。

它同时支持 `v-model`（通过 `modelValue` / `update:modelValue`）与非受控用法。非受控时，组件在内部自行管理文本状态，并在提交时清空（可通过 `clearOnSubmit` 配置）。

<Callout type="info">
  转写按钮（麦克风、取消、完成）只有在对应事件挂接了监听器时才会渲染——
  例如，只有绑定 `@start-transcribe` 后麦克风按钮才会出现。相比之下，
  发送按钮始终渲染：在挂接 `@submit-message` 监听器且输入非空之前它一直处于
  禁用状态；智能体运行期间它会切换为停止控件，且只有挂接 `@stop` 监听器时
  才可用。绑定 `@add-file` 会在工具菜单中添加文件附件项，而不是独立按钮。
  也就是说，你通过监听打算处理的事件来按需启用功能。
</Callout>

## 导入

```vue
<script setup lang="ts">
import { CopilotChatInput } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>
```

## 示例

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CopilotChatInput } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";

const value = ref("");

function handleSubmit(text: string) {
  sendMessage(text);
}
</script>

<template>
  <CopilotChatInput v-model="value" @submit-message="handleSubmit" />
</template>
```

## 属性（Props）

<PropertyReference name="modelValue" type="string">
  输入框当前的文本值。受控模式下用 `v-model` 绑定（或传 `:model-value` 并配合
  `@update:model-value`）。省略时组件自行管理内部状态（非受控模式）。
</PropertyReference>

<PropertyReference
  name="mode"
  type='"input" | "transcribe" | "processing"'
  default='"input"'
>
  输入组件当前的工作模式。- `"input"` —— 带文本域和发送按钮的标准文本输入模式。
  - `"transcribe"` —— 用音频录制器组件替换文本域以进行语音输入。-
  `"processing"` —— 用加载指示器替换文本域，表示后台处理正在进行。
</PropertyReference>

<PropertyReference name="disabled" type="boolean" default="false">
  为 `true` 时，文本域与所有操作按钮均被禁用，提交、工具菜单与斜杠命令都被抑制。
</PropertyReference>

<PropertyReference name="placeholder" type="string">
  文本域的占位文本。省略时回退到由
  [`useCopilotChatConfiguration`](/reference/vue/hooks/useCopilotChatConfiguration)
  解析出的 `chatInputPlaceholder` 标签。
</PropertyReference>

<PropertyReference name="autoFocus" type="boolean" default="true">
  为 `true` 时，文本域在挂载后自动获得焦点（仅在 `"input"` 模式下）。
</PropertyReference>

<PropertyReference name="clearOnSubmit" type="boolean" default="true">
  为 `true` 时，消息提交后输入文本会被清空。设为 `false` 可在提交后保留文本。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean" default="false">
  智能体当前是否正在执行。为 `true` 时（且不处于 `"transcribe"` 模式），
  发送按钮会替换为停止按钮（在存在 `@stop` 监听器时），按 Enter 会触发停止
  而非提交。
</PropertyReference>

<PropertyReference name="toolsMenu" type="(ToolsMenuItem | '-')[]" default="[]">
  工具菜单的声明式配置。每个条目要么是一个 `ToolsMenuItem` 对象，要么是
  分隔符字符串 `"-"`。条目结构参见 [ToolsMenuItem](#toolsmenuitem)。
  非空时会显示菜单按钮，并且这些条目会作为 `/` 斜杠命令在文本域内可用。
</PropertyReference>

<PropertyReference name="maxRows" type="number" default="5">
  自动增高的文本域在变为可滚动之前可扩展到的最大行数。
</PropertyReference>

<PropertyReference name="positioning" type='"static" | "absolute"' default='"static"'>
  输入容器的布局定位。`"absolute"` 会把输入固定在其相对父元素的底部，
  并默认显示免责声明。
</PropertyReference>

<PropertyReference name="keyboardHeight" type="number" default="0">
  屏幕键盘的像素高度。大于 `0` 时，容器会向上平移该距离以保持在键盘上方。
</PropertyReference>

<PropertyReference name="showDisclaimer" type="boolean">
  控制是否在输入框下方渲染免责声明文本。省略时，仅当
  `positioning === "absolute"` 时默认为 `true`。
</PropertyReference>

<PropertyReference name="bottomAnchored" type="boolean" default="false">
  当输入作为 flex 最后一个子元素位于容器底部时设为 `true`。为固定的
  CopilotKit 许可横幅预留底部空间，避免两者重叠。`positioning === "absolute"`
  时无需设置，该模式已预留空间。
</PropertyReference>

## 事件（Events）

`CopilotChatInput` 会发出以下事件。用 `v-on`（`@` 简写）绑定处理器。
若干操作按钮只有在对应事件挂接了监听器时才会渲染。

<PropertyReference name="update:modelValue" type="(value: string) => void">
  输入文本变化时发出，是 `v-model` 的底层支撑。若只需要感知变更而不需要
  双向绑定，可直接用 `@update:model-value` 绑定。
</PropertyReference>

<PropertyReference name="submit-message" type="(value: string) => void">
  用户提交消息时发出（按 Enter 或点击发送按钮）。接收去除首尾空白后的
  文本值。只有存在 `@submit-message` 监听器且输入非空时发送按钮才可用。
</PropertyReference>

<PropertyReference name="stop" type="() => void">
  在 `isRunning` 为 `true` 期间，用户点击停止按钮（或按 Enter）时发出。
  只有存在 `@stop` 监听器时发送按钮才会切换为停止按钮。
</PropertyReference>

<PropertyReference name="add-file" type="() => void">
  用户在工具菜单中选择文件附件项时发出。只有存在 `@add-file` 监听器时
  才会把附件项加入菜单。
</PropertyReference>

<PropertyReference name="start-transcribe" type="() => void">
  用户点击麦克风按钮开始语音转写时发出。只有存在 `@start-transcribe`
  监听器时麦克风按钮才会渲染。通常用于把 `mode` 切换为 `"transcribe"`。
</PropertyReference>

<PropertyReference name="cancel-transcribe" type="() => void">
  用户取消进行中的语音转写时发出。取消按钮只在 `"transcribe"` 模式下且
  存在 `@cancel-transcribe` 监听器时才渲染。
</PropertyReference>

<PropertyReference name="finish-transcribe" type="() => void">
  用户结束语音转写时发出。结束时会始终发出（在音频 Blob 可用时先发出
  `finish-transcribe-with-audio`）。完成按钮只在 `"transcribe"` 模式下且
  存在 `@finish-transcribe` 监听器时才渲染。
</PropertyReference>

<PropertyReference
  name="finish-transcribe-with-audio"
  type="(audioBlob: Blob) => void"
>
  用户结束语音转写且有录音可用时发出。以 `Blob` 形式接收录制的音频。
  需要把原始音频发送到服务端做语音转文字处理时使用此事件。
</PropertyReference>

## 插槽（Slots）

`CopilotChatInput` 暴露了多个具名插槽，让你可以在保留组件行为的同时覆盖
UI 的各个部分。每个插槽都会接收作用域插槽 props（事件处理器、状态与标签），
因此你的自定义标记可以驱动与默认实现相同的逻辑。

<PropertyReference name="text-area" type="slot">
  替换默认的自动增高文本域。作用域 props 包括 `value`、`disabled`、
  `placeholder`、`onInput`、`onKeydown`、`autoFocus`、`isExpanded`、`rows`
  与 `labels`。仅在 `"input"` 模式下渲染。
</PropertyReference>

<PropertyReference name="send-button" type="slot">
  替换默认的发送/停止按钮。作用域 props：`disabled`、`isProcessing` 与
  `onClick`。
</PropertyReference>

<PropertyReference name="add-menu-button" type="slot">
  替换默认的工具菜单触发按钮。作用域 props：`disabled`、`menuOpen`、
  `toggleMenu` 与 `labels`。
</PropertyReference>

<PropertyReference name="start-transcribe-button" type="slot">
  替换开始转写的麦克风按钮。作用域 props：`disabled`、`onClick` 与
  `labels`。只有存在 `@start-transcribe` 监听器时才渲染。
</PropertyReference>

<PropertyReference name="cancel-transcribe-button" type="slot">
  替换取消进行中转写的按钮。作用域 props：`disabled`、`onClick` 与
  `labels`。仅在 `"transcribe"` 模式下且存在 `@cancel-transcribe` 监听器时
  才渲染。
</PropertyReference>

<PropertyReference name="finish-transcribe-button" type="slot">
  替换完成转写的按钮。作用域 props：`disabled`、`onClick` 与 `labels`。
  仅在 `"transcribe"` 模式下且存在 `@finish-transcribe` 监听器时才渲染。
</PropertyReference>

<PropertyReference name="audio-recorder" type="slot">
  替换 `"transcribe"` 模式下渲染的音频录制器。默认为
  [`CopilotChatAudioRecorder`](#copilotchataudiorecorder)。
</PropertyReference>

<PropertyReference name="disclaimer" type="slot">
  替换输入框下方显示的免责声明文本。作用域 prop：`labels`。仅在启用
  免责声明时渲染（见 `showDisclaimer`）。
</PropertyReference>

<PropertyReference name="layout" type="slot">
  替换整个内部布局（输入外壳及其全部控件）。接收丰富的作用域 props，包括
  `mode`、`isMultiline`、`value`、`disabled`、`placeholder`、`isProcessing`、
  `sendDisabled`、`menuOpen`、`menuItems`，以及 `onUpdateValue`、`onSubmit`、
  `onKeydown`、`onSendClick`、`onToggleMenu`、`onMenuAction`、
  `onStartTranscribe`、`onCancelTranscribe`、`onFinishTranscribe` 等处理器。
  想在复用其状态机的同时完全掌控输入结构时使用此插槽。
</PropertyReference>

## ToolsMenuItem

`ToolsMenuItem` 类型定义了工具菜单中的条目。条目可以直接触发操作，
也可以包含嵌套子菜单。

```ts
type ToolsMenuItem = { label: string } & (
  | { action: () => void; items?: never }
  | { action?: never; items: (ToolsMenuItem | "-")[] }
);
```

<PropertyReference name="label" type="string" required>
  菜单项的显示文本。
</PropertyReference>

<PropertyReference name="action" type="() => void">
  选中该条目时调用的回调。与 `items` 互斥。
</PropertyReference>

<PropertyReference name="items" type="(ToolsMenuItem | '-')[]">
  嵌套的子菜单条目。每个条目要么是另一个 `ToolsMenuItem`，要么是分隔符
  字符串 `"-"`。与 `action` 互斥。
</PropertyReference>

### 分隔符

把字符串 `"-"` 作为数组条目使用，即可在菜单项之间渲染一条视觉分隔线：

```ts
const toolsMenu = [
  { label: "Search", action: () => search() },
  "-",
  { label: "Settings", action: () => openSettings() },
];
```

### 嵌套子菜单

带 `items` 数组的菜单项会渲染为可展开的子菜单：

```ts
const toolsMenu = [
  {
    label: "Export",
    items: [
      { label: "As PDF", action: () => exportPDF() },
      { label: "As CSV", action: () => exportCSV() },
      "-",
      { label: "Print", action: () => printDoc() },
    ],
  },
];
```

## CopilotChatAudioRecorder

转写模式下使用的音频波形可视化组件。它实时显示麦克风输入的波形可视化效果，
并通过模板 `ref` 暴露命令式 API。

### 导入

```vue
<script setup lang="ts">
import { CopilotChatAudioRecorder } from "@copilotkit/vue/v2";
</script>
```

### 命令式 API（CopilotChatAudioRecorderRef）

该组件通过模板 `ref` 暴露以下成员：

<PropertyReference name="state" type='"idle" | "recording" | "processing"'>
  录制器当前的状态。
</PropertyReference>

<PropertyReference name="start" type="() => Promise<void>">
  开始音频录制并启动波形可视化。
</PropertyReference>

<PropertyReference name="stop" type="() => Promise<Blob>">
  停止当前录制会话，并以 `Blob` 形式返回录制的音频。
</PropertyReference>

<PropertyReference name="dispose" type="() => void">
  清理录制器使用的所有资源（媒体流、音频上下文等）。
</PropertyReference>

### 用法

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CopilotChatAudioRecorder } from "@copilotkit/vue/v2";

// The component exposes `start()` / `stop()` via its instance type.
const recorder = ref<InstanceType<typeof CopilotChatAudioRecorder> | null>(null);
</script>

<template>
  <CopilotChatAudioRecorder ref="recorder" />
  <button @click="recorder?.start()">Record</button>
  <button @click="recorder?.stop()">Stop</button>
</template>
```

## 用法

### 带语音转写

```vue
<script setup lang="ts">
import { ref } from "vue";
import { CopilotChatInput } from "@copilotkit/vue/v2";

const value = ref("");
const mode = ref<"input" | "transcribe">("input");

async function handleFinishWithAudio(blob: Blob) {
  value.value = await transcribeAudio(blob);
  mode.value = "input";
}
</script>

<template>
  <CopilotChatInput
    v-model="value"
    :mode="mode"
    @submit-message="(text) => sendMessage(text)"
    @start-transcribe="mode = 'transcribe'"
    @cancel-transcribe="mode = 'input'"
    @finish-transcribe-with-audio="handleFinishWithAudio"
  />
</template>
```

### 带工具菜单

```vue
<script setup lang="ts">
import { CopilotChatInput, type ToolsMenuItem } from "@copilotkit/vue/v2";

const toolsMenu: (ToolsMenuItem | "-")[] = [
  { label: "Search the web", action: () => triggerSearch() },
  { label: "Analyze data", action: () => triggerAnalysis() },
  "-",
  {
    label: "Export",
    items: [
      { label: "As PDF", action: () => exportPDF() },
      { label: "As Markdown", action: () => exportMarkdown() },
    ],
  },
];
</script>

<template>
  <CopilotChatInput
    :tools-menu="toolsMenu"
    @submit-message="(text) => sendMessage(text)"
  />
</template>
```

### 执行期间带停止按钮

```vue
<script setup lang="ts">
import { CopilotChatInput, useAgent, useCopilotKit } from "@copilotkit/vue/v2";

const { agent } = useAgent();
const { copilotkit } = useCopilotKit();

function handleSubmit(text: string) {
  if (!agent.value) return;
  agent.value.addMessage({
    role: "user",
    content: text,
    id: crypto.randomUUID(),
  });
  // Drive the run through CopilotKit so registered frontend tools execute and
  // the run is tracked for stop/abort.
  copilotkit.value.runAgent({ agent: agent.value });
}

function handleStop() {
  if (!agent.value) return;
  copilotkit.value.stopAgent({ agent: agent.value });
}
</script>

<template>
  <CopilotChatInput
    :is-running="agent?.isRunning ?? false"
    auto-focus
    @submit-message="handleSubmit"
    @stop="handleStop"
  />
</template>
```

### 样式化插槽

```vue
<script setup lang="ts">
import { CopilotChatInput } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotChatInput @submit-message="(text) => sendMessage(text)">
    <template #send-button="{ disabled, onClick }">
      <button
        :disabled="disabled"
        class="rounded-full bg-green-500 px-3 py-1 text-white"
        @click="onClick"
      >
        Send
      </button>
    </template>
  </CopilotChatInput>
</template>
```

## 行为

- **自动增高文本域**：默认文本域会随用户输入自动扩展，最多到 `maxRows` 行（默认 5）。达到上限后，文本域变为可滚动。
- **布局堆叠**：当输入文本超过一行时，布局会从内联（文本域与按钮并排）切换为堆叠（文本域位于包含操作按钮的控制行上方）。在窄视口下则无条件使用堆叠布局。
- **模式切换**：把 `mode` 设为 `"transcribe"` 会用 `audio-recorder` 插槽替换文本域并自动开始录制。取消与完成按钮会替换标准发送按钮。把 `mode` 设为 `"processing"` 会在文本域位置显示加载指示器。
- **受控与非受控**：组件同时支持受控模式（通过 `v-model` / `modelValue`）与非受控模式（内部状态）。启用 `clearOnSubmit`（默认启用）时，输入会在每次提交后清空。
- **工具菜单与斜杠命令**：非空的 `toolsMenu` 会渲染一个菜单按钮，并把叶子操作暴露为可内联输入的 `/` 斜杠命令。用方向键导航斜杠菜单，按 Enter 运行高亮命令。
- **由监听器门控的控件**：转写按钮（麦克风、取消、完成）只有在对应事件监听器挂接后才会渲染。发送按钮始终渲染，但在挂接 `@submit-message` 监听器且输入非空之前一直禁用；智能体运行期间它会切换为停止控件，且仅在挂接 `@stop` 监听器时可用。绑定 `@add-file` 会在工具菜单中添加文件附件项（而非独立按钮）。每个功能都通过处理其对应事件来按需启用。
