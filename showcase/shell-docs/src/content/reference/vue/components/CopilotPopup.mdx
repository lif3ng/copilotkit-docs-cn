<Callout type="info">
  这是 Vue 3 弹窗组件，请从 `@copilotkit/vue/v2` 导入。
</Callout>

`CopilotPopup` 渲染一个带切换按钮的浮动聊天弹窗。它包装了 [`CopilotChat`](/reference/vue/components/CopilotChat)，并提供弹窗专属的布局、尺寸与打开/关闭行为。弹窗包含一个带标题和关闭按钮的页眉，还可选择支持点击外部关闭。

`"popup"` 特性需要许可。未获得许可时，组件会渲染内联警告并输出控制台警告；参见 [copilotkit.ai/pricing](https://copilotkit.ai/pricing)。

## 示例

```vue
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotPopup
    agent-id="my-agent"
    :labels="{ modalHeaderTitle: 'Assistant' }"
  />
</template>
```

## 属性（Props）

### 自身 props

<PropertyReference name="defaultOpen" type="boolean" default="true">
  组件首次挂载时弹窗是否打开。挂载后，打开/关闭状态由用户交互驱动
  （切换按钮、关闭按钮、点击外部）。
</PropertyReference>

<PropertyReference name="width" type="number | string">
  弹窗面板的宽度。接受数字（像素）或 CSS 字符串（例如 `"400px"` 或 `"30vw"`）。
</PropertyReference>

<PropertyReference name="height" type="number | string">
  弹窗面板的高度。接受数字（像素）或 CSS 字符串（例如 `"600px"` 或 `"80vh"`）。
</PropertyReference>

<PropertyReference name="clickOutsideToClose" type="boolean" default="false">
  点击弹窗面板外部时是否关闭弹窗。
</PropertyReference>

### 继承自 CopilotChat 的 props

`CopilotPopup` 继承自 [`CopilotChatProps`](/reference/vue/components/CopilotChat)，因此接受相同的智能体接线与聊天视图 props。最常用的有：

<PropertyReference name="agentId" type="string">
  要使用的智能体 ID。必须与 `CopilotKitProvider` 中配置的某个智能体匹配。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  对聊天内所渲染文本字符串的部分标签覆盖（包括弹窗页眉用的 `modalHeaderTitle`）。
</PropertyReference>

<PropertyReference name="autoScroll" type="AutoScrollMode | boolean" default="true">
  控制新消息流入时聊天视图的滚动方式。接受 `"pin-to-bottom"` / `true`、
  `"pin-to-send"` 或 `"none"` / `false`。
</PropertyReference>

<PropertyReference name="welcomeScreen" type="boolean" default="true">
  没有消息时是否显示欢迎屏。
</PropertyReference>

<PropertyReference name="inputValue" type="string">
  聊天输入区的受控值。
</PropertyReference>

<PropertyReference name="inputMode" type="CopilotChatInputMode" default='"input"'>
  聊天输入模式。
</PropertyReference>

<PropertyReference name="inputToolsMenu" type='(ToolsMenuItem | "-")[]' default="[]">
  输入区工具菜单中显示的菜单项。使用 `"-"` 插入分隔线。
</PropertyReference>

<PropertyReference name="onError" type="(event: { error: Error; code: CopilotKitCoreErrorCode; context: Record<string, any> }) => void | Promise<void>">
  可选的错误处理器，在发生聊天错误时调用。
</PropertyReference>

## 插槽（Slots）

所有插槽都会向下转发给内部的 `CopilotPopupView`。每个插槽都接收可供绑定的作用域属性。

<PropertyReference name="header" type="(props: CopilotPopupViewHeaderSlotProps) => unknown">
  覆盖弹窗页眉。插槽属性：`title`、`onClose`、`isOpen`。
</PropertyReference>

<PropertyReference name="toggle-button" type="(props: CopilotPopupViewToggleButtonSlotProps) => unknown">
  覆盖浮动切换按钮。插槽属性：`isOpen`、`toggle`、`open`、`close`。
</PropertyReference>

<PropertyReference name="chat-view" type="(props: CopilotChatViewOverrideSlotProps) => unknown">
  替换整个弹窗聊天视图。接收完整的聊天视图 props 以及事件处理器
  （`onSubmitMessage`、`onStop`、`onInputChange`、`onSelectSuggestion`，
  以及转写/文件处理器）。
</PropertyReference>

<PropertyReference name="message-view" type="(props: CopilotChatMessageViewSlotProps) => unknown">
  覆盖消息列表。插槽属性：`messages`、`isRunning`。
</PropertyReference>

<PropertyReference name="input" type="(props: CopilotSidebarWelcomeScreenInputSlotProps) => unknown">
  覆盖聊天输入区。插槽属性包括 `modelValue`、`isRunning`、`inputMode`、
  `inputToolsMenu` 以及输入事件处理器。
</PropertyReference>

<PropertyReference name="suggestion-view" type="(props: CopilotSidebarWelcomeScreenSuggestionViewSlotProps) => unknown">
  覆盖建议列表。插槽属性：`suggestions`、`loadingIndexes`、`onSelectSuggestion`。
</PropertyReference>

<PropertyReference name="welcome-screen" type="(props: CopilotChatWelcomeScreenSlotProps) => unknown">
  覆盖没有消息时显示的欢迎屏。
</PropertyReference>

<PropertyReference name="welcome-message" type="() => unknown">
  仅覆盖默认欢迎屏内的欢迎消息内容。
</PropertyReference>

## 事件（Events）

`CopilotPopup` 发出以下事件（模板中使用 kebab-case）：

| 事件 | 负载 |
| --- | --- |
| `submit-message` | `value: string` |
| `stop` | （无） |
| `input-change` | `value: string` |
| `select-suggestion` | `suggestion: Suggestion, index: number` |
| `add-file` | （无） |
| `start-transcribe` | （无） |
| `cancel-transcribe` | （无） |
| `finish-transcribe` | （无） |

## 用法

### 基本用法

```vue
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotPopup
    agent-id="my-agent"
    :labels="{ modalHeaderTitle: 'Assistant' }"
  />
</template>
```

### 自定义尺寸与点击外部关闭

```vue
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotPopup
    agent-id="my-agent"
    :default-open="false"
    :width="450"
    height="80vh"
    :click-outside-to-close="true"
  />
</template>
```

### 自定义页眉插槽

```vue
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotPopup agent-id="my-agent">
    <template #header="{ title, onClose }">
      <div class="flex items-center justify-between bg-blue-600 px-4 py-2 text-white">
        <span>{{ title }}</span>
        <button type="button" @click="onClose">Close</button>
      </div>
    </template>
  </CopilotPopup>
</template>
```

### 处理事件

```vue
<script setup lang="ts">
import { CopilotPopup } from "@copilotkit/vue/v2";

function onSubmit(value: string) {
  console.log("submitted:", value);
}
</script>

<template>
  <CopilotPopup agent-id="my-agent" @submit-message="onSubmit" />
</template>
```

## 行为

- **切换按钮**：渲染一个打开和关闭弹窗的浮动切换按钮。可用 `toggle-button` 插槽覆盖。
- **开关状态**：初始状态由 `defaultOpen` 设置；挂载后，状态变化来自用户交互（切换按钮、关闭按钮、点击外部）。
- **点击外部**：当 `clickOutsideToClose` 为 `true` 时，点击弹窗面板外部会关闭弹窗。默认为 `false`。
- **布局**：内部使用 `CopilotPopupView`，它提供弹窗专属的欢迎屏布局。
- **智能体连接**：所有智能体接线（消息、运行状态、建议）均由内部的 `CopilotChat` 处理。
