## 概览

`CopilotChat` 是一个高层聊天容器，负责把智能体接入 [`CopilotChatView`](/reference/vue/components/CopilotChatView) 并提供配置上下文。它通过 [`useAgent`](/reference/vue/hooks/useAgent) 获取智能体，订阅智能体的消息与运行状态，管理建议，处理输入值与音频转写，接好文件附件，并在消息提交后自动清空输入框。

通常你只需要指定要连接哪个智能体，并可选地自定义标签或覆盖某个具名插槽。

<Callout type="info">
  `CopilotChat` 还把底层布局组件暴露为 `CopilotChat.View`，即 [`CopilotChatView`](/reference/vue/components/CopilotChatView) 页面所记录的同一个组件。当你只想要布局而不想要智能体接线时，可以直接使用它。
</Callout>

## 导入

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>
```

## 属性（Props）

所有响应式 props 都通过 `defineProps` 声明。`CopilotChat` 继承了 `CopilotChatView` 的 props，但省略了它自行管理的那些（`messages`、`isRunning`、`suggestions`、`suggestionLoadingIndexes`、`attachments`、`onRemoveAttachment`、`onAddFile`、`dragOver`、`onDragOver`、`onDragLeave`、`onDrop`）。

### 自身属性（Own Props）

<PropertyReference name="agentId" type="string">
  要连接的智能体 ID。必须与 `CopilotKitProvider` 中配置的某个智能体匹配。省略时先回退到外层 `CopilotChatConfigurationProvider` 提供的 `agentId`，再回退到默认智能体。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。传入具体的线程 ID 可恢复既有会话。省略时会在本地生成一个线程 ID，并在智能体首次运行时创建新线程。
</PropertyReference>

<PropertyReference name="throttleMs" type="number">
  转发给 `useAgent` 的节流间隔（毫秒），用于在智能体流式输出时批量合并响应式更新。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  对聊天界面内所渲染文本（输入框占位符、欢迎消息、工具栏按钮、免责声明等）的局部标签覆盖。省略的标签回退到内置默认值。通过 [`useCopilotChatConfiguration`](/reference/vue/hooks/useCopilotChatConfiguration) 提供给后代组件。
</PropertyReference>

<PropertyReference name="attachments" type="AttachmentsConfig">
  文件附件的配置（可接受的 MIME 类型、上传处理等）。设置后即可启用添加文件操作与拖放功能，聊天会自动管理附件队列。
</PropertyReference>

<PropertyReference name="onError" type="(event: { error: Error; code: CopilotKitCoreErrorCode; context: Record<string, any> }) => void | Promise<void>">
  作用于本聊天智能体的错误处理器。除提供方级别的错误处理外还会触发。只接收 `context.agentId` 与本聊天智能体匹配的错误，以及不带 `agentId` 上下文的错误。

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";

function handleError(event: {
  error: Error;
  code: string;
  context: Record<string, any>;
}) {
  if (event.code === "agent_connect_failed") {
    showToast("Could not connect to agent. Please retry.");
  }
}
</script>

<template>
  <CopilotChat agent-id="my-agent" :on-error="handleError" />
</template>
```

</PropertyReference>

### 继承自 CopilotChatView 的属性

<PropertyReference name="autoScroll" type="AutoScrollMode | boolean" default="true">
  控制新消息流式到达时聊天的滚动方式。接受 `"pin-to-bottom"` / `true`（位于底部时固定在底部）、`"pin-to-send"`（助手输出时将最新用户消息锚定在顶部附近）或 `"none"` / `false`（从不自动滚动）。
</PropertyReference>

<PropertyReference name="welcomeScreen" type="boolean" default="true">
  在没有消息且未选择明确线程时是否显示欢迎屏。传 `false` 禁用。覆盖 `welcome-screen` 插槽可完全自定义。
</PropertyReference>

<PropertyReference name="inputValue" type="string">
  聊天输入框的受控值。提供后，聊天会把输入视为受控模式，并通过 `input-change` 事件把变更回传。
</PropertyReference>

<PropertyReference name="inputMode" type='"input" | "transcribe" | "processing"' default='"input"'>
  初始输入模式。组件会在音频转写期间管理这些模式之间的切换。
</PropertyReference>

<PropertyReference name="inputToolsMenu" type='(ToolsMenuItem | "-")[]'>
  输入框工具菜单的菜单项。每个菜单项包含一个 `label`，以及 `action` 回调或嵌套的 `items` 二者之一；使用 `"-"` 表示分隔符。
</PropertyReference>

<PropertyReference name="onFinishTranscribeWithAudio" type="(audioBlob: Blob) => void | Promise<void>">
  转写结束时以录制的音频 Blob 调用的自定义处理器。省略时，`CopilotChat` 会使用所配置的运行时转写音频，并把结果追加到输入框。
</PropertyReference>

## 事件（Events）

`CopilotChat` 会发出以下事件（在模板中用 `@event-name` 监听）。这些事件在组件内部处理之外额外触发，因此你可以在不禁用默认行为的情况下观察交互。

| 事件                | 载荷                                | 触发时机                          |
| ------------------- | ---------------------------------- | ----------------------------------- |
| `submit-message`    | `value: string`                    | 消息被提交时              |
| `stop`              | 无                               | 按下停止按钮时          |
| `input-change`      | `value: string`                    | 输入值变化时             |
| `select-suggestion` | `suggestion: Suggestion, index: number` | 选中某个建议胶囊时  |
| `add-file`          | 无                               | 触发添加文件操作时    |
| `start-transcribe`  | 无                               | 音频转写开始时          |
| `cancel-transcribe` | 无                               | 音频转写被取消时    |
| `finish-transcribe` | 无                               | 音频转写结束时        |

## 插槽（Slots）

Vue 使用具名插槽替代 React 的 render props 与子组件 props。提供相应插槽即可替换聊天的对应部分。每个插槽都会接收作用域 props，可用 `v-slot` 解构。下方未列出的插槽会经由 `CopilotChatView` 向下转发给消息视图。

<PropertyReference name="chat-view" type="CopilotChatViewOverrideSlotProps">
  替换内部的整个 `CopilotChatView`。接收所有组合后的视图状态与处理器（`messages`、`isRunning`、`suggestions`、`inputValue`、`onSubmitMessage`、`onSelectSuggestion`、`onStop`、转写与附件处理器等），让你能够渲染完全自定义的布局。
</PropertyReference>

<PropertyReference name="message-view" type="{ messages: Message[]; isRunning: boolean }">
  替换默认的消息列表渲染。
</PropertyReference>

<PropertyReference name="input" type="CopilotChatInputSlotProps">
  替换默认的聊天输入框。接收 `modelValue`、`isRunning`、`inputMode`、`inputToolsMenu`，以及 `onUpdateModelValue`、`onSubmitMessage`、`onStop` 等处理器和转写回调。
</PropertyReference>

<PropertyReference name="suggestion-view" type="CopilotChatSuggestionViewSlotProps">
  替换默认的建议胶囊。接收 `suggestions`、`loadingIndexes` 与 `onSelectSuggestion`。
</PropertyReference>

<PropertyReference name="welcome-screen" type="CopilotChatWelcomeScreenSlotProps">
  替换在没有任何消息时显示的默认欢迎屏。接收建议 props、输入框 model value 与提交处理器，让你能够组合出自己的问候布局。
</PropertyReference>

<PropertyReference name="welcome-message" type="() => unknown">
  只替换默认欢迎屏内的标题文本，周边布局保持不变。
</PropertyReference>

<PropertyReference name="interrupt" type="CopilotChatInterruptSlotProps">
  渲染人机协同（human-in-the-loop）中断 UI。接收 `event`、当前 `result` 与 `resolve` 回调。
</PropertyReference>

<Callout type="info">
  转发给消息视图的插槽（例如自定义助手消息或用户消息插槽）会直接透传，由 `CopilotChatMessageView` 渲染。完整的布局级插槽（如 `scroll-view`、`feather` 与 `scroll-to-bottom-button`）参见 [`CopilotChatView`](/reference/vue/components/CopilotChatView)。
</Callout>

## 用法

### 基本用法

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotChat
    agent-id="my-agent"
    :labels="{ chatInputPlaceholder: 'Ask me anything...' }"
  />
</template>
```

### 自定义欢迎屏

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";
</script>

<template>
  <CopilotChat agent-id="my-agent">
    <template #welcome-screen="{ onSubmitMessage, suggestions, onSelectSuggestion }">
      <div class="flex h-full flex-col items-center justify-center gap-4">
        <h2>Welcome to the assistant</h2>
        <button
          v-for="(suggestion, index) in suggestions"
          :key="index"
          @click="onSelectSuggestion(suggestion, index)"
        >
          {{ suggestion.title }}
        </button>
      </div>
    </template>
  </CopilotChat>
</template>
```

### 监听事件

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";

function onSubmit(value: string) {
  console.log("user submitted:", value);
}
</script>

<template>
  <CopilotChat agent-id="my-agent" @submit-message="onSubmit" />
</template>
```

### 直接使用布局组件

`CopilotChat.View` 是不带智能体接线的布局组件。当你自行管理 `messages` 与处理器时可以使用它。

```vue
<script setup lang="ts">
import { CopilotChat } from "@copilotkit/vue/v2";
import { ref } from "vue";

// Vue SFC templates cannot resolve dotted tags like `<CopilotChat.View>`,
// so alias the layout to a local component first.
const ChatView = CopilotChat.View;

const messages = ref([]);

function handleSubmit(value: string) {
  // manage your own message state
}
</script>

<template>
  <ChatView :messages="messages" @submit-message="handleSubmit" />
</template>
```
