## 概览

`CopilotChatMessageView` 用于渲染聊天消息列表，并可在智能体运行期间显示输入光标。它会根据每条消息的 `role`（assistant、user 或 reasoning）将其分发给对应的默认子组件，同时暴露具名插槽，让你可以替换或包装默认渲染。当 `isRunning` 为 `true` 时，最后一条消息之后会显示一个脉冲光标。

与 React 参考组件不同，Vue 中的定制完全通过具名插槽实现，而非 render props 或插槽属性系统。该组件还为中断、活动消息、工具调用，以及注册在 CopilotKit 实例上的自定义消息渲染器提供了插槽。

## 导入

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>
```

## 示例

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <copilot-chat-message-view
    :messages="agent?.messages ?? []"
    :is-running="agent?.isRunning ?? false"
  />
</template>
```

## 属性（Props）

<PropertyReference name="messages" type="Message[]" default="[]">
  要渲染的聊天消息数组。每个消息对象至少包含一个 `id` 和一个 `role`
  （例如 `"user"`、`"assistant"`、`"reasoning"` 或 `"activity"`）。
  `id` 重复的消息会在渲染前去重；共享同一 id 的助手消息分片会被合并。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean" default="false">
  智能体当前是否正在执行。为 `true` 时，会在最后一条消息之后渲染 `cursor`
  插槽，以指示正在进行的活动。当最后一条消息是推理消息时，光标会被隐藏。
</PropertyReference>

<Callout type="info">
  未声明为 prop 的属性（例如 `class`、`style` 或 `data-*`）会通过
  `v-bind="$attrs"` 透传到组件的根 `<div>` 上。
</Callout>

## 插槽（Slots）

以下每个插槽均为具名插槽。使用 `<template #slot-name="slotProps">` 块即可覆盖或包装默认渲染。对于有默认实现的插槽，省略时会回退到内置子组件。

<PropertyReference name="assistant-message" type="{ message: AssistantMessage; messages: Message[]; isRunning: boolean }">
  在 `role === "assistant"` 的消息上渲染。默认使用
  [`CopilotChatAssistantMessage`](/reference/vue/components/CopilotChatAssistantMessage)，
  它提供 Markdown 渲染、工具调用展示和操作工具栏。

```vue
<template>
  <copilot-chat-message-view :messages="messages" :is-running="isRunning">
    <template #assistant-message="{ message }">
      <div class="my-assistant-msg">{{ message.content }}</div>
    </template>
  </copilot-chat-message-view>
</template>
```

</PropertyReference>

<PropertyReference name="user-message" type="{ message: UserMessage }">
  在 `role === "user"` 的消息上渲染。默认使用
  [`CopilotChatUserMessage`](/reference/vue/components/CopilotChatUserMessage)，
  它提供右对齐的消息展示。

```vue
<template>
  <copilot-chat-message-view :messages="messages" :is-running="isRunning">
    <template #user-message="{ message }">
      <div class="my-user-msg">{{ message.content }}</div>
    </template>
  </copilot-chat-message-view>
</template>
```

</PropertyReference>

<PropertyReference name="reasoning-message" type="{ message: ReasoningMessage; messages: Message[]; isRunning: boolean }">
  在 `role === "reasoning"` 的消息上渲染。默认使用
  `CopilotChatReasoningMessage`，它负责渲染智能体的推理轨迹。
</PropertyReference>

<PropertyReference name="cursor" type="() => unknown">
  当 `isRunning` 为 `true`（且最后一条消息不是推理消息）时显示的输入指示器。默认为脉冲圆点动画。

```vue
<template>
  <copilot-chat-message-view :messages="messages" :is-running="isRunning">
    <template #cursor>
      <span class="animate-bounce">...</span>
    </template>
  </copilot-chat-message-view>
</template>
```

</PropertyReference>

<PropertyReference name="interrupt" type="{ event: unknown; result: unknown; resolve: (value: unknown) => void }">
  当 CopilotKit 实例报告存在活动中断（人机协同，human-in-the-loop）时渲染。它会接收中断
  `event`、当前的 `result`，以及用于完成该中断的 `resolve` 回调。
</PropertyReference>

<PropertyReference name="message-before" type="{ message: Message; position: 'before'; runId: string; messageIndex: number; messageIndexInRun: number; numberOfMessagesInRun: number; agentId: string; stateSnapshot: unknown }">
  在每条消息之前渲染。它会接收该消息的运行与位置元数据。省略此插槽时，
  将改用注册在 CopilotKit 实例上、位于 `"before"` 位置的自定义消息渲染器。
</PropertyReference>

<PropertyReference name="message-after" type="{ message: Message; position: 'after'; runId: string; messageIndex: number; messageIndexInRun: number; numberOfMessagesInRun: number; agentId: string; stateSnapshot: unknown }">
  在每条消息之后渲染，元数据与 `message-before` 相同。省略时，
  将改用为 `"after"` 位置注册的自定义消息渲染器。
</PropertyReference>

<PropertyReference name="activity-message" type="{ activityType: string; content: unknown; message: ActivityMessage; agent: unknown }">
  `role === "activity"` 消息的兜底插槽。若提供了更具体的
  `activity-<activityType>` 插槽，则优先使用后者。两个插槽都未提供时，
  会使用注册在 CopilotKit 实例上、匹配相应 `activityType` 的活动渲染器。
</PropertyReference>

<PropertyReference name="tool-call" type="{ name: string; args: unknown; status: string; result: string | undefined; toolCall: unknown; toolMessage: ToolMessage | undefined }">
  透传给助手消息子组件以渲染工具调用。特定的 `tool-call-<name>`
  插槽可按名称针对单个工具；其余情况由通用的 `tool-call` 插槽处理。
</PropertyReference>

## 用法

### 基本消息列表

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <copilot-chat-message-view
    :messages="agent?.messages ?? []"
    :is-running="agent?.isRunning ?? false"
  />
</template>
```

### 自定义助手消息与用户消息

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <copilot-chat-message-view
    :messages="agent?.messages ?? []"
    :is-running="agent?.isRunning ?? false"
  >
    <template #assistant-message="{ message }">
      <div class="bg-blue-50 p-4 rounded-xl">{{ message.content }}</div>
    </template>

    <template #user-message="{ message }">
      <div class="bg-gray-100 p-4 rounded-xl">{{ message.content }}</div>
    </template>
  </copilot-chat-message-view>
</template>
```

### 自定义输入指示器

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <copilot-chat-message-view
    :messages="agent?.messages ?? []"
    :is-running="agent?.isRunning ?? false"
  >
    <template #cursor>
      <div class="animate-pulse text-gray-400">Thinking...</div>
    </template>
  </copilot-chat-message-view>
</template>
```

### 渲染特定工具调用

```vue
<script setup lang="ts">
import { CopilotChatMessageView } from "@copilotkit/vue/v2";
import { useAgent } from "@copilotkit/vue/v2";

const { agent } = useAgent();
</script>

<template>
  <copilot-chat-message-view
    :messages="agent?.messages ?? []"
    :is-running="agent?.isRunning ?? false"
  >
    <template #tool-call-get_weather="{ args, status, result }">
      <div class="rounded-lg border p-3">
        <p>Status: {{ status }}</p>
        <p v-if="result">Result: {{ result }}</p>
      </div>
    </template>
  </copilot-chat-message-view>
</template>
```

## 行为

- **消息渲染**：每条消息会根据其 `role`（assistant、user、reasoning 或 activity）分发给对应的默认子组件，除非提供了相应的具名插槽。
- **去重**：共享同一 `id` 的消息会被去重；id 相同的助手消息分片会被合并（内容与工具调用合并）。在开发环境下，丢弃重复消息时会在控制台输出警告。
- **光标显示**：只有当 `isRunning` 为 `true` 且最后一条消息不是推理消息时，才会渲染 `cursor` 插槽。它出现在最后一条消息之后。
- **插槽透传**：传递给 `CopilotChatMessageView` 的插槽（包括 `tool-call` 和 `tool-call-<name>`）会透传给默认的助手与用户消息子组件，因此无需重新实现这些组件即可正常渲染工具调用。
- **自定义渲染器与活动渲染器**：当 `message-before`、`message-after` 或 `activity-message` 插槽被省略时，组件会回退到注册在 CopilotKit 实例上的渲染器，并在适用时按当前 `agentId` 限定作用范围。
