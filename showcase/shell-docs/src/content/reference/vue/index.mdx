`@copilotkit/vue` 把 CopilotKit 带到 Vue 3。它提供一个 [provider](/reference/vue/components/CopilotKitProvider)、一组预构建聊天组件，以及与 React SDK 对应的组合式函数。一切构建在 [AG-UI](https://docs.ag-ui.com) 智能体协议之上。

<Callout type="info">
  v2 API 位于 `/v2` 子路径下，与 web SDK 使用的约定一致。请从 `@copilotkit/vue/v2` 导入 provider、组件与组合式函数。
</Callout>

## 安装

```sh
npm install @copilotkit/vue
```

## 样式

使用预构建 UI 组件时，请在应用入口处一次性导入样式表：

```ts
import "@copilotkit/vue/styles.css";
```

## Provider 配置

用 [`CopilotKitProvider`](/reference/vue/components/CopilotKitProvider) 包裹你的应用（或某个子树）以配置运行时连接。组合式函数与组件通过 Vue 的 [provide/inject](https://vuejs.org/guide/components/provide-inject) 读取该上下文，因此必须在 provider 内使用。

```vue
<script setup lang="ts">
import { CopilotKitProvider, CopilotChat } from "@copilotkit/vue/v2";
import "@copilotkit/vue/styles.css";
</script>

<template>
  <CopilotKitProvider runtime-url="/api/copilotkit">
    <CopilotChat />
  </CopilotKitProvider>
</template>
```

## Vue 约定

本参考中有几种模式反复出现，且与 React SDK 不同：

- **返回状态的组合式函数使用 ref**：诸如 [`useAgent`](/reference/vue/hooks/useAgent) 的组合式函数返回响应式 ref（例如 `{ agent }`）。在 `<script setup>` 中用 `.value` 读取，或在模板中直接解包。`useFrontendTool` 等注册型组合式函数不返回值。
- **响应式参数**：许多组合式函数接受 `MaybeRefOrGetter` 参数，因此你可以传入普通值、`ref` 或 getter，组合式函数会对变化保持响应。
- **模板中 props 使用 kebab-case**：组件 props 以 camelCase 名称记录，但在模板中写作 kebab-case 属性（例如 `runtimeUrl` 写作 `runtime-url`）。
- **插槽取代 render props**：React SDK 使用 render props 或 `children` 的地方，Vue 组件提供具名[插槽](https://vuejs.org/guide/components/slots)实现同样的自定义。
