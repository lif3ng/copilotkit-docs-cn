## 概览

`useComponent` 是构建在 `useFrontendTool` 之上的一个便捷 hook。
它会注册一个工具，并使用工具调用参数在聊天中渲染 React 组件。

它属于 v2 工具渲染 hook 套件，同属该套件的还有 [`useRenderTool`](/reference/hooks/useRenderTool)、[`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool) 与 [`useRenderToolCall`](/reference/hooks/useRenderToolCall)。

当你想要一个可视化的组件渲染器、又不想手写完整的前端工具配置时，就使用它。

## 签名

```tsx
import { z } from "zod";
import type { ComponentType } from "react";
import { useComponent } from "@copilotkit/react-core/v2";

function useComponent<TSchema extends z.ZodTypeAny | undefined = undefined>(
  config: {
    name: string;
    description?: string;
    parameters?: TSchema;
    // When parameters is provided, props are inferred via z.infer.
    // When omitted, render accepts any props.
    render: ComponentType<InferRenderProps<TSchema>>;
    agentId?: string;
    followUp?: boolean;
  },
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

- `config.name`：智能体调用该组件工具所用的工具名称。
- `config.description`：可选的额外描述，用于引导模型。
- `config.parameters`：可选的 Zod schema，描述工具参数。提供时，`render` 的 props 会从该 schema 推断。省略时，工具会以空参数 schema（`{ "type": "object", "properties": {} }`）对外声明，因此智能体调用它时不带任何参数。
- `config.render`：以工具调用的参数为 props 进行渲染的 React 组件。调用流式进行期间，props 是参数的部分解析 JSON，而不是 schema 解析结果，因此字段可能缺失（参见行为）。省略 `parameters` 时可接受任意 props。
- `config.agentId`：可选的注册作用域（智能体）。
- `config.followUp`：渲染组件后智能体是否继续运行。默认为 `true`；设为 `false` 可在工具调用后停止。
- `deps`：可选的依赖数组，用于刷新注册。

## 行为

- 会在描述前追加一条默认指令：_“Use this tool to display the \"&lt;name&gt;\" component in the chat...”_。
- 内部调用 `useFrontendTool`，其渲染函数会把工具参数展开为组件 props。
- **工具调用流式进行期间，props 会分批到达。** 智能体一开始工具调用，组件就会渲染，并随每个参数流入而再次渲染。在调用完成前，任何字段都可能缺失。props 是智能体发送的参数，而不是 schema 解析后的结果，因此 `.default("c")` 这类 schema 默认值不会被填入。`render` 的类型显示的是完整参数，所以 TypeScript 不会告警。请在组件中把每个 prop 都当作可选处理，并为缺失字段渲染占位内容。
- 继承 `useFrontendTool` 的生命周期行为：重名覆盖警告、卸载时移除工具，以及为聊天历史保留渲染器。
- 以 `config.name` 加 `deps` 追踪更新（把任何会变化的捕获值放进 `deps`）。
- **`deps` 比较**：对纯数据（字符串、数字、布尔值、`null`、日期，以及由它们组成的普通对象和数组）按值比较，因此 `[{ status }]` 这类内联字面量只在其内容变化时才重新注册。函数与之前一样永远不会被判为已变化，所以请把会变化的回调保存在 ref 中。类实例与其他对象按引用比较，因此像 `useAgent` 返回的 `agent` 这样的循环引用值可以安全传入。增删条目也算变化。

## 用法

```tsx
const weatherCardSchema = z.object({
  city: z.string().describe("City name"),
  unit: z.enum(["c", "f"]).default("c"),
});

type WeatherCardProps = z.infer<typeof weatherCardSchema>;

// Props are partial while the tool call streams, so read each field as optional.
function WeatherCard({ city, unit }: Partial<WeatherCardProps>) {
  return (
    <div className="rounded border p-3">
      <div className="text-sm text-zinc-500">Weather request</div>
      <div className="font-medium">
        {city ?? "…"} ({(unit ?? "c").toUpperCase()})
      </div>
    </div>
  );
}

function App() {
  useComponent(
    {
      name: "showWeatherCard",
      description: "Render a weather card in chat for the requested city.",
      parameters: weatherCardSchema,
      render: WeatherCard,
    },
    [],
  );

  return null;
}
```
