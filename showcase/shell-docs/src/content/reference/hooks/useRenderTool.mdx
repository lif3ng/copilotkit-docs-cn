## 概览

`useRenderTool` 为工具调用注册一个聊天渲染器。
你可以针对某个具体的工具名称（携带带类型的 Zod `parameters` schema），也可以使用通配（`"*"`）兜底渲染器。

它属于 v2 工具渲染 Hook 套件，同套件的还有 [`useComponent`](/reference/hooks/useComponent)、[`useDefaultRenderTool`](/reference/hooks/useDefaultRenderTool) 与 [`useRenderToolCall`](/reference/hooks/useRenderToolCall)。

该 Hook 只负责渲染，不注册前端处理器。

## 签名

### 通配重载

```tsx
import { useRenderTool } from "@copilotkit/react-core/v2";

useRenderTool(
  {
    name: "*",
    render: (props) => React.ReactElement | null,
    agentId?: string,
    group?: boolean,
  },
  deps?: ReadonlyArray<unknown>,
);
```

### 具名重载

```tsx
import { z } from "zod";
import { useRenderTool } from "@copilotkit/react-core/v2";

useRenderTool(
  {
    name: string,
    parameters: z.ZodTypeAny,
    render: (props) => React.ReactElement | null,
    agentId?: string,
    group?: boolean,
  },
  deps?: ReadonlyArray<unknown>,
);
```

## Render Props

`render` 会收到以下状态之一：

- `{ status: "inProgress", parameters: Partial<T>, result: undefined }`
- `{ status: "executing", parameters: T, result: undefined }`
- `{ status: "complete", parameters: T, result: string }`

`name` 在所有状态下都始终存在。

## 行为

- `render` 可以返回 `null`，表示不为某个工具调用绘制任何内容。在渲染器被*调用*的地方，`null` 一直是合法的——`ReactToolCallRenderer.render` 是一个 `React.ComponentType`，函数组件返回 `ReactNode`，而 `null` 是 `ReactNode` 的成员之一——此前只有构建侧的签名禁止它。
- 通过 `defineToolCallRenderer` 构建渲染器条目。
- `group: true` 允许聊天界面把该渲染器绘制的调用折叠进它的工具调用组（参见 [`toolCallDisplay`](/reference/components/CopilotChatMessageView#toolcalldisplay)）。如果渲染器是你 UI 的一部分，或者可能什么都不绘制，请保持不设置；它们的调用始终会单独显示。
- 以 `agentId:name` 为键去重（后注册者生效）。
- 有意在清理时不移除渲染器，以便既往聊天历史仍能渲染。
- 以 `config.name` 加 `deps` 中的值跟踪更新（把会变化的捕获值放进 `deps`）。
- **`deps` 比较**：对普通数据（字符串、数字、布尔值、`null`、日期以及由它们组成的普通对象和数组）按值比较，因此 `[{ status }]` 这样的内联字面量只在其内容变化时才会重新注册。与之前一样，函数永远不会被视为已变化，所以请把会变化的回调保存在 ref 中。类实例和其他对象按引用（identity）比较，因此传入来自 `useAgent` 的 `agent` 这类循环引用的值是安全的。增删数组条目也算变化。

## 用法

### 具名工具渲染器

```tsx
function App() {
  useRenderTool(
    {
      name: "searchDocs",
      parameters: z.object({ query: z.string() }),
      render: ({ name, parameters, status, result }) => {
        if (status === "inProgress") return <div>Preparing {name}…</div>;
        if (status === "executing")
          return <div>Searching for: {parameters.query}</div>;
        return <div>Done: {result}</div>;
      },
    },
    [],
  );

  return null;
}
```

### 通配兜底渲染器

```tsx
function App() {
  useRenderTool(
    {
      name: "*",
      render: ({ name, status }) => (
        <div>
          {status === "complete" ? "✓" : "⏳"} {name}
        </div>
      ),
    },
    [],
  );

  return null;
}
```

### 禁用某个工具的渲染

返回 `null` 即可隐藏默认 UI。通配（`"*"`）无需 schema；具名工具则使用直通 schema（`z.any()`）。

```tsx
import { z } from "zod";

function App() {
  // One specific tool…
  useRenderTool(
    { name: "searchDocs", parameters: z.any(), render: () => null },
    [],
  );
  // …or everything without its own renderer.
  useRenderTool({ name: "*", render: () => null }, []);

  return null;
}
```
