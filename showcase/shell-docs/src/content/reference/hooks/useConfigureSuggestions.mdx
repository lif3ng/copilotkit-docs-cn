## 概览

`useConfigureSuggestions` 是一个 React hook，用于向 CopilotKit core 注册建议配置。它支持两种模式：**静态**建议（固定列表）与**动态**建议（由智能体根据指令生成）。

配置会在挂载时自动注册、卸载时自动移除。配置变化时，建议会自动重新加载。

## 签名

```tsx
import { useConfigureSuggestions } from "@copilotkit/react-core/v2";

function useConfigureSuggestions(
  config: SuggestionsConfigInput | null | undefined,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="config" type="SuggestionsConfigInput | null | undefined">
  建议配置。传入 `null` 或 `undefined` 可禁用建议。可以是 `DynamicSuggestionsConfig` 或 `StaticSuggestionsConfigInput`。

### 动态配置

适用于需要智能体在运行时生成建议的场景。

<PropertyReference name="instructions" type="string" required>
  供模型生成建议所用的提示或指令。这是区分动态配置与静态配置的关键字段。
</PropertyReference>

<PropertyReference name="minSuggestions" type="number" default="1">
  生成建议的最小数量。
</PropertyReference>

<PropertyReference name="maxSuggestions" type="number" default="3">
  生成建议的最大数量。
</PropertyReference>

<PropertyReference
  name="available"
  type="SuggestionAvailability"
  default='"after-first-message"'
>
  建议何时可用。可选值：- `"before-first-message"`——在发送任何消息之前显示建议。 - `"after-first-message"`——在第一条消息之后显示建议（动态配置的默认值）。 - `"always"`——始终显示建议。 - `"disabled"`——禁用建议。
</PropertyReference>

<PropertyReference name="providerAgentId" type="string" default='"default"'>
  生成建议的提供方智能体 ID。
</PropertyReference>

<PropertyReference name="consumerAgentId" type="string" default='"*"'>
  显示建议的消费方智能体 ID。默认为 `"*"`（所有智能体）。
</PropertyReference>

### 静态配置

适用于建议为预定义列表的场景。

<PropertyReference name="suggestions" type="StaticSuggestionInput[]" required>
  建议对象数组。每条建议包含：- `title: string`——建议的简短显示标题。 - `message: string`——选中时发送的消息内容。 - `isLoading?: boolean`——可选的加载状态（默认为 `false`）。
</PropertyReference>

<PropertyReference
  name="available"
  type="SuggestionAvailability"
  default='"before-first-message"'
>
  建议何时可用。可选值与动态配置相同。
</PropertyReference>

  <PropertyReference name="consumerAgentId" type="string" default='"*"'>
    显示建议的消费方智能体 ID。默认为 `"*"`（所有智能体）。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。当数组中任何值变化时，建议会重新加载。对于依赖外部状态的动态建议很有用。
</PropertyReference>

## 用法

### 静态建议

```tsx
function WelcomeSuggestions() {
  useConfigureSuggestions({
    suggestions: [
      { title: "Get started", message: "Help me get started with my project" },
      { title: "Show examples", message: "Show me some example use cases" },
      {
        title: "Documentation",
        message: "Where can I find the documentation?",
      },
    ],
    available: "before-first-message",
  });

  return null;
}
```

### 动态建议

```tsx
function SmartSuggestions() {
  useConfigureSuggestions({
    instructions:
      "Suggest follow-up questions based on the conversation so far. " +
      "Focus on actionable next steps the user might want to take.",
    maxSuggestions: 3,
    minSuggestions: 1,
    available: "after-first-message",
  });

  return null;
}
```

### 带依赖的动态建议

```tsx
function ContextualSuggestions() {
  const [topic, setTopic] = useState("general");

  useConfigureSuggestions(
    {
      instructions: `Generate suggestions related to the topic: ${topic}`,
      maxSuggestions: 3,
    },
    [topic],
  );

  return (
    <select value={topic} onChange={(e) => setTopic(e.target.value)}>
      <option value="general">General</option>
      <option value="technical">Technical</option>
      <option value="business">Business</option>
    </select>
  );
}
```

### 按条件禁用建议

```tsx
function ConditionalSuggestions({ enabled }: { enabled: boolean }) {
  useConfigureSuggestions(
    enabled
      ? {
          suggestions: [{ title: "Help", message: "I need help" }],
        }
      : null,
  );

  return null;
}
```

### 面向特定智能体

```tsx
function AgentSpecificSuggestions() {
  useConfigureSuggestions({
    instructions: "Suggest data analysis tasks the user can perform.",
    maxSuggestions: 4,
    providerAgentId: "analyst",
    consumerAgentId: "analyst",
    available: "always",
  });

  return null;
}
```

## 行为

- **自动注册**：配置在挂载时向 core 注册，卸载时移除。这保证了干净的生命周期管理。
- **变化检测**：该 hook 会把配置序列化为 JSON 进行比较。若序列化结果发生变化，旧配置会被移除并注册新配置，从而触发重新加载。
- **依赖追踪**：提供 `deps` 数组时，其值的任何变化都会触发建议重新加载，即使序列化后的配置本身没有变化。
- **配置判别**：该 hook 通过检查是否存在 `instructions` 属性来区分动态与静态配置。若存在 `instructions`，则视为动态配置。
- **禁用状态**：传入 `null`、`undefined` 或 `available: "disabled"` 的配置，会移除此前注册的所有配置，并且不再产生建议。
- **isLoading 归一化**：对于静态建议，`isLoading` 字段在未显式提供时默认为 `false`。
