## 概览

`useSuggestions` 是一个 React hook，用于获取指定智能体当前的聊天建议。它会订阅建议的变更事件，并在建议被更新、清除或重新加载时自动重新渲染。

建议通过 [`useConfigureSuggestions`](/reference/hooks/useConfigureSuggestions) 进行配置，既可以是静态的（预定义），也可以是动态的（由智能体生成）。

## 签名

```tsx
import { useSuggestions } from "@copilotkit/react-core/v2";

function useSuggestions(options?: UseSuggestionsOptions): UseSuggestionsResult;
```

## 参数

<PropertyReference name="options" type="UseSuggestionsOptions">
  该 hook 的可选配置对象。

  <PropertyReference name="agentId" type="string" default='"default"'>
    要获取其建议的智能体 ID。若省略，则回退到最近的 `CopilotChatConfigurationProvider` 提供的智能体 ID，否则为 `"default"`。
  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="result" type="UseSuggestionsResult">
  包含当前建议与控制函数的对象。

<PropertyReference name="suggestions" type="Suggestion[]">
  当前建议的数组。每个 `Suggestion` 包含：- `title: string` --
  建议的简短显示标题。 - `message: string` -- 选中该建议时发送的消息
  内容。 - `isLoading: boolean` -- 该建议是否仍在生成中。
</PropertyReference>

<PropertyReference name="reloadSuggestions" type="() => void">
  触发重新加载已解析智能体的建议。对于动态建议，这会重新执行生成过程。`isLoading` 状态会通过订阅事件自动更新。
</PropertyReference>

<PropertyReference name="clearSuggestions" type="() => void">
  清除已解析智能体的所有当前建议。
</PropertyReference>

  <PropertyReference name="isLoading" type="boolean">
    当前是否正在生成或加载建议。
  </PropertyReference>
</PropertyReference>

## 用法

### 基本用法

```tsx
function SuggestionsList() {
  const { suggestions, isLoading } = useSuggestions();

  if (isLoading) {
    return <div>Loading suggestions...</div>;
  }

  return (
    <ul>
      {suggestions.map((suggestion, i) => (
        <li key={i}>
          <strong>{suggestion.title}</strong>
          <p>{suggestion.message}</p>
        </li>
      ))}
    </ul>
  );
}
```

### 带重新加载与清除控件

```tsx
function SuggestionsPanel() {
  const { suggestions, reloadSuggestions, clearSuggestions, isLoading } =
    useSuggestions();

  return (
    <div>
      <div>
        <button onClick={reloadSuggestions} disabled={isLoading}>
          Refresh
        </button>
        <button onClick={clearSuggestions}>Clear</button>
      </div>
      {suggestions.map((suggestion, i) => (
        <button key={i} disabled={suggestion.isLoading}>
          {suggestion.title}
        </button>
      ))}
    </div>
  );
}
```

### 面向特定智能体

```tsx
function AgentSuggestions() {
  const { suggestions } = useSuggestions({ agentId: "support-agent" });

  return (
    <div>
      <h3>Support Agent Suggestions</h3>
      {suggestions.map((s, i) => (
        <div key={i}>{s.title}</div>
      ))}
    </div>
  );
}
```

## 行为

- **自动订阅**：该 hook 会在核心实例上订阅建议变更事件，并在已解析智能体的建议被添加、移除或更新时重新渲染。
- **智能体解析**：`agentId` 按以下优先级解析：显式传入的 `agentId` 选项、来自最近 `CopilotChatConfigurationProvider` 的 `agentId`，最后是默认智能体 ID（`"default"`）。
- **加载状态**：当动态建议重新加载开始时，`isLoading` 变为 `true`；生成完成后恢复为 `false`。
- **初始状态**：挂载时，该 hook 会从核心实例同步读取当前建议，因此静态建议不会出现不必要的加载闪烁。
