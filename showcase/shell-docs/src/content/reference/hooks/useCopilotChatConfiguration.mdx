## 概览

`useCopilotChatConfiguration` 是一个读取聊天配置上下文的 React hook。它返回最近的 `CopilotChatConfigurationProvider` 所提供的配置值；若不存在任何 Provider，则返回 `null`。

本页同时记录 **hook** 与 **`CopilotChatConfigurationProvider`** 组件，二者共同为聊天 UI 组件所用的本地化标签、智能体/线程绑定与弹窗状态提供一个轻量上下文。

## CopilotChatConfigurationProvider

一个 Provider 组件，向所有后代聊天组件暴露本地化标签、智能体与线程 ID，以及可选的弹窗状态。

### 签名

```tsx
import { CopilotChatConfigurationProvider } from "@copilotkit/react-core/v2";

<CopilotChatConfigurationProvider
  labels={...}
  agentId="my-agent"
  threadId="thread-123"
  isModalDefaultOpen={true}
>
  {children}
</CopilotChatConfigurationProvider>
```

### Props

<PropertyReference name="children" type="ReactNode" required>
  可以访问聊天配置上下文的子组件。
</PropertyReference>

<PropertyReference name="labels" type="Partial<CopilotChatLabels>">
  标签覆盖项的部分集合。未提供的标签会先回退到默认值，再回退到父 Provider 的标签。所有可用键参见下文 [CopilotChatLabels](#copilotchatlabels) 一节。
</PropertyReference>

<PropertyReference name="agentId" type="string" default='"default"'>
  与此聊天上下文关联的智能体 ID。回退到父 Provider 的 `agentId`，最后是 `"default"`。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  用于会话延续的线程 ID。若省略，回退到父 Provider 的 `threadId`，否则生成一个新的随机 UUID。
</PropertyReference>

<PropertyReference name="isModalDefaultOpen" type="boolean">
  提供时，会在该 Provider 内创建弹窗打开/关闭状态，其初始值用作默认状态。若省略，弹窗状态从父 Provider 继承（如有）。
</PropertyReference>

## useCopilotChatConfiguration

### 签名

```tsx
import { useCopilotChatConfiguration } from "@copilotkit/react-core/v2";

function useCopilotChatConfiguration(): CopilotChatConfigurationValue | null;
```

### 参数

该 hook 不接受任何参数。

### 返回值

在 `CopilotChatConfigurationProvider` 之外使用时返回 `null`。否则返回一个 `CopilotChatConfigurationValue` 对象：

<PropertyReference name="config" type="CopilotChatConfigurationValue">
  解析后的聊天配置。

<PropertyReference name="labels" type="CopilotChatLabels">
  完整解析后的标签对象，由默认值、父 Provider 与最近 Provider 的覆盖项合并而成。所有键参见 [CopilotChatLabels](#copilotchatlabels)。
</PropertyReference>

<PropertyReference name="agentId" type="string">
  该聊天上下文解析出的智能体 ID。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  该聊天上下文解析出的线程 ID。
</PropertyReference>

<PropertyReference name="isModalOpen" type="boolean | undefined">
  当前弹窗打开状态。若组件树中没有任何 Provider 通过 `isModalDefaultOpen` 创建弹窗状态，则为 `undefined`。
</PropertyReference>

  <PropertyReference name="setModalOpen" type="((open: boolean) => void) | undefined">
    控制弹窗打开状态的函数。若组件树中没有任何 Provider 创建弹窗状态，则为 `undefined`。
  </PropertyReference>
</PropertyReference>

## 用法

### 基本标签自定义

```tsx
import {
  CopilotChatConfigurationProvider,
  useCopilotChatConfiguration,
} from "@copilotkit/react-core/v2";

function App() {
  return (
    <CopilotChatConfigurationProvider
      labels={{
        chatInputPlaceholder: "Ask me anything...",
        modalHeaderTitle: "AI Assistant",
        welcomeMessageText: "Hello! What can I do for you?",
        chatDisclaimerText: "Responses are AI-generated.",
      }}
    >
      <ChatUI />
    </CopilotChatConfigurationProvider>
  );
}
```

### 在组件中读取配置

```tsx
function ChatHeader() {
  const config = useCopilotChatConfiguration();

  if (!config) {
    return <h2>Chat</h2>;
  }

  return <h2>{config.labels.modalHeaderTitle}</h2>;
}
```

### 绑定到特定智能体与线程

```tsx
function SupportChat() {
  return (
    <CopilotChatConfigurationProvider
      agentId="support-agent"
      threadId="ticket-456"
      labels={{
        chatInputPlaceholder: "Describe your issue...",
        modalHeaderTitle: "Support Chat",
      }}
    >
      <ChatWindow />
    </CopilotChatConfigurationProvider>
  );
}
```

### 弹窗状态管理

```tsx
import {
  CopilotChatConfigurationProvider,
  useCopilotChatConfiguration,
} from "@copilotkit/react-core/v2";

function App() {
  return (
    <CopilotChatConfigurationProvider isModalDefaultOpen={false}>
      <ToggleButton />
      <ChatModal />
    </CopilotChatConfigurationProvider>
  );
}

function ToggleButton() {
  const config = useCopilotChatConfiguration();

  if (!config?.setModalOpen) return null;

  return (
    <button onClick={() => config.setModalOpen!(!config.isModalOpen)}>
      {config.isModalOpen
        ? config.labels.chatToggleCloseLabel
        : config.labels.chatToggleOpenLabel}
    </button>
  );
}
```

### 嵌套 Provider

Provider 可以嵌套。子 Provider 会继承并合并父级的标签，子级覆盖项优先。

```tsx
function App() {
  return (
    <CopilotChatConfigurationProvider
      labels={{ chatDisclaimerText: "Company-wide disclaimer." }}
    >
      <CopilotChatConfigurationProvider
        agentId="sales"
        labels={{ modalHeaderTitle: "Sales Assistant" }}
      >
        {/* This context has both the company disclaimer and the sales title */}
        <SalesChat />
      </CopilotChatConfigurationProvider>
    </CopilotChatConfigurationProvider>
  );
}
```

## 行为

- **标签合并**：标签按以下顺序合并：内置默认值，然后是父 Provider 的标签，最后是当前 Provider 的标签。因此可以在任意层级进行部分覆盖。
- **智能体 ID 解析**：`agentId` 从最近的 Provider 解析，逐级回退到父 Provider，最后是 `"default"`。
- **线程 ID 生成**：如果任何层级都没有提供 `threadId`，会生成一个随机 UUID，并在 Provider 存续期间保持不变。
- **弹窗状态归属**：只有当 Provider 显式设置 `isModalDefaultOpen` 时才会创建弹窗状态（`isModalOpen` / `setModalOpen`）。未设置该 prop 的 Provider 会透传父级的弹窗状态。
- **返回 null**：在任何 `CopilotChatConfigurationProvider` 之外使用时，该 hook 返回 `null` 而不是抛出错误。组件应妥善处理这种情况。
