## 概览

`useFrontendTools` 一次调用即可注册多个客户端工具。当你编写组件时工具集合尚不确定——工具来自状态、props 或后端返回的列表——就使用它。

[`useFrontendTool`](/reference/hooks/useFrontendTool) 每次调用只注册一个工具，因此无法对长度会变化的列表做循环调用，那会破坏 Hook 的规则。`useFrontendTools` 则改为对整个数组运行单个 effect，所以数组这一次渲染可以为空，下一次渲染可以包含二十个条目。

每个条目与 `useFrontendTool` 接收的 `ReactFrontendTool` 对象相同。完整的工具结构（包括 `parameters`、`handler`、`render` 与 `webmcp`）请参见该页。

## 签名

```tsx
import { useFrontendTools } from "@copilotkit/react-core/v2";

function useFrontendTools(
  tools: ReadonlyArray<ReactFrontendTool<any>> | undefined,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="tools" type="ReadonlyArray<ReactFrontendTool<any>> | undefined" required>
  要注册的工具。数组可以为空、可以在两次渲染之间改变长度，也可以在数据尚在加载时为 `undefined`。每个条目的字段与 [`useFrontendTool`](/reference/hooks/useFrontendTool) 的 `tool` 参数相同。

  工具由 `name` 加 `agentId` 标识，因此同一个 `name` 可以服务于两个不同的智能体。如果同一个数组中出现了两次相同的 `name` 与 `agentId`，以最后一个条目为准，并会记录一条警告。
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。它的约定与 `useEffect` 的第二个参数相同。条目按引用比较，且数组在渲染之间必须保持长度恒定。只要有任何条目变化，注册就会刷新。当某个 handler 捕获了不属于工具定义的外部状态（例如路由器或 mutation 函数）时，请使用它。

  不要把源数据集合放在这里。该 Hook 本身已经以 `tools` 的内容为键。把 `reports` 或 `data` 加进 `deps` 会导致每次渲染都重新注册所有工具，因为那个数组每次都会重建。
</PropertyReference>

## 用法

### 从应用状态构建的工具

```tsx
function ReportTools({ reports }: { reports: Report[] }) {
  const navigate = useNavigate();

  useFrontendTools(
    reports.map((report) => ({
      name: `open_${report.id}`,
      description: `Open the ${report.title} report`,
      handler: async () => {
        navigate(`/reports/${report.id}`);
        return `Opened ${report.title}`;
      },
    })),
    [navigate],
  );

  return null;
}
```

`reports` 增加时，新工具会被注册；某个报告从列表中消失时，它的工具会被注销，其余工具保持注册状态。

### 由后端描述的工具

```tsx
function BackendTools() {
  const { data, isLoading } = useQuery({
    queryKey: ["tool-descriptors"],
    queryFn: fetchToolDescriptors,
  });

  useFrontendTools(
    data?.map((descriptor) => ({
      name: descriptor.name,
      description: descriptor.description,
      parameters: z.object({
        query: z.string().describe("What to look up"),
      }),
      handler: async ({ query }) => {
        const result = await runDescriptor(descriptor.id, query);
        return JSON.stringify(result);
      },
    })),
    [],
  );

  return isLoading ? <Spinner /> : null;
}
```

查询进行中时传入 `undefined`，不会注册任何工具。数据到达后工具随即出现，无需为加载状态编写另一条代码路径。

### 关闭部分工具

```tsx
function PermissionedTools({ isAdmin }: { isAdmin: boolean }) {
  useFrontendTools([
    {
      name: "searchOrders",
      description: "Search orders by status",
      parameters: z.object({ status: z.string() }),
      handler: async ({ status }) => JSON.stringify(await search(status)),
    },
    {
      name: "refundOrder",
      description: "Refund an order by ID (admin only)",
      parameters: z.object({ orderId: z.string() }),
      handler: async ({ orderId }) => refund(orderId),
      available: isAdmin,
    },
  ]);

  return null;
}
```

`available: false` 会保留工具的注册，但把它对智能体隐藏。切换该值会重新注册该工具，与 `useFrontendTool` 的行为一致。

### 带渲染组件的工具

```tsx
function ChartTools({ metrics }: { metrics: Metric[] }) {
  useFrontendTools(
    metrics.map((metric) => ({
      name: `chart_${metric.key}`,
      description: `Chart the ${metric.label} metric`,
      parameters: z.object({ days: z.number() }),
      handler: async ({ days }) => JSON.stringify(await load(metric, days)),
      render: ({ status, result }) => {
        if (status !== ToolCallStatus.Complete || !result) {
          return <div className="animate-pulse">Loading {metric.label}…</div>;
        }
        return <Chart data={JSON.parse(result)} />;
      },
    })),
    [],
  );

  return null;
}
```

## 行为

- **基于值的重新注册**：数组通常是内联构建的，因此它的引用每次渲染都会变化。该 Hook 改为以每个条目的 `name`、`description`、`agentId`、`available` 与 `webmcp` 为键。产生相等列表的重新渲染不会重新注册任何东西。
- **描述保持最新**：`description` 是键的一部分。由你的数据派生的描述，例如 `` `Open the ${report.title} report` ``，会在数据变化时立即同步给智能体，无需任何 `deps` 条目。这是该 Hook 的键与 [`useFrontendTool`](/reference/hooks/useFrontendTool) 唯一不同的地方——后者只以 `name`、`available` 与 `webmcp` 为键。
- **新增与移除**：列表变化时，新增的工具会被注册，离开的工具会被注销。同时出现在新旧列表中的工具会以最新定义重新注册。
- **卸载**：该 Hook 注册的所有工具都会在卸载时注销。
- **重名**：同一个数组中出现两次的 `name` 与 `agentId` 组合属于调用代码的错误。以最后一个条目为准，该 Hook 会记录一条指名该工具的警告。
- **覆盖其他注册**：如果相同 `name` 与 `agentId` 的工具已在别处注册，该 Hook 会覆盖它并记录一条警告，与 `useFrontendTool` 一致。
- **渲染组件生命周期**：带有 `render` 函数的条目会注册一个渲染器。渲染器在卸载后被有意保留在原处，以便历史中的既往工具调用仍能正常渲染。
- **handler 与 parameters 不属于键的一部分**：`handler` 是函数、`parameters` schema 是对象，两者都无法按值比较。只改动其中之一本身不会触发重新注册。当 handler 闭包引用了必须保持最新的值时请传入 `deps`，正如上面示例中对 `navigate` 的处理。
- **无返回值**：该 Hook 返回 `void`。
