## 概览

`useCapabilities` 返回某个智能体声明的 [AG-UI `AgentCapabilities`](https://docs.ag-ui.com/concepts/capabilities)。能力描述了智能体支持哪些特性——工具调用、流式传输、多智能体协同、人机协同（human-in-the-loop）等。

能力信息来自连接时 runtime 的 `/info` 响应。在 runtime 握手完成之前，或智能体未声明能力时，该值为 `undefined`。

## 签名

```tsx
import { useCapabilities } from "@copilotkit/react-core/v2";

function useCapabilities(agentId?: string): AgentCapabilities | undefined
```

## 参数

<PropertyReference name="agentId" type="string" default='"default"'>
  要读取其能力的智能体 ID。若省略，则使用默认智能体。
</PropertyReference>

## 返回值

<PropertyReference name="capabilities" type="AgentCapabilities | undefined">
  智能体的能力声明；如果智能体尚未上报能力（例如 runtime 握手仍在进行中），或未实现 `getCapabilities()`，则为 `undefined`。

  有值时，该对象包含以下可选类别：

  <PropertyReference name="identity" type="IdentityCapabilities">
    智能体元数据：`name`、`type`（框架）、`description`、`version`、`provider`、`documentationUrl`、`metadata`。
  </PropertyReference>

  <PropertyReference name="transport" type="TransportCapabilities">
    支持的传输方式：`streaming`、`websocket`、`httpBinary`、`pushNotifications`、`resumable`。
  </PropertyReference>

  <PropertyReference name="tools" type="ToolsCapabilities">
    工具支持情况：`supported`、`items`、`parallelCalls`、`clientProvided`。
  </PropertyReference>

  <PropertyReference name="output" type="OutputCapabilities">
    输出格式：`structuredOutput`、`supportedMimeTypes`。
  </PropertyReference>

  <PropertyReference name="state" type="StateCapabilities">
    状态管理：`snapshots`、`deltas`、`memory`、`persistentState`。
  </PropertyReference>

  <PropertyReference name="multiAgent" type="MultiAgentCapabilities">
    多智能体协同：`supported`、`delegation`、`handoffs`、`subAgents`。
  </PropertyReference>

  <PropertyReference name="reasoning" type="ReasoningCapabilities">
    推理/思考过程的可见性：`supported`、`streaming`、`encrypted`。
  </PropertyReference>

  <PropertyReference name="multimodal" type="MultimodalCapabilities">
    多模态输入/输出：`input` 与 `output` 子对象，涵盖图像、音频、视频、PDF 与文件支持。
  </PropertyReference>

  <PropertyReference name="execution" type="ExecutionCapabilities">
    代码执行：`codeExecution`、`sandboxed`、`maxIterations`、`maxExecutionTime`。
  </PropertyReference>

  <PropertyReference name="humanInTheLoop" type="HumanInTheLoopCapabilities">
    人机协同：`supported`、`approvals`、`interventions`、`feedback`。
  </PropertyReference>

  <PropertyReference name="custom" type="Record&lt;string, unknown&gt;">
    任意键值对，用于集成特有的能力。
  </PropertyReference>
</PropertyReference>

## 用法

### 根据能力条件渲染 UI

```tsx title="ToolPanel.tsx"
import { useCapabilities } from "@copilotkit/react-core/v2";

function ToolPanel() {
  const capabilities = useCapabilities();

  if (!capabilities?.tools?.supported) {
    return null; // Agent doesn't support tools — hide the panel
  }

  return (
    <div>
      <h3>Tools</h3>
      {capabilities.tools.clientProvided && (
        <p>This agent accepts client-provided tools.</p>
      )}
    </div>
  );
}
```

### 读取特定智能体的能力

```tsx title="AgentInfo.tsx"
import { useCapabilities } from "@copilotkit/react-core/v2";

function AgentInfo({ agentId }: { agentId: string }) {
  const capabilities = useCapabilities(agentId);

  if (!capabilities) {
    return <p>Loading capabilities…</p>;
  }

  return (
    <ul>
      <li>Streaming: {capabilities.transport?.streaming ? "Yes" : "No"}</li>
      <li>Tools: {capabilities.tools?.supported ? "Yes" : "No"}</li>
      <li>Human-in-the-loop: {capabilities.humanInTheLoop?.supported ? "Yes" : "No"}</li>
    </ul>
  );
}
```

## 行为

- **同步读取**——该 hook 直接从智能体实例读取 `capabilities`。没有单独的加载状态或异步请求——在 runtime `/info` 握手填充之前该值为 `undefined`，之后变为有值。
- **重渲染**——该 hook 内部调用了 `useAgent()`，因此组件会在智能体状态、消息与运行状态变化时重新渲染（默认 `updates` 集合）。如果你只需要能力信息、希望减少重渲染，可以通过 `useAgent({ updates: [] })` 直接读取 `agent.capabilities`。
- **稳定引用**——能力对象的引用只在智能体重连或 runtime 响应变化时才会改变。不会在每次渲染时都改变。
