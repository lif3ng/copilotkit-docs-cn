## 概览

`useFrontendTool` 在组件作用域内将一个客户端工具注册到 CopilotKit。当智能体决定调用该工具时，提供的 `handler` 函数会在浏览器中执行。你还可以选择提供一个 `render` 组件，在聊天界面中展示自定义 UI，以呈现工具的执行进度与结果。

该 Hook 管理完整的注册生命周期：如果同名工具已存在会发出警告，挂载时注册工具及其渲染组件，卸载时清理这两项注册。在 v2 中，参数 schema 改用 [Zod](https://zod.dev) 定义，而非普通的参数数组。

## 签名

```tsx
import { useFrontendTool } from "@copilotkit/react-core/v2";

function useFrontendTool<T extends Record<string, unknown>>(
  tool: ReactFrontendTool<T>,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="tool" type="ReactFrontendTool<T>" required>
  工具定义对象。

<PropertyReference name="name" type="string" required>
  工具的唯一名称。智能体在决定调用工具时会引用这个名称。如果已注册同名工具，则会记录一条警告。
</PropertyReference>

<PropertyReference name="description" type="string" required>
  一段自然语言描述，告诉智能体该工具做什么、何时使用。
</PropertyReference>

<PropertyReference name="parameters" type="z.ZodSchema" required>
  定义工具输入参数的 Zod schema。该 schema 驱动对外通告的工具 schema 与类型推断。运行时参数会被 JSON 解析，但不会对照该 schema 进行校验。
</PropertyReference>

<PropertyReference
  name="handler"
  type="(args: T, context: FrontendToolHandlerContext) => Promise<unknown>"
  required
>
  智能体调用工具时执行的异步函数。它接收解析后的参数（类型来自 `parameters`，但不做校验）以及上下文对象：

  - `toolCall`（`ToolCall`）—— 原始工具调用的元数据
  - `agent`（`AbstractAgent | undefined`）—— 调用该工具的智能体实例；通过 WebMCP 调用工具时不存在
  - `signal`（`AbortSignal | undefined`）—— 一个 `AbortSignal`，当用户停止智能体（通过 `stopAgent()` 或 `agent.abortRun()`）时会被中止。长时间运行的处理器可以检查 `signal.aborted` 以提前退出。
  - `isReplay`（`boolean | undefined`）—— 当该调用是在恢复线程历史时运行（见 `reconnectBehavior`）则为 `true`；来自实时运行的调用则不存在该字段。

  `FrontendToolHandlerContext` 从 `@copilotkit/core` 导出。
</PropertyReference>

<PropertyReference
  name="render"
  type="React.ComponentType<{ name: string; args: Partial<T>; status: ToolCallStatus; result: string | undefined }>"
>
  可选的 React 组件，渲染在聊天界面中，用于可视化工具的执行过程。该组件接收：- `name` —— 工具名称 - `args` —— 参数（流式传输期间为部分参数，执行开始后为完整参数） - `status` —— `ToolCallStatus.InProgress`、`ToolCallStatus.Executing` 或 `ToolCallStatus.Complete` 之一 - `result` —— 处理器返回的字符串结果（仅在状态为 `Complete` 时可用）
</PropertyReference>

  <PropertyReference name="available" type='"enabled" | "disabled" | "remote"' default='"enabled"'>
    控制工具的可用性。设为 `"disabled"` 可临时阻止智能体调用该工具；设为 `"remote"` 表示该工具由服务端处理。
  </PropertyReference>

  <PropertyReference name="reconnectBehavior" type='"passive" | "resume-pending"' default='"passive"'>
    当线程历史被恢复时（例如页面重新加载之后），该工具仍未应答的调用会如何处理。使用 `"passive"` 时，调用会显示但处理器不会运行。使用 `"resume-pending"` 时，处理器会针对该调用运行（其上下文中 `isReplay: true`），随后运行照常继续。只对可以安全重复运行的处理器启用该选项。在同一页面上，一个调用不会同时启动两次；但如果它的结果从未送达智能体，那么在停止或切换线程之后它可能再次运行，并且两个恢复同一线程的标签页可能各自运行一次。如果智能体在调用该工具的同时还调用了一个保持 passive 的工具，后续运行会发送那个没有结果的 passive 调用，某些模型提供方会拒绝这种消息。
  </PropertyReference>

  <PropertyReference name="webmcp" type="boolean | { annotations?: { readOnlyHint?: boolean; untrustedContentHint?: boolean } }">
    通过 WebMCP API（`document.modelContext`）同时把工具暴露给浏览器智能体。传 `true` 表示以默认注解注册，或传一个对象以携带 WebMCP 注解注册。浏览器智能体调用该工具时运行的是同一个 `handler`；此时上下文中没有 `agent`。在 WebMCP 不可用的环境（SSR、React Native 或未启用该 API 的浏览器）中这是空操作。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。提供后，只要数组中的值发生变化，工具注册就会刷新。当你的 handler 或 render 函数捕获了外部状态时，请使用它。

  `deps` 对普通数据（字符串、数字、布尔值、`null`、日期以及由它们组成的普通对象和数组）按值比较，因此 `[{ status }]` 这样的内联字面量只在其内容变化时才会重新注册。与之前一样，函数永远不会被视为已变化，所以请把会变化的回调保存在 ref 中。类实例和其他对象按引用（identity）比较，因此传入来自 `useAgent` 的 `agent` 这类循环引用的值是安全的。增删数组条目也算变化。
</PropertyReference>

## 用法

### 使用 Zod 参数的基础工具

```tsx
function TodoManager() {
  const [todos, setTodos] = useState<string[]>([]);

  useFrontendTool(
    {
      name: "addTodo",
      description: "Add a new item to the user's todo list",
      parameters: z.object({
        text: z.string().describe("The todo item text"),
        priority: z.enum(["low", "medium", "high"]).describe("Priority level"),
      }),
      handler: async ({ text, priority }) => {
        setTodos((prev) => [...prev, text]);
        return `Added "${text}" with ${priority} priority`;
      },
    },
    [],
  );

  return (
    <ul>
      {todos.map((t, i) => (
        <li key={i}>{t}</li>
      ))}
    </ul>
  );
}
```

### 带自定义渲染组件的工具

```tsx
function WeatherWidget() {
  useFrontendTool(
    {
      name: "getWeather",
      description: "Fetch and display weather information for a city",
      parameters: z.object({
        city: z.string().describe("City name"),
        units: z.enum(["celsius", "fahrenheit"]).default("celsius"),
      }),
      handler: async ({ city, units }, { signal }) => {
        const response = await fetch(
          `/api/weather?city=${city}&units=${units}`,
          { signal },
        );
        const data = await response.json();
        return JSON.stringify(data);
      },
      render: ({ args, status, result }) => {
        if (status === ToolCallStatus.InProgress) {
          return (
            <div className="animate-pulse">
              Fetching weather for {args.city}...
            </div>
          );
        }
        if (status === ToolCallStatus.Complete && result) {
          const data = JSON.parse(result);
          return (
            <div className="p-4 border rounded">
              <h3>{data.city}</h3>
              <p>
                {data.temperature}&deg; {data.units}
              </p>
              <p>{data.conditions}</p>
            </div>
          );
        }
        return null;
      },
    },
    [],
  );

  return null;
}
```

### 按条件启用的工具

```tsx
function AdminPanel({ isAdmin }: { isAdmin: boolean }) {
  useFrontendTool(
    {
      name: "deleteUser",
      description: "Delete a user account by ID (admin only)",
      parameters: z.object({
        userId: z.string().describe("The ID of the user to delete"),
      }),
      handler: async ({ userId }) => {
        await fetch(`/api/users/${userId}`, { method: "DELETE" });
        return `User ${userId} deleted`;
      },
      available: isAdmin ? "enabled" : "disabled",
    },
    [isAdmin],
  );

  return <div>{/* admin UI */}</div>;
}
```

### 将工具暴露给浏览器智能体（WebMCP）

传入 `webmcp` 可以同时在 `document.modelContext` 上注册该工具。支持 [WebMCP](https://developer.chrome.com/docs/ai/webmcp) 的浏览器智能体便能在页面打开期间发现并调用该工具。

```tsx
function OrderSearch() {
  useFrontendTool({
    name: "searchOrders",
    description: "Search the signed-in user's orders by status",
    parameters: z.object({
      status: z.enum(["open", "shipped", "delivered"]),
    }),
    handler: async ({ status }) => {
      const orders = await searchOrders(status);
      return JSON.stringify(orders);
    },
    webmcp: {
      annotations: { readOnlyHint: true },
    },
  });

  return null;
}
```

## LangGraph 智能体：description 与 system_prompt 的取舍

对于简单的 UI 控制类工具（例如切换主题），`description` 字段通常足以让 LangGraph 智能体在恰当的时机发现并调用该工具。对于**强制性**工具——即智能体在回答之前必须调用、而不能基于过期上下文自行推理的工具——应将清晰的 `description` 与智能体 `system_prompt` 中的明确指令配合使用。

```python title="agent.py — make mandatory tools explicit in system_prompt"
graph = create_agent( # create_agent supersedes the deprecated create_react_agent, which accepts neither middleware= nor system_prompt=
    model="openai:gpt-4o",
    tools=[],
    middleware=[CopilotKitMiddleware()],
    state_schema=CopilotKitState,
    system_prompt=(
        "You are a helpful assistant.\n\n"
        "IMPORTANT: When the user asks about current sales data, you MUST call "
        "the `fetch_sales_by_month_range` frontend tool first. "
        "Never answer from memory or previously seen context values."
    ),
)
```

完整模式与 TypeScript 示例参见[确保智能体可靠调用前端工具](/integrations/langgraph/frontend-tools#ensuring-your-agent-reliably-calls-frontend-tools)。

## 行为

- **重名检测**：如果已注册同名 `name` 的工具，该 Hook 会记录一条警告。同一时间每个名称只有一个工具处于激活状态。
- **挂载/卸载生命周期**：工具及其可选的渲染组件在挂载时注册，在卸载时移除。
- **依赖跟踪**：提供 `deps` 后，只要某个依赖发生变化，工具注册就会刷新。普通数据按值比较；函数和其他对象按引用比较。
- **WebMCP 注册**：设置了 `webmcp` 时，工具还会注册到 `document.modelContext` 上，并在卸载时注销。为此工具需要一个 `description`（WebMCP 会拒绝没有描述的工具）。
- **渲染组件生命周期**：如果提供了 `render` 函数，它会被加入内部的渲染工具调用注册表。它会接收流式传输的 `args`（`InProgress` 期间为部分参数，`Executing` 与 `Complete` 期间为完整参数）。
- **无返回值**：该 Hook 返回 `void`。
