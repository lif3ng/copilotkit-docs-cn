## 概览

`ToolCallStatus` 描述工具调用在其生命周期中所处的阶段——从参数仍在流式传入，到结果完整执行完毕。当你在前端工具处理器或自定义渲染逻辑中渲染或响应工具调用时会遇到它。

## 导入

```ts
import { ToolCallStatus } from "@copilotkit/core";
```

## 定义

```ts
enum ToolCallStatus {
  InProgress = "inProgress",
  Executing = "executing",
  Complete = "complete",
}
```

## 成员

<PropertyReference name="InProgress" type="inProgress">
  工具调用仍在接收中——它的参数正在流式传入，尚未完整。
</PropertyReference>

<PropertyReference name="Executing" type="executing">
  参数已完整到达，工具处理器正在运行。
</PropertyReference>

<PropertyReference name="Complete" type="complete">
  处理器已执行完毕，结果可用。
</PropertyReference>

## 用法

```ts
import { ToolCallStatus } from "@copilotkit/core";

function renderToolCall(status: ToolCallStatus) {
  switch (status) {
    case ToolCallStatus.InProgress:
      return "Receiving arguments…";
    case ToolCallStatus.Executing:
      return "Running…";
    case ToolCallStatus.Complete:
      return "Done";
  }
}
```
