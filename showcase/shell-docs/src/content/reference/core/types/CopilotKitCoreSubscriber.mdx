## 概览

`CopilotKitCoreSubscriber` 是传给 [`CopilotKitCore.subscribe`](/reference/core/classes/CopilotKitCore) 的对象。每个回调都是可选的，会接收一个始终包含 `copilotkit` 实例的事件对象，并可以返回 `void` 或 `Promise<void>`。可以用它来响应连接状态、工具执行、建议、配置变更和错误。

## 导入

```ts
import type { CopilotKitCoreSubscriber } from "@copilotkit/core";
```

## 定义

每个回调都是可选的，会接收一个始终包含 `copilotkit` 实例的事件对象，并返回 `void` 或 `Promise<void>`。下面的结构展示了具有代表性的 `onRuntimeConnectionStatusChanged` 回调；[属性](#属性)一节记录了每个回调的确切事件结构。

```ts
interface CopilotKitCoreSubscriber {
  onRuntimeConnectionStatusChanged?: (event: {
    copilotkit: CopilotKitCore;
    status: CopilotKitCoreRuntimeConnectionStatus;
  }) => void | Promise<void>;
  // ...one optional callback per lifecycle event (tool execution, agents,
  // context, suggestions, properties, headers, Inspector metadata, errors,
  // and thread stores).
  // See the Properties section below for each callback's event shape.
}
```

## 属性

<PropertyReference name="onRuntimeConnectionStatusChanged" type="(event) => void | Promise<void>">
  在运行时连接状态变化时触发。事件为 `{ copilotkit, status }`，其中 `status` 是一个 [`CopilotKitCoreRuntimeConnectionStatus`](/reference/core/enums/CopilotKitCoreRuntimeConnectionStatus)。
</PropertyReference>

<PropertyReference name="onToolExecutionStart" type="(event) => void | Promise<void>">
  在前端工具开始执行时触发。事件为 `{ copilotkit, toolCallId, agentId, toolName, args }`。
</PropertyReference>

<PropertyReference name="onToolExecutionEnd" type="(event) => void | Promise<void>">
  在前端工具执行结束时触发。事件为 `{ copilotkit, toolCallId, agentId, toolName, result, error? }`，其中 `result` 是字符串化后的工具结果。
</PropertyReference>

<PropertyReference name="onAgentsChanged" type="(event) => void | Promise<void>">
  在已注册智能体发生变化时触发。事件为 `{ copilotkit, agents }`。
</PropertyReference>

<PropertyReference name="onContextChanged" type="(event) => void | Promise<void>">
  在共享上下文变化时触发。事件为 `{ copilotkit, context }`。
</PropertyReference>

<PropertyReference name="onSuggestionsConfigChanged" type="(event) => void | Promise<void>">
  在建议配置变化时触发。事件为 `{ copilotkit, suggestionsConfig }`。
</PropertyReference>

<PropertyReference name="onSuggestionsChanged" type="(event) => void | Promise<void>">
  在为某个智能体生成的建议变化时触发。事件为 `{ copilotkit, agentId, suggestions }`。
</PropertyReference>

<PropertyReference name="onSuggestionsStartedLoading" type="(event) => void | Promise<void>">
  在某个智能体的建议生成开始时触发。事件为 `{ copilotkit, agentId }`。
</PropertyReference>

<PropertyReference name="onSuggestionsFinishedLoading" type="(event) => void | Promise<void>">
  在某个智能体的建议生成完成时触发。事件为 `{ copilotkit, agentId }`。
</PropertyReference>

<PropertyReference name="onPropertiesChanged" type="(event) => void | Promise<void>">
  在转发属性变化时触发。事件为 `{ copilotkit, properties }`。
</PropertyReference>

<PropertyReference name="onHeadersChanged" type="(event) => void | Promise<void>">
  在 `setHeaders` 接受了一个真正变化时触发——归一化后值不同的 record、新的构建器函数，或 record 与构建器之间的切换。构建器仅为某次请求解析出新 token 时不会触发（单纯的 token 轮换绝不会触发此回调）。事件为 `{ copilotkit, headers }`。
</PropertyReference>

<PropertyReference name="onInspectorMetadataChanged" type="(event) => void | Promise<void>">
  在可选的受信任 Inspector 元数据变化或被清除时触发。事件为 `{ copilotkit, inspectorMetadata }`，其中 `inspectorMetadata` 是一个 `InspectorMetadataV1 | undefined` 快照。元数据通知是有序的，某个回调失败不会阻塞后续的订阅者或刷新。
</PropertyReference>

<PropertyReference name="onError" type="(event) => void | Promise<void>">
  在发生错误时触发。事件为 `{ copilotkit, error, code, context }`，其中 `code` 是一个 [`CopilotKitCoreErrorCode`](/reference/core/enums/CopilotKitCoreErrorCode)。
</PropertyReference>

<PropertyReference name="onThreadStoreRegistered" type="(event) => void | Promise<void>">
  在线程存储注册时触发。事件为 `{ copilotkit, agentId, store }`。
</PropertyReference>

<PropertyReference name="onThreadStoreUnregistered" type="(event) => void | Promise<void>">
  在线程存储被移除时触发（通过显式注销，或被替代性的注册所替换）。先前的存储会通过 `prevStore` 传递。事件为 `{ copilotkit, agentId, prevStore }`。
</PropertyReference>

## 用法

```ts
const subscription = copilotkit.subscribe({
  onRuntimeConnectionStatusChanged: ({ status }) => {
    console.log("connection:", status);
  },
  onError: ({ code, error }) => {
    console.error(code, error);
  },
  onInspectorMetadataChanged: ({ inspectorMetadata }) => {
    console.log("project context:", inspectorMetadata);
  },
});

// later
subscription.unsubscribe();
```
