## 概览

`ProxiedCopilotRuntimeAgentConfig` 是 [`ProxiedCopilotRuntimeAgent`](/reference/core/classes/ProxiedCopilotRuntimeAgent) 的构造函数参数。它扩展了 AG-UI 的 `HttpAgentConfig`（省略了 `url`，它由 `runtimeUrl` 推导得出），并添加了代理访问 CopilotRuntime 所需的路由、传输方式和运行时模式字段。

## 导入

```ts
import type { ProxiedCopilotRuntimeAgentConfig } from "@copilotkit/core";
```

## 定义

```ts
interface ProxiedCopilotRuntimeAgentConfig
  extends Omit<HttpAgentConfig, "url"> {
  runtimeUrl?: string;
  transport?: CopilotRuntimeTransport;
  credentials?: RequestCredentials;
  runtimeMode?: RuntimeMode | "pending";
  intelligence?: IntelligenceRuntimeInfo;
  capabilities?: AgentCapabilities;
  debug?: ResolvedDebugConfig;
  runtimeAgentId?: string;
}
```

## 属性

<PropertyReference name="runtimeUrl" type="string">
  CopilotRuntime 的基础 URL。智能体的请求 URL 由该值和解析出的传输方式推导得出。
</PropertyReference>

<PropertyReference name="transport" type='"rest" | "single" | "auto"' default="auto">
  用于访问运行时的传输方式。`"auto"` 会先探测 REST，然后回退到单端点信封格式。
</PropertyReference>

<PropertyReference name="credentials" type="RequestCredentials">
  应用于运行时 fetch 请求的凭据模式（例如 `"include"`）。
</PropertyReference>

<PropertyReference name="runtimeMode" type='"sse" | "intelligence" | "pending"' default="sse">
  运行时模式。`"sse"` 和 `"intelligence"` 是已解析的模式；`"pending"` 表示模式尚未解析（在 Intelligence 委托路径上通过一次运行时信息获取来解析）。
</PropertyReference>

<PropertyReference name="intelligence" type="IntelligenceRuntimeInfo">
  以 Intelligence 模式运行时使用的运行时元数据（例如 websocket URL）。
</PropertyReference>

<PropertyReference name="capabilities" type="AgentCapabilities">
  由 `getCapabilities()` 返回的已声明的智能体能力。
</PropertyReference>

<PropertyReference name="debug" type="ResolvedDebugConfig">
  客户端事件管线的已解析调试配置。
</PropertyReference>

<PropertyReference name="runtimeAgentId" type="string">
  设置后，运行时请求会被路由到运行时上的这个智能体，而不是 `agentId`。本地的 `agentId` 仍作为注册表键，用于订阅者的内部记录；只有出站路由会被覆盖。
</PropertyReference>

## 用法

```ts
import { ProxiedCopilotRuntimeAgent } from "@copilotkit/core";

const agent = new ProxiedCopilotRuntimeAgent({
  runtimeUrl: "/api/copilotkit",
  agentId: "default",
  transport: "auto",
  credentials: "include",
});
```
