## 概览

`Suggestion` 表示呈现给用户的一条建议提示词（通常以可点击的胶囊按钮形式展示）。建议由 [`SuggestionsConfig`](/reference/core/types/SuggestionsConfig) 生成，并通过 [`CopilotKitCoreSubscriber.onSuggestionsChanged`](/reference/core/types/CopilotKitCoreSubscriber) 对外呈现。

## 导入

```ts
import type { Suggestion } from "@copilotkit/core";
```

## 定义

```ts
type Suggestion = {
  title: string;
  message: string;
  isLoading: boolean;
  className?: string;
};
```

## 属性

<PropertyReference name="title" type="string" required>
  显示在建议胶囊按钮上的简短标签。
</PropertyReference>

<PropertyReference name="message" type="string" required>
  选中该建议时发送给智能体的消息。
</PropertyReference>

<PropertyReference name="isLoading" type="boolean" required>
  表示该建议是否仍在生成中。
</PropertyReference>

<PropertyReference name="className" type="string">
  应用于建议胶囊按钮的可选 CSS 类名。
</PropertyReference>

## 用法

```ts
import type { Suggestion } from "@copilotkit/core";

const suggestion: Suggestion = {
  title: "Summarize",
  message: "Summarize the current document",
  isLoading: false,
};
```
