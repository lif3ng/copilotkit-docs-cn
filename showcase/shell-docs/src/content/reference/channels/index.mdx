Channels SDK 通过一个长驻的 `@copilotkit/channels` 进程将智能体连接到聊天提供方。在托管的 Slack 与 Microsoft Teams 路径中，提供方连接由 CopilotKit Intelligence 负责，而你的进程则负责智能体、工具、审批、状态与部署。该包还导出了由开发者自运营的直连适配器，覆盖 Slack、Teams、Discord 与 WhatsApp。

## 提供方指南

从你正在部署的提供方与智能体框架入手：

- [在 Slack 中连接并运行你的智能体](/slack/connect)
- [在 Microsoft Teams 中连接并运行你的智能体](/teams/connect)

在这些指南之间切换 Slack 与 Teams 时，提供方选择器会保留当前任务与已选的智能体框架。
