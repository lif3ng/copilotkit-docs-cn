---

`StateStore` 是 Channels 运行时所使用的异步持久化边界。

## 接口

```ts
interface StateStore {
  kv: {
    get<T>(key: string): Promise<T | undefined>;
    set<T>(key: string, value: T, ttlMs?: number): Promise<void>;
    consume<T>(key: string): Promise<T | undefined>;
    delete(key: string): Promise<void>;
  };
  list: {
    append<T>(
      key: string,
      value: T,
      options?: { maxLen?: number; ttlMs?: number },
    ): Promise<number>;
    range<T>(key: string, start?: number, stop?: number): Promise<T[]>;
    trim(key: string, maxLen: number): Promise<void>;
    delete(key: string): Promise<void>;
  };
  lock: {
    acquire(
      key: string,
      options?: { ttlMs?: number },
    ): Promise<{ token: string } | null>;
    release(key: string, token: string): Promise<void>;
  };
  dedup: {
    seen(key: string, ttlMs: number): Promise<boolean>;
  };
  queue: {
    enqueue<T>(
      key: string,
      value: T,
      options?: {
        maxSize?: number;
        onFull?: "drop-oldest" | "drop-newest";
      },
    ): Promise<number>;
    dequeue<T>(key: string): Promise<T | undefined>;
    depth(key: string): Promise<number>;
  };
}
```

## 语义

- `list.range` 按最旧优先排列，并使用非负的闭区间索引。
- `kv.consume` 原子地返回并删除一个值。并发调用方最多只能观察到一次非 `undefined` 的结果。
- `list.append({ ttlMs })` 会设置整个列表的过期时间。不带 `ttlMs` 的 append 会保留既有的过期时间。
- 当另一个令牌持有未过期的锁时，`lock.acquire` 返回 `null`。
- `lock.release` 不得释放由其他（或更新的）令牌持有的锁。
- `dedup.seen` 首次观察到时返回 `false`，在 TTL 内重复出现时返回 `true`。
- 队列为 FIFO。所配置的溢出策略必须是确定性的。

远程存储必须支持可 JSON 序列化的值。`MemoryStore` 按引用保留对象，但该行为不可移植。

## 一致性测试

```ts
import { runStateStoreConformance } from "@copilotkit/channels/testing";

runStateStoreConformance("postgres", () => createPostgresStateStore());
```

KV 消费、锁、去重与队列在跨进程时必须是原子的。请使用项目/Channel 命名空间来防止键冲突。

通过 `createChannel({ store: { adapter } })` 传入适配器。参见[持久化与扩缩容](/slack/persistence-and-scaling)。
