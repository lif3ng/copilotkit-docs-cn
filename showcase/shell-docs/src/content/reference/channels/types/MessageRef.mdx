`MessageRef` 标识一条提供方消息：

```ts
interface MessageRef {
  id: string;
  [key: string]: unknown;
}
```

将 ref 与 `thread.update()` 或 `thread.delete()` 配合使用：

```ts
const ref = await thread.post("Working…");
await thread.update(ref, "Done.");
```

## 托管生命周期

`thread.post()` 返回的 ref 携带当次托管投递的路由信息。不要把它持久化下来，并指望在后续投递中仍能用它进行编辑。

对于后续的组件回调，请使用 `ctx.message.ref`。在可用时，Intelligence 会将源提供方消息标记到该次交互投递上：

```ts
if (message.ref.id) {
  try {
    await thread.update(message.ref, "Updated");
  } catch {
    // Provider updates are best-effort.
  }
}
```

Teams 的 `Action.Submit` 可能不带 `replyToId` 就到达，从而产生空 ref。Slack 与 Teams 的删除能力也各有差异；参见 [`Thread`](/reference/channels/classes/Thread)。
