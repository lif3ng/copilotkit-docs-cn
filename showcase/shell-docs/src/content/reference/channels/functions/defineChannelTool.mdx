---
title: defineChannelTool
description: 定义一个经 Standard Schema 校验的工具，自动推导参数类型并提供 Channels 线程上下文。
---

`defineChannelTool` 用于保留工具定义，同时从其 Standard Schema 推导出处理器参数类型。

## 签名

```ts
function defineChannelTool<Schema extends ObjectSchema>(
  tool: ChannelTool<Schema>,
): ChannelTool<Schema>;
```

```ts
interface ChannelTool<Schema extends ObjectSchema> {
  name: string;
  description: string;
  parameters: Schema;
  handler(
    args: InferSchemaOutput<Schema>,
    context: ChannelToolContext,
  ): unknown | Promise<unknown>;
}
```

## 示例

```ts title="tools.ts"
import { defineChannelTool } from "@copilotkit/channels";
import { z } from "zod";

export const getIncident = defineChannelTool({
  name: "get_incident",
  description: "Read an incident by id.",
  parameters: z.object({
    incidentId: z.string(),
  }),
  async handler({ incidentId }) {
    const incident = await incidents.get(incidentId);
    return incident;
  },
});
```

在 `createChannel({ tools })` 中注册工具，在启动前用 `channel.tool(tool)` 添加单个工具，或把回合级作用域的工具传给 `thread.runAgent({ tools })`。

## 处理器上下文

| 字段       | 类型                           | 托管行为                                                          |
| ---------- | ------------------------------ | ------------------------------------------------------------------------- |
| `thread`   | `Thread`                       | 当前会话的句柄。                                              |
| `message`  | `IncomingMessage \| undefined` | 当运行由消息触发开始时，为当前入站消息。        |
| `user`     | `ApplicationUser \| null`      | 为此事件选出的应用用户。                                 |
| `actor`    | `ProviderActor`                | 触发此事件的提供方账号。                                  |
| `signal`   | `AbortSignal \| undefined`     | 保留的可选字段；当前 SDK 工具运行器不为其赋值（保持 undefined）。 |
| `platform` | `string`                       | 归一化的来源提供方，例如 `"slack"` 或 `"teams"`。               |

数据类工具可直接返回原始对象或数组。SDK 会把非字符串结果 JSON 序列化后交给模型。已经发送过 UI 的工具应返回一句简短的自然语言确认，以免模型重复渲染同一张卡片。

完整的托管示例参见 [Tools and context](/slack/tools)。
