---
title: renderToIR
description: 将 Channels JSX 或文本转换为可序列化的 ChannelNode 中间表示。
---

`renderToIR(renderable)` 会把片段（fragment）与函数组件展开为由原生（intrinsic）`ChannelNode` 值构成的数组。

## 签名

```ts
function renderToIR(ui: Renderable): ChannelNode[];
```

```ts
type Renderable =
  | string
  | ChannelNode
  | ChannelNode[]
  | { raw: unknown; provider?: "slack" | "teams" };
```

## 示例

```tsx
import { Header, Message, renderToIR } from "@copilotkit/channels/ui";

const ir = renderToIR(
  <Message>
    <Header>Incident update</Header>
  </Message>,
);
```

运行时会在绑定回调与渲染消息之前自动调用它。组件测试或自定义适配器场景可以直接使用它。

字符串，以及用作组件子元素的数字，会成为 `text` 节点。`false`、`null` 和 `undefined` 不会渲染任何内容。函数组件会被立即求值，因此请保持其纯净，避免包含提供方相关的副作用。

`{ raw, provider }` 逃生舱口会生成特定提供方的 `raw` 节点。原生块使用 `provider: "slack"`，单个 Adaptive Card 对象使用 `provider: "teams"`。省略 `provider` 时默认为 Slack。若把 raw 节点发送给不匹配的活跃提供方，会在该效果真正触达提供方之前显式报错；它绝不会被转换改写或静默丢弃。
