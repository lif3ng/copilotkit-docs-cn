---
title: defineChannelCommand
description: 定义一个归一化的直连适配器命令，及其自由文本或结构化参数。
---

`defineChannelCommand` 用于保留命令定义，并在提供方提供结构化选项时推导出它们。

## 签名

```ts
function defineChannelCommand<Schema extends ObjectSchema>(
  command: ChannelCommand<Schema>,
): ChannelCommand<Schema>;
```

```ts
interface ChannelCommand<Schema extends ObjectSchema> {
  name: string;
  description?: string;
  options?: Schema;
  handler(
    context: CommandContext<InferSchemaOutput<Schema>>,
  ): void | Promise<void>;
}
```

## 示例

```ts title="commands.ts"
import { defineChannelCommand } from "@copilotkit/channels";

export const triage = defineChannelCommand({
  name: "triage",
  description: "Triage the current conversation.",
  async handler({ thread, text, user, platform }) {
    await thread.runAgent({
      prompt: text || "Triage this conversation.",
      context: [
        { description: "Provider", value: platform },
        {
          description: "Invoking user",
          value: user?.name ?? user?.id ?? "unknown",
        },
      ],
    });
  },
});
```

在启动前通过 `createChannel({ commands: [triage] })` 或 `channel.onCommand(triage)` 注册它。

托管 Slack 和 Teams 不会分发命令：以斜杠开头的内容仍作为普通消息处理。此 API 适用于开发者自有的直连适配器发出 `IncomingCommand` 的场景。

## CommandContext

| 字段        | 类型                      | 说明                                                                                     |
| ----------- | ------------------------- | ---------------------------------------------------------------------------------------- |
| `thread`    | `Thread`                  | 调用该命令的会话。                                               |
| `command`   | `string`                  | 归一化名称：不含前导斜杠，统一小写；连字符与下划线路由等价。 |
| `text`      | `string`                  | 直连适配器提供的原始参数文本。                                         |
| `options`   | `TOptions`                | 适配器提供时的结构化选项。                                        |
| `user`      | `ApplicationUser \| null` | 由 `identifyUser` 选出的应用用户。                                              |
| `actor`     | `ProviderActor`           | 调用该命令的提供方账号。                                                |
| `platform`  | `string`                  | 直连适配器报告的原生提供方。                                           |
| `openModal` | function 或 `undefined`   | 仅当适配器支持打开模态框时才存在。                                     |

托管提供方的边界限制参见 [Commands and reactions](/slack/commands-and-reactions)。
