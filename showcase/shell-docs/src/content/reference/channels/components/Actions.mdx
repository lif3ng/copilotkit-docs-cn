---
title: "Actions"
description: "在一条消息的操作区中组合可移植按钮与 Slack 选择控件。"
---

`Actions` 用于组合交互控件。

```tsx
import { Actions, Button, Message, Section } from "@copilotkit/channels/ui";

<Message>
  <Section>Approve this deployment?</Section>
  <Actions>
    <Button value="approve" style="primary" onClick={handleDecision}>
      Approve
    </Button>
    <Button value="deny" style="danger" onClick={handleDecision}>
      Deny
    </Button>
  </Actions>
</Message>;
```

| Prop       | 类型          | 说明                              |
| ---------- | ------------- | --------------------------------- |
| `children` | `BotChildren` | 交互式 Channels 组件。            |

托管 Slack 会渲染一个操作块（actions block）。托管 Teams 会将 `Button` 子元素提升到 Adaptive Card 的顶层操作。跨提供方的托管工作流请使用按钮。Teams 的 Button 回调会在 `ctx.values` 中收到具名的 Adaptive Card 输入字段；Teams 不会将 `Select.onSelect` 或 `Input.onSubmit` 作为独立回调分发。
