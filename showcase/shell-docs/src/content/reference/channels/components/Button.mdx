---
title: "Button"
description: "在 Slack 与 Microsoft Teams 中发布可移植的回调按钮或链接按钮。"
---

`Button` 创建可移植性最高的托管交互控件。

```tsx
import { Actions, Button } from "@copilotkit/channels/ui";

<Actions>
  <Button
    value={{ approved: true }}
    style="primary"
    onClick={async ({ action, thread }) => {
      if (action.value) await thread.resume(action.value);
    }}
  >
    Approve
  </Button>
</Actions>;
```

## Props

| Prop       | 类型                      | 说明                                                                                  |
| ---------- | ------------------------- | ------------------------------------------------------------------------------------- |
| `value`    | `TValue`                  | 作为 `ctx.action.value` 返回的 JSON 可序列化值。它同时会推断回调的值类型。            |
| `onClick`  | `ClickHandler<TValue>`    | 原生按钮提交的回调。                                                                  |
| `url`      | `string`                  | 创建原生链接按钮。设置后，`onClick` 与 `value` 会被忽略。                             |
| `style`    | `"primary" \| "danger"`   | 映射到最接近的提供方强调样式。                                                        |
| `children` | `BotChildren`             | 按钮标签。                                                                            |

托管 Slack 渲染一个 Block Kit 按钮。托管 Teams 渲染 `Action.Submit`，设置 `url` 时则渲染 `Action.OpenUrl`。Teams 的提交可能在缺少来源消息引用的情况下到达，因此只有当 `ctx.message.ref.id` 非空时才调用 `thread.update()`。

注册拥有 `onClick` 的具名组件。当按钮必须在 runner 重启后仍然可用时，添加持久化的 `StateStore`。
