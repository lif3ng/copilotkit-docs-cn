---
title: Table、Row 与 Cell
description: 使用可移植的 Channels 表格原语渲染表格数据。
---

`Table` 用于组织 `Row` 与 `Cell` 子元素。

```tsx
import { Cell, Row, Table } from "@copilotkit/channels/ui";

<Table
  columns={[
    { header: "Service", align: "left" },
    { header: "p95", align: "right" },
  ]}
>
  <Row>
    <Cell>Checkout</Cell>
    <Cell>1.8s</Cell>
  </Row>
</Table>;
```

## 属性

| 组件 | 属性 | 类型 | 说明 |
| --- | --- | --- | --- |
| `Table` | `columns` | `{ header: string; align?: "left" \| "center" \| "right" }[]` | 可选的表头与对齐元数据。 |
| `Table` | `children` | `BotChildren` | `Row` 子元素。 |
| `Row` | `children` | `BotChildren` | `Cell` 子元素。 |
| `Cell` | `children` | `BotChildren` | 单元格文本。 |

托管 Slack 会渲染原生表格块；托管 Teams 则会渲染 Adaptive Card 1.5 表格。两种渲染器都会按提供方的预算限制行数、列数与单元格文本长度。对于无法显示原生表格结构的客户端，请在表格外保留一段简短的文字摘要。
