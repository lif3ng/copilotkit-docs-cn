---
title: Markdown
description: 渲染一个显式的可移植 Markdown 文本块。
---

`Markdown` 是一个用于承载格式化内容的显式正文文本块。

```tsx
import { Markdown, Message } from "@copilotkit/channels/ui";

<Message>
  <Markdown>{"**Owner:** Payments\n\n`p95 = 1.8s`"}</Markdown>
</Message>;
```

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `children` | `BotChildren` | Markdown 文本与可移植的子内容。 |

它目前映射到与 [`Section`](/reference/channels/components/Section) 相同的提供方原语：Slack `mrkdwn` 以及一个可换行的 Teams `TextBlock`。当源内容的语义意图是格式化文本时，请使用它。
