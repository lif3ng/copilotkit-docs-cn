---
title: Divider
description: 在富文本 Channels 消息中添加一个可移植的视觉分隔线。
---

`Divider` 不接受任何 props 或子元素。

```tsx
import { Divider, Message, Section } from "@copilotkit/channels/ui";

<Message>
  <Section>Summary</Section>
  <Divider />
  <Section>Next action</Section>
</Message>;
```

托管 Slack 会渲染一个分隔线块。Adaptive Cards 没有独立的分隔元素，因此托管 Teams 会渲染一个空的分隔文本块来形成视觉边界。
