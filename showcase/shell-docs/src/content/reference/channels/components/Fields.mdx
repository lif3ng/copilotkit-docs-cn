---
title: Fields and Field
description: 在 Slack 和 Microsoft Teams 中渲染紧凑的标签-值事实信息。
---

`Fields` 将若干 `Field` 值组合成紧凑的事实布局。

```tsx
import { Field, Fields, Message } from "@copilotkit/channels/ui";

<Message>
  <Fields>
    <Field>Owner: Payments</Field>
    <Field>Status: Investigating</Field>
  </Fields>
</Message>;
```

## Props

| 组件 | Prop | 类型 | 说明 |
| --- | --- | --- | --- |
| `Fields` | `children` | `BotChildren` | `Field` 子元素。 |
| `Field` | `label` | `string` | 可选的提供方标签。托管 Slack 会以粗体渲染它。 |
| `Field` | `children` | `BotChildren` | 字段值。 |

托管 Slack 会创建 section 字段并遵循 `label` prop。托管 Teams 则通过在每个字段文本的第一个冒号处拆分来创建 Adaptive Card `FactSet`；它目前不会读取 `label` prop。当同一个组件需要在两个提供方中都保留标签时，请像示例中那样使用 `Label: value` 形式的文本。
