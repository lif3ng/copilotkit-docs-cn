---
title: "Context"
description: "在可移植的 Channels 消息中渲染弱化的元数据或脚注文本。"
---

`Context` 在主消息内容下方渲染次要元数据。

```tsx
import { Context, Message, Section } from "@copilotkit/channels/ui";

<Message>
  <Section>Deployment completed.</Section>
  <Context>Production · commit 4f8a2d1</Context>
</Message>;
```

| Prop       | 类型          | 说明             |
| ---------- | ------------- | ---------------- |
| `children` | `BotChildren` | 次要文本内容。   |

托管 Slack 渲染一个上下文块（context block）。托管 Teams 渲染小号、低调、可换行的文本。不要把必要指令只放在 `Context` 里，因为原生客户端会有意弱化它。
