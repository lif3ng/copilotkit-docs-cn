---
title: Image
description: 在可移植的 Slack 或 Microsoft Teams 消息中渲染一个图片 URL。
---

`Image` 向富文本消息中添加一张可从外部访问的图片。

```tsx
import { Image, Message } from "@copilotkit/channels/ui";

<Message>
  <Image
    url="https://example.com/status.png"
    alt="Checkout latency over the last hour"
  />
</Message>;
```

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `url` | `string` | 必填的图片 URL。 |
| `alt` | `string` | 无障碍替代文本。 |

托管 Slack 会渲染一个图片块。托管 Teams 则渲染一个 Adaptive Card 图像。提供方客户端必须能够在不携带你应用私有 cookie 或请求头的情况下抓取该 URL。当图片必须以字节形式上传时，请使用 `thread.postFile()`。
