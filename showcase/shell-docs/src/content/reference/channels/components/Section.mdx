---
title: Section
description: 在 Slack 或 Microsoft Teams 中渲染可移植的正文区块。
---

`Section` 用于渲染富消息的主体正文。

```tsx
import { Message, Section } from "@copilotkit/channels/ui";

<Message>
  <Section>Checkout latency is **above the SLO**.</Section>
</Message>;
```

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `children` | `BotChildren` | 文本与嵌套的可移植内容。 |

托管 Slack 会将 GitHub 风格 Markdown 转换为 Slack 的 `mrkdwn`；托管 Teams 则会渲染外层包裹的 Adaptive Card `TextBlock`。各提供方的 Markdown 方言并不完全一致，因此复杂表格、提及（mention）和链接请在两个客户端中分别验证。
