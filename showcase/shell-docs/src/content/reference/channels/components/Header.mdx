---
title: Header
description: 在 Slack Block Kit 消息或 Teams Adaptive Card 中渲染一个可移植的标题行。
---

`Header` 在消息顶部附近渲染醒目的文本。

```tsx
import { Header, Message } from "@copilotkit/channels/ui";

<Message>
  <Header>INC-421 · Investigating</Header>
</Message>;
```

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `children` | `BotChildren` | 文本与嵌套的可移植内容。 |

托管 Slack 会渲染一个纯文本 header 块。托管 Teams 则渲染一个加大、加粗、可换行的 `TextBlock`。标题请保持简短；各提供方都会将文本截断至其原生负载预算之内。
