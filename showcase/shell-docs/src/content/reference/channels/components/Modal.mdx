---
title: Modal
description: 导出的模态框组件族参考，及其在托管 Channels 中的可用性。
---

UI 包为支持模态框的适配器导出了 `Modal`、`TextInput`、`ModalSelect`、`ModalSelectOption` 和 `RadioButtons`。

```tsx
import {
  Modal,
  ModalSelect,
  ModalSelectOption,
  TextInput,
} from "@copilotkit/channels/ui";

<Modal callbackId="triage" title="Triage incident" submitLabel="Assign">
  <TextInput id="summary" label="Summary" multiline />
  <ModalSelect id="owner" label="Owner">
    <ModalSelectOption label="Payments" value="payments" />
  </ModalSelect>
</Modal>;
```

<Callout type="warn" title="托管 Slack 或 Teams 上不可用">
  Intelligence 适配器会报告 `supportsModals: false`；托管交互上下文不会暴露 `openModal`，托管入口也不会投递模态框的提交或关闭事件。请改用已发送的 `Button` 卡片，并在稍后调用 `thread.resume(value)`。
</Callout>

## Modal 的 props

| Prop | 类型 | 说明 |
| --- | --- | --- |
| `callbackId` | `string` | 用于提交与关闭路由的稳定 id。 |
| `title` | `string` | 模态框标题。 |
| `submitLabel` | `string` | 可选的提交按钮标签。 |
| `closeLabel` | `string` | 可选的关闭按钮标签。 |
| `notifyOnClose` | `boolean` | 在支持的适配器上请求关闭事件。 |
| `privateMetadata` | `string` | 原样回传给提交或关闭处理器的不透明元数据。 |
| `children` | `BotChildren` | 模态框输入组件。 |

这些组件对直连适配器仍然公开可用。对于本文所记载的托管 Slack 与 Teams 配置，它们仅供参考。
