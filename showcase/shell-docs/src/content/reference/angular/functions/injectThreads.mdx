---
title: "injectThreads"
description: "Angular 函数，用于借助 signal 列出和管理 CopilotKit Intelligence 线程，支持分页、实时更新以及注入器作用域的自动清理。"
---

## 概览

`injectThreads` 以 Angular signal 和稳定回调的形式返回单个智能体的线程列表与各项变更操作。它会从 CopilotKit Intelligence 拉取经运行时身份验证的用户的线程，在可用时通过实时更新保持元数据最新，并按最近一次智能体活动对列表排序。

在 Angular 注入上下文（例如组件字段初始化器或构造函数）中调用它。当所属注入器被销毁时，列表订阅、实时连接和核心 store 注册会自动移除。

## 签名

```ts
import { injectThreads } from "@copilotkit/angular";

function injectThreads(input: InjectThreadsInput): InjectThreadsResult;
```

## 输入

<PropertyReference name="agentId" type="string | Signal<string>" required>
  要列出并管理其线程的智能体。提供 signal 时，store 会在其值变化时重新连接。
</PropertyReference>

<PropertyReference name="includeArchived" type="boolean | Signal<boolean | undefined>">
  是否包含已归档的线程。默认为 `false`。
</PropertyReference>

<PropertyReference name="limit" type="number | Signal<number | undefined>">
  每页线程的最大数量。提供该值后，可通过 `hasMoreThreads` 和 `fetchMoreThreads` 进行基于游标的分页。
</PropertyReference>

<PropertyReference name="enabled" type="boolean | Signal<boolean | undefined>">
  是否允许该 store 发起请求或订阅。默认为 `true`。对于在获得访问权限前必须完全不发起网络请求的受控界面，请将其设为 `false`。
</PropertyReference>

## 返回值

返回的 `InjectThreadsResult` 包含：

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `threads` | `Signal<Thread[]>` | 以服务器为准的列表，按最近一次智能体活动排序 |
| `isLoading` | `Signal<boolean>` | 列表初始加载状态 |
| `listError` | `Signal<Error \| null>` | 适合展示给用户的列表或变更错误 |
| `error` | `Signal<Error \| null>` | 最近一次错误，包括开发者配置错误 |
| `fetchMoreError` | `Signal<Error \| null>` | 最近一次下一页请求的错误 |
| `hasMoreThreads` | `Signal<boolean>` | 是否还有下一页可用 |
| `isFetchingMoreThreads` | `Signal<boolean>` | 下一页是否正在加载 |
| `isMutating` | `Signal<boolean>` | 是否有重命名、归档、恢复或删除操作正在进行 |
| `fetchMoreThreads()` | `() => void` | 在存在下一页时获取下一页 |
| `refetchThreads()` | `() => void` | 刷新列表且不清空当前可见列表 |
| `startNewThread()` | `() => void` | 重置为全新的客户端线程；持久化从其首次运行开始 |
| `renameThread(id, name)` | `Promise<void>` | 重命名线程 |
| `archiveThread(id)` | `Promise<void>` | 通过可逆归档隐藏线程 |
| `unarchiveThread(id)` | `Promise<void>` | 恢复已归档的线程 |
| `deleteThread(id)` | `Promise<void>` | 永久删除线程 |

每个 `Thread` 都包含 `id`、`agentId`、`name`、`archived`、`createdAt`、`updatedAt`，以及可选的 `lastRunAt`。面向用户的活动时间戳应优先使用 `lastRunAt`，因为仅元数据的变化也可能更新 `updatedAt`。

## 用法

```ts title="src/app/thread-list.component.ts"
import { Component, signal } from "@angular/core";
import { injectThreads } from "@copilotkit/angular";

@Component({
  selector: "app-thread-list",
  standalone: true,
  template: `
    <button type="button" (click)="threads.startNewThread()">
      New conversation
    </button>

    @if (threads.isLoading()) {
      <p>Loading conversations…</p>
    } @else {
      @for (thread of threads.threads(); track thread.id) {
        <button type="button" (click)="selectedThreadId.set(thread.id)">
          {{ thread.name ?? "Untitled conversation" }}
        </button>
      }
    }

    @if (threads.listError()) {
      <p>Conversations could not be loaded.</p>
      <button type="button" (click)="threads.refetchThreads()">Retry</button>
    }

    @if (threads.hasMoreThreads()) {
      <button
        type="button"
        [disabled]="threads.isFetchingMoreThreads()"
        (click)="threads.fetchMoreThreads()"
      >
        Load more
      </button>
    }
  `,
})
export class ThreadListComponent {
  readonly selectedThreadId = signal<string | undefined>(undefined);
  readonly threads = injectThreads({
    agentId: "support",
    limit: 20,
  });
}
```

在同个功能模块内，将选中的 id 绑定到聊天组件：

```html
<copilot-chat agentId="support" [threadId]="selectedThreadId()" />
```

## 变更行为

重命名、归档、取消归档和删除都会以乐观更新的方式刷新可见列表，并返回一个在平台确认操作后才敲定（settle）的 Promise。请在调用方 UI 中处理拒绝情况。删除操作不可逆，如果请求失败会回滚其乐观移除；调用它之前应先请用户确认。

面向最终用户的提示信息请使用 `listError`。更宽泛的 `error` signal 可能包含配置细节，例如缺少运行时 URL 或线程端点不可用，它面向的是开发者诊断。
