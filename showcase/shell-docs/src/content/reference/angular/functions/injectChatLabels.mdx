---

## 概览

`injectChatLabels` 返回当前作用域内完整的 [`CopilotChatLabels`](/reference/angular/functions/provideCopilotChatLabels#parameters) 集合：即通过 [`provideCopilotChatLabels`](/reference/angular/functions/provideCopilotChatLabels) 提供的标签覆盖项与 `COPILOT_CHAT_DEFAULT_LABELS` 合并后的结果。如果未提供任何标签，则原样返回默认值。

它（可选地）读取 `COPILOT_CHAT_LABELS` 注入令牌，因此必须在 Angular 注入上下文（构造函数、字段初始化器或工厂函数）中运行。预构建聊天组件会在内部调用它；当你构建自己的聊天 UI 并希望使用同样的可配置文案时，可以直接调用它。

## 签名

```ts
import { injectChatLabels } from "@copilotkit/angular";

function injectChatLabels(): CopilotChatLabels;
```

## 返回值

返回一个完整的 `CopilotChatLabels` 对象。由于该值是你的覆盖项与默认值合并后的结果，每个字段始终存在（永远不会是 `undefined`）。

## 用法

在注入上下文中调用它，并读取你需要的标签。

```ts title="src/app/my-chat.component.ts"
import { Component } from "@angular/core";
import { injectChatLabels } from "@copilotkit/angular";

@Component({
  selector: "app-my-chat",
  standalone: true,
  template: `<input [placeholder]="labels.chatInputPlaceholder" />`,
})
export class MyChatComponent {
  protected readonly labels = injectChatLabels();
}
```
