## 概览

`provideCopilotChatLabels` 返回一个 Angular [`Provider`](https://angular.dev/guide/di/dependency-injection-providers)，用于自定义预构建聊天组件中通用的文字标签，例如输入框占位符、工具栏按钮标签、免责声明文本和欢迎消息。你只需传入一部分标签，它们会合并到默认值之上，因此只覆盖你想修改的字符串。

将它加入应用或组件的 `providers` 数组。组件通过 [`injectChatLabels`](/reference/angular/functions/injectChatLabels) 读取合并后的标签。

完整的默认值集合位于 `COPILOT_CHAT_DEFAULT_LABELS` 中。你省略的任何字段都会回退到其默认值。

## 签名

```ts
import { provideCopilotChatLabels } from "@copilotkit/angular";
import type { Provider } from "@angular/core";

function provideCopilotChatLabels(
  config: Partial<CopilotChatLabels>,
): Provider;
```

## 返回值

返回一个 Angular `Provider`，它将合并后的标签绑定到 `COPILOT_CHAT_LABELS` 注入令牌。

## 用法

在应用配置中覆盖几个标签。你没有列出的内容都保留默认值。

```ts title="src/app/app.config.ts"
import { ApplicationConfig } from "@angular/core";
import {
  provideCopilotKit,
  provideCopilotChatLabels,
} from "@copilotkit/angular";

export const appConfig: ApplicationConfig = {
  providers: [
    provideCopilotKit({ runtimeUrl: "/api/copilotkit" }),
    provideCopilotChatLabels({
      chatInputPlaceholder: "Ask me anything...",
      welcomeMessageText: "Welcome! What can I help you build?",
    }),
  ],
};
```

你也可以不把提供器加进应用配置，而是加入功能组件的 `providers` 数组，从而将标签的作用域限定在应用的一部分。
