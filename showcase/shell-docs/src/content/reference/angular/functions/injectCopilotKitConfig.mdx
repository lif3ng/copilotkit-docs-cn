## 概览

`injectCopilotKitConfig` 返回你通过 [`provideCopilotKit`](/reference/angular/functions/provideCopilotKit) 注册的 [`CopilotKitConfig`](/reference/angular/functions/provideCopilotKit#parameters)。它读取绑定到 `COPILOT_KIT_CONFIG` 注入令牌的值，因此必须在 Angular 注入上下文（构造函数、字段初始化器或工厂函数）中运行。

大多数应用不会直接调用它。[`CopilotKit`](/reference/angular/services/CopilotKit) 服务会在内部使用它来构建自己的核心。当你需要读取所提供的原始配置时（例如读取自己的 `properties` 或 `runtimeUrl`），可以使用它。

## 签名

```ts
import { injectCopilotKitConfig } from "@copilotkit/angular";

function injectCopilotKitConfig(): CopilotKitConfig;
```

## 返回值

返回绑定到 `COPILOT_KIT_CONFIG` 令牌的 `CopilotKitConfig`。注意 `headers` 字段反映的是 `provideCopilotKit` 计算出的合并后请求头，其中可能包含由你的 `licenseKey` 推导出的 `X-CopilotCloud-Public-Api-Key` 请求头。

## 用法

在注入上下文中调用它，例如服务构造函数或组件字段初始化器。

```ts title="src/app/runtime-info.service.ts"
import { Injectable } from "@angular/core";
import { injectCopilotKitConfig } from "@copilotkit/angular";

@Injectable({ providedIn: "root" })
export class RuntimeInfoService {
  private readonly config = injectCopilotKitConfig();

  get runtimeUrl(): string | undefined {
    return this.config.runtimeUrl;
  }
}
```
