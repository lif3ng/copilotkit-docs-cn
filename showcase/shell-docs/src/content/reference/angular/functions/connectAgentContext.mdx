---

---

## 概览

`connectAgentContext` 向智能体注册 [context](https://docs.ag-ui.com/concepts/context)，使其能够读取你的应用状态。它接受静态的 `Context` 对象或无参访问器。内部的 Angular `effect` 会追踪访问器读取的所有 signals，并在它们变化时更新上下文。

注册包裹在 Angular `effect` 中，因此当所属组件或服务销毁时，上下文会自动清理。

若需基于模板的方式，请使用 [`CopilotKitAgentContext`](/reference/angular/directives/CopilotKitAgentContext) 指令。

<Callout type="warn">
  请在 Angular 注入上下文中调用它，例如构造函数或字段初始化器。当前实现会先解析环境注入器再读取配置，因此传入 `config.injector` 也无法让上下文之外的调用生效。
</Callout>

## 签名

```ts
import { connectAgentContext } from "@copilotkit/angular";
import type { Injector } from "@angular/core";
import type { Context } from "@ag-ui/client";

interface ConnectAgentContextConfig {
  injector?: Injector;
}

function connectAgentContext(
  context: Context | (() => Context),
  config?: ConnectAgentContextConfig,
): void;
```

## 参数

<PropertyReference name="context" type="Context | (() => Context)" required>
  要与智能体共享的上下文，或返回该上下文的无参访问器。`Context` 是一个包含以下字段的对象。当访问器读取 Angular signals 时，这些 signals 变化时上下文会重新注册。

  <PropertyReference name="description" type="string" required>
    一段人类可读的说明，描述此上下文表示什么，例如 `"User preferences"`。
  </PropertyReference>

  <PropertyReference name="value" type="string" required>
    上下文的值。传入前请先对非字符串值做字符串化（例如使用 `JSON.stringify`）。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="config" type="ConnectAgentContextConfig">
  可选配置。你仍必须在注入上下文中调用该函数。

  <PropertyReference name="injector" type="Injector">
    用于解析 `CopilotKit` 并持有响应式 effect 的注入器。提供时优先于环境注入器。
  </PropertyReference>
</PropertyReference>

## 用法

### 静态上下文

```ts title="src/app/preferences.component.ts"
import { Component } from "@angular/core";
import { connectAgentContext } from "@copilotkit/angular";

@Component({
  selector: "app-preferences",
  standalone: true,
  template: `<!-- ... -->`,
})
export class PreferencesComponent {
  constructor() {
    connectAgentContext({
      description: "User preferences",
      value: JSON.stringify({ theme: "dark", locale: "en-US" }),
    });
  }
}
```

### 使用访问器的响应式上下文

传入一个读取 signals 的访问器，让智能体始终看到当前值。

```ts title="src/app/cart.component.ts"
import { Component, signal } from "@angular/core";
import { connectAgentContext } from "@copilotkit/angular";

@Component({
  selector: "app-cart",
  standalone: true,
  template: `<button (click)="add()">Add item</button>`,
})
export class CartComponent {
  readonly items = signal<string[]>([]);

  constructor() {
    // Re-registers with the agent whenever the cart changes.
    connectAgentContext(() => ({
      description: "Current shopping cart",
      value: JSON.stringify(this.items()),
    }));
  }

  add() {
    this.items.update((items) => [...items, "Item"]);
  }
}
```

## 行为

- **响应式更新**。当访问器读取 signals 时，只要其中任一 signals 变化，上下文就会被移除并重新添加。
- **自动清理**。注册运行在 Angular `effect` 内部；effect 被销毁时上下文会被移除——这发生在所属组件、服务或注入器销毁之时。
- **必须在注入上下文中调用**。在注入上下文之外调用该函数时，Angular 会抛出 `NG0203`。
