---
title: "injectCapabilities"
description: "Angular 函数，以只读 signal 的形式读取智能体声明的能力。"
---

## 概览

`injectCapabilities` 以 Angular signal 的形式返回已解析智能体声明的 [AG-UI `AgentCapabilities`](https://docs.ag-ui.com/concepts/capabilities)。

能力信息来自运行时 `/info` 响应。该函数是基于 `injectAgentStore` 的便捷选择器；它不单独维护能力状态，也不会自行发起请求。在运行时发现完成之前，或当智能体未声明能力时，该 signal 为 `undefined`。

## 签名

```ts
import { injectCapabilities } from "@copilotkit/angular";
import type { Signal } from "@angular/core";
import type { AgentCapabilities } from "@ag-ui/core";

function injectCapabilities(
  agentId?: string | Signal<string | undefined>,
): Signal<AgentCapabilities | undefined>;
```

## 参数

<PropertyReference
  name="agentId"
  type="string | Signal<string | undefined>"
  required={false}
>
  要读取其能力的智能体的 ID。显式提供的 id 优先。省略或为 `undefined` 时，函数会使用外围 `CopilotChatConfiguration` 的智能体，再回退到默认智能体。传入 signal 可响应式切换智能体。
</PropertyReference>

## 返回值

<PropertyReference
  name="capabilities"
  type="Signal<AgentCapabilities | undefined>"
>
  一个只读 signal，包含已解析智能体的能力声明。`undefined` 表示运行时发现尚未完成，或智能体未声明能力；它并不代表某项能力一定不受支持。
</PropertyReference>

## 用法

```ts title="src/app/tool-panel.component.ts"
import { Component } from "@angular/core";
import { injectCapabilities } from "@copilotkit/angular";

@Component({
  selector: "app-tool-panel",
  standalone: true,
  template: `
    @if (capabilities()?.tools?.supported === true) {
      <p>This agent supports tools.</p>
    }
  `,
})
export class ToolPanelComponent {
  readonly capabilities = injectCapabilities();
}
```

要读取其他智能体或响应式切换，请在组件类中传入其 id 或 id signal：

```ts
import { signal } from "@angular/core";
import { injectCapabilities } from "@copilotkit/angular";

export class AgentCapabilitiesComponent {
  readonly agentId = signal<string | undefined>("support");
  readonly capabilities = injectCapabilities(this.agentId);
}
```
