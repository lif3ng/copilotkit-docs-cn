## 概览

`CopilotChatInput` 是聊天的输入区域。它渲染文本框、发送按钮、可选的工具菜单、添加文件按钮以及语音转写控件。它有三种模式：`"input"`（默认文本框）、`"transcribe"`（录制音频并显示转写控件）和 `"processing"`（智能体运行期间禁用文本框与发送按钮）。

`CopilotChatInput` 需要父注入器提供 `ChatState`。它通过 `injectChatState` 读取该状态，并把提交、值变化、转写与文件上传接到了该状态上。它的输出会在这些内置行为之外额外触发，因此你可以在不禁用内置行为的情况下观察交互。

## 用法

`CopilotChatInput` 是一个 standalone 组件，选择器为 `copilot-chat-input`。下面的示例提供了所需的 `ChatState`。如果希望由 CopilotKit 替你管理该状态，请使用 [`CopilotChat`](/reference/angular/components/CopilotChat)。

```ts title="src/app/chat.component.ts"
import { Component, forwardRef, signal } from "@angular/core";
import { ChatState, CopilotChatInput } from "@copilotkit/angular";

@Component({
  selector: "app-chat",
  standalone: true,
  imports: [CopilotChatInput],
  providers: [
    {
      provide: ChatState,
      useExisting: forwardRef(() => ChatComponent),
    },
  ],
  template: `
    <copilot-chat-input
      [autoFocus]="true"
      (submitMessage)="onSubmit($event)"
    />
  `,
})
export class ChatComponent extends ChatState {
  readonly inputValue = signal("");

  submitInput(value: string) {
    // Send the message through your chat state owner.
    console.log("user submitted:", value);
  }

  changeInput(value: string) {
    this.inputValue.set(value);
  }
}
```

## 输入

### 行为输入

<PropertyReference name="mode" type='"input" | "transcribe" | "processing"'>
  受控的输入模式。省略时组件以 `"input"` 模式启动，并自行管理后续的模式切换。
</PropertyReference>

<PropertyReference name="toolsMenu" type='(ToolsMenuItem | "-")[]'>
  输入工具菜单的条目。每个 `ToolsMenuItem` 都有一个 `label`，以及 `action` 回调或嵌套的 `items`。使用字符串 `"-"` 表示分隔符。为空时，除非添加文件操作可用，否则工具菜单会隐藏。
</PropertyReference>

<PropertyReference name="autoFocus" type="boolean" default="true">
  视图初始化后文本框是否自动聚焦。省略时默认为 `true`。
</PropertyReference>

<PropertyReference name="value" type="string">
  文本框的受控值。省略时组件读取 `ChatState` 中保存的值。显式传入空字符串会使文本框保持为空。
</PropertyReference>

<PropertyReference name="inputClass" type="string">
  已由组件声明，但当前版本并未应用它。请使用宿主 `class` 或插槽覆盖。
</PropertyReference>

<PropertyReference name="additionalToolbarItems" type="TemplateRef<any>">
  一个模板，渲染在工具栏前置条目之后，用于向工具栏添加你自己的控件。
</PropertyReference>

### 文本框输入

<PropertyReference name="textAreaClass" type="string">
  应用于默认文本框的类。
</PropertyReference>

<PropertyReference name="textAreaMaxRows" type="number">
  文本框滚动前可增长到的最大行数。
</PropertyReference>

<PropertyReference name="textAreaPlaceholder" type="string">
  文本框的占位文本。
</PropertyReference>

### 插槽覆盖输入

每个交互部件都可以用组件类（`*Component`）替换。同一插槽的模板会从内容投影中读取。

<PropertyReference name="sendButtonComponent" type="Type<any>">
  发送按钮的组件类。可用 `sendButtonClass` 为默认按钮设置样式。
</PropertyReference>

<PropertyReference name="toolbarComponent" type="Type<any>">
  工具栏的组件类。
</PropertyReference>

<PropertyReference name="textAreaComponent" type="Type<any>">
  文本框的组件类。
</PropertyReference>

<PropertyReference name="audioRecorderComponent" type="Type<any>">
  转写模式下显示的录音器的组件类。
</PropertyReference>

<PropertyReference name="startTranscribeButtonComponent" type="Type<any>">
  开始转写按钮的组件类。
</PropertyReference>

<PropertyReference name="cancelTranscribeButtonComponent" type="Type<any>">
  取消转写按钮的组件类。
</PropertyReference>

<PropertyReference name="finishTranscribeButtonComponent" type="Type<any>">
  完成转写按钮的组件类。
</PropertyReference>

<PropertyReference name="addFileButtonComponent" type="Type<any>">
  添加文件按钮的组件类。
</PropertyReference>

<PropertyReference name="toolsButtonComponent" type="Type<any>">
  工具菜单按钮的组件类。
</PropertyReference>

<Callout type="warn">
  当前版本为工具栏、录音器、转写按钮、添加文件按钮和工具按钮声明了类输入，但并未应用它们。`sendButtonClass` 和 `textAreaClass` 则会生效。
</Callout>

## 输出

这些事件会在输入组件内置处理之外额外触发，因此你可以在不替换默认行为的情况下观察交互。

<PropertyReference name="submitMessage" type="string">
  用户发送消息时（按 Enter 而非 Shift+Enter，或点击发送按钮）触发，携带去除首尾空白后的消息文本。
</PropertyReference>

<PropertyReference name="valueChange" type="string">
  文本框值每次变化时触发。
</PropertyReference>

<PropertyReference name="startTranscribe" type="void">
  语音转写开始时触发（输入组件切换到 transcribe 模式）。
</PropertyReference>

<PropertyReference name="cancelTranscribe" type="void">
  语音转写被取消时触发（输入组件返回 input 模式）。
</PropertyReference>

<PropertyReference name="finishTranscribe" type="void">
  语音转写完成时触发（输入组件返回 input 模式）。
</PropertyReference>

<PropertyReference name="finishTranscribeWithAudio" type="Blob">
  转写完成且带有录音时触发，携带录制的音频 blob。该 blob 也会交给周边的 `ChatState` 进行转写。
</PropertyReference>

<PropertyReference name="addFile" type="void">
  添加文件操作被触发时触发。仅在周边聊天启用了附件功能时可用。
</PropertyReference>

## 插槽

要进行深度定制，可在 `<copilot-chat-input>` 内提供具名的 `<ng-template>` 元素。每个模板都通过 `contentChild` 读取，且优先级高于对应的 `*Component` 输入。发送按钮与工具栏模板会收到带类型的上下文。

<PropertyReference name="sendButton" type="TemplateRef<SendButtonContext>">
  自定义发送按钮。上下文：`send: () => void`、`disabled: boolean`、`value: string`。
</PropertyReference>

<PropertyReference name="toolbar" type="TemplateRef<ToolbarContext>">
  自定义工具栏。上下文：`mode: CopilotChatInputMode`、`value: string`。
</PropertyReference>

<PropertyReference name="textArea" type="TemplateRef<any>">
  自定义文本框。
</PropertyReference>

<PropertyReference name="audioRecorder" type="TemplateRef<any>">
  转写模式的自定义录音器。
</PropertyReference>

<PropertyReference name="startTranscribeButton" type="TemplateRef<any>">
  自定义开始转写按钮。
</PropertyReference>

<PropertyReference name="cancelTranscribeButton" type="TemplateRef<any>">
  自定义取消转写按钮。
</PropertyReference>

<PropertyReference name="finishTranscribeButton" type="TemplateRef<any>">
  自定义完成转写按钮。
</PropertyReference>

<PropertyReference name="addFileButton" type="TemplateRef<any>">
  自定义添加文件按钮。
</PropertyReference>

<PropertyReference name="toolsButton" type="TemplateRef<any>">
  自定义工具菜单按钮。
</PropertyReference>

### 工具菜单示例

```ts title="src/app/chat.component.ts"
import { Component, forwardRef, signal } from "@angular/core";
import { ChatState, CopilotChatInput } from "@copilotkit/angular";
import type { ToolsMenuItem } from "@copilotkit/angular";

@Component({
  selector: "app-chat",
  standalone: true,
  imports: [CopilotChatInput],
  providers: [
    {
      provide: ChatState,
      useExisting: forwardRef(() => ChatComponent),
    },
  ],
  template: `
    <copilot-chat-input [toolsMenu]="toolsMenu" />
  `,
})
export class ChatComponent extends ChatState {
  readonly inputValue = signal("");
  toolsMenu: (ToolsMenuItem | "-")[] = [
    { label: "Summarize", action: () => this.summarize() },
    "-",
    { label: "Translate", action: () => this.translate() },
  ];

  summarize() {}
  translate() {}

  submitInput(value: string) {
    // Send the message through your chat state owner.
  }

  changeInput(value: string) {
    this.inputValue.set(value);
  }
}
```
