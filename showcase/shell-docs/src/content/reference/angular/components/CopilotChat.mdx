## 概览

`CopilotChat` 是一站式聊天组件。它将智能体接入 [`CopilotChatView`](/reference/angular/components/CopilotChatView)，只需一个选择器就能得到可用的聊天界面。它通过 [`injectAgentStore`](/reference/angular/functions/injectAgentStore) 解析智能体，订阅该智能体的消息与运行状态，管理建议，跟踪输入值，处理语音转写，接入文件附件，并在每条消息发送后清空输入。

`CopilotChat` 继承自 `ChatState`，并将自身提供给其下的视图与输入组件。通常你只需把它指向一个智能体。

如果只需要布局而不需要智能体接线，可直接使用 [`CopilotChatView`](/reference/angular/components/CopilotChatView)。

## 用法

`CopilotChat` 是一个 standalone 组件，选择器为 `copilot-chat`。将该类导入组件的 `imports` 数组，并在模板中使用该元素。聊天组件从 [`provideCopilotKit`](/reference/angular/functions/provideCopilotKit) 读取配置，因此该 provider 必须在作用域内。

```ts title="src/app/app.component.ts"
import { Component } from "@angular/core";
import { CopilotChat } from "@copilotkit/angular";

@Component({
  selector: "app-root",
  standalone: true,
  imports: [CopilotChat],
  template: `<copilot-chat />`,
})
export class AppComponent {}
```

记得在全局样式中导入一次样式表：

```css title="src/styles.css"
@import "@copilotkit/angular/styles.css";
```

## 输入

<PropertyReference name="agentId" type="string">
  要连接的智能体 ID。必须与 [`provideCopilotKit`](/reference/angular/functions/provideCopilotKit) 中配置的某个智能体匹配。省略时使用默认智能体。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  会话线程的 ID。传入具体的线程 ID 可恢复已有会话。省略时会在本地生成一个线程 ID，智能体在首次运行时连接。显式设置 `threadId` 还会让聊天组件尝试在智能体上连接（恢复）该线程。
</PropertyReference>

<PropertyReference name="attachments" type="AttachmentsConfig">
  文件附件的配置。通过 `attachments` 别名绑定（底层输入为 `attachmentsConfig`）。当 `enabled` 为 true 时，添加文件操作与拖拽上传将被启用，聊天组件会自动管理附件队列。
</PropertyReference>

<PropertyReference name="inputComponent" type="Type<any>">
  用于替代默认 [`CopilotChatInput`](/reference/angular/components/CopilotChatInput) 的自定义 Angular 组件类。会转发给底层的 [`CopilotChatView`](/reference/angular/components/CopilotChatView)。
</PropertyReference>

<PropertyReference name="assistantMessageComponent" type="Type<any>">
  用于助手消息的组件类。
</PropertyReference>

<PropertyReference name="assistantMessageTemplate" type="TemplateRef<any>">
  用于助手消息的模板。优先级高于 `assistantMessageComponent`。
</PropertyReference>

<PropertyReference name="assistantMessageClass" type="string">
  转发给助手消息插槽的 CSS 类。
</PropertyReference>

<PropertyReference name="reasoningMessageComponent" type="Type<any>">
  用于推理消息的组件类。
</PropertyReference>

<PropertyReference name="reasoningMessageTemplate" type="TemplateRef<any>">
  用于推理消息的模板。优先级高于 `reasoningMessageComponent`。
</PropertyReference>

<PropertyReference name="reasoningMessageClass" type="string">
  转发给推理消息插槽的 CSS 类。
</PropertyReference>

<PropertyReference name="messageViewChildrenComponent" type="Type<any>">
  渲染在消息列表之后、流式光标之前的组件。
</PropertyReference>

<PropertyReference name="messageViewChildrenTemplate" type="TemplateRef<any>">
  渲染在消息列表之后的模板。优先级高于 `messageViewChildrenComponent`。
</PropertyReference>

<PropertyReference name="messageViewChildrenClass" type="string">
  转发给消息列表子内容插槽的 CSS 类。
</PropertyReference>

## 输出

`CopilotChat` 没有声明自己的输出。它通过提供给输入与视图组件的 `ChatState`，在内部处理消息提交、建议选择和语音转写。若要观察更底层的交互，可通过 `inputComponent` 渲染自定义输入（或直接使用 [`CopilotChatInput`](/reference/angular/components/CopilotChatInput)），它会暴露 `submitMessage` 等输出以及转写事件。

## 自定义

`CopilotChat` 保持了布局的简洁，并把插槽自定义委托给它渲染的视图。可以通过 `inputComponent` 输入替换输入区域，也可以用 [`CopilotChatView`](/reference/angular/components/CopilotChatView) 自行组合布局——它暴露了全部插槽输入与内容投影模板（消息视图、滚动视图、feather、免责声明、输入容器以及输入工具栏按钮）。

要自定义文本字符串（输入占位符、欢迎消息、工具栏标签、免责声明），请通过 [`provideCopilotChatLabels`](/reference/angular/functions/provideCopilotChatLabels) 提供标签。聊天组件内部通过 `injectChatLabels` 读取它们。
