---
title: "CopilotSidebar"
description: "面向 Angular 的响应式停靠或覆盖模式 Copilot 聊天侧边栏。"
---

`CopilotSidebar` 以停靠（docked）或覆盖（overlay）模式渲染一个位于左侧或右侧的助手。它是一个 standalone、OnPush 组件，选择器为 `copilot-sidebar`。

```ts
import { Component, signal } from "@angular/core";
import { CopilotSidebar } from "@copilotkit/angular";

@Component({
  imports: [CopilotSidebar],
  template: `
    <copilot-sidebar
      [(open)]="open"
      mode="docked"
      position="right"
      [width]="480"
      title="Workspace assistant"
    />
  `,
})
export class WorkspaceAssistant {
  readonly open = signal(false);
}
```

## 输入与模型

| 名称                  | 类型                         | 默认值        | 行为                           |
| --------------------- | ---------------------------- | ------------- | ------------------------------ |
| `open`                | `ModelSignal<boolean>`       | `true`        | 可双向绑定的打开状态           |
| `mode`                | `"docked" \| "overlay"`      | `"docked"`    | 桌面端呈现模式                 |
| `position`            | `"left" \| "right"`          | `"right"`     | 视口的逻辑侧                   |
| `width`               | `number \| string`           | `480`         | 像素数值或 CSS 尺寸            |
| `title`               | `string`                     | `"Copilot"`   | 地标/对话框名称与标题文本      |
| `clickOutsideToClose` | `boolean`                    | `false`       | 启用覆盖模式下的点击遮罩关闭   |
| `chatComponent`       | `Type<unknown>`              | `CopilotChat` | 用于替换的聊天主体组件         |
| `headerComponent`     | `Type<unknown> \| undefined` | `undefined`   | 用于替换的头部组件             |

覆盖模式采用模态对话框语义、焦点陷阱、Escape 关闭以及启动器焦点还原。停靠模式使用 complementary 地标，并调整文档 body 的逻辑边距。紧凑视口始终采用模态呈现。

同一时刻只允许一个停靠侧边栏接管文档布局。第二个打开的停靠侧边栏会被拒绝并记录一条明确的警告；独立的覆盖侧边栏则不受限制。关闭或销毁时，持有者会精确恢复之前的 body 边距，并移除其媒体查询监听器。DOM 与媒体查询操作仅在浏览器中进行，且在渲染之后才开始，因此 SSR 保持无副作用。在水合完成之前，请保持 `open`、`mode` 和 `position` 稳定不变。
