## 概览

`CopilotChatUserMessage` 渲染单条用户消息。它会显示图片或文件附件，渲染消息文本，并展示一个带有复制与编辑操作的工具栏。当该消息属于一组重新生成的分支时，分支控件可让你在它们之间切换。

复制和编辑按钮始终渲染。只有当 `numberOfBranches` 大于 1 时，才会渲染分支导航控件。

该组件是 standalone 组件，并使用 `OnPush` 变更检测。响应式输入基于 Angular 的 [signals](https://angular.dev/guide/signals)。

## 用法

导入该组件类，并使用其 `copilot-chat-user-message` 选择器。

```ts title="src/app/user-message.component.ts"
import { Component, signal } from "@angular/core";
import { CopilotChatUserMessage } from "@copilotkit/angular";
import type { UserMessage } from "@ag-ui/core";

@Component({
  selector: "app-user-message",
  standalone: true,
  imports: [CopilotChatUserMessage],
  template: `
    <copilot-chat-user-message
      [message]="message()"
      (editMessage)="onEdit($event)"
    />
  `,
})
export class UserMessageComponent {
  message = signal<UserMessage>({
    id: "1",
    role: "user",
    content: "What is the weather today?",
  });

  onEdit(event: { message: UserMessage }) {
    console.log("edit", event.message.id);
  }
}
```

## 输入

<PropertyReference name="message" type="UserMessage">
  要渲染的用户消息。其内容会被展平为文本交给渲染器，任何媒体部分则以附件形式显示在其上方。
</PropertyReference>

<PropertyReference name="branchIndex" type="number" default="0">
  当前显示分支的从零开始的索引。由分支导航控件使用。
</PropertyReference>

<PropertyReference name="numberOfBranches" type="number" default="1">
  此消息重新生成分支的总数。只有当该值大于 1 时，才会渲染分支导航。
</PropertyReference>

<PropertyReference name="additionalToolbarItems" type="TemplateRef<any>">
  一个前置于默认工具栏的模板，位于复制和编辑按钮之前。
</PropertyReference>

<PropertyReference name="inputClass" type="string">
  合并到消息容器上的额外 CSS 类。
</PropertyReference>

### 插槽类名输入

其中每一项都会向对应的默认子组件传递额外的 CSS 类。

<PropertyReference name="messageRendererClass" type="string">
  用于默认消息渲染器的类。
</PropertyReference>

<PropertyReference name="toolbarClass" type="string">
  用于默认工具栏的类。
</PropertyReference>

<PropertyReference name="copyButtonClass" type="string">
  用于默认复制按钮的类。
</PropertyReference>

<PropertyReference name="editButtonClass" type="string">
  用于默认编辑按钮的类。
</PropertyReference>

<PropertyReference name="branchNavigationClass" type="string">
  用于默认分支导航控件的类。
</PropertyReference>

### 插槽组件输入

其中每一项都会用你自己的组件类替换对应的默认子组件。内容投影模板（见下文）优先于这些输入。

<PropertyReference name="messageRendererComponent" type="Type<any>">
  替换默认的消息渲染器。
</PropertyReference>

<PropertyReference name="toolbarComponent" type="Type<any>">
  替换默认的工具栏。
</PropertyReference>

<PropertyReference name="copyButtonComponent" type="Type<any>">
  替换默认的复制按钮。
</PropertyReference>

<PropertyReference name="editButtonComponent" type="Type<any>">
  替换默认的编辑按钮。
</PropertyReference>

<PropertyReference name="branchNavigationComponent" type="Type<any>">
  替换默认的分支导航控件。
</PropertyReference>

## 输出

<PropertyReference name="editMessage" type="CopilotChatUserMessageOnEditMessageProps">
  点击编辑按钮时触发。载荷为 `{ message: UserMessage }`。
</PropertyReference>

<PropertyReference name="switchToBranch" type="CopilotChatUserMessageOnSwitchToBranchProps">
  通过分支导航控件选择其他分支时触发。载荷为 `{ message: UserMessage; branchIndex: number; numberOfBranches: number }`。
</PropertyReference>

## 插槽与内容投影

你可以通过投影具名模板来覆盖消息的任何部分。投影模板优先于匹配的 `*Component` 输入。每个模板都会接收一个带类型的上下文对象。

| 模板名 | 上下文类型 | 替换对象 |
| --- | --- | --- |
| `messageRenderer` | `MessageRendererContext` (`{ content: string }`) | 消息文本渲染器 |
| `toolbar` | `UserMessageToolbarContext` (`{ children?: any }`) | 整个工具栏 |
| `copyButton` | `CopyButtonContext` (`{ content?: string; copied?: boolean }`) | 复制按钮 |
| `editButton` | `EditButtonContext`（空；通过输出处理点击） | 编辑按钮 |
| `branchNavigation` | `BranchNavigationContext` (`{ currentBranch, numberOfBranches, onSwitchToBranch?, message }`) | 分支导航控件 |

```html title="src/app/user-message.component.html"
<copilot-chat-user-message [message]="message()">
  <ng-template #messageRenderer let-content="content">
    <p class="my-user-text">{{ content }}</p>
  </ng-template>
</copilot-chat-user-message>
```
