---
title: "CopilotPopup"
description: "面向 Angular 的无障碍浮动 Copilot 聊天对话框。"
---

`CopilotPopup` 渲染一个浮动启动器和响应式聊天对话框。它是一个 standalone、OnPush 组件，选择器为 `copilot-popup`。

```ts
import { Component, signal } from "@angular/core";
import { CopilotPopup } from "@copilotkit/angular";

@Component({
  imports: [CopilotPopup],
  template: `
    <copilot-popup
      [(open)]="open"
      title="Support assistant"
      [width]="420"
      [height]="560"
      [clickOutsideToClose]="false"
    />
  `,
})
export class SupportAssistant {
  readonly open = signal(false);
}
```

## 输入与模型

| 名称                  | 类型                         | 默认值        | 行为                                   |
| --------------------- | ---------------------------- | ------------- | -------------------------------------- |
| `open`                | `ModelSignal<boolean>`       | `true`        | 可双向绑定的打开状态                   |
| `title`               | `string`                     | `"Copilot"`   | 无障碍对话框名称与默认标题文本         |
| `width`               | `number \| string`           | `420`         | 像素数值或 CSS 尺寸                    |
| `height`              | `number \| string`           | `560`         | 像素数值或 CSS 尺寸                    |
| `clickOutsideToClose` | `boolean`                    | `false`       | 启用点击遮罩关闭                       |
| `chatComponent`       | `Type<unknown>`              | `CopilotChat` | 用于替换的聊天主体组件                 |
| `headerComponent`     | `Type<unknown> \| undefined` | `undefined`   | 用于替换的头部组件                     |

该对话框会捕获焦点，把初始焦点移到关闭控件上，按 Escape 时关闭，并把焦点还原给启动器。在紧凑视口下它会变为全屏，且在用户要求减少动画（reduced motion）时禁用入场动画。销毁该组件会移除其渲染的对话框以及 Angular CDK 焦点陷阱状态。浏览器焦点操作在渲染完成后才开始，SSR 期间不生效；在水合完成之前，请保持初始 `open` 值不变。
