## 概览

`CopilotChatAssistantMessage` 渲染单条助手消息。它通过 Markdown 渲染器展示消息内容，渲染附带的工具调用，并显示一个包含复制、点赞/点踩、朗读与重新生成操作的工具栏。

只有当消息具有非空文本内容时工具栏才会出现。复制按钮始终渲染；当你为点赞/点踩按钮提供了自定义插槽，或周边的 [`CopilotChatView`](/reference/angular/components/CopilotChatView) 提供了点赞处理函数时，点赞与点踩按钮才会渲染。朗读与重新生成按钮仅在你提供自定义插槽时才渲染。

该组件是 standalone 组件，使用 `OnPush` 变更检测。响应式输入基于 Angular 的 [signals](https://angular.dev/guide/signals)。

## 用法

导入该组件类并使用其 `copilot-chat-assistant-message` 选择器。`message` 输入为必填。

```ts title="src/app/assistant.component.ts"
import { Component, signal } from "@angular/core";
import { CopilotChatAssistantMessage } from "@copilotkit/angular";
import type { AssistantMessage } from "@ag-ui/client";

@Component({
  selector: "app-assistant",
  standalone: true,
  imports: [CopilotChatAssistantMessage],
  template: `
    <copilot-chat-assistant-message [message]="message()" />
  `,
})
export class AssistantComponent {
  message = signal<AssistantMessage>({
    id: "1",
    role: "assistant",
    content: "Hello, how can I help?",
  });
}
```

## 输入

<PropertyReference name="message" type="AssistantMessage" required>
  要渲染的助手消息。其 `content` 会传给 Markdown 渲染器，其 `toolCalls` 驱动工具调用视图。
</PropertyReference>

<PropertyReference name="messages" type="Message[]" default="[]">
  周边的消息列表。转发给工具调用视图，使工具渲染可以读取先前上下文。
</PropertyReference>

<PropertyReference name="agentId" type="string">
  产生该消息的智能体 ID。转发给工具调用视图，用于解析匹配的工具渲染器。
</PropertyReference>

<PropertyReference name="isLoading" type="boolean" default="false">
  智能体当前是否正在流式输出。转发给工具调用视图。
</PropertyReference>

<PropertyReference name="toolbarVisible" type="boolean" default="true">
  是否允许显示工具栏。即使为 `true`，工具栏也只在消息具有非空文本内容时才渲染。
</PropertyReference>

<PropertyReference name="additionalToolbarItems" type="TemplateRef<any>">
  一个模板，追加在默认工具栏的末尾、内置按钮之后。
</PropertyReference>

### 插槽类名输入

当前版本会将 `markdownRendererClass`、`toolbarClass` 和 `copyButtonClass` 应用到各自的默认部件上。

<PropertyReference name="markdownRendererClass" type="string">
  默认 Markdown 渲染器的类。
</PropertyReference>

<PropertyReference name="toolbarClass" type="string">
  默认工具栏的类。
</PropertyReference>

<PropertyReference name="copyButtonClass" type="string">
  默认复制按钮的类。
</PropertyReference>

<Callout type="warn">
  `inputClass`、点赞/朗读/重新生成的类输入以及 `toolCallsViewClass` 已声明但在当前版本中不影响渲染。请对这些部件使用组件或模板覆盖。
</Callout>

### 插槽组件输入

其中每一项都会用你自己的组件类替换对应的默认子组件。内容投影模板（见下文）的优先级高于这些输入。

<PropertyReference name="markdownRendererComponent" type="Type<any>">
  替换默认的 Markdown 渲染器。
</PropertyReference>

<PropertyReference name="toolbarComponent" type="Type<any>">
  替换默认的工具栏。
</PropertyReference>

<PropertyReference name="copyButtonComponent" type="Type<any>">
  替换默认的复制按钮。
</PropertyReference>

<PropertyReference name="thumbsUpButtonComponent" type="Type<any>">
  替换默认的点赞按钮。
</PropertyReference>

<PropertyReference name="thumbsDownButtonComponent" type="Type<any>">
  替换默认的点踩按钮。
</PropertyReference>

<PropertyReference name="readAloudButtonComponent" type="Type<any>">
  替换默认的朗读按钮。
</PropertyReference>

<PropertyReference name="regenerateButtonComponent" type="Type<any>">
  替换默认的重新生成按钮。
</PropertyReference>

<PropertyReference name="toolCallsViewComponent" type="Type<any>">
  替换默认的工具调用视图。
</PropertyReference>

## 输出

<PropertyReference name="thumbsUp" type="CopilotChatAssistantMessageOnThumbsUpProps">
  当配置的点赞组件或模板被点击时触发。载荷为 `{ message: AssistantMessage }`。
</PropertyReference>

<PropertyReference name="thumbsDown" type="CopilotChatAssistantMessageOnThumbsDownProps">
  当配置的点踩组件或模板被点击时触发。载荷为 `{ message: AssistantMessage }`。
</PropertyReference>

<PropertyReference name="readAloud" type="CopilotChatAssistantMessageOnReadAloudProps">
  当配置的朗读组件或模板被点击时触发。载荷为 `{ message: AssistantMessage }`。
</PropertyReference>

<PropertyReference name="regenerate" type="CopilotChatAssistantMessageOnRegenerateProps">
  当配置的重新生成组件或模板被点击时触发。载荷为 `{ message: AssistantMessage }`。
</PropertyReference>

## 插槽与内容投影

你可以通过投影命名模板来覆盖消息的任意部分。投影模板的优先级高于对应的 `*Component` 输入。每个模板都会收到一个带类型的上下文对象。

| 模板名 | 上下文类型 | 替换对象 |
| --- | --- | --- |
| `markdownRenderer` | `AssistantMessageMarkdownRendererContext`（`{ content: string }`） | Markdown 内容渲染器 |
| `toolbar` | `AssistantMessageToolbarContext`（`{ children?: any }`） | 整个工具栏 |
| `copyButton` | `AssistantMessageCopyButtonContext`（`{ content?: string }`） | 复制按钮 |
| `thumbsUpButton` | `ThumbsUpButtonContext`（空；通过输出处理点击） | 点赞按钮 |
| `thumbsDownButton` | `ThumbsDownButtonContext`（空；通过输出处理点击） | 点踩按钮 |
| `readAloudButton` | `ReadAloudButtonContext`（空；通过输出处理点击） | 朗读按钮 |
| `regenerateButton` | `RegenerateButtonContext`（空；通过输出处理点击） | 重新生成按钮 |
| `toolCallsView` | `any` | 工具调用视图 |

```html title="src/app/assistant.component.html"
<copilot-chat-assistant-message [message]="message()">
  <ng-template #markdownRenderer let-content="content">
    <article class="my-markdown">{{ content }}</article>
  </ng-template>
</copilot-chat-assistant-message>
```
