## 概览

`CopilotChatView` 是纯布局的聊天视图。它渲染消息流、输入容器、羽化效果、免责声明、建议胶囊，并在没有消息时显示欢迎界面。它本身不接线任何智能体。你向它传入 `messages`，并从外围的 `ChatState` 读取交互处理器。

[`CopilotChat`](/reference/angular/components/CopilotChat) 负责接线智能体、消息、运行状态、建议与提交，然后渲染 `CopilotChatView`。当你自行管理这些值和处理器，或需要完全掌控布局及其插槽时，可直接使用 `CopilotChatView`。

生效的插槽输入既可以接受组件类（`*Component`），也可以接受 Angular 模板（`*Template`）。两者同时设置时，模板优先。

## 用法

`CopilotChatView` 是一个 standalone 组件，选择器为 `copilot-chat-view`。它的默认输入需要一个 `ChatState` 提供者。下面的示例就提供了一个。

```ts title="src/app/chat.component.ts"
import { Component, forwardRef, signal } from "@angular/core";
import { ChatState, CopilotChatView } from "@copilotkit/angular";
import type { Message } from "@ag-ui/client";

@Component({
  selector: "app-chat",
  standalone: true,
  imports: [CopilotChatView],
  providers: [
    {
      provide: ChatState,
      useExisting: forwardRef(() => ChatComponent),
    },
  ],
  template: `
    <copilot-chat-view [messages]="messages()" [autoScroll]="true" />
  `,
})
export class ChatComponent extends ChatState {
  readonly messages = signal<Message[]>([]);
  readonly inputValue = signal("");

  submitInput(value: string) {
    // Send the message through your chat state owner.
  }

  changeInput(value: string) {
    this.inputValue.set(value);
  }
}
```

## 输入

### 核心输入

<PropertyReference name="messages" type="Message[]" default="[]">
  要在消息流中渲染的消息。当其为空（且未选择显式线程）时，将改为显示欢迎界面。
</PropertyReference>

<PropertyReference name="state" type="unknown" default="{}">
  传递给消息列表子内容的当前智能体状态。
</PropertyReference>

<PropertyReference name="agentId" type="string">
  正在渲染其消息的智能体的 ID。转发给滚动视图，用于按智能体渲染。
</PropertyReference>

<PropertyReference name="autoScroll" type="boolean" default="true">
  新消息流入时，消息流是否吸附在底部。
</PropertyReference>

<PropertyReference name="showCursor" type="boolean" default="false">
  智能体响应期间，是否在消息流末尾显示流式光标。
</PropertyReference>

<PropertyReference name="hasExplicitThreadId" type="boolean" default="false">
  是否提供了显式的线程 id。为 true 时，即使没有消息也会隐藏欢迎界面（表示正在恢复会话）。
</PropertyReference>

### 插槽输入

该视图转发消息、输入、滚动按钮、输入容器、羽化和免责声明这几个插槽。

<PropertyReference name="messageViewComponent" type="Type<any>">
  用于渲染消息列表的组件类。可搭配 `messageViewClass` 设置样式，或使用 `messageViewTemplate` 以模板方式渲染。
</PropertyReference>

<PropertyReference name="messageViewTemplate" type="TemplateRef<any>">
  用于渲染消息列表的模板。
</PropertyReference>

<PropertyReference name="messageViewClass" type="string">
  应用到消息列表的类。
</PropertyReference>

<Callout type="warn">
  当前版本声明了 `scrollViewComponent`、`scrollViewTemplate` 和 `scrollViewClass`，但默认布局始终使用其内置的滚动视图。需要替换时请使用 `customLayout`。
</Callout>

<PropertyReference name="assistantMessageComponent" type="Type<any>">
  用于助手消息的组件类。
</PropertyReference>

<PropertyReference name="assistantMessageTemplate" type="TemplateRef<any>">
  用于助手消息的模板。优先于 `assistantMessageComponent`。
</PropertyReference>

<PropertyReference name="assistantMessageClass" type="string">
  转发给助手消息的 CSS 类。
</PropertyReference>

<PropertyReference name="reasoningMessageComponent" type="Type<any>">
  用于推理消息的组件类。
</PropertyReference>

<PropertyReference name="reasoningMessageTemplate" type="TemplateRef<any>">
  用于推理消息的模板。优先于 `reasoningMessageComponent`。
</PropertyReference>

<PropertyReference name="reasoningMessageClass" type="string">
  转发给推理消息的 CSS 类。
</PropertyReference>

<PropertyReference name="messageViewChildrenComponent" type="Type<any>">
  渲染在消息列表之后、光标之前的组件。
</PropertyReference>

<PropertyReference name="messageViewChildrenTemplate" type="TemplateRef<any>">
  渲染在消息列表之后的模板。优先于 `messageViewChildrenComponent`。
</PropertyReference>

<PropertyReference name="messageViewChildrenClass" type="string">
  转发给消息列表子内容插槽的 CSS 类。
</PropertyReference>

<PropertyReference name="scrollToBottomButtonComponent" type="Type<any>">
  滚动到底部按钮的组件类。
</PropertyReference>

<PropertyReference name="scrollToBottomButtonTemplate" type="TemplateRef<any>">
  滚动到底部按钮的模板。
</PropertyReference>

<PropertyReference name="scrollToBottomButtonClass" type="string">
  应用到滚动到底部按钮的类。
</PropertyReference>

<PropertyReference name="inputComponent" type="Type<any>">
  聊天输入框的组件类。默认为 [`CopilotChatInput`](/reference/angular/components/CopilotChatInput)。
</PropertyReference>

<PropertyReference name="inputTemplate" type="TemplateRef<any>">
  聊天输入框的模板。
</PropertyReference>

<PropertyReference name="inputContainerComponent" type="Type<any>">
  包裹输入框和免责声明的容器的组件类。
</PropertyReference>

<PropertyReference name="inputContainerTemplate" type="TemplateRef<any>">
  输入容器的模板。
</PropertyReference>

<PropertyReference name="inputContainerClass" type="string">
  应用到输入容器的类。
</PropertyReference>

<PropertyReference name="featherComponent" type="Type<any>">
  输入框上方羽化（渐隐）效果的组件类。
</PropertyReference>

<PropertyReference name="featherTemplate" type="TemplateRef<any>">
  羽化效果的模板。
</PropertyReference>

<Callout type="warn">
  `featherClass` 已声明，但当前版本不会把它的字符串值传递给羽化插槽。请使用羽化组件或模板来为该区域设置样式。
</Callout>

<PropertyReference name="disclaimerComponent" type="Type<any>">
  显示在输入框下方的免责声明的组件类。
</PropertyReference>

<PropertyReference name="disclaimerTemplate" type="TemplateRef<any>">
  免责声明的模板。
</PropertyReference>

<PropertyReference name="disclaimerClass" type="string">
  应用到免责声明的类。
</PropertyReference>

<PropertyReference name="disclaimerText" type="string">
  免责声明的文本内容。
</PropertyReference>

## 输出

`CopilotChatView` 会把助手消息的操作从消息流向上冒泡。每个载荷都是一个包含相关 `message` 的对象。

<PropertyReference name="assistantMessageThumbsUp" type="{ message: Message }">
  在助手消息上触发点赞操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageThumbsDown" type="{ message: Message }">
  在助手消息上触发点踩操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageReadAloud" type="{ message: Message }">
  在助手消息上触发朗读操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageRegenerate" type="{ message: Message }">
  在助手消息上触发重新生成操作时发出。
</PropertyReference>

<Callout type="warn">
  当前版本声明了 `userMessageCopy` 和 `userMessageEdit`，但默认消息视图并不会发出它们。
</Callout>

## 内容投影

`CopilotChatView` 支持一个名为 `customLayout` 的生效投影模板。

<PropertyReference name="customLayout" type="TemplateRef<CopilotChatViewLayoutContext>">
  替换整个默认布局。该模板为已配置的 `messageView`、`input`、`scrollView`、`scrollToBottomButton`、`feather`、`inputContainer` 和 `disclaimer` 插槽提供具名上下文值。未配置某个插槽时，对应的值可能为 undefined。
</PropertyReference>

<Callout type="warn">
  该类为输入按钮和助手消息部件声明了投影模板，但当前版本并不转发它们。请通过 `inputComponent`、消息插槽输入或自定义布局来配置这些部件。
</Callout>

### 自定义布局示例

```ts title="src/app/chat.component.ts"
import { Component, forwardRef, signal } from "@angular/core";
import {
  ChatState,
  CopilotChatInput,
  CopilotChatMessageView,
  CopilotChatView,
} from "@copilotkit/angular";
import type { Message } from "@ag-ui/client";

@Component({
  selector: "app-chat",
  standalone: true,
  imports: [CopilotChatInput, CopilotChatMessageView, CopilotChatView],
  providers: [
    {
      provide: ChatState,
      useExisting: forwardRef(() => ChatComponent),
    },
  ],
  template: `
    <copilot-chat-view [messages]="messages()">
      <ng-template #customLayout>
        <div class="my-layout">
          <copilot-chat-message-view [messages]="messages()" />
          <copilot-chat-input />
        </div>
      </ng-template>
    </copilot-chat-view>
  `,
})
export class ChatComponent extends ChatState {
  readonly messages = signal<Message[]>([]);
  readonly inputValue = signal("");

  submitInput(value: string) {
    // Send the message through your chat state owner.
  }

  changeInput(value: string) {
    this.inputValue.set(value);
  }
}
```
