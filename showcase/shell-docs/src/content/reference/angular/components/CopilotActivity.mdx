## 概览

`CopilotActivity` 渲染单条活动消息。它会查找为该消息的 `activityType` 注册的渲染器——通过 `provideCopilotKit({ renderActivityMessages })` 或 [`registerRenderActivityMessage`](/reference/angular/functions/registerRenderActivityMessage)——校验消息内容是否符合渲染器的 schema，并以 `activityType`、`content`、`message` 和 `agent` 这些输入挂载渲染器组件。

它是 `RenderToolCalls` 在活动消息上的对应物，也是 React 的 `useRenderActivityMessage()` 在 Angular 中的等价物。[`CopilotChatMessageView`](/reference/angular/components/CopilotChatMessageView) 对每条 `role: "activity"` 的消息都会使用它，因此内置聊天与你自己的模板共用同一套实现。

当你构建不使用 `CopilotChatMessageView` 的自定义聊天外壳，或在聊天之外完全独立地承载活动——例如仪表盘、侧边面板、输出区域——时，可以直接使用它。

该组件是 standalone 组件。响应式输入基于 Angular 的 [signals](https://angular.dev/guide/signals)。

## 用法

```ts title="src/app/activity-panel.component.ts"
import { Component, computed, input } from "@angular/core";
import { CopilotActivity } from "@copilotkit/angular";
import type { ActivityMessage, Message } from "@ag-ui/core";

@Component({
  selector: "app-activity-panel",
  standalone: true,
  imports: [CopilotActivity],
  template: `
    @for (activity of activities(); track activity.id) {
      <copilot-activity [message]="activity" [agentId]="agentId()" />
    }
  `,
})
export class ActivityPanelComponent {
  messages = input.required<Message[]>();
  agentId = input<string>();

  activities = computed(() =>
    this.messages().filter(
      (message): message is ActivityMessage => message.role === "activity",
    ),
  );
}
```

## 渲染器解析

对于给定的 `activityType`，按以下顺序取第一个匹配的渲染器：

1. 以相同 `agentId` 注册的该类型渲染器
2. 不带 `agentId` 的该类型渲染器（全局）
3. `"*"` 通配符渲染器

在同一层级内，由注册顺序决定：传给 `provideCopilotKit` 或在运行时注册的渲染器排在内置渲染器（A2UI、Open Generative UI、MCP Apps）之前，因此应用级渲染器可以覆盖同一活动类型的内置渲染器。

如果没有匹配的渲染器，则不渲染任何内容。如果渲染器的内容 schema 拒绝了该消息内容，则同样不渲染，并会记录一条警告。

## 输入

| 输入      | 类型                  | 默认值      | 说明                                                                                                        |
| --------- | --------------------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `message` | `ActivityMessage`     | —（必填）   | 要渲染的活动消息。                                                                                          |
| `agentId` | `string \| undefined` | `undefined` | 用于渲染器解析的智能体作用域。也用于查找传递给渲染器 `agent` 输入的 `AbstractAgent`。                       |
