title: "CopilotChatMessageView"
description: "Angular standalone 组件，渲染聊天消息列表，按插槽自定义将每条消息分流到助手、用户、推理或活动渲染。"
---

## 概览

`CopilotChatMessageView` 渲染一个消息数组，并根据每条消息的 `role` 将其路由到正确的渲染器：助手消息交给 [`CopilotChatAssistantMessage`](/reference/angular/components/CopilotChatAssistantMessage)，用户消息交给 [`CopilotChatUserMessage`](/reference/angular/components/CopilotChatUserMessage)，推理消息交给推理渲染器，活动消息交给 [`CopilotActivity`](/reference/angular/components/CopilotActivity)，由它解析已注册的活动渲染器。在智能体流式输出期间，它还可以在列表末尾渲染一个输入中的光标。

这是 [`CopilotChatView`](/reference/angular/components/CopilotChatView) 所使用的消息列表层。当你自己管理 `messages` 数组、只想要列表而不想要外围的滚动容器与输入时，可以直接使用它。

该组件是 standalone 组件，使用 `OnPush` 变更检测。响应式输入基于 Angular 的 [signals](https://angular.dev/guide/signals)。

## 用法

导入该组件类，并在模板中使用其 `copilot-chat-message-view` 选择器。

```ts title="src/app/messages.component.ts"
import { Component, signal } from "@angular/core";
import { CopilotChatMessageView } from "@copilotkit/angular";
import type { Message } from "@ag-ui/core";

@Component({
  selector: "app-messages",
  standalone: true,
  imports: [CopilotChatMessageView],
  template: `
    <copilot-chat-message-view
      [messages]="messages()"
      [showCursor]="isLoading()"
      [isLoading]="isLoading()"
    />
  `,
})
export class MessagesComponent {
  messages = signal<Message[]>([]);
  isLoading = signal(false);
}
```

## 输入

<PropertyReference name="messages" type="Message[]" default="[]">
  要渲染的消息。每条消息按其 `role`（`assistant`、`user`、`reasoning` 或 `activity`）路由。其他 role 的条目会被跳过。
</PropertyReference>

<PropertyReference name="showCursor" type="boolean" default="false">
  是否在列表末尾显示输入中的光标。当最后一条消息是推理消息时，光标会被隐藏。
</PropertyReference>

<PropertyReference name="isLoading" type="boolean" default="false">
  智能体当前是否正在流式输出。转发给助手与推理渲染器。
</PropertyReference>

<PropertyReference name="state" type="unknown" default="{}">
  传递给消息列表之后所渲染内容的当前智能体状态。
</PropertyReference>

<PropertyReference name="inputClass" type="string">
  合并到默认列表容器（`flex flex-col`）上的额外 CSS 类。
</PropertyReference>

<PropertyReference name="agentId" type="string">
  正在渲染其消息的智能体 ID。用于解析匹配的活动消息渲染器，以及传递给它的智能体实例。
</PropertyReference>

### 助手消息插槽输入

<PropertyReference name="assistantMessageComponent" type="Type<any>">
  用于渲染每条助手消息的组件类，替代默认的 [`CopilotChatAssistantMessage`](/reference/angular/components/CopilotChatAssistantMessage)。
</PropertyReference>

<PropertyReference name="assistantMessageTemplate" type="TemplateRef<any>">
  用于渲染每条助手消息的模板。两者同时设置时优先于 `assistantMessageComponent`。
</PropertyReference>

<PropertyReference name="assistantMessageClass" type="string">
  转发给每个助手消息渲染器的额外 CSS 类。
</PropertyReference>

### 用户消息插槽输入

<PropertyReference name="userMessageComponent" type="Type<any>">
  用于渲染每条用户消息的组件类，替代默认的 [`CopilotChatUserMessage`](/reference/angular/components/CopilotChatUserMessage)。
</PropertyReference>

### 推理消息插槽输入

<PropertyReference name="reasoningMessageComponent" type="Type<any>">
  用于推理消息的组件类。
</PropertyReference>

<PropertyReference name="reasoningMessageTemplate" type="TemplateRef<any>">
  用于推理消息的模板。优先级高于 `reasoningMessageComponent`。
</PropertyReference>

<PropertyReference name="reasoningMessageClass" type="string">
  转发给推理消息插槽的 CSS 类。
</PropertyReference>

### 消息列表后的内容

<PropertyReference name="childrenComponent" type="Type<any>">
  渲染在消息之后、流式光标之前的组件。
</PropertyReference>

<PropertyReference name="childrenTemplate" type="TemplateRef<any>">
  渲染在消息之后的模板。优先级高于 `childrenComponent`。
</PropertyReference>

<PropertyReference name="childrenClass" type="string">
  转发给子内容插槽的 CSS 类。
</PropertyReference>

<PropertyReference name="userMessageTemplate" type="TemplateRef<any>">
  用于渲染每条用户消息的模板。两者同时设置时优先于 `userMessageComponent`。
</PropertyReference>

<PropertyReference name="userMessageClass" type="string">
  转发给每个用户消息渲染器的额外 CSS 类。
</PropertyReference>

### 光标插槽输入

<PropertyReference name="cursorComponent" type="Type<any>">
  用于渲染输入中光标的组件类，替代默认光标。
</PropertyReference>

<PropertyReference name="cursorTemplate" type="TemplateRef<any>">
  用于渲染输入中光标的模板。两者同时设置时优先于 `cursorComponent`。
</PropertyReference>

<PropertyReference name="cursorClass" type="string">
  转发给光标渲染器的额外 CSS 类。
</PropertyReference>

## 输出

助手消息操作会从助手消息子组件向上冒泡。每个载荷都是 `{ message: Message }`。

<PropertyReference name="assistantMessageThumbsUp" type="{ message: Message }">
  在助手消息上触发点赞操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageThumbsDown" type="{ message: Message }">
  在助手消息上触发点踩操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageReadAloud" type="{ message: Message }">
  在助手消息上触发朗读操作时发出。
</PropertyReference>

<PropertyReference name="assistantMessageRegenerate" type="{ message: Message }">
  在助手消息上触发重新生成操作时发出。
</PropertyReference>

<Callout type="warn">
  当前版本声明了 `userMessageCopy` 和 `userMessageEdit`，但默认的用户消息子组件不会转发这些事件。需要时请在自定义的用户消息组件上监听。
</Callout>

## 自定义布局

若要完全控制列表的布局方式，可投影一个名为 `customLayout` 的模板。它会收到一个上下文对象，包含当前的 `messages`、`isLoading` 与 `showCursor` 标志，以及 `messageElements`（过滤为可渲染 role 的消息）。该模板存在时，默认的列表渲染会被完全替换。

```html title="src/app/messages.component.html"
<copilot-chat-message-view [messages]="messages()" [showCursor]="isLoading()">
  <ng-template #customLayout let-messages="messages" let-showCursor="showCursor">
    <div class="my-list">
      @for (message of messages; track message.id) {
        <div class="my-row">{{ message.content }}</div>
      }
      @if (showCursor) {
        <span class="my-cursor">...</span>
      }
    </div>
  </ng-template>
</copilot-chat-message-view>
```

## 自定义消息渲染

要在不重做布局的情况下更换整个 role 的渲染方式，传入一个插槽输入即可。该插槽既接受组件类也接受模板，模板优先。

```ts title="src/app/messages.component.ts"
import { Component, signal } from "@angular/core";
import { CopilotChatMessageView } from "@copilotkit/angular";
import { MyAssistantMessage } from "./my-assistant-message.component";
import type { Message } from "@ag-ui/core";

@Component({
  selector: "app-messages",
  standalone: true,
  imports: [CopilotChatMessageView],
  template: `
    <copilot-chat-message-view
      [messages]="messages()"
      [assistantMessageComponent]="assistantMessage"
    />
  `,
})
export class MessagesComponent {
  messages = signal<Message[]>([]);
  protected readonly assistantMessage = MyAssistantMessage;
}
```
