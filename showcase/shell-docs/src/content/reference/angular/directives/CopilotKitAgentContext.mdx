## 概览

`CopilotKitAgentContext` 是一个 standalone Angular 指令，可在模板中把一段 [context](https://docs.ag-ui.com/concepts/context) 共享给智能体。它可以应用到任意元素。元素初始化时会添加完整上下文，输入变化时会更新既有注册，元素销毁时会移除该上下文。

你既可以通过指令选择器输入传入单个对象，也可以通过分开的 `description` 和 `value` 输入提供上下文。两者同时提供时，上下文对象优先。

这是 [`connectAgentContext`](/reference/angular/functions/connectAgentContext) 的基于模板的替代方案。

## 导入

该指令是 standalone 的。把类导入组件的 `imports` 数组，然后在模板中使用 `copilotkitAgentContext` 属性选择器。

```ts title="src/app/profile.component.ts"
import { Component } from "@angular/core";
import { CopilotKitAgentContext } from "@copilotkit/angular";

@Component({
  selector: "app-profile",
  standalone: true,
  imports: [CopilotKitAgentContext],
  template: `
    <div copilotkitAgentContext
         description="User profile"
         [value]="profileJson">
    </div>
  `,
})
export class ProfileComponent {
  profile = { name: "Ada", plan: "pro" };
  profileJson = JSON.stringify(this.profile);
}
```

## 选择器

```
[copilotkitAgentContext]
```

它是一个属性型指令，可以应用到任意元素。

## 输入

<PropertyReference name="copilotkitAgentContext" type="Context">
  一个同时包含 `description` 和 `value` 的完整上下文对象。也就是指令的选择器输入（`[copilotkitAgentContext]="..."`）。提供时优先于分开的 `description` 和 `value` 输入。`Context` 的结构为 `{ description: string; value: string }`。
</PropertyReference>

<PropertyReference name="description" type="string">
  一段人类可读的说明，描述此上下文表示什么。在未提供 `copilotkitAgentContext` 对象输入时，用于构建上下文对象。只有当 `description` 和 `value` 都已设置时，上下文才会注册。
</PropertyReference>

<PropertyReference name="value" type="any">
  未提供对象输入时，与 `description` 一起转发的值。该指令目前把此输入声明为 `any`，但 AG-UI 的 `Context` 契约要求字符串。绑定对象前请先序列化。只有初始化时 `description` 和 `value` 都已设置，上下文才会注册。
</PropertyReference>

## 用法

### 分开输入

```html
<div copilotkitAgentContext
     description="User preferences"
     [value]="userSettingsJson">
</div>
```

### 上下文对象

通过选择器输入传入一个完整的 `{ description, value }` 对象。

```html
<div [copilotkitAgentContext]="contextObject"></div>
```

### 更新已注册的上下文

当初始化期间已注册完整上下文之后，输入变化时指令会重新注册上下文。请在初始化时就提供两个字段。

```html
<div [copilotkitAgentContext]="formContext"></div>
```

如果初始对象或分开的值缺失，后续的输入变化不会创建首次注册。请等到完整上下文可用后再渲染该指令，或改用 [`connectAgentContext`](/reference/angular/functions/connectAgentContext) 获得响应式访问器。

## 行为

- **初始化时添加**。上下文在 `ngOnInit` 中注册到智能体。
- **更新既有注册**。当初始化已注册上下文之后，`copilotkitAgentContext`、`description` 或 `value` 发生变化时，指令会移除旧上下文并添加新上下文。
- **初始化为空时不添加**。如果初始化时没有完整上下文，后续输入变化不会创建首次注册。
- **销毁时移除**。宿主元素销毁时，上下文会被移除。
- **对象输入优先**。设置了 `copilotkitAgentContext` 对象输入时，将使用它，并忽略分开的 `description` 和 `value` 输入。否则，上下文由 `description` 和 `value` 构建，且仅在两者都已设置时才注册。
