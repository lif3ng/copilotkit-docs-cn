## 概览

`useHumanInTheLoop` 注册一个交互式工具，它会暂停智能体的执行，直到用户通过你的自定义 UI 做出响应。与 `useFrontendTool` 不同，这里没有 `handler` 函数。取而代之，该钩子提供一个内部状态机（`InProgress` -> `Executing` -> `Complete`），并在工具处于 `Executing` 状态时向渲染组件提供 `respond` 回调。在 `respond` 被传入用户输入调用之前，智能体会一直保持暂停。

<Callout type="info">
  该钩子从 `@copilotkit/react-core/v2` 重新导出，与 [React (V2) 的 `useHumanInTheLoop`](/reference/v2/hooks/useHumanInTheLoop) 相同，唯一区别是导入路径。
</Callout>

该钩子构建在 `useFrontendTool` 之上，内部管理一个处理函数，在 `respond` 被调用时解析工具调用的 promise。它适用于确认对话框、审批工作流、表单收集，或任何需要人工提供输入之后智能体才能继续的场景。`render` 组件返回 React Native 元素，由 CopilotKit 在聊天中呈现，写入的是与 [`useRenderTool`](/reference/react-native/hooks/useRenderTool) 和 `useFrontendTool` 相同的共享渲染器注册表。

## 签名

```tsx
import { useHumanInTheLoop } from "@copilotkit/react-native";

function useHumanInTheLoop<T extends Record<string, unknown>>(
  tool: ReactHumanInTheLoop<T>,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="tool" type="ReactHumanInTheLoop<T>" required>
  交互式工具定义。

<PropertyReference name="name" type="string" required>
  工具的唯一名称。智能体在需要人工输入时会引用该名称。
</PropertyReference>

<PropertyReference name="description" type="string" required>
  用自然语言描述工具的用途与调用时机（例如“在删除记录前请用户确认”）。
</PropertyReference>

<PropertyReference name="parameters" type="z.ZodSchema" required>
  定义智能体传给工具的参数的 Zod 模式。这些参数会被转发给渲染组件，方便你构建具备上下文感知能力的 UI。
</PropertyReference>

  <PropertyReference name="render" type="React.ComponentType<RenderProps>" required>
    驱动人工交互的 React Native 组件。该组件根据当前状态接收不同的 props：

    **当 `status` 为 `ToolCallStatus.InProgress` 时**：
    - `args: Partial<T>`：部分流式传输的参数
    - `respond: undefined`：尚不可用
    - `result: undefined`

    **当 `status` 为 `ToolCallStatus.Executing` 时**：
    - `args: T`：完整解析后的参数
    - `respond: (result: unknown) => Promise<void>`：调用它把用户的响应发回智能体并恢复执行
    - `result: undefined`

    **当 `status` 为 `ToolCallStatus.Complete` 时**：
    - `args: T`：原始参数
    - `respond: undefined`：已不可用
    - `result: string`：序列化后的结果

  </PropertyReference>

  <PropertyReference name="available" type='"enabled" | "disabled" | "remote"' default='"enabled"'>
    控制工具可用性。设为 `"disabled"` 可暂时阻止智能体通过该工具请求人工输入。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。提供时，数组中任何值变化都会刷新工具注册。

  `deps` 对普通数据（字符串、数字、布尔值、`null`、日期，以及由它们构成的普通对象和数组）按值进行比较，因此诸如 `[{ status }]` 这样的内联字面量只在其内容变化时才重新注册。函数与之前一样永远不算变化，所以要把会变化的回调保存在 ref 中。类实例和其他对象按引用（同一性）比较，因此传入来自 `useAgent` 的 `agent` 这类循环引用的值是安全的。增加或移除条目都算变化。
</PropertyReference>

## 用法

### 确认对话框

智能体请求用户确认破坏性操作的常见模式。

```tsx
import { Text, TouchableOpacity, View } from "react-native";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-native";
import { z } from "zod";

function DeleteConfirmation() {
  useHumanInTheLoop(
    {
      name: "confirmDeletion",
      description: "Ask the user to confirm before deleting items",
      parameters: z.object({
        itemName: z.string().describe("Name of the item to delete"),
        itemCount: z.number().describe("Number of items to delete"),
      }),
      render: ({ args, status, respond, result }) => {
        if (status === ToolCallStatus.InProgress) {
          return (
            <View style={{ padding: 16 }}>
              <Text style={{ color: "#6b7280" }}>Preparing confirmation...</Text>
            </View>
          );
        }

        if (status === ToolCallStatus.Executing && respond) {
          return (
            <View style={{ padding: 16, borderWidth: 1, borderRadius: 8 }}>
              <Text>
                Are you sure you want to delete {args.itemCount} {args.itemName}
                (s)?
              </Text>
              <View style={{ flexDirection: "row", gap: 8, marginTop: 16 }}>
                <TouchableOpacity
                  onPress={() => respond({ confirmed: true })}
                  style={{ backgroundColor: "#ef4444", paddingHorizontal: 16, paddingVertical: 8, borderRadius: 6 }}
                >
                  <Text style={{ color: "#fff" }}>Delete</Text>
                </TouchableOpacity>
                <TouchableOpacity
                  onPress={() => respond({ confirmed: false })}
                  style={{ backgroundColor: "#d1d5db", paddingHorizontal: 16, paddingVertical: 8, borderRadius: 6 }}
                >
                  <Text>Cancel</Text>
                </TouchableOpacity>
              </View>
            </View>
          );
        }

        if (status === ToolCallStatus.Complete && result) {
          const parsed = JSON.parse(result);
          return (
            <View style={{ padding: 8 }}>
              <Text style={{ fontSize: 12, color: "#4b5563" }}>
                {parsed.confirmed ? "Items deleted." : "Deletion cancelled."}
              </Text>
            </View>
          );
        }

        return null;
      },
    },
    [],
  );

  return null;
}
```

### 表单输入收集

在智能体继续之前收集用户的结构化输入。

```tsx
import { useState } from "react";
import { Text, TextInput, TouchableOpacity, View } from "react-native";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-native";
import { z } from "zod";

function ShippingAddressForm() {
  useHumanInTheLoop(
    {
      name: "collectShippingAddress",
      description:
        "Collect shipping address from the user before placing an order",
      parameters: z.object({
        orderSummary: z
          .string()
          .describe("A summary of the order being placed"),
      }),
      render: ({ args, status, respond }) => {
        const [address, setAddress] = useState({
          street: "",
          city: "",
          zip: "",
        });

        if (status === ToolCallStatus.Executing && respond) {
          return (
            <View style={{ padding: 16, borderWidth: 1, borderRadius: 8, gap: 12 }}>
              <Text style={{ fontWeight: "500" }}>Order: {args.orderSummary}</Text>
              <Text>Please enter your shipping address:</Text>
              <TextInput
                placeholder="Street address"
                value={address.street}
                onChangeText={(street) => setAddress({ ...address, street })}
                style={{ borderWidth: 1, padding: 8, borderRadius: 6 }}
              />
              <TextInput
                placeholder="City"
                value={address.city}
                onChangeText={(city) => setAddress({ ...address, city })}
                style={{ borderWidth: 1, padding: 8, borderRadius: 6 }}
              />
              <TextInput
                placeholder="ZIP code"
                value={address.zip}
                onChangeText={(zip) => setAddress({ ...address, zip })}
                style={{ borderWidth: 1, padding: 8, borderRadius: 6 }}
              />
              <TouchableOpacity
                onPress={() => respond(address)}
                style={{ backgroundColor: "#3b82f6", paddingHorizontal: 16, paddingVertical: 8, borderRadius: 6 }}
              >
                <Text style={{ color: "#fff" }}>Submit Address</Text>
              </TouchableOpacity>
            </View>
          );
        }

        if (status === ToolCallStatus.Complete) {
          return (
            <View style={{ padding: 8 }}>
              <Text style={{ color: "#16a34a" }}>
                Shipping address submitted.
              </Text>
            </View>
          );
        }

        return null;
      },
    },
    [],
  );

  return null;
}
```

### 带上下文的审批工作流

```tsx
import { Text, TouchableOpacity, View } from "react-native";
import { useHumanInTheLoop, ToolCallStatus } from "@copilotkit/react-native";
import { z } from "zod";

function ExpenseApproval() {
  useHumanInTheLoop(
    {
      name: "approveExpense",
      description: "Request manager approval for an expense report",
      parameters: z.object({
        employeeName: z.string().describe("Name of the employee"),
        amount: z.number().describe("Expense amount in dollars"),
        category: z.string().describe("Expense category"),
        description: z.string().describe("Description of the expense"),
      }),
      render: ({ args, status, respond, result }) => {
        if (status === ToolCallStatus.Executing && respond) {
          return (
            <View style={{ padding: 16, borderWidth: 1, borderRadius: 8 }}>
              <Text style={{ fontWeight: "700" }}>Expense Approval Required</Text>
              <View style={{ marginTop: 8, gap: 4 }}>
                <Text style={{ fontSize: 12 }}>Employee: {args.employeeName}</Text>
                <Text style={{ fontSize: 12 }}>Amount: ${args.amount.toFixed(2)}</Text>
                <Text style={{ fontSize: 12 }}>Category: {args.category}</Text>
                <Text style={{ fontSize: 12 }}>Description: {args.description}</Text>
              </View>
              <View style={{ flexDirection: "row", gap: 8, marginTop: 16 }}>
                <TouchableOpacity
                  onPress={() => respond({ approved: true })}
                  style={{ backgroundColor: "#22c55e", paddingHorizontal: 16, paddingVertical: 8, borderRadius: 6 }}
                >
                  <Text style={{ color: "#fff" }}>Approve</Text>
                </TouchableOpacity>
                <TouchableOpacity
                  onPress={() =>
                    respond({ approved: false, reason: "Needs more detail" })
                  }
                  style={{ backgroundColor: "#ef4444", paddingHorizontal: 16, paddingVertical: 8, borderRadius: 6 }}
                >
                  <Text style={{ color: "#fff" }}>Reject</Text>
                </TouchableOpacity>
              </View>
            </View>
          );
        }

        if (status === ToolCallStatus.Complete && result) {
          const parsed = JSON.parse(result);
          return (
            <View style={{ padding: 8 }}>
              <Text style={{ fontSize: 12, color: parsed.approved ? "#16a34a" : "#dc2626" }}>
                {parsed.approved
                  ? "Expense approved."
                  : `Expense rejected: ${parsed.reason}`}
              </Text>
            </View>
          );
        }

        return null;
      },
    },
    [],
  );

  return null;
}
```

## 行为

- **阻塞智能体执行**：调用该工具时智能体会暂停，等待 `respond` 回调被调用后才继续。
- **内部状态机**：钩子管理三个状态：`InProgress`（参数流式传输中）、`Executing`（等待用户响应）和 `Complete`（用户已响应）。渲染组件会针对每个状态收到相应的 props。
- **单次响应**：每次工具调用只应调用一次 `respond` 回调。调用它会用所提供的值解析工具调用的 promise。
- **构建于 `useFrontendTool` 之上**：在底层，该钩子用内部生成的处理函数包装了 `useFrontendTool`，因此所有相同的生命周期行为（挂载/卸载注册、重复警告）同样适用。
- **挂载/卸载生命周期**：工具及其渲染组件在挂载时注册，在卸载时移除。
- **无返回值**：该钩子返回 `void`。

## ToolCallStatus

`ToolCallStatus` 枚举从 `@copilotkit/react-native` 导出，定义了工具执行的三个阶段：

| 值                          | 描述                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| `ToolCallStatus.InProgress` | 参数正在从智能体流式传输。工具尚未开始执行。                                                 |
| `ToolCallStatus.Executing`  | 参数已完全解析。对于 `useHumanInTheLoop`，`respond` 回调可用。                               |
| `ToolCallStatus.Complete`   | 执行已结束。`result` 字符串可用。                                                            |
