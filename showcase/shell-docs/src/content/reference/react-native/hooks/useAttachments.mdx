---

## 概览

`useAttachments` 是 Web 版 `useAttachments` hook 在 React Native 上的对应实现。它负责为聊天挑选、校验、上传和消费文件附件，使用 [`expo-document-picker`](https://docs.expo.dev/versions/latest/sdk/document-picker/) 和 [`expo-file-system`](https://docs.expo.dev/versions/latest/sdk/filesystem/) 替代 Web 的 `FileReader` / `<input type="file">` API。

无头（headless）的 [`CopilotChat`](/reference/react-native/components/CopilotChat) 在你传入其 `attachments` 属性时会自动接好这个 hook。只有在 `CopilotChat` 之外自行管理附件时，才需要直接调用 `useAttachments`。需要安装 `expo-document-picker` 和 `expo-file-system` 这两个对等依赖。

## 签名

```tsx
import { useAttachments } from "@copilotkit/react-native";

function useAttachments(props: UseNativeAttachmentsProps): UseNativeAttachmentsReturn;
```

## 参数

<PropertyReference name="props" type="UseNativeAttachmentsProps">
  该 hook 的配置对象。

  <PropertyReference name="config" type="NativeAttachmentsConfig">
    附件配置。

    <PropertyReference name="enabled" type="boolean" required>
      启用文件附件。为 `false` 时该 hook 不做任何事。
    </PropertyReference>

    <PropertyReference name="accept" type="string" default='"*/*"'>
      选择器的 MIME 类型过滤。支持通配符（`"image/*"`）和逗号分隔列表（`"image/*,application/pdf"`）。
    </PropertyReference>

    <PropertyReference name="maxSize" type="number" default="20971520">
      最大文件大小（字节）。默认为 20&nbsp;MB。
    </PropertyReference>

    <PropertyReference name="onUpload" type="(file: NativeFileInput) => AttachmentUploadResult | Promise<AttachmentUploadResult>">
      自定义上传处理函数。省略时，文件会经 `expo-file-system` 读取为 base64 并直接嵌入消息。
    </PropertyReference>

    <PropertyReference name="onUploadFailed" type="(error: { reason: AttachmentUploadErrorReason; file: NativeFileInput; message: string }) => void">
      附件未通过校验（例如类型错误或过大）或上传失败时调用。
    </PropertyReference>

  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="attachments" type="Attachment[]">
  当前已选择的附件（上传中 + 就绪）。
</PropertyReference>

<PropertyReference name="enabled" type="boolean">
  附件功能是否已启用。
</PropertyReference>

<PropertyReference name="openPicker" type="() => Promise<void>">
  打开原生文档选择器（经 `expo-document-picker`）并处理所选文件。
</PropertyReference>

<PropertyReference name="processFiles" type="(files: NativeFileInput[]) => Promise<void>">
  校验、读取一组文件并加入附件队列。当你从文档选择器以外的地方获取文件时很有用。
</PropertyReference>

<PropertyReference name="removeAttachment" type="(id: string) => void">
  按 ID 从队列中移除一个附件。
</PropertyReference>

<PropertyReference name="consumeAttachments" type="() => Attachment[]">
  返回就绪的附件并清空队列。提交消息时调用。
</PropertyReference>

### `NativeFileInput`

Web `File` 对象在 React Native 上的等价物。

<PropertyReference name="uri" type="string">
  本地文件 URI，例如 `file:///path/to/file`。
</PropertyReference>

<PropertyReference name="name" type="string">
  带扩展名的文件名。
</PropertyReference>

<PropertyReference name="size" type="number">
  文件大小（字节）。
</PropertyReference>

<PropertyReference name="mimeType" type="string">
  MIME 类型，例如 `"image/jpeg"`。
</PropertyReference>

## 用法

```tsx
import { useAttachments } from "@copilotkit/react-native";
import { getSourceUrl } from "@copilotkit/shared";
import { Button, Image, View } from "react-native";

function Composer() {
  const { attachments, openPicker, removeAttachment } = useAttachments({
    config: {
      enabled: true,
      accept: "image/*,application/pdf",
      maxSize: 10 * 1024 * 1024,
    },
  });

  return (
    <View>
      <Button title="Attach file" onPress={openPicker} />
      {attachments.map((a) => (
        <Image
          key={a.id}
          source={{ uri: getSourceUrl(a.source) }}
          style={{ width: 48, height: 48 }}
        />
      ))}
    </View>
  );
}
```

每个 `Attachment` 都以 `source`（base64 数据源或 URL 源）的形式暴露内容，而不是现成的 URL。`@copilotkit/shared` 的 `getSourceUrl` 可把这两种形式转换为可传给 `Image` 的字符串。

大多数应用改为通过 `CopilotChat` 以声明式方式启用附件：

```tsx
<CopilotChat agentId="default" attachments={{ enabled: true, accept: "image/*" }}>
  <MyChatUI />
</CopilotChat>
```
