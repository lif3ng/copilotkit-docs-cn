## 概览

`useThreads` 是一个用于管理 CopilotKit Intelligence 中会话线程的 React 钩子。它获取指定智能体的线程列表，通过 WebSocket 保持实时同步，并暴露重命名、归档和删除线程的变更方法。

<Callout type="warn">
  线程持久化运行在 CopilotKit Intelligence 中，需要使用 `publicLicenseKey` 访问。该密钥在 React Native 上**尚不支持**（参见 [`CopilotKitProvider`](/reference/react-native/components/CopilotKitProvider)），因此 `useThreads` 在此仅为保持 API 对等而记录，在 React Native 上尚不可用。
</Callout>

<Callout type="info">
  该钩子从 `@copilotkit/react-core/v2` 重新导出，与 [React (V2) 的 `useThreads`](/reference/v2/hooks/useThreads) 相同，唯一区别是导入路径。
</Callout>

线程按最近更新时间降序排列。提供 `limit` 时，钩子支持基于游标的分页。

## 签名

```tsx
import { useThreads } from "@copilotkit/react-native";

function useThreads(input: UseThreadsInput): UseThreadsResult
```

## 参数

<PropertyReference name="input" type="UseThreadsInput">
  钩子的配置对象。

  <PropertyReference name="agentId" type="string">
    要列出其线程的智能体 ID。必须与运行时中配置的某个智能体匹配。
  </PropertyReference>

  <PropertyReference name="includeArchived" type="boolean" default="false">
    是否在列表中包含已归档的线程。
  </PropertyReference>

  <PropertyReference name="limit" type="number" default="undefined">
    每页获取的最大线程数。设置后会通过 `fetchMoreThreads()` 和 `hasMoreThreads` 启用基于游标的分页。
  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="result" type="UseThreadsResult">

  ### 状态

  <PropertyReference name="threads" type="Thread[]">
    当前用户与智能体的线程数组，按最近更新时间降序排列。每个 `Thread` 包含：
    - `id: string`：唯一的线程标识符
    - `agentId: string`：该线程所属的智能体
    - `name: string | null`：线程名称（首次运行时由 LLM 自动生成，或通过 `renameThread` 手动设置）
    - `archived: boolean`：线程是否已归档
    - `createdAt: string`：ISO 8601 时间戳
    - `updatedAt: string`：ISO 8601 时间戳
    - `lastRunAt?: string`：此线程上最近一次运行的 ISO 8601 时间戳。仅当线程至少运行过一次时才存在。适用于展示与 `updatedAt` 有区分的“最近活动”时间（重命名/归档等元数据变更也会更新 `updatedAt`）。
  </PropertyReference>

  <PropertyReference name="isLoading" type="boolean">
    正在获取初始线程列表时为 `true`。
  </PropertyReference>

  <PropertyReference name="error" type="Error | null">
    获取或变更线程时最近一次的错误，未发生过错误则为 `null`。
  </PropertyReference>

  <PropertyReference name="hasMoreThreads" type="boolean">
    当前页之外还有更多线程时为 `true`。仅在设置了 `limit` 时有意义。
  </PropertyReference>

  <PropertyReference name="isFetchingMoreThreads" type="boolean">
    正在获取更多线程时为 `true`。
  </PropertyReference>

  ### 方法

  <PropertyReference name="fetchMoreThreads" type="() => void">
    获取下一页线程。当 `hasMoreThreads` 为 `false` 或已有获取在进行中时为空操作。
  </PropertyReference>

  <PropertyReference name="renameThread" type="(threadId: string, name: string) => Promise<void>">
    重命名线程。服务器确认操作后 promise 解析，失败时以 `Error` 拒绝。
  </PropertyReference>

  <PropertyReference name="archiveThread" type="(threadId: string) => Promise<void>">
    软删除线程。线程保留在数据库中且 `archived: true`，但除非 `includeArchived` 为 `true`，否则不会出现在列表中。已归档的线程可通过 `unarchived` 平台事件恢复。服务器确认后 promise 解析，失败时以 `Error` 拒绝。没有内置的确认对话框，如有需要请自行实现。
  </PropertyReference>

  <PropertyReference name="deleteThread" type="(threadId: string) => Promise<void>">
    永久且不可逆地删除线程。线程记录会从数据库中彻底移除。服务器确认后 promise 解析，失败时以 `Error` 拒绝。没有内置的确认对话框，如有需要请自行实现。
  </PropertyReference>
</PropertyReference>

## 用法

```tsx title="ThreadList.tsx"
import { useThreads } from "@copilotkit/react-native"; // [!code highlight]
import { FlatList, Text, TouchableOpacity, View } from "react-native";

function ThreadList() {
  const {
    threads,
    isLoading,
    renameThread,
    archiveThread,
    deleteThread,
  } = useThreads({ agentId: "my-agent" }); // [!code highlight]

  if (isLoading) {
    return (
      <View>
        <Text>Loading threads...</Text>
      </View>
    );
  }

  return (
    <FlatList
      data={threads}
      keyExtractor={(thread) => thread.id}
      renderItem={({ item: thread }) => (
        <View>
          <Text>{thread.name ?? "Untitled"}</Text>
          <TouchableOpacity onPress={() => renameThread(thread.id, "New name")}>
            <Text>Rename</Text>
          </TouchableOpacity>
          <TouchableOpacity onPress={() => archiveThread(thread.id)}>
            <Text>Archive</Text>
          </TouchableOpacity>
          <TouchableOpacity onPress={() => deleteThread(thread.id)}>
            <Text>Delete</Text>
          </TouchableOpacity>
        </View>
      )}
    />
  );
}
```

## 行为

- 挂载时获取线程列表并建立实时 WebSocket 订阅。
- 来自任何客户端的线程创建、重命名、归档与删除都会立即反映出来，无需轮询。
- 所有变更方法都采用**悲观更新**：UI 只在服务器通过 WebSocket 确认操作后才更新，而不是在发出请求时立即更新。promise 在确认时解析（15 秒超时），失败时拒绝。
- `error` 状态会更新为任何操作的最近一次错误。
- `threads` 数组始终保持按 `updatedAt` 降序排列（最新的在前）。
- 新线程会在首次运行后由 LLM **自动命名**（2 到 5 个词的短标题）。可通过运行时上的 `generateThreadNames` 进行配置。
