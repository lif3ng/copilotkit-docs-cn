## 概览

`useSuggestions` 是一个 React 钩子，用于访问指定智能体当前的聊天建议。它订阅建议的变化，并在建议被更新、清除或重新加载时自动重新渲染。

<Callout type="info">
  该钩子从 `@copilotkit/react-core/v2` 重新导出。它与 [React (V2) 的 `useSuggestions`](/reference/v2/hooks/useSuggestions) 完全相同，仅导入路径不同。
</Callout>

建议通过 [`useConfigureSuggestions`](/reference/react-native/hooks/useConfigureSuggestions) 配置，可以是静态（预定义）的，也可以是动态（由智能体生成）的。

## 签名

```tsx
import { useSuggestions } from "@copilotkit/react-native";

function useSuggestions(options?: UseSuggestionsOptions): UseSuggestionsResult;
```

## 参数

<PropertyReference name="options" type="UseSuggestionsOptions">
  钩子的可选配置对象。

  <PropertyReference name="agentId" type="string" default='"default"'>
    要获取其建议的智能体 ID。如果省略，会回退到最近的 `CopilotChatConfigurationProvider` 提供的智能体 ID，或 `"default"`。
  </PropertyReference>
</PropertyReference>

## 返回值

<PropertyReference name="result" type="UseSuggestionsResult">
  包含当前建议与控制函数的对象。

<PropertyReference name="suggestions" type="Suggestion[]">
  当前建议的数组。每个 `Suggestion` 包含：`title: string`，建议的简短显示标题；`message: string`，选中该建议后发送的消息内容；以及 `isLoading: boolean`，该建议是否仍在生成中。
</PropertyReference>

<PropertyReference name="reloadSuggestions" type="() => void">
  触发重新加载已解析智能体的建议。对于动态建议，这会重新调用生成过程。`isLoading` 状态通过订阅事件自动更新。
</PropertyReference>

<PropertyReference name="clearSuggestions" type="() => void">
  清除已解析智能体的所有当前建议。
</PropertyReference>

  <PropertyReference name="isLoading" type="boolean">
    建议当前是否正在生成或加载。
  </PropertyReference>
</PropertyReference>

## 用法

### 基本用法

```tsx
import { Text, View } from "react-native";

function SuggestionsList() {
  const { suggestions, isLoading } = useSuggestions();

  if (isLoading) {
    return <Text>Loading suggestions...</Text>;
  }

  return (
    <View>
      {suggestions.map((suggestion, i) => (
        <View key={i}>
          <Text style={{ fontWeight: "bold" }}>{suggestion.title}</Text>
          <Text>{suggestion.message}</Text>
        </View>
      ))}
    </View>
  );
}
```

### 带重新加载与清除控件

```tsx
import { Text, TouchableOpacity, View } from "react-native";

function SuggestionsPanel() {
  const { suggestions, reloadSuggestions, clearSuggestions, isLoading } =
    useSuggestions();

  return (
    <View>
      <View>
        <TouchableOpacity onPress={reloadSuggestions} disabled={isLoading}>
          <Text>Refresh</Text>
        </TouchableOpacity>
        <TouchableOpacity onPress={clearSuggestions}>
          <Text>Clear</Text>
        </TouchableOpacity>
      </View>
      {suggestions.map((suggestion, i) => (
        <TouchableOpacity key={i} disabled={suggestion.isLoading}>
          <Text>{suggestion.title}</Text>
        </TouchableOpacity>
      ))}
    </View>
  );
}
```

### 面向特定智能体

```tsx
import { Text, View } from "react-native";

function AgentSuggestions() {
  const { suggestions } = useSuggestions({ agentId: "support-agent" });

  return (
    <View>
      <Text>Support Agent Suggestions</Text>
      {suggestions.map((s, i) => (
        <Text key={i}>{s.title}</Text>
      ))}
    </View>
  );
}
```

## 行为

- **自动订阅**：钩子订阅核心实例上的建议变化事件，每当已解析智能体的建议被添加、移除或更新时就会重新渲染。
- **智能体解析**：`agentId` 按以下优先级解析：显式的 `agentId` 选项、来自最近 `CopilotChatConfigurationProvider` 的 `agentId`，然后是默认智能体 ID（`"default"`）。
- **加载状态**：动态建议重新加载开始时 `isLoading` 变为 `true`，生成完成后恢复为 `false`。
- **初始状态**：挂载时，钩子会从核心实例同步读取当前建议，因此静态建议不会出现不必要的加载闪烁。
