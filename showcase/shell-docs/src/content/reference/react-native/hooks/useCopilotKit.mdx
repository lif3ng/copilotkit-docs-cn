## 概览

`useCopilotKit` 是一个底层 React 钩子，返回 CopilotKit 上下文的值，提供对核心实例与提供方（provider）级状态的直接访问。它订阅运行时连接状态的变化，并在连接状态更新时触发重新渲染。

<Callout type="info">
  该钩子从 `@copilotkit/react-core/v2` 重新导出，与 [React (V2) 的 `useCopilotKit`](/reference/v2/hooks/useCopilotKit) 相同，唯一区别是导入路径。
</Callout>

<Callout type="info">
  `useCopilotKit` 是一个底层钩子。大多数应用应改用 `useAgent` 或 `useFrontendTool` 等更高层的钩子。
</Callout>

**在 `CopilotKitProvider` 之外使用会抛出错误**。

## 签名

```tsx
import { useCopilotKit } from "@copilotkit/react-native";

function useCopilotKit(): CopilotKitContextValue;
```

## 参数

此钩子不接受任何参数。

## 返回值

<PropertyReference name="context" type="CopilotKitContextValue">
  包含核心实例与提供方级状态的上下文对象。

  <PropertyReference name="copilotkit" type="CopilotKitCoreReact">
    活动的 CopilotKit 核心实例。它是管理智能体、工具、建议以及运行时通信的中央协调器，暴露以下方法：
    - 智能体管理（`agents`、`getAgent`）
    - 工具注册与执行
    - 建议配置与获取
    - 运行时连接管理
    - 通过 `subscribe()` 进行事件订阅

    核心实例每个 `CopilotKitProvider` 只创建一次，并在重新渲染之间保持稳定。

  </PropertyReference>

  <PropertyReference name="executingToolCallIds" type="ReadonlySet<string>">
    当前正在执行的工具调用 ID 集合。它在提供方（provider）级别进行跟踪，以确保即使子组件尚未挂载，工具执行事件也能被捕获。这对于人机协同（human-in-the-loop）重连等场景非常重要——组件树挂载时可能已经存在待处理的工具调用。
  </PropertyReference>
</PropertyReference>

## 用法

### 访问核心实例

```tsx
import { Text, View } from "react-native";
import { useCopilotKit } from "@copilotkit/react-native";

function DebugPanel() {
  const { copilotkit } = useCopilotKit();

  const agents = Object.keys(copilotkit.agents ?? {});

  return (
    <View>
      <Text>Registered Agents</Text>
      {agents.map((id) => (
        <Text key={id}>{id}</Text>
      ))}
    </View>
  );
}
```

### 运行智能体

`copilotkit.runAgent()` 直接从代码触发智能体运行。这是经过验证的 React Native 模式：先向智能体添加一条消息，然后运行它。

```tsx
import { useCallback, useState } from "react";
import { Text, TextInput, TouchableOpacity, View } from "react-native";
import { useAgent, useCopilotKit } from "@copilotkit/react-native";

function Composer() {
  const [inputText, setInputText] = useState("");
  const { copilotkit } = useCopilotKit();
  const { agent } = useAgent({ agentId: "default" });

  const handleSend = useCallback(async () => {
    const text = inputText.trim();
    if (!text || !agent) return;
    setInputText("");
    agent.addMessage({
      id: `user-${Date.now()}`,
      role: "user",
      content: text,
    });
    try {
      await copilotkit.runAgent({ agent });
    } catch (error) {
      console.error("CopilotKit runAgent failed:", error);
    }
  }, [inputText, agent, copilotkit]);

  return (
    <View>
      <TextInput
        value={inputText}
        onChangeText={setInputText}
        placeholder="Type a message..."
        onSubmitEditing={handleSend}
      />
      <TouchableOpacity onPress={handleSend}>
        <Text>Send</Text>
      </TouchableOpacity>
    </View>
  );
}
```

### 订阅核心事件

```tsx
import { useEffect } from "react";
import { useCopilotKit } from "@copilotkit/react-native";

function ConnectionMonitor() {
  const { copilotkit } = useCopilotKit();

  useEffect(() => {
    const subscription = copilotkit.subscribe({
      onRuntimeConnectionStatusChanged: () => {
        console.log("Runtime connection status changed");
      },
    });

    return () => {
      subscription.unsubscribe();
    };
  }, [copilotkit]);

  return null;
}
```

### 以编程方式运行工具

`copilotkit.runTool()` 让你可以直接从代码执行已注册的前端工具，无需 LLM 轮次。工具的处理函数会运行，渲染组件会出现在 UI 中，并且工具调用与结果都会被加入智能体的消息历史。

```tsx
import { Text, TouchableOpacity } from "react-native";
import { useCopilotKit, useFrontendTool } from "@copilotkit/react-native";
import { z } from "zod";

function ExportButton() {
  const { copilotkit } = useCopilotKit();

  // Register the tool
  useFrontendTool({
    name: "exportData",
    description: "Export data as CSV",
    parameters: z.object({ format: z.string() }),
    handler: async ({ format }) => {
      const csv = await generateCsv(format);
      await saveFile(csv);
      return `Exported as ${format}`;
    },
  });

  // Trigger it from a button, no LLM needed
  const handleExport = async () => {
    const { result, error } = await copilotkit.runTool({
      name: "exportData",
      parameters: { format: "csv" },
    });
    if (error) console.error(error);
  };

  return (
    <TouchableOpacity onPress={handleExport}>
      <Text>Export CSV</Text>
    </TouchableOpacity>
  );
}
```

#### `runTool` 参数

<PropertyReference name="params" type="CopilotKitCoreRunToolParams">
  <PropertyReference name="name" type="string" required>
    要执行的已注册前端工具的名称。
  </PropertyReference>

<PropertyReference name="agentId" type="string">
  用于工具与消息作用域的智能体 ID。默认为 `"default"`。
</PropertyReference>

<PropertyReference
  name="parameters"
  type="Record<string, unknown>"
  default="{}"
>
  传递给工具处理函数的参数。
</PropertyReference>

  <PropertyReference name="followUp" type="string | false" default="false">
    控制执行后是否触发 LLM 后续操作：
    - `false`：执行工具并停止（默认）
    - `"generate"`：触发智能体运行，让 LLM 响应工具结果
    - 任意其他字符串：以此文本添加一条用户消息，然后触发智能体运行
  </PropertyReference>
</PropertyReference>

#### `runTool` 返回值

<PropertyReference name="result" type="CopilotKitCoreRunToolResult">
  <PropertyReference name="toolCallId" type="string">
    工具调用的唯一 ID，与添加到历史记录中的消息相对应。
  </PropertyReference>

<PropertyReference name="result" type="string">
  工具处理函数返回值的字符串化形式（仅渲染的工具为空字符串）。
</PropertyReference>

  <PropertyReference name="error" type="string | undefined">
    处理函数抛出错误时的错误消息。工具结果消息将包含 `"Error: ..."`。
  </PropertyReference>
</PropertyReference>

### 检查工具执行状态

```tsx
import { Text } from "react-native";
import { useCopilotKit } from "@copilotkit/react-native";

function ToolExecutionIndicator() {
  const { executingToolCallIds } = useCopilotKit();

  if (executingToolCallIds.size === 0) {
    return null;
  }

  return <Text>Executing {executingToolCallIds.size} tool call(s)...</Text>;
}
```

## 行为

- **缺少 Provider 时报错**：在 `CopilotKitProvider` 之外使用该钩子会抛出错误。
- **运行时状态订阅**：该钩子订阅 `onRuntimeConnectionStatusChanged` 事件，因此当运行时连接完成或失败时，组件会重新渲染。
- **稳定的核心引用**：`copilotkit` 实例每个提供方只创建一次，并在重新渲染之间保持稳定。只有 `executingToolCallIds` 集合会随着工具调用的开始与结束而变化。
- **提供方级工具跟踪**：`executingToolCallIds` 在提供方（provider）级别而非各个组件中进行跟踪。这确保了在子组件挂载之前触发的工具执行开始事件不会丢失。
