## 概览

`useComponent` 是构建在 `useFrontendTool` 之上的一个便捷 hook。
它会注册一个工具，并使用工具调用参数在聊天中渲染 React Native 组件。

<Callout type="info">
  从 `@copilotkit/react-core/v2` 重新导出。与 [React (V2) 的 `useComponent`](/reference/v2/hooks/useComponent) 完全相同，只是导入路径不同。
</Callout>

当你想要一个可视化的组件渲染器、又不想手写完整的前端工具配置时，就使用它。你传给 `render` 的组件返回 React Native 元素，由 CopilotKit 呈现在聊天中——它注册到与 [`useRenderTool`](/reference/react-native/hooks/useRenderTool) 和 `useFrontendTool` 写入的同一个共享渲染器注册表，聊天则通过 `useRenderToolCall` 读取该注册表。

## 签名

```tsx
import { z } from "zod";
import type { ComponentType } from "react";
import { useComponent } from "@copilotkit/react-native";

function useComponent<TSchema extends z.ZodTypeAny | undefined = undefined>(
  config: {
    name: string;
    description?: string;
    parameters?: TSchema;
    // When parameters is provided, props are inferred via z.infer.
    // When omitted, render accepts any props.
    render: ComponentType<InferRenderProps<TSchema>>;
    agentId?: string;
  },
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

- `config.name`：智能体调用该组件工具所用的工具名称。
- `config.description`：可选的额外描述，用于引导模型。
- `config.parameters`：可选的 Zod schema，描述工具的参数。提供时，`render` 的 props 会从该 schema 推断。省略时，工具会以空参数 schema（`{ "type": "object", "properties": {} }`）对外声明，因此智能体调用它时不带任何参数。
- `config.render`：以解析后的工具参数为 props 进行渲染的 React Native 组件。省略 `parameters` 时可接受任意 props。
- `config.agentId`：可选的注册作用域（智能体）。
- `deps`：可选的依赖数组，用于刷新注册。

## 行为

- 会在描述前追加一条默认指令：_“Use this tool to display the \"&lt;name&gt;\" component in the chat...”_。
- 内部调用 `useFrontendTool`，其渲染函数会把工具参数展开为组件 props。
- 继承 `useFrontendTool` 的生命周期行为：重名覆盖警告、卸载时移除工具，以及为聊天历史保留渲染器。
- 以 `config.name` 加 `deps` 追踪更新（把任何会变化的捕获值放进 `deps`）。
- **`deps` 比较**：对纯数据（字符串、数字、布尔值、`null`、日期，以及由它们组成的普通对象和数组）按值比较，因此 `[{ status }]` 这类内联字面量只在其内容变化时才重新注册。函数与之前一样永远不会被判为已变化，所以请把会变化的回调保存在 ref 中。类实例与其他对象按引用比较，因此像 `useAgent` 返回的 `agent` 这样的循环引用值可以安全传入。增删条目也算变化。

## 用法

```tsx
import { Text, View } from "react-native";
import { useComponent } from "@copilotkit/react-native";
import { z } from "zod";

const weatherCardSchema = z.object({
  city: z.string().describe("City name"),
  unit: z.enum(["c", "f"]).default("c"),
});

type WeatherCardProps = z.infer<typeof weatherCardSchema>;

function WeatherCard({ city, unit }: WeatherCardProps) {
  return (
    <View style={{ borderWidth: 1, borderRadius: 8, padding: 12 }}>
      <Text style={{ fontSize: 12, color: "#71717a" }}>Weather request</Text>
      <Text style={{ fontWeight: "500" }}>
        {city} ({unit.toUpperCase()})
      </Text>
    </View>
  );
}

function App() {
  useComponent(
    {
      name: "showWeatherCard",
      description: "Render a weather card in chat for the requested city.",
      parameters: weatherCardSchema,
      render: WeatherCard,
    },
    [],
  );

  return null;
}
```
