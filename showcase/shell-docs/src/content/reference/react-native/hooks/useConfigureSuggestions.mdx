## 概览

`useConfigureSuggestions` 是一个 React 钩子，用于向 CopilotKit 核心注册建议配置。它支持两种模式：**静态**建议（固定列表）和**动态**建议（由智能体根据指令生成）。

<Callout type="info">
  该钩子从 `@copilotkit/react-core/v2` 重新导出。它与 [React (V2) 的 `useConfigureSuggestions`](/reference/v2/hooks/useConfigureSuggestions) 完全相同，仅导入路径不同。
</Callout>

配置会在挂载时自动注册，并在卸载时自动移除。当配置发生变化时，建议会自动重新加载。

## 签名

```tsx
import { useConfigureSuggestions } from "@copilotkit/react-native";

function useConfigureSuggestions(
  config: SuggestionsConfigInput | null | undefined,
  deps?: ReadonlyArray<unknown>,
): void;
```

## 参数

<PropertyReference name="config" type="SuggestionsConfigInput | null | undefined">
  建议配置。传入 `null` 或 `undefined` 可禁用建议。可以是 `DynamicSuggestionsConfig` 或 `StaticSuggestionsConfigInput`。

### 动态配置

当建议需要由智能体在运行时生成时使用。

<PropertyReference name="instructions" type="string" required>
  用于让模型生成建议的提示或指令。这是区分动态配置与静态配置的关键字段。
</PropertyReference>

<PropertyReference name="minSuggestions" type="number" default="1">
  要生成的建议数量下限。
</PropertyReference>

<PropertyReference name="maxSuggestions" type="number" default="3">
  要生成的建议数量上限。
</PropertyReference>

<PropertyReference
  name="available"
  type="SuggestionAvailability"
  default='"after-first-message"'
>
  建议何时可用。选项：`"before-first-message"` 在发送任何消息之前显示建议；`"after-first-message"` 在第一条消息之后显示建议（动态配置的默认值）；`"always"` 始终显示建议；`"disabled"` 关闭建议。
</PropertyReference>

<PropertyReference name="providerAgentId" type="string" default='"default"'>
  生成建议的提供方（provider）的智能体 ID。
</PropertyReference>

<PropertyReference name="consumerAgentId" type="string" default='"*"'>
  显示建议的消费方（consumer）的智能体 ID。默认为 `"*"`（所有智能体）。
</PropertyReference>

### 静态配置

当建议是预定义列表时使用。

<PropertyReference name="suggestions" type="StaticSuggestionInput[]" required>
  建议对象数组。每个建议包含：`title: string`，建议的简短显示标题；`message: string`，选中后发送的消息内容；以及 `isLoading?: boolean`，可选的加载状态（默认为 `false`）。
</PropertyReference>

<PropertyReference
  name="available"
  type="SuggestionAvailability"
  default='"before-first-message"'
>
  建议何时可用。选项与动态配置相同。
</PropertyReference>

  <PropertyReference name="consumerAgentId" type="string" default='"*"'>
    显示建议的消费方（consumer）的智能体 ID。默认为 `"*"`（所有智能体）。
  </PropertyReference>
</PropertyReference>

<PropertyReference name="deps" type="ReadonlyArray<unknown>">
  可选的依赖数组。当数组中任何值发生变化时，建议会重新加载。这对于依赖外部状态的动态建议很有用。
</PropertyReference>

## 用法

### 静态建议

```tsx
function WelcomeSuggestions() {
  useConfigureSuggestions({
    suggestions: [
      { title: "Get started", message: "Help me get started with my project" },
      { title: "Show examples", message: "Show me some example use cases" },
      {
        title: "Documentation",
        message: "Where can I find the documentation?",
      },
    ],
    available: "before-first-message",
  });

  return null;
}
```

### 动态建议

```tsx
function SmartSuggestions() {
  useConfigureSuggestions({
    instructions:
      "Suggest follow-up questions based on the conversation so far. " +
      "Focus on actionable next steps the user might want to take.",
    maxSuggestions: 3,
    minSuggestions: 1,
    available: "after-first-message",
  });

  return null;
}
```

### 带依赖的动态建议

```tsx
import { useState } from "react";
import { Text, TouchableOpacity, View } from "react-native";

const TOPICS = ["general", "technical", "business"];

function ContextualSuggestions() {
  const [topic, setTopic] = useState("general");

  useConfigureSuggestions(
    {
      instructions: `Generate suggestions related to the topic: ${topic}`,
      maxSuggestions: 3,
    },
    [topic],
  );

  return (
    <View style={{ flexDirection: "row", gap: 8 }}>
      {TOPICS.map((value) => (
        <TouchableOpacity key={value} onPress={() => setTopic(value)}>
          <Text style={{ fontWeight: topic === value ? "700" : "400" }}>
            {value}
          </Text>
        </TouchableOpacity>
      ))}
    </View>
  );
}
```

### 条件性禁用建议

```tsx
function ConditionalSuggestions({ enabled }: { enabled: boolean }) {
  useConfigureSuggestions(
    enabled
      ? {
          suggestions: [{ title: "Help", message: "I need help" }],
        }
      : null,
  );

  return null;
}
```

### 面向特定智能体

```tsx
function AgentSpecificSuggestions() {
  useConfigureSuggestions({
    instructions: "Suggest data analysis tasks the user can perform.",
    maxSuggestions: 4,
    providerAgentId: "analyst",
    consumerAgentId: "analyst",
    available: "always",
  });

  return null;
}
```

## 行为

- **自动注册**：配置会在挂载时向核心注册，并在卸载时移除。这保证了清晰的生命周期管理。
- **变更检测**：钩子会将配置序列化为 JSON 进行比较。如果序列化后的值发生变化，旧配置会被移除并注册新配置，从而触发重新加载。
- **依赖追踪**：提供 `deps` 数组时，其值的任何变化都会触发建议重新加载，即使序列化后的配置本身没有变化。
- **配置判别**：钩子通过检查 `instructions` 属性是否存在来区分动态配置与静态配置。如果存在 `instructions`，则视为动态配置。
- **禁用状态**：传入 `null`、`undefined` 或带有 `available: "disabled"` 的配置，会移除之前注册的任何配置，并且不产生建议。
- **isLoading 归一化**：对于静态建议，`isLoading` 字段在未显式提供时默认为 `false`。
