## 概览

`CopilotChat` 会连接一个智能体，并将其会话状态暴露给后代组件。它有**两个**版本，由导入路径决定：

- **无头版**（`@copilotkit/react-native`）不渲染任何 UI。它会接入 [`useAgent`](/reference/react-native/hooks/useAgent)、管理附件，并通过 [`useCopilotChatContext`](#usecopilotchatcontext) 暴露一切，让你用 React Native 视图自行构建界面。
- **预构建 UI**（`@copilotkit/react-native/components`）是现成的全屏聊天界面，带消息列表、输入栏和可选头部。参见[预构建 UI](#预构建-ui)。

## 无头 `CopilotChat`

```tsx
import { CopilotChat, useCopilotChatContext } from "@copilotkit/react-native";
```

### 属性

<PropertyReference name="agentId" type="string" default='"default"'>
  要连接的智能体 ID。解析顺序：`agentId` → `agentName` →
  `"default"`。
</PropertyReference>

<PropertyReference name="agentName" type="string">
  **已弃用**。请使用 `agentId`。仅为向后兼容而保留。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  此聊天会话的线程 ID。提供时，聊天会恢复指定的线程，而不是开启新线程。
</PropertyReference>

<PropertyReference name="onError" type="(event: { error: Error; code: CopilotKitCoreErrorCode; context: Record<string, any> }) => void | Promise<void>">
  作用域限定为此聊天智能体的错误处理器。它在提供方层级 `onError` 之外触发（不会抑制后者），只接收 `context.agentId` 与此聊天智能体匹配的错误。
</PropertyReference>

<PropertyReference name="throttleMs" type="number">
  由消息变更触发的重新渲染的节流间隔（毫秒）。覆盖提供方的 `defaultThrottleMs`。
</PropertyReference>

<PropertyReference name="attachments" type="NativeAttachmentsConfig">
  启用并配置多模态文件附件。子组件从 [`useCopilotChatContext`](#usecopilotchatcontext) 读取附件状态与操作。参见
  [`useAttachments`](/reference/react-native/hooks/useAttachments)。
</PropertyReference>

<PropertyReference name="children" type="ReactNode">
  你的聊天 UI。渲染消费
  [`useCopilotChatContext`](#usecopilotchatcontext) 的 React Native 视图。
</PropertyReference>

### `useCopilotChatContext`

在 `<CopilotChat>` 树内调用以读取会话状态与操作。在 `<CopilotChat>` 之外调用会抛出异常。

```tsx
function useCopilotChatContext(): CopilotChatContextValue;
```

<PropertyReference name="agent" type="AbstractAgent">
  已解析的智能体实例。
</PropertyReference>

<PropertyReference name="isRunning" type="boolean">
  智能体当前是否正在运行。
</PropertyReference>

<PropertyReference name="messages" type="Message[]">
  当前会话消息。
</PropertyReference>

<PropertyReference name="attachments" type="Attachment[]">
  当前选中的附件（上传中 + 就绪）。
</PropertyReference>

<PropertyReference name="attachmentsEnabled" type="boolean">
  此聊天是否启用了附件。
</PropertyReference>

<PropertyReference name="openPicker" type="() => Promise<void>">
  打开原生文档选择器以添加文件。
</PropertyReference>

<PropertyReference name="removeAttachment" type="(id: string) => void">
  按 ID 移除附件。
</PropertyReference>

<PropertyReference name="submitMessage" type="(text: string) => Promise<void>">
  提交消息。会消耗就绪的附件、构建消息内容、添加用户消息并运行智能体。
</PropertyReference>

### 用法

```tsx
import { CopilotChat, useCopilotChatContext } from "@copilotkit/react-native";
import { useState } from "react";
import { FlatList, Text, TextInput, TouchableOpacity, View } from "react-native";

function ChatUI() {
  const { messages, isRunning, submitMessage } = useCopilotChatContext();
  const [text, setText] = useState("");

  return (
    <View style={{ flex: 1 }}>
      <FlatList
        data={messages.filter((m) => m.content)}
        keyExtractor={(m, i) => m.id ?? String(i)}
        renderItem={({ item }) => (
          <Text style={{ padding: 12 }}>{item.content}</Text>
        )}
      />
      <View style={{ flexDirection: "row", padding: 8 }}>
        <TextInput
          style={{ flex: 1, borderWidth: 1, borderRadius: 8, padding: 8 }}
          value={text}
          onChangeText={setText}
          placeholder="Type a message..."
        />
        <TouchableOpacity
          disabled={isRunning}
          onPress={() => {
            submitMessage(text);
            setText("");
          }}
          style={{ padding: 8 }}
        >
          <Text>Send</Text>
        </TouchableOpacity>
      </View>
    </View>
  );
}

export function ChatScreen() {
  return (
    <CopilotChat agentId="default">
      <ChatUI />
    </CopilotChat>
  );
}
```

## 预构建 UI

想要现成的界面，请从 `/components` 子路径导入 `CopilotChat`。它渲染一个全屏聊天界面，带消息列表、输入栏、可选头部和内联工具调用渲染——它读取由 [`useRenderTool`](/reference/react-native/hooks/useRenderTool)、`useFrontendTool` 和 `useComponent` 写入的共享渲染器注册表。

```tsx
import { CopilotChat } from "@copilotkit/react-native/components";
```

### 属性

<Callout type="info">
  预构建 UI 组件使用 `agentName`（而非无头版的 `agentId`）选择智能体。二者等价；`agentName` 只是预构建组件目前暴露的 prop 名称。
</Callout>

<PropertyReference name="agentName" type="string" default='"default"'>
  要连接的智能体 ID。
</PropertyReference>

<PropertyReference name="placeholder" type="string">
  输入框的占位文本。
</PropertyReference>

<PropertyReference name="initialMessages" type="string[]" default="[]">
  空状态下显示的建议胶囊按钮。
</PropertyReference>

<PropertyReference name="emptyStateTitle" type="string">
  无消息时显示的标题。
</PropertyReference>

<PropertyReference name="emptyStateSubtitle" type="string">
  无消息时显示的副标题。
</PropertyReference>

<PropertyReference name="headerTitle" type="string">
  可选头部栏的标题。
</PropertyReference>

<PropertyReference name="showHeader" type="boolean" default="true">
  是否显示头部栏。
</PropertyReference>

<PropertyReference name="style" type="ViewStyle">
  最外层容器的样式覆盖。
</PropertyReference>

<PropertyReference name="messageContainerStyle" type="ViewStyle">
  消息列表容器的样式覆盖。
</PropertyReference>

<PropertyReference name="inputContainerStyle" type="ViewStyle">
  输入栏容器的样式覆盖。
</PropertyReference>

<PropertyReference name="onSendMessage" type="(text: string) => void">
  用户发送消息时触发的回调。
</PropertyReference>

<PropertyReference name="FlatListComponent" type="React.ComponentType<any>" default="FlatList">
  自定义列表组件，例如嵌套在底部弹层（bottom sheet）中时使用 `BottomSheetFlatList`。
</PropertyReference>

<PropertyReference name="disableKeyboardAvoiding" type="boolean" default="false">
  为 `true` 时，跳过 `KeyboardAvoidingView` 包装器（当父级已处理键盘时很有用）。
</PropertyReference>

### 用法

```tsx
import { CopilotChat } from "@copilotkit/react-native/components";

export function ChatScreen() {
  return (
    <CopilotChat
      agentName="default"
      headerTitle="Assistant"
      placeholder="Ask me anything..."
      initialMessages={["What's the weather?", "Summarize my tasks"]}
    />
  );
}
```
