## 概览

`CopilotSidebar` 渲染一个从屏幕右缘滑入的抽屉，带有标题栏、遮罩层，以及一个用于切换它的可选悬浮操作按钮（FAB）。抽屉的聊天区域包装了一个无头（headless）的 [`CopilotChat`](/reference/react-native/components/CopilotChat)。将你的聊天 UI 作为 `children` 渲染（消费 [`useCopilotChatContext`](/reference/react-native/components/CopilotChat#usecopilotchatcontext)），或直接放入来自 `@copilotkit/react-native/components` 的预构建 `CopilotChat` UI。

可以通过 `CopilotSidebarHandle` ref 以命令式方式控制它。

## 导入

```tsx
import { CopilotSidebar, type CopilotSidebarHandle } from "@copilotkit/react-native";
```

## 属性

接受无头 [`CopilotChat` 的属性](/reference/react-native/components/CopilotChat#props)（`agentId`、`agentName`、`threadId`、`onError`、`throttleMs`、`attachments`），其中 `children` 被改用作抽屉主体内容，此外还有：

<PropertyReference name="defaultOpen" type="boolean" default="false">
  抽屉是否以打开状态启动。
</PropertyReference>

<PropertyReference name="width" type="number | string" default='"85%"'>
  抽屉面板的宽度。接受点数（数字）或相对于屏幕宽度解析的百分比字符串。
</PropertyReference>

<PropertyReference name="headerTitle" type="string" default='"Copilot"'>
  抽屉标题栏中显示的标题。
</PropertyReference>

<PropertyReference name="showToggleButton" type="boolean" default="true">
  显示一个用于切换抽屉的悬浮操作按钮。抽屉打开期间该按钮隐藏。
</PropertyReference>

<PropertyReference name="onOpen" type="() => void">
  抽屉完成打开后调用。
</PropertyReference>

<PropertyReference name="onClose" type="() => void">
  抽屉完成关闭后调用。
</PropertyReference>

<PropertyReference name="style" type="ViewStyle">
  应用于抽屉容器的自定义样式。
</PropertyReference>

<PropertyReference name="children" type="ReactNode">
  在抽屉内、标题栏下方渲染的内容。在这里基于 [`useCopilotChatContext`](/reference/react-native/components/CopilotChat#usecopilotchatcontext) 构建你的聊天 UI。
</PropertyReference>

## Ref 句柄

<PropertyReference name="CopilotSidebarHandle" type="{ open(): void; close(): void; toggle(): void }">
  通过 `ref` 暴露的命令式句柄，用于以编程方式打开、关闭和切换抽屉。
</PropertyReference>

## 用法

```tsx
import { CopilotSidebar, type CopilotSidebarHandle } from "@copilotkit/react-native";
import { CopilotChat } from "@copilotkit/react-native/components";
import { useRef } from "react";

export function ChatScreen() {
  const sidebarRef = useRef<CopilotSidebarHandle>(null);

  return (
    <CopilotSidebar ref={sidebarRef} agentId="default" headerTitle="Assistant">
      <CopilotChat agentName="default" showHeader={false} />
    </CopilotSidebar>
  );
}
```

## 行为

- **动画**：使用 React Native 的 `Animated` API 在 300 毫秒内滑入/滑出。
- **遮罩层**：半透明、可按压的遮罩层会关闭抽屉。
- **FAB**：当 `showToggleButton` 为 `true` 时，悬浮按钮可打开抽屉，抽屉打开期间该按钮隐藏。
