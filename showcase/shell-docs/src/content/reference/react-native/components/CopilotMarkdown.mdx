## 概览

`CopilotMarkdown` 以合理的 React Native 样式渲染 Markdown 字符串，构建于 [`react-native-streamdown`](https://www.npmjs.com/package/react-native-streamdown) 之上。它能优雅地处理不完整的（流式）Markdown，随内容到达逐步渲染，因此非常适合助手消息。需要 `react-native-streamdown` 对等依赖。

## 导入

```tsx
import { CopilotMarkdown, defaultMarkdownStyles } from "@copilotkit/react-native/components";
```

## 属性

<PropertyReference name="content" type="string" required>
  要渲染的 Markdown 字符串。
</PropertyReference>

<PropertyReference name="style" type="MarkdownStyle">
  可选的样式覆盖，合并在默认样式之上。它是 Markdown 元素名（如 `paragraph`、`h1`、`link`、`code`）到样式对象的映射，因此只需覆盖需要的部分。
</PropertyReference>

<PropertyReference name="streamingAnimation" type="boolean" default="true">
  是否在内容到达时启用流式淡入动画。
</PropertyReference>

## `defaultMarkdownStyles`

默认样式映射。展开它即可扩展而非替换内置样式：

```tsx
import { CopilotMarkdown, defaultMarkdownStyles } from "@copilotkit/react-native/components";

const styles = {
  ...defaultMarkdownStyles,
  h1: { fontSize: 28, fontWeight: "800" },
};

<CopilotMarkdown content="# Hello\nThis is **bold**." style={styles} />;
```

## 用法

```tsx
import { CopilotMarkdown } from "@copilotkit/react-native/components";

<CopilotMarkdown content="**Hello** from CopilotKit!" />;
```
