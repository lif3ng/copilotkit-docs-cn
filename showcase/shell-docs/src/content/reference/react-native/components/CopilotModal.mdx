## 概览

与 [`CopilotChat`](/reference/react-native/components/CopilotChat) 一样，`CopilotModal` 也提供**两个**版本，由导入路径决定：

- **无头版**（`@copilotkit/react-native`）是 `CopilotChat` 的轻量包装器，对齐 web SDK 的 `CopilotModal` API。它只负责智能体接线；弹窗展示由你用 React Native 的 `Modal`（或任意浮层）处理，聊天 UI 则基于 [`useCopilotChatContext`](/reference/react-native/components/CopilotChat#usecopilotchatcontext) 构建。
- **预构建 UI**（`@copilotkit/react-native/components`）是[`@gorhom/bottom-sheet`](https://ui.gorhom.dev/components/bottom-sheet/) 中的现成聊天界面，带吸附点与下滑关闭。参见[预构建 UI](#预构建-ui)。

## 无头 `CopilotModal`

```tsx
import { CopilotModal } from "@copilotkit/react-native";
```

接受所有[无头 `CopilotChat` 属性](/reference/react-native/components/CopilotChat#props)（`agentId`、`agentName`、`threadId`、`onError`、`throttleMs`、`attachments`），另外还有：

<PropertyReference name="children" type="ReactNode">
  你的聊天 UI，渲染在聊天上下文内。消费
  [`useCopilotChatContext`](/reference/react-native/components/CopilotChat#usecopilotchatcontext)
  来读取消息并提交输入。
</PropertyReference>

### 用法

```tsx
import { CopilotModal } from "@copilotkit/react-native";
import { Modal } from "react-native";

function App({ isOpen }: { isOpen: boolean }) {
  return (
    <Modal visible={isOpen} animationType="slide">
      <CopilotModal agentId="default">
        <MyChatUI />
      </CopilotModal>
    </Modal>
  );
}
```

## 预构建 UI

从 `/components` 子路径导入 `CopilotModal` 即可获得底部弹层聊天。可通过 `CopilotModalRef` 命令式控制，或用 `visible` prop 声明式控制。需要 `@gorhom/bottom-sheet`、`react-native-gesture-handler` 与 `react-native-reanimated` 对等依赖。

```tsx
import { CopilotModal, type CopilotModalRef } from "@copilotkit/react-native/components";
```

### 属性

<Callout type="info">
  与预构建 `CopilotChat` 一样，该组件使用 `agentName`（预构建 UI 目前暴露的 prop）选择智能体，而非无头版的 `agentId`。
</Callout>

<PropertyReference name="visible" type="boolean">
  受控可见性：`true` 打开弹层，`false` 关闭。
</PropertyReference>

<PropertyReference name="onDismiss" type="() => void">
  弹层被关闭时调用（点击背景、下滑或 `close()`）。
</PropertyReference>

<PropertyReference name="snapPoints" type="(string | number)[]" default="['50%', '90%']">
  底部弹层的吸附点，原样传递给 `@gorhom/bottom-sheet`。
</PropertyReference>

<PropertyReference name="initialSnapIndex" type="number" default="0">
  打开时所处的吸附点索引。
</PropertyReference>

<PropertyReference name="enableDismissOnClose" type="boolean" default="true">
  关闭弹层时是否触发 `onDismiss`。
</PropertyReference>

<PropertyReference name="backdropOpacity" type="number" default="0.5">
  弹层打开时的背景遮罩不透明度。
</PropertyReference>

<PropertyReference name="agentName" type="string">
  要连接的智能体。原样传递给内部的 `CopilotChat`。
</PropertyReference>

<PropertyReference name="placeholder" type="string">
  输入框占位文本。
</PropertyReference>

<PropertyReference name="initialMessages" type="string[]">
  空状态下显示的建议胶囊按钮。
</PropertyReference>

<PropertyReference name="headerTitle" type="string">
  聊天头部区域显示的标题。
</PropertyReference>

### Ref 句柄

<PropertyReference name="CopilotModalRef" type="{ open(): void; close(): void }">
  通过 `ref` 暴露的命令式句柄，用于以编程方式打开和关闭弹层。
</PropertyReference>

### 用法

```tsx
import { CopilotModal, type CopilotModalRef } from "@copilotkit/react-native/components";
import { useRef } from "react";
import { Button, View } from "react-native";

export function ChatScreen() {
  const modalRef = useRef<CopilotModalRef>(null);

  return (
    <View style={{ flex: 1 }}>
      <Button title="Open chat" onPress={() => modalRef.current?.open()} />
      <CopilotModal
        ref={modalRef}
        agentName="default"
        headerTitle="Assistant"
        snapPoints={["50%", "90%"]}
      />
    </View>
  );
}
```
