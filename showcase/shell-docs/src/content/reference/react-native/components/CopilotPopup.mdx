## 概览

`CopilotPopup` 渲染一个悬浮操作按钮（FAB），点击后在模态覆盖卡片中打开聊天，卡片带有标题栏和可点击关闭的遮罩层。与 [`CopilotSidebar`](/reference/react-native/components/CopilotSidebar) 一样，它的聊天区域包装了一个无头（headless）的 [`CopilotChat`](/reference/react-native/components/CopilotChat)。你可以将聊天 UI 作为 `children` 传入，也可以直接放入来自 `@copilotkit/react-native/components` 的预构建 `CopilotChat` UI。

可以通过 `CopilotPopupHandle` ref 以命令式方式控制它。

## 导入

```tsx
import { CopilotPopup, type CopilotPopupHandle } from "@copilotkit/react-native";
```

## 属性

<PropertyReference name="agentId" type="string" default='"default"'>
  要连接的智能体 ID。会透传给内部的 `CopilotChat`。
</PropertyReference>

<PropertyReference name="agentName" type="string">
  **已弃用**。请改用 `agentId`。
</PropertyReference>

<PropertyReference name="threadId" type="string">
  此聊天会话的线程 ID。
</PropertyReference>

<PropertyReference name="throttleMs" type="number">
  重新渲染的节流间隔（毫秒）。
</PropertyReference>

<PropertyReference name="defaultOpen" type="boolean" default="false">
  弹窗是否以打开状态启动。
</PropertyReference>

<PropertyReference name="height" type="number | string" default='"60%"'>
  弹窗卡片的高度。接受点数（数字）或相对于屏幕高度解析的百分比字符串。
</PropertyReference>

<PropertyReference name="onError" type="(error: Error) => void">
  作用于此弹窗聊天智能体的错误处理回调。
</PropertyReference>

<PropertyReference name="headerTitle" type="string" default='"CopilotKit"'>
  弹窗标题栏中显示的标题。
</PropertyReference>

<PropertyReference name="attachments" type="NativeAttachmentsConfig">
  启用多模态文件附件。会转发给内部的 `CopilotChat`；子组件通过 [`useCopilotChatContext`](/reference/react-native/components/CopilotChat#usecopilotchatcontext) 读取附件状态。
</PropertyReference>

<PropertyReference name="children" type="ReactNode">
  在弹窗卡片内、聊天内容下方渲染的内容。
</PropertyReference>

<PropertyReference name="onOpen" type="() => void">
  弹窗打开时触发的回调。
</PropertyReference>

<PropertyReference name="onClose" type="() => void">
  弹窗关闭时触发的回调。
</PropertyReference>

<PropertyReference name="dismissOnBackdropPress" type="boolean" default="true">
  点击半透明遮罩层时是否关闭弹窗（等同于 Web SDK 的 `clickOutsideToClose`）。
</PropertyReference>

<PropertyReference name="showToggleButton" type="boolean" default="true">
  是否显示用于切换弹窗的悬浮操作按钮。弹窗打开期间该按钮会隐藏。
</PropertyReference>

<PropertyReference name="style" type="ViewStyle">
  应用于弹窗卡片容器的自定义样式。
</PropertyReference>

## Ref 句柄

<PropertyReference name="CopilotPopupHandle" type="{ open(): void; close(): void; toggle(): void }">
  通过 `ref` 暴露的命令式句柄，用于以编程方式打开、关闭和切换弹窗。
</PropertyReference>

## 用法

```tsx
import { CopilotPopup, type CopilotPopupHandle } from "@copilotkit/react-native";
import { CopilotChat } from "@copilotkit/react-native/components";
import { useRef } from "react";

export function ChatScreen() {
  const popupRef = useRef<CopilotPopupHandle>(null);

  return (
    <CopilotPopup ref={popupRef} agentId="default" headerTitle="Chat">
      <CopilotChat agentName="default" showHeader={false} />
    </CopilotPopup>
  );
}
```

## 行为

- **覆盖层**：弹窗以模态卡片形式打开，悬浮在你的内容之上，并带有半透明遮罩层。
- **点击遮罩关闭**：当 `dismissOnBackdropPress` 为 `true` 时，点击遮罩层会关闭弹窗。
- **FAB**：当 `showToggleButton` 为 `true` 时，由悬浮操作按钮打开弹窗，弹窗打开期间该按钮隐藏。
- **高度**：百分比形式的 `height`（例如 `"60%"`）相对于屏幕高度解析；数字则作为点数使用。
