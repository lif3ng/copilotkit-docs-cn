## 概览

`UserMessage` 为用户消息轮次渲染一个右对齐的聊天气泡。内容以纯文本显示（不解析 Markdown），主色背景配白色文字。在无头（headless）的 [`CopilotChat`](/reference/react-native/components/CopilotChat) 之上构建自定义聊天 UI 时非常有用。

## 导入

```tsx
import { UserMessage } from "@copilotkit/react-native/components";
```

## 属性

<PropertyReference name="content" type="string" required>
  要显示的纯文本内容。
</PropertyReference>

<PropertyReference name="timestamp" type="Date">
  可选的时间戳，显示在气泡下方，以 12 小时制格式化。
</PropertyReference>

<PropertyReference name="style" type="ViewStyle">
  可选的外层容器样式覆盖。
</PropertyReference>

## 用法

```tsx
import { UserMessage } from "@copilotkit/react-native/components";

<UserMessage content="What's the weather today?" timestamp={new Date()} />;
```
