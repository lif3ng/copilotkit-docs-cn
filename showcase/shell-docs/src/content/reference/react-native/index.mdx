`@copilotkit/react-native` 将 CopilotKit 带到了 React Native。它提供了一个轻量的 [Provider 组件](/reference/react-native/components/CopilotKitProvider)、一组预构建 UI 组件、专为 React Native 打造的 Hook，以及从 `@copilotkit/react-core` 转发的平台无关 Hook。一切均构建在 [AG-UI](https://docs.ag-ui.com) 智能体协议之上，不依赖任何 DOM、CSS 或 Web 框架。

<Callout type="info">
  包根路径导出的**就是** v2 API。与 Web SDK 在 `/v2` 子路径下暴露 v2 不同，
  React Native 直接从 `@copilotkit/react-native` 导出 v2 接口。
</Callout>

## 安装

```sh
npm install @copilotkit/react-native
```

预构建 UI 组件与原生附件功能依赖若干 peer dependencies，请按需安装你要用到的那些：

```sh
npm install @gorhom/bottom-sheet react-native-gesture-handler react-native-reanimated react-native-streamdown
```

## Polyfills

React Native 的 JS 运行时（Hermes）缺少 CopilotKit 所依赖的若干 Web API（`ReadableStream`、`TextEncoder`、`crypto.getRandomValues`、`DOMException`、`location`）。导入 `@copilotkit/react-native` 时会**自动安装**这些 polyfill，因此无需手动导入。

如果你自带 polyfill，可以在入口文件中、位于任何其他代码之前，只导入需要的部分：

```js title="index.js"
import "@copilotkit/react-native/polyfills/streams";
import "@copilotkit/react-native/polyfills/encoding";
import "@copilotkit/react-native/polyfills/crypto";
import "@copilotkit/react-native/polyfills/dom";
import "@copilotkit/react-native/polyfills/location";
```

## Provider 配置

用 [`CopilotKitProvider`](/reference/react-native/components/CopilotKitProvider) 包裹你的应用（或某个子树），以配置运行时连接：

```tsx
import { CopilotKitProvider } from "@copilotkit/react-native";

export default function App() {
  return (
    <CopilotKitProvider runtimeUrl="https://your-server/api/copilotkit">
      <ChatScreen />
    </CopilotKitProvider>
  );
}
```

## 构建聊天 UI 的两种方式

这个包分为两个层级，你可以自行决定要亲手编写多少 UI：

| 层级 | 导入路径 | 提供的内容 |
|------|--------|--------------|
| **无头（headless）** | `@copilotkit/react-native` | 用于接入智能体并暴露其状态的基础组件。[`CopilotChat`](/reference/react-native/components/CopilotChat) 与 [`CopilotModal`](/reference/react-native/components/CopilotModal) 不渲染任何 UI，界面需由你用 React Native 视图自行搭建。 |
| **预构建 UI** | `@copilotkit/react-native/components` | 开箱即用的聊天 UI：全屏的 [`CopilotChat`](/reference/react-native/components/CopilotChat#prebuilt-ui)、底部弹层的 [`CopilotModal`](/reference/react-native/components/CopilotModal#prebuilt-ui)、[`CopilotMarkdown`](/reference/react-native/components/CopilotMarkdown)，以及[消息气泡](/reference/react-native/components/AssistantMessage)。 |

包根路径还导出两个预构建外壳组件：[`CopilotSidebar`](/reference/react-native/components/CopilotSidebar)（滑入式抽屉）和 [`CopilotPopup`](/reference/react-native/components/CopilotPopup)（浮动操作按钮 + 遮罩层）。

<Callout type="info">
  `CopilotChat` 与 `CopilotModal` 在**两个**层级中都存在，但 props 不同。
  包根路径导出的是无头版本，`/components` 导出的是预构建 UI。
  每个组件页面会同时记录两者，并通过导入路径加以区分。
</Callout>
