要将 FastAPI 服务器连接到 Copilot Cloud，我们借助了一个名为“远程端点（Remote Endpoints）”的概念，它允许 CopilotKit 运行时连接到各种后端。

首先，<LinkToCopilotCloud asButton={false}>前往 Copilot Cloud</LinkToCopilotCloud>。

<Callout title="不想使用隧道？">
  可以直接跳过隧道配置，改用你托管的 FastAPI 服务器地址。
</Callout>

```sh
npx copilotkit@latest dev --port <port_number>
```
