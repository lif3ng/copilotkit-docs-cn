## 哪个名称标识智能体

你在前端寻址智能体时所用的名称，必须等于**运行时 `agents` 映射的某个键**。该键是前端唯一可以请求的名称。智能体自身的 `name`、`id` 或类名从不用于路由，两者可以各不相同。

```ts title="app/api/copilotkit/[[...slug]]/route.ts"
const runtime = new CopilotRuntime({
  agents: {
    // `my_agent` is the key — the one string the frontend may ask for.
    my_agent: new HttpAgent({ url: "http://localhost:8000/" }),
  },
});
```

<FrontendOnly frontend="react">
```tsx title="app/providers.tsx"
<CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
  <YourApp />
</CopilotKit>
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```html title="src/app/app.component.html"
<copilot-chat agentId="my_agent" />
```
</FrontendOnly>

大多数集成会像上文那样把这个键直接写在运行时路由里，绑定关系在一个文件中一目了然。有些集成则通过推导得到它，规则在那时就不再直观：

- **Mastra** —— `MastraAgent.getRemoteAgents` 与 `getLocalAgents` 都基于 `listAgents()` 构建映射，其键取自 `new Mastra({ agents: { ... } })` 中的**记录键**，而非智能体的 `id`。若 `new Agent({ name: "My Agent" })` 以 `myAgent` 导出并注册为 `agents: { myAgent }`，运行时键就是 `myAgent`。
- **LangGraph** —— `graphId` 是一条*独立*的绑定，从运行时指向你部署的 `langgraph.json` 中的某个键。它不必等于运行时 agents 映射的键，也不是前端请求所用的名称。起步模板恰好对两者都使用了 `sample_agent`。

<Callout type="warn" title="智能体声明的名称不是它的路由键">
  请求一个运行时未注册的名称将解析不到任何智能体，前端会抛出 `CopilotKitAgentDiscoveryError` —— 参见[智能体发现失败](/troubleshooting/error-reference)。错误消息会列出运行时实际返回的键，这是查看真实名称最快的方式。
</Callout>

要直接读取已注册的键，请访问 `GET {runtimeUrl}/info`。它会返回运行时对外公布的智能体，名称与前端必须使用的完全一致。
