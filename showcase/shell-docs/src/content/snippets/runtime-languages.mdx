## 运行时语言

**TypeScript 是默认且功能最全面的运行时，也是唯一无需 CopilotKit Intelligence 即可运行的运行时**。你可以将它用于开源部署，或在需要 Intelligence 的服务时将其接入 Intelligence。

Python、Go、Ruby 以及 C#/.NET 运行时需要一个 Intelligence 项目和服务端 API 密钥。它们既适用于[云端托管](/intelligence/managed-intelligence-platform)的 Intelligence，也适用于[自托管](/intelligence/self-hosting)的 Intelligence；它们不提供内存运行器或 SQLite 运行器。

| 语言 | 宿主 | 不使用 Intelligence |
| --- | --- | --- |
| TypeScript | Next.js、Express、Hono 及其他 JavaScript 服务器 | 是 |
| Python | ASGI，需 Python 3.11+ | 否 |
| Go | `net/http`，需 Go 1.22+ | 否 |
| Ruby | Rack（含 Rails 与 Sinatra），需 Ruby 2.7+ | 否 |
| C#/.NET | ASP.NET Core，需 .NET 8 | 否 |

你的运行时语言不必与智能体语言一致。每个运行时都可以连接远程 AG-UI 智能体。例如，Python 智能体可以留在 TypeScript 运行时之后。

各语言的安装、身份验证与服务器设置请参阅 [Intelligence 快速开始](/intelligence/quickstart#connect-your-runtime)。共享的 Intelligence 能力并不意味着各运行时的 API 完全一致：诸如 `BuiltInAgent`、自定义 `AgentRunner` 类、音频转写以及开放生成式 UI（Open Generative UI）等 TypeScript 特性，并非在每种实现中都可用。
