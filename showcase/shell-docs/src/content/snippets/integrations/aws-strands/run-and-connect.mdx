在继续之前，你需要先运行你的智能体并将其连接到 CopilotKit。

如果尚未将 CopilotKit 与你的智能体连接，请从以下选项中选择一个：

<Accordions>
  <Accordion title="我已有智能体">
    你可以按照[快速开始](/aws-strands/quickstart)指南中的说明操作。
  </Accordion>
  <Accordion title="我想从零开始">
    运行以下命令，克隆一个预配置了智能体的全新项目：

    <Tabs groupId="language_strands_agent" items={['Python', 'TypeScript']} persist>
      <Tab value="Python">
        ```bash
        npx copilotkit create --framework aws-strands-py
        ```
      </Tab>
      <Tab value="TypeScript">
        ```bash
        npx copilotkit create --framework aws-strands-ts
        ```
      </Tab>
    </Tabs>

  </Accordion>
</Accordions>
