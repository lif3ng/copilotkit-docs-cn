## CopilotKit + LangSmith 平台

[LangSmith Deployment](https://docs.langchain.com/langsmith/deployment) 为你的 LangGraph 与
Google ADK 智能体提供托管运行时（默认为 serverless）——负责扩缩容、持久化以及
LangGraph Server API。CopilotKit 则为这些智能体提供一个可用于生产环境的前端。

## 工作原理

两者通过 **CopilotKit Runtime** 相连——这是一个轻量的服务端层，位于你的浏览器与 LangSmith
部署之间。它与你配合任何 CopilotKit 驱动的智能体时使用的运行时是同一个——只是必须在服务端
运行，这样你的 `LANGSMITH_API_KEY` 才不会暴露到浏览器。

```
Browser → CopilotKit Runtime → LangSmith deployment → your agent
```

LangSmith 只托管智能体本身，并不提供前端托管服务。你可以把 CopilotKit 前端与运行时部署在
现有应用的托管位置（Vercel、自己的 Node 服务器等），并把运行时指向 LangSmith 部署的 URL。

## 你将获得

- **聊天 UI**——预构建的聊天界面，或使用无头 hooks 自行搭建
- **共享状态**——智能体状态与你的 React UI 之间的双向同步
- **生成式 UI**——通过工具调用实时渲染自定义组件
- **人机协同（human-in-the-loop）**——让用户审阅、批准或重定向智能体的操作
- **托管持久化**——线程历史与检查点都保存在 LangSmith 部署中

## 快速开始

<Callout type="info" title="LangSmith 官方参考">
  这些步骤在本文档内复现了 LangSmith 的部署流程，你无需离开本页即可完成。关于权威参考——
  定价、部署类型与自托管——请查阅
  [LangSmith 部署文档](https://docs.langchain.com/langsmith/deployment)。
</Callout>

<Callout type="info" title="前置条件">
  你需要一个 **Plus 套餐或更高**的 [LangSmith 账户](https://smith.langchain.com)，以及一个
  LangSmith API 密钥（`lsv2_...`）。部署使用 LangGraph CLI；Docker 为可选项（仅本地容器构建时
  才需要）。**Google ADK** 还需要 **Python 3.11+**、`deployments-wrap-sdk[google-adk]` 包；
  若使用 Gemini 模型，还需要 **Google AI API 密钥**。
</Callout>

<Callout type="info" title="部署模式">
  本指南通过 CLI 使用 **LangSmith Cloud**——默认为 serverless，也可用 `--deployment-type
  dedicated` 创建专用部署。LangSmith 还支持自托管控制平面、混合与独立服务器等模式；请参阅
  [部署概览](https://docs.langchain.com/langsmith/deployment)来选择。无论部署到哪种模式，
  下文的 CopilotKit 接线方式都相同。
</Callout>

      <Step>
        ### 安装 LangGraph CLI

        该 CLI 会搭建一个可部署的项目脚手架，并将其推送到 LangSmith：

        ```bash
        uv tool install langgraph-cli
        ```
      </Step>

      <Step>
        ### 创建可部署的应用

        LangSmith 部署可以是任何通过 `langgraph.json` 导出图的项目。

        <Tabs groupId="langsmith-agent-framework" items={['LangGraph', 'Google ADK']}>
          <Tab value="LangGraph">
            使用官方模板搭建新项目：

            ```bash
            langgraph new ./my-agent --template new-langgraph-project-python
            ```

            模板自带的 `langgraph.json` 已经导出了一个图：

            ```json title="langgraph.json"
            {
              "$schema": "https://langgra.ph/schema.json",
              "dependencies": ["."],
              "graphs": {
                "agent": "./src/agent/graph.py:graph"
              },
              "env": ".env"
            }
            ```

            `graphs` 键（此处为 `agent`）就是稍后你要让 CopilotKit 指向的**图 ID**。
          </Tab>

          <Tab value="Google ADK">
            ADK 智能体无法直接部署到 LangSmith——你需要包装 ADK 的 `Runner`，使其导出一个与
            LangGraph 兼容的图，然后像部署 LangGraph 应用一样部署它。

            安装包装器 SDK（发布名是 `deployments-wrap-sdk`，导入名是 `saf_sdk`）：

            ```bash
            pip install "deployments-wrap-sdk[google-adk]"
            ```

            用 `wrap()` 和 `LangsmithSessionService` 包装你的 ADK `Runner`，然后将结果导出为
            模块级的 `agent`：

            ```python title="agent.py"
            from google.adk.agents import Agent
            from google.adk.runners import Runner
            from saf_sdk.adk import LangsmithSessionService, wrap

            agent = wrap(
                Runner(
                    agent=Agent(
                        name="my_agent",
                        model="gemini-3.8-flash",
                        instruction="You are a helpful assistant.",
                    ),
                    app_name="my_adk_agent",
                    session_service=LangsmithSessionService(),
                )
            )
            ```

            <Callout type="warn">
              `Runner.session_service` **必须**是 `LangsmithSessionService`。ADK 的其他会话服务
              （`InMemorySessionService`、`DatabaseSessionService`、
              `VertexAiSessionService`）都会被拒绝——会话状态保存在 LangGraph 检查点中。
            </Callout>

            让 `langgraph.json` 指向导出的符号：

            ```json title="langgraph.json"
            {
              "$schema": "https://langgra.ph/schema.json",
              "dependencies": ["."],
              "graphs": {
                "my_agent": "./agent.py:agent"
              },
              "env": ".env"
            }
            ```

            `graphs` 键（此处为 `my_agent`）就是稍后你要让 CopilotKit 指向的**图 ID**。
            完整流程请参阅[部署 Google ADK 智能体](https://docs.langchain.com/langsmith/deploy-google-adk)
            指南。

            <Callout type="warn" title="ADK 包装器的限制">
              包装器将 ADK 适配到 LangGraph Server 上，因此部分 ADK 与 CopilotKit 特性无法沿用。
              依据 LangChain 的
              [ADK 指南](https://docs.langchain.com/langsmith/deploy-google-adk)：

              - **不支持多模态输入**——只把 `messages[-1].content` 作为单个文本部分转发；传入的
                图片、文件或音频会被丢弃。
              - **仅发送最后一条消息**——每轮只把 `messages` 中的最后一项发送给 ADK 智能体。
              - **不支持实时 / 音频 / 语音**——不使用 ADK 的 `run_live()` 双向流式传输。
              - **仅支持文本输出**——非文本输出部分（图片、音频、文件）不会被呈现。
              - **没有中间事件**——工具调用、工具结果与子智能体回合不会作为独立消息发出。
              - **必须使用 `LangsmithSessionService`**——其他 ADK 会话服务都会被拒绝。
              - **不支持 LangGraph 中断**——`interrupt` / `Command(resume=...)` 未被暴露，因此
                依赖原生中断的人机协同流程无法在包装后的 ADK 智能体上工作。
            </Callout>
          </Tab>
        </Tabs>
      </Step>

        ### 添加你的 API 密钥

        把你的 LangSmith API 密钥添加到项目的 `.env` 中。部署命令会自动读取它：

        ```plaintext title=".env"
        LANGSMITH_API_KEY=lsv2_...
        ```
      </Step>

      <Step>
        ### 部署

        <Callout type="info" title="先在本地验证">
          部署前，先在项目根目录运行 `langgraph dev`，在本地启动该图并确认它能正常启动。
          这样可以比远程构建以更清晰的反馈发现导入错误、图导出问题，或（对 ADK 而言）缺失
          `LangsmithSessionService`、模型凭据等情况。
        </Callout>

        在项目根目录下：

        ```bash
        langgraph deploy --name my-agent
        ```

        默认会创建一个 **serverless** 部署。常用参数与后续操作：

        - `--deployment-type dedicated`——开通一个专用（非 serverless）部署
        - `--name <name>`——设置部署名称（用同名重新运行 `langgraph deploy` 会**就地更新现有部署**）
        - `langgraph deploy list`——列出你的部署
        - `langgraph deploy logs`——跟踪运行时日志
        - `langgraph deploy delete <id>`——删除一个部署
      </Step>

      <Step>
        ### 获取部署的 API URL

        <Callout type="info" title="在哪里找到 URL">
          在 [LangSmith UI](https://smith.langchain.com) 中，打开侧边栏的 **Deployments**，
          选择你的部署，然后从详情视图中复制 **API URL**。其形如
          `https://<deployment-id>.<region>.langgraph.app`。
        </Callout>
      </Step>

      <Step>
        ### 安装 CopilotKit

        在你的前端应用中：

        ```npm
        npm install @copilotkit/react-core @copilotkit/runtime
        ```
      </Step>

      <Step>
        ### 配置 CopilotKit Runtime

        CopilotKit Runtime 是连接你的前端与 LangSmith 部署的服务端层。创建一个 API 路由：

        ```typescript title="app/api/copilotkit/[[...slug]]/route.ts" doctest="component"
        import {
          CopilotRuntime,
          createCopilotRuntimeHandler,
          InMemoryAgentRunner,
        } from "@copilotkit/runtime/v2";
        import { LangGraphAgent } from "@copilotkit/runtime/langgraph";

        const runtime = new CopilotRuntime({
          agents: {
            my_agent: new LangGraphAgent({
              deploymentUrl: process.env.LANGGRAPH_DEPLOYMENT_URL!, // your LangSmith API URL
              graphId: "agent", // must match a key in your langgraph.json "graphs"
              langsmithApiKey: process.env.LANGSMITH_API_KEY!,
            }),
          },
          runner: new InMemoryAgentRunner(),
        });

        const handler = createCopilotRuntimeHandler({
          runtime,
          basePath: "/api/copilotkit",
        });

        export const GET = handler;
        export const POST = handler;
        ```

        <Callout type="info" title="graphId 必须与 langgraph.json 匹配">
          `graphId` 就是 `langgraph.json` 中 `graphs` 对象里的键——LangGraph 模板中为 `agent`，
          或你为 ADK 图取的任意名称（如 `my_agent`）。如果不匹配，运行时将找不到你的图。
        </Callout>
      </Step>

      <Step>
        ### 添加 CopilotKit Provider

        ```tsx title="app/providers.tsx"
        "use client";

        import { CopilotKit } from "@copilotkit/react-core/v2";

        export function Providers({ children }: { children: React.ReactNode }) {
          return (
            <CopilotKit runtimeUrl="/api/copilotkit" agent="my_agent" useSingleEndpoint={false}>
              {children}
            </CopilotKit>
          );
        }
        ```

        `app/layout.tsx` 是服务端组件，无法直接导入该 provider，因此它改为渲染你的客户端文件：

        ```tsx title="app/layout.tsx"
        import { Providers } from "./providers";
        import "@copilotkit/react-core/v2/styles.css";

        export default function RootLayout({ children }: { children: React.ReactNode }) {
          return (
            <html lang="en">
              <body>
                <Providers>
                  {children}
                </Providers>
              </body>
            </html>
          );
        }
        ```
      </Step>

      <Step>
        ### 🎉 运行应用

        让你的应用指向该部署并启动。创建 `.env.local`：

        ```bash title=".env.local"
        LANGGRAPH_DEPLOYMENT_URL=https://<deployment-id>.<region>.langgraph.app
        LANGSMITH_API_KEY=lsv2_...
        ```

        然后：

        ```bash
        npm run dev
        ```

        在任意页面添加一个 `<CopilotSidebar />` 并打开 `localhost:3000`。前端运行在你托管它的
        地方，而智能体留在 LangSmith 上——`/api/copilotkit` 路由会使用你的 API 密钥把每次调用
        转发到你的部署。
      </Step>
    </TailoredContentOption>

## 故障排查

<Accordions>
  <Accordion title="运行时找不到我的图 / 调用时返回 404">
    你的 `graphId` 必须与部署所用 `langgraph.json` 中 `graphs` 对象的某个键完全一致。
    LangGraph 模板将其命名为 `agent`；ADK 应用则使用你设置的任意键（如 `my_agent`）。
    不确定时，可在 LangSmith UI 中查看该部署的配置。
  </Accordion>
  <Accordion title="部署返回 401 / 身份验证错误">
    确认 `LANGSMITH_API_KEY` 设置在**服务端**（即 CopilotKit Runtime 运行之处）而非浏览器中，
    并且该密钥与部署属于同一个 LangSmith 工作区。密钥必须以 `lsv2_` 开头。
  </Accordion>
  <Accordion title="langgraph deploy 失败或卡住">
    确保你的 LangSmith 账户是 **Plus 套餐或更高**，且 `.env` 中存在 `LANGSMITH_API_KEY`。
    本地容器构建需要 Docker（守护进程须在运行）——在 Apple Silicon 上还需要 Docker Buildx。
  </Accordion>
  <Accordion title="我的 ADK 智能体无法部署">
    ADK 智能体必须用 `saf_sdk.adk` 中的 `wrap()` 包装，并使用 `LangsmithSessionService`。
    包装后的对象必须导出为模块级变量，供 `langgraph.json` 指向（如 `./agent.py:agent`）。
    请参阅[部署 Google ADK 智能体](https://docs.langchain.com/langsmith/deploy-google-adk)
    指南。
  </Accordion>
</Accordions>
