将 `CopilotKitMiddleware()` 传给 `create_deep_agent`——正是这一步让前端工具对你的智能体可用：

<Tabs groupId="language_langgraph_agent" items={['Python']} default="Python" persist>
    <Tab value="Python">
        ```python title="agent.py"
        from deepagents import create_deep_agent
        from copilotkit import CopilotKitMiddleware # [!code highlight]

        agent = create_deep_agent(
            model="openai:gpt-5.4",
            tools=[],  # Backend tools go here
            middleware=[CopilotKitMiddleware()], # [!code highlight]
            system_prompt="You are a helpful assistant.",
        )
        ```
    </Tab>
</Tabs>

`CopilotKitMiddleware` 会在运行时自动把前端工具注入智能体的工具列表。
