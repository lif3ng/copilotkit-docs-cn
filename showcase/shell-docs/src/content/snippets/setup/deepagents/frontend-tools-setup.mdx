<Steps>
  <Step>
    ### 将 CopilotKit 中间件接入你的智能体

    Deep Agents 会编译为 LangGraph 图，而 `CopilotKitMiddleware` 正是其中的桥梁。它会从请求中读取转发来的工具，并将其合并进模型所见的工具列表，因此通过 `useComponent` 注册的组件只有在中间件存在时才会被模型感知到。

    ```python title="agent.py"
    from deepagents import create_deep_agent
    from copilotkit import CopilotKitMiddleware

    agent = create_deep_agent(
        model="openai:gpt-5.4",
        tools=[],  # Backend tools go here
        middleware=[CopilotKitMiddleware()],
        system_prompt=SYSTEM_PROMPT,
    )
    ```

    没有中间件时，运行仍会照常完成，但组件永远不会渲染，因为模型从未被告知该工具的存在。

  </Step>
  <Step>
    ### 告诉模型何时调用它

    转发的工具会在每次运行时送达，但如果模型没有得到关于它的任何指示，就会用一段文字作答而从不调用它。请在 `system_prompt` 中写明该工具的名称及其用途。

    ```python title="agent.py"
    SYSTEM_PROMPT = """
    You are a data visualization assistant.

    When the user asks for a chart, call `render_bar_chart` with a concise
    title and a `data` array of `{label, value}` items.

    Keep chat responses brief and let the chart do the talking.
    """
    ```

  </Step>
</Steps>
