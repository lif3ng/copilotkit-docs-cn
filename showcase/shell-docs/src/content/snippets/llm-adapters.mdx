LLM 适配器（LLM Adapters）负责与 LLM 执行请求，并将请求/响应的格式标准化为 Copilot Runtime 能够理解的形式。

目前，我们原生支持以下 LLM 适配器：

- [OpenAI 适配器（也支持 Azure）](/reference/v1/classes/llm-adapters/OpenAIAdapter)
- [OpenAI Assistant 适配器](/reference/v1/classes/llm-adapters/OpenAIAssistantAdapter)
- [LangChain 适配器](/reference/v1/classes/llm-adapters/LangChainAdapter)
- [Groq 适配器](/reference/v1/classes/llm-adapters/GroqAdapter)
- [Google Generative AI 适配器](/reference/v1/classes/llm-adapters/GoogleGenerativeAIAdapter)
- [Anthropic 适配器](/reference/v1/classes/llm-adapters/AnthropicAdapter)

<Callout type="info">
  你可以使用 [LangChain
  适配器](/reference/v1/classes/llm-adapters/LangChainAdapter)来接入我们尚未原生支持的任意 LLM 提供方！
</Callout>

<Callout type="info">
  从零开始编写自己的 LLM 适配器并不难——不妨参考现有适配器寻找灵感。当然，我们也非常欢迎你贡献代码！⭐️
</Callout>
