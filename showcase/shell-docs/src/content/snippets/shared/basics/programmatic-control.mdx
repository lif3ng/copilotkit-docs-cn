## 概览

`useAgent` Hook 让你可以从任意 React 组件直接访问智能体。它提供对智能体状态、消息与执行状态的实时访问，并允许你订阅自定义事件。

借助它，你可以构建自定义智能体仪表盘、监控工具，以及能够响应智能体行为的交互特性。

## 以编程方式运行智能体

使用 `copilotkit.runAgent()` 即可从任意组件触发智能体——无需聊天 UI。这正是 CopilotKit 内置的 `<CopilotChat />` 内部所使用的方法。

```tsx title="page.tsx"
import { useAgent } from "@copilotkit/react-core/v2";
import { useCopilotKit } from "@copilotkit/react-core/v2";
import { randomUUID } from "@copilotkit/shared";

export function AgentTrigger() {
  const { agent } = useAgent();
  // [!code highlight:1]
  const { copilotkit } = useCopilotKit();

  const handleRun = async () => {
    // Add a user message to the agent's conversation
    agent.addMessage({
      id: randomUUID(),
      role: "user",
      content: "Summarize the latest sales data",
    });

    // [!code highlight:2]
    // Run the agent — handles tool execution, follow-ups, and streaming
    await copilotkit.runAgent({ agent });
  };

  return <button onClick={handleRun}>Run Agent</button>;
}
```

### `copilotkit.runAgent()` 与 `agent.runAgent()` 的区别

两种方法都能触发智能体，但它们作用于不同的层级：

- **`copilotkit.runAgent({ agent })`**——推荐方式。它会编排智能体的完整生命周期：执行前端工具、在工具请求时处理后续运行，并通过订阅者系统管理错误。
- **`agent.runAgent()`**——智能体实例上的底层方法。它会把请求发送到运行时，但**不会**执行前端工具，也不会处理后续运行。仅当你需要对智能体的执行过程进行直接控制时才使用它。若要从一次中断中恢复，标准 AG-UI 中断请使用 `copilotkit.runAgent({ agent, resume })`，旧版 `on_interrupt` 自定义事件请使用 `copilotkit.runAgent({ agent, forwardedProps: { command: { resume, interruptEvent } } })`，这样订阅者生命周期仍会包裹恢复后的这次运行。

### 停止运行

你可以使用 `copilotkit.stopAgent()` 停止正在运行的智能体：

```tsx title="page.tsx"
const handleStop = () => {
  copilotkit.stopAgent({ agent });
};
```
