## 这是什么？

每个 CopilotKit 聊天组件都由可组合的**插槽**（slot）构成——即可以逐个覆盖的具名子组件。插槽系统提供三个层级的自定义能力，而无需重建整个 UI：

1. **Tailwind 类**——传入字符串以添加/覆盖 CSS 类
2. **Props 覆盖**——传入对象以覆盖默认组件上的特定 props
3. **自定义组件**——传入你自己的 React 组件以完全替换某个插槽

插槽是递归的——你可以在任意深度逐层深入嵌套的子组件。

## Tailwind 类

这是自定义插槽最简单的方式。传入一个 Tailwind 类字符串，它将与默认组件的类合并。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat
      // [!code highlight:2]
      messageView="bg-gray-50 dark:bg-gray-900 p-4"
      input="border-2 border-blue-400 rounded-xl"
    />
  );
}
```

## Props 覆盖

传入一个对象来覆盖默认组件上的特定 props。这适用于添加 `className`、事件处理器、data 属性，或默认组件接受的任何其他 prop。

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:4]
  messageView={{
    className: "my-custom-messages",
    "data-testid": "message-view",
  }}
  input={{ autoFocus: true }}
/>
```

## 自定义组件

若要完全掌控，可以传入你自己的 React 组件。它会接收与默认组件相同的所有 props。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

// [!code highlight:8]
const CustomMessageView = ({ messages, isRunning }) => (
  <div className="space-y-4 p-6">
    {messages?.map((msg) => (
      <div
        key={msg.id}
        className={msg.role === "user" ? "text-right" : "text-left"}
      >
        {msg.content}
      </div>
    ))}
    {isRunning && <div className="animate-pulse">Thinking...</div>}
  </div>
);

export function Chat() {
  return (
    // [!code highlight:1]
    <CopilotChat messageView={CustomMessageView} />
  );
}
```

## 嵌套插槽（逐层深入）

插槽是递归的。通过嵌套对象，你可以在任意深度自定义子组件。

### 深入两层

在消息视图内覆盖助手消息的工具栏：

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:7]
  messageView={{
    assistantMessage: {
      toolbar: CustomToolbar,
      copyButton: CustomCopyButton,
    },
    userMessage: CustomUserMessage,
  }}
/>
```

### 深入三层

覆盖助手消息工具栏内的某个具体按钮：

```tsx title="page.tsx"
<CopilotChat
  messageView={{
    // [!code highlight:5]
    assistantMessage: {
      copyButton: ({ onClick }) => <button onClick={onClick}>Copy</button>,
    },
  }}
/>
```

### input 子插槽

```tsx title="page.tsx"
<CopilotChat
  input={{
    // [!code highlight:2]
    textArea: CustomTextArea,
    sendButton: CustomSendButton,
  }}
/>
```

### scrollView 子插槽

```tsx title="page.tsx"
<CopilotChat
  scrollView={{
    // [!code highlight:2]
    feather: CustomFeather,
    scrollToBottomButton: CustomScrollButton,
  }}
/>
```

### suggestionView 子插槽

```tsx title="page.tsx"
<CopilotChat
  suggestionView={{
    // [!code highlight:2]
    suggestion: CustomSuggestionPill,
    container: CustomSuggestionContainer,
  }}
/>
```

## children 渲染函数

若要完全掌控布局，可以使用 `children` 渲染函数模式。它会为你提供预构建的插槽元素，你可以随意编排它们。

```tsx title="page.tsx"
import { CopilotChat } from "@copilotkit/react-core/v2";

export function Chat() {
  return (
    <CopilotChat>
      {/* [!code highlight:8] */}
      {({ messageView, input, scrollView, suggestionView }) => (
        <div className="flex flex-col h-full">
          <header className="p-4 border-b font-semibold">My Agent</header>
          {scrollView}
          <div className="border-t p-4">{input}</div>
        </div>
      )}
    </CopilotChat>
  );
}
```

## 重塑消息列表

插槽改变的是每条消息**如何**渲染。要改变渲染的_哪些_消息——隐藏某些消息、替换它们或重新排序——可以向消息视图传入 `transformMessages`。它接收整个列表，并返回要渲染的列表。

```tsx title="page.tsx"
import { useCallback } from "react";
import { CopilotChat, type Message } from "@copilotkit/react-core/v2";

export function Chat() {
  // [!code highlight:4]
  const transformMessages = useCallback(
    (messages: Message[]) => messages.filter((m) => m.role !== "tool"),
    [],
  );

  return <CopilotChat messageView={{ transformMessages }} />;
}
```

需要了解的几点：

- **长线程保持虚拟化**。一旦线程超过 50 条消息，聊天组件就只会挂载出现在屏幕上的行。它按 `transformMessages` 返回的消息计数，因此被隐藏的消息不占用任何行。
- **工具卡片保留其结果**。工具调用的渲染器会在完整列表中查找结果，因此如上例那样隐藏工具结果消息，并不会使展示它们的卡片变空。
- **保持 id 唯一且稳定**。每条消息的 id 至多返回一次。你自己构建的消息（例如替代表若干条消息的那条）需要有自己的 id，且在线程流式传输期间该 id 必须保持不变。可以从某个固定来源派生它，比如它所替换的第一条消息的 id。聊天组件会用你返回的最后一条消息来判断哪条消息仍在流式输出。
- **传入稳定的函数**。只要消息或函数发生变化，转换就会重新执行。内联函数也能工作，但会在每次渲染时重新执行。

### 将多条消息归组为一行

要将多条消息一起渲染——比如把一连串工具调用折叠为一个块——传入 `groupMessages`。它接收消息列表（若两者都用，则在 `transformMessages` 之后）并返回若干行：`messageRow(message)` 表示一条消息独占一行，`messageGroup({ key, messages, wrapper })` 表示多条消息一起渲染在你的 `wrapper` 内。

```tsx title="page.tsx"
import { useCallback } from "react";
import {
  CopilotChat,
  messageGroup,
  messageRow,
  type Message,
  type MessageGroupWrapperProps,
  type MessageRow,
} from "@copilotkit/react-core/v2";

// Define wrappers at module level. One created inside groupMessages is a new
// component on every call, so React would remount it each time.
function ToolActivity({
  messages,
  children,
  state,
  setState,
}: MessageGroupWrapperProps<boolean>) {
  const open = state ?? false;
  return (
    <div className="rounded-lg border">
      <button onClick={() => setState(!open)}>
        {messages.length} tool steps {open ? "▾" : "▸"}
      </button>
      {open && children}
    </div>
  );
}

// An assistant message that also carries text stays on its own row, so the
// text (or a card waiting on the user) is never folded into a closed group.
const isToolStep = (m: Message) =>
  m.role === "tool" ||
  (m.role === "assistant" && !!m.toolCalls?.length && !m.content);

export function Chat() {
  // [!code highlight:18]
  const groupMessages = useCallback((messages: Message[]): MessageRow[] => {
    const rows: MessageRow[] = [];
    let run: Message[] = [];
    const flush = () => {
      if (run.length > 0) {
        rows.push(
          messageGroup({ key: run[0].id, messages: run, wrapper: ToolActivity }),
        );
      }
      run = [];
    };
    for (const message of messages) {
      if (isToolStep(message)) run.push(message);
      else {
        flush();
        rows.push(messageRow(message));
      }
    }
    flush();
    return rows;
  }, []);

  return <CopilotChat messageView={{ groupMessages }} />;
}
```

- **一组即一行**。虚拟化会把它作为整体进行窗口化与测量，展开它也只是该行变高而已。50 条消息的阈值仍按消息计数，因此折叠成少数几组的长线程依然保持虚拟化。
- **包装器的状态比行更持久**。聊天组件会以组的 `key` 为键保存 `state` 与 `setState`，因此用户展开过的块在滚回来时仍是展开状态。当 key 不再出现时这些状态会被丢弃，线程变化时会被清空。请用组内第一条消息的 id 作为组的 key：如果后端在流式传输中途重命名该消息（一些 LangChain 提供方会把临时的 `lc_run--…` id 换成最终 id），聊天组件会像处理单条消息一样沿用该组，使其既不重新挂载也不丢失状态。任何其他 key 在线程流式传输期间也必须保持不变。
- **`children` 是组内消息的默认渲染结果**。你可以包裹它、隐藏它，或自行用 `messages` 渲染这些消息。
- **每条消息至多归入一行**。在开发环境下，若某条消息被渲染两次或两个组共用同一个 key，聊天组件会发出警告。

如果你向消息视图传入 `children` 渲染函数来亲自排布渲染后的消息，虚拟化将关闭，且每条消息都会被挂载。列表层面的改动请优先使用 `transformMessages` 与 `groupMessages`；在开发环境下，若正是 `children` 导致虚拟化关闭，聊天组件会发出警告。

## 标签文本

通过 `labels` prop 自定义 UI 中的任意文本字符串。它不使用插槽系统——而是 `CopilotChat`、`CopilotSidebar` 与 `CopilotPopup` 上一个独立的便利 prop。

```tsx title="page.tsx"
<CopilotChat
  // [!code highlight:5]
  labels={{
    chatInputPlaceholder: "Ask your agent anything...",
    welcomeMessageText: "How can I help you today?",
    chatDisclaimerText: "AI responses may be inaccurate.",
  }}
/>
```

## 可用插槽

### `CopilotChat` / `CopilotSidebar` / `CopilotPopup`

这些是所有聊天组件上都可用的根级插槽 prop：

| 插槽             | 说明                                   |
| ---------------- | -------------------------------------- |
| `messageView`    | 消息列表容器。                         |
| `scrollView`     | 带自动滚动行为的滚动容器。             |
| `input`          | 文本输入区，含发送/语音转写控件。      |
| `suggestionView` | 消息下方显示的建议按钮。               |
| `welcomeScreen`  | 初始空状态屏幕（传 `false` 可禁用）。  |

`CopilotSidebar` 与 `CopilotPopup` 还包括：

| 插槽           | 说明                 |
| -------------- | -------------------- |
| `header`       | 模态框顶栏。         |
| `toggleButton` | 打开/关闭切换按钮。  |

### `messageView` 子插槽

可通过 `messageView={{ ... }}` 使用：

| 插槽               | 说明                                                    |
| ------------------ | ------------------------------------------------------- |
| `assistantMessage` | 渲染助手回复。拥有自己的子插槽（见下文）。              |
| `userMessage`      | 渲染用户消息。拥有自己的子插槽（见下文）。              |
| `reasoningMessage` | 渲染模型推理/思考步骤。拥有自己的子插槽（见下文）。     |
| `cursor`           | 智能体响应期间显示的流式光标指示器。                    |
| `workSummary`      | 当 `toolCallDisplay` 为 `"turn"` 时显示的“正在处理… / 用时 9 秒”文本行。 |

### `assistantMessage` 子插槽

可通过 `messageView={{ assistantMessage: { ... } }}` 使用：

| 插槽               | 说明                                                       |
| ------------------ | ---------------------------------------------------------- |
| `markdownRenderer` | Markdown 渲染组件。参见 [Markdown 渲染](/custom-look-and-feel/markdown)。 |
| `toolbar`          | 消息下方的操作工具栏。                                     |
| `copyButton`       | 复制消息按钮。                                             |
| `thumbsUpButton`   | 点赞反馈按钮。                                             |
| `thumbsDownButton` | 点踩反馈按钮。                                             |
| `readAloudButton`  | 朗读按钮。                                                 |
| `regenerateButton` | 重新生成回复按钮。                                         |
| `toolCallsView`    | 工具调用可视化。拥有自己的子插槽（见下文）。               |

### `toolCallsView` 子插槽

可通过 `messageView={{ assistantMessage: { toolCallsView: { ... } } }}` 使用：

| 插槽    | 说明                                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `group` | 智能体连续进行的工具调用，折叠为一条摘要（grouped、line 与 stacked 显示形态）。参见 [`CopilotChatToolCallGroup`](/reference/components/CopilotChatToolCallGroup)。 |

### `userMessage` 子插槽

可通过 `messageView={{ userMessage: { ... } }}` 使用：

| 插槽               | 说明                                             |
| ------------------ | ------------------------------------------------ |
| `messageRenderer`  | 用户消息的文本渲染组件。                         |
| `toolbar`          | 悬停时显示的操作工具栏。                         |
| `copyButton`       | 复制消息按钮。                                   |
| `editButton`       | 编辑消息按钮。                                   |
| `branchNavigation` | 消息分支之间的导航（编辑后出现）。               |

### `reasoningMessage` 子插槽

可通过 `messageView={{ reasoningMessage: { ... } }}` 使用：

| 插槽          | 说明                               |
| ------------- | ---------------------------------- |

| `contentView` | 推理内容区域。                     |
| `toggle`      | 展开/收起切换的包装器。            |

| `startTranscribeButton`  | 开始语音转写的按钮。       |

可通过 `welcomeScreen={{ ... }}` 使用：

| ---------------- | ------------------------------ |
| `welcomeMessage` | 空状态下显示的欢迎文本。       |

| 插槽           | 说明                   |
| -------------- | ---------------------- |
| `titleContent` | 头部中的标题文本。     |
