## 这是什么？

CopilotKit CLI 可帮助你创建连接到 CopilotKit Intelligence 的 CopilotKit 应用，无论是云托管还是自托管。它负责处理浏览器登录、项目选择、项目范围的运行时 API 密钥、历史线程导入以及本地项目配置，使你的应用能够使用线程与会话历史。

当你想创建新应用、导入历史 ADK 或 LangGraph 会话，或为你的编码智能体安装 CopilotKit 智能体技能（agent skills）时，请使用该 CLI。

## 前置条件

- Node.js 20+
- 一个用于云托管 CopilotKit Intelligence 的 CopilotKit 账户
- 你选择的起步模板应用所需的 OpenAI API 密钥或其他模型提供方密钥

<Callout type="info" title="Team Self-hosted 是一个套餐">
  Team Self-hosted 是面向自托管部署的套餐。你在云托管账户上选择它。部署会使用你自己的身份提供方。
</Callout>

## 创建新应用

<Callout type="info" title="新建应用与在现有应用中添加的区别">
  `init`（别名为 `create`）会在独立目录中搭建一个全新的项目——它会提示输入应用名称，且不会检测或引导你已有的应用。若要向现有应用添加 CopilotKit，请改为遵循[快速开始](/quickstart)中的手动安装步骤。
</Callout>

<Steps>
  <Step>
    ### 运行 create

    ```bash title="Terminal"
    npx copilotkit@latest create
    ```

    CLI 会提示输入应用名称与框架，在需要时打开浏览器登录，搭建起步模板，并将应用连接到一个云托管的 CopilotKit Intelligence 项目。
  </Step>

  <Step>
    ### 注册或登录

    如果你尚未登录，CLI 会打开浏览器登录流程。新账户需要接受 CopilotKit 自助服务协议。已经接受过的账户不会再次接受。

    如果浏览器没有打开，CLI 会打印一个登录 URL，并支持手动粘贴作为后备方式。
  </Step>

  <Step>
    ### 选择或创建组织

    在浏览器中选择或创建一个组织。新组织会选择 Developer 套餐或付费套餐。Developer 是免费套餐。若想更改该选择，请阅读[套餐](/intelligence/plans)。
  </Step>

  <Step>
    ### 回到终端

    完成组织引导后，回到终端。原来的 CLI 命令会继续执行，并提示你选择或创建项目。
  </Step>

  <Step>
    ### 选择或创建项目

    选择一个现有的云托管项目，或创建一个新项目。项目是你的应用的线程、消息与平台元数据的存储位置。

    CLI 会将所选项目写入 `.copilotkit/project.json`：

    ```json title=".copilotkit/project.json"
    {
      "projectId": "proj_...",
      "projectSlug": "support-assistant",
      "clerkOrgId": "org_..."
    }
    ```
  </Step>

  <Step>
    ### 使用生成的环境

    `init` 及其 `create` 别名会把云托管平台 URL、`SL_ENABLED` 以及项目范围的运行时 API 密钥写入 `.env`。

    ```bash title=".env"
    INTELLIGENCE_API_URL=https://...
    INTELLIGENCE_GATEWAY_WS_URL=wss://...
    CPK_INTELLIGENCE_API_KEY=cpk-...
    CPK_TELEMETRY_ID=...
    SL_ENABLED=true
    ```

    请将 `CPK_INTELLIGENCE_API_KEY` 保留在服务端。项目密钥用于将 Runtime 连接到 Intelligence。`CPK_TELEMETRY_ID` 是可选的、非机密的分析标识。

    云托管配置不会签发 `COPILOTKIT_LICENSE_TOKEN`。该令牌仅用于离线或自托管许可，不能替代云托管项目 API 密钥。
  </Step>

  <Step>
    ### 开始开发

    ```bash title="Terminal"
    npm run dev
    ```

    起步模板会运行你的本地应用与运行时，同时把线程存储在 CLI 所选的云托管项目中。
  </Step>
</Steps>

## 在本地评估 Intelligence

想在没有云托管项目的情况下试用 Intelligence，可以在你自己的机器上用 Docker 运行它。本地评估是一项预览特性，支持在 macOS 上配合 Docker Desktop 使用。受支持的预览范围请阅读[在本地评估 Intelligence](/intelligence/self-hosting-local)。在你的应用文件夹中运行：

```bash title="Terminal"
npx copilotkit@latest local setup
npx copilotkit@latest local connect --approve-connection
```

CLI 会检查 Docker、为你的组织获取评估许可、安装最新版本，并将应用连接到它。相关要求、仪表盘登录与模型配置请阅读[在本地评估 Intelligence](/intelligence/self-hosting-local)。

| 命令 | 作用 |
|---|---|
| `npx copilotkit@latest local status` | 显示服务健康状况、URL 以及任何失败的配置步骤。 |
| `npx copilotkit@latest local start` | 启动应用的本地技术栈。 |
| `npx copilotkit@latest local stop` | 停止技术栈并保留其数据。 |
| `npx copilotkit@latest local login` | 打开本地仪表盘并登录。 |
| `npx copilotkit@latest local setup` | 安装技术栈、配置 Automatic Learning 模型，或继续未完成的配置。 |
| `npx copilotkit@latest local update` | 将技术栈更新到最新版本并保留其数据。 |
| `npx copilotkit@latest local renew` | 续订评估许可。 |
| `npx copilotkit@latest local delete` | 先确认，然后删除技术栈及其数据。 |

## 导入并同步历史会话

在通过 CLI 创建且启用了 CopilotKit Intelligence 的 CopilotKit 应用中使用 `import`。导入器面向当前目录已选定的 CopilotKit Intelligence 项目。

<Tabs groupId="cli-import-source" items={["ADK", "LangGraph"]}>
  <Tab value="ADK">

    ```bash
    npx copilotkit@latest import --source adk --dry-run
    ```

  </Tab>
  <Tab value="LangGraph">

    ```bash
    npx copilotkit@latest import --source langgraph --dry-run
    ```

  </Tab>
</Tabs>

该命令默认以交互方式运行。先用 `--dry-run` 可以在不开启导入批次的情况下，探明源智能体键、会话数量、跳过项以及预计的上传大小。

如果需要导入到另一个项目，请先选择它，再继续真正的导入：

```bash title="Terminal"
npx copilotkit@latest project select
```

这会更改当前目录所选择的项目，并将其项目范围的运行时密钥写入起步模板生成的 `.env`。

在真正导入之前，先从该 `.env` 导出目标值：

```bash title="Terminal"
export INTELLIGENCE_API_URL="https://..."
export CPK_INTELLIGENCE_API_KEY="cpk-..."
```

导入器读取 `--api-url` 与 `--api-key`，或当前进程的环境变量。它不会自动加载 `.env` 或 `.copilotkit/project.json`。密钥也接受 `COPILOTKIT_API_KEY`。

项目选择会更新应用配置；导入器仍然通过命令行标志或导出的环境变量获取其目标。

完整的接入流程请参见[为现有线程添加 AG-UI 流](/threads-import)。各数据源的具体配置见[为 ADK 会话添加 AG-UI 流](/google-adk/threads-import)与[为 LangGraph 线程添加 AG-UI 流](/langgraph-python/threads-import)。

## 验证你的配置

`verify` 回答每个集成最终都会遇到的问题：*它真的在正常工作吗？* 它从浏览器之外检查接线情况，因此在完全没有浏览器的场景——React Native，或远程主机上的运行时——它是应当求助的证明手段。

```bash
npx copilotkit@latest verify
```

它会检查是否已选定云托管项目、项目 API 密钥能否通过身份验证、运行时是否有响应，以及运行时是否声明了至少一个智能体——然后报告运行时版本、智能体框架、网关接线情况与许可状态。

<Callout type="warn" title="逐项阅读检查结果，而非只看汇总">
  每项检查都会报告 **PASS**、**FAIL** 或 **UNKNOWN**。`UNKNOWN` 表示该项检查无法运行，绝不表示检查已通过。
</Callout>

要证明智能体真的在*运行*而不仅是*已配置*，可以加上 `--round-trip`。它会通过运行时发送一个真实请求，并从线程中读回答案：

```bash
npx copilotkit@latest verify --round-trip
```

<Callout type="warn" title="--round-trip 不能证明什么">
  它发送的是一个**固定**的提示，并记录答案的字符数以及出现的工具调用名称——**绝不记录答案文本**。它能证明确实有答案返回，却永远无法告诉你答案说了什么，因此不能替代对照项目实际持有的数据来核查响应。

  它也只能证明智能体以*声明的 id* 作了答，而不能证明回答的是**哪个部署**——指向其他项目智能体的运行时会给出完全相同的响应。

  由于它会运行智能体，因此会消耗一次模型调用并记录一个线程。这正是它被设计为可选开启而非默认启用的原因。
</Callout>

| 选项 | 作用 |
|---|---|
| `--runtime-url <url>` | 要探测的运行时端点。默认 `http://localhost:3000/api/copilotkit`——只要运行时不在默认位置，就应传入该选项。 |
| `--round-trip` | 同时运行智能体并读回其答案。 |
| `--agent <id>` | 当运行时声明了多个智能体时，指定要运行哪一个。 |
| `--expect-runtime <mode>` | `intelligence`（默认）或 `oss`。使用 `oss` 时，云托管项目与凭据检查不适用。 |
| `--timeout <seconds>` | 等待答案的时长。默认 `90`。 |
| `--header "<name>: <value>"` | 额外的请求头，可重复使用。当你的 `identifyUser` 读取 CLI 不携带的会话时使用它。 |
| `--json` | 仅在 stdout 上输出机器可读的负载。 |

除非所有检查都通过，否则 `verify` 会以非零状态码退出，因此可以用作 CI 门禁。

## 身份验证命令

| 命令 | 作用 |
|---|---|
| `npx copilotkit@latest login` | 打开浏览器登录流程，并存储本地 CLI 会话。 |
| `npx copilotkit@latest whoami` | 显示当前登录的用户与活动组织。 |
| `npx copilotkit@latest logout` | 清除本地 CLI 会话。 |

## 项目命令

| 命令 | 作用 |
|---|---|
| `npx copilotkit@latest project select` | 为当前目录选择或创建一个云托管 CopilotKit Intelligence 项目。 |
| `npx copilotkit@latest import --source adk --dry-run` | 导入前预览历史 Google ADK 会话线程。 |
| `npx copilotkit@latest import --source langgraph --dry-run` | 导入前预览历史 LangGraph 会话线程。 |
| `npx copilotkit@latest license create` | 为仍需要许可证的流程签发 CopilotKit 许可证令牌。 |
| `npx copilotkit@latest license list` | 列出当前用户或组织的许可证元数据。 |

当你需要把 CLI 创建的应用迁移到另一个云托管项目时，重新运行 `project select` 是安全的。该命令会更新 `.copilotkit/project.json`，并为所选项目预配一个项目范围的 API 密钥。

## Skills 命令

| 命令 | 作用 |
|---|---|
| `npx copilotkit@latest skills install` | 为受支持的编码智能体安装 CopilotKit 智能体技能。 |
| `npx copilotkit@latest skills onboard` | 安装技能，然后为现有应用启动智能体辅助的引导流程。 |
