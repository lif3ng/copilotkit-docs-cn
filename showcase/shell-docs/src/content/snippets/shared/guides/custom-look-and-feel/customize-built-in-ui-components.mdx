## CSS 变量（最简单）

更改 Copilot UI 组件所用颜色的最简单方式，就是覆盖 CopilotKit 的 CSS 变量。

<Callout type="info">
  将鼠标悬停在下方交互式 UI 元素上，即可查看可用的 CSS 变量。
</Callout>

<CopilotKitCSS />
<InteractiveCSSInspector />

找到合适的变量后，你可以导入 `CopilotKitCSSProperties`，只需将 CopilotKit 包裹在一个 div 中并覆盖 CSS 变量即可。

```tsx
import { CopilotKitCSSProperties } from "@copilotkit/react-ui";

<div
  // [!code highlight:5]
  style={
    {
      "--copilot-kit-primary-color": "#222222",
    } as CopilotKitCSSProperties
  }
>
  <CopilotSidebar .../>
</div>
```

### 参考

| CSS 变量                                 | 描述                                                  |
| ---------------------------------------- | ----------------------------------------------------- |
| `--copilot-kit-primary-color`            | 主品牌色/操作色 —— 用于按钮和交互元素                 |
| `--copilot-kit-contrast-color`           | 与主色形成对比的颜色 —— 用于主色元素上的文本          |
| `--copilot-kit-background-color`         | 页面/容器的主背景色                                   |
| `--copilot-kit-secondary-color`          | 次级背景色 —— 用于卡片、面板和浮起表面                |
| `--copilot-kit-secondary-contrast-color` | 主内容的主要文本颜色                                  |
| `--copilot-kit-separator-color`          | 分隔线与容器的边框颜色                                |
| `--copilot-kit-muted-color`              | 用于禁用/非激活状态的弱化色                           |

## 自定义 CSS

除了自定义颜色之外，CopilotKit CSS 的结构也便于通过 CSS 类进行自定义。

```css title="globals.css"
.copilotKitButton {
  border-radius: 0;
}

.copilotKitMessages {
  padding: 2rem;
}

.copilotKitUserMessage {
  background: #007aff;
}
```

## 自定义字体

你可以通过更新 CopilotKit 所用各类 CSS 类中的 `fontFamily` 属性来自定义字体。

```css title="globals.css"
.copilotKitMessages {
  font-family: "Arial, sans-serif";
}

.copilotKitInput {
  font-family: "Arial, sans-serif";
}
```

### 参考

你可以更新主要的内容类来更改各组件的字体。

| CSS 类                        | 描述                       |
| ----------------------------- | -------------------------- |
| `.copilotKitMessages`         | 所有消息的主容器           |
| `.copilotKitInput`            | 输入框                     |
| `.copilotKitMessage`          | 所有聊天消息的基础样式     |
| `.copilotKitUserMessage`      | 用户消息                   |
| `.copilotKitAssistantMessage` | AI 回复                    |

## 自定义图标

你可以通过向 `CopilotSidebar`、`CopilotPopup` 或 `CopilotChat` 组件传入 `icons` 属性来自定义图标。

```tsx
<CopilotChat
  icons={{
    // Use your own icons here – any React nodes
    openIcon: <YourOpenIconComponent />,
    closeIcon: <YourCloseIconComponent />,
  }}
/>
```

### 参考

| 图标              | 描述                            |
| ----------------- | ------------------------------- |
| `openIcon`        | 打开聊天按钮所用的图标          |
| `closeIcon`       | 关闭聊天按钮所用的图标          |
| `headerCloseIcon` | 头部关闭聊天按钮所用的图标      |
| `sendIcon`        | 发送按钮所用的图标              |
| `activityIcon`    | 活动指示器所用的图标            |
| `spinnerIcon`     | 加载动画所用的图标              |
| `stopIcon`        | 停止按钮所用的图标              |
| `regenerateIcon`  | 重新生成按钮所用的图标          |
| `pushToTalkIcon`  | 按住说话（push to talk）的图标  |

## 自定义标签

要自定义标签，请向 `CopilotSidebar`、`CopilotPopup` 或 `CopilotChat` 组件传入 `labels` 属性。

```tsx
<CopilotChat
  labels={{
    welcomeMessageText: "Hello! How can I help you today?",
    modalHeaderTitle: "My Copilot",
    chatInputPlaceholder: "Ask me anything!",
    stopGenerating: "Stop",
    regenerateResponse: "Regenerate",
  }}
/>
```

### 参考

| 标签                   | 描述                                 |
| ---------------------- | ------------------------------------ |
| `welcomeMessageText`   | 在聊天窗口中展示的初始消息           |
| `modalHeaderTitle`     | 头部展示的标题                       |
| `chatInputPlaceholder` | 输入框中展示的占位文本               |
| `stopGenerating`       | 停止按钮上展示的标签                 |
| `regenerateResponse`   | 重新生成按钮上展示的标签             |
