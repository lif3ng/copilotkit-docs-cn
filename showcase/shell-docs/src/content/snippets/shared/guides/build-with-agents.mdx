AI 编码智能体对 CopilotKit 的 API、模式与最佳实践的了解可能不是最新的。本页的资源能让它们在自己的上下文中直接获得准确、最新的知识。

## CopilotKit Skills

Skill 是一些包含指令的文件夹，编码智能体会自动发现并使用它们。CopilotKit 的 Skill 刻意保持精简：它们不复述 API，而是教会你的智能体去查询当前的正确答案——查这些文档、查源码、查 CLI。API 的副本会过时，检索不会。

<Callout type="info">
  Skill 是让你的智能体掌握 CopilotKit 知识的推荐方式。它们在 Claude Code、Cursor、Codex、Gemini CLI 以及任何支持 [agentskills.io](https://agentskills.io) 标准的工具中原生可用。
</Callout>

共有两个：

| Skill            | 用途                                                                                                                                                                                   |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `copilotkit`     | 回答任何 CopilotKit 相关问题，依据最新文档与源码。它会以 Markdown 形式抓取文档，并在插件提供时使用 `copilotkit-docs` MCP 服务器                                                         |
| `copilotkit-cli` | 驱动 CLI——脚手架创建项目、连接 Intelligence，并在手动调试之前用 `copilotkit verify` 验证项目的接线是否正确                                                                               |

你无需在两者之间做选择——你的智能体会加载适合当前任务的那个。[skills 目录](https://github.com/CopilotKit/CopilotKit/tree/main/skills)中还包含几个流程类 Skill，例如设置 Slack 渠道，它们会逐步引导你完成横跨多个系统的操作。

<Steps>
  <Step>
    ### 安装 Skill

    在你正在构建的项目根目录下运行：

    ```bash
    npx skills add CopilotKit/CopilotKit/skills -y
    ```

    这会把 Skill 安装到你的项目中，任何在该项目中工作的编码智能体（Claude Code、Codex、Cursor 或 Gemini CLI）都会自动发现它们。无需针对单个智能体做任何配置。

    <Callout type="info">
      想自行选择安装内容？运行 `npx skills add CopilotKit/CopilotKit/skills` 且不带 `-y`，即可交互式地挑选具体的 Skill、目标智能体与作用范围——或者加上 `-g`，全局安装到每个项目。
    </Callout>

  </Step>
  <Step>
    ### 开始构建

    打开一个新的智能体会话，用一条起步提示词让 Skill 派上用场：

    ```
    Help me add CopilotKit to this app. Look up the current setup in the CopilotKit docs first.
    ```

    你的智能体会检索文档而不是凭记忆行事，并且在出现问题时会使用 `copilotkit verify`。
  </Step>
</Steps>
