`useDefaultRenderTool` 为**任何**未定义特定 `useRenderToolCall` 的工具提供了一个兜底渲染器。它适用于以下场景：

- 在开发过程中展示所有工具调用
- 渲染 MCP（Model Context Protocol）工具
- 为意外出现的工具提供通用的后备 UI

```tsx title="app/page.tsx"
import { useDefaultRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
// ...

const YourMainContent = () => {
  // ...
  // [!code highlight:15]
  useDefaultRenderTool({
    render: ({ name, args, status, result }) => {
      return (
        <div style={{ color: "black" }}>
          <span>
            {status === "complete" ? "✓" : "⏳"}
            {name}
          </span>
          {status === "complete" && result && (
            <pre>{JSON.stringify(result, null, 2)}</pre>
          )}
        </div>
      );
    },
  });
  // ...
};
```

<Callout type="info">
  与按名称针对特定工具的 `useRenderToolCall` 不同，
  `useDefaultRenderTool` 会捕获**所有**没有专用渲染器的工具。
</Callout>

<Callout type="info">
  在 v2 中，请使用 [`useDefaultRenderTool`](/reference/v2/hooks/useDefaultRenderTool)
  进行通配兜底渲染，使用
  [`useRenderTool`](/reference/v2/hooks/useRenderTool)
  注册具名或通配渲染器。
</Callout>
