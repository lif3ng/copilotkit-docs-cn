## MCP 文档服务器

CopilotKit MCP 服务器为 AI 编码智能体提供关于 CopilotKit API、模式和最佳实践的深度知识。连接到你的开发环境后，它能让 AI 助手：

- 提供专家级指导
- 生成准确的代码
- 为你的 AI 智能体提供用户界面
- 帮助你正确实现 CopilotKit 特性

### Cursor

[Cursor](https://cursor.sh/) 是一款专为提升生产力打造的 AI 代码编辑器。它内置 AI 辅助功能，并支持通过 MCP 用外部工具扩展 AI 能力。

<Steps>
  <Step>
    ### 在 Cursor 中打开 MCP 设置
    1. 按 `Shift+Command+J`（Mac）或 `Shift+Ctrl+J`（Windows/Linux）打开 Cursor 设置。
    2. 在左侧边栏分类中找到 “MCP Tools”。
    3. 点击 “Add Custom MCP”。
    这会在编辑器中打开 mcp.json 文件，你需要编辑该文件。

    此界面打开的是全局 `~/.cursor/mcp.json`，它会为你打开的每个项目注册该服务器。若只想在当前项目注册，请在项目根目录创建 `.cursor/mcp.json`，并放入相同的配置。
  </Step>
  <Step>
    ### 将 MCP 服务器添加到 Cursor
    复制 CopilotKit MCP 的配置，并粘贴到 mcp.json 文件的 mcpServers 键下。

    <Tabs groupId="transport" items={['HTTP', 'SSE']} default="HTTP">
      <Tab value="HTTP">
        ```json
        {
          "mcpServers": {
            "CopilotKit MCP": {
              "command": "npx",
              "args": [
                "-y",
                "mcp-remote",
                "https://mcp.copilotkit.ai/mcp"
              ]
            }
          }
        }
        ```
      </Tab>
      <Tab value="SSE">
        ```json
        {
          "mcpServers": {
            "CopilotKit MCP": {
              "url": "https://mcp.copilotkit.ai/sse"
            }
          }
        }
        ```
      </Tab>
    </Tabs>

  </Step>
</Steps>

### Claude Web

[Claude](https://claude.ai/) 是 Anthropic 的 AI 助手，可通过网页界面访问。它支持被称为 Connectors 的 MCP 集成，用于连接外部工具和服务。

<Steps>
  <Step>
    在 Claude 中前往 [Connectors](https://claude.ai/settings/connectors) 设置
    页面。 1. 点击聊天框左下角的你的用户头像，然后在出现的菜单选项中选择
    “Settings”。 2. 在 Settings 页面左侧菜单中选择 “Connectors”
  </Step>
  <Step>点击 “Add custom connector”</Step>
  <Step>
    1. 在 Name 字段中为 CopilotKit connector 输入一个易记的名称，
    如 `CopilotKit` 2. 在 URL 字段中输入以下内容： ```
    https://mcp.copilotkit.ai/sse ```
  </Step>
  <Step>点击 “Add”</Step>
</Steps>

### Claude Code

[Claude Code](https://docs.claude.com/en/docs/claude-code) 是 Anthropic 官方的 Claude CLI。它支持 MCP 集成以连接外部工具和服务，用专业知识增强 AI 能力。

<Steps>
  <Step>
    ### 将 MCP 服务器添加到 Claude Code
    使用 Claude Code CLI 添加 CopilotKit MCP 服务器：

    ```bash
    claude mcp add --transport sse copilotkit-mcp https://mcp.copilotkit.ai/sse --scope project
    ```

    **预期输出：**
    ```
    Added SSE MCP server copilotkit-mcp with URL: https://mcp.copilotkit.ai/sse to project config
    File modified: /path/to/your/project/.mcp.json
    ```

    `--scope project` 会在项目根目录写入 `.mcp.json`，因此所有检出该仓库的人都会注册此服务器。若不加该参数，命令会回退到 `local` 作用域，写入你主目录下的 `~/.claude.json`：注册仅对你本人可见，且改动位于项目之外 —— 无人值守运行的编码智能体通常不被允许这样做。

  </Step>
  <Step>
    ### 验证连接
    检查服务器是否已正确连接：

    ```bash
    claude mcp list
    ```

    **预期输出：**
    ```
    Checking MCP server health...

    copilotkit-mcp: https://mcp.copilotkit.ai/sse (SSE) - ✓ Connected
    ```

    <div className="mt-4 p-4 rounded-lg bg-muted">
      <div className="font-medium text-sm mb-2">💡 服务器名称要求</div>
      <div className="text-sm text-muted-foreground">
        服务器名称只能包含字母、数字、连字符和下划线。请避免在服务器名称中使用空格。
      </div>
    </div>

  </Step>
  <Step>
    ### 在 Claude Code 中使用 MCP 工具
    配置完成后，在与 Claude Code 交互处理 CopilotKit 相关开发任务时，CopilotKit MCP 服务器的工具会自动可用。AI 会根据你的提问智能地使用这些工具。

    **MCP 服务器提供的内容**：
    - CopilotKit 开发的专家级指导
    - CopilotKit 特性的准确代码生成
    - 最佳实践与实现模式
    - 对 CopilotKit API 的深入理解

    **管理命令**：
    ```bash
    # 查看服务器详情
    claude mcp get copilotkit-mcp

    # 如有需要，移除服务器
    claude mcp remove copilotkit-mcp -s project
    ```

  </Step>
</Steps>

### Windsurf

[Windsurf](https://codeium.com/windsurf) 是 Codeium 推出的智能体化 IDE，将 AI 编码辅助与传统开发工具相结合。它配备支持 MCP 集成的 Cascade AI 助手。

<Steps>
  <Step>
    ### 进入 Windsurf MCP 设置
    1. 打开 Windsurf 设置（点击右下角的设置按钮）
    2. 前往 “Cascade” 部分
    3. 找到 “Model Context Protocol” 或 “MCP” 设置
    4. 如果尚未启用 MCP，请启用 MCP 支持
  </Step>
  <Step>
    ### 将 MCP 服务器添加到 Windsurf
    你可以通过多种方式添加 CopilotKit MCP：

    <Tabs groupId="windsurf-setup" items={['Using the Built-in Server Browser', 'Manual Configuration']} default="Using the Built-in Server Browser">
      <Tab value="Using the Built-in Server Browser">
        1. 在 Cascade 部分点击 “Add Server”
        2. 选择 “Add custom server”
        3. 选择传输类型：
           - **SSE/HTTP** 用于远程服务器
           - **stdio** 用于基于本地命令的服务器
      </Tab>
      <Tab value="Manual Configuration">
        将服务器配置添加到你的 mcp_config.json 文件：

        <Tabs groupId="windsurf-transport" items={['HTTP Transport', 'SSE Transport', 'stdio Transport (Local)']} default="HTTP Transport">
          <Tab value="HTTP Transport">
            ```json
            {
              "mcpServers": {
                "CopilotKit MCP": {
                  "url": "https://mcp.copilotkit.ai/mcp",
                  "disabled": false,
                  "timeout": 30
                }
              }
            }
            ```
          </Tab>
          <Tab value="SSE Transport">
            ```json
            {
              "mcpServers": {
                "CopilotKit MCP": {
                  "url": "https://mcp.copilotkit.ai/sse",
                  "disabled": false,
                  "timeout": 30
                }
              }
            }
            ```
          </Tab>
          <Tab value="stdio Transport (Local)">
            ```json
            {
              "mcpServers": {
                "CopilotKit MCP": {
                  "command": "npx",
                  "args": ["-y", "mcp-remote", "https://mcp.copilotkit.ai/mcp"]
                }
              }
            }
            ```
          </Tab>
        </Tabs>
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 配置文件位置
    MCP 配置通常存储在：

    <Tabs groupId="windsurf-os" items={['macOS', 'Windows', 'Linux']} default="macOS">
      <Tab value="macOS">
        ```
        ~/.codeium/windsurf/mcp_config.json
        ```
      </Tab>
      <Tab value="Windows">
        ```
        %APPDATA%\.codeium\windsurf\mcp_config.json
        ```
      </Tab>
      <Tab value="Linux">
        ```
        ~/.config/codeium/windsurf/mcp_config.json
        ```
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 在 Windsurf 中使用 MCP 工具
    配置完成后，CopilotKit MCP 工具将在 Windsurf 的 Cascade AI 助手中可用：

    - 打开 Cascade 面板（AI 聊天界面）
    - MCP 工具会自动对 AI 可用
    - 你可以在对话中使用 `@CopilotKit MCP` 引用特定工具
    - Windsurf 会根据你的请求智能选择要使用的工具

    ### 管理 MCP 服务器
    在 Windsurf MCP 设置中，你可以：
    - 启用/禁用单个服务器
    - 查看服务器状态和连接健康度
    - 配置工具权限与自动审批设置
    - 监控服务器日志以便调试
    - 在服务器无响应时重启服务器

    AI 会将 CopilotKit MCP 功能无缝集成到你的开发工作流中！

  </Step>
</Steps>

### Cline

[Cline](https://github.com/cline/cline) 是一个提供自主 AI 编码辅助的 VS Code 扩展。它可以使用 MCP 工具与外部系统交互来执行复杂任务。

<Steps>
  <Step>
    ### 打开 Cline MCP 设置
    1. 在 VS Code 中打开 Cline 扩展面板
    2. 点击 Cline 面板右上角的菜单（⋮）
    3. 从下拉菜单中选择 “MCP Servers”
    
    这会打开 MCP Servers 界面，你可以在其中管理服务器连接。
  </Step>
  <Step>
    ### 将 MCP 服务器添加到 Cline
    在 MCP Servers 界面中，你有三个主要选项：

    <Tabs groupId="cline-setup" items={['Remote Server Setup', 'Configuration File Setup']} default="Remote Server Setup">
      <Tab value="Remote Server Setup">
        1. 点击 “Remote Servers” 标签页
        2. 输入 Server Name（例如 “CopilotKit MCP”）
        3. 输入 Server URL：
        ```
        https://mcp.copilotkit.ai/sse
        ```
        4. 点击 “Add Server” 完成连接
      </Tab>
      <Tab value="Configuration File Setup">
        你也可以通过高级设置进行配置：
        1. 在 “Installed” 标签页中点击 “Configure MCP Servers”
        2. 将以下配置添加到你的设置文件：
        ```json
        {
          "mcpServers": {
            "CopilotKit MCP": {
              "url": "https://mcp.copilotkit.ai/sse",
              "disabled": false,
              "timeout": 30
            }
          }
        }
        ```
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 在 Cline 中使用 MCP 工具
    连接后，当你与 AI 助手交互时，Cline 会自动使用 CopilotKit MCP 提供的工具。MCP 工具无需手动选择即可使用 —— Cline 的 AI 会根据你的请求智能选择要使用的工具。

    **服务器状态指示器**：
    - 绿点：已连接，可以使用
    - 黄点：正在连接
    - 红点：连接错误

    你可以在 MCP Servers 界面的 “Installed” 标签页中管理服务器设置、重启连接或禁用服务器。

  </Step>
</Steps>

### GitHub Copilot

[GitHub Copilot](https://github.com/features/copilot) 是 Microsoft 集成到 VS Code 和其他编辑器中的 AI 结对编程工具。它支持 MCP，通过外部工具和服务扩展其能力。

<Steps>
  <Step>
    ### 在 VS Code 中启用 MCP 支持
    1. 打开 VS Code 设置（Mac 上为 `Cmd+,`，Windows/Linux 上为 `Ctrl+,`）
    2. 在设置搜索栏中搜索 “MCP”
    3. 启用 `chat.mcp.enabled` 设置
  </Step>
  <Step>
    ### 将 MCP 服务器添加到 GitHub Copilot
    你可以通过多种方式为 GitHub Copilot 配置 MCP 服务器：

    <Tabs groupId="copilot-config" items={['Workspace Configuration (Recommended)', 'User Settings Configuration', 'Command Palette']} default="Workspace Configuration (Recommended)">
      <Tab value="Workspace Configuration (Recommended)">
        在项目根目录创建 `.vscode/mcp.json` 文件：
        ```json
        {
          "servers": {
            "CopilotKit MCP": {
              "url": "https://mcp.copilotkit.ai/sse"
            }
          }
        }
        ```
      </Tab>
      <Tab value="User Settings Configuration">
        添加到你的 VS Code `settings.json`：
        ```json
        {
          "mcp": {
            "servers": {
              "CopilotKit MCP": {
                "url": "https://mcp.copilotkit.ai/sse"
              }
            }
          }
        }
        ```
      </Tab>
      <Tab value="Command Palette">
        1. 打开命令面板（`Cmd+Shift+P` 或 `Ctrl+Shift+P`）
        2. 输入 “MCP: Add Server” 并选择该命令
        3. 选择 “HTTP (sse)” 作为服务器类型
        4. 输入服务器 URL：`https://mcp.copilotkit.ai/sse`
        5. 为服务器命名：`CopilotKit MCP`
      </Tab>
    </Tabs>

  </Step>
  <Step>
    ### 在 GitHub Copilot 中使用 MCP 工具
    1. 在 VS Code 中打开 Copilot Chat（点击活动栏中的 Copilot 图标）
    2. 从聊天下拉菜单中切换到 Agent 模式
    3. 点击 Tools（🔧）按钮查看可用的 MCP 工具
    4. 你的 CopilotKit MCP 工具将被列出，并可自动使用

    GitHub Copilot 会根据你的提问智能地使用 MCP 工具。你也可以使用 `#` 加工具名称来直接引用工具。

  </Step>
  <Step>
    ### 管理 MCP 服务器
    使用 “MCP: List Servers” 命令查看和管理你已配置的服务器：

    - 启动/停止/重启服务器
    - 查看服务器日志以便调试
    - 浏览可用的工具和资源

  </Step>
</Steps>

### Codex

[Codex](https://developers.openai.com/codex/mcp) 直接支持 Streamable HTTP MCP 服务器。

<Steps>
  <Step>
    ### 将 MCP 服务器添加到 Codex
    运行此命令：

    ```bash
    codex mcp add copilotkit --url https://mcp.copilotkit.ai/mcp
    ```

    或者，将此表添加到 `~/.codex/config.toml`：

    ```toml title="~/.codex/config.toml"
    [mcp_servers.copilotkit]
    url = "https://mcp.copilotkit.ai/mcp"
    ```

    如果你之前使用的是 `mcp-remote` 配置，请将其 `command` 和 `args` 条目替换为 `url`。
    Streamable HTTP 请使用 `/mcp`。根 URL（`https://mcp.copilotkit.ai`）会返回 404。
  </Step>
  <Step>
    ### 验证连接
    列出已配置的 MCP 服务器：

    ```bash
    codex mcp list
    ```

    此命令仅验证注册情况。请新开一个 Codex 会话并运行 `/mcp`，以检查连接和可用工具。

    让 Codex 测试一次文档搜索：

    ```text
    Use CopilotKit's search-docs tool to find documentation for useFrontendTool.
    ```

    工具调用成功会返回文档结果。如果服务器连接失败，请验证其 URL 是否以 `/mcp` 结尾。
  </Step>
</Steps>

### 其他

对于上文未列出的 MCP 兼容应用，请使用这些通用集成模式。MCP（Model Context Protocol）是一个开放标准，允许 AI 应用连接外部工具和数据源。

#### 连接方式

大多数 MCP 兼容应用支持以下一种或两种连接方式：

<Tabs groupId="universal-transport" items={['SSE', 'stdio']} default="SSE">
  <Tab value="SSE">
    适用于基于 Web 或远程的集成：
    ```
    https://mcp.copilotkit.ai/sse
    ```
  </Tab>
  <Tab value="stdio">
    适用于本地命令行集成：
    ```json
    {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.copilotkit.ai/mcp"]
    }
    ```
  </Tab>
</Tabs>

#### 集成步骤

1. **找到 MCP 设置** —— 在应用设置中查找 “MCP”、“Model Context Protocol” 或 “Tools”
2. **添加服务器** —— 使用 SSE URL：`https://mcp.copilotkit.ai/sse`
3. **测试连接** —— 重启应用，并确认服务器出现在可用工具中

#### 常见配置模式

<Tabs groupId="config-patterns" items={['JSON Configuration File', 'Application Settings']} default="JSON Configuration File">
  <Tab value="JSON Configuration File">
    许多应用使用配置文件（位置因应用而异）：
    ```json
    {
      "servers": {
        "CopilotKit MCP": {
          "url": "https://mcp.copilotkit.ai/sse"
        }
      }
    }
    ```
  </Tab>
  <Tab value="Application Settings">
    一些应用将 MCP 集成到主设置中：
    ```json
    {
      "mcp": {
        "enabled": true,
        "servers": {
          "CopilotKit MCP": {
            "url": "https://mcp.copilotkit.ai/sse"
          }
        }
      }
    }
    ```
  </Tab>
</Tabs>
