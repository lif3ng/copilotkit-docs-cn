## 这是什么？

前端工具让你可以定义智能体可调用的客户端函数，其执行完全发生在用户的浏览器中。当智能体调用前端工具时，逻辑在客户端运行，让你可以直接访问前端环境。

这可用于 UI 控制、生成式 UI 或人机协同（human-in-the-loop）交互。本指南介绍如何将前端工具用于人机协同。

## 什么时候应该使用它？

当你需要智能体与客户端底层能力交互时，可以使用前端工具，例如：

- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage 或 cookie 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 创建前端人机协同工具

前端工具的使用方式多种多样。其中一种是构建人机协同流程：工具的响应由用户的决定来把关。

在本例中，我们将模拟执行命令的“审批”流程。使用 `useHumanInTheLoop` hook 创建一个会请求用户批准的工具。

```tsx title="page.tsx"
import { useHumanInTheLoop } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";

export function Page() {
  // ...

  // [!code highlight:16]
  useHumanInTheLoop({
    name: "humanApprovedCommand",
    description: "Ask human for approval to run a command.",
    parameters: z.object({
      command: z.string().describe("The command to run"),
    }),
    render: ({ args, respond, status }) => {
      if (status !== "executing") return <></>;
      return (
        <div>
          <pre>{args.command}</pre>
          {/* [!code highlight:2] */}
          <button onClick={() => respond?.(`Tell the user the command ran`)}>
            Approve
          </button>
          <button
            onClick={() => respond?.(`Tell the user the command wasn't run`)}
          >
            Deny
          </button>
        </div>
      );
    },
  });

  // ...
}
```
