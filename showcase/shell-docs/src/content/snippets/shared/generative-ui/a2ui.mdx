## A2UI 是什么？

A2UI 是 Google 推出的声明式生成式 UI 规范，其设计目标包括：

- **基于 JSONL** —— 使用 JSON Lines 格式进行流式传输
- **对 LLM 友好** —— 语言模型易于生成
- **平台无关** —— 可在任何平台上渲染
- **流式优先** —— 为实时、渐进式渲染而生

## 为什么选择 A2UI？

### 声明式方法

A2UI 允许智能体以声明式方式描述 UI 组件，让 LLM 无需了解实现细节，就能更轻松地生成动态界面。

### 流式支持

A2UI 从设计之初就面向流式传输，随着智能体生成响应即可渐进式渲染，带来更好的用户体验。

### 平台无关

A2UI 规范可以在 Web、移动端或任何其他平台上渲染，让你的智能体 UI 真正实现通用。

## 在 CopilotKit 中配置

### 后端

在 `CopilotRuntime` 中传入 `a2ui: {}` 即可启用 A2UI：

```ts title="app/api/copilotkit/route.ts"
import {
  CopilotRuntime,
  createCopilotRuntimeHandler,
} from "@copilotkit/runtime/v2";

const runtime = new CopilotRuntime({
  agents: { default: myAgent },
  a2ui: {},
});

// Single-route: only POST needed, no catch-all [...path] required
const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  mode: "single-route",
});

export { handler as POST };
```

这会自动为所有已注册的智能体应用 `A2UIMiddleware`。若想只作用于特定智能体，可以通过 `agents` 属性指定：`a2ui: { agents: ["my-agent"] }`。

本页的两部分都是 v2 入口：服务端使用 `@copilotkit/runtime/v2`，浏览器端使用 `@copilotkit/react-core/v2`。如果你仍在使用旧的 `@copilotkit/runtime` 根导入并配合 `copilotRuntimeNextJSAppRouterEndpoint`，A2UI 依然可用——该类会把 `a2ui` 直接转发给 v2 运行时——但 v2 handler 才是当前的 API，我们自己的 showcase 集成也已迁移过去（#6618）。其他宿主环境请参阅 [Deploy to any runtime](/runtime-server-adapter)。

配置完成后，智能体返回的任何 A2UI 输出都会自动渲染在聊天界面中——无需额外的前端代码。

### 前端

A2UI 渲染器会自动启用——前端无需额外配置。可选地，传入自定义主题：

```tsx
import { CopilotKit, type A2UITheme } from "@copilotkit/react-core/v2";

// Your own theme object — the renderer reads the keys it understands.
// Leave the `a2ui` prop off entirely to keep the built-in theme.
const myCustomTheme: A2UITheme = {
  // ...your theme keys
};

<CopilotKit runtimeUrl="/api/copilotkit" a2ui={{ theme: myCustomTheme }}>
  {children}
</CopilotKit>;
```

只有当你想覆盖默认主题时，才需要在 `<CopilotKit>` 上设置 `a2ui` 属性。
