## 这是什么？

工具是 LLM 调用预定义（通常为确定性）函数的一种方式。CopilotKit 允许你把这些工具作为自定义组件渲染到 UI 中，我们称之为**生成式 UI**（Generative UI）。

## 什么时候应该使用它？

当你想就智能体正在做的事情向用户提供反馈时——尤其是在智能体调用工具时——在 UI 中渲染工具会非常有用。CopilotKit 允许你完全自定义这些工具在聊天中的渲染方式。

## 在前端渲染工具调用

使用 `useRenderTool` hook 在 UI 中渲染工具调用。其名称必须与你的智能体中定义的工具名称一致。

<Callout type="info" title="重要">
要在 UI 中渲染工具调用，名称必须与工具的名称一致。[了解更多](/server-tools)。
</Callout>

```tsx title="app/page.tsx"
import { useRenderTool } from "@copilotkit/react-core/v2"; // [!code highlight]
import { z } from "zod";
// ...

const weatherParams = z.object({
  location: z.string().describe("The location to get weather for"),
});

const YourMainContent = () => {
  // ...
  // [!code highlight:14]
  useRenderTool({
    name: "get_weather",
    parameters: weatherParams,
    render: ({ status, parameters }) => {
      return (
        <p className="text-gray-500 mt-2">
          {status !== "complete" && "Calling weather API..."}
          {status === "complete" && `Called the weather API for ${parameters.location}.`}
        </p>
      );
    },
  });
  // ...
}
```
