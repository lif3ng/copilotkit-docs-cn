感谢你有为 CopilotKit 做贡献的兴趣。我们欢迎新的贡献者，也感谢你帮助 CopilotKit 变得更好。

本指南将帮助你尽可能顺利地开始。

## 第 1 步：安装前置条件

- [Node.js](https://nodejs.org/en/) 20.x 或更高版本
- 全局安装 [pnpm](https://pnpm.io/) v10.x（`npm i -g pnpm@^10`）

## 第 2 步：仓库设置

<Steps>
  <Step>
  ### Fork 仓库
  首先，前往 [CopilotKit 仓库](https://github.com/CopilotKit/CopilotKit)并创建一个 fork。

然后，把你的 fork 克隆到本地：

```bash
git clone https://github.com/<your-username>/CopilotKit
cd CopilotKit/src/v1.x
```

  </Step>
  <Step>
  ### 安装依赖
  <Callout type="info">
    CopilotKit 仓库是一个使用 [pnpm](https://pnpm.io/) workspace 的 monorepo。跨包的任务由 [Nx](https://nx.dev/) 编排。
  </Callout>

使用 pnpm 安装依赖：

```bash
pnpm install
```

  </Step>
  <Step>
  ### 构建包
  为确保一切正常，先把所有包构建一次：
  ```bash
  pnpm run build
  ```
  </Step>
</Steps>

## 第 3 步：开发模式

一切就绪且运行正常后，你就可以开始开发了：

```bash
# 以开发模式启动所有包
pnpm run dev

# 以开发模式启动特定包
pnpm exec nx watch --projects=packages/package-name -- pnpm run build
```

现在你可以开始修改代码了。

<Callout type="info">
  你可以在 monorepo 的 `packages` 文件夹下找到所有 `@copilotkit/*` 包。
</Callout>

## 第 4 步：实时测试更改

在大多数情况下，你希望在开发过程中能够无缝地实时测试自己的更改。

monorepo 中有一个 `examples` 文件夹，包含若干使用 CopilotKit 的不同示例。你可以运行这些示例来测试自己的更改，因为它们已与 monorepo 中的 `@copilotkit/*` 包建立链接。

在本教程中，我们将使用 `next-openai` 示例，具体是 Presentation Demo（`/presentation`）。

在另一个终端中运行以下命令来启动该示例：

```bash
cd examples/v1/next-openai
export OPENAI_API_KEY=<your-openai-api-key>
pnpm run example-dev
```

<Callout type="info">
  我们使用 `pnpm run example-dev` 命令来运行示例，这与开发各个包时使用的 `pnpm run dev` 命令不同。
</Callout>

现在打开 http://localhost:3000/presentation，你应该能看到示例正在运行。你对 CopilotKit 包所做的任何更改都会立即反映在这里。

## 第 5 步：格式化与代码检查

在提交更改之前，请在 monorepo 根目录运行以下命令，确保文件已正确格式化：

```bash
pnpm run format
```

此外，确保没有任何 lint 错误：

```bash
pnpm run lint
```

## 第 6 步：提交 Pull Request

完成更改后，提交（commit）并推送（push）它们。然后只需前往 [Pull Requests 页面](https://github.com/CopilotKit/CopilotKit/pulls)创建一个 pull request 即可。干得漂亮！

## 启动支持热重载的开发环境

CopilotKit 提供了一个现成的脚本，用于基于某个 CoAgent 示例启动开发环境。它让你可以在核心 TypeScript 与 Python 代码上开发 CopilotKit 内部实现，同时看到更改应用到所选示例上。

前置条件：确保已安装 GNU parallel 和 langgraph CLI。

接着，进入 `CopilotKit/` 目录，为你要开发的示例运行 `example.sh` 脚本：

```bash
./scripts/develop/example.sh coagents-starter
```

这会启动一个支持热重载的开发环境。

你也可以选择在 LangGraph 平台上运行同一示例：

```bash
./scripts/develop/example.sh coagents-starter langgraph-platform
```

## 调试

每次在 localhost 上运行 CopilotKit 时，你都能在聊天窗口中看到 **CopilotKit Dev Console**。Dev Console 为你提供调试 copilot 的实用功能（例如查看 copilot 感知到的状态、它可以执行的操作等）。

</Frame>

如果你想在本地禁用 Dev Console，只需在 `<CopilotKit />` provider 中把 `showDevConsole` 设置为 `false`。

## （进阶）包链接

某些情况下，你想在自己的项目中测试对 CopilotKit 所做的更改。例如，你尝试把 CopilotKit 集成到自己的代码库时遇到了一个想修复的 bug。

方便的是，你可以把本地的 CopilotKit 包链接到你自己的项目来测试更改。

具体做法请参阅[进阶：包链接](/contributing/code-contributions/package-linking)指南。
