CopilotKit 构建于 [AG-UI 协议](https://ag-ui.com)之上——这是一个轻量级的、基于事件的标准，定义了 AI 智能体如何通过 Server-Sent Events（SSE）与面向用户的应用通信。

消息、状态更新、工具调用以及智能体生命周期事件都经由 AG-UI 流转。理解这一层有助于你调试和扩展任何 CopilotKit 集成。

<FrontendOnly frontend="react">
## 使用 `useAgent` 访问你的智能体

`useAgent` 返回你的 copilot 背后的 AG-UI `AbstractAgent`：

```tsx
import { useAgent } from "@copilotkit/react-core/v2";

function AgentStatus() {
  const { agent } = useAgent({ agentId: "research-agent" });

  // agent.messages  — conversation history
  // agent.state     — current shared state
  // agent.isRunning — whether the agent is running
}
```
</FrontendOnly>

<FrontendOnly frontend="angular">
## 使用 `injectAgentStore` 访问你的智能体

`injectAgentStore` 暴露 AG-UI 智能体，并将其消息、状态与运行状态投影为 Angular signals：

```ts title="src/app/agent-status.component.ts"
import { Component, computed } from "@angular/core";
import { injectAgentStore } from "@copilotkit/angular";

@Component({
  selector: "app-agent-status",
  template: `
    <p>{{ messageCount() }} messages</p>
    @if (store().isRunning()) {
      <p>Agent is running…</p>
    }
  `,
})
export class AgentStatusComponent {
  readonly store = injectAgentStore("research-agent");
  readonly messageCount = computed(() => this.store().messages().length);
}
```
</FrontendOnly>

解析得到的智能体是一个标准的 AG-UI `AbstractAgent`。你可以读取它的状态、调用协议方法，并订阅它的事件流。

### 订阅 AG-UI 事件

<FrontendOnly frontend="react">
在 effect 中订阅，并在组件卸载时取消订阅：

```tsx
import { useEffect } from "react";
import { useAgent } from "@copilotkit/react-core/v2";

function EventLog() {
  const { agent } = useAgent({ agentId: "research-agent" });

  useEffect(() => {
    const subscription = agent.subscribe({
      onTextMessageContentEvent({ textMessageBuffer }) {
        console.log("Streaming text:", textMessageBuffer);
      },
      onToolCallEndEvent({ toolCallName, toolCallArgs }) {
        console.log("Tool called:", toolCallName, toolCallArgs);
      },
      onStateChanged({ agent }) {
        console.log("State changed:", agent.state);
      },
    });
    return () => subscription.unsubscribe();
  }, [agent]);
}
```
</FrontendOnly>

<FrontendOnly frontend="angular">
订阅 `store().agent`，并由所属 injector 释放订阅：

```ts
private readonly destroyRef = inject(DestroyRef);
readonly store = injectAgentStore("research-agent");

constructor() {
  const subscription = this.store().agent.subscribe({
    onTextMessageContentEvent({ textMessageBuffer }) {
      console.log("Streaming text:", textMessageBuffer);
    },
    onToolCallEndEvent({ toolCallName, toolCallArgs }) {
      console.log("Tool called:", toolCallName, toolCallArgs);
    },
    onStateChanged({ agent }) {
      console.log("State changed:", agent.state);
    },
  });
  this.destroyRef.onDestroy(() => subscription.unsubscribe());
}
```
</FrontendOnly>

回调名称与 [AG-UI 事件类型](https://docs.ag-ui.com/concepts/events)直接对应：

| 事件 | 回调 |
| --- | --- |
| 运行生命周期 | `onRunStartedEvent`, `onRunFinishedEvent`, `onRunErrorEvent` |
| 步骤 | `onStepStartedEvent`, `onStepFinishedEvent` |
| 文本消息 | `onTextMessageStartEvent`, `onTextMessageContentEvent`, `onTextMessageEndEvent` |
| 工具调用 | `onToolCallStartEvent`, `onToolCallArgsEvent`, `onToolCallEndEvent`, `onToolCallResultEvent` |
| 状态 | `onStateSnapshotEvent`, `onStateDeltaEvent` |
| 消息 | `onMessagesSnapshotEvent` |
| 自定义 | `onCustomEvent`, `onRawEvent` |
| 高层变更 | `onMessagesChanged`, `onStateChanged` |

## 代理模式

当你将 CopilotKit 与运行时搭配使用时，前端并不直接与后端智能体通信。CopilotKit 通过运行时的 `/info` 端点发现智能体，并用一个实现相同 `AbstractAgent` 接口的代理来表示每个智能体。

<FrontendOnly frontend="react">
```tsx title="你的组件所看到的"
const { agent } = useAgent();
agent.messages;
agent.state;
agent.subscribe({ /* … */ });
```

```tsx title="底层实际发生的"
// useAgent() → registry checks /info → resolves a proxy agent
// agent.runAgent() → runtime POST → agent execution → SSE events
```
</FrontendOnly>

<FrontendOnly frontend="angular">
```ts title="你的组件所看到的"
const store = injectAgentStore("default");
const agent = store().agent;
store().messages();
store().state();
agent.subscribe({ /* … */ });
```

```ts title="底层实际发生的"
// injectAgentStore() → registry checks /info → resolves a proxy agent
// core.runAgent({ agent }) → runtime POST → agent execution → SSE events
```
</FrontendOnly>

这层间接性让运行时能够提供身份验证、中间件、智能体路由以及 CopilotKit Intelligence，而无需改变前端与智能体交互的方式。

## 智能体如何接入运行时

在服务端，`CopilotRuntime` 接受一个 AG-UI `AbstractAgent` 实例映射。框架适配器、指向远程服务器的 `HttpAgent`，以及自定义实现，都走相同的请求路径：

1. 运行时按 ID 解析目标智能体。
2. 它克隆该智能体以实现请求隔离，并提供消息、状态与线程上下文。
3. `AgentRunner` 执行智能体并接收 AG-UI 事件。
4. 运行时将这些事件编码为 SSE，并流式传输到前端代理。

后端框架可以更换，而无需对前端的 AG-UI 契约做相应更改。

若要自行编写自定义实现，并让它在第 2 步的克隆过程中保留自己的字段，请参阅[编写你自己的 AG-UI 智能体](/backend/custom-ag-ui-agent)。
