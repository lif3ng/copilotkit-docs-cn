## **生成式 UI 规范**

近期发布的多个规范使智能体能够返回生成式 UI，大大增强了智能体与用户对话的表现力和灵活性。

**A2UI**、**MCP Apps** 和 **Open-JSON-UI** 都是生成式 UI 规范，它们让智能体在回应用户时不再局限于文本，还能返回动态 UI 组件。
CopilotKit 现已全面支持所有主流生成式 UI 规范。

| **规范**          | **来源/维护方**         | **用途**                                                                                                             |
| ----------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **A2UI**          | Google                  | 一种声明式、对 LLM 友好的生成式 UI 规范。基于 JSONL 且支持流式传输，为跨平台渲染而设计。                              |
| **Open-JSON-UI**  | OpenAI                  | 对 OpenAI 内部声明式生成式 UI schema 的开放标准化。                                                                   |
| **MCP Apps**      | MCP 生态                | 基于 iframe 的生成式 UI 规范，扩展了 MCP，使服务器能够返回交互式 UI 组件。                                            |

## **AG-UI 与生成式 UI 规范**

尽管名字相似，**AG-UI 并不是生成式 UI 规范**——它是一个**用户交互协议**，在智能体与应用之间提供**双向运行时连接**。

AG-UI 原生支持上述所有生成式 UI 规范，同时也允许开发者定义**自定义的生成式 UI 标准**。
