## 什么是 CopilotKit Intelligence？

你希望获得 AG-UI 流、用户记忆（User Memory）、自动学习（Automatic Learning）、渠道与产品分析（Product Analytics），又不想自己运维这些存储。CopilotKit Intelligence 会为你已有的 CopilotKit 应用补上这一层。你的前端、智能体和模型都保持原样。

保留你现有的线程系统。接入智能中枢时，无需替换已有的线程存储。[自带线程系统](/intelligence/bring-your-own-thread-system)一文解释了智能中枢如何记录自己的一份副本，同时由你的框架继续管理原始会话与智能体状态。

想添加哪项能力，就打开对应的页面。下面每个页面各自负责一个主题。

通过[快速开始](/intelligence/quickstart)接入现有应用，配置页提供 TypeScript、Python、Go、Ruby 和 C#/.NET 等选项卡。TypeScript 不启用智能中枢也能工作；其他运行时实现则必须启用。

## 已有智能体对话？

将现有应用接入智能中枢，在你当前的智能体之外加上 AG-UI 流。如果需要更早的历史记录，一次性导入即可：

- [导入 LangGraph 线程](/langgraph-python/threads-import)：可从 LangGraph Server / LangSmith 部署，或具备持久化存储的 Python FastAPI 应用导入。
- [导入 Google ADK 会话](/google-adk/threads-import)：可从受支持的 ADK 数据库会话存储，或 Vertex/Agent Engine 会话历史导入。
- 导入 AWS Strands 对话记录：支持 [Python](/strands/threads-import) 与 [TypeScript](/strands-typescript/threads-import)，可从本地会话文件或 S3 导入，Python 还支持原生 AgentCore Memory 会话。

导入只是复制历史，不会建立持续的数据库复制。此后由 CopilotKit 介入的运行会持久化到智能中枢；只要你的智能体仍连接着框架的持久化存储，原有持久化会继续生效。请保留这套原生持久化。

[技能分发](/intelligence/learned-skills)可将来自多个学习容器的已发布 Skills 组合到一个智能体中，每次刷新只需发起一次请求。

轨迹（Trajectories）会在智能体对话的同时记录浏览器活动。[轨迹快速开始](/intelligence/trajectories-quickstart)会把你的应用连接到本地智能中枢项目，并保存你的第一条轨迹。这些指南目前处于早期访问阶段。
