## 概览

无头 UI 使用 `useCopilotChatHeadless_c` hook。聊天 UI 由你自己构建，而 CopilotKit 仍负责运行线程、生成式 UI、建议与中断。

<Callout type="warn">
  **该 hook 需要公开许可证密钥**。自托管与开源项目使用该密钥。云端托管项目使用
  `CPK_INTELLIGENCE_API_KEY`，且不包含此 hook。如果你的项目由 CopilotKit CLI
  创建，请改用[无头 UI](/built-in-agent/custom-look-and-feel/headless-ui)
  中的 v2 基础组件构建 UI。
</Callout>

## 快速开始

  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/full-headless-chat.mp4"

  loop

这些步骤需要一个 `publicLicenseKey`。`npx copilotkit@latest create` 创建的是**云端托管**项目，它拿到的是 `CPK_INTELLIGENCE_API_KEY` 而非许可证密钥，因此由 CLI 脚手架生成的项目不要按本节操作。请改用[无头 UI](/built-in-agent/custom-look-and-feel/headless-ui)。

<Steps>
<Step>
### 创建新应用

脚手架生成一个自托管或开源的 CopilotKit 项目：

```bash
npx copilotkit@latest create
```

然后[自托管 Runtime](/intelligence/self-hosting)，并为提供方获取免费的公开许可证密钥。
</Step>

<Step>
### 为 CopilotKit 提供方配置许可证密钥

用 `CopilotKit` 包裹你的根布局，并传入公开许可证密钥：

```tsx title="src/app/layout.tsx"
<CopilotKit publicLicenseKey="your-free-public-license-key">
  {children}
</CopilotKit>
```
</Step>

<Step>
### 构建无头聊天组件

使用 `useCopilotChatHeadless_c` 获取消息、发送函数与加载状态，再把它们接入你自己的 UI：

```tsx title="src/app/page.tsx"
"use client";
import { useState } from "react";
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";

export default function Home() {
  const { messages, sendMessage, isLoading } = useCopilotChatHeadless_c();
  const [input, setInput] = useState("");

  const handleSend = () => {
    if (input.trim()) {
      sendMessage({
        id: Date.now().toString(),
        role: "user",
        content: input,
      });
      setInput("");
    }
  };

  return (
    <div>
      <h1>My Headless Chat</h1>

      <div>
        {messages.map((message) => (
          <div key={message.id}>
            <strong>{message.role === "user" ? "You" : "Assistant"}:</strong>
            <p>{message.content}</p>
          </div>
        ))}
        {isLoading && <p>Assistant is typing...</p>}
      </div>

      <div>
        <input
          value={input}
          onChange={(e) => setInput(e.target.value)}
          onKeyDown={(e) => e.key === "Enter" && handleSend()}
          placeholder="Type your message here..."
        />
        <button onClick={handleSend} disabled={isLoading}>
          Send
        </button>
      </div>
    </div>
  );
}
```
</Step>
</Steps>

## 使用生成式 UI

你可以通过 `useFrontendTool` / `useComponent` 渲染生成式 UI，也可以读取工具并直接渲染。

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/gen-ui.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### 通过 `useFrontendTool`

注册一个前端工具并附加渲染函数。只要该工具调用出现在消息流中，CopilotKit 就会插入你的组件：

```tsx title="src/app/components/chat.tsx"
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";
import { useFrontendTool } from "@copilotkit/react-core/v2";

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  useFrontendTool({
    name: "showCustomComponent",
    handler: () => "Foo, Bar, Baz",
    render: ({ result, args, status }) => (
      <div
        style={{
          backgroundColor: "red",
          padding: "10px",
          borderRadius: "5px",
        }}
      >
        <p>Custom component</p>
        <p>Result: {result}</p>
        <p>Args: {JSON.stringify(args)}</p>
        <p>Status: {status}</p>
      </div>
    ),
  });

  return (
    <div>
      {messages.map((message) => (
        <p key={message.id}>
          {message.role === "user" ? "User: " : "Assistant: "}
          {message.content}
          {message.role === "assistant" && message.generativeUI?.()}
        </p>
      ))}
    </div>
  );
};
```

### 直接使用原始工具调用数据

如果不想使用 `useFrontendTool`，可以直接渲染原始数据：

```tsx title="src/app/components/chat.tsx"
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  return (
    <div>
      {messages.map((message) => (
        <p key={message.id}>
          {message.role === "assistant" &&
            message.toolCalls?.map((toolCall) => (
              <p key={toolCall.id}>
                {toolCall.function.name}: {toolCall.function.arguments}
              </p>
            ))}
        </p>
      ))}
    </div>
  );
};
```

## 使用建议

CopilotKit 的建议为用户提供一组生成式或静态的提示。无头 hook 对其完整生命周期提供了完全控制。

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/suggestions.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### 生成建议

使用 `useCopilotChatSuggestions` 在无头 UI 中生成并展示提示建议：

```tsx title="src/app/components/chat.tsx"
import {
  useCopilotChatHeadless_c,
  useCopilotChatSuggestions,
} from "@copilotkit/react-core";
import { useEffect } from "react";

export const Chat = () => {
  useCopilotChatSuggestions({
    instructions:
      "Suggest 5 interesting activities for programmers to do on their next vacation",
    maxSuggestions: 5,
  });

  const { suggestions, generateSuggestions, sendMessage } =
    useCopilotChatHeadless_c();

  useEffect(() => {
    generateSuggestions();
  }, []);

  return (
    <div>
      {suggestions.map((s, i) => (
        <button
          key={i}
          onClick={() =>
            sendMessage({
              id: Date.now().toString(),
              role: "user",
              content: s.message,
            })
          }
        >
          {s.title}
        </button>
      ))}
    </div>
  );
};
```

### 以编程方式设置建议

如果需要确定性的控制，可以手动设置建议：

```tsx
const { suggestions, setSuggestions } = useCopilotChatHeadless_c();

useEffect(() => {
  setSuggestions([
    { title: "Suggestion 1", message: "The actual message for suggestion 1" },
    { title: "Suggestion 2", message: "The actual message for suggestion 2" },
  ]);
}, []);
```

## 使用人机协同

人机协同（human-in-the-loop，HITL）会暂停聊天并等待用户输入。它有两种形式：**基于工具**与**基于中断**（仅部分框架支持）。

<video
  src="https://cdn.copilotkit.ai/docs/copilotkit/videos/hitl.mp4"
  className="rounded-xl shadow-lg border"
  loop
  playsInline
  autoPlay
  muted
/>

### 基于工具

基于工具的 HITL 会暂停工具执行，直到用户做出响应。该响应会成为工具的结果。

```tsx title="src/app/components/chat.tsx"
import { useState } from "react";
import { useCopilotChatHeadless_c } from "@copilotkit/react-core";
import { useFrontendTool } from "@copilotkit/react-core/v2";

const NameForm = ({ defaultName, onSubmit }) => {
  const [name, setName] = useState(defaultName || "");

  return (
    <div>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="Enter your name"
      />
      <button onClick={() => onSubmit?.(name)}>Submit</button>
    </div>
  );
};

export const Chat = () => {
  const { messages } = useCopilotChatHeadless_c();

  useFrontendTool({
    name: "getName",
    renderAndWaitForResponse: ({ respond, args, status }) => {
      if (status === "complete") return <div>Name retrieved…</div>;

      // `respond` resolves the pending tool call, so call it only on submit.
      // Editing the field must not complete the turn on the first keystroke.
      return <NameForm defaultName={args.name} onSubmit={respond} />;
    },
  });

  return (
    <>
      {messages.map((message) => (
        <p key={message.id}>
          {message.role === "user" ? "User: " : "Assistant: "}
          {message.content}
          {message.role === "assistant" && message.generativeUI?.()}
        </p>
      ))}
    </>
  );
};
```
