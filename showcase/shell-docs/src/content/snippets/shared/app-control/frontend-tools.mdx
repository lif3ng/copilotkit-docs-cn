## 这是什么？

前端工具让你能够定义智能体可调用的客户端函数，其执行完全发生在用户的浏览器中。当智能体调用前端工具时，逻辑在客户端运行，让你可以直接访问前端环境。

它可以用来让智能体控制 UI、实现生成式 UI，或进行人机协同（human-in-the-loop）交互。本指南将介绍如何使用前端工具来驱动 UI 并与之交互。

## 何时应该使用？

当你需要智能体与以下客户端能力交互时，可以使用前端工具：

- 读取或修改 React 组件状态
- 访问 localStorage、sessionStorage、cookies 等浏览器 API
- 触发 UI 更新或动画
- 与第三方前端库交互
- 执行需要用户当前浏览器上下文的操作

## 创建前端工具

使用 `useFrontendTool` hook 创建一个智能体可从客户端调用的工具：

```tsx title="page.tsx"
import { z } from "zod";
import { useFrontendTool } from "@copilotkit/react-core/v2"; // [!code highlight]

export function Page() {
  // ...

  // [!code highlight:12]
  useFrontendTool({
    name: "sayHello",
    description: "Say hello to the user",
    parameters: z.object({
      name: z.string().describe("The name of the user to say hello to"),
    }),
    handler: async ({ name }) => {
      alert(`Hello, ${name}!`);
      return `Said hello to ${name}!`;
    },
  });

  // ...
}
```
