CopilotKit 使用仅含元数据的产品遥测来了解如何改进开源软件包。

- 我们不会收集提示、消息、智能体状态、工具数据或其他应用内容。
- 我们不会出售遥测数据，也不会与第三方共享。
- 我们不会在开源遥测中使用 cookie 或追踪器。

Runtime 会按以下顺序使用第一个非空且能放入 HTTP 头的遥测身份：显式指定的 `telemetryId`、`CPK_TELEMETRY_ID`，然后是 `COPILOTKIT_LICENSE_TOKEN` 所携带的身份。

`CPK_TELEMETRY_ID` 是可选且非机密的。CopilotKit CLI 不会创建或写入 `CPK_TELEMETRY_ID`，你自行选择的值也不会自动把 Runtime 事件与 CLI 脚手架事件关联起来。设置它不会开启遥测、不会授予产品访问权限，也不能替代项目的智能中枢 API 密钥。

云托管的智能中枢起步模板使用 `CPK_INTELLIGENCE_API_KEY` 访问平台。项目 API 密钥不是遥测身份。

云托管配置不会签发 `COPILOTKIT_LICENSE_TOKEN`。该令牌仅用于离线或自托管授权，因此云托管起步模板不携带许可证令牌身份。自托管部署设置了该令牌时，它就提供回退身份。若这些身份都不存在，Runtime 会发送匿名遥测。

Inspector 会在本地存储中保存一个随机浏览器 ID，并在功能使用事件中直接发送该 ID。CopilotKit 注册链接可以携带该 ID，以便我们衡量从使用 Inspector 到注册的路径。Inspector 的遥测发送不依赖 `CPK_TELEMETRY_ID`。

## Inspector 元数据事件

当受信任的项目上下文模块变为可见、以及用户执行套餐相关操作时，Inspector 会发送粗粒度事件：

| 事件                                    | 与特性相关的属性                                                                                 |
| --------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `oss.inspector.metadata_module_viewed`  | `module`、`license_bucket`，以及可见模块为操作时的 `action_kind`                                 |
| `oss.inspector.metadata_action_clicked` | **Manage plan** 与 **Renew** 点击所对应的 `module: "action"`、`action_kind` 和 `license_bucket`  |

`module` 取值为 `identity`、`plan` 或 `action`。`action_kind` 取值为 `manage_plan`、`renew` 或 `enable_intelligence`。`license_bucket` 取值为 `valid`、`none`、`expired` 或 `unknown`。

**Enable Intelligence** 的点击仍沿用已有的 `oss.inspector.threads_intelligence_signup_clicked` 事件，以便现有报表保持连续。同一次点击不会再额外发送 `oss.inspector.metadata_action_clicked`。

与特性相关的载荷绝不包含组织、项目、账户或用户名称；账户、组织、项目、用户、线程、运行或消息 ID；操作或 runtime URL；用量数值、限额或计数；也不包含对话与工具内容。不会发送元数据用量曝光。标准匿名遥测信封包含包身份信息、匿名 distinct ID 以及事件时间戳。

## 如何退出开源遥测

在你的运行时环境中设置 `COPILOTKIT_TELEMETRY_DISABLED=true`。这会同时关闭 CopilotRuntime 和 Inspector 的遥测。我们同样遵循 [Do Not Track（DNT）](https://consoledonottrack.com/)。
