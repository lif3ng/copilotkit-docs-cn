## 概览

CopilotKit V2 将前端整合为单一包。钩子和 UI 组件现在都从 `@copilotkit/react-core/v2` 导出。你的后端无需任何更改。

**变更内容**：

| 之前                              | 之后                                   |
| --------------------------------- | -------------------------------------- |
| v1 hooks from `@copilotkit/react-core` | v2 hooks from `@copilotkit/react-core/v2` |
| `@copilotkit/react-ui`            | `@copilotkit/react-core/v2`            |
| `@copilotkit/react-ui/styles.css` | `@copilotkit/react-core/v2/styles.css` |

**保持不变的内容**：

- 后端包（`@copilotkit/runtime` 等）无需更改。
- 你的 `CopilotRuntime` 配置保持不变。
- 智能体定义与后端设置保持不变。
- `<CopilotKit>` Provider 名称不变，但需从 `@copilotkit/react-core/v2` 导入。

## 迁移步骤

<Steps>
<Step>
### 更新 v1 钩子导入

将来自 `@copilotkit/react-core` 的 v1 钩子替换为 `@copilotkit/react-core/v2` 中对应的 v2 版本。
`<CopilotKit>` Provider 名称不变，但需从 `@copilotkit/react-core/v2` 导入。

#### 之前

```tsx
import { CopilotKit } from "@copilotkit/react-core";
import { useCopilotReadable, useCopilotAction } from "@copilotkit/react-core";
```

#### 之后

```tsx
import { CopilotKit, useAgent } from "@copilotkit/react-core/v2";
```

#### v1 到 v2 的钩子映射

使用下表查找每个 v1 钩子对应的 v2 替代：

| v1 钩子 | v2 钩子 |
| --- | --- |
| `useCopilotAction` | `useFrontendTool` |
| `useCopilotReadable` | `useAgentContext` |
| `useCopilotAdditionalInstructions` | `useAgentContext` |
| `useCoAgent` | `useAgent` |
| `useCopilotChat` | `useAgent`（低层无头聊天：`useCopilotChatHeadless_c`） |

聊天 UI 自定义属性在 v2 中也做了重命名：

| v1（组件属性） | v2（插槽/属性） |
| --- | --- |
| `AssistantMessage` | `assistantMessage` 插槽（位于 `messageView` 下） |
| `markdownTagRenderers` | `markdownRenderer` 插槽（位于 `assistantMessage` 下） |

v2 的插槽系统如何取代 v1 的组件覆盖属性，参见[插槽](/custom-look-and-feel/slots)。

</Step>
<Step>
### 替换 React UI 导入

`CopilotChat`、`CopilotSidebar` 和 `CopilotPopup` 等 UI 组件现在从 `@copilotkit/react-core/v2` 导出。

#### 之前

```tsx
import { CopilotPopup } from "@copilotkit/react-ui";
import { CopilotSidebar } from "@copilotkit/react-ui";
import { CopilotChat } from "@copilotkit/react-ui";
```

#### 之后

```tsx
import { CopilotPopup } from "@copilotkit/react-core/v2";
import { CopilotSidebar } from "@copilotkit/react-core/v2";
import { CopilotChat } from "@copilotkit/react-core/v2";
```

</Step>
<Step>
### 更新样式导入

#### 之前

```tsx
import "@copilotkit/react-ui/styles.css";
```

#### 之后

```tsx
import "@copilotkit/react-core/v2/styles.css";
```

</Step>
<Step>
### 如果直接使用 AG-UI client，请将其升级

如果你直接从 `@ag-ui/client` 导入，请安装 `@copilotkit/runtime` 所依赖的版本：

```bash
npm install @ag-ui/client@1.0.2
```

安装不同的版本会导致该包出现第二份副本，并带有自己的 `HttpAgent` 类。运行 `npm ls @ag-ui/client` 确保只安装了一个版本。

注意：如果你只使用 CopilotKit 的 React 包，`@ag-ui/client` 的类型已经从 `@copilotkit/react-core/v2` 重新导出，无需单独安装。

</Step>
</Steps>

## 完整示例

### 之前

```tsx
import { CopilotKit } from "@copilotkit/react-core";
import { CopilotPopup } from "@copilotkit/react-ui";
import "@copilotkit/react-ui/styles.css";

export function App() {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit">
      <YourApp />
      <CopilotPopup />
    </CopilotKit>
  );
}
```

### 之后

```tsx
import { CopilotKit, CopilotPopup } from "@copilotkit/react-core/v2";
import "@copilotkit/react-core/v2/styles.css";

export function App() {
  return (
    <CopilotKit runtimeUrl="/api/copilotkit">
      <YourApp />
      <CopilotPopup />
    </CopilotKit>
  );
}
```
