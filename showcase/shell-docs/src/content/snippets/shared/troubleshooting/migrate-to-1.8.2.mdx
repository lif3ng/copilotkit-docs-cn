## 有哪些变更？

### 全新的外观与体验

CopilotKit 1.8.2 引入了全新的默认外观与体验，包括主题化变量的新用法、新组件，以及整体焕然一新的视觉效果。

**点击右下角的按钮，即可查看全新外观与体验的实际效果！**

### 点赞/点踩处理函数

聊天组件现在支持 `onThumbsUp` 和 `onThumbsDown` 处理函数。指定这两个函数后，鼠标悬停在每条消息上时会出现图标，允许用户提供反馈。

```tsx
<CopilotChat
  onThumbsUp={(message) => console.log(message)}
  onThumbsDown={(message) => console.log(message)}
/>
```

此前在我们的框架中也能实现这一功能，但现在我们将其提升为一等公民！你可以借此通过 CopilotKit 微调模型，或者一般性地跟踪用户反馈。

### 移除 ResponseButton 属性

`ResponseButton` 属性已被移除。该属性曾用于自定义聊天中生成响应后出现的按钮。

取而代之的是，我们现在在每条消息下方放置以下按钮：

- 点赞
- 点踩
- 复制
- 重新生成

每个按钮的行为、图标和样式都可以自定义。详情请参阅我们的[外观与体验指南](/custom-look-and-feel)。

### 开箱即用的深色模式支持

CopilotKit 现已支持开箱即用的深色模式。它由 `.dark` 类（Tailwind）和 `color-scheme` CSS 选择器控制。

如果你想制作自定义主题，请参阅[自定义外观与体验](/custom-look-and-feel)指南。
