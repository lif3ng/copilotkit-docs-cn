  <Tab value="CopilotPopup">

    `CopilotPopup` 是 `CopilotChat` 的一种便捷包装器，它与你的主内容处于视图层级的同一层级，提供一个**可随时开启和关闭的浮动聊天界面**。

    <img src="https://cdn.copilotkit.ai/docs/copilotkit/images/popup-example.gif" alt="Popup Example" className="w-full rounded-lg my-4" />

    ```tsx
    // [!code word:CopilotPopup]
    import { CopilotPopup } from "@copilotkit/react-core/v2";

    export function YourApp() {
      return (
        <>
          <YourMainContent />
          <CopilotPopup
            labels={{
              modalHeaderTitle: "Popup Assistant",
              welcomeMessageText: "Need any help?",
            }}
          />
        </>
      );
    }
    ```

  <Tab value="CopilotSidebar">
    `CopilotSidebar` 是 `CopilotChat` 的一种便捷包装器，它在视图层级中包裹你的主内容，提供一个**可折叠、可展开的侧边栏**聊天界面。

    <img src="https://cdn.copilotkit.ai/docs/copilotkit/images/sidebar-example.gif" alt="Sidebar Example" className="w-full rounded-lg my-4" />

    ```tsx
    // [!code word:CopilotSidebar]
    import { CopilotSidebar } from "@copilotkit/react-core/v2";

    export function YourApp() {
      return (
        <CopilotSidebar
          defaultOpen={true}
          labels={{
            modalHeaderTitle: "Sidebar Assistant",
            welcomeMessageText: "How can I help you today?",
          }}
        >
          <YourMainContent />
        </CopilotSidebar>
      );
    }
    ```

  </Tab>
  <Tab value="CopilotChat">
    `CopilotChat` 是一个灵活的聊天界面组件，**可以放置在应用中的任意位置**，并能按需调整大小。

    <img src="https://cdn.copilotkit.ai/docs/copilotkit/images/copilotchat-example.gif" alt="CopilotChat Example" className="w-full rounded-lg my-4" />

    ```tsx
    // [!code word:CopilotChat]
    import { CopilotChat } from "@copilotkit/react-core/v2";

    export function YourComponent() {
      return (
        <CopilotChat
          labels={{
            modalHeaderTitle: "Your Assistant",
            welcomeMessageText: "Hi! How can I assist you today?",
          }}
        />
      );
    }
    ```

  <Tab value="Headless UI">
    内置的 Copilot UI 可以通过多种方式进行自定义——既可以通过 CSS，也可以使用插槽（slot）系统替换组件。

    CopilotKit 还通过 `useAgent` 和 `useCopilotKit` 这两个 Hook 提供**完全自定义的无头（headless）UI**。凡是内置 UI 能构建的一切（乃至更多），都可以用无头 UI 实现，可定制程度非常深。

    ```tsx
    import { useAgent } from "@copilotkit/react-core/v2";
    import { useCopilotKit } from "@copilotkit/react-core/v2";
    import { randomUUID } from "@copilotkit/shared";

    export function CustomChatInterface() {
      const { agent } = useAgent();
      const { copilotkit } = useCopilotKit();

      const sendMessage = async (content: string) => {
        agent.addMessage({
          id: randomUUID(),
          role: "user",
          content,
        });
        await copilotkit.runAgent({ agent });
      };

      return (
        <div>
          {/* Implement your custom chat UI here */}
        </div>
      );
    }
    ```
