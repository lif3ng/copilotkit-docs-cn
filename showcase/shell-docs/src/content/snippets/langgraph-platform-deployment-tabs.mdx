  <Tab value="本地（LangGraph Studio）">
    在本地开发时，你可以使用 [LangGraph CLI](https://docs.langchain.com/langsmith/cli) 启动一个开发服务器和 LangGraph studio 会话。

    <Callout type="info">
      使用此方法需要一个 [LangSmith 账户](https://smith.langchain.com)。
    </Callout>

    <Callout type="warning">
      **仅限 Python 智能体**：如果遇到 “No checkpointer set” 错误，请在命令前加上 `LANGGRAPH_API=true`：

      ```bash
      LANGGRAPH_API=true langgraph dev --host localhost --port 8000
      ```

      这会让你的智能体在不使用自定义 checkpointer 的情况下运行，转而依赖 LangGraph 内置的状态管理。
    </Callout>

    ```bash
    # 适用于 Python 3.11 或更高版本
    langgraph dev --host localhost --port 8000
    ```

    ```bash
    # 适用于 TypeScript 与 Node 20 或更高版本
    npx @langchain/langgraph-cli dev --host localhost --port 8000
    ```

    启动 LangGraph 服务器后，部署 URL 将为 `http://localhost:8000`。

    <Accordions className="mb-4">
        <Accordion title="遇到问题？">
            如果你无法运行 `langgraph dev` 命令，或在使用它时遇到任何问题，请改用这条命令：
            `uvx --refresh --from "langgraph-cli[inmem]" --with-editable . --python 3.12 langgraph dev`
        </Accordion>
        <Accordion title="langgraph dev 出现 “No checkpointer set” 错误">
          Python 智能体会自动检测其运行环境，但有时需要显式指引：

          - **使用 `langgraph dev` 时**：设置 `LANGGRAPH_API=true` 以禁用自定义 checkpointer
          - **使用本地 FastAPI 时**：不要设置该标志；会自动使用 MemorySaver
          - **JavaScript 智能体**：不受此问题影响
        </Accordion>
    </Accordions>

  </Tab>

  <Tab value="自托管（FastAPI）">
    <Callout type="info">
      此方法目前仅支持 Python LangGraph 智能体。
    </Callout>

    1. 添加一个 `.env` 文件，用于存放你的 LangSmith API 密钥。

    ```plaintext title=".env"
    LANGSMITH_API_KEY=your_langsmith_api_key
    ```

    2. 接下来，使用 CopilotKit 的 FastAPI 集成来托管你的 LangGraph 智能体。

    ```python title="server.py"
    import os
    from fastapi import FastAPI
    import uvicorn
    from copilotkit import LangGraphAGUIAgent # [!code highlight]
    from ag_ui_langgraph import add_langgraph_fastapi_endpoint # [!code highlight]
    from sample_agent.agent import graph # the coagents-starter path, replace this if its different # [!code highlight]

    from dotenv import load_dotenv
    load_dotenv()

    app = FastAPI()
    # [!code highlight:9]
    add_langgraph_fastapi_endpoint(
      app=app,
      agent=LangGraphAGUIAgent(
        name="sample_agent", # the name of your agent defined in langgraph.json
        description="Describe your agent here, will be used for multi-agent orchestration",
        graph=graph, # the graph object from your langgraph import
      ),
      path="/your-agent-path", # the endpoint you'd like to serve your agent on
    )

    # add new route for health check
    @app.get("/health")
    def health():
        """Health check."""
        return {"status": "ok"}

    def main():
        """Run the uvicorn server."""
        port = int(os.getenv("PORT", "8000"))
        uvicorn.run(
            "sample_agent.demo:app", # the path to your FastAPI file, replace this if its different
            host="0.0.0.0",
            port=port,
            reload=True,
        )

    ```
