按照 [Agno 快速开始](/agno/quickstart) 配置你的智能体。如果走 **使用现有智能体**（Use an existing agent）路径，启动 `main.py` 应用：

```bash title="智能体应用"
uv run main.py
```

如果你选择的是 CLI 起步模板，则保持其 `npm run dev` 进程运行。

Agno 会把主智能体暴露在这个固定的 AG-UI 端点上：

```dotenv title=".env"
AGENT_URL=http://localhost:8000/agui
```

在渠道（Channels）进程中安装 HTTP 适配器：

```bash title="终端"
npm install @ag-ui/client@0.0.59
```

为每个渠道线程创建一个新的 HTTP 适配器：

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
