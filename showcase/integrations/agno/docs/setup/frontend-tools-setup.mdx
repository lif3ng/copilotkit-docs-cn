    ### 将组件声明为外部工具

    Agno 的 AG-UI 接口不会把请求中的工具定义转发给模型。模型只能看到声明在 `Agent` 上的工具，因此通过 `useComponent` 注册的组件需要一个对应的声明，且其函数体保持为空。将其标记为 `external_execution=True`：Agno 会暂停这次运行，浏览器渲染组件，然后运行带着结果恢复。

    名称与参数必须和 `useComponent` 的注册完全一致。docstring 是模型会读到的内容，所以要在这里描述何时调用它。

    ```python title="src/agents/chart_agent.py"
    from agno.agent import Agent
    from agno.models.openai import OpenAIChat
    from agno.tools import tool


    @tool(external_execution=True)
    def render_bar_chart(title: str, data: list[dict]):
        """
        Render a bar chart in the chat.

        Call this whenever the user asks for a chart or a comparison.

        Args:
            title (str): A concise chart title.
            data (list[dict]): Items shaped `{label, value}`.
        """


    agent = Agent(
        model=OpenAIChat(id="gpt-4o"),
        db=db,
        tools=[render_bar_chart],
        instructions=SYSTEM_PROMPT,
    )
    ```

  </Step>
  <Step>
    ### 为智能体提供存放暂停运行的位置

    在浏览器返回结果之前，Agno 需要先把暂停的运行存储起来，因此持有外部工具的 `Agent` 需要一个数据库。带有外部工具却没有 `db` 的智能体，在浏览器作答之后无法恢复运行。

    ```python title="src/agents/chart_agent.py"
    from agno.db.sqlite import SqliteDb

    db = SqliteDb(db_file="tmp/agno.db")
    ```

    `SqliteDb` 需要安装 `sqlalchemy`。生产环境请使用 `PgDb` 这类持久化的共享存储，因为临时性的容器文件无法在另一个实例上恢复运行。

  </Step>
</Steps>
