按照 [Mastra 快速开始](/mastra/quickstart) 操作，并用其原有命令保持该应用运行：

```bash title="Mastra 应用"
npm run dev
```

Mastra 当前的 Next.js 示例暴露的是 CopilotKit 的单路由协议，而不是 `HttpAgent` 能直接调用的 URL。请在现有路由旁边添加下面这个多路由桥接。它复用快速开始中注册的 `myAgent`，同时为每个传入的线程创建一个请求作用域的适配器：

```ts title="src/app/api/copilotkit/[...path]/route.ts"
import { getLocalAgent } from "@ag-ui/mastra";
import {
  CopilotRuntime,
  createCopilotRuntimeHandler,
} from "@copilotkit/runtime/v2";
import { mastra } from "@/mastra";

const runtime = new CopilotRuntime({
  agents: async ({ request }) => {
    const input =
      request.method === "POST"
        ? await request
            .clone()
            .json()
            .catch(() => ({}) as { threadId?: string })
        : ({} as { threadId?: string });
    const threadId =
      typeof input.threadId === "string" ? input.threadId : "channels-info";

    return {
      myAgent: getLocalAgent({
        mastra,
        agentId: "myAgent",
        resourceId: threadId,
      }),
    };
  },
});

const handler = createCopilotRuntimeHandler({
  runtime,
  basePath: "/api/copilotkit",
  cors: true,
});

export const GET = handler;
export const POST = handler;
export const OPTIONS = handler;
```

独立的渠道（Channels）运行器调用的是该桥接中具体的智能体运行路由：

```dotenv title=".env"
AGENT_URL=http://localhost:3000/api/copilotkit/agent/myAgent/run
```

如果你注册的是别的 Mastra 智能体 id，请把桥接代码和 URL 中的 `myAgent` 都替换为那个确切的 id。

在渠道运行器中安装 HTTP 适配器，并为每个渠道线程创建一个全新的客户端：

```bash title="渠道运行器"
npm install @ag-ui/client@0.0.59
```

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
