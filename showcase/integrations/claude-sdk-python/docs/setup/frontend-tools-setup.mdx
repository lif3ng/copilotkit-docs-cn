    ### 将浏览器工具转发给 Claude

    通过 `useFrontendTool` 注册的前端工具会随 AG-UI 运行输入送达。本示例的服务器在运行携带前端工具时会直接调用 Anthropic Messages API，因此它先把每个 AG-UI 工具定义转换为 Messages API 的工具 schema。

    `ag_ui_claude_sdk` 发布的 `ClaudeAgentAdapter` 则无需这种转换。它会把自己的进程内 MCP 工具服务器上的每个前端工具注册为 `mcp__ag_ui__<name>` 并将其加入允许列表，当 Claude 调用该工具时结束这次运行，让浏览器得以执行该工具。把运行输入传给适配器，前端工具无需额外接线即可工作。
