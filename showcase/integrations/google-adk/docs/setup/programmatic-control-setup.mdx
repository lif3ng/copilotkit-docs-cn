    ### 安装 ADK + AG-UI 桥接器

    ```bash
    pip install ag-ui-adk
    ```

  </Step>
  <Step>
    ### 将 `AGUIToolset()` 添加到你的智能体

    编程式控制（`copilotkit.runAgent`、`agent.subscribe`、`agent.addMessage`）通过与聊天 UI 所用的同一个智能体来驱动运行，因此后端接线完全相同——只需接入一次 `AGUIToolset()`，每个入口看到的转发工具和状态都一样。

    <DemoCode file="src/agents/hitl_in_chat_agent.py" region="setup" />

    ADK 没有提供原生 `interrupt(...)` 原语——对于无头（headless）的中断解析器模式，请改用前端基于 Promise 的 `useFrontendTool` 处理器。

  </Step>
