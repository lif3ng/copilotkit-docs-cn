按照 [LangGraph FastAPI 快速开始](/langgraph-fastapi/quickstart) 配置 `sample_agent` 图和 AG-UI 端点，然后启动同一个 FastAPI 应用：

```bash title="智能体应用"
uv run main.py
```

将 LangGraph HTTP 适配器指向 AG-UI 端点：

```dotenv title=".env"
AGENT_URL=http://localhost:8123/
```

通过 Channels 快速开始安装的 Runtime 包已包含原生 LangGraph 适配器。

这个 selector 变体沿用了快速开始中的 FastAPI 部署方式，因此需使用 `LangGraphHttpAgent`。为每个渠道线程返回一个全新的适配器：

```ts title="agent.ts"
import { LangGraphHttpAgent } from "@copilotkit/runtime/langgraph";

export function makeAgent(threadId: string) {
  const agent = new LangGraphHttpAgent({
    url: process.env.AGENT_URL!,
  });
  agent.threadId = threadId;
  return agent;
}
```
