    ### 将浏览器工具转发给 Claude

    通过 `useFrontendTool` 注册的前端工具会随 AG-UI 运行输入一起送达。本示例的服务器对携带前端工具的运行直接调用 Anthropic Messages API，因此会先把每个 AG-UI 工具定义转换为 Messages API 工具 schema。

    来自 `@ag-ui/claude-agent-sdk` 的已发布 `ClaudeAgentAdapter` 则无需这种转换。它会把每个前端工具以 `mcp__ag_ui__<name>` 的形式注册到自己的进程内 MCP 工具服务器上，将其加入允许列表，并在 Claude 调用它时结束本次运行，让浏览器得以执行该工具。只要把运行输入传给适配器，前端工具无需任何额外接线即可工作。
