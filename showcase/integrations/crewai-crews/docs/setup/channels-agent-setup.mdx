通过 AG-UI 服务器暴露你的 CrewAI Flow。[CopilotKit CrewAI Crews showcase](https://github.com/CopilotKit/CopilotKit/tree/main/showcase/integrations/crewai-crews) 包含一个参考服务器；在该集成目录下运行：

```bash title="智能体应用"
PYTHONPATH=src python -m uvicorn agent_server:app --host 0.0.0.0 --port 8000 --reload
```

共享的聊天 Flow 挂载在 `/chat`：

```dotenv title=".env"
AGENT_URL=http://localhost:8000/chat
```

在 Channels 进程中安装 HTTP 适配器：

```bash title="终端"
npm install @ag-ui/client@0.0.59
```

为每个渠道线程创建一个新的 HTTP 适配器：

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
