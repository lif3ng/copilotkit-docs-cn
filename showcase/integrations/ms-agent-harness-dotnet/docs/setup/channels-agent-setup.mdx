按照 [Microsoft Agent Harness .NET 快速开始](/ms-agent-harness-dotnet/quickstart) 配置你的智能体。保持其 AG-UI 服务器在 `http://localhost:8000` 上运行：可以是 CLI 起步模板的 `agent` 项目，也可以是**使用现有智能体**路径的 `AGUIServer` 项目。

共享的 Microsoft 智能体映射在服务器根路径：

```dotenv title=".env"
AGENT_URL=http://localhost:8000/
```

在渠道（Channels）进程中安装 HTTP 适配器：

```bash title="终端"
npm install @ag-ui/client@0.0.59
```

为每个渠道线程创建一个新的 HTTP 适配器：

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
