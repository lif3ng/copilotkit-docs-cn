<Steps>
  <Step>
    ### 智能体侧无需任何接线

    AG2 的 AG-UI 流会在每次运行时把前端注册的工具呈现给模型，因此智能体自身无需声明任何工具。通过 `useComponent` 注册的组件会经由 AG-UI 请求负载到达模型，模型按名称调用它。当参与其中的工具全部是前端工具时，把 `tools` 留空即可。

    ```python title="src/agents/chart_agent.py"
    from ag2 import Agent
    from ag2.ag_ui import AGUIStream
    from ag2.config import OpenAIResponsesConfig

    chart_agent = Agent(
        name="chart_agent",
        prompt=SYSTEM_PROMPT,
        config=OpenAIResponsesConfig(model="gpt-5.5"),
        tools=[],
    )

    chart_stream = AGUIStream(chart_agent)
    ```

  </Step>
  <Step>
    ### 告诉模型何时调用它

    这是最容易漏掉的一步。工具虽然每次运行都会送达，但如果模型没有收到任何相关指示，它就会用一段文字作答，而永远不会调用该工具。在 `prompt` 中点名这个工具，并说明它的用途。

    ```python title="src/agents/chart_agent.py"
    SYSTEM_PROMPT = (
        "You are a data visualization assistant. "
        "When the user asks for a chart, call `render_bar_chart` with a "
        "concise title and a `data` array of `{label, value}` items. "
        "Keep chat responses brief and let the chart do the talking."
    )
    ```

  </Step>
</Steps>
