  <Step>
    ### 智能体侧无需任何接线

    每次运行时，AG-UI Strands 适配器都会针对请求携带的每个工具，在智能体的工具注册表中注册一个代理工具，因此智能体自身无需声明任何工具。通过 `useComponent` 注册的组件按名称送达模型，由浏览器执行调用。

    ```python title="src/agents/chart_agent.py"
    from strands import Agent
    from strands.models.openai import OpenAIModel

    from ag_ui_strands import StrandsAgent

    strands_agent = Agent(
        model=OpenAIModel(model_id="gpt-4o"),
        system_prompt=SYSTEM_PROMPT,
        tools=[],
    )

    agui_agent = StrandsAgent(
        agent=strands_agent,
        name="chart_agent",
        description="Renders charts from data.",
    )
    ```

    已占用该名称的后端工具优先：适配器绝不会用代理工具替换原生工具。请保持 `useComponent` 的名称与 `tools=` 中的所有工具名称互不相同。

  </Step>
  <Step>
    ### 告诉模型何时调用它

    这是最容易被忽略的一步。工具虽然每次运行都会送达，但如果模型没有收到相关指示，它只会用文字作答，永远不会调用工具。请在 `system_prompt` 中写明工具名称，并说明它的用途。

    ```python title="src/agents/chart_agent.py"
    SYSTEM_PROMPT = (
        "You are a data visualization assistant.\n"
        "When the user asks for a chart, call the frontend `render_bar_chart` "
        "tool with a concise title and a `data` array of `{label, value}` "
        "items.\n"
        "Keep chat responses brief and let the chart do the talking."
    )
    ```

  </Step>
</Steps>
