按照 [LangGraph Python 快速开始](/langgraph-python/quickstart) 配置 `sample_agent` 图。启动它自带的 LangGraph 服务器：

```bash title="智能体应用"
npx @langchain/langgraph-cli dev --port 8123 --no-browser
```

将原生 LangGraph 适配器指向该部署：

```dotenv title=".env"
LANGGRAPH_DEPLOYMENT_URL=http://localhost:8123
```

通过 Channels 快速开始安装的 Runtime 包已包含原生 LangGraph 适配器。

LangGraph Server 使用的是 LangGraph API，因此应选用 `LangGraphAgent` 而非 `HttpAgent`。为每个渠道线程返回一个全新的适配器：

```ts title="agent.ts"
import { LangGraphAgent } from "@copilotkit/runtime/langgraph";

export function makeAgent(threadId: string) {
  const agent = new LangGraphAgent({
    deploymentUrl: process.env.LANGGRAPH_DEPLOYMENT_URL!,
    graphId: "sample_agent",
  });
  agent.threadId = threadId;
  return agent;
}
```
