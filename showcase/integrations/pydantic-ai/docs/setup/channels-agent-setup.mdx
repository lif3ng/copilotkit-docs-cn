按照 [PydanticAI 快速开始](/pydantic-ai/quickstart) 配置你的智能体。对于其中**使用现有智能体**这条路径，启动 `main.py`：

```bash title="智能体应用"
uv run main.py
```

如果你选择的是 CLI 起步模板，请保持其 `npm run dev` 进程持续运行。

共享的 PydanticAI 智能体挂载在服务器根路径：

```dotenv title=".env"
AGENT_URL=http://localhost:8000/
```

在 Channels 进程中安装 HTTP 适配器：

```bash title="终端"
npm install @ag-ui/client@0.0.59
```

为每个渠道线程创建一个新的 HTTP 适配器：

```ts title="agent.ts"
import { HttpAgent } from "@ag-ui/client";

export function makeAgent(threadId: string) {
  const agent = new HttpAgent({ url: process.env.AGENT_URL! });
  agent.threadId = threadId;
  return agent;
}
```
